# 생성 〈보기〉 문항과 실제 기출 비교

## 새 관찰

- 생성 지문 3편의 12문항과 기출 지문 3편의 실제 〈보기〉 4문항을 원문·그림까지 비교했다. 정답 경로와 한계는 `docs/experiments/item-on-generated-2026-11-17/REPORT-generated-vs-past-exam-{human,desktop}.md`.
- 과학·기술 생성 지문의 정답은 지문 결론 문장과 직접 맞물리는 사례가 반복됐다. 같은 생성기 비교의 ‘정리 문장으로 풀림’ 7/12(생성 지문) 대 3/12(기출 지문)는 `docs/experiments/item-on-generated-2026-11-17/JUDGE.md`의 기존 단독 판정이다. 과설명은 원인 **가설**이고, 주제 차이가 있어 인과 검증은 아니다.
- 청약 철회 생성 문항은 적용·계산 단계가 있으나 버전 간 함정 중복 검사가 있다. 기출도 도플러 11번처럼 직접 대조형을 포함한다. 실제 학생 변별력 자료는 없다.

## 다음

- 과학·기술 지문의 정리 문장 압력을 조절한 별도 조건 비교를 설계한다. 새 외부 전송 전에 저장된 요청·응답의 지시문·모델·입력 일치를 확인해 기준 조건 재활용 여부를 판단한다(D-0168). 규칙 변경과 운영 채택은 미결정이다.
