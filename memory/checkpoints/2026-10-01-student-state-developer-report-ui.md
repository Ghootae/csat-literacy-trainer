# 학생 상태 개발자 리포트 UI

개발자 워크벤치에 학생 상태 리포트 드로어를 연결했다.

- 학생 학습과 개발자 캘리브레이션 기록을 전환하되 같은 프로필에 섞지 않는다.
- 최근 7·30·90일 관측 창을 선택하고 요청 기간을 프로필에 보존한다.
- 네 상태 차원의 긍정·부정·불확정 증거, 서로 다른 콘텐츠 수, 자료 신뢰도, 도움 단계 분포를 표시한다.
- 강점 후보·연습 후보·다음 행동과 해석 한계를 함께 표시한다.
- 자료가 없거나 부족하면 능력 판단 대신 자료 부족을 명시한다.
- 학생용 `/dialogue`에는 리포트를 노출하지 않았다.

검증:

- 학생 상태 코어·저장소·문단/문제 controller 29테스트 통과
- 서버·클라이언트 TypeScript 검사 통과
- 격리 포트의 `dialogue-workbench.spec.ts` 브라우저 4/4 통과. 학생/개발자 기록 전환, 빈 상태,
  기존 3단 워크벤치, 선택적 보완, 학생 모바일 흐름, 개발자 API 비활성 보안을 함께 확인했다.

다음은 새 형식의 실제 사용 로그를 축적·감사해 현재 휴리스틱과 문구를 사람 검토하고, 학생용
정기 피드백 노출 여부와 주기를 별도로 승인하는 것이다.
