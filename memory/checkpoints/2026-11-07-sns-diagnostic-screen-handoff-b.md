## 인계 B 판단(사용자 승인, 웹 에이전트 의견 반영)

- J1 층별 꼬리표(큰 그림형/나열형) 없이 층별 개수만. J3 관계 자체 오류 개수 함께 표시. J4·J5 바뀐 내용 문장·추천 대응표는 빈 형식, 공개 전 필수.
- J2 요약과 틀린 문항 연결 포함: 선지 연결 동결본 `twistTargetIds`(비틀린 조각 51개 중 47개, id 49개 모두 지도에 있음).
  "적절하지 않은 것" 문항(16문항 중 7)은 고른 선지에 비틂이 없어 정답 선지의 비튼 부분을 본다.
- J6 원문 복사는 화면에서 거르지 않고 5글자 묶음 겹침 비율(`copyOverlap`)만 기록.
- J7 새 학생 문장 확정, 버튼은 "근거 미제출"(D-0208과 같게).

## 검토에서 고친 것(코드 에이전트 diff 검토)

- 요약 연결 문장이 문단 번호 대신 문단 개수를 썼고, (가)(나) 지문은 이어진 번호(예: (나) 3문단 = 7)였다. 서버가 `paragraphLabel`("2·3문단", "(나) 3문단")을 만들고
  문장은 "… 확인해야 했던 (나) 3문단 내용은 …"으로 바꿨다(괄호 겹침 피함). 인계의 `{k}` 표기가 모호했던 탓.
