# 학생 상태 증거 영속화·개발자 API

학생 상태 V1 코어를 실제 연결 학습 세션에 연결했다.

- 문단 전체 handoff 완성 시 문단 증거를 한 번 기록한다.
- 문제 완료 시 최초 근거·회복·확신도 증거를 한 번 기록한다.
- `JsonlStudentEvidenceStore`가 증거 JSONL을 저장·조회하고 프로필과 피드백을 재계산한다.
- 개발자 전용 `GET /api/developer/student-state`가 로컬 프로필과 정기 피드백을 반환한다.
- 학생용 UI 노출은 하지 않았다.

검증은 학생 상태 코어·저장소·문단 controller·문제 controller 4파일 29테스트 통과, 전체 서버·클라이언트 TypeScript 검사 통과다. 전체 회귀의 과거 `.omc` fixture 부재 1건은 이전 체크포인트에 별도로 기록했다.

다음 단계는 실제 또는 보존된 사용자 로그로 이벤트 변환과 피드백 문구를 감사하고, 개발자 UI에서 근거를 펼쳐볼 수 있는 리포트를 만드는 것이다.
