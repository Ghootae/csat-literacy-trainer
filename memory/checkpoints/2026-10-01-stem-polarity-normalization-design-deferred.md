# 발문 극성 정규화 설계 승인·구현 보류

- 날짜: 2026-10-01 KST
- 결정: [D-0049](../decisions/D-0049-stem-polarity-normalization-deferred.md)

## 작업 delta

- 발문 극성을 세션 시작 시 `VALID`/`INVALID` 선택 과제로 한 번 정규화하는 방향을 승인했다.
- 선택이 뜻하는 선지 판정, 학생 발화 기반 추론, 근거가 함의하는 선지 판정, 두 판정의 일관성,
  추론 내용 정확성을 서로 다른 계약으로 분리한다.
- 학생이 직접 말하지 않은 결론은 학생 발화 재구성에 섞지 않고 파생 결론으로 보존한다.
- 정보 비대칭 13번의 부정 발문 극성 상실을 첫 고정 재현 사례로 사용한다.
- 코드·프롬프트·스키마·상태 머신·UI·테스트는 변경하지 않았다. 다른 문제 풀이 수정 사안과 함께
  구현하라는 사용자 요청 전까지 보류한다.
