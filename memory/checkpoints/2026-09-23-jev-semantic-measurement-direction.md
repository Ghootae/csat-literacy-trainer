# JEV 의미 측정 계층 방향 합의

- 사용자는 JEV를 단일 분류기가 아니라 축별 core·optional·collision을 여러 기능 질의로 측정하는
  의미 센서 배열로 연구하는 방향에 동의했다.
- 축 분해 주체는 JEV가 아니라 OpenAI API를 사용하는 오프라인 골드 생성 또는 골드 후처리다.
  JEV는 고정된 분해 자산을 학생 응답마다 평가한다.
- 보상 후보는 단순 평균이 아니라 모든 필수 core 충족과 낮은 collision의 결합으로 정한다.
- 학생이 축별 신호를 보고 보완/진행을 선택하며, 보완을 눌렀을 때만 V4가 독립 검증·피드백한다.
- broad 1회 대 core 3~5개+collision 1개의 20~30응답 비교가 다음 실험 후보지만, 실행·비용·
  임계값·운영 반영은 승인되지 않았다.
