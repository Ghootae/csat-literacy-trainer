# 문항 재생성 방향 검토

- 새 실행 없이 저장 자료 검토. 생성 7개와 풀이 4파일·구조 판정자별 4파일의 존재 확인. 저장 판정상 P1 7개가 (가)~(다)를 충족하며 사용자 깊이 판정은 미완료.
- 근거·상세: `docs/reports/REPORT-item-regeneration-direction-desktop.md`, 인간 보고: `docs/reports/REPORT-item-regeneration-direction-human.md`.
- 관측: 플라스틱 b는 적용 선지 5개여도 반복적 물성 방향 비교다. 법인 a/b는 기출과 무상증자·자본금 변화가 겹친다. 자동 문구 겹침 0은 의미 중복 없음이 아니다. 표면 장력 b 풀이 notes의 해석 전제는 사람 검토가 필요하다.
- 메인 에이전트 권고(미승인): 기존 기준을 소급 변경하지 않고 최소 필요 추론·의미 중복을 보조 검토한 후, 기준을 고정해 새 지문에서 검증. 새 정책 결정 없음.
- WORK_TREE의 준비·전송 대기 표기를 실제 생성·저장 판정 완료에 맞춰 정정. CURRENT_STATE의 ‘생성 끝, 판정·풀이 집계부터’는 여전히 유효하므로 유지.
