# 지문 완료 시점의 문단 증거 저장

- 날짜: 2026-10-01 KST
- 관련 결정: [D-0048](../decisions/D-0048-student-state-model-next-goal.md)

## 발견

문단 증거 저장이 `createProblemHandoff` 호출에 묶여 있어, 학생이 전체 지문을 마친 뒤 연결
문제를 열지 않으면 문단 수행이 상태 원장에 남지 않았다. 이는 문제까지 진행한 세션만
과대표집할 수 있는 수집 편향이었다.

## 변경

- 전체 지문의 문단이 PASS 또는 학생의 명시적 진행으로 마무리되는 즉시 handoff를 만들고 문단 증거를 저장한다.
- 연결 문제 시작은 같은 세션의 문단 증거를 재기록하지 않는다.
- PASS로 완료한 경로와 모든 문단을 명시적으로 넘어간 경로를 각각 테스트한다.
- 부분 지문에서 중단한 문단을 증거로 기록하는 정책은 이번 V1 범위에 추가하지 않았다.

## 검증

- 관련 모델·저장소·대화·문제·클라이언트 테스트 40/40 통과
- 서버·클라이언트 타입 검사 통과
- 학생·개발자·피드백 브라우저 5/5 통과
