# 직접 표시 + 기호 해석표: 같은 호출·별도 호출 비교

D-0083 시험을 완료했다. 별도 호출은 이번3회 모두 학생의 d/e 역전을 정확히 지적했다.
같은 호출은 표가3회 모두 맞았지만1회 학생의 역전 발화를 정상 발화로 바꿔 읽어 통과시켰다.
운영 승격이나 일반화 검증은 아니다.

## 방법과 출처

원래 v3 기반, gpt-5.6-terra/medium, 공손룡12번·C4 선택·같은 역전 근거로 각3반복했다.
학생 근거는 “d는 빨간 옷만 가리키고, e는 색을 한정하지 않은 일반적인 옷을 가리켜요.
서로 다른 대상을 지시하므로 같다고 한 4번은 틀렸어요.”다.

- inline_only: 원문에 기호 시작/끝 표시만 추가한 새 대조군.
- same_call: 해당 선지의 d/e 해석표와 최초 평가를 함께 생성.
- separate_call: 학생 응답 없는 별도 호출로 표를 생성한 뒤 평가.
- 표는 원문 표현·인접 절·문장 속 역할·해석·불확실성을 담는다. 두 처치 모두 최초 표를
  다음 교정 질문 호출에서 재사용한다. 의미 정답을 새 지침으로 추가하지 않았다.
- 별도 해석도 원문·문항·선지·정답·제공 해설을 본다. 학생 응답만 없으며 해설 블라인드가 아니다.
- 원래 v3 파일 해시 고정. 운영 프롬프트·코드·UI·서버 미변경, 후보3 모순 검사기 미추가.

근거: `scripts/test-gongsun-interpretation-modes.mjs`,
`docs/experiments/gongsun-interpretation-modes-2026-10-03/FROZEN.json`,
`docs/experiments/gongsun-interpretation-modes-2026-10-03/prompts.json`,
동 디렉터리 `source.json`, `mapping-input.json`, `requests.jsonl`.
이하 결과 파일명은 이 실험 디렉터리 기준이다.

## 결과: 분기와 의미를 분리

| 항목 | 직접 표시만 | 같은 호출 + 표 | 별도 호출 + 표 |
|---|---|---|---|
| 표의 d/e 의미 구분 | 해당 없음 | 3/3 | 3/3 |
| 최초 CLEAR_ERROR 분기 | 3/3 | 2/3 | 3/3 |
| 최초 설명에서 학생 역전을 올바르게 지적 | 2/3 | 2/3 | 3/3 |
| 교정 질문 생성 | 3/3 | 2/3 | 3/3 |
| 확인된 의미 실패 | r1 최초 d/e 동일시 | r3 학생 주장 덮어쓰기 | 같은 오류 미관측 |

Codex 원출력 검토이며 독립 사람 정확도가 아니다. 질문 생성 수치는 질문 품질 전체 통과가 아니다.

### 직접 표시만

`inline_only-r1.json` 최초 reason은 “ⓓ는 필요한 빨간 옷, 즉 ⓔ와 같은 대상을 가리킨다.”고
설명해 학생의 맞는 ‘서로 다르다’까지 오류로 보았다. 분기만 CLEAR_ERROR로 맞았다.
r2는 최초·질문에서 올바른 대응을 명시했다. r3 최초는 학생 역전과 선택 정답을 구분했지만
질문에서 “ⓓ의 ‘옷’은 실제로 어떤 옷의 부재를 뜻하고”라고 물어 부정 범위를 흐린다.
r3를 명시적 d=빨간 옷 역전으로 추가 집계하지 않는다.

### 같은 호출

`recovered/same_call-r1.json`, `recovered/same_call-r2.json`은 올바른 표→학생 역전 지적→
대상/속성 구분 질문으로 이어졌다. r1 reason에 ㉣/㉤을 d/e와 임의 병기한 표기 문제도 있으나
학생 질문에는 d/e만 사용했다.
`same_call-r3.json`은 표에서 d=일반적인 옷/e=빨간 옷을 맞게 생성했다. 그러나 reason은
“학생은 ⓓ와 ⓔ의 지시 대상을 각각 색이 한정되지 않은 일반적인 옷과 빨간 옷으로 구별했고”라며
SUPPORTED로 통과시켰다. studentEvidence에는 실제 역전 발화를 정확히 인용했다.
원문 해석 오류가 아니라 올바른 원문 해석을 학생의 주장으로 잘못 귀속한 실패다.
이 종료 분기에 따라 질문은 호출하지 않았고 최초 평가를 재추첨하지 않았다.

### 별도 호출

`recovered/separate_call-r1.json`~`r3.json` 모두 원문 의미와 학생 역전을 구분했다.
r1/r3 질문은 각각의 지시 대상을 직접 묻는다. r2 질문은 “ ‘정말 없다’는 뜻으로 부정된 것은
ⓓ의 ‘옷’인가요, 아니면 ⓔ의 ‘빨간 옷’인가요?”로, 없음을 부정하는지 없다고 말하는지 읽기가
불편하다. 내부 의미 판정은 맞지만 질문 명료성이 남는다. 학생 수정·재선택·최종 코칭은 미시험이다.

## 인용 중단과 복구

최초12요청 중 같은 호출 r1/r2와 별도 해석 r1/r2/r3 총5출력이 새 인용 검사에서 중단됐다.
원문 단어는 맞지만 표시용 태그가 생략됐다. 원출력/원집계를 보존하고
`scripts/resume-gongsun-interpretation-modes.mjs`로 원문에 유일하게 대응되는 인용의 태그만
복원했다. 비인용 의미 필드 불변과 틀린 구절 거부를 확인했다. 최초 표/평가를 재생성하지 않고
빠진 후속8요청만 실행했다. 이 결과를 처음부터 계약 실패 없는 성공으로 집계하면 안 된다.

원래 `RESULTS.json`은 최초 중단 이력, `recovered/PLAN.json`은 변경 필드/원장 해시,
`recovered/RESULTS.json`은9경로 통합 집계다. 원본 및 `recovered/requests.jsonl`에서
START/END 각20, 미확정 예약0을 확인했다. 과거 단가 추정$0.26433(청구 확정액 아님).
직접6요청/$0.0808872, 같은 호출5요청/$0.082926, 별도9요청/$0.1005168이다.
같은 호출은 과수용으로 질문1회가 빠져 동등한 경로의 비용 효율로 비교할 수 없다.

## 한계와 다음 검토

별도 호출은 추가 검증할 후보지만 단일 문항·단일 응답·각3회로 안정성/우월성은 미확정이다.
학생 응답 노출 시점·출력 계약도 달라 순수 호출 분리 효과를 분리하지 못했다.
해석표가 맞아도 학생 발화 보존은 별도 실패 지점이라는 관측을 얻었다.
Q-0030 open 유지. 다른 기호 문항·올바른 근거·부분 오류/모호 근거와 질문 명료성 검토가 남는다.
추가 유료 시험·제품 반영은 이번 완료에 포함하지 않는다.
