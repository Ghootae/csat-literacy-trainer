# 학생 증거 원장 결합 계약

- 날짜: 2026-10-01 KST
- 관련 결정: [D-0048](../decisions/D-0048-student-state-model-next-goal.md)

## 발견

증거 생성기는 올바른 조합을 만들었지만 입력 스키마는 관측 종류와 상태 차원·출처의 결합을
강제하지 않았다. 손상되거나 수동 작성된 레코드가 확신도 관측을 핵심 이해로 집계하는 식의
오분류를 만들 수 있었다.

## 변경

- 문단 최초 축은 핵심 이해/문단, 문단 관계 전이는 교정 회복/문단 조합만 허용한다.
- 문제 최초 근거는 근거 기반 문제 해결/문제, 문제 교정은 교정 회복/문제 조합만 허용한다.
- 확신도 비교는 자기 점검/문제/독립/불확정 조합만 허용한다.
- 확신도 절대·제곱 오차를 원 확신도와 최초 정오에서 재계산해 불일치 레코드를 거부한다.

## 검증

- 손상 차원·출처·계산값 거부를 포함한 학생 상태 모델 테스트 8/8 통과
- 관련 테스트 41/41, 서버·클라이언트 타입 검사 통과
