# 2026-09-23 JEV collision 단일 질문 대조

- 정보 비대칭 AX1의 교차 collision이 다중 질문 결합 때문에 발생하는지 target-only 단일 질문으로 비교했다.
- 동일 문구에서 MR2 오류→MR3은 묶음0.49·단일0.61, MR3 오류→MR2는0.63·0.57이었다. 표적 오류는 MR2 0.97·0.97, MR3 0.93·0.93으로 같았다.
- 더 엄격한 단일 질문에서도 교차0.45·0.59, 표적0.95·0.92, 생략0.06·0.07이었다.
- 동일 문구 생략 단일2건은 무료 제한 HTTP429였지만 기존 묶음0.05·0.08 및 엄격 단일0.06·0.07과 함께 보면 정보 부재가 높은 collision을 만든다는 패턴은 없다.
- 결론: 다중 질문 분리는 교차 collision을 해결하지 않는다. 현상은 연결된 다른 MR의 명시적 오류가 target으로 전파되는 semantic spillover에 가깝다. 단독 호출 증가는 보류하고 target-only에서 무관·인접·직접 오류를 확장 비교한다.
