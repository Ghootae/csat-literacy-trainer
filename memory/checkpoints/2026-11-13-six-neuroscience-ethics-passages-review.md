# 붙여 넣은 신경과학·윤리 지문 6편 검토

- 사용자 제공 가~바 지문을 과학·입장 연결, 입장 깊이, 기존 기출 모방 느낌, 사실·논리 의심점으로 평가했다. [인간 보고](../../docs/reports/REPORT-six-neuroscience-ethics-passages-human-2026-11-13.md), [상세 보고](../../docs/reports/REPORT-six-neuroscience-ethics-passages-desktop-2026-11-13.md).
- 현재 글의 편집 순위 권고는 마 > 가 > 라 > 다 > 나 > 바. 마·가·라·다·나는 ‘조금 고치면’, 바는 ‘못 씀’. 사용자 채택 결정이나 문항 검증 결과는 아니다.
- 확인할 문장: 다 ㉯의 이익 없음/허용 범위, 나의 평균 신호→개별 시행 시작 가정, 라의 접근 평등→격차 축소 가능성, 바의 초기 수행·도파민 수준·약효 연결. 가와 마에는 확정적 과학 오류를 찾지 못했지만 기준 명칭과 판정 조건을 다듬어야 한다.
- 리벳 원 실험, 준비 전위 누적기 연구, 메틸페니데이트 단회 투여 종설·PET 운반체 점유 연구·처방 자극제 메타분석·초기 작업 기억 수행 연구를 대조했다(링크는 상세 보고). 실제 학생 이해도·문항 정답 유일성은 검사하지 않았다. 코드·정책 변경 없음.
