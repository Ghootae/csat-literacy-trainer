# 문단 상태 전이 역전 회고 조사

- 날짜: 2026-09-11 KST
- 성격: 기존 직접 사용·합성 회귀의 전수 회고

## 확인 결과

- 사용자 직접 30문단·43호출에서는 공손룡 3문단만 `CAPTURED → UNCLEAR` 사후 역전이 있었다.
- 두 번 질문한 법인 1·2문단은 원판정과 검증 판정이 일치했고, 답변 뒤에도 서로 다른 중심 연결이
  남아 있어 같은 기술 결함으로 분류하지 않았다.
- 42사례 초기 산출물에는 상태 복원이 14턴·6사례에 있었고, 원판정 `CAPTURED` 역전은 9턴이었다.
- 공손룡 3문단 외에도 정보 비대칭 3·4문단과 공손룡 2문단의 명시적 오류 사례에서 학생이 오류를
  수정했는데 이전 `distorted`가 남아 같은 교정을 반복하는 동일 계열 실패가 확인됐다.
- 표적 재실행을 합친 최종 42사례에서는 normalization event가 0회였지만, 코드는 남아 있었으므로
  실행 변동에 따라 잠복한 결함이었다.
