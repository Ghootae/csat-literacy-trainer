# 학생 상태 모델·정기 피드백 목표 설정

- 사용자가 학생 상태 모델과 정기 피드백을 다음 개발 목표로 지정했다.
- 현재 문단 handoff에는 최초·최종 축/관계 상태, 오류, 질문 유형, 교정·신규 확인 전이가 있다.
- 문제 세션에는 최초 선택, 근거 판정, 확신도, 개입 경로, 해결 회차, 학생 해결·정답 공개가 있다.
- 초기 모델은 이 기록을 이용한 증거 기반 다차원 프로필로 한정한다.
- 난이도 보정 전 단일 독해력 점수, 실제 내적 상태 단정, 적응형 제시는 범위 밖이다.
