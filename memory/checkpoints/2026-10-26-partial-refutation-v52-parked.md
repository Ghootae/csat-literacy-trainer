# UI 메모 기록과 「부분 반박 근거 판정 (v5.2)」 보관

## 변화

- UI 메모(커밋 `5948f54`): 문제 화면 메모장 30번 "논의 → 수정 안 함"(사용자 "별 문제가 아닌거 같은데"), 37~44번 새 메모(38번은 결정: [다시 풀기]를 주 버튼 왼쪽), 문단 화면 v4.7 사용 메모 1·2번. 출제자 전략·선지 직접 누르기 화면의 별도 사용 메모는 없었다(사용자 "따로 남긴 메모는 없어").
- 「부분 반박 근거 판정 (v5.2)」(사용자가 이름 지정): 회사법 13번 ② 정답 근거 "주식회사 법인격의 부여 대상은 단체, not 개인"이 재구성 불가("다 보이지 않았어")로 처리된 데서 시작. 판정 지시문 v5.2·서버 검증·마지막 설명 지시문을 바꿔 실모델 6차·48세션 첫 판정까지 확인했다. 반영 미결정이라 보관 브랜치 `wip/partial-refutation-v52`(커밋 `7192f9f`, 푸시 안 함)에 두고 작업 브랜치 코드는 v5.1로 되돌렸다(사용자 "추천대로 진행해줘"). 변경 단위 P1~P6(판정)·E1~E5(마지막 설명)와 실험 자료·인계 문서는 그 브랜치에 있다.
- 사용자 원리(2026-10-26): 틀린 선지는 틀린 지점 중 어느 하나라도 원문으로 확실하면 충분하다. 선지 숨은 전제를 판정기가 재구성하는 것은 위험하다(사용자). 근거 부족 칸은 "학생의 선지 읽기 풀어 쓰기 → 인정 → 선지 문장과 비교 → 핵심 오류" 구조(사용자 예시, 방향 예시).
