# 2026-10-13 정답 경로 요소·추론 깊이 설계 합의 (실행 보류)

- 사용자 제기: 함정 유형만이 아니라 정답에 필요한 전략·추론 과정을 미리 분석하면, 맞혔을 때 충족 요소와 틀렸을 때 부족 요소를 알 수 있다.
- 합의: 요구 요소 어휘 E1~E10(함정 태그 짝), 선지별 연산 사슬·고리 수(깊이), sol 1회 생성·동결(일치 검토 없음).
- 채점 단순화(사용자): 정답이면 근거 무관 사슬 전체 성공, 오답이면 끊긴 고리 위치, 확인 질문 없음. 정답 지표(도달 깊이)와 오답 지표(끊김 위치 비율)는 분리.
- 이전에 Claude가 제안한 "정답은 성공의 증거가 아니다"·Claude·sol 일치 검토는 채택하지 않았다.
