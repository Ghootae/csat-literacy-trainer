# 문단 게이트 계약 재시도 구현

- 날짜: 2026-09-11 KST
- 성격: 사용자 승인 수정 구현

## 변경

- 축 상태 변경에 최신 학생 직접 근거 또는 명시적 철회가 없으면 이전 상태로 복원하지 않고
  `CentralStoryGateContractError`를 발생시킨다.
- 계약 오류는 전송 재시도와 별도로 최대 1회 자동 재시도한다.
- 재시도 입력에는 오류 설명과 직전 무효 출력을 포함하며, 학생의 누적 응답은 그대로 유지한다.
- 재시도 전 무효 출력은 `decisionAudit.contractFailures`에 보존한다.
- 축 상태와 전체 status가 불일치하는 출력도 계약 재시도 대상으로 바꿨다.
- 유효하지 않은 질문 대상 축의 후보 보정과 잘못된 최초 철회 근거 제거는 유지했다.

## 회귀

- 공손룡형 누적 답변: 첫 무효 출력 뒤 최신 근거를 해당 축에 귀속한 재시도 결과 `CAPTURED` 유지.
- 음성 대조: 최신 답변이 다른 축만 설명하면 재시도 결과 기존 `partial` 유지.
- 철회만으로 이해를 승격하거나 과거 후속 답변을 최신 근거로 재사용하는 출력은 계약 오류.

## 검증 결과

- 표적 게이트·2단계 테스트: 18/18 통과.
- 문단 대화 전체 테스트: 64/64 통과.
- `tsc --build --force` 통과.
- `node scripts/validate-memory.mjs`는 본 체크포인트 작성 뒤 실행한다.

## 남은 확인

- 실제 모델로 공손룡 동일 입력을 재실행해 첫 후속 답변 뒤 추가 질문 없이 PASS하는지 확인한다.
