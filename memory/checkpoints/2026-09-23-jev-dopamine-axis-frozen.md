# JEV 도파민 AX1 파일럿 축 동결

- 사용자가 도파민 1문단 AX1의 파일럿 요소를 C1 외부 도파민 기능 불가, C2 내부 합성 도파민의
  신호 전달 기능, C3 두 대상의 기능적 대조, O1 혈액-뇌 장벽 원인으로 동결했다.
- C1~C3은 core, O1은 optional이다. C3은 `contrast(C1,C2)`이되 대조 표지어를 강제하지 않는
  `inferable_from_arguments`로 기록했다.
- Collision X1과 Broad B0은 의미 graph 요소가 아니라 비교용 평가 질의로 분리했다.
- 자산: `docs/experiments/jev-semantic-elements-dopamine-pilot-v1-2026-09-23/FROZEN-AXIS.json`.
- OpenAI API 분해 시험과 JEV Playground 평가는 아직 실행하지 않았다.
