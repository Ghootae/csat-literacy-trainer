# JEV Playground 민감 사례 예비 시험

- 사용자는 독립 제3자 `jevplayground.com`에 원문 6개·합성 민감 사례 18개를 각 3회, 최대54회
  보내는 범위를 일괄 승인했다. 실제 학생 개인정보는 전송하지 않았다.
- 브라우저 UI 호출10건 뒤11번째에서 HTTP429가 발생해 재시도 없이 중단했다. 성공10건의 공급자
  표시 지연 중앙값은173.945ms였다.
- 명시적 오류 단회 두 건의 충돌 확률은 공손룡0.97·mRNA0.94였다.
- 원문을 함께 준 도파민 AX1은 충분0.95·핵심 누락0.85였다. 원문 없이 축+답변만 준 앞선 수동/자동
  중립 시험의 누락0.51/0.47보다 높아, 원문에서 학생 미표현 관계를 보충하는 위험을 분리 검증해야 한다.
- 운영 V4·골드·UI·서비스는 변경하지 않았고 JEV를 운영 후보로 승격하지 않았다.
- 근거: `docs/experiments/jev-playground-sensitive-v1-2026-09-23/REPORT.md`, 같은 폴더의 `results.json`.
