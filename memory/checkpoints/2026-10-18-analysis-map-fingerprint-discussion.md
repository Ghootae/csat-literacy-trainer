# 2026-10-18 분석 지도 쓰임 논의와 다음 우선순위

- 사용자: 분석 지도는 오프라인 사고 상태 판정용, 공손룡 v3 품질이면 충분. 기준선 = 동결 지도 r3 + 입장 확정본 + 판정 v3 + 오류 집계 규칙([D-0143](../decisions/D-0143-analysis-map-gongsun-pilot.md)), 열린 항목 상위 부분·라운드 하락·교차 관계·3회 판정.
- 사용자 이미지: 관계 유형별 성공률로 학생 "문단 이해 지문"(예: 사실 파악 강, 논의 전환 약), 명제-선지 연결로 문제 풀이 사고 복원. Claude 함의: 닫힌 관계 목록 필수(D-0141), 전환 관계는 교차 관계라 지문 단위 판정 필요, 안 말함/모름 구별에 선지 연결이 보완. 기록 [논의 문서](../../docs/review/analysis-map-student-fingerprint-2026-10-18.md). 축 질문(가/나/다) 답 대기.
- 우선순위(사용자): 도파민·정보 비대칭 중 하나로 품질 유지 확인이 먼저.
