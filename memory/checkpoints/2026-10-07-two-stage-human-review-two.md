# 두 단계 생성의 개관·요약 축 사용자 판정

사용자가 두 단계 생성 `REVIEW.md`를 검토해 도파민4 AX1(개관 문장)과 표면 장력6 AX2(요약 문장)를 **잉여**로 판정했다. 기록은 `docs/experiments/central-story-two-stage-2026-10-07/HUMAN-REVIEW.md`에 있다.

- 두 문단 모두 1단계가 개관·요약 문장을 설명 단위로 배정해 minimumAxes가 2가 됐다.
- 앞선 판정(표면 장력3·정보 비대칭2는 1축 적당)과 같은 방향이다. 실질 설명 하나에 개관·도입·연결·요약 문장이 붙은 문단은 1축이 적당하다.
- 규칙 변경은 아직 결정하지 않았다(CONNECTIVE 정의에 개관·요약 문장을 포함할지).
