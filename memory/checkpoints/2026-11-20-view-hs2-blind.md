# 인문·사회 관점형 재실행 독립 판정 · 2026-11-20

두 평가자 모두 신규 생성 4문항을 전부 ‘중’, 같은 지문의 기출 2문항을 모두 ‘수능 같음’으로 판정했다. 신규 문항 기준으로 기출보다 높은 문항 0개, 같은 등급 0개, 낮은 문항 4개다. 두 평가자 모두 7/7 정답이었고 등급은 6/7, 결함 조합은 4/7에서 일치했다. 이전 생성 의미 나는 주 평가자 ‘수능 같음’, 초견 독립 평가자 ‘중’이었다. 이번 정의의 ㉴는 두 평가자 모두 0건이었다.
