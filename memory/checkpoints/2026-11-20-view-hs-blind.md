# 인문·사회 관점형 독립 판정 · 2026-11-20

생성 8문항 중 같은 지문 기출과 같은 등급을 받은 문항은 주 평가자 2개(의미 라·정보 나), 독립 평가자 1개(의미 라)였다. 나머지는 각각 6개·7개가 낮았다. 두 기출은 모두 ‘수능 같음’이었다. 기출을 웃돈 생성 문항은 없었으며 두 평가자 모두 10/10 정답이었다. ㉴(보기가 평가자의 입장이나 판정 관계를 직접 말함)는 주 평가자가 의미 가·다에 표시했고 독립 평가자는 어느 문항에도 표시하지 않았다.
