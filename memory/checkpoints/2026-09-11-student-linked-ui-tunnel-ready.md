# 학생용 문단–문항 연결 UI와 임시 터널 준비

- 날짜: 2026-09-11 KST
- 성격: 구현·검증 체크포인트

## 변경

- `/dialogue` 시작 화면을 개발자용 검사 화면에서 학생용 학습 선택 화면으로 정리했다.
- 이용 가능한 6개 지문만 노출하고, 문단 읽기 → 자기 말로 설명 → 연결 문제 풀이 순서를
  화면에 명시했다.
- 현재 문단이 통과된 뒤에만 다음 문단 버튼이 나타나도록 했고, 문단 결과의 내부 라벨과 호출
  시간 대신 학생용 표현을 사용한다.
- 새 대화 세션 ID를 URL에 보존하며, 새로고침 뒤 후속 질문이 남아 있으면 이어갈 질문을 다시
  표시한다.
- 문단에서 연결된 문제 화면에서는 내부 평가·교정 상태 세부값을 숨기고 학생에게 필요한 선택
  진행과 최종 안내만 표시한다.

  `packages/app/src/client/ProblemApp.tsx`, `packages/app/src/client/styles.css`

- 단위 회귀: 문단·문항·복구 관련 24건 통과
- 브라우저 확인: 데스크톱과 390×844 모바일 화면에서 렌더링, 공개 터널의 `/dialogue`에서
  학습 세트 6개와 콘솔 오류 0건 확인

## 운영 상태

- API와 Vite 서버, 계정 없는 Cloudflare Quick Tunnel은 해당 실행 프로세스가 살아 있는 동안만
  유지된다. Quick Tunnel URL은 영구 배포 주소가 아니다.
- 문단 평가 호출 상한은 기존 서버 기본값 60회를 유지한다.
- 실제 학생 사용성 질문 `Q-0009`는 열려 있다. 이번 확인은 UI 도달 가능성과 기술 흐름 검증이며
  학생 학습 효과의 증거가 아니다.
