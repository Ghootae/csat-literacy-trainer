# 공손룡 12번 기호 해석본 자동 생성과 형식 비교

[D-0084](../decisions/D-0084-local-marker-gloss-direction.md) 이후, 해석본을 문항별 분기 없는 공통 지시로 자동 생성할 수 있는지 시험했다.
모든 외부 전송은 사용자가 단계별로 승인했다. 의미 판정은 Claude가 먼저 고정한 뒤 GPT(GPT-6 Astra, Codex 읽기 전용)가 블라인드로
판정하고 한 차례 반론했다.

## 새로 확인된 것

- 공통 생성기 v1(3요청 $0.1349, `gpt-5.6-terra`/high, [결과](../../docs/experiments/marker-gloss-generator-gongsun-2026-10-06/REVIEW-SUMMARY.json)):
  다섯 기호의 지시 대상·화자는 3회 모두 원문과 일치했다. 허용·오류 읽기 경계, 대상 칸의 판단 혼입, 인용 따옴표 덧붙임은 흔들려
  무수정 사용은 불가로 판정됐다.
- 예시 포함 대 대상만(68요청 $1.1334, [결과](../../docs/experiments/gongsun-gloss-examples-2026-10-06/REVIEW-SUMMARY.json)):
  두 형식의 차이는 S5('ⓓ는 옷장에 있는 옷')뿐이었다. 승인 해석본(허용 예에 '옷장의 옷')은 3/3 통과, 대상만은 0/3이었다.
  승인 예시는 실제 학생 답을 알고 넣은 것이라 순환적이다.
- 사용자 결정(2026-10-07): 해석본은 사람 검토를 전제하지 않는다. 자동 생성 예시 포함과 중간안(예시 없이 대상 칸에 같은 자료 안 구체 대상)을 비교한다.
- 생성기 v2(6요청 $0.2744, [폴더](../../docs/experiments/marker-gloss-generator-v2-gongsun-2026-10-07/)): 6칸 모두 첫 시도에 자동 검사 통과,
  인용 복원·재생성 0. middle은 3/3이 ⓓ 대상 칸에 '옷장 안에 있는 옷은 그 범위에 드는 사례'를 넣었다. examples는 3/3이
  ⓓ 허용 예에 같은 자료 안 구체 대상을 넣지 않았다(지시 불이행).
- 자동 생성 두 형식 판정 비교(71요청 $1.186, 계약 실패 0, [결과](../../docs/experiments/gongsun-auto-gloss-formats-2026-10-07/REVIEW-SUMMARY.json)):
  라벨 일치 examples 21/24, middle 20/24. S5는 두 형식 모두 0/3이다. 판정기는 '옷장에 있는 옷'을 '옷장 안의 옷만'으로 읽어 반박했으며,
  middle 해석본의 포함 관계 설명이 있어도 같았다. middle S7 1건은 ⓓ 오류를 놓쳤다. 의미 실패 수는 Claude 3 대 4, GPT 7 대 6으로
  판정자에 따라 방향이 뒤집혀 형식 우열은 말할 수 없다.
- 교정 질문이 정답 표현을 양자택일로 보여 주거나 원문 단어만 찾으면 답할 수 있는 문제는 형식과 무관하게 남았다.

## 해석(가설)

- 구체 예를 지시 대상으로 단정한 학생 표현을 허용할지는 원문만으로 정해지지 않는 판정 기준이다. 지금까지는 그 표현을 허용 예로 직접 적은
  경우(사람이 손본 승인본)만 판정기가 허용했다. 포함 관계 설명은 그 기준으로 작동하지 않았다.
- examples 생성본이 구체 예를 빠뜨렸으므로, 이번 결과를 예시 목록 무효의 증거로 읽지 않는다(GPT).

## 남은 이견

- E21·E28·E78을 근거 오류로 셀지(GPT 유지, Claude 경계적). '만' 덧붙임을 기존 귀속 대체와 같은 유형으로 셀지.

## 변경한 것

- `scripts/test-marker-gloss-generator.mjs`, `scripts/test-marker-gloss-generator-v2.mjs`, `scripts/test-gongsun-gloss-examples.mjs`,
  `scripts/test-gongsun-auto-gloss-formats.mjs`와 각 실험 폴더. 운영 판정기 코드·프롬프트·UI·서버는 바꾸지 않았다.

## 보류한 해결 후보(사용자 결정 2026-10-07, 후속 논의 대상)

- 후보 A, 판정 기준 완화: 학생이 말한 대상이 해석본 대상의 범위 안에 있으면 합치로 본다. Claude 검토: '범위 안'만으로는
  S2(ⓓ=빨간 옷)·S7(ⓓ=갑이 가지고 있지 않은 옷)도 통과하므로 범위 안·문맥 무충돌·선지 판단에 필요한 구별 보존을 모두 요구해야 한다.
  '만'처럼 명시적으로 좁힌 응답의 처리, 다른 기호 대상과 겹치는 응답, '더 좁게 말했지만 허용' 별도 기록 여부가 미정.
- 후보 B, 운용 규칙 변경: 명백한 오류는 교정 질문, 명백하지 않으면 진단 질문 1회 뒤 학생 답으로 판정한다. Claude 제안 기준은
  '학생 말의 합리적 읽기 중 하나라도 원문과 맞으면 명백한 오류가 아님'. [D-0051](../decisions/D-0051-bounded-problem-feedback-flow-deferred.md)의
  정답 모호 근거 무질문 종료·진단 질문 배제, [D-0054](../decisions/D-0054-insufficient-wrong-rationale-exit-deferred.md)와 충돌하므로
  채택 시 부분 대체 결정이 필요하다. 정답·오답 적용 범위, 표현 모호와 연결 부재의 구분, 학생 답 이후 처리, 해석본·인용 규칙 병행이 미정.
- 두 후보 모두 실험·구현하지 않았다.
