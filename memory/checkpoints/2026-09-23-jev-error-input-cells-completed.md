# JEV 명시적 오류 입력 셀 보완

- 선행 통합 보고서에서 비어 있던 공손룡·mRNA 명시적 오류의 `축+응답` 및
  `구조 분리+귀속 지시` 네 조건 셀을 Playground UI로 실행해 모두 채웠다.
- 공손룡 오류는 축+응답 평균0.96(n=2), 구조 분리 평균0.96(n=2)이었고, 선행 원문 혼합
  단회0.97과 비슷했다.
- mRNA 오류는 축+응답 평균0.907(n=3), 구조 분리 평균0.94(n=3)이었고, 선행 원문 혼합
  단회0.94와 비슷했다.
- 신규10호출 뒤 HTTP429가 발생해 공손룡 두 셀은 계획한3회 중2회에서 멈췄다. 빈 셀은 없지만
  반복 수는 불균형하다. 합성 오류 두 사례뿐이므로 JEV 단독 오류 확정은 승인하지 않았고 shadow
  충돌 신호라는 기존 운영 범위를 유지했다.
- 근거: `docs/experiments/jev-error-input-v1-2026-09-23/REPORT.md`, 같은 폴더의
  `results.json`, 통합본 `docs/experiments/jev-attribution-v1-2026-09-23/USER-REPORT.md`.
