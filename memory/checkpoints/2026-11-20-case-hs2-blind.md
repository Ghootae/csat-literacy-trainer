# 인문·사회 사례 재실행 독립 판정 · 2026-11-20

신규 생성 4문항 중 같은 지문 기출과 같은 등급을 받은 문항은 주 평가자 기준 1개(공시 다), 독립 평가자 기준 0개였다. 둘 다 공시 라와 명실 가·나를 기출보다 낮게 평가했다. 기출 두 문항은 두 평가자 모두 ‘수능 같음’이었다. 두 사람 모두 7/7 정답이었고, 등급은 5/7, 결함 기호는 7/7 일치했다. 주 평가자는 직전 대화에서 공시 가·나와 명실 다를 이미 풀고 출처를 확인했다. 이번 정답표는 두 평가자의 답·등급·결함을 고정한 뒤에 열었다. 독립 평가자는 직전 대화 없이 이번 풀이지만 읽었다. 별도 API 호출은 없었다.
