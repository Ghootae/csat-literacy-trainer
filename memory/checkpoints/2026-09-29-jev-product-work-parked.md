# JEV 제품 적용 연구 보류

- 사용자는 자연 응답 shadow까지 포함한 JEV 실험을 검토한 뒤 현재 제품 계획에서 JEV를 계속
  유지할 이유가 충분하지 않다고 결정했다.
- JEV 자동 PASS, MR 게이지 UI, MR 중요도·가중치 추가, collision 오류 유형 확장, 추가 호출을
  중단하고 기존 결과·원출력·스크립트만 연구 자료로 보존한다.
- 운영 문단 평가기는 현재 V4를 유지한다.
- JEV는 영구 폐기가 아니라 `PARKED`이며, V4 비용·지연의 실제 병목과 좁은 새 효용이 함께
  확인될 때만 재검토한다.
