# 2026-09-23 JEV 정보 비대칭 MR coverage 파일럿

- 정보 비대칭 AX1에 충분·MR2/3 누락·부분·소재 언급·MR1/2/3 충돌의 가상 학생 응답 8개와 사전 기대값을 고정했다.
- 공식 API/key 없이 JEV Playground 공개 평가 경로를 사용했다. 원문은 제외하고 AX·학생 응답·질문별 target MR을 구조 분리했다.
- boolean coverage는 충분 0.87/0.91, MR3 누락 0.93/0.07, MR2 누락 0.12/0.84로 표적 누락을 분리했다. 부분 MR2는 0.09여서 값은 부분 포함률보다 “MR 전체가 충분한가”의 확률에 가깝다.
- collision은 표적 오류를 0.93~0.98로 감지했지만 비표적 MR도 0.77~0.90까지 상승했다. AX 제거 대조에서도 교차 점수 0.49~0.64가 남아 MR별 오류 국소화는 실패했다.
- 0~4 score는 충분 MR 3.85~3.96, 누락 MR 1.48~1.64, 부분 MR2 1.93이었다. 관련 소재만인 MR2가 2.12로 부분 응답보다 높아 학생용 충족률로 직접 해석할 수 없다.
- 동일 8응답의 coverage에서 AX를 제거해도 충분·누락 순위가 유지됐다. 호출당 입력 42토큰(평균3.6%)을 줄였지만 관련 소재 MR2가0.14→0.23으로 올라 정확도 개선 근거는 아니다. target-only는 단순 기준선 후보이며 자연 응답 반복 검증이 필요하다.
- 첫 회차 8건 모델 표시 지연 평균 약226ms·중앙값 약188ms. 반복 요청은 무료 경로 제한으로 24건 중 10성공·14 HTTP429였으며 제한은 의미 실패로 집계하지 않았다.
- 결론: MR-first boolean coverage는 후속 검증 가치가 있고 P 분해는 필요할 때만 한다. collision과 백분율 게이지는 현재 미통과다.
