# 공손룡 기호 범위 보완 A/B 결과

D-0078 외부 전송 승인 뒤15요청을 완료했다. 기호 보완 조건에서 실제 응답 과잉 교정과
대상 역전 오류 누락은 이번 표본에서 나타나지 않았으나, 내부 의미 설명 오류1회가 남았다.
따라서 분기 개선 신호는 있지만 문제 전체가 해결됐다고 결론 내릴 수 없다.

## 비교 조건과 결과

`docs/experiments/gongsun-marker-input-ab-2026-10-02/`의 `cases.json`, `sources.json`,
`FROZEN.json`에 실행 전 고정했다. `requests.jsonl`의 모든 평가 지시 해시는 동일한 승인
v3 기반 v4 후보 `98d36119a84d612fbb0b1a20553a49df2170633e1a78470f632b0b24ee7ec2b2`다.
모델 gpt-5.6-terra/medium·런타임·학생 응답·정답/해설을 고정하고 source의 scenario(ⓒ 위치)와
textAnnotations(지문/보기6범위), 조건부 필드 설명만 달리했다. 위치/범위의 개별 효과는 미분리다.
baseline은 수정 전 입력, candidate는 수정 후 입력이며 기존 v4/새 후보 프롬프트 비교가 아니다.

| 응답 | 수정 전 | 수정 후 |
|---|---|---|
| 실제: d는 옷장에 있는 옷, e는 빨간 옷 → 다른 대상 | 검증 정답2/3, 근거 미검증1/3 | 검증 정답3/3 |
| 가상: d는 빨간 옷만, e는 일반적인 옷 → 다른 대상 | 오류 검출2/3, 검증 정답 과수용1/3 | 오류 분기3/3; 내부 설명 오류1회 별도 |
| 관계를 모르겠다는 근거 | 근거 미검증 정답1/1 | 근거 미검증 정답1/1 |

최초 분기 기대값 일치는 수정 전5/7, 수정 후7/7이다. 사전 에이전트 기대값과의 일치이며
독립 사람 정확도나 설명 전문 정확도가 아니다. 이번 수정 전 실제 응답에는 ERROR 과잉 교정이
없었으므로 과거의 과잉 교정1/3과 이번 수치 차이를 인과적 개선으로 단정하지 않는다.
기대값 검사와 실제 원출력을 함께 읽었다.

## 남은 의미 오류

`initial/candidate-G-error-r2.json`은 contentAssessment=ERROR와 교정 질문 분기를 맞췄지만,
errors[0].description에서 “ⓓ ‘옷’은 갑이 필요한 ‘빨간 옷’을 가리키며, ⓔ는 그 빨간 옷을
명시한 표현”이라고 설명했다. 공식 해설의 d=일반적인 옷/e=빨간 옷 구분과 충돌한다.
미공개 coaching은 더 나아가 둘이 같은 대상을 지시하며 ④가 적절하다고 말한다.
따라서 ERROR 라벨을 맞힌 것만으로 오류를 정확히 진단했다고 볼 수 없다.

학생에게 실제 공개된 message는 “갑의 설명에서 ⓓ ‘옷’과 ⓔ ‘빨간 옷’은 각각 무엇을
가리키나요?”였다. 잘못된 코칭 전문이 학생용 메시지로 공개된 것은 아니며, 내부 오류 설명은
후속 평가 및 개발자 검사 대상이라는 위험을 구분한다. 이 두 번째 반복의 후속은 계획에 없어
실행하지 않았다. 문제의 내부 설명이 후속을 어떻게 바꿀지는 미검증이다.

`initial/baseline-G-error-r2.json`은 학생이 대상을 뒤집어 말했는데도 reconstructedPath에서
d=일반적인 옷/e=빨간 옷으로 임의 교정한 뒤 SUPPORTED로 종료했다. 원문 정답 내용을
학생이 말한 것처럼 재구성하는 오류가 수정 전 조건에서 관측됐다.

## 수정 답변 경로

계획대로 `candidate-G-error-r1`에서 나온 질문 뒤 기존 G-repair 답변을 제출했다.
“d는 색을 한정하지 않은 일반적인 옷이고 e는 빨간 옷”이라는 최신 o2 답변을 인용하고
REPAIRED·verificationComplete=true·rationaleSufficient=true로 평가했다.
새 오류 없이 VERIFIED_CORRECT로 종료하고 선택 횟수1을 유지했다. 최초 선택이 정답이므로
재선택을 요구하지 않는 것이 기대 경로다. 근거: `cycles/G-repair.json`.

  전송 오류0·최종 계약 실패0. 과거 단가 기준 추정$0.1827112, 미확정 예약0.

  올바른 문자열 위치와 문맥상 지시 대상의 의미를 안정적으로 구분하는지는 별도 문제다.
