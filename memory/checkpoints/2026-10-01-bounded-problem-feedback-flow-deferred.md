# 문제 풀이 개입·재선택 제한 후보 기록

## 작업 delta

- 사용자 요청에 따라 [D-0051](../decisions/D-0051-bounded-problem-feedback-flow-deferred.md)을 추가했다.
- 근거 기본 제출과 명시적 답만 제출, 근거 생략 오답의 감점 리스크를 기록했다. 개발에서는 실제 차감하지 않는다.
- 선택 최대 2회·교정 질문 최대 1회이며 실제 교정 성공에만 재선택한다. 실패·수정 확인 불가이면 코칭 후 종료한다.
- 불명확한 최초 오답 근거는 내부 추론 가능성 게이트를 거쳐 오류 파악 가능 시 교정하고, 추론 불가능 시 확인 어려움 안내·코칭 후 종료한다.
- 재선택에는 종료 규칙이 우선하며, 정답의 오류 근거도 추가 질문 없이 코칭 후 종료한다.
- D-0050의 과잉 재구성 금지는 유지하고, 추론 불가능 이후 진단 질문 경로만 후속 후보에서 변경했다. 기존 결정 본문은 보존하고 후속 링크를 추가했다.
- 현재 상태·색인·열린 질문을 갱신했다. 코드·프롬프트·UI·운영 설정·포인트는 변경하지 않았다.
