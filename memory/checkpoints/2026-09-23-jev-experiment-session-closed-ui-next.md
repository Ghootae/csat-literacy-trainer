# 2026-09-23 JEV 실험 종료·UI 프로토타입 다음 단계

- 사용자는 현재 V4를 직접 사용한 결과가 나쁘지 않고 개입 수준도 적당했다고 평가했다.
- 오늘 JEV 실험은 종료했다. JEV를 V4 대체 판정기로 사용하지 않고 MR별 coverage 게이지와 학생의 `보완/진행` 선택을 지원하는 전단 UI 후보로 정리했다.
- 후보 라우팅은 고신뢰 required MR 전부 충족+낮은 오류 신호에서 자동 PASS, 애매·낮은 coverage에서 학생 선택, 보완 선택 또는 높은 오류 신호에서만 V4 독립 검증·피드백이다.
- 학생에게 JEV 확률을 이해도 백분율로 표시하지 않는다. 진행 선택과 검증 PASS를 별도 상태로 기록한다.
- 다음 작업은 개인용 UI까지 구현해 사용자가 직접 사용감을 확인하는 것이다. 임계값·자동 PASS 운영 개방·보상·공식 API 연결·학생용 배포는 미승인이다.
- 비용·시간 참고: 현재 V4 최초 판정은 실측 약 `$0.022~0.025`, API 중앙값 약8.7~11.6초. JEV 5문항 target-only 묶음은 공개 단가 기준 약`$0.000047`, 플레이그라운드 왕복 중앙값 약0.61초이나 무료 경로 429 제한이 있었다.
