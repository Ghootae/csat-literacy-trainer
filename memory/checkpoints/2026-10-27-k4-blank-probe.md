# K4 확인 단계 (나) 짧은 실험

## 새로 확인된 것

- 두 번째 확인 호출(빈자리·단서·반박, K4 문구 없음)을 K4와 대조 4사례에 각 3회 보냈다(15호출, $0.03). K4 수용 1/3, 대조 사례 잘못 수용 0. 근거: [보고](../../docs/experiments/k4-blank-probe-2026-10-27/REPORT-desktop.md).
- 판정기는 빈자리와 cue를 매번 찾았지만, ②의 '법인격을 부여받은 쪽'을 대체로 A(회사)로 읽어 "갑이 법인격을 받았다"를 선지의 자연스러운 뜻으로 보지 않았다. 앞선 모든 실행의 K4 불인정도 이 읽기 차이로 설명된다(해석).

## 결정된 것

- 사용자 "권고대로 (라)로 정리하고 커밋해줘": K4는 현재 동작 수용, (나) 미연결([D-0182](../decisions/D-0182-problem-feedback-v53-three-cell-adopted.md)).
