# 실제8응답 조건부 메타 판정 완료

## 새로 확인된 것

- 실제 최초 응답8개를 L1 각3회, SERIOUS가 있는6회에만 L2로 판정했다. 미보유2문단 축 공동생성을 포함해32호출, 모두계약유효·재시도0.
- 기존 공동생성6문단을 재사용했다. 새 mRNA1은 면역 과정·백신 적용의2축으로 나뉘어 과거 운영1축과 다르다.
- 최신 사람 허용 경로는 L2 없는 동일L1에서12/24, 조건부L2에서15/24였다. L2가 도파민2회·자본금1회 질문을 선택보완으로 완화했다. 실제2응답의3반복관측이며 독립24표본 정확도가 아니다.
- 1·5·6·7번은3/3허용, 도파민2/3·자본금1/3, 공손룡3·mRNA2는0/3. 불일치9회는 모두 원하는 선택보완이 조용한통과로 사라진 경우였다.
- 도파민AX1 S/S/OK, 자본금AX2 S/OK/OK 경계가 보완표시 변동으로 이어졌다. 백신 누락은 S+L2미충족3/3으로 질문 유지.
- L2가 메타 문구의 외부도파민 배제·자본금 최후수단을 학생이 쓰지 않아도 내부합성·존립위험 중심으로 충족했다. 사람 경로 일치와 메타 의미 판정 정확성은 구분한다.
- L1 요청 지연 중앙값8.52초, L2 2.64초. 실제 평가경로 합 중앙값8.54초·평균9.98초. 캐시적용·실험조건 수치이며 운영UI지연 아님.

## 결정된 것

- D-0045는 이번 조건부 실험 승인이다. D-0040 정책, 운영V4·골드·UI·서버·보상·JEV보류는 변경하지 않았다.
- 사람 기준은 D-0044 그대로이며 모델 요청에 포함하지 않았다. 미호출 L2를 임의로 측정값처럼 보충하지 않았다.

## 변경한 것

- 격리 실험 스크립트, 동결 요청·입력·사람기준, API 전송본문·원출력, 재검증 감사, 보고서와 전체검토패킷을 추가했다.

## 미해결

- L2의 제한적 효용은 관측됐지만 어떤 의미 생략을 허용하는 메타 판정인지, 선택보완을 원하는 부분이 OK무표시 정책과 어떻게 정합될지는 남았다.
- 오류 대조군·질문 생성·후속 응답·교육 효과는 이번 범위 밖이다. 일부 사람 기준은 과거 결과 공개 후 수정되어 독립블라인드검증이 아니다.

## 다음 행동

- 보고서2·3·4·8번을 사용자와 검토하여 선택보완이 남아야 하는 기준을 먼저 정리한다. 정책 변경·운영 채택은 별도 승인 후 진행한다.
