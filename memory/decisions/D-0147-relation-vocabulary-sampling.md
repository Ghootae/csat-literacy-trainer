# 관계 유형 닫힌 목록: 표본을 넓힌 뒤 정한다

## 결정

[D-0141](./D-0141-paragraph-analysis-map-direction.md)의 닫힌 소수 관계 어휘는 공손룡·도파민 두 지문으로 정하지 않는다. Claude 초안(`docs/review/relation-vocabulary-draft-2026-10-18.md`)은 결정 아닌 메모로 두고, 표본 정리 때 참고하지 않는다.

1. **표본 넓히기.** 저장소의 나머지 지문 5개(법인·정보 비대칭·mRNA·표면장력·헤겔)로 지도 생성 지시문(공손룡 `MAP-PROMPT.md`, 무수정)을 각 3회 돌린다. 공손룡·도파민과 합쳐 7지문.
2. **지문·분야별로 먼저 정리한 뒤 전체를 묶어** 1차 목록을 만든다.
3. **목록 작성에 쓰지 않은 새 지문**으로 기타 비율과 분류 일치율을 잰다(저장소 지문을 떼어 두기보다 새 지문 권고).
4. 7지문도 작은 표본이므로 "1차 목록"으로 부르고 지문이 늘면 다시 본다.

실행 메모(Claude, 2026-10-19): 헤겔 지문은 1문단이라 지도 구조 규칙(합성 노드 자식 2개 이상, TOP 포함)과 맞지 않아 dry-run 검증이 실패했고 관계 표본도 적어 제외했다. 표본은 공손룡·도파민 포함 6지문, 실행 12요청.

외부 전송 승인(사용자 "진행해줘", 2026-10-19): 지문 5개 원문만, `gpt-6.1-sol` medium, 지문당 3회(총 15요청), 재시도 없음, 합계 상한 $3.
