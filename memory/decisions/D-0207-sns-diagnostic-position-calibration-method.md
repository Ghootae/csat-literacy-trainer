# SNS 진단 위치 보정은 기준 시험 하나(2026학년도 수능)의 원점수 등급컷으로 하고, 선택과목 두 집단 백분위를 평균한다

## 결정

[D-0203](./D-0203-megastudy-rates-public-display-and-calibration.md) 2의 "시험마다 평가원 공식 분포에 맞춰 난이도를 옮기는 보정"을
구체화한다. 평가원 문항별 자료는 쓰지 않는다(공개되지 않음).

1. **방법.** 메가스터디 정답률 → Rasch 난이도(σ=1) → 세트 E 정답 수로 능력(EAP, 80% 구간) → 기준 시험 45문항 예상 원점수 →
   원점수 등급컷 보간으로 전국 백분위·등급.
2. **기준 시험 하나.** 2026학년도 수능(메가스터디 seq 349). 새 수능이 나오면 기준 시험만 바꾼다. 시험마다 따로 옮기지 않는다.
3. **선택과목.** 화법과작문·언어와매체 집단을 각각 일관되게 계산하고 백분위를 평균한다(사용자 선택 (가)).
4. **자료.** 원점수 등급컷은 입시업체 실채점 추정치(2026 수능: 종로학원, 2023~2025 수능: 사용자 제공 표)를 내부 환산에만 쓰고
   화면에 보이지 않는다.

## 근거

- 계산(외부 전송 없음): `docs/experiments/sns-diagnostic-calibration-2026-11-06/`(`REPORT-desktop.md`, `OUTPUT.md`, `calibrate.py`).
  - 기준 시험을 2024·2025·2026 수능으로 바꿔도 같은 능력의 백분위 차이가 θ ≥ 0에서 3~5, θ = −1에서 최대 9.
  - 메가스터디 이용자 평균 원점수의 전국 백분위: 화작 59.8~64.1, 언매 78.0~82.3. 보정 없으면 위치가 낮게 나온다.
  - 집단을 일관되게 쓰면 화작·언매 차이는 백분위 4~5.
- 메가스터디 역대 등급컷은 표준점수만 있다(원점수 없음, 2026-11-06 조회).
- 사용자: 종로학원 페이지·2023~2025 표 제공, "매해 자료가 필요할까?", 선택과목 "가로 하자"(2026-11-06).

## 한계

- 네 시험 메가스터디 이용자 집단이 같은 척도라는 가정, 독서 16문항으로 국어 45문항 점수를 추정하는 가정, 업체 추정 컷,
  σ 미식별(민감도 1~4 백분위). 화면 표현은 "수능 기준 환산 추정"(D-0200)을 유지한다.

## 다시 볼 조건

- 참가자 자료로 다시 맞출 때(D-0203 (C)) 이 방법과의 차이를 비교한다.
- 새 수능 컷이 나오면 기준 시험을 바꾸고 `calibrate.py`로 이전 기준과 비교한다.
