# 문단 판정과 다음 문단 진행 권한을 분리

## 결정

사용자는 UNCLEAR-SERIOUS와 ERROR에도 시스템 오판 가능성이 있으므로, 수정 요구에
응답하지 않고 다음 문단으로 넘어갈 선택권을 학생에게 주기로 했다.

- PASS, UNCLEAR-OK, UNCLEAR-SERIOUS, ERROR 모두 학생의 다음 문단 진행을 허용한다.
- SERIOUS의 확인 질문과 ERROR의 교정 질문은 제시하되, 답변·수정 완료를 진행의 필수
  조건으로 삼지 않는다. 앞선 검토안의 ‘필수 수정’ 구상은 이 결정으로 변경한다.
- 학생이 진행을 선택한 사실은 이해 확인이나 오류 교정 완료와 구분한다. 기존 응답과
  판정 기록을 보존하고 진행 선택 때문에 PASS로 바꾸지 않는다.
- 중심축에 근거한 의미 판정 범위(D-0010)는 유지한다. 문제 풀이 정책은 이번 결정 범위가 아니다.

## 적용 상태

후속 갱신: [D-0013](./D-0013-paragraph-optional-revision-v4.md)에서 V4로 구현했다.
아래는 이 원칙을 최초 결정했을 때의 적용 상태다.

설계 원칙은 확정됐지만 코드·UI·프롬프트·서버에는 아직 적용하지 않았다. 축별 박스 공개와
UNCLEAR 세분화의 상세 계약, 질문 소진 시 마무리, UI 표현은 후속 설계 대상이다.
새 런타임 버전 이름을 지정하거나 유료 실험을 승인한 결정이 아니다.

  있도록 선택권을 주자.’
- 제안과 후속 결정 기록: `docs/review/paragraph-optional-revision-proposal-2026-09-19.md`.

## 검증 및 재검토

실제 사용성·교육 효과는 미검증이다. 구현 시 모든 비통과 상태에서 응답 없이 진행되는지,
기존 판정·학생 발화가 유지되는지, 진행을 PASS로 집계하지 않는지 확인한다.
장기적인 학습 방치나 사용 불편이 관측되면 사용자와 재검토하며, 자동으로 강제 통과 관문을
복구하지 않는다.
