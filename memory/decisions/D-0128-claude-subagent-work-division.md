# 클로드 단독 업무 분장: 확정 설계 실행은 executor 하위 에이전트에 위임

## 사용자 지시

1. 챗GPT 계정이 종료되어 코덱스를 더 쓸 수 없다(사용자, 2026-10-14).
2. 클로드만 구독하고, 확정 설계 실행은 소넷 하위 에이전트에 넘기는 변경안을 적용한다
   (사용자 지시, 2026-10-14).

## 결정

- 클로드(메인 세션)는 문제 해결의 주된 사고 파트너로 설계·판단·검토를 맡는다.
- 설계가 확정된 작업의 실행은 `executor` 하위 에이전트(모델 sonnet)에 위임한다. 설계 확정은
  [D-0092](./D-0092-claude-codex-work-division.md)와 같이 `docs/handoffs/`에 인계 문서가 있다는
  뜻이며, 인계 문서가 곧 하위 에이전트의 지시문이다. 인계 문서가 있는 작업은 사용자가 매번
  요청하지 않아도 위임한다.
- 하위 에이전트는 인계 문서와 충돌하거나 설계 공백을 발견하면 설계를 바꾸지 않고 멈춘 뒤
  보고한다. 메인 세션이 인계 문서 대비 diff로 검토한다.
- 작은 작업 예외·`memory/` 기록·커밋 확인 규칙은 D-0092 그대로 유지한다.
- 코덱스 보조 논의 역할은 폐지한다. 독립 의견이 필요하면 메인 세션의 결론을 주지 않고 문제와
  근거 자료만 준 하위 에이전트(예: `critic`, `architect`)에 묻는다.

## D-0092에서 바뀐 것

| 항목 | D-0092 | D-0128 |
|---|---|---|
| 확정 설계 실행 | 코덱스 | `executor` 하위 에이전트(sonnet) |
| 보조 논의 | 코덱스(명시 시) | 하위 에이전트(명시 시), 결론 없이 문제·근거만 전달 |
| 인계 문서·중단 보고·diff 검토·커밋 확인 | 유지 | 유지 |

## 근거

- 사용자 지시(2026-10-14): 챗GPT 계정 종료, 변경안 적용.
- 하위 에이전트 모델 지정 확인: OMC 4.15.6 `agents/executor.md`의 `model: sonnet`.
- 클로드 코드 2.1.299의 기본 지침은 사용자 요청 없이 하위 에이전트를 띄우지 않는 쪽이므로,
  위임 조건을 `AGENTS.md` 규칙으로 명시한다.

## 미검증

- 소넷 executor의 실행 품질·사용 한도 소모는 이 저장소에서 아직 측정하지 않았다.
