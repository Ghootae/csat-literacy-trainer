# 선지 연결 층: 방향과 첫 단계

## 결정

1. **선지 연결 층을 분석 골드 위에 새 층으로 만든다.** 선지마다 정오, 연결되는 지도 단위(명제·합성·요지·관계), 비틂 종류와 설명을 남긴다. 맞는 선지도 연결한다(비틂 없음). 지도만으로 판단할 수 없는 선지(〈보기〉·추론)는 "지도 밖 정보 필요"로 표시하고 연결 가능한 부분만 잇는다. 지도는 고치지 않는다.
2. **먼저 오프라인 진단용으로 쓴다.** 학생 이해 지문(D-0160)에 오류 유형 칸(축 (다))을 더한다. 문제 풀이 피드백 런타임에는 넣지 않는다([D-0002](./D-0002-problem-source-direct-runtime.md)·[D-0003](./D-0003-problem-gold-offline-only.md) 유지). 피드백 쪽 쓰임은 판정이 끝난 뒤 좌표만 쓰는 좁은 방식으로 따로 비교 실험한 뒤 정한다.
3. **비틂 종류 닫힌 목록은 UI 6지문(공손룡·도파민·법인·정보 비대칭·표면 장력·mRNA)의 연결 문항으로 만들고, 맞춰 보기 6지도(5세트) 문항으로 검증한다.** 나중 피드백 실험이 UI 연결 문항에서 돌기 때문이다.
4. 이를 위해 UI 4지문(법인·정보 비대칭·mRNA·표면 장력)의 분석 골드를 D-0151 절차(점검표 v2, Claude 검토, D-0158)로 만들었다.

## 근거

- 사용자(2026-10-21): 선지 연결 정리("1번 선지: 적절하지 않음. -> 관련 명제 연결 -> 명제가 어떻게 뒤틀렸는지 명시"), 피드백 자료 가능성 질문 뒤 오프라인 먼저·피드백은 따로 실험 권고에 "오케이 그렇게 진행", UI 6지문 질문("ui와 연결된 6개 지문이 포함되는 세트인가?") 뒤 UI 6지문으로 만들고 맞춰 보기 6지도로 검증 권고에 "오케이 그렇게 진행".
- D-0002 근거: 구조화 문제 골드(선지 주장·추론 경로·대표 오답 경로)를 런타임에 넣으면 저정보 발화에 없는 오류를 채워 넣는 과잉 교정이 생겼다. D-0084는 범위를 좁힌 입력(기호 해석본)의 선례.
- 기존 구조화 문제 골드(후보 23, 승인 0)는 지도 단위와 연결되지 않아 그대로 쓰지 않는다.
- UI 4지문 분석 골드(`docs/experiments/analysis-gold-ui-2026-10-21/`): 지도 v2 12회 모두 검증 통과($1.49), 동결 법인 r1·정보 비대칭 r1·mRNA r2(closeCall)·표면 장력 r2, 입장 4($0.159, 덮어쓰기 0, FIGURE는 정보 비대칭 15), 관계 유형 156관계 기타 0($0.219).
- 외부 전송 승인(사용자 "승인", 2026-10-21): UI 4지문 원문·동결 지도, `gpt-6.1-sol` medium, 지도 12·입장 4·분류 4요청, 재시도 없음(응답 없는 오류만 1회), 상한 지도 $2.5·입장 $0.4·분류 $0.5. 실제 합계 약 $1.87.

## 포함하지 않는 것

비틂 목록 자체(다음 단계), 선지 연결 생성기, 학생 답안 수집, 피드백 런타임 변경, 다리 층.

## 재검토 조건

비틂 목록 검증에서 기타 비율이 높을 때, 또는 피드백 비교 실험 결과가 나올 때.
