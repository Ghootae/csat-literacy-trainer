# 다음 시험에서 근소한 점수 차이면 적은 축을 우선

## 결정

사용자는 다음 테스트 규칙으로 ‘1,2위 점수가 근소할 때는 축이 적은 것이 승리’를 기록하도록 명시했다.

- JEV 반복 평균 점수로 후보1위·2위를 구한다.
- 4점 만점의 반복 평균에서 **1위 점수 − 2위 점수 ≤ 0.10**이면 두 후보 중 축 개수가 적은 후보를 선택한다. 경계값0.10을 포함한다.
- 단순히 축 수가 적다는 이유로 점수 차이가 큰 후보까지 우선하지 않는다.
- 두 후보의 축 개수가 같으면 이 규칙으로 경계를 선택할 수 없으며 기존 점수 비교를 유지한다.
- 처음 기록할 때 임계값을 미정으로 두고 확인 요청했다. 사용자가 같은 작업에서 ‘0.10점 이내’를 선택해 위 기준을 확정했다. 이번 작업은 규칙 기록이며 자동 선택 코드나 추가 호출은 실행하지 않았다.

다음 오프라인 시험에 적용하는 선택 원칙 승인이다. 기존 실험의 원시 점수·선택·L1/L2 결과를 소급 수정하거나 기존 골드·UI를 변경하지 않는다. D-0066/D-0067의 실험 당시 평균1위 선택은 그대로 보존한다.

## 근거

- 사용자 ‘다음 테스트를 위한 규칙으로 기록: 1,2위 점수가 근소할 때는 축이 적은 것이 윈.’
- `docs/experiments/axis-candidate-jev-mrna-passage-2026-10-02/selection.json`: 1문단4축3.430/3축3.376, 2문단3축3.324/4축3.316. 이 수치는 동기의 사례다. 임계값은 별도 사용자 답변 ‘0.10점 이내’로 확정했다.

## 미결정과 재검토

‘근소’의 수치 기준은0.10이하로 확정했다. 동일축수의 평균동률·세 후보 이상 근접한 경우의 확장 규칙은 미확정이다. 현재 명시 범위는1·2위 비교이며 모든 근접 후보를 묶는 확장은 추론하지 않는다.
