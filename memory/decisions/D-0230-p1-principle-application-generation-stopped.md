# 원리 적용형 P1 생성 방식 중단: 중단된 실험으로 기록, 새 갈래는 출제자 시뮬레이션 + 골드 지도 API 파이프라인

## 결정

사용자 결정(2026-11-11).

1. **P1 생성 방식을 중단한다.** P1은 "중단된 실험"으로 기록한다. P1 생성 방식은 규칙 추출 → 상황+계산표 → 선지 작성이다(D-0215 C, D-0227).
2. **판정 결과:** 법인 a 하나를 판정했다. 결과는 "사용 가능, 품질 중하"이다. 근거는 `docs/experiments/principle-application-pilot-2026-11-09/REVIEW-p1-items.md`의 판정 표다.
   - 발문의 "(단, …)"는 수능 형식이 아니다.
   - 선지 깊이는 ①②③이 1단계, ④가 1.5단계다. ⑤는 ④와 같은 내용이다.
   - 핵심 개념인 무상 증자를 깊이 이해했는지 검증하지 못한다.
   - 나머지 6문항은 판정하지 않고 멈췄다.
3. **새 갈래:**
   - 출제자 시뮬레이션으로 출제 규칙을 뽑는다.
   - 깊은 문항은 API 파이프라인으로 만든다. 순서는 골드 지도 탐색 → 선별 → 〈보기〉 조립 → 풀이 검증이다(D-0229).

## 중단 이유 (사용자)

- 상황이 변수와 값을 직접 준다. 그래서 학생이 상황을 지문의 개념으로 옮기는 단계가 빠진다.
- 문항이 산수처럼 된다.
- a(지문 안 상황)와 b(〈보기〉 새 사례)가 겹친다.

## 남는 것

- **구조 분류 기준표와 판정 결과**(D-0223·D-0224)는 기록으로 남긴다. 기출 결과는 "원리 적용이 모인 문항은 〈보기〉 문항에 몰림(7/10 대 2~3/21)"이다.
- **D-0220의 방향은 유지한다.**
  - 큰 표본으로 유형을 범주화한다.
  - 다른 유형의 생성기도 만든다.
  - 난이도 축은 Q-0046에서 다룬다.
- **P1 실행 자료는 지운다고 결정한 것이 아니다.** 스크립트, `runs*/`, 보고서는 기록으로 저장소에 남긴다.
