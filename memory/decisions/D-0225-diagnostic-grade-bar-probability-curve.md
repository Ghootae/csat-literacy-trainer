# 진단 등급 띠 위 확률 곡선: 전국 분포 곡선 대신 띠 바로 위에 등급별 확률 선, 지문 결과와 세트 결과 모두

## 결정

사용자(2026-11-10, 세트 결과 화면 사진 두 장, "이걸 의도한게 아니라 이런 식인거야"). 질문 셋에 대한 답:

1. **전국 분포 곡선 제거**(사용자 "둘 다 없애"): 세트 결과 "① 내 위치"의 "전국 분포에서의 위치" 정규분포 곡선과 그 아래 "n등급: 전국 상위 …%" 문장을 없앤다.
2. **확률 곡선 위치**(사용자 (가)): 등급 띠 바로 위에 곡선을 그린다. 가로축은 띠의 1~9등급 눈금과 같고 높이는 그 등급 확률이다. 띠를 함께 쓰는 지문 결과 화면과 세트 결과 화면 모두에 그린다. "지문을 풀수록 또렷해진 위치"의 작은 띠에는 넣지 않는다(코드 에이전트 제안, 사용자 수용).
3. **모양**(사용자 (가)): 선만 그린다(아래 채우기 없음).

## 정정

- D-0222 2번의 "작은 전국 분포 곡선"은 코드 에이전트가 사용자 답 (다)를 잘못 옮긴 것이다. 사용자가 뜻한 것은 띠 위의 확률 곡선이었다(이 결정의 대화).

## 구현 (코드 에이전트)

- `packages/app/src/client/diagnostic/logic.ts` `gradeCurvePath`: 등급 칸 가운데 높이 = 확률 / 최댓값(최댓값이 맨 위), 이웃 가운데 사이는 띠 진하기(`gradeGradient`)와 같은 코사인 곡선으로 잇는다. `zOfPercentile`, `GRADE_EDGES`, `gradeShareText`는 쓰는 곳이 없어 지웠다.
- `GradeBar.tsx`: 큰 띠 위 SVG 선(`data-testid="grade-curve"`), 커서 확률 말풍선은 띠와 곡선 어디에 대도 보인다.
- `ResultView.tsx`: 전국 분포 곡선·문장 제거. `diagnostic.css`: 곡선 칸, 쓰지 않는 곡선·띠 색 변수 제거.

## 근거

- 시험: 화면 vitest 40건 통과(곡선 높이 시험 추가, 전국 비율·z 시험 제거), Playwright 진단 2건 통과(따로 띄운 시험 서버, 곡선 보임·"전국 분포에서의 위치" 없음 확인). 사용자가 띄워 둔 5173 서버를 재사용하면 실제 서버로 요청이 가서 실패한다(시험 환경 문제, 코드와 무관).

## 다시 볼 조건

- 코사인 잇기는 등급 칸 가운데에서 기울기가 0이라 곡선에 작은 턱이 보인다. 매끄러움이 문제가 되면 띠 진하기와 곡선을 함께 다른 잇기(예: 단조 3차 보간)로 바꾼다.
