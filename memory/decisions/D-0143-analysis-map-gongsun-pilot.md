# 문단 분석 지도 공손룡 1지문 실험: 판정 설계와 1단계 승인

## 결정

[D-0141](./D-0141-paragraph-analysis-map-direction.md) 방향을 공손룡과 후기 묵가 지문 하나로 시험한다. 실험 스크립트로만 하고 웹앱에는 연결하지 않는다.

- **두 단계, 따로 승인.**
  - 1단계 지도 생성: sol로 3회 생성한다. Claude가 비교 문서(예전 손 위계 p1~p11·c1~c5 대조 포함)를 쓰고, 사용자가 하나를 골라 고치거나 그대로 동결한다.
  - 2단계 하향 판정: 동결 지도의 노드 수로 호출 수·비용을 계산해 다시 승인받는다.
- **판정 설계 (확정).**
  1. 노드마다 독립 판정한다. 호출 하나에 노드 하나를 넣고, 위계 정보(상위·하위, 다른 노드의 판정)는 넣지 않는다. 입력은 학생 발화, 노드 문장, 노드의 근거 원문 문장이다. 문단 전체 원문은 넣지 않는다.
  2. 위계 결합은 코드 규칙으로 한다.
     - 상위 충족 + 하위 일부 부분·충족 → 상위 포섭(정상)
     - 상위 충족 + 하위 전부 없음 → 불일치 표시(사람 검토)
     - 상위 없음 + 하위 여럿 충족 → 나열형 패턴
  3. 가지치기는 이번 실험에서 하지 않는다.
  4. 판정 형식은 순서형 라벨(직접 충족 / 부분 / 없음 / 모순)과 근거 인용이다. 인용은 학생 발화에서만 하고, 인용이 없으면 직접 충족을 줄 수 없다.
  5. 반복은 3회, 판정 모델은 luna와 sol 둘 다.
- **라운드.** 1차는 첫 응답이다. 2차 입력은 첫 응답 + 질문 + 학생 답을 그대로 이어 붙인다(모델 재작성 없음). 질문은 맥락용이며 인용 근거가 될 수 없다.
- **응답 재료.** 기존 기록만 쓴다. V4 대화 로그 공손룡(시험 문구 제외)과 단순 형식 개발자 모드 로그다. 부족하면 나중에 단순 형식 모드로 보탠다.
- **관계 라벨.** 이번에는 자유 이름으로만 붙인다(열린 라벨링). 닫힌 목록은 정하지 않는다.
- **1단계 승인.** OpenAI로 공손룡 지문 원문을 전송한다(학생 응답은 보내지 않음). sol(`gpt-6.1-sol`, medium) 3회, 재시도 없음, 상한 2달러.

## 2단계 결정 (2026-10-16 추가)

1단계 뒤 사용자와 정한 2단계 범위다. 위 판정 설계 5번(반복 3회, luna·sol)은 이번 2단계에서 적용하지 않고 정확성 단계로 미룬다.

- **목적.** 판정 정확성이 아니라 구현 로직(추출 → 라운드 → 판정 → 코드 결합 → 기록)을 명확히 하는 것.
- **동결 지도.** r3를 수정 없이 동결한다(`docs/experiments/analysis-map-gongsun-2026-10-16/FROZEN.md`). 비교 문서의 두 군데 수정 권고는 관계 선(R5, R18·R19)과 충돌해 적용하지 않는다.
- **모델·반복.** luna(`gpt-6-luna`) 1회만.
- **관계를 별도 판정 단위로 넣는다.** 관계 하나당 호출 하나, 노드와 같은 4단계 라벨과 인용 규칙. 판정 기준은 관계 이름이 아니라 설명(note)이다. 관계는 양 끝 중 뒤쪽 문단의 대화에 배정하고, X·TOP이 끝에 붙은 관계는 뺀다. 결합 규칙에 "관계 충족 + 이 문단 끝 노드 없음 → 불일치"를 더한다.
- **결합 규칙 세부**(Claude 정리, 인계 문서 5절): 상위 충족 = DIRECT, 하위 잡음 = DIRECT·PARTIAL. 상위 PARTIAL은 패턴 없음.
- **외부 전송 승인(사용자 "승인").** OpenAI `gpt-6-luna`(medium, 1회)로 공손룡 대화의 학생 발화·교사 질문(V4 로그·단순 형식 로그)과 동결 지도의 노드 문장·근거 원문을 보낸다. 상한 2,000요청·$1, 재시도 없음(실패분만 같은 상한 안에서 재전송 가능). 학생 발화가 든 결과는 `stage2/`에 저장한다.
- **재개 승인(2026-10-17, 사용자 "승인").** 첫 실행이 네트워크 연결 오류 666건으로 끊기고 실패분을 예약액으로 계산해 $1 상한에 닿았다(실제 청구 $0.11). 연결 오류(서버 미도달)는 $0, 타임아웃은 예약액으로 계산하고, 요청 상한을 시도 2,300건으로, 비용 상한은 실제 청구 $1로 바꿨다. 연결 오류 10회 연속이면 멈춘다.

근거(사용자): 2단계 진행과 관계 포함("일단 2단계 실험을 해보자. 관계 정보를 넣는 게 현실적일거 같은데?"), 목적과 규모("'구현 로직'을 명확히 해보려는 거니까. 루나로만 반복 1회 판정해보는건 어때?"), 관계 방식("오케이."), 지도("동결"). 인계 문서: `docs/handoffs/2026-10-16-analysis-map-gongsun-stage2.md`.

## 근거

사용자(2026-10-16): "공손룡으로 하자", 라운드별 판정("첫번째 응답-> 하향 판정 1차, 질문 후 재구성된 응답 -> 하향 판정 2차"), "루나와 솔 둘로 같이 해보고 비교", "일단 실험". 각 노드 독립 판정과 판정 설계 다섯 항목에는 "응 맞아, 그렇게 확정하자", 지도 생성 방식에는 "응 그렇게 하자", 재구성 방식 A에는 "응 A로 하자", 응답 재료에는 "응 기존 기록으로 먼저 하자", 1단계 조건에는 "응 승인, 진행해".

불일치 표시 갈래는 사용자의 지적("상위 노드는 충족인데 하위 노드는 모두 미충족. 이건 말이 안되는데")에서 나왔다.
