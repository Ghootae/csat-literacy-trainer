## 1. 설정

| 항목 | 값 |
|---|---|
| 생성 모델 | gpt-6.2-sol, reasoning medium, 재시도·수리 없음 |
| 규칙 | `docs/experiments/easy-items-2026-11-27/rules-underline-v3.md` (developer 메시지 전문) |
| 의뢰 | 발문·정답 번호를 의뢰에서 정함. 밑줄 대상은 의뢰가 정하거나 생성기가 고름(쌍이면 ㉠·㉡). 같은 지문 둘째 문항은 첫 문항의 targets 와 선지("이미 쓴 선지")를 받음 |

규칙 핵심:
- 밑줄은 지문에 딱 한 번 나오는 구절, 그 개념을 정의·설명하는 자리에 긋는다.
- 다섯 선지는 모두 밑줄 대상을 주어로, 서로 다른 측면을 묻는다.
- 정답은 지문의 원리·정의를 ㉠에 한 번 적용한 것이다.
- "적절한 것" 발문의 오답 4개: 문장 끝 반대말·부정·'만' 붙이기(끝 반전)는 1개까지, 원리 적용이나 지문 두 곳 맞대기가 필요한 오답 1개 이상, 나머지는 문장 안쪽(짝 순서·주체·순서·목적·이유 절)을 비튼다.
- "이유" 발문은 "맞지만 이유 아님"이나 "결과를 원인으로" 오답을 하나 넣는다.

## 3. 알고 확정하는 약점

1. 표본이 작다. 우리 지문 2편, 문항 4개. 혈액 응고 2개는 v2로 만든 것(v3는 밑줄 자리 조항만 더함).
2. 천장 효과: 기출 8개 중 7개가 늘 2.00이라 생성 2.00과 차이가 안 보인다. 기출 수소(HY)는 실행마다 1.5 → 1.0 → 0.75로 흔들렸다.
3. 평가자가 평가원 기출을 기억할 수 있다(내용 일치 시험 때 8개 중 6개).
4. 평가자는 같은 모델(gpt-6.1-sol)이다. 학생·교사 판정이 아니다.
5. 4차 점수 상승은 밑줄 자리와 함께 문항도 새로 만들어진 결과다.
6. 〈보기〉 적용 문항, [A] 바탕 추론, 관점 평가, 어휘 뜻 문항은 다루지 않는다. "이유" 발문은 블라인드로 따로 재지 않았다.
