# 어휘 문항 생성 규칙 v3 확정

세트 마지막 문항(어휘, 2점)은 `rules-vocab-v3.md` 규칙으로 만든다. 두 꼴을 모두 쓴다. 꼴 A는 문맥적 의미("ⓐ와 문맥상 의미가 가장 가까운 것은?")이고, 꼴 B는 바꿔 쓰기("문맥상 ⓐ~ⓔ와 바꿔 쓰기에 적절하지 않은 것은?/가장 적절한 것은?")다. **꼴 B는 세트 시험 때 사람이 함께 본다**(아래 3절 1번). 세트 조립기는 이 설정을 그대로 부른다. 설정을 바꾸려면 새 결정이 필요하다.

결정: Ghootae 2026-11-28 16:49 KST 카드 "확정, 바꿔 쓰기는 사람 확인".

## 1. 설정

| 항목 | 값 |
|---|---|
| 생성 모델 | gpt-6.2-sol, reasoning medium, 재시도·수리 없음 |
| 규칙 | `docs/experiments/easy-items-2026-11-27/rules-vocab-v3.md` (developer 메시지 전문) |
| 의뢰 | 꼴(A/B)·방향(B: 한자어→고유어 또는 고유어→한자어)·발문·정답 번호를 의뢰에서 정함. 같은 지문 둘째 어휘 문항(또는 세트 안 다른 어휘 표시)은 "이미 고른 낱말"을 받음 |
| 실행 파일 | `docs/experiments/easy-items-2026-11-27/vocab-d/gen_vocab.mjs` (+ `vocab-a/mark_passages.py` 로 지문에 ⓐ~ⓔ 표시) |
| 바닥 검사 | 정답 하나(풀이 2회), 표시 구절 지문에 딱 한 번, 꼴별 형식(A: 예문 5개 같은 낱말 / B: ⓐ~ⓔ 순서, 한자어 선지는 한자 병기), 겉모양, 꼴 B 의 other_sentence 확인. `vocab-a/floor/`, `vocab-d` |

규칙 핵심:
- 전문 용어·핵심 개념어는 고르지 않는다. 표시는 지문에 한 번만 나오는 구절에 한다.
- 선지마다 사전 뜻을 한 줄 적는다.
- 꼴 A:
  - 고유어 기본 동사의 2차·추상 뜻을 고른다.
  - 예문 5개는 같은 낱말·같은 활용형으로 쓴다.
  - 정답은 지문과 같은 뜻이되 **지문과 같은 말 묶음은 쓰지 않는다**.
  - 오답에는 구체적 기본 뜻 하나와 정답 뜻에 가까운 이웃 뜻 하나를 넣는다.
- 꼴 B:
  - "안 맞는 낱말"은 지문 낱말의 다른 뜻과 짝이어야 한다. 즉 다른 문장에서는 바꿔 쓸 수 있어야 한다(other_sentence).

## 2. 근거 (코덱스 단독 블라인드, 수능 같음 2 / 중 1 / 아님 0)

| 시험 | 규칙 | 지문 | 꼴 A | 꼴 B | 전체 | 기출 8개 | 판정 |
|---|---|---|---|---|---|---|---|
| vocab-a | v1 | 기출 표면 장력·노비제 | 2.00 / 0.13 | 2.00 / 1.50 | 1.41 | 1.75 | 미달(말 묶음 반복 1문항) |
| vocab-b | v2 | 노비제 꼴 A만 | 1.75 | (위 점수) | 1.81 | 1.81 | 통과 |
| vocab-c | v2 | 우리 혈액 응고·청약 철회 | 1.88 / 2.00 | 1.25 / 0.75 | 1.47 | 1.78 | 통과(여유 0.09) |
| vocab-d | v3 | 우리 지문 꼴 B만 | (위 점수) | 0.75 / 1.00 | 1.41 | 1.78 | 미달(꼴 B 규칙 효과 없음) |

- 근거 문서: `ANALYSIS-vocab-gichul.md`(평가원 어휘 20문항), `vocab-a~d/REPORT-*.md`.

## 3. 알고 확정하는 약점

1. **꼴 B(바꿔 쓰기)는 우리 지문에서 0.75~1.25로 기출 꼴 B(1.84)보다 낮다.** 평가자가 거의 매번 "너무 쉬움"을 붙였다. 기출 꼴 B도 오답이 비슷하게 뚜렷하다(수소: 단축·제작·습득·성행). 같은 규칙으로 기출 지문 위에 만든 꼴 B는 2.00·1.50이었다. 그래서 평가자가 진짜 기출을 알아보고 후하게 주는 탓일 수 있다고 보지만, 확인하지 않았다. 세트 시험 때 사람이 꼴 B를 함께 본다.
2. 표본이 작다. 꼴마다 우리 지문 2문항.
3. 정답이 사전 뜻에 달려 있다. 평가자도 같은 계열 모델이라 뜻 구별 오류를 못 잡을 수 있다(정답 일치는 모든 시험에서 8/8).
4. 두 낱말 짝 꼴("ⓐ, ⓑ의 의미로 쓰인 예가 바르게 짝지어진 것은?", 평가원 20 중 3)과 교육청의 "사전적 의미" 꼴은 다루지 않는다.

## 4. 다시 볼 조건

- 세트 시험에서 사람이 꼴 B를 "기출보다 쉽다"고 보면 꼴 B 규칙을 다시 연다.
- 출처를 가린 기출(지문을 살짝 바꾼 것)로 평가자의 기출 알아보기 효과를 재면, 그 결과로 3절 1번을 다시 판단한다.
- 생성 모델이 바뀔 때.
