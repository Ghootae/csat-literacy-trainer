# 규칙 감사 결론: 생성 규칙 v6.2 채택

규칙 감사 4단계(v5·v6 시험 3회, 비용 $7.20)를 마치고 생성 규칙 v6.2(다섯 층 + 생성 기준 GN1 = 옛 C23 되살림)를 채택한다. 검사기는 v6.1(관점 수리 끔)이다. 칸 생성은 재개하며 앞으로 모든 칸은 `RULES_V=6`(생성 모델 gpt-6.2-sol)로 만든다. 결정은 사전에 정한 기준(PROPOSAL-v62 4절)을 따른 것이고, 순서표 등 남은 손질은 사용자가 `REVIEW-step4-r3-web.md` 2·3절을 승인했다.

## 근거: 3회차 기준 값 (REVIEW-step4-r3-web.md 1절)

| 기준 (PROPOSAL-v62 4절) | 값 | 판정 |
|---|---|---|
| ① 수능 아님 2회 이상 문항 없음 | 0개 | 지킴 |
| ② v5보다 0.5 넘게 낮지 않음 | +0.562 (공시 +0.375, 의미 +0.750) | 지킴 |
| ③ 수능 같음 3회 이상 문항 1개 이상 | 3개 (공시 A·B, 의미 B) | 지킴 |
| ④ 결함 남은 문항 없음 | 0개 | 지킴 |

회차 경과: v6(1회차) 수능 같음 0/16 → v6.1 깊이 전략 의무(2회차) 0/16 → v6.2 옛 C23을 생성 기준 GN1로 되살림(3회차) 9/16, 같은 회차 v5 대비 +0.56. 평가자 흔들림(이번 회차 v5·기출이 함께 낮게 나옴)은 같은 회차 비교로 보정했고 결론을 뒤집지 않는다.

## 4단계에서 배운 것

1. 기출 준수율만으로 생성 규칙의 층을 정하면 안 된다. 기출이 자주 어기는 규칙(C23, 13/26)도 생성기에는 필요할 수 있어 '생성 기준(G)' 층을 따로 둔다. 이 층의 규칙은 시험 생성 근거가 있어야 둔다.
2. 감사 표(F4)의 '원리 적용'은 "정의를 반대로 말한 선지"와 진짜 적용을 가르지 못한다. 다음 감사 칸 후보로 적는다(지금은 고치지 않음).
3. 선택 전략 깊이 의무(v6.1)는 효과를 따로 재지 못했다. 해롭다는 근거가 없어 유지한다.
4. 관점 수리 끔(v6.1)은 확인용 관점 기출의 거짓 경보를 없앴다(수리 대상 4/7 → 2/7).
