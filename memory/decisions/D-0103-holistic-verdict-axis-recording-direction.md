# 문단 판정 방향: 판정은 전체 판정(H0), 기록과 질문 생성은 축 근거

## 결정

다음 문단 판정기 설계 후보의 방향을 정한다.

- **질문 여부 판정:** 문단 전체 판정(H0, 축 없는 원문 기반)으로 한다.
- **미확인 기록과 질문 생성:** 축을 근거로 한다.
- **철회 규칙:** 그림자 실험의 철회 규칙("V4 해결·그림자 미해결인데 학생 발화 인용이 없으면 해결로 바꾼다")은 학생이 중요한 정보를 빠뜨린 경우를 통과시키는 결함이 있다. 사용자가 이를 확인했다.

**이 결정에 포함되지 않는 것:**

- 운영 V4 교체, UI 변경
- 프롬프트 수정의 확정
- 블라인드 재판정(`REVIEW-SECOND.md`)에 따른 그림자 실험 결론 확정

후속 설계는 별도 결정으로 한다. 설계를 바꾼 판정기는 이번 85시점이 아닌 새 응답으로 검증한다(과적합 방지).

## 추가 합의 (2026-10-08, GPT 의견에 사용자 동의)

- **철회 규칙 대신 종류별 근거 요건:** "인용이 없으면 미해결을 철회한다"는 규칙은 다음 설계에서 쓰지 않는다. 오류(incorrect)는 학생 발화 인용을 근거로 한다. 누락(missing)은 어떤 핵심 관계가 빠졌고 왜 중요한지를 근거로 한다. "전체 미해결·축 해결이면 근거를 재검토한다"는 자동 철회와 다르다.
- **"원문과 다른 주장이 있는가"와 "질문할 만큼 중요한가"를 분리한다:** 판정기 출력과 사람 판정 양식 모두에서 따로 기록한다.
- **1차 실험의 "오류 놓침 0건"은 오류 탐지의 안전성 근거가 아니다:** 사람 양식이 두 판단을 한 칸에 섞었다(R012 허가와 보고의 혼동). 확인된 것은 명백한 방향 역전 탐침 3개를 잡았다는 것뿐이다.
- **재판정 양식:** `REVIEW-SECOND.md`에 "원문과 다른 주장: 있음/없음"과 "다른 주장 인용" 칸을 더했다.
