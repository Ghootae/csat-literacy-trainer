# 최초 오답의 확인된 복수 오류를 순차 질문하고 누적 답변으로 최종 판정

## 결정

사용자는 ‘확인된 관련 오류가 남지 않고, 실제 수정이 누적 답변에서 확인될 때 성공이며,
그렇지 않으면 코칭 종료’에 동의하고 다음 두 오류 경로를 지정했다.

1. 최초 오답 근거에서 오류 1과 오류 2를 확인한다.
2. 오류 1에 대한 교정 질문을 하고 답변을 받는다.
3. 첫 답변의 수정 성공·실패와 관계없이 오류 2에 대한 교정 질문을 하고 답변을 받는다.
4. 두 질문에 대한 답변을 포함한 누적 발화로 전체 수정 여부를 재평가한다.
5. 확인된 관련 오류가 남지 않고 실제 수정이 확인되면 재선택 1회를 제공한다.
6. 실패하거나 수정 여부를 확인할 수 없으면 상세 코칭 후 종료한다.

중간 답변의 실패만으로 조기 종료하거나, 하나의 오류 수정만으로 조기 재선택하지 않는다.
‘합산’은 성공 횟수의 합계·다수결이 아니라 누적 발화에서 관련 오류가 모두 해소됐는지 확인하는
것이다. 뒤의 답변에서 앞 오류를 고칠 수도 있으므로 최초 실패 판정을 영구 고정하지 않는다.

## 이전 후보와의 관계

- D-0051의 최초 오답 ‘교정 질문 총 1회’와 ‘그 답변 실패 시 즉시 종료’는 이번 복수 오류
  경로에서 대체한다. 오류별 한 질문으로 순차 진행하며 사용자 예시에서는 총 2회다.
- D-0051의 선택 최대 2회·최종 재선택 종료 규칙은 유지한다. D-0051 전체를 폐기하지 않는다.
- D-0053의 전체 결론 확인 불가 우선은 유지한다. 게이트에서 확인 불가이면 국소 오류가
  여러 개 보여도 이 교정 묶음에 진입하지 않고 코칭 종료한다.
- D-0052에 따라 수정된 답변과 과거 선택의 불일치를 새 실행 오류로 만들지 않는다.
- 교정 성공을 정답 근거 충분성이나 학생이 말하지 않은 추가 결론 이해로 자동 확대하지 않는다.

## 범위와 미정 사항

최신 확정: [D-0059](./D-0059-problem-feedback-clarifications-consolidated.md)에서 새 오류의 질문 추가
금지·누적 최종 평가 반영과 이미 수정된 질문 생략을 승인했다. 교정 단계에는 응답별 오류 원칙을
공통 적용한다. 아래는 단계별 합의 이력이며 현재 설계는 D-0059를 우선 읽는다.

후속 합의: [D-0056](./D-0056-question-count-per-error-deferred.md)에서 오류 N개에는 오류별 1회씩
질문 N개를 제시하고 총수 상한을 두지 않기로 확정했다. 아래 ‘3개 이상일 때 상한 미정’은
당시 이력이며 더 이상 미정이 아니다. 새 오류 추가 등 별도 경계는 남는다.

이번에 명시된 사례는 최초 오답의 오류 2개다. 최초 정답의 복수 오류에 동일한 질문 묶음을
적용할지, 오류가 3개 이상일 때 총 질문 수 상한을 어떻게 둘지, 교정 중 새로 드러난 오류를
질문 대상으로 추가할지 등은 별도 확정 대상이다. 관련 오류가 남으면 성공이 아니라는 원칙과,
남은 오류에 추가 질문할 권한은 구별한다. 무제한 질문을 승인한 것으로 해석하지 않는다.
초기 질문 답변에서 후속 대상 오류까지 이미 수정한 경우 예정 질문을 생략할지도 별도 경계다.
