# 깊은 〈보기〉 v5.3 비교 종료 및 v5.2 기준 유지

사용자가 정한 채택선은 v5.3 8문항 중 두 평가자 모두 ‘수능 같음’ 3개 이상, ‘수능 아님’ 0개다. 둘 중 하나라도 미달이면 멈추고 v5.2를 기준 버전으로 둔다. 실제 공동 최고 1개, 한 명 이상 최하 3개(공동 최하 2개)로 모두 미달했다. 이 결정은 v5.2와 v5.3의 비교에 적용된다.
