# 별도 지시가 없으면 프롬프트는 한글로 작성

사용자는 앞으로 별도의 언어 지시가 없는 경우 프로젝트에서 새로 작성하는 프롬프트를 한글로
작성하도록 결정했다.

- 시스템·개발자·외부 API 계약이 특정 언어를 요구하지 않으면 한글을 기본으로 한다.
- 기존에 실행된 프롬프트는 실험 재현성과 해시 보존을 위해 소급 번역하지 않는다.
- 기존 프롬프트를 개선할 때는 새 버전을 만들고 한글로 작성한다.
- JSON schema의 필드명, enum, 코드 식별자처럼 프로그램 계약에 해당하는 영문은 유지할 수 있다.
- 다른 언어가 성능 비교나 외부 계약상 필요한 경우 그 실험에서 명시적으로 기록한다.

근거: 2026-09-23 사용자의 명시적 지시.
