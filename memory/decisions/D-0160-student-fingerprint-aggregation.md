# 학생 이해 지문 집계 방식

## 결정

판정 자료(라운드별 노드·관계 라벨)를 묶음 × 칸으로 세어 학생 이해 지문을 낸다. 구현 `scripts/aggregate-student-fingerprint.mjs`, 인계 `docs/handoffs/2026-10-21-student-fingerprint-aggregation.md`(보완 v2 포함).

1. **칸.** 노드는 층(명제·합성·요지), 관계는 18유형과 4갈래(D-0147). 축 (나)(`docs/review/analysis-map-student-fingerprint-2026-10-18.md`).
2. **묶음.** 학생 한 명 = 세션(학생 표시가 생기면 그것으로 바꿈). 출처별(v4·sh·test·copy) 묶음은 점검용.
3. **세기.** 칸마다 포착률 (D+P)/N, 정밀도 D/(D+P), 오류율 C/(D+P+C)을 따로 낸다. 한 점수로 합치지 않는다. 포착률에는 말 안 함과 모름이 섞여 있어 판단에는 오류율을 먼저 쓴다. 첫 라운드를 기본으로, 마지막 라운드는 따로. 오류 사건 수(D-0143 집계 규칙)를 칸 옆에 적는다.
4. **문단을 넘는 관계는 세지 않는다.** 문단 요약은 문단 안 활동이라 분모에도 넣지 않는다. 칸도 두지 않는다.
5. **관계 오류는 자체 오류만 센다.** 관계의 양 끝 노드 중 하나라도 같은 라운드에서 ✕이면 "물려받은 오류"로 따로 적고 비율 분모에서 뺀다.
6. **표본.** 칸 N<10은 "표본 적음". 학생별 표는 층·갈래까지만, 18유형은 합친 표에서만 본다.

## 근거

- 사용자(2026-10-21): 범위 (가) 집계 스크립트+기존 판정 자료 시험 "가로 가자", 세션 단위·출처 점검 "진행", 세기 방식 "오케이 진행", 문단 넘는 관계 "분모에 넣지 않아. 문단 요약은 문단 내에서만 이루어지는 활동인데, 문단간의 관계를 세는건 말이 안돼", 관계 분류 전송 "승인", 보완 v2 "오케이".
- 점검(`docs/experiments/student-fingerprint-2026-10-21/by-source/FINGERPRINT.md`, 첫 라운드): 원문 복사 4라운드 포착 100%·오류 0; 시험 응답 8라운드 명제 오류율 37%, 사건 16.
- 보완 v2 근거: 첫 실행에서 시험 응답의 근거 관계 오류율 100%·대조 67%였으나 심은 오류는 모두 명제 사실 오류. v2 뒤 시험 응답 관계 자체 오류 0(물려받은 18). 기록 응답의 자체 오류 3건(공손룡 R1·R6·R7)은 Claude 확인 결과 모두 실제 방향·인과 뒤집기.
- 표본: 세션 53개 중 49개가 1라운드, 칸 N≥5 유형이 있는 세션 8개. 문단당 문단 안 관계 약 4.5개.
- 외부 전송 승인(사용자 "승인"): 공손룡·도파민 동결 지도 관계 유형 분류 v3, sol medium 2요청, 상한 $0.3. 실제 $0.090, 63관계 기타 0.

## 포함하지 않는 것

새 학생 응답 수집, 재판정, 말 안 함/모름 구별(선지 연결 단계), 다리 층, UI.

## 재검토 조건

실제 학생 응답이 쌓여 학생별 칸이 채워질 때(표본 기준·갈래 단위 재검토), 또는 선지 연결로 포착률 해석이 바뀔 때.
