# 사고 진단은 주기 실행, 모델은 sol 고정

## 결정 (사용자, 2026-10-10)

- 사고 진단(결과 유형·실패 단계·함정 유형)은 문항마다 실시간으로 하지 않고 일정 주기로 묶어 실행한다.
- 진단 모델은 `gpt-6.1-sol`로 고정한다. 주기 실행이라 지연이 문제되지 않고, 요청당 약 $0.012(v0.1 측정)라 비용 부담이 작다.

## 근거

- [v0.1 결과](../checkpoints/2026-10-10-thought-diagnosis-v01-results.md): sol은 함정 태그 Jaccard 0.96, 판단 불가 사유 7/7. luna는 0.72, 4/7이고 함정 유형을 `MISREAD_FACT`로 뭉뚱그리는 경향이 있다.

## 경계 (Claude 제안, 미확정 세부)

- 진단 결과는 실시간 판정기 입력으로 쓰지 않는다. 리포트와 다음 주기 문항 선택에만 쓴다.
- 주기 기준(문항 수 대 기간), 패턴 확정 규칙, 다음 주기의 확인 문항 배치는 미정이다.
- 증거 확보(풀이 유도·확인 질문·행동 흔적 기록)는 실시간 세션에서 해야 한다.
