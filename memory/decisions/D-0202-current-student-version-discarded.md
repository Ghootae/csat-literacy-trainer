# 지금의 학생용은 폐기한다: 학생용은 개발자용 확정 뒤 그것을 고쳐 새로 만든다

## 결정

1. **개발자 경로가 정본이다.** 판정 방식과 화면은 `/dialogue/lab`(문단 단순 형식)과 `/problem/lab`(문제 v5)에서 확정한다.
2. **지금의 학생용은 폐기한다.** 문단 V4(골드 축을 쓰는 판정, [D-0013](./D-0013-paragraph-optional-revision-v4.md)), 문제 v3
   ([D-0008](./D-0008-problem-dialogue-v3-operational-default.md)), 학생용 화면(`/dialogue` 등)은 "학생용 기본값"이 아니다. 설계·판단의
   근거나 비교 기준으로 들지 않는다.
3. **학생용은 확정된 개발자용을 고쳐 새로 만든다.** D-0176의 얇은 학생판(2단계)과 정식 전환(5′)도 이 방식이다.
4. **기록 수준의 폐기다(사용자 선택 (가)).** 코드는 지금 지우지 않는다. 남길 것과 지울 것은 학생용을 새로 만들 때 한 번에 정한다
   ([D-0180](./D-0180-student-state-model-v1-discarded.md)과 같은 방식).

## 근거

- 사용자(2026-11-05): "몇번 반복해서 얘기한건데, 학생용은 차후에 개발자용을 확정한 후 수정해서 만든다고 했어. 따라서 현재
  학생용은 폐기하면 돼." 폐기 범위는 코드 에이전트 권고 (가) 기록 수준에 "(가)로 기록해줘".
- 계기: 코드 에이전트가 판정의 골드 사용을 답하면서 `CURRENT_STATE.md`의 "학생용 기본값 V4·v3" 서술을 살아 있는 기준으로 읽고
  "V4는 골드를 쓴다"를 예외로 들었다. 정정: 판정 단계(문단 단순 형식, 문제 v5)는 골드를 쓰지 않는다.
- 같은 방향의 이전 기록: [D-0031](./D-0031-developer-ui-url-only.md)(학생용 UI는 개발자 화면 확정 전 수정·안내하지 않음),
  [D-0176](./D-0176-student-switch-roadmap-pilot-before-expansion.md) 사용자 원안("UI만 다소 수정해 학생용 완성").

## 영향

- `CURRENT_STATE.md`·`WORK_TREE.md`에서 "학생용 기본값" 서술을 지우고 이 결정으로 바꾼다.
- 축 기반 쪽(Q-0036)의 "학생용이 V4라 코드 유지" 이유는 사라진다. 코드 정리는 4항대로 학생용을 새로 만들 때 한다.
- 정책 문서(`PS-PROBLEM-SOURCE-DIRECT-V1`, `PS-DIALOGUE-STUDENT-AGENCY-V4`)는 역사 자료로 남긴다.

## 다시 볼 조건

- 학생용을 새로 만들 때 폐기한 코드의 정리 범위를 정한다.
