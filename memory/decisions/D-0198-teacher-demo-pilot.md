# 중학교 국어 교사 원격 시연을 학생 확인 앞의 사전 점검으로 둔다

## 결정

- 섭외된 중학교 국어 교사 2~3명에게 개발자 화면을 원격으로 쓰게 하고, 사용 후 짧은 설문으로 사용감·개선점을 받는다. D-0176 순서의 "실제 학생 확인" 앞에 두는 사전 점검이며 학생 확인을 대신하지 않는다.
- 범위: 지문 하나로 문단 요약(`/dialogue/lab`, v4.8) → [문제 풀기] → 문제 풀이(`/problem/lab`, v5.8). 학생용 `/dialogue`(V4·v3)가 아니라 운영 후보를 보인다.
- 방식: 튜토리얼 웹 페이지(정보 비대칭 지문 + 13번 각본, 문단별 예비 답 포함)를 따라 한 뒤 자유 사용. 사용자는 동석하지 않는다.
- 교사에게 판정별 동의 의견은 받지 않는다(부담). 판정 정확성은 남은 기록으로 코드 에이전트·사용자가 따로 본다.
- 교사 구분은 설문에 세션 주소를 붙여 넣는 문항으로 대신한다(구현 없음). 판정 서랍은 숨기지 않고 "열지 않아도 됨"으로 안내한다.
- 접속은 기간을 정해 로컬 서버·터널을 켜 두고 잠자기 방지·API 한도를 건다. 인증은 두지 않는다.
- 시연용은 개발용과 나눈다: 고정 커밋의 별도 worktree(`/Users/mac/Projects/csat-literacy-teacher-demo`, 브랜치 `demo/teacher-2026-11`)를 포트 5273~5275로 띄우고 터널은 5273으로 보낸다. 기록은 그 폴더에 따로 쌓인다(사용자, 2026-11-03).

## 근거

- 사용자 답변(2026-11-03, 이 대화): 범위 (다), 버전 B, 튜토리얼 후 직접 사용, 2~3명 섭외 완료·기간 무관·중학교, 판정 의견 미수집("너무 로드가 커서"), 설문 방식·접속 방식은 권고 동의. 지문은 사용자가 정보 비대칭 선택("과학지문은 사람들이 부담스러워해").
- 각본 시험: 최종 각본의 모든 칸이 3/3(문단 2 보강판 포함) 기대 반응(`docs/experiments/teacher-tutorial-2026-11-03/REPORT-script-run-desktop.md`).

## 산출물

- 튜토리얼을 저장된 판정 재생(모델 하우스)으로 고정하는 안: 결과는 항상 같아지지만 각본과 다른 답을 넣으면 대응하지 못해 불채택(사용자, 2026-11-03). 실제 판정 + 각본 + 예비 답을 유지한다.
