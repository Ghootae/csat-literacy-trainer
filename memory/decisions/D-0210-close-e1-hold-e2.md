# E1 닫음, E2 보류, 원리 적용형 선지는 차후 별도

## 결정

1. **E1(골드 기반 문항 생성)을 닫는다.** v3가 사전 성립 기준(D-0206 보완 2의 24)에 미달했다. 결론은 다음과 같다.
   - 정확성은 A·A′·B 모두 천장이고, 맞는 선지에 지어낸 관계는 0이다.
   - 깊이 상승은 지시 효과다(A′ v2 7 → v3 12, B 11 → 11). 골드 지도의 문항 수준 이점은 관찰되지 않았다.
   - 기출과의 차이는 원리·정의를 새 상황에 적용하는 추론 선지다(기출 16 대 생성 2~4).
2. **E2(지문 대체 생성)는 보류한다.** D-0206 "다시 볼 조건"(B가 A′보다 낫지 않음)에 해당한다.
3. **원리 적용형 선지 생성은 차후 별도 과제로 진행한다.** 지문의 규칙·식·정의를 지문에 없는 새 상황에 적용하는 선지다. E1의 연장이 아니라 새 설계로 다룬다. 〈보기〉 문항 생성(D-0206 14′)과의 관계는 그때 정한다.
4. D-0206 8(사용자 블라인드 판정)·5·6(풀이 검사)은 E1을 닫으면서 실행하지 않는다.
