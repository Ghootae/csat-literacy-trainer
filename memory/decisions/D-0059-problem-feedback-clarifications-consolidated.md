# 마지막 네 가지 명료화 승인 및 문제 풀이 수형도 통합

## 승인 범위

사용자가 남은 네 가지 제안에 모두 동의하고 저장 가능한 전체 수형도를 요청했다. 아래는
D-0049~D-0058을 결합한 최신 설계다. 기존 결정은 이력으로 보존하며 운영 v3는 변경하지 않는다.

1. 정답을 선택했어도 전체 근거의 선지 판단을 확인할 수 없으면 국소 명시 오류보다 확인 불가를
   우선하여 교정 없이 근거 미검증 정답으로 종료한다. 최종 재선택 정답에도 같은 게이트를 적용한다.
2. 교정 질문 대상은 해당 최초 응답에서 확인한 오류로 고정한다. 교정 답변의 새 오류는 질문
   목록에 추가하지 않고 누적 최종 평가에 반영한다. 최종적으로 남아 있으면 코칭 종료한다.
3. 앞 질문에 대한 답변에서 후속 대상 오류까지 실제 수정된 것이 확인되면 해당 예정 질문은 생략한다.
4. 최초 오답의 근거 보완 요청에서도 명시적 ‘근거 미제출’을 허용한다. 이를 선택하면 더 요구하지
   않고 확인 불가·상세 코칭·정답 공개 후 종료하며 재선택을 허용하지 않는다.

## 통합 원칙

- 발문 극성을 한 번 정규화하고 선택이 뜻하는 판정, 학생 발화, 근거의 파생 결론을 분리한다.
  UNKNOWN은 선택–근거 충돌이나 근거 타당 판정이 아니다.
- 기본은 근거 제출이고, 명시적 근거 미제출과 아무 제출 동작이 없는 대기는 다르다.
- 선택은 최대 2회다. 최초 오답의 실제 교정 성공에만 마지막 재선택을 제공한다.
- 교정에 진입한 한 응답에는 오류별 1회의 질문 기회를 둔다. 최초 정답/오답의 교정에 공통
  적용하며 별도 총수 상한은 없다. 질문 대상 N개 중 이미 수정한 것을 생략하므로 실제 질문은
  N개 이하다. 같은 오류의 실패에 재질문하지 않는다.
- 중간 성공/실패로 종료하지 않고 남은 최초 오류들을 순차적으로 다룬 뒤 누적 최종 평가한다.
  모든 관련 오류의 실제 수정이 확인돼야 성공이다. 새 오류도 최종적으로 남아 있으면 성공이 아니다.
- 교정 답변은 기존 오류 수정 여부로 평가한다. 과거 선택과 새 근거의 불일치를 새 실행 오류로
  만들지 않으며 학생이 말하지 않은 최종 결론을 교정 확인의 새 요구로 추가하지 않는다.
- 최초 정답의 교정 성공은 종료하며, 근거 충분성과 실제 오류 수정을 별도로 기록한다. 충분성
  미확인은 검증 정답으로 승격하지 않는다. 최종 재선택에는 추가 질문이 없다.
- 모든 정상 코칭 종료는 정답·해설 공개와 문항 종료를 포함하고 재선택이 없다. 공개된 정답을
  학생의 독립 해결·실제 수정 증거로 기록하지 않는다.
- 근거 없는 오답 선택은 감점 대상이지만 개발에서는 실제 포인트를 차감하지 않는다. 근거
  보완 제출이나 평가 재시도는 새로운 선지 선택으로 세지 않는다.
- 자료 누락·문항/정답 충돌·극성 정규화 불가·시스템 장애는 학생의 확인 불가와 분리한다.
  기존 자료 경계 및 평가 재개 정책을 유지하고 부정확한 정답을 강제로 공개하지 않는다.

## 명료화 상태와 구현 상태

이번 대화에서 제시한 학습 분기 명료화는 완료됐다. 이것은 자연어 판정의 실모델 정확성이나
미구현 상태 머신의 검증 완료를 뜻하지 않는다. Q-0028~Q-0030은 구현·회귀 검증을 위해 열린
상태로 유지한다. 포인트 실제 차감·운영 배포는 여전히 범위 밖이다.
