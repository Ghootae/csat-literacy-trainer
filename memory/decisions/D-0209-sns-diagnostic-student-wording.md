# SNS 진단평가 학생용 표현: 비틂 14종·관계 4갈래 이름과 한 줄 설명 확정, 기타 숨김, 바뀐 내용 문장은 한 번 생성·사람 손질

## 결정

확정본: `docs/review/sns-diagnostic-student-wording-draft-2026-11-06.md`(2판). 화면 인계 B는 이 문서의 이름·설명을 그대로 쓴다.

1. **비틂 14종.** 학생용 이름과 반말 한 줄 설명을 확정본 1절대로 쓴다. 기존 이름에서 바꾼 것은 6개다:
   `CONFLATION` 다른 두 가지를 같은 것으로, `WRONG_REASON` 상관없는 두 사실 잇기, `HOLDER_SWAP` 주장의 주인 바꾸기,
   `PAIR_SWAP` 두 대상의 특징 맞바꾸기, `ABSOLUTIZE` '모두·반드시'로 단정하기, `ADDED_METHOD` 글이 하지 않은 서술 방식.
2. **기타(`OTHER`).** 유형 이름을 보이지 않고 꼬리표는 "그 밖의 함정", 카드에는 바뀐 내용 문장만. "자주 걸린 함정" 집계에서 뺀다.
3. **관계 4갈래.** 대상 사이의 관계(내용)·주장과 근거(논증)·사람·이론 사이의 입장(관점)·글의 흐름(흐름). 화면 문장은 평가어 없이
   개수로 쓴다(예: "글의 흐름은 6곳 중 2곳을 잡았어", [D-0183](./D-0183-paragraph-analysis-ui-tree-and-relation-graphs.md)).
4. **말투.** 학생용 표현은 반말([D-0116](./D-0116-student-facing-tone-banmal.md)). 설명의 주어는 선지·글이고 학생 능력 평가는 쓰지 않는다.
5. **무너진 단계 다섯 개** 이름은 그대로 쓴다.
6. **"바뀐 내용" 문장.** 동결본 `twistDetail`(개발용 명사구)을 화면에 그대로 쓰지 않는다. 세트가 고정돼 있으므로 학생용 문장을
   한 번 생성하고 사람이 손본 뒤 세트 자료로 고정한다. 런타임 생성 단계는 두지 않는다. 세트 E 대상은 비틀린 선지 43개(조각 51개).
   생성은 외부 전송이라 범위를 따로 승인받는다.

## 근거

- 1판(해요체)에 대한 사용자 판정(2026-11-06): 말투가 D-0116과 다름, 정도 바꾸기·서술 방식 예 교체, "맞는 사실을 엉뚱한 이유로"는
  원인·근거 바꿔치기와 안 갈리므로 "상관없는 두 사실 잇기", 단정하기/범위 넓히기는 "말을 바꿈/대상을 넓힘"을 첫마디에,
  "내용끼리의 연결"은 뜻이 흐림, "놓친 곳이 많았어"는 평가어라 개수로, ★ 이름 4개 채택, 기타 숨기기 동의, 바뀐 내용은
  한 번 생성·직접 손질 추천.
- 2판에 사용자 "확정"(2026-11-06). 내용 갈래 이름은 사용자 후보 둘 중 코드 에이전트가 "대상 사이의 관계"를 골라 2판에 반영했다.
- 1판의 해요체는 코드 에이전트가 D-0116이 대체한 D-0110을 따른 오류다.
- 43개 집계: `docs/experiments/sns-diagnostic-gold-2026-11-05/choice-link/frozen/*.json`의 `twistType`이 있는 조각 51개, `truth: FALSE` 선지 43개.
  사용자 판정의 "약 60개"는 오답 선지 전체(16×4)로 보이며, "옳지 않은 것" 문항의 오답 선지는 맞는 말이라 바뀐 내용이 없다.

## 다시 볼 조건

실제 학생 사용에서 이름·설명을 잘못 읽는 사례가 반복될 때, 또는 비틂 목록·관계 목록이 바뀔 때.
