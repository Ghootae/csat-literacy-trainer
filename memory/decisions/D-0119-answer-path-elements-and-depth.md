# 정답 경로 요구 요소·추론 깊이 축 추가, 단순 채점 규칙 (실행 보류)

## 결정 (사용자, 2026-10-13)

- 문항 지도에 함정 태그 외에 **정답 쪽 분석**을 더한다: 요구 요소 어휘 E1~E10(함정 태그와 짝), 선지별 연산 사슬과 고리 수(추론 깊이).
- 문항 지도는 정확성보다 일관성이 목적이다. sol이 1회 생성해 동결하고, Claude·sol 일치 검토는 하지 않는다.
- 학생 채점은 추가 확인 질문 없이 한다. 정답이면 정답 선지 사슬 전체와 정답 경로 요구 요소를 성공으로 센다. 오답이면 잘못 판정한 선지 사슬에서 끊긴 고리 위치와 그 요소를 풀이 근거로 기록한다. 근거 없는 오답은 끊긴 위치를 관측 안 됨으로 둔다.
- 정답 지표(도달 깊이)와 오답 지표(끊김 위치 비율)는 섞지 않고 따로 집계한다.
- **실행은 보류**한다. 인계 문서는 아직 쓰지 않는다.

상세 정의: [`docs/review/answer-path-element-vocabulary-v0-2026-10-13.md`](../../docs/review/answer-path-element-vocabulary-v0-2026-10-13.md).

## 근거

- 함정 강도처럼 홀리스틱 판단은 LLM이 일관되게 하지 못했다([함정 지도 v0 결과](../checkpoints/2026-10-10-trap-map-v0-results.md)). 그래서 깊이는 "강도"가 아니라 연산 고리 수로 센다.
- 정답 문항도 진단 자료로 쓰고, 요소 단위 성공 횟수로 강점을 보고하기 위해서다.

## 알려진 대가

- 찍어 맞힌 정답도 성공으로 들어가 성공 쪽이 부풀려진다. 같은 규칙을 계속 적용하면 변화 추적에 영향이 작다고 보고 수용했다. 리포트에 한계를 적는다.
- 도달 깊이는 풀어 본 문항 구성에 좌우되므로 깊이 분모와 함께 보인다.

## 재개 시 첫 단계 (Claude 제안, 미승인)

6문항 문항 지도(요소·사슬)를 sol로 1회 생성·동결 → v0.1 사례 36개를 위 규칙으로 채점해 끊김 위치 판정이 정답지와 맞는지 확인.
