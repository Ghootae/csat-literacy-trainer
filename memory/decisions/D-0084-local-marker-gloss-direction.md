# 기호 지칭 부분에 한한 국소 해석본 방향 채택

## 결정

문제 풀이 판정기에서 기호(ⓐ, ㉠ 등)나 복잡한 도표·그림이 지칭하는 부분은 매 세션 모델이 새로
해석하지 않고, 문항마다 정답·발문 극성·모든 선지를 아는 상태에서 미리 만든 **기호 해석본**을
판정기 전용 입력으로 붙이는 방향을 채택한다. 이는 [D-0002](./D-0002-problem-source-direct-runtime.md)와
[D-0003](./D-0003-problem-gold-offline-only.md)를 **기호·도표 지칭 해석 범위에 한해** 부분 대체한다.
두 결정의 나머지(원문 직접 판정, 문항 전체 명제·선지 주장·추론 경로·대표 오답 경로의 런타임 미사용)는
그대로 유지한다.

해석본 범위는 기호 해석만이다(조건 gloss_markers). 선지별 해석·정오(조건 gloss_full)는 판정기에
넣지 않고 해석본 검증과 사람 확인에만 쓴다. 해석본은 기호마다 이름, 이 발화에서 가리키는 대상, 말한 사람,
절에 걸린 장치(부정·반문 등), 허용 읽기·오류 읽기 예, 원문 근거를 담고, 원문은 수정하지 않으며
원문 결속 해시로 원문 변경 시 사용을 막는다. 판정 이유에서 학생 판단은 학생 발화를 그대로 인용하고
평가자 판단과 분리해 쓰는 형식 규칙(quoteRule)을 함께 쓴다.

**운영 연결은 아직 하지 않는다.** 학생용 v3·개발자용 v4 판정기 코드·프롬프트·UI·서버는 바꾸지 않았다.
연결 전 조건은 아래 재검토 조건의 선행 과제로 둔다.

## 근거

- 사용자 결정(2026-10-06): 매 세션 안정된 해석을 보장할 수 없으니 정책을 수정해 문항별 국소 골드로 가고,
  정규화는 기호·복잡한 도표·그림 지칭처럼 꼭 필요한 부분만 한다. 이어 해석본 작성 방식(정답 패턴을 아는
  상태의 가장 자연스러운 해석, 해설은 참고용), 수정안 반영, 세 조건 비교와 인용 형식 실험을 승인했다.
- 사용자 요청: 이 결정을 기록으로 남긴다.
- 세 조건 비교(공손룡 12번, 응답 5유형×3회): 라벨 일치 none 13/15, gloss_markers 15/15, gloss_full 15/15.
  허용 읽기 "옷장에 있는 옷"(S5) 과잉 교정 none 2/3 → 해석본 조건 0/6. 대상 자리에 문장 뜻을 쓰는 실패
  none 3/15 → 해석본 조건 0/30. gloss_markers와 gloss_full의 의미 통과는 13/15로 같았다.
  Claude·GPT 조건 가림 판정이 45건 모두 일치했다.
- 같은 비교에서 해석본이 학생 표현을 해석본 표현으로 바꿔 학생에게 귀속하는 부작용 3/6(S5)을 만들었다.
  인용 형식 실험(S5, 조건당 8회)에서 quoteRule 추가 시 귀속 대체 4/8 → 0/8, SUPPORTED 유지는 두 조건
  7/8로 같았다. Claude·GPT 판정이 16건 모두 일치했다.

## 폐기한 대안

- 매 세션 실행 중 기호 해석 생성: 정책 변경 없이 가능하지만 같은 입력에서 해석이 흔들리는 것이
  반복 관측됐다(첫 평가 단계 역전 서술, "부재" 치환).
- 선지 해석까지 판정기에 넣기(gloss_full): 기호 해석만과 의미 통과 차이가 없고, D-0002가 폐기한
  선지 주장 골드에 더 가깝다.
- 원문에 해석을 괄호로 끼워 넣기: 판정기가 해석을 원문처럼 인용하고 원문 인용 검사가 깨진다.

## 재검토 조건

운영 연결 전에 다음을 확인한다. 하나라도 실패하면 이 결정의 운영 적용을 다시 연다.

- 다른 기호 문항(부정·대조·인용절 안의 기호, 같은 표면형이 여러 기호에 붙은 경우)에서도 해석본 조건이
  해석본 없음보다 과잉 교정·오독을 줄이고, 학생 표현 귀속 대체가 quoteRule로 억제되는가.
- 해석본이 있어도 남은 허용 읽기 과잉 교정(해석본 조건 누적 1/14)과 발문 극성 오적용(1/8) 대책.
  첫 판정과 질문 단계 판정이 엇갈리는 경우를 신호로 쓰는 방안을 포함한다.
- quoteRule을 질문 단계 reconstructedPath 등 학생 판단을 요약하는 다른 필드에도 적용할지.
- ⓒ 위치의 원 시험지 대조(해석본 상태 `USER_APPROVED_SOURCE_POSITION_UNVERIFIED`).
- 해석본 제작·검토 절차(누가 만들고 누가 승인하는지)와 도표·그림 지칭의 범위 정의.
