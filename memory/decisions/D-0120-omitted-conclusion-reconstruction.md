# 결론 문장이 없어도 사실에서 판정이 한 방향으로 나오면 재구성한다 (D-0054 보완)

## 결정

사용자 확정(2026-10-13, UI 메모장 16번).

v5 판정 지시문에 아래 경계 규칙을 넣는다.

> 학생이 결론을 쓰지 않았어도, 학생이 밝힌 사실이 선지의 핵심 전제(대상·조건)를 직접 다루고, 그 사실에서 선지의 참·거짓이 한 방향으로만 나오면 그 판정을 학생 근거의 결론으로 재구성한다. 결론 문장의 유무로 나누지 않는다. 사실이 선지의 핵심 전제에 닿지 않거나 두 방향이 모두 가능하면 확인 불가다.

- [D-0054](./D-0054-insufficient-wrong-rationale-exit-deferred.md)를 대체하지 않는다. D-0054가 이미 정한 "결론 문장의 유무로 기계적으로 나누지 않는다"를 지시문에 반영하고 경계를 구체화한다.
- 판정 방향이 없는 근거(예: "이익 잉여금이라는 말이 걸려요")는 지금처럼 확인 불가다.
- 감수할 점: 학생이 직접 쓰지 않은 연결을 판정기가 채워 교정 질문이 빗나갈 수 있다. 질문이 두 갈래·짧은 직접 질문이라(D-0118) 학생 답으로 바로잡을 수 있다고 본다.

## 보완: 선택을 결론으로 삼는 경계 (2026-10-13, 사용자 "R-I2 경계 확장 동의")

실모델 시험에서 사용자 사례 ②(R-I2)가 확인 불가로 남았다. 모델은 학생 사실이 선지의 핵심 전제(ⓐ의 적용 대상)에 닿지 않는다고 봤다. 그래서 아래 문장을 더한다.

> 학생이 밝힌 사실이 선지가 판단하는 상황(대상의 행동·조건)과 맞고, 학생의 선택이 그 사실에서 곧바로 나오는 판정과 같은 방향이면, 학생의 선택을 결론으로 삼아 재구성한다.

- 이 학생의 실제 오류는 말하지 않은 전제("ⓐ가 갑에게도 적용된다")이고, 결론을 붙였을 때 나온 질문이 그 지점을 짚었다.
- 상황에 대한 사실이 없는 근거(대조군, 예: "이익 잉여금이라는 말이 걸려요")는 이 문장의 대상이 아니다.
- 감수할 점: 판정기가 학생의 연결을 더 많이 짐작한다. R군·대조군 재시험으로 확인한다.
- 재시험(2026-10-13, `docs/experiments/v5-live-check-2026-10-13-r2/`)에서도 R-I2는 확인 불가였다(R 7/8, 대조군 변화 없음). 문구 수정 여부는 사용자 판단 대기.
- 2차(사용자 "진행"): 보완 문장을 "'그 사실 → 학생이 고른 판정'을 학생의 경로로 재구성하고, 연결이 원문상 맞는지는 재구성 단계에서 따지지 않는다"로 바꿨다. R-I2는 3/3 재구성됐으나 3/3 INSUFFICIENT로 질문은 나가지 않았다. 오류는 명시 주장 중 원문과 충돌한 것에서만 만든다는 규칙 때문이다. 대조군은 변화가 없다(`docs/experiments/v5-live-check-2026-10-13-r3/`).
- 정리(2026-10-13, 사용자 "권고안으로 확정"):
  - 넓힌 재구성 문장은 유지한다.
  - 학생이 사실만 쓰고 틀린 연결을 말하지 않은 근거(R-I2 유형)는 질문 없이 마지막 설명으로 끝낸다.
  - "명시 주장 중 원문과 충돌한 것에서만 오류를 만든다"는 규칙은 바꾸지 않는다. 판정기가 학생이 하지 않은 말로 오류를 만드는 것을 막기 위해서다.

## 근거

- 사용자 직접 사용(2026-10-13, 정보 비대칭 q13). 상세는 UI 메모장 "16번 상세".
  - ② "갑은 인공지능을 이용해 광고를 만들고, 이를 알리지 않았음."은 확인 불가였다. 같은 문장에 "그러므로 제재 대상"을 붙이면 교정 질문이 나왔다.
  - ③ "을은 규제 찬성, 다수는 규제 반대"는 확인 불가였다. "서로 부합하지 않음."을 붙이면 선택 확인 질문이 나왔다.
- 원인: 지시문의 "확인되지 않은 판단 내용은 복원하지 않는다"만 있고, D-0054의 "결론 문장 유무로 나누지 않는다"가 지시문에 없다.
- 사용자 판단: 실제 학생은 결론 앞까지만 쓸 가능성이 높다.
