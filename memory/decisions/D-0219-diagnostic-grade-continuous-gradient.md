# 진단 등급 띠: 실수 등급 축의 연속 그라데이션, 커서를 대면 그 등급의 확률, 큰 글씨는 최빈 정수 등급

## 결정

사용자(2026-11-10, "등급을 실수화 + interpolation을 이용해서 연속적인 gradation 형식으로. 바에 커서를 대면 확률이 확인되도록"). 질문 셋에 대한 답:

1. 실수 등급은 전국 백분위를 등급 경계(상위 4·11·23·40·60·77·89·96%) 사이에서 선형 보간해 만든다(예: 상위 7.5% → 2.5등급). 정수 부분은 기존 정수 등급과 같다.
2. 커서를 대면 그 지점이 속한 정수 등급의 확률을 보인다("2등급일 확률 42%")(안 가).
3. 큰 글씨는 확률이 가장 높은 정수 등급 그대로("2등급")(안 가).

## 구현 (코드 에이전트)

- `packages/pipeline/src/diagnostic-position/position.ts`: `continuousGradeOfPercentile`, 능력값 사후분포 격자를 실수 등급 축 90칸(등급마다 10칸)으로 모으고 가우스 커널(σ 1.5칸)로 펴서 `grade.density`(합 1)로 낸다. 두 선택과목은 산술 평균(D-0218과 같음). 펴기 때문에 등급별 합은 정수 등급 확률과 조금 다를 수 있다(시험 기준 0.1 안). 커서 숫자는 정수 등급 확률(`probabilities`)을 쓴다.
- 화면 `packages/app/src/client/diagnostic/Pages.tsx` `GradeBar`: `linear-gradient` 연속 띠(진하기 0.06~1, 최댓값 기준), 포인터를 대거나 누르면 말풍선.

## 근거

- 시험: 위치 계산 시험(보간 값, 칸 수·합·등급별 합), 화면 시험(그라데이션·말풍선), `npm test` 기존 실패 2건 외 통과. 화면 사진 `docs/review/diagnostic-passage-result-screens-2026-11-10/07-all-revealed-desktop.png`.

## 변경 (같은 날, 사용자 결정)

1. **실수 등급 계산 정정(코드 에이전트)**: 위 결정 1의 백분위 선형 보간은 띠가 울퉁불퉁했다(등급마다 원점수 폭이 달라 경계에서 꺾임). 원점수 → 실수 등급을 단조 3차 보간(PCHIP, 100점 1.0, 등급컷 k → k+1, 0점 → 10)으로 바꿨다(`continuousGradeOfRaw`, `pchip`). 그래도 완만한 물결이 남았다.
2. **띠는 9개 등급 확률로 칠한다(사용자, "띠를 9개 등급 확률 사이를 부드럽게 잇는 방식으로")**: 등급 칸 가운데의 진하기 = 그 등급 확률(최댓값 기준 0.06~1), 이웃 가운데 사이는 코사인 곡선으로 꺾임 없이 잇는다(`packages/app/src/client/diagnostic/logic.ts` `gradeGradient`). 커서 확률과 진하기가 정확히 맞는다. 위치 계산의 `grade.density`(실수 등급 축)는 화면에서 쓰지 않는다(API에는 남아 있음, 정리 여부는 미정).
3. **큰 글씨 아래 한 줄(사용자)**: "3등급일 확률이 35%로 가장 높아"(`gradeSentence`). 반올림한 퍼센트가 같은 등급이 더 있으면 "2등급과 3등급일 확률이 각각 34%로 가장 높아". 실수 범위 표기("2등급(1.6–2.5등급)")는 쓰지 않는다.
   - 근거: 세트 E 문항으로 계산하면 16문항을 다 풀어도 80% 범위가 약 2.3등급 폭(예: 12/16 정답 2.1–4.4), 10~30% 범위는 좁지만 확신도가 낮고, 범위 중심(중앙값)과 제목(최빈 등급)이 어긋나는 경우가 있다(예: 4/4 정답, 제목 1등급, 10% 범위 2.4–2.9). 계산 스크립트는 세션 임시 파일이었고 저장소에 두지 않았다.
   - 최빈 등급 확률은 지문 1개 뒤 약 30%, 16문항 뒤 약 40~45%로 낮게 읽힐 수 있다(사용 중 관찰 대상).
- 시험: 화면 vitest 30건, 위치 시험 통과, Playwright 진단 3건 통과(한 줄 문구 확인 추가). 화면 사진 `docs/review/diagnostic-passage-result-screens-2026-11-10/07-all-revealed-desktop.png`, `08-all-revealed-390.png`.
