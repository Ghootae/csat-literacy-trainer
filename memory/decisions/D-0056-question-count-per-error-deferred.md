# 한 응답의 교정 질문 수는 오류 수에 따르며 고정 상한을 두지 않는다

## 결정

교정 단계에 진입한 한 학생 응답에서 확인된 교정 대상 오류가 N개이면 오류별 1회씩 N개의
교정 질문을 순차 제시한다. 총 질문 수에 별도의 고정 상한을 두지 않는다. D-0055의 오류 2개
예시는 N개로 일반화하며, 당시 미정이었던 3개 이상 오류의 총 질문 상한 문제를 닫는다.

- 중간 성공·실패와 무관하게 해당 오류들을 순차적으로 다룬다.
- 질문 묶음 이후 누적 답변으로 관련 오류의 실제 수정 여부를 최종 평가한다.
- 최초 오답 경로는 모두 수정되면 재선택 1회, 실패·수정 확인 불가이면 상세 코칭 후 종료한다.
- ‘총수 상한 없음’은 오류 수에 비례한다는 뜻이다. 같은 오류에 성공할 때까지 질문을 반복하는
  정책으로 바꾸지 않는다.
- 게이트의 전체 확인 불가 종료, 마지막 재선택의 추가 질문 없는 종료 규칙은 유지한다.

## 범위와 상태

후속 확정: [D-0059](./D-0059-problem-feedback-clarifications-consolidated.md)에서 새 오류는 질문
목록에 추가하지 않고 최종 평가에 반영하며, 이미 수정된 대상의 질문은 생략하기로 했다.
따라서 고정된 최초 오류 수 N에 대해 실제 질문 수는 N개 이하다. 아래는 당시 미정 이력이다.

교정 질문 수의 고정 상한 문제만 확정했다. 교정 도중 새로 드러난 오류를 새로운 질문 대상으로
추가할지, 후속 대상까지 이미 수정한 경우 질문을 생략할지는 별도 경계로 남긴다. 교정 단계
진입 여부와 종료 분기를 이번 질문 수 원칙만으로 변경하지 않는다. 구현·운영 승격은 보류한다.
