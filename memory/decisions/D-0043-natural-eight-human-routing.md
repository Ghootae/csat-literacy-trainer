# 실제 응답 8건의 학생 경험 기준

2026-10-01 후속 정정은 [D-0044](./D-0044-natural-eight-acceptable-routes.md)에 있다. 아래는 최초 판정 이력이다.

사용자는 원문과 최초 응답8건을 보고 통과(N01/N24/N30/N38), 선택적 보완(N03/N08/N20),
질문 필요(N36)를 지정했다. 보완 초점은 속성·외연, 외부 도파민 통과 불가, 자본금 사용 조건이며
N36은 백신 부분 누락을 질문할 대상으로 지정했다. 기계 원라벨·메타 충족 여부를 지정한 것은 아니다.

이번에는 모델 결과를 숨겼으나 과거 노출도 있어 신규 독립 블라인드 검증이 아니다.
이8건 기준으로 후속 결과를 비교하며 D-0040 라우팅·운영은 자동 변경하지 않는다.
과거 V4 단회 라벨을 당시 정책상 해석하면6/8일치하나 새 구체 인정L1 측정은 아니다.

과거15건 검토에서는 N36 OK·비자동질문을 승인했고 이번에는 질문을 지정했다. 향후 이8건에서는
최신N36선택을 사용한다. 과거 자료·집계·다른14건을 소급 변경하지 않는다.
추가 유료 실험·프롬프트·코드·운영 변경의 승인이 아니다.
