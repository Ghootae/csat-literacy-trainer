# 요소 지표는 오답의 실패 분포만 보인다

## 결정 (사용자, 2026-10-14)

- 리포트의 요소 지표는 "요소가 기록된 오답이 어느 요소에서 끊겼나"의 분포로만 보인다. 분모는 요소가 기록된 오답 수다(예: "원인이 드러난 오답 8개 중 조건·범위 4 · 지시 대상 2").
- "사례 대응 4/6" 같은 요소별 성공·실패 비율은 리포트에 쓰지 않는다. 요소별 성공 횟수는 내부 기록으로만 남긴다.
- 요소별 실패율(실패 ÷ 그 요소가 실패 후보로 노출된 문항 수)은 문항 지도가 쌓이고 외부 선택률 기준(베이지안 아이디어)이 생기면 다시 검토한다.
- D-0119·D-0121의 채점 규칙(정답 = 정답 선지 노드·요소 전부 성공)은 바꾸지 않는다. 바뀌는 것은 누적 지표의 표시뿐이다.

정의: `docs/review/answer-path-element-vocabulary-v0-2026-10-13.md` "v0.1 개정 규칙 > 누적 지표".

## 근거

- 정답은 근거와 무관하게 정답 선지 요소를 통째로 성공으로 센다. 그래서 요소별 성공 횟수는 정답 수를 요소 출현 빈도로 나눠 다시 보여 준다. 발문 유지(E1)처럼 거의 모든 문항에 있는 요소일수록 정답 수와 같아진다. 사용자 지적(2026-10-14): 모든 문항이 같은 요소를 공유하면 요소 프로파일이 틀린 개수가 된다.
- 오답 하나는 요소 하나만 실패로 남긴다. 그래서 오답 수가 같아도 실패 요소의 분포는 학생마다 다르다. 학생 간 차이를 만드는 정보는 이 분포다. 정답 쪽 정보는 깊이별 정답과 꼬리표가 맡는다.
- 반영: 서윤 샘플 리포트(https://claude.ai/artifact/NzJgstQeGYcYHqTSvE3fe5, version 2)의 요소 표를 실패 분포 막대로 바꿨다.
