# 1차 생성 유지, 별도 2차 축 필터의 6문단 비교 구현

사용자가 1차 골드 프롬프트를 바꾸지 않고 2차 필터를 구현하여 민감한 6문단을 비교하도록 요청했다.
이 결정은 실험 구현 범위이며 운영 승격이나 기존 자산 덮어쓰기 승인이 아니다.

- 기존 gold-v2를 공통 출발점으로 재사용. 원본 생성 프롬프트·파일 보존.
- 학생 응답 없이 원문과 축을 받아 자연어 축의 최소 의미를 정제하는 별도 필터.
- 원본/필터 골드로 같은 응답과 같은 V4 평가기 비교. 상태 전이 코드도 변경하지 않음.
- 충분 답·경계 압축·주제 나열·명시적 오류 및 실제 공손룡 보완을 포함해 손실도 검토.
- 모든 필터·판정 원출력과 해시를 보존하며 한 묶음 안에서 프롬프트를 바꾸지 않음.

0호출 상태다. 명시 승인 후 재개한다. D-0005 생산 기준선·D-0013 운영 평가 정책은 유지한다.
재검토 조건: 필터가 핵심 조건을 지우거나 충분 답의 과도 보류가 개선되지 않으면 승격하지 않는다.

## 후속 실행 2026-09-20

사용자가 원문·축·고정 학생 답 및 필요 상세 관계를 OpenAI API terra로 전송하는 합계 USD 2
상한 실험을 명시 승인했다. [보고서](../../docs/experiments/axis-core-filter-six-2026-09-20/REPORT.md)에
따라 82요청, 49유효 평가+1계약 실패로 비교를 마쳤다. 공손룡에서 필터가 논쟁을 삭제하고
전문성·대표성을 남겨 보완 답을 SERIOUS로 보류했다. 현재 후보는 승격하지 않고 원본을 유지했다.
이것은 전체 2차 필터 접근의 영구 기각이나 새 프롬프트 수정 승인이 아니다.
