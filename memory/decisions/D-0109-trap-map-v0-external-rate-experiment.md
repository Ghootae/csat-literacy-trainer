# 함정 지도 v0와 외부 선지 선택 비율 대조 실험

## 결정

사고 추적기 구상([논의 기록](../../docs/review/inner-thought-inference-moat-discussion-2026-10-10.md), Q-0034)에서
가장 의심스러운 가정인 "LLM의 선지별 함정 분석을 믿을 수 있는가"를 학생 데이터 없이 먼저 확인한다.
기존 연결 문항 6개에 대해 LLM이 선지별 근거 위치·선지 거리·함정 태그·예상 선택 비율을 만들고,
메가스터디 공개 선지별 선택 비율과 대조한다. 실행은 Codex에 인계한다
([인계 문서](../../docs/handoffs/2026-10-10-trap-map-v0-external-rates.md)).

## 사용자 승인 (2026-10-10)

- 모델: `gpt-6.1-sol`, `gpt-6-luna`(reasoning effort medium), 문항당 3회 반복. 합계 약 36요청, 비용 상한 합계 3.5달러.
- 외부 전송: 6개 문항의 지문·발문·〈보기〉·선지·정답·공식 해설과 mRNA 그림을 OpenAI로 보낸다.
- 외부 자료: 메가스터디 「역대 정답률 & 난이도」의 해당 회차 선지별 선택 비율을 스크립트로 수집해 실험 폴더에만
  저장한다(내부 실험 전용, 제품 노출 없음, 원 HTML 미커밋). 이용 약관은 확인하지 않았다.

## 설계 경계

- 함정 지도는 분석층 자산이다. 대화 판정기의 런타임 입력으로 쓰지 않는다([D-0003](./D-0003-problem-gold-offline-only.md)과 같은 방향).
- 모델은 외부 선택 비율을 보지 않는다. 지시문에는 문항별 내용이나 예시를 넣지 않는다.
- 한계: Claude는 지시문 작성 전에 정보 비대칭 13번·표면 장력 16번의 실제 비율을 보았다. 지시문은 일반 정의만 담는다.
- 표본은 오답 선지 최대 24개다. 첫 신호 확인용이며 일반화 근거가 아니다.

## 재검토 조건

- 실험 결과가 우연 수준(최다 오답 적중 25% 근처)이면 LLM 함정 지도를 분석층 기본값으로 두는 방향을 재검토한다.
- 약관 확인 결과 수집·보관이 허용되지 않으면 저장한 수치를 삭제하고 대체 출처를 찾는다.
