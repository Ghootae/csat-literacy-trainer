# luna 기호 오독(Q-0030)은 고치지 않고 관찰로 남긴다

## 결정

- 정답 선택 판정기(luna)의 공손룡 12번 ⓓ 오독은 지금 대응하지 않고 관찰한다.
- 후보 ①(교정 질문 자동 검사)·②(교정 단계 sol)는 채택하지 않는다. ③(공손룡 ⓓ 해석 한 줄 입력)은 아래 조건이 올 때 D-0114·D-0167 2항 결정과 함께 검토한다.

## 근거

- 사용자(2026-11-03): "관찰로 남기기."
- 저장 기록 luna 출력 1665개(중복 제거) 집계: 확정 오독 6건, 모두 공손룡 ⓓ, 학생 노출 1건(10-22 S2-r3, 양자택일 질문 형식 때)(`docs/experiments/luna-marker-misread-count-2026-11-03/REPORT-desktop.md`).
- v5.8 표적 재현 20회: 판정 20/20 맞음, 내부 칸 오독 2/20, 학생 노출 0. 교정 질문은 D-0188 직접형이라 오독을 담지 않았다.
- 오독 세션 2개의 마지막 설명: 기호 오독 0/8 문단, 기호 없는 흔적·논리 비약 1문단(G2-r1 answer[1])(`docs/experiments/luna-marker-misread-count-2026-11-03/end-v58/`, opus 독립 판정 일치).
- ①은 막을 대상이 없고, ②는 오독이 첫 SELECTION 판정에서 생겨 효과가 없다.

## 다시 볼 조건
