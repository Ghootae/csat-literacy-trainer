# 깊은 문항 생성 방향 확정: 출제자 시뮬레이션 규칙 → 골드 지도 탐색 → 선별 → 〈보기〉 조립 → 독립 풀이 검증 API 파이프라인

## 결정

사용자 결정(2026-11-11). 기록은 2026-11-12.

1. 깊은 문항은 P1 방식(D-0230에서 중단) 대신 다음 API 파이프라인으로 만든다.
   1. 출제자 시뮬레이션으로 출제 규칙을 뽑는다.
   2. 골드 지도 탐색: 지문 명제 쌍에서 헷갈리는 인근 지점을 찾는다.
   3. 선별: 쓸 후보 진술을 고른다.
   4. 〈보기〉 조립: 〈보기〉와 선지를 만든다.
   5. 독립 풀이 검증: 다른 호출이 문항을 풀어 정답 일치·복수 정답·지문 밖 지식을 점검한다.
2. 사용자 판정: **promising**.
3. **계산 양식 규칙은 아직 후보다(확정 아님).** `docs/handoffs/2026-11-11-calculation-format-rules.md`의 규칙(21개 + API 비교에서 추가한 22번 "사례 건너뛰기 연결")은 이 결정으로 확정되지 않는다.

## 근거

- **법인 블라인드**(`docs/experiments/gold-search-api-2026-11-11/REVIEW-blind.md`): 웹 생성과 API 생성 사이에 품질 차이가 없었고, 모두 사용 가능하다고 판정했다. 그래서 스크립트화할 수 있는 API 경로를 택한다.
- **표면 장력 A/B 블라인드**(`docs/experiments/gold-search-api-surface-tension-2026-11-11/REVIEW-blind.md`, 정답·출처는 `KEY.md`·`KEY-web-notes.md`):
  - 사용자 순위: 라 > 다 > 가 > 나.
  - 라 = A-V2(개념 연결 규칙), 다 = B-V1·가 = B-V2(계산 양식 규칙), 나 = A-V1(개념 연결 규칙).
  - 라는 기출 16번보다 깊은 3단계 연결이다. 정답 선지 ⑤가 폐포 사례(계면 활성제 → 표면 장력↓ → 확장 쉬움)의 변수 방향을 잉크의 오네소르게 수 식에 옮기게 한다(표면 장력↓ → 오네소르게 수↑ → 상한 초과에서 더 멀어짐).
  - 네 문항 모두 풀이 답이 출제 정답과 같았고, 풀이자는 복수 정답·〈보기〉와 지문의 모순을 지적하지 않았다.
- **인문 6문항**(`docs/experiments/gold-search-api-batch2-2026-11-11/REVIEW-open.md`, 정답·출처는 `KEY.md`): 수정 후 실전 사용 가능, 상향 평준화(Ghootae 2026-11-12).
- 출제자 시뮬레이션 규칙 문서:
  - `docs/handoffs/2026-11-11-examiner-simulation-corporate-law-rules.md`
  - `docs/handoffs/2026-11-11-calculation-format-rules.md`(후보)
- 생성 절차의 원 결정: [D-0229](./D-0229-deep-bogi-item-generation-gold-map-search.md). P1 중단: [D-0230](./D-0230-p1-principle-application-generation-stopped.md).
