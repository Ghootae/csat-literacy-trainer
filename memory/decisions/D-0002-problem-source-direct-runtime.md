# 문제 풀이 전체 런타임을 원문 직접 방식으로 운영

## 결정

최초 판정, 진단·교정 질문, 후속 판정, 수정 확인, 재선택, 상세 코칭까지 문제 풀이의 모든
런타임 단계는 `SOURCE_DIRECT` 입력을 사용한다.

허용 입력은 완전한 원문, 문항·보기·선지, 정답, 공식 해설, 원자료 이미지와 누적 학생 발화다.
구조화 문제 골드의 명제, 선지 주장, 추론 경로, 대표 오답 경로는 입력하지 않는다.

## 근거

15문항·45응답 조합의 반복 비교에서 원문 직접 방식이 현행 정책 행동 일치, 오답 블라인드 품질,
진단 근거성, 지연과 비용에서 가장 나았다. 구조화 골드는 저정보 학생 발화에 없는 오류를
보충해 과잉 교정하는 경향을 보였다.

## 폐기한 대안

- 간결 문제 골드를 런타임 라우팅 입력으로 사용
- 상세 문제 골드를 런타임 라우팅과 피드백 입력으로 사용
- 최초 판정만 원문 직접으로 하고 후속 대화에서 구조화 골드 사용

## 재검토 조건

구조화 골드를 다시 런타임에 넣으려면 응답 수준별 독립 비교에서 원문 직접 방식보다 학생 발화
보존과 오류 진단이 개선되고, 별도 사용자 결정이 있어야 한다.
