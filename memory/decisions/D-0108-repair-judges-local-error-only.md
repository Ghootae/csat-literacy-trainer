# 교정 판정은 질문이 겨냥한 국소 오류만 본다

## 결정

사용자 원칙(2026-10-10):

1. 사용자의 머릿속에서 자신의 오류가 수정되었는지를 파악하는 것은 사용자 자신에게 맡긴다.
2. 시스템이 할 일은 국소적 오류를 수정하는 것이고, 판정은 이에 대한 것으로 국한한다.
3. 국소적 수정을 통해 전역적 오류가 내적으로 간파되고 수정될 것을 기대한다. 그에 대한 판단은 재선택 여부를 묻는 부분에서 사용자 스스로 수행한다
   ([D-0106](./D-0106-post-repair-choice-reselect-or-coaching.md)의 [다시 선택] / [코칭 보기]).

이에 따라 REPAIR 판정 규칙을 다음처럼 정한다.

| 경우 | 판정 |
|---|---|
| 교정 질문이 겨냥한 판단에 맞게 답함(짧거나 질문의 일부 칸만 답해도) | 고쳤음 |
| 답하면서 그 국소 오류를 다시 틀리게 말함 | 못 고쳤음 |
| 같은 답변 안에서 원래 오류 기록의 잘못된 판단을 다시 말함(질문이 묻지 않은 부분이어도) | 못 고쳤음(2026-10-10 사용자 결정 (가): 추측이 아니라 이번 답변에 명시된 말이다) |
| 내용 없는 답(동의만, 질문 반복) | 못 고쳤음 |
| 선택 불일치 질문에 불일치를 인정함("아니요") | 고쳤음(바로잡는 일은 재선택에서) |
| 다른 질문 차례의 오류까지 함께 고침 | 그 오류도 고쳤음, 질문 생략(현행 유지) |
| 정답 세션의 근거 충분성 | 기록만 한다(전역 판단, D-0104 후속 판단과 같음) |
| 답변 속 새 오류 | 기록만 하고 교정 성공 여부에는 반영하지 않는다. 종료 코칭이 짚을 수 있다 |

- [D-0059](./D-0059-problem-feedback-clarifications-consolidated.md)의 "모든 관련 오류의 실제 수정이 확인돼야 성공이다. 새 오류도 최종적으로 남아 있으면 성공이 아니다"를
  "질문한 국소 오류가 모두 고쳐지면 성공이다. 새 오류는 기록만 한다"로 바꾼다.
- 오류 기록(description)에 함께 적힌 결론이나 질문이 묻지 않은 부분, 학생의 처음 발화가 철회되지 않았다는 사실은 판정 근거로 쓰지 않는다.

## 근거

- [REPAIR 본 실행](../../docs/experiments/v5-repair-test-2026-10-10/repair-gpt-6-luna/RESULTS.json)(luna 183칸): 기대 일치 168/183, 미수정 답을 고쳤음으로 본 경우 0.
  어긋난 15칸은 모두 맞는 짧은 답·일부 칸 답을 못 고쳤음으로 본 경우였다(S2 "큰 경우요" 3/3, M2 "중성이 돼요" 3/3, M4 "낮은 pH에서 양전하를 띠어요" 3/3, 선택 불일치 "아니요" 4/9 등).
  luna의 이유는 "기존 오류의 다른 부분을 철회하지 않았다", "질문의 다른 칸을 답하지 않았다"였다. 탁상 점검에서 S2는 세 모델 모두 같은 판정.
- 원인: 판정 대상이 질문이 아니라 오류 기록 전체이고, 지시문의 엄격 문장("한 부분의 수정으로 다른 오류까지 해소됐다고 추정하지 않는다", "답변이 질문에 맞는다는 사실만으로 교정을 확정하지 않는다")이 짧은 정답에도 적용되며, 학생의 처음 틀린 발화가 누적 입력에 남아 있다.
- 새 오류 처리: 사용자가 Claude 권고 (가)에 동의("권고에 동의").

## 범위와 상태
