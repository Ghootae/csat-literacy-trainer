# "원문에 없음" 근거는 선지가 원문 사실로 반박되는지로 가른다 (D-0159·D-0161 보완)

## 결정

사용자 결정(2026-10-22, UI 메모장 36번). 사용자 규칙: "선지 A: x->y. 실제 x,y가 지문과 보기에 존재하고, 실제로는 x~->y. 이때는 '지문에 x는 없는
내용이에요' -> 근거 불충분 … 선지 B: x->y. 실제 x,y는 지문에 없는 내용(따라서 x->y 도 거짓). 이런 경우 '지문에 x에 없는 내용이에요' -> 충족."
있는 내용을 없다고 한 진술은 오류로 교정 질문(Claude (나)안, 사용자 "나에 동의").

- 선지가 원문·<보기>의 사실로 반박되지는 않고 뒷받침만 없는데(근거 없는 덧붙임), 학생이 그 덧붙인 내용을 짚어 "없다/근거 없다"고 했으면 그것이 핵심
  관계다. [D-0159](./D-0159-correct-unverified-judgment-method-note.md)의 판단 방식이 아니며, 원문이 대신 말하는 내용은 요구하지 않는다.
  [D-0161](./D-0161-supported-needs-key-relation-coverage.md) 조각은 '선지가 덧붙인 내용'과 '그 근거가 원문과 <보기>에 없음'으로 나눈다.
- 선지가 원문·<보기>의 사실로 반박되면(어긋나면), "없다"고만 한 근거는 지금처럼 판단 방식 부족(D-0159)이다.
- 학생이 없다고 한 대상·사실이 실제로 원문·<보기>에 있으면 CONTRADICTED 주장 → CONTENT 오류, 정답 선택이어도 교정 질문.
- 지시문(`source-direct-problem-feedback-v5.md`) 세 군데만 바꿨다. 서버·스키마·마지막 설명 지시문은 그대로다.

## 이유

- 세션 `7bf0eab0`(mRNA 19번 ⑤, 정답): "ph가 높아지면 소수성이 약해진다는 근거가 없음 → 5번 적절하지 않음"이 공식 해설의 핵심("근거가 없습니다")과
  같은데 판단 방식 부족으로 분류됐고, 마지막 설명이 그 방식을 짚은 뒤 같은 방식으로 정답을 설명했다([검토](../../docs/reports/REPORT-mrna-q19-session-review-2026-10-22-human.md)).
- Claude가 처음 낸 C안(원문이 실제로 말하는 내용까지 요구)은 같은 논리에 상황 설명만 더한 것이라는 사용자 지적으로 버렸다.

## 확인

  A형 0/2(둘 다 SUPPORTED로 넘어감), 회귀 5/6. 구분 문장을 "원문 사실로 반박되는가"로 바꾼 2차: A형 2/2 JUDGMENT_METHOD, B형 2/2 SUPPORTED, K1 3/3 SUPPORTED.
