# 단순 형식 v4.4를 운영 예정 형식으로 지정, V4 블라인드 비교 생략

## 결정

- 문단 요약 대화의 운영 예정 형식은 단순 형식 v4.4(프롬프트 `paragraph-simple-holistic-prompt-v4.4.md`, [D-0145](./D-0145-paragraph-simple-multi-gap-questions.md)와 보완 v4.1~v4.4)다.
- 운영 V4와의 블라인드 비교는 하지 않는다. [D-0139](./D-0139-paragraph-simple-format-question-rules.md)의 채택 조건(새 응답 검증 뒤 채택)을 사용자 판단으로 대체한다.
- 학생용 화면 전환은 아직 하지 않는다. 추가 검토 뒤 진행한다. 검토의 다음 단계는 다른 문단으로 시뮬레이션 일치도를 더 보는 것이다.

## 근거

사용자(2026-10-19): "V4.3을 운영 모델로 생각하고 있어. 굳이 테스트를 안해도 V4 보다는 낫다고 생각해. 그래서 굳이 블라인드 테스트를 할 필요는 없을 것 같아." 버전 확인에 "v4.4 맞아", 범위 확인에 "전환은 좀더 검토후에 진행할거야", "다른 문단을 대상으로 시뮬레이션과의 일치도를 좀더 검토해보는건 어떨까?"

참고 근거: 사용자 직접 사용 인상("지금까지 해왔던 많은 버전들 중에 가장 나은거 같은 인상"), 경로 시뮬레이션 일치 57→101·갈라짐 66→7([v4.4 결과](../../docs/experiments/simple-holistic-path-simulation-2026-10-17/runs/2026-10-19-v4.4/RESULTS.md)).

## 알려진 한계

- 조정에 쓴 문단은 공손룡 2와 도파민 4뿐이다. 시뮬레이션은 기대와의 일치도이며 질문의 교육적 질을 재지 않는다.
- 대화마다 핵심 부분 선택이 다를 수 있다(공손룡 40%, 도파민 21%가 다른 부분 포함).
- 판정 모델은 gpt-6-luna(환경 변수). 코드 기본값은 아직 테라다.
