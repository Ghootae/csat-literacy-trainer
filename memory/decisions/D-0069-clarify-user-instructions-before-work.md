# 작업 전에 불명확한 사용자 지시를 순차적으로 확인

## 사용자 지시

이 프로젝트(csat-literacy-problem-solving-mvp)에서 사용자의 작업 지시를 충분히 이해하지 못한 부분이 있다면 작업 수행 전에 다음 절차를 따른다.

1. 이해하지 못한 부분을 목록으로 출력한다.
2. 그 부분들을 하나씩 질문하고 사용자 답변을 기다린다.
3. 답변을 바탕으로 이해한 내용을 확인하고, 질문이 충분히 해소됐는지 점검한다. 불충분하면 추가 질문한다.

불명확한 부분을 임의로 가정해 실행하지 않는다. 질문이 충분히 해소된 뒤 작업을 시작한다.

## 적용

`AGENTS.md`에 동일한 절차를 추가해 이후 프로젝트 작업에도 적용한다. 이번 지시는 제품 판정 규칙·프롬프트의 변경이나 복구 실행 승인이 아니다.

## 근거

- 사용자 직접 지시(2026-10-02): 작업 전 불명확한 부분 목록 출력, 하나씩 질문, 사용자 답변으로 충분히 해소됐는지 확인.
- 적용 파일: `AGENTS.md`.
