# 개인 테스트 URL은 개발자용 화면만 안내

- 앞으로 사용자에게 개인 테스트용 UI 주소를 제시할 때는 `https://dialogue.cogaxis.net/dialogue/dev`만 안내한다.
- 학생용 `/dialogue` 주소는 사용자가 별도로 요청하지 않는 한 안내하지 않는다.
- 현재 UI 수정 범위도 개발자용 3단 화면으로 한정한다.
- 학생용 UI는 개발자용 UI가 확정된 뒤 별도 논의를 거쳐야 하며, 그전에는 수정하지 않는다.
- 이 결정은 사용자가 인증 없는 개발자 화면의 골드·내부 평가 공개 위험을 명시적으로 승인한 현재 개인 테스트 환경을 전제로 한다.

근거: 사용자 결정, `memory/checkpoints/2026-09-22-public-developer-mode-enabled.md`.

재검토: 학생용 UI 설계를 별도로 시작하거나 개발자 화면의 공개 방식을 인증 구조로 바꿀 때.
