# 사실은 맞지만 선지 판단 근거가 부족한 오답은 확인 불가·코칭 종료

## 결정

최초 오답에서 학생 문장이 명료하고 사실 자체도 맞지만, 제출 근거와 누적 맥락으로 해당 선지의
판단 경로를 확인할 수 없으면 확인 불가로 처리하고 상세 코칭 후 종료한다. 추가 진단 질문으로
연결을 캐묻지 않는다. 이는 D-0051·D-0053의 오답 분기를 명확화한 후속 설계 합의다.

- 다른 대상의 사실 등 무관한 근거뿐 아니라, 관련 사실이지만 선지 판단에는 불충분한 근거도 포함한다.
- 학생의 사고가 틀렸거나 비논리적이라고 단정하지 않고 제출 근거만으로 확인하기 어렵다고 안내한다.
- 학생이 표현하지 않은 연결을 모델이 만들어 오류를 확정하지 않는다. 코칭은 원문의 판단 관계를 설명한다.
- 잘못된 연결 자체가 발화·누적 맥락에서 확인되면 단순한 연결 부재와 구별한다. 전체 판단 경로를
  확인할 수 있고 오류가 명확한 경우에는 기존 교정 질문 경로를 유지한다.
- 반대로 전체 결론 확인 불가인데 일부 명제만 틀린 경우는 D-0053에 따라 확인 불가가 우선한다.
- 특정 접속어나 결론 문장의 유무로 기계적으로 나누지 않는다. 문맥상 안정적인 생략 표현은
  해석할 수 있지만 확인되지 않은 판단 내용을 보충하지 않는 기존 원칙을 유지한다.

## 범위

분기 감사 C 중 ‘명료하고 참이지만 선지 판단에 불충분한 최초 오답’의 처리만 설계상 해결됐다.
충분하고 타당한 근거와 공식 정답이 충돌하는 문항 경계, D-0053의 정답 분기 적용 범위,
교정 성공 범위 및 입력·종료 예외까지 해결됐다는 의미가 아니다. 구현·검증은 계속 보류한다.
