# 원문 내 기호 범위 직접 표시 시험 승인

사용자는 해결 후보1인 원문 안 기호 범위 직접 표시를 먼저 시험하고 자료 외부 전송을
일괄 승인했다. 이번 공손룡 원래 v3·동일 역전 응답 비교에 적용한다. 다른 자료나 목적의
무제한 전송 승인으로 확대하지 않는다.

control은 검증된 별도 기호 범위 정보, inline은 그 정보를 유지한 채 원문을
`〈ⓓ〉옷〈/ⓓ〉`처럼 표시한다. 단어 뜻이나 정답 해석을 새로 추가하지 않는다.
v3 프롬프트·모델·판정 구조를 고정하고 각3반복, 교정 질문 포함 최대12요청·추정2달러.
기호별 의미 해석 표나 별도 모순 판정기는 이번 시험에 추가하지 않는다.
제품/UI·운영 정책·실행 서버의 전환 승인은 아니다.
