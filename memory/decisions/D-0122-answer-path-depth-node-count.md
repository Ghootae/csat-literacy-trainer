# 정답 경로 깊이 = 선지 노드 수

## 결정 (사용자, 2026-10-13)

- 깊이 지표를 층수에서 **선지 판정에 필요한 노드 수**(`READ`+`LINK`+`APPLY`)로 바꾼다. "근거를 몇 개 찾고 몇 번 이어야 하나"를 나타낸다.
- 층(의존 관계)은 문항 지도 구조로 남기되 리포트 지표로 쓰지 않는다.
- D-0121의 나머지(노드 종류·필요 노드만·오답=실패 종류·정답 꼬리표·오답 분모·재채점 일관성)는 유지한다.

## 근거

- [파일럿 2차](../checkpoints/2026-10-13-answer-path-depth-pilot-v2-results.md): 10개 선지 중 9개가 3층, 1개가 4층으로 수렴. 노드 수는 3~7로 차이가 났다(표면장력 정답 ③ 3, 정보 비대칭 정답 ⑤ 5, 정보 비대칭 ①②④ 7).
- 층수는 오답 끊김 위치(%)의 순서 의존 문제를 풀려고 도입했으나, 그 지표는 D-0121에서 폐지돼 층수의 필요가 사라졌다. 노드 수는 배열 순서와 무관하다.

## 한계

- 노드 분할 규칙의 문항 간 일관성(같은 종류 연산을 같은 단위로 쪼개는가)은 2문항에서만 확인했다.
