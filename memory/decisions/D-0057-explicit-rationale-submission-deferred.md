# 근거 미제출 선택과 아직 제출하지 않은 상태를 구분

## 결정

학생이 ‘근거 미제출’ 또는 ‘근거 입력 후 제출’을 명시적으로 선택하는 입력 구조를 사용한다.
아무것도 제출하지 않은 상태와 근거를 생략하고 제출한 상태를 구분한다.

- 근거 미제출 선택: 제출 행위가 완료된 것으로 처리하며 해당 단계의 근거 없는 응답 분기로 간다.
- 근거 입력 후 제출: 입력된 발화를 근거로 평가한다.
- 어느 제출 동작도 하지 않음: 입력 대기로 유지한다. 자동으로 교정 실패나 종료로 기록하지 않는다.
- 최초 오답의 근거 확인 단계에서 ‘모르겠어요’, ‘찍었어요’처럼 판단 근거를 확인할 수 없는
  답변을 제출하면 확인 불가로 처리하고 상세 코칭 후 종료한다.
- 위 문구는 예시이며, 실제로 추가 근거가 포함된 답변까지 문자열만 보고 일괄 분류하지 않는다.

## 기존 분기와의 관계

후속 확정: [D-0059](./D-0059-problem-feedback-clarifications-consolidated.md)에서 최초 오답의 근거
보완 요청에도 미제출 선택을 허용하고, 선택 시 반복 요구 없이 확인 불가·코칭·정답 공개 후 종료하기로
했다. 아래의 해당 미정 표현은 당시 이력이며 더 이상 미정이 아니다.

D-0051의 최초 선택에서 근거를 생략한 정답은 미검증 정답 종료, 최초 오답은 오답·감점 대상
안내 후 근거 요구, 마지막 재선택 오답은 추가 근거 요구 없이 코칭 종료하는 구분을 유지한다.
명시적 ‘근거 미제출’ 선택 자체를 ‘아무것도 제출하지 않음’으로 잘못 처리하지 않는다.

이번 결정만으로 교정 질문 묶음 중 한 답변이 ‘모르겠다’인 경우의 중간 종료를 새로 허용하지
않는다. D-0055·D-0056의 중간 성공/실패 무관 순차 진행과 누적 최종 판정은 유지한다.
최초 오답 뒤 근거 보완 요청에서도 다시 미제출을 선택할 수 있게 할지와 그 후속 처리는 별도
확정 대상이다. 입력 구조 합의를 최초 오답 근거 요구 규칙의 삭제로 확대하지 않는다.

## 구현 상태

후속 설계만 기록했다. UI·코드·프롬프트·포인트·운영 설정은 변경하지 않는다.
