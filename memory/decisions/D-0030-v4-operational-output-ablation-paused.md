# 운영 V4를 유지하고 출력 필드 절삭 연구를 보류

사용자는 문단 요약 평가기의 운영 기본값을 현재 V4로 유지하고, 지금까지 수행한 최소 출력·필드 절삭 실험 결과를 연구 자료로 보존하기로 결정했다.

- 학생용 운영 평가기와 계약은 현재 V4를 그대로 사용한다.
- V4-light, S1, S2, S3, 짧은 계획 A, 압축 원장 B1은 운영에 승격하지 않는다.
- 제안만 된 B2 유료 시험과 추가 필드 절삭은 실행하지 않고 보류한다.
- 실험 보고서·원출력·비용·지연·판정 변동·사람 승인 자료는 삭제하거나 성공 사례로 재해석하지 않고 그대로 보존한다.
- S1·S2의 약 9~12% 비용 감소는 관측값이지만 반복 안정성이 확정되지 않았으므로 운영 절감치로 간주하지 않는다.
- A·B1의 추가 절감은 약 1~2% 수준이었고 검증·구현 부담에 비해 제품 실익이 입증되지 않았다.
- 다음 우선순위는 실제 학생 관점의 사용성·학습 흐름 검증과 지문·문항 세트 확장이다.
- 출력 최적화는 V4의 비용이나 체감 대기 시간이 실제 사용을 방해한다는 관측이 생길 때만 재개한다. 재개 시 필드 삭제 자체보다 판정·질문·화면 표시 중 실제 대기 구간과 목표 지연을 먼저 측정한다.
- N03의 정확 인용 문장부호 문제는 출력 절삭과 별개의 계약 문제로 남기며, 이번 보류 결정으로 닫지 않는다.
