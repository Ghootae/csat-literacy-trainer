# 보여 주기 개발자 모드: 질문·피드백 반말

## 결정

- 개발자 모드 `v4-boundary-show`에서 생성되는 질문과 피드백 문장을 반말로 바꾼다. 문제 풀이 화면과 같은 친근한 반말이다([D-0134](./D-0134-boundary-show-dev-mode-central-object.md) 보여 주기 화면 말투와 같음).
- 방법: 이 모드 전용 피드백 프롬프트 변형(현재 `packages/pipeline/experiments/dialogue/selective-feedback-prompt-v4.md` 기반)을 둔다. 말투 외 질문 내용 지침은 바꾸지 않는다. 운영 V4 프롬프트는 그대로다.
- 이 모드에서 보이는 코드 고정 존댓말 문구도 반말로 맞춘다(예: `two-stage-evaluator.ts`의 "이번 문단의 질문은 여기까지입니다…", `schema.ts`의 `PASS_STUDENT_FEEDBACK` "핵심 논리를 잘 파악했습니다."). 운영 경로에서 공유하는 문구는 운영에서 바뀌지 않게 모드별로 나눈다.
- 개발자 모드 시험에서 괜찮으면 같은 버전을 운영에도 적용한다. 운영 반영은 시험 결과를 보고 별도 승인한다.

## 근거

- 사용자 명시(2026-10-15): "질문 말투는 반말로 바꾸자", "개발자 모드에서 실험을 해서 괜찮다면 똑같은 버전으로 운영할거야", 피드백 문장도 "함께 바꾸자".
- 계기: 첫 사용 피드백 6번(`docs/review/boundary-show-dev-ui-feedback-2026-10-15/README.md`), 오류 응답의 피드백·질문이 존댓말이라 보여 주기 화면의 반말과 섞였다.

## 확인할 점

말투만 바꿔도 생성 질문의 내용·초점이 달라질 수 있다. 개발자 모드 시험에서 질문 내용이 존댓말 버전과 같은 수준인지 함께 본다.

## 포함하지 않는 것

운영 V4 프롬프트·운영 화면 변경(시험 후 별도 승인), 게이트 프롬프트 변경.
