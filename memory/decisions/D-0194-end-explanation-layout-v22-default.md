# 마지막 설명 기본값을 layout v2.2(문단 목록 + 칠할 곳)로 바꾸고 실제 생성에 연결한다

## 결정

- 문제 풀이 마지막 설명(M4)의 기본 레이아웃은 `layout-v2`다. 모델은 칸마다 문단 목록 `{text, mark}`를 내고, 서버(`arrangeEndParagraphs`)가 짧은 마지막 문단 합치기, 문장 단위 칠하기, 같은 칸 안의 겹친 칠하기 지우기를 한다. 화면은 D-0193 방식이다.
- 지시문은 v2.2 실험 글(`instructions-v2.txt`, sha `12d686b9…`)에 메모 42번 asked 문장 하나를 v1과 같은 자리에 더한 것이다(사용자 승인 2026-11-02).
- 문단 속 ‘…’ 인용이 선지·원문에 없으면 재시도한다. 마지막 시도에서도 인용 문제만 남으면 그 따옴표만 벗기고 통과시킨다(`QUOTE_STRIPPED` 기록).
- `layout-v1`·`v5.3`과 그 형식으로 저장된 세션은 칸당 말풍선 하나로 계속 보인다.
