# 선지 연결 좌표를 마지막 설명에만 넣는 비교 실험

## 결정

1. 선지 연결 골드(D-0162, `docs/experiments/choice-link-2026-10-22/runs/ui-v5/frozen/`)의 첫 쓰임은 **피드백 비교 실험**으로 한다. 오프라인 진단(학생별 비틂 통계)은 실제 학생 답안이 생길 때 한다. D-0162 2항의 "오프라인 먼저" 순서를 이 결정으로 바꾼다. 운영 런타임은 바꾸지 않는다(D-0002 유지).
2. 좌표는 **v5 마지막 설명(END_EXPLANATION, 오답 종료)에만** 넣는다. 첫 판정과 교정 질문에는 넣지 않는다. 교정 질문은 첫 판정과 같은 호출에서 만들어져 판정 입력이 바뀌고, 학생 생각 단정이나 다시 고르기 전 정답 노출 위험이 있다.
3. 비교 방식: 지난 회귀 시험의 오답 종료 30세션(6문항 × A1·A3·B1·B2·B3)의 마지막 설명 요청을 그대로 다시 보낸다(기존 조건). 같은 요청에 좌표와 사용 규칙을 더한 것을 함께 보낸다(좌표 조건). 앞 대화는 고정이라 차이는 좌표에서만 생긴다.
4. 판정: 쌍마다 X·Y를 무작위로 붙인다(열쇠 파일 분리). Claude가 블라인드로 판정한다. 기준은 ① 원문 정확성 ② 선지의 비튼 지점 짚기 ③ 학생 생각 단정 없음 ④ 형식이다. ①③④는 안전 기준, ②는 기대 효과다. 6쌍은 사용자가 Claude 판정을 보지 않고 판정해 맞춰 본다.
5. 결과에 따른 판단: 좌표 조건이 낫고 안전 기준을 지키면 운영 반영을 검토한다. 비슷하면 v5를 유지한다. 단정이나 원문 오류가 생기면 규칙을 고쳐 재시험하거나 접는다.

## 근거

- 사용자(2026-10-23): A안·B안 차이 설명 뒤 "B안으로 테스트". 질문 단계와 마지막 설명 단계 비교 예시 뒤 "A안으로 동의"(마지막 설명에만). 가상 피드백 예시 확인 뒤 비교 대상 정리("v5랑 지금 실험하려고 하는 것과의 출력의 퀄리티를 비교한다는거구나"), "오케이 다음 스텝으로 진행 승인".
- v5 실제 기록(회귀 시험 S-A1·S-A2): 교정 질문은 좌표 없이도 비튼 지점을 이미 겨냥했다. 그래서 질문 단계는 이득이 작고 위험이 크다고 봤다.
- UI 6문항 중 5개가 "적절하지 않은 것" 문항이라, 학생이 고른 오답은 맞는 선지다. 좌표는 고른 선지의 근거 명제와 정답 선지의 비틂 양쪽을 준다.

## 오프라인 진단 기록 규칙 메모 (사용자 정리, 2026-10-23)

선택 하나는 고른 선지와 정답 선지 두 곳의 정보를 준다.

| 발문 | 결과 | 기록 |
|---|---|---|
| 틀린 것 고르기 | 정답 | 정답 선지의 비틂을 알아봄 |
| 틀린 것 고르기 | 오답(맞는 선지 고름) | 정답 선지의 비틂을 놓침 + 고른 선지의 근거 명제를 확인하지 못함 |
| 맞는 것 고르기 | 정답 | 정답 선지의 근거 명제·관계를 바르게 확인함 |
| 맞는 것 고르기 | 오답(틀린 선지 고름) | 고른 선지의 비틂에 속음 + 정답 선지의 근거 명제를 확인하지 못함 |

선택만으로는 약한 증거다. "알아봄·확인함"은 v5가 판정한 학생 근거가 있을 때 확정한다. 고르지 않은 나머지 선지는 기록하지 않는다.

## 재검토 조건

## 보완 1: 정답·근거 약함 세션 추가 (2026-10-23)

사용자 "정답, 근거 약함도 지도를 넣는 것으로 하자." 표본에 정답·근거 미확인 12세션(CT·CP)을 더해 42세션으로 한다. 모델은 운영 규칙 그대로다(오답 마지막 설명 sol, 정답 쪽 luna). 정답 세션에서는 좌표를 answer 칸의 빠진 연결을 채우는 데 쓰고, 학생이 비틂을 알아봤거나 놓쳤다고 단정하지 않는다. 사용자 확인 6쌍 중 1쌍은 정답 세션(G-CT)이다.

## 결과 (2026-10-23)

- 실행: LINK 41/42(I-B3 503), $0.578. 단정 0, 원문 오류 1(S-CP LINK luna "점도에 비례").
- 사용자 41쌍 블라인드 판정("이해가 잘 되는가"): LINK 20·BASE 18·비슷 3, 위치 쏠림 없음. Claude 블라인드(LINK 35·BASE 1·비슷 5)와 일치 20/41, 우연 수준.
- 5항에 따라 **좌표는 운영 v5 마지막 설명에 넣지 않는다.** 선지 연결 골드는 오프라인 자료(D-0162)로 남는다.
- 사용자 판정 이유는 좌표와 무관한 서술 품질(문단 나눔, 결론 닫기, 간결함, 시작 방식)이 대부분이었다. 마지막 설명 이해 용이성 규칙은 별도 과제 후보다. 이해 용이성은 Claude 블라인드 판정으로 대신하지 않는다.
