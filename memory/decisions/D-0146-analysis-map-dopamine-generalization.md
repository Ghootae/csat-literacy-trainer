# 분석 지도 일반화 확인: 도파민 지문

## 결정

공손룡 파일럿 기준선([D-0143](./D-0143-analysis-map-gongsun-pilot.md): 지도 생성 프롬프트, 입장 표시, 판정 v3, 오류 집계)이 성격이 다른 지문에서도 품질을 유지하는지 도파민 지문(`dopamine-motor-control`, 4문단)으로 확인한다. 공손룡 지시문을 도파민에 맞춰 고치지 않는다. 기준에 못 미치면 그 자체를 결과로 보고 원인을 따진다.

- **단계와 확인 지점.** ① 지도 sol 3회 → Claude 비교·권고 → 사용자 동결 선택. ② 입장 표시 sol 1회 → Claude 원문 대조 → 사용자 확정. ③ 시험 응답 정답표(Claude 작성) → 사용자 확인. ④ 판정 v3 luna 1회 → 기준표 채점.
- **통과 기준(사전 확정).**
  - ① 3회 모두 구조 검증 6항목 통과, 문단 요지와 문단 안 큰 묶음이 3회 중 2회 이상 같음.
  - ② 검증 3항목 통과, 사람 수정이 명제의 10% 이하.
  - ③ 원문 복사 대조군 모순 0·직접 충족 85% 이상, 심은 오류 80% 이상 ✕ 검출, 정상 응답 오류 사건 중 오탐 25% 이하.
- **응답 재료.** 원문 복사 4(코드 생성), Claude가 쓴 일부러 틀린 응답 8(문단당 2, 틀린 곳 약 12, 정답표 판정 전 확정), 기존 V4 도파민 대화 기록(약 10). 오탐 비율이 기준 근처면 응답을 늘린다.
- **스크립트 일반화.** 공손룡 전용 스크립트를 지문 ID·실험 폴더를 바꿔 끼울 수 있게 고친다. 옵션 없이 실행하면 공손룡 동작은 그대로.
- **외부 전송 승인.** ① 도파민 원문만, `gpt-6.1-sol` medium 3회, 재시도 없음, $2. ② 원문·동결 지도 명제, sol 1회, $0.5. ④ 도파민 V4 대화·시험 응답·원문 복사·동결 지도와 입장, `gpt-6-luna` medium 1회, 요청 1,000·실제 청구 $0.5. 각 단계는 앞 단계 확인 뒤에만 보낸다.
