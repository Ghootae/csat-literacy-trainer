# 원문 표시와 기호 해석 표를 결합한 두 방식 시험

사용자는 후보1 원문 내 표시와 후보2 기호별 해석을 함께 시험하도록 요청했고, 같은 호출과
별도 호출 두 방식 모두를 선택했다. 앞서 같은 문제 논의의 자료 외부 전송을 일괄 승인했다.
공손룡 원래 v3 기반·같은 가상 역전 응답의 오프라인 실험에 한정한다.

세 조건은 직접 표시만, 한 호출 안에서 해석 표→평가 출력, 학생 응답 없는 별도 해석 표 호출→평가다.
각3반복·교정 질문 포함 최대21요청·과거 단가 추정3달러, 모델 gpt-5.6-terra/medium을 유지한다.
별도 해석 입력에도 동일 원문·문항·정답/제공 해설이 있다. 학생 응답만 없으며 해설 블라인드는 아니다.
처치 두 조건은 최초 해석 표를 다음 질문 호출에서 재사용한다. 해석 표는 기호 문자열·인접 절 인용·
문장 속 역할·의미·불확실성을 출력하고 의미 정답을 새 프롬프트에 넣지 않는다.

표를 모델이 원문에서 매회 생성하는 실험이며 사전 의미 골드의 제품 재도입 승인이 아니다.
D-0002 운영 원문 직접 원칙을 유지하고 생산 프롬프트/코드/UI/서버는 바꾸지 않는다.
후보3 별도 모순 검사기는 추가하지 않는다. 기대 의미는 동결 기록에만 있고 모델 입력에는 없다.

근거: 사용자 ‘1+2 같이 테스트’, ‘둘다 테스트해보자’, 앞선 자료 외부 전송 일괄 승인,
`scripts/test-gongsun-interpretation-modes.mjs`,
`docs/experiments/gongsun-interpretation-modes-2026-10-03/FROZEN.json`, `mapping-input.json`, `prompts.json`.
