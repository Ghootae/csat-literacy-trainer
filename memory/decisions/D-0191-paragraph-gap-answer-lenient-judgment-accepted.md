# 문단 빈 곳 답: 질문 전제를 이어받은 답과 덜 말한 답을 충족으로 치는 현재 판정을 받아들인다

## 결정

사용자 판정(2026-10-30), `/dialogue/lab` 학생 역할 시뮬레이션(판정 지시문 v4.8) 검토 기준.

1. 빈 곳 질문이 원인 같은 전제를 주고 학생이 빠진 결과를 자기 말로 말한 답은 충족으로 친다. 판정기가 질문과 답을 합쳐 읽는 현재 동작(`targetGapReadings`)을 유지한다. 예: "생성형 인공지능의 활용은 온라인 광고 환경에 어떤 변화를 가져왔어?" → "가짜 광고가 많아졌어".
2. 원문 정리 문장 수준으로 말하고 구체 쟁점을 덜 말한 답, 요건 일부만 말한 답도 충족으로 치는 현재 판정을 받아들인다. 빠진 내용은 마무리 핵심 상자가 공개한다. 예: 정보 비대칭 2문단 "개입해야 된다는 쪽이랑 하면 안 된다는 쪽"(원문 "정부 개입에 관하여 엇갈리는 주장"), 법인 2문단 "관할 기관 허가."
3. 이 결정은 판정 쪽만 너그럽게 둔다. 빈 곳 질문에 관계 요소를 넣지 않는 v4.9 질문 규칙 6(D-0186의 질문 흘림 대응)은 유지한다. 사용자: "과도하게 힌트를 주는 것도 문제 없다고 봄" → 범위는 이번 사례 유형에 한정(메인 세션 권고 채택).
4. 같은 검토에서 교정 질문 중 정답 문장 힌트 강조도 문제로 올라왔으나, [D-0175](./D-0175-paragraph-simple-correction-hint-during-question.md)를 그대로 유지한다("기존 규칙 그대로 두기"). 새 결정 아님.
