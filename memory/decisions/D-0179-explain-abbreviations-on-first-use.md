# 보고 속 약어는 첫 사용에 설명을 붙인다

## 결정

사용자 결정(2026-10-27): "이런 약어에는 설명을 붙이는 것을 규칙으로 기록(한 보고 내에서 약어의 첫번째 사용에만 설명 붙이기)."

- 보고(채팅 답, 보고서 파일, 체크포인트·결정 기록처럼 사용자가 읽는 글)에서 변경 단위·사례·조건 약어(예: P4, E2, K4, KC, S-CT,
  D-0161)를 쓸 때, 그 보고 안에서 처음 나올 때만 짧은 설명을 붙인다. 예: "P4(틀린 지점은 선지 문장에 쓰인 주장만)".
- 같은 보고 안의 두 번째 사용부터는 약어만 쓴다.
- 보고가 바뀌면(새 답, 새 파일) 다시 첫 사용으로 본다.

## 이유

- 2026-10-27 v5.2 정리 답에서 "P4"를 설명 없이 써서 사용자가 "P4가 뭐야?"라고 다시 물었다.
- 약어는 기록 안에서 정의되어도 사용자가 세션을 건너 기억하기 어렵다. 갈래 이름에 부 명칭을 붙이는 기존 습관과 같은 목적이다.
