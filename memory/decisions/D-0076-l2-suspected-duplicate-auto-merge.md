# L2 중복 의심 그룹은 추가 확인 없이 자동 병합

## 사용자 결정

사용자는 ‘일단 L2 유사성이 의심되면 과감하게 자동으로 합치는 걸로 하자. 항상 피해야 하는 건 fa rather than miss’라고 결정했다. 원문 분할 골드 후보의 다음 시험에는 L2 탐지가 반환한 중복 의심 그룹을 그대로 자동 병합한다.

## 규칙

1. 기존 후보 생성·JEV 선택·평균1·2위 차이≤0.1의 적은 축 우선·별도 L2 생성은 유지한다.
2. L2 중복 의심 탐지가 인접 축 그룹을 출력하면 해당 그룹을 자동 병합한다.
3. L1·원문으로 병합의 의미적 타당성을 다시 승인·거절하는 API 단계는 제거한다. 별도 감사기 거부로 병합을 취소하지 않는다.
4. 병합 경계와 일치하는 기존 후보가 있으면 선택하고, 없으면 해당 구간의 병합 L1을 생성한다. 변경된 L1에 대응하는 L2를 다시 생성한다.
5. 축 삭제는 이번 결정에 포함하지 않는다. ID·인접성·원문 복원 등 기계적 계약은 유지한다.

‘의심’은 현재 탐지 출력의 그룹을 뜻하며 새로운 수치 유사도 임계값을 발명하지 않는다. FA/miss의 사건별 공식 정의·효과 측정은 이번에 추가하지 않았다. 별도 반복 탐지/병합 루프도 새로 승인된 것으로 추론하지 않는다.

## 적용 범위와 계보

다음 원문 분할 후보 시험의 규칙이다. D-0071/D-0075의 기존 시험은 확인 단계를 포함한 실행 기록으로 보존한다. 그 단계는 사용자에게 기존의 기계적 병합 의도와 다른 구현이었다고 설명했다. 이 결정은 현재 UI 자산·학생 판정기·기존 실험 결과를 소급 변경하지 않는다. 새로운 시험이나 API 호출은 이번 작업에서 실행하지 않았고, 시험 스크립트 코드는 아직 변경하지 않았다.
