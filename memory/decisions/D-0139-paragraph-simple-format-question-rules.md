# 문단 질문 생성: 축 근거 대신 단순 형식과 질문 작성 규칙

## 결정

- 문단 요약 다음 설계 후보는 단순 형식으로 한다. 문단과 학생 응답만으로 전체 판정을 하고, 부족하면 질문 하나를 쓴다. 질문 생성에 축을 근거로 쓰지 않는다([D-0103](./D-0103-holistic-verdict-axis-recording-direction.md)의 "질문 생성은 축 근거"를 대체한다).
- "가장 큰 구멍"은 빠진 세부가 아니라 문단 전체 관계에서 가장 크게 빈 곳으로 정의한다.
- 질문 작성 규칙:
  1. 문단 전체 관계를 다시 보게 하는 방향으로 묻는다. 세부를 콕 찍지 않는다.
  2. 답이 되는 개념어나 관계를 질문에 넣지 않는다.
  3. 이미 받은 질문을 되풀이하지 않는다.
  4. 한 번에 하나만 묻는다.
- 이 형식은 조정에 쓰지 않은 새 응답으로 판정·질문 여부·질문의 질을 함께 검증한 뒤에 채택 여부를 정한다. 그림자 실험 85시점과 질문 비교 10쌍은 검증에 다시 쓰지 않는다.

## 근거

- 사용자 동의(2026-10-15): "동의해" (단순 형식 유지, 질문 규칙 네 가지 권고에 대해)
- 질문 비교 10쌍 블라인드 결과([RESULTS](../../docs/experiments/question-quality-h0-vs-v4-2026-10-15/RESULTS.md)): 선택 H0 4·V4 6, Q01~05 적절성 합 16 대 16, 누출 중간 이상 H0 2·V4 3. "전체를 아우르는 질문" 선호는 H0 2·V4 2로 축 쪽 우세가 없었다. H0가 진 이유는 누출·이전 질문 반복·겹질문으로, 질문 작성 규칙으로 다룰 종류다(Claude 해석).
- 사전 제안 규칙의 첫 조건(H0 선택 ≥ V4)은 충족하지 않았다. 이 결정은 그 규칙의 둘째 갈래(원인 논의)의 결론이다.
- 판정 쪽 근거는 [D-0138](./D-0138-paragraph-fundamental-review-question-quality-first.md).
