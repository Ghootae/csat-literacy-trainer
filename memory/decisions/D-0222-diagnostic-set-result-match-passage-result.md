# 진단 세트 결과: 지문 결과와 같은 등급 표시(최빈 등급·확률·등급 띠), 작은 전국 분포 곡선, 지문별 누적 등급 띠, 문항 칸 색 규칙 통일

## 결정

사용자(2026-11-10, "세트 완료 결과도 지문별 결과 보고와 맞춰서 수정해야해", 화면 사진). 질문 넷에 대한 답:

1. **큰 글씨와 문장**(사용자 (가)): 세트 결과 "① 내 위치"의 큰 글씨는 16문항 전체 기준 확률 최대 등급("2등급"), 그 아래 "2등급일 확률이 45%로 가장 높아"(지문 결과와 같은 `gradeSentence`). 범위 표기("1~3등급")는 쓰지 않는다.
2. **그래프**(사용자 (다)): 주 그래프는 지문 결과와 같은 그라데이션 등급 띠(커서를 대면 그 등급 확률). 그 아래 정규분포 곡선을 작게 "전국 분포에서의 위치" 참고용으로 둔다.
   - 2-1(사용자 (나)): 작은 곡선에는 확률 최대 등급 구간 하나만 칠하고 그 등급의 전국 비율을 적는다(예: "2등급: 전국 상위 4~11%"). 범위 세로선은 없앤다. 등급의 전국 비율은 등급 정의라 추정 범위가 아니다.
3. **"지문을 풀수록 좁아진 범위"**(사용자 (가)): 지문 1, 1~2, 1~3, 1~4 누적 기준 줄마다 작은 그라데이션 등급 띠와 "4등급 · 29%"(최빈 등급과 그 확률). 제목은 "지문을 풀수록 또렷해진 위치" 정도. 최빈 등급이 지문마다 오르내려도 그대로 보인다.
4. **범위**(사용자 (가)): ① 내 위치(1~3번) + ② 문제 풀이 결과의 문항별 칸을 지문 결과 문제 버튼과 같은 색 규칙(`resultGroup`: 정답 / 근거 확인 / 오답, 판정 중 표시)과 같은 글자 표시(`RESULT_GROUP_MARK`)로 바꾸고 칸 아래 설명을 고친다. 문항 카드 내용, ③ 독해 패턴, 추천은 그대로.

## 근거

- 사용자 원문: 이 결정의 대화(2026-11-10). 범위 표기를 쓰지 않는 이유는 D-0219 "변경" 절(16문항에서도 80% 범위 약 2.3등급 폭).
- 코드(2026-11-10): `packages/app/src/client/diagnostic/ResultView.tsx` `Position`(범위 큰 글씨·곡선 위 범위 세로선·지문별 범위 막대), `Solve`(문항 칸 `cellState`: 정답·오답·확인 중), `packages/app/src/server/diagnostic/controller.ts` `positionByPassage`(누적 백분위 범위만).

## 영향

- 인계: `docs/handoffs/2026-11-10-diagnostic-set-result-match.md`.
- 정정(코드 에이전트): 질문 4 설명에서 지문 결과 색이 "근거 강도별"이라고 했으나 실제 색 무리는 셋(정답 / 근거 확인 = 근거 오류 정답 / 오답)과 판정 중 표시다. 결정 내용(같은 규칙을 쓴다)은 바뀌지 않는다.

## 다시 볼 조건

- 학생이 작은 곡선과 등급 띠를 서로 다른 정보로 오해하는 일이 실사용에서 보이면 곡선을 뺀다.
