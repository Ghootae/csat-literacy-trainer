# 문단 분석 결과의 화면 사용: 지문 수형도(보상)와 관계 유형 그래프(진단)

## 결정

문단 분석 지도([D-0141](./D-0141-paragraph-analysis-map-direction.md))의 판정 결과를 화면에 쓴다. 지문 요약을 마친 뒤 왼쪽에 지문 수형도, 오른쪽에 관계 유형 그래프를 둔다.

1. **수형도(시각적 보상이 주목적).** 동결 지도의 TOP→CROSS→문단 요지→합성→명제를 그린다. 처음엔 TOP과 문단 요지까지 보이고 누르면 펼친다. 노드를 누르면 명제 문장·관계 내용을 본다.
   - 노드 밝기: `DIRECT` 밝게, `PARTIAL` 반쯤 밝게, `ABSENT`·`CONTRADICTS` 흐리게. 틀림(`CONTRADICTS`)은 수형도에서 구별하지 않고 그래프에서만 다룬다.
   - 판정 차례: 문단마다 **마지막 차례**.
   - CROSS·TOP은 판정이 없으므로 자식에서 계산한다: 자식 모두 밝음 → 밝게, 모두 반쯤 이상 → 반쯤, 그 밖 → 흐리게. 개발자 화면에서 "계산값"으로 표시한다. 지문의 모든 문단을 마치면 TOP에 "완료" 테두리(이해 표시와 별개의 완료 보상).
2. **관계 유형 그래프(진단).** 판정 차례는 **첫 차례**(D-0160 기본값).
   - 누적: 갈래(4갈래)별 잡은 개수(D+P)·틀린 개수(C) 막대. 비율이 아닌 개수. 막대를 누르면 18유형이 펼쳐지고, N<10 칸은 "아직 적음".
   - 추이: 지문마다 관계 오류율 선, 포착률은 흐린 보조선.
   - 틀린 관계를 누르면 관계 내용과 학생 문장을 보인다. 첫 차례에 틀리고 마지막 차례에 D·P가 된 관계는 "대화 뒤 고침" 표시.
   - 문단을 넘는 관계는 세지 않는다(D-0160 유지).
3. **단계.**
   - 1단계: 개발자 새 주소 `/dialogue/lab/analysis`에서 기존 판정 기록(공손룡·도파민)으로 그린다. `/dialogue/lab` 요약 흐름은 손대지 않는다. 나머지 UI 4지문(법인·정보 비대칭·표면 장력·mRNA)은 구조만 그린다. 18유형 이름은 `TYPE_KO` 그대로. 외부 전송 없음.
   - 2단계: 학생 확인 단계에 넣을 때 요약 완료 직후 판정을 돌린다. 기다리는 동안 구조를 먼저 보이고 판정이 오면 노드를 켠다. 그 전에 판정 1회 시간·비용을 재고 승인받는다. UI 4지문 판정도 그때 함께 돌린다. 학생용 유형 이름도 그 전에 정한다.

## 근거

- 사용자(2026-10-27): 수형도·노드 클릭·시각적 보상, 오른편 18유형 누적·추이 그래프 제안. 이후 질문마다 "권고대로, 틀림은 그래프에서만 다루자", "권고대로 진행", "동의", "승인".
- 판정 자료(`docs/experiments/analysis-map-gongsun-2026-10-16/stage2-v3/combined.json`, `docs/experiments/analysis-map-dopamine-2026-10-18/judge-v3/combined.json`): 판정은 문단 단위이고 TOP·CROSS 판정은 없다. 공손룡 다섯 문단을 다 판정받은 세션 2개, 도파민 0개. 공손룡 노드 라벨 PARTIAL 366·DIRECT 353.
- 표본: 문단당 문단 안 관계 약 4.5개(D-0160)라 지문 하나로 18유형 비율은 잡음이다.
- 지도 크기: 법인 동결 지도 명제 60·노드 30·관계 39.

## 이전 결정과의 관계

- [D-0141](./D-0141-paragraph-analysis-map-direction.md)·[D-0001](./D-0001-semantic-relation-verdict.md): 지도는 학생 점수가 아니라는 경계를 바꾼다. 판정을 학생에게 보이지만 점수(충족 개수 점수)로 쓰지는 않는다. 노출은 2단계(학생 확인)부터.
- [D-0160](./D-0160-student-fingerprint-aggregation.md): 집계 규칙(칸·세기·문단 넘는 관계 제외·물려받은 오류)을 그대로 쓴다.
- [D-0176](./D-0176-student-switch-roadmap-pilot-before-expansion.md): 학생 노출은 학생 확인 단계 순서를 따른다.

## 포함하지 않는 것

2단계 구현, 새 판정 실행, 문단을 넘는 판정, 학생용 유형 이름, 문제 풀이 파트 화면.

## 재검토 조건

1단계 화면에서 수형도 가독성이 나쁘거나 계산값 TOP이 보상으로 작동하지 않을 때, 또는 2단계 시간·비용 측정에서 요약 직후 판정이 어렵다고 나올 때.
