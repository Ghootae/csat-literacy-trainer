# 문단 분석 지도 방향: 상향 위계 지도, 동결, 표본 기반 닫힌 어휘, 생성형 판정

## 결정

[Q-0037](../OPEN_QUESTIONS.md)의 학생 상태 분석 자료에 대한 브레인스토밍 단계의 방향 합의다. 구현·API 실행은 정하지 않았다.

- 분석 자료는 대화를 이끄는 골드와 분리한다. 문단을 명제로 분해하고 관계를 잡아 최상위 층까지 위계적으로 합성하는 상향 지도를 만든다(사용자 아이디어).
- 학생 응답은 지도에 위에서 아래로 적용해 명제·관계의 충족을 판단하고, 활성 명제·관계를 누적해 반복 패턴을 본다. 실시간 노출이 아니므로 일관성이 우선이다.
- 지도는 문단마다 1회 생성·검토 후 동결한다.
- 문단 간 비교는 미리 정한 짧은 라벨 목록(닫힌 어휘)으로만 한다. 목록은 분야별 지문을 **지문 단위로** 샘플링한 뒤 만든다.
- 판정은 일반 생성형 모델로 한다. JEV는 쓰지 않는다.

상위 정보 입력 제외·코드 규칙 결합·가지치기, 순서형 라벨+근거 인용+반복 일치율, 목록 작성 절차는 Claude 제안이며 합의되지 않았다([논의 기록](../../docs/review/paragraph-analysis-map-brainstorm-2026-10-16.md) 8절).
