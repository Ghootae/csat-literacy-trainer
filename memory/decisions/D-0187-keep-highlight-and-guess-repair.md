# 교정 질문의 지문 표시와 추측 답의 '고침' 인정은 그대로 둔다

## 결정

사용자 판정(2026-10-29), v5.7 재실행 5세션 기준.

1. **지문 표시:** v5.7 교정 질문은 답을 보기로 주지 않지만, 화면이 칠하는 표시 구절에 답이 든 문장이 있어 옮겨 쓰면 답이 되는 경우가 있다(6개 중 4개). 이를 그대로 둔다. 세션별: prob-5 수용 가능(질문이 두 가지를 묻는 점 포함), prob-6·8·9 문제 없음.
2. **추측 답:** prob-10의 "중성 되나 봄", "낮아지는 듯" 같은 확신 없는 교정 답을 REPAIRED로 인정하는 현재 판정을 유지한다. 확신 없는 답을 UNCONFIRMED로 돌려 다시 묻는 것은 학생을 몰아세우는 위험이 더 크다(사용자: "너무 학생을 몰아세우는게 더 위험").
3. 따라서 코드 에이전트가 제안한 v5.8 후보 '추측 답 미확인'은 채택하지 않는다. v5.8 후보는 인계 4번(결론 재계산·정의 한 단계 적용 추론)만 남는다.
