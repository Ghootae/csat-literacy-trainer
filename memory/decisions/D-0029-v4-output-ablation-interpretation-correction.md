# 출력 절삭 후보의 안정성·비용 해석을 첫 실행 기준으로 정정

사용자는 S2와 B1 결과의 해석을 다음처럼 정정했다. 이 결정은 D-0028의 운영 V4 유지, 사람 승인 기준, 단계적 비교 원칙을 폐기하지 않고 후속 실험 결과의 표현을 좁힌다.

- S2는 안정적인 통과점이 아니다. 첫 실행에서 새 질문이 발생했고 제한 재실행에서 사라진 것은 비재현성·변동의 증거이지 15/15 안정성의 증거가 아니다.
- 후보 비교의 주 지표는 사례별 첫 실행이다. 제한 재실행은 계약 복구 또는 판정 변동을 확인하는 별도 자료다.
- 비용은 첫 실행, 운영상 계약 재시도, 연구 목적 의미 재실행, 질문 생성 비용을 분리한다. 연구 재실행을 운영 비용으로 합산하지 않는다.
- N27은 사람 승인 기준과 불일치하므로 B1 후보의 실패로 기록한다. 단회 불일치만으로 B1 압축 구조가 과개입을 유발했다고 인과 해석하지 않는다.
- B1의 메타데이터 복원 설계 타당성은 확인됐지만 제품 도입의 품질·비용 실익은 입증되지 않았다. 보류하며 작은 메타데이터 절삭의 우선순위를 낮춘다.
- S1·S2를 운영 후보로 다시 검토하려면 현재 V4와 같은 조건에서 반복 비교해야 한다.
- N03의 반복 정확 인용 실패는 출력 절삭과 분리한 인용 생성·검증 문제로 다룬다. 원모형 출력을 보존하고, 제한된 문장부호 정규화로 학생 응답의 유일한 위치가 확인될 때만 원문의 정확한 부분 문자열로 복원하는 방안을 별도 검토한다. 의미가 달라지거나 후보 위치가 여럿이면 기존처럼 실패시킨다.

재검토: 동일 조건 반복 비교가 S1·S2의 질문 행동 안정성과 순비용 이득을 입증하거나, 제한적 인용 정규화가 의미 변경 없이 반복 계약 실패를 제거할 때.
