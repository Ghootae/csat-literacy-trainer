# 문단 전체 판정 그림자 실험 설계

## 결정

운영 문단 요약 판정기 V4(`axis-dialogue-selective-v4`)는 그대로 두고, 같은 학생 응답에 문단 전체 판정(그림자)을 오프라인으로 덧붙여 비교한다. 설계 전문은 `docs/experiments/holistic-verdict-shadow-2026-10-08/PLAN-DRAFT.md`다.

- **데이터:** 실데이터 72시점과 탐침 13개.
  - 실데이터 A: 09-21 V4 재판정 45시점(`docs/experiments/natural-response-disagreement-v1-2026-09-21/`)
  - 실데이터 B: `sessions.jsonl`의 V4 세션 가운데 A에 없는 14세션, 27시점
  - 탐침: Claude가 쓰고 사용자가 블라인드로 판정했다. 해시로 고정했다.
- **축과 모델:** gold-v2 축, `gpt-5.6-terra` medium. V4 판정과 같은 기준이다.
- **그림자 입력 변형:**
  - H0: 원문, 지문, 학생 원발화, V4 질문(대화 맥락으로 표시)
  - H1: H0에 gold-v2 L1을 기계적으로 이어 붙인 참조 해석을 더한다.
  - 축 정보는 전체 판정에 넣지 않는다. 미해결일 때 축 귀속 호출에서만 쓴다.
- **분석:**
  - 주 분석: 실데이터 최초 45시점
  - 탐침: 사례로 따로 보고
  - 후속 27시점: 진단용
  - 모든 시점은 독립 판정한다.
- **실행:** 1차는 1회 실행한다. 그림자 2·3회차와 갈린 시점의 V4 추가 실행은 1차를 본 뒤 따로 승인받는다. V4를 새로 돌릴 때는 09-21의 고정 V4 요청을 쓴다.
- **사람 판정:** 갈린 시점 전체와 일치 표본 최대 10건을 블라인드로 판정한다. 며칠 뒤 재판정해 판정이 바뀐 시점은 경계 사례로 분리한다.
- **성공 판정 규칙:** PLAN 11절로 확정했다(사용자 확정 2026-10-08).
- **진행 순서:** 인계 → Codex 구현(모의 검증) → Claude 검토 → 별도 전송 승인 → 실행([D-0092](./D-0092-claude-codex-work-division.md))

## 근거

- 사용자 지시서(2026-10-08, 대화로 전달)와 근거 논의 `notes/no-chunk-evaluator-review-2026-10-07.md`(대화로 전달, 저장소 미보관)
- 사용자 결정(2026-10-08):
  - 축은 V4가 쓴 gold-v2를 쓴다("권고대로 진행").
  - 추가 14세션을 포함한다.
  - 1차는 1회만 실행한다.
  - 사람 판정에 일치 표본을 더한다.
  - 후속 응답에 V4 질문을 넣는다.
  - 독립 Claude 검토 의견을 반영한다.
  - 탐침은 Claude가 쓰고 사용자가 판정한다.
  - 성공 규칙과 "뚜렷하다"의 기준을 확정한다("권고대로 진행").
- 데이터 확인: B의 9개 문단 골드 해시가 A의 gold-v2, 현재 `packages/pipeline/fixtures/experiments/dialogue/gold-v2/`와 같다.

## 폐기한 대안

- 두 단계 생성 v3 축을 쓰는 안: V4 원판정과 축이 달라져 판정 방식의 차이와 축의 차이가 섞인다.
- 갈린 시점만 사람이 판정하는 안: 두 판정기가 함께 틀린 경우를 볼 수 없다.
- 후속 시점에 이전 그림자 판정을 넘기는 안("기준 고정"): 학생의 실제 후속 답은 V4 질문에 대한 답이다.
- 사용자가 탐침을 직접 쓰는 안: 축을 알고 쓰게 되어 블라인드가 깨진다.
- 탐침 제외: 실데이터에는 FA 방향 칸이 최대 8개라 FA 감소를 볼 수 없다.
- 탐침을 실데이터와 같은 분모에 넣는 안: FA 표적으로 만든 답이라 갈림률이 부풀려진다.
