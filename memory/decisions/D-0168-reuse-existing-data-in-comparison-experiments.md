# 비교 실험 전 기존 자료 재활용 검토

## 결정

비교 실험을 설계할 때는 외부 전송 계획 전에 재활용할 수 있는 기존 자료(지난 실험의 저장된 요청·응답·출력, 동결 자료)가 있는지 먼저 검토한다. 기존 출력이 같은 지시문·모델·입력으로 만들어졌으면 기준 조건으로 다시 쓰고 새 조건만 생성한다. 확인 방법과, 재활용하지 않으면 그 이유를 전송 승인 요청에 적는다.

## 근거

- 사용자(2026-10-23): 마지막 설명 좌표 비교(D-0167)에서 Claude가 기존 조건까지 새로 생성하는 84요청 계획을 올리자 "v5 버전에 대한 실험 자료는 이미 있지 않아?"라고 짚었다. 회귀 시험의 저장된 출력(지시문·모델·입력 일치 확인됨)을 쓰면 42요청이면 된다. 이어서 "항상 비교 실험을 할 때는, 재활용 가능한 기존 자료가 있는지 검토할 것. 이 규칙을 기록해둬."라고 했다.
