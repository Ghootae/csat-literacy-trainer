# 문단 판정기는 V4 유지

## 결정

문단 이해 판정기는 운영 중인 V4(`axis-dialogue-selective-v4`, gold-v2)를 유지한다. [D-0103](./D-0103-holistic-verdict-axis-recording-direction.md)의 "판정은 H0" 방향은 채택하지 않는다. D-0103의 나머지(철회 규칙 폐기, 종류별 근거, 오류 존재와 질문 필요 분리)는 유지한다.

## 경과

- 판정 기준을 gold-v2 `centralStory`로, 질문 기준을 축으로 하는 안(C1)을 검토했다. 사용자 판정이 갈린 5사례(T02·T04·B-81557c-t1 질문 필요, T05·T12 충분)에서 빠진 내용이 모두 중심 이야기 안에 있어, 중심 이야기 복원 여부로는 경계를 가를 수 없었다. C1은 진행하지 않는다.
- 사용자는 경계 기준을 명확히 말할 수 없고, 이유를 찾아도 일반화되지 않을 것이라고 했다. Claude는 경계 판정을 맞히는 대신 경계에서 질문 없이 중심 이야기를 보여 주는 처리를 제안했고, 사용자가 수용했다.
- 그 처리를 V4 출력에 적용한 오프라인 계산(API 0회): [REPORT "사람 판정 2회차"](../../docs/experiments/holistic-verdict-shadow-2026-10-08/REPORT.md)
  - 사람 경계 판단은 2회 블라인드 판정에서 32/33 같았다.
  - (나) ERROR만 질문: 불필요한 질문 7→2, 사람 "질문 필요" 11 중 8을 보여 주기로 낮춤
  - (가) OK만 보여 주기: 질문 불변, 놓친 1개(S024)를 보여 주기로 건짐
  - 사람 "원문과 다른 주장 있음" 4개는 모두 V4 ERROR

## 근거

- 사용자 명시 "V4로 결정하자"(2026-10-14)
- 1차 실험 잠정 결론 "V4 유지"(PLAN §11: H0 갈림 3<5, FA 방향 4<6)

## 포함하지 않는 것

경계 보여 주기 화면, 운영 판정·UI 변경, 추가 API 실행. 경계 처리 규칙 채택 여부는 미정이다.
