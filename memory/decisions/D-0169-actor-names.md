# 실행 주체 명칭: 호출 모델·코드 에이전트·하위 에이전트·웹 에이전트

## 결정

기록과 보고에서 "Claude"만으로 실행 주체를 쓰지 않고 다음 네 이름으로 구분한다.

| 이름 | 대상 |
|---|---|
| 호출 모델 | API로 부르는 모델(luna, sol 등) |
| 코드 에이전트 | Claude Code 메인 세션(사용자와 대화하며 설계·판단·검토를 맡음) |
| 하위 에이전트 | 코드 에이전트가 띄우는 executor 등(확정 설계의 실행을 맡음, D-0128) |
| 웹 에이전트 | claude.ai 웹·데스크톱 앱에서 사용자가 직접 대화하는 Claude. 기존 문서의 "Desktop Claude"와 같은 대상 |

- 보고서 파일명 `REPORT-*-desktop.md`는 바꾸지 않는다. 이미 만든 보고서 경로를 깨지 않기 위해서다. 이 파일은 웹 에이전트와 논의하는 용도다.
- 지난 기록의 "Claude"·"Desktop Claude"는 고쳐 쓰지 않는다.

## 근거

- 사용자(2026-10-23): "실행 주체 명칭을 명확히하자.(기록) 1. api 사용: 호출 모델 2. 클로드 코드 에이전트(지금 대화 대상인 너): 코드 에이전트 3. 웹앱 상의 클로드 에이전트: 웹 에이전트".
- 웹 에이전트가 Desktop Claude와 같은 대상인지 확인했고, 사용자가 "같은 대상이야. 권고대로 해"라고 답했다.
- 하위 에이전트 이름은 코드 에이전트가 권고했고 사용자가 "권고대로 해"로 승인했다. 이유는 검토 책임(메인 세션)과 실행(하위 에이전트)의 구분(D-0128)이 기록에 남아야 하기 때문이다.
- 계기: 출제자 전략 피드백 설계에서 "Claude가 정확성을 검토"라는 표현이 셋 중 누구를 뜻하는지 모호했다.
