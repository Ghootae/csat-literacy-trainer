# SNS 진단평가 기본 세트는 조합 E(지문마다 난이도가 퍼진 4지문 16문항)로 한다

## 결정

[D-0200](./D-0200-sns-diagnostic-mode-result-screen-direction.md) SNS 진단평가의 기본 16문항 세트는 아래 4지문이다. 어휘 문항은 뺀다.

| 분야 | 지문 | 시험 | set_id | 쓰는 문항 | 정답률 범위(%) |
|---|---|---|---|---|---|
| 인문(복합 (가)(나)) | 의식과 인지 과정에 대한 철학적 논의 | 2024학년도 6월 평가원 | `69c0114f78128b2a9bedd8fc` | 12~16 (5) | 49~75 |
| 사회 | 경마식 보도와 선거 방송 토론회 | 2024학년도 수능 | `69c0041afa5063deffe1a036` | 4~7 (4) | 50~88 |
| 과학 | 플라스틱의 중합 반응과 물리적 성질 | 2025학년도 6월 평가원 | `69bc1c89a029f488d9e54e5b` | 8~10 (3) | 30~79.5 |
| 기술 | 오디오 신호의 디지털 저장과 지각부호화 압축 | 2026학년도 9월 평가원 | `69bc96468095df3b8c51460e` | 14~17 (4) | 44.5~73.5 |

- 16문항, 정답률 구간(<40·40~55·55~70·70~85·≥85) 1·4·4·6·1, 평균 63.1%(메가스터디 이용자, 화법과작문·언어와매체 평균).
- UI 6지문은 진단 기본 세트에서 빼고, 학생이 원해서 더 푸는 추가 문항이나 확장 시험에 쓴다(D-0200 후속 2·3).
- 이 4지문의 분석 골드(D-0151)와 선지 연결(D-0162)을 기존 절차로 만들어 동결한다. 경마식 보도는 분석 골드가 이미
  동결돼 있다(`docs/experiments/analysis-gold-calibration-2026-10-20/horse-race-reporting/`).

## 근거

- 후보 추리기 보고: [`REPORT-human.md`](../../docs/experiments/sns-diagnostic-candidates-2026-11-05/REPORT-human.md),
  [`REPORT-desktop.md`](../../docs/experiments/sns-diagnostic-candidates-2026-11-05/REPORT-desktop.md). 고3 수능·평가원 30세트,
  정답 번호 30/30 trainer 정답과 일치.
- 사용자: 평균보다 "쉬운 문제부터 어려운 문제까지 넓게 있는 세트가 좋은데"(2026-11-05) → 코드 에이전트가 2,042조합을 다시 따져
  D(전체 구간 3·3·3·3·3이지만 난이도가 지문 단위로 갈림), E, E′를 비교. E 추천 이유: 결과 화면에서 분야·비틂·무너진 단계를
  보여 주므로 난이도가 지문에 몰리지 않아야 분야별 결과가 지문 난이도와 섞이지 않는다. 사용자 "오케이 E로 하자".

## 한계

- 40% 미만 문항이 1개(플라스틱)라 상위권 변별이 약하다. 추가 문항에 어려운 지문(예: 도덕 문장, 근대 문명)을 두어 보완한다.
- 정답률은 메가스터디 이용자 기준(Q-0042), 분야는 제목 기준 코드 에이전트 분류다.
- 결함 문항·비틂 분포(기준 ⑤)는 동결 뒤에 확인한다.

## 다시 볼 조건

- 동결 뒤 결함 문항이 나오거나 비틂이 한두 종류에 몰리면 같은 분야의 다음 후보(`spread-within-top.json`)로 바꾼다.
- 자체 응답이 쌓여 정답률을 다시 보정하면 구간 분포를 다시 본다.
