# 현재 개발자 골드 생성 흐름의 명칭

## 결정

사용자의 명칭 기록 요청에 따라 현재 개발자 UI용 문단 골드 생성 흐름을 **중심 이야기 기반 L1·L2 공동 생성**으로 부른다.

이는 생성 방식의 명칭이다. 자산 schemaVersion은 `conditional-meta-gold-v1`이며 v4는 문단 이해 판정기 계열의 버전으로 구분한다. 이 이름은 기존 중심 이야기로부터 구체 축(L1)과 기능적 메타 축(L2)을 함께 생성하는 단계를 지칭한다. 앞선 원문 분석과 중심 이야기 생산까지 포함한 전체 생산 기준선의 이름을 대체하지 않는다.

원문 기반 후보 생성·JEV 선택·별도 L2·중복 병합은 별도의 오프라인 실험이며 이 명칭에 포함하지 않는다. 명칭 기록만 수행했고 생성 코드·골드·UI는 변경하지 않았다.
