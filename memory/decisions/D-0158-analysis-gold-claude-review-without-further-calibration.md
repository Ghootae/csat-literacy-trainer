# 분석 골드: 맞춰 보기를 끝내고 동결·입장을 Claude 검토로 운용

## 결정

[D-0151](./D-0151-analysis-gold-standard-procedure.md)의 맞춰 보는 기간을 둘째 묶음으로 끝낸다. 전문: [`docs/ANALYSIS-GOLD-PROCEDURE-2026-10-20.md`](../../docs/ANALYSIS-GOLD-PROCEDURE-2026-10-20.md) 5·7·10절.

1. **동결 선택은 Claude가 점검표 v2로 한다.** 두 묶음 연속 통과(4/4, 2/2).
2. **입장 표시도 Claude가 확정한다.** 입장 통과 기준(인물 귀속 불일치 0건)은 두 묶음 모두 못 넘었지만 더 맞춰 보지 않는다. 분석 골드는 학생과의 대화에 직접 쓰는 자료가 아니라서, 경계 사례의 작은 오류는 받아들인다.
3. 입장 점검표에 둘째 묶음에서 나온 규칙 두 개를 더한다: "예를 들어"로 든 예시는 필자; 귀속 표지 없는 문장은 같은 인물의 귀속 문장 사이에 끼어 그 이론 내용을 이루면 인물, 귀속 문장 뒤에서 현상을 설명하는 데 그치면 필자.
4. 6절 넘김 조건은 그대로 둔다(지도 3회 모두 검증 실패·고르기 어려움, 입장 덮어쓰기 10% 초과, 관계 기타 5% 초과). '모호' 표시 층은 만들지 않는다.

## 근거

- 둘째 묶음(`docs/experiments/analysis-gold-calibration-2-2026-10-21/`): 동결 통과(회차 일치 1/2, 다른 1건 "써도 됨"), 입장 명제 일치 61/62(98.4%), 인물 귀속 불일치 1건(virtual P3-6, 관형절 전제를 지도가 "주목한다"로 바꿔 쓴 경계 사례). `calibration/FREEZE-COMPARE.md`, `calibration/STANCE-COMPARE.md`.
- 두 묶음의 입장 불일치는 모두 관형절 전제에서 반대 방향으로 났고, 사용자도 같은 유형을 "모호"로 표시했다(첫 묶음 ga P4-3, 둘째 묶음 의미 P4-7~9·가상 P2-3~6).
- 사용자(2026-10-21): "어차피 이건 학생과의 인터랙션에 사용되는 자료가 아니고, 약간의 오류는 큰 문제가 안돼. 그냥 클로드가 입장 표시한느 걸로 결정". 규칙 3의 두 항목은 사용자 검토 이유("예를 들어"는 필자의 예시, P4-7~9와 P2-3~6을 "한 규칙으로 맞추는 게 좋겠어요")에서 왔다.
- 외부 전송: D-0155 승인 범위(A 지도 6요청+응답 없음 재전송 1, B 입장 2, C 관계 분류 4). 확인된 청구 지도 약 $0.58, 입장 $0.083, 분류 $0.168. 시간 초과 1건은 청구 여부 모름.

## 이전 결정과의 관계

D-0151 재검토 조건("맞춰 보는 기간을 두 번 연속 통과하지 못할 때")에 따른 재검토 결과다. D-0151의 층 구성·복합 지문·넘김 조건은 그대로다. 두 묶음 6지도의 동결본·입장 확정본(사용자 판단)은 그대로 쓴다.

## 포함하지 않는 것

다리 층, 학생 이해 지문 집계, 지시문 v3, 공손룡·도파민 동결본에 관계 유형 붙이기.

## 재검토 조건

입장 층을 학생 대화나 선지 판정에 직접 쓰게 될 때, 또는 운용 중 사용자가 묶음 요약에서 Claude 판단을 뒤집는 일이 반복될 때.
