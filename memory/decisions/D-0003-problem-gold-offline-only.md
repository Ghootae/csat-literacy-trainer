# 구조화 문제 골드를 오프라인 자산으로 제한

## 결정

기존 문제 골드와 생산 파이프라인은 삭제하지 않되, 오프라인 문항 감사, 회귀 기대값,
교사·개발자 검토와 비교 연구에만 사용한다. 골드의 존재나 승인 상태를 학생용 문제 풀이
런타임의 선행 조건으로 만들지 않는다.

## 근거

문제 풀이 런타임 비교에서 별도 골드 입력의 이익이 없었고 저정보 응답의 과잉추론 위험이
커졌다. 반면 이미 생산한 골드는 문항 품질 감사와 실험 대조군으로 독립적인 가치가 있다.

## 폐기한 대안

- 문제 골드 생산 완료를 웹앱 운영의 필수 조건으로 지정
- 런타임에서 쓰지 않는다는 이유로 기존 자산과 계보를 삭제

## 재검토 조건

오프라인 감사나 새로운 평가 연구에서 구체적 필요가 생기면 생산은 재개할 수 있다. 런타임
사용 재개에는 [`D-0002`](./D-0002-problem-source-direct-runtime.md)의 재검토 조건도 충족해야
한다.
