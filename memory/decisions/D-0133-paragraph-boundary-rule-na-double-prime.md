# 문단 판정 경계 처리 규칙 방향: (나″)

## 결정

[D-0132](./D-0132-paragraph-judge-keep-v4.md)의 V4 축 판정 위에서 시점별 행동을 다음 규칙 (나″)로 정하는 방향을 채택한다. 축 판정 중 위에서부터 먼저 걸리는 줄을 따른다.

| 상황 | 행동 |
|---|---|
| ERROR가 하나라도 있음 | 질문 |
| 모든 축이 UNCLEAR_SERIOUS(중심축을 하나도 못 잡음: 소재 나열·제목형, 1축 문단의 SERIOUS 포함) | 질문 |
| UNCLEAR_SERIOUS가 일부 있음 | 질문 없이 문단 끝에 중심 이야기 보여 주기 |
| UNCLEAR_OK만 있음 | 통과 |
| 모두 PASS | 통과 |

V4 현행과의 차이는 "SERIOUS가 일부 있음"을 질문에서 보여 주기로 낮춘 것 하나다.

## 근거

- 사용자 명시 "나\"로 기록."(2026-10-15)
- 사용자 원칙(2026-10-14): 누락을 놓치는 것보다 불필요한 질문에 의한 이탈을 더 우려한다. 사람의 경계는 암묵적이라 프롬프트로 복구하기 어렵다.
- 33시점 오프라인 계산(사람 2회차 기준, API 0회, [REPORT](../../docs/experiments/holistic-verdict-shadow-2026-10-08/REPORT.md)):

| | V4 현행 | (나) | (나′) | (나″) |
|---|---:|---:|---:|---:|
| 질문 | 17 | 5 | 9 | 9 |
| 불필요한 질문 | 7 | 2 | 2 | 2 |
| 보여 주기 | 0 | 19 | 15 | 8 |
| 사람 "질문 필요" 11 중 질문 | 10 | 3 | 7 | 7 |
| "질문 필요" 중 보여 주기만 | 0 | 8 | 4 | 3 |
| "질문 필요" 중 아무것도 안 함 | 1 | 0 | 0 | 1 |

  - (나′)는 (나″)와 같되 OK만 있는 시점을 보여 주기로 처리한다. OK만 있는 7시점 중 6개는 사람도 불필요로 판정했고, 나머지 S024(B-81557c-t2)는 확신 낮음이며 V4 현행에서도 통과였다.
  - 전체 질문 SERIOUS 4시점(S002 T08, S003 A-N13, S022 A-N31, S025 B-222e04-t1)은 모두 사람 "질문 필요"였다.

## 한계

- 같은 33시점으로 규칙을 골라 과적합 위험이 있다. OK만 있는 시점은 7개뿐이다.
- 오류 탐지 근거가 약하다. 사람 "다른 주장 있음" 4개는 모두 V4 ERROR였지만 3개는 Claude가 쓴 탐침이다.

## 포함하지 않는 것

운영 판정·UI 변경, 추가 API 실행. 다음 순서는 (1) 조정에 쓰지 않은 새 응답으로 오프라인 검증(불필요한 질문·놓침·오류 탐지), (2) 문단 끝 중심 이야기 보여 주기 화면 설계(항상 보여 주기 대 조건부 보여 주기 포함)를 별도 결정으로 한다.
