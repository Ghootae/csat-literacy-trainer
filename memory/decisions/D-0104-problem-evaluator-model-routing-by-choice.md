# 문제 풀이 판정기 모델: 선택 정오로 라우팅(정답 luna, 오답 sol)

## 결정

v5 판정기([D-0090](./D-0090-problem-evaluator-v5-naming.md))의 모델을 학생 선택의 정오로 정한다.
서버가 판정기 호출 전에 공식 정답과 비교해 고르며, 한 판정 호출에는 모델 하나만 쓴다.

- 정답 선택: `gpt-6-luna`, reasoning effort medium
- 오답 선택: `gpt-6.1-sol`, reasoning effort medium

## 근거

- 사용자 결정(2026-10-10): "선택 정오 라우팅으로 결정하자." 비교 대상은 luna 판정이 근거 부족·확인 불가일 때 sol을 부르는 방식이었다.
- [v5 다문항 시험](../checkpoints/2026-10-09-v5-multi-item-luna-sol.md)(methods 조건, 5문항 30응답 × 3반복)의 기존 결과로 계산했다
  (`docs/experiments/v5-multi-item-luna-sol-2026-10-08/`, [의미 검토](../../docs/experiments/v5-multi-item-luna-sol-review-2026-10-08/REVIEW-SUMMARY.json)).
  - 선택 정오 라우팅: sol 45/90칸, 자동 일치 88/90, 칸 중앙값 18.2초·p90 33.4초, 보수 비용 1.49달러.
  - luna 판정 기반 라우팅: sol 29/90칸, 90/90, 22.7초·35.7초, 0.93달러. sol로 넘어간 칸은 두 판정을 차례로 기다린다.
  - luna의 학생 노출 결함(결론 중복 오류 12칸, 판단 방향 뒤집힌 코칭 1, '반비례' 강화 2, 내부 선지 번호 노출 17칸 대부분)과 I1은 모두 오답 응답에서 나왔다.
    정답 응답 중 이유가 틀린 6개 응답 18칸은 luna가 모두 맞혔다. 선택 정오 라우팅에서 남는 luna 실패는 D6 2칸(근거 충분인데 근거 미확인 정답, 학생에게는 고정 문구)이다.
- Claude 권고와 일치. 사용자 가정: 정답을 고르고 잘못된 근거를 대는 경우는 드물다(미검증).
- 사용자 판단(2026-10-10): 정답 선택에서는 과도한 개입보다 과도한 관대함이 낫다. 명확한 오류만 잘 잡으면 luna로 충분하다.
  REPAIR 탁상 점검([결과](../../docs/experiments/v5-repair-desk-check-2026-10-10/), Codex 안에서 Astra·luna·sol 대행 판정, 15변형)에서
  luna만 수정 후 근거 충분성을 후하게 판정(S4a·M2a)했고, 수정 실패 답을 수정으로 본 경우는 세 모델 모두 없었다.
  따라서 정답 세션의 근거 충분성 과대 판정은 실패로 세지 않고, 명확한 오류 누락과 미수정 답의 수정 판정만 실패로 센다.
  '근거 확인 정답' 기록을 통계·포인트에 쓰게 되면 이 관대함을 다시 검토한다.

## 폐기한 대안

- luna 단독: 오답 응답에서 학생에게 보이는 문장 결함이 남는다.
- sol 단독: 비용 약 1.8배(이번 세트 2.71달러), 칸 중앙값 23.9초.
- luna 판정이 근거 부족·확인 불가면 sol: luna가 내용 오류로 판정한 오답 칸의 결함을 거르지 못하고, 넘어간 칸의 응답 시간이 늘어난다.
- JEV 1차 판정: [D-0036](./D-0036-jev-product-work-parked.md) 보류 조건 미충족, 확실 구간에서도 luna가 독립 판정하는 구조상 효과가 없다.

## 범위와 미검증

- 운영 코드·서버·UI는 아직 바꾸지 않았다. 구현(판정기 모델 선택, 공개 문구의 내부 선지 번호 후처리 여부)은 별도 설계·승인 대상이다.
- 교정 답변 판정(REPAIR)과 재선택 판정에서의 두 모델 품질은 시험하지 않았다. 세션 안에서 어느 모델이 이어 맡는지(최초 선택 기준 고정 여부)도 정하지 않았다.
- 비용은 오답 비율에 비례한다. 시험 세트는 정답·오답 반반으로 설계됐다.

## 재검토 조건

- 실제 학생 기록에서 오답 비율이 높아 비용이 sol 단독에 가깝거나, 정답 선택의 잘못된 근거가 드물지 않은 것으로 확인될 때
- REPAIR 시험에서 한쪽 모델의 품질이 운영에 부적합할 때
- 모델 가격·성능이 바뀔 때
