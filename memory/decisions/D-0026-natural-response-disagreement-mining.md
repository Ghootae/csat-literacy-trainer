# 합성 경계 최적화를 멈추고 자연 응답 불일치 검토로 이동

사용자의 ‘오케이. 진행해줘’는 현재 V4와 동결된 direct-v1 전체 축 판정을 실제/자연 응답에 오프라인 적용하고 불일치를 검토하는 방향을 승인한다. 프롬프트 규칙 추가·축별 독립 호출 운영 전환·새 합성 실험은 이번 범위에서 하지 않는다. 과거 실험의 효과 부재를 확정하거나 버전을 삭제하는 결정은 아니다.

- 현재 V4와 direct-v1을 동일 누적 학생 발화로 새로 실행한다. 역사적 라벨을 현재 V4의 결과로 재사용하지 않는다.
- 현재 비교는 이전 모델 상태 없이 누적 발화를 재판정한다. 기존 질문과 이미 공개된 도움은 보존한다. 운영 상태 전이·재시도나 새 질문의 전체 사이클 시험이 아니다.
- SERIOUS/ERROR ↔ PASS/OK, PASS↔OK, ERROR 경계 및 계약 실패를 구분한다. 축 차이와 문단 전체 질문 후보 변화도 구분한다.
- 불일치 전부와 일부 일치 사례를 블라인드 검토한다. 사람 판정은 미입력이며 에이전트의 해석을 정답표로 확정하지 않는다.
- 개인 프로젝트 사용자1인의 자료여서 외부 학생의 사용성·학습 효과로 일반화하지 않는다. 운영V4/문제V3/골드/UI 유지.

동결 표본: 출처 확인31세션·고유30문단·45시점(최초31/후속14), 두 조건 각1회90호출 예정. 에이전트가 로컬$2 추정 상한을 설정했다.

## 실행 권한의 남은 조건

비교 진행 방향은 승인됐지만, 실행 명령의 안전 검토가 **해당 자연 응답을 OpenAI API에 외부 전송하는 명시적 승인**을 요구하며 거절했다. 실제 호출0·비용0이다. 우회 실행하지 않으며 해당 데이터 범위·수신처·상한을 명시한 사용자 승인 뒤 재개한다. 준비 완료와 실험 완료를 혼동하지 않는다.

근거: `docs/experiments/natural-response-disagreement-v1-2026-09-21/PLAN.md`, `manifest.json`, `STATUS.md`, `preflight-audit.json`(모두 같은 실험 디렉터리). 원자료 근거는 계획에 연결된 기존 실사용 보고서 및 `scripts/lib/natural-response-disagreement.mjs`의 명시적 선택 조건이다.

재검토: 사람 검토 결과 불필요한 개입 감소/중요한 누락 과수용 차이가 확인된 뒤에만 운영 후보 범위를 다시 결정한다. 현 시점 판정 차이 결과는 없다.

## 외부 전송 승인 확보

2026-09-21, 동결된 원문·축·직접 응답·이전 질문·공개 도움을 OpenAI API에 전송하며90호출/$2 로컬 추정 상한으로 비교한다는 명시적 요청에 사용자가 ‘승인’했다. 직전 안전 검토의 승인 조건이 해소돼 기존 동결 계획으로 재개한다. 근거: `docs/experiments/natural-response-disagreement-v1-2026-09-21/AUTHORIZATION.md` 및 해당 사용자 승인 메시지. 위 실행 대기 문단은 승인 전 이력이다.

## 실행 완료
