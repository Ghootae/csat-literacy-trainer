# 중심축만 통과 기준으로 사용하는 문단 대화 V3

후속: [D-0013](./D-0013-paragraph-optional-revision-v4.md)은 이 범위 원칙을 유지하면서
축별 공개·선택적 보완 V4를 구현한다. 아래 V3 실험은 당시 결과로 보존한다.

사용자가 mRNA 2문단 실사용 이후 중심축을 기준으로 고정하고 원문을 보조자료로 사용하며
중심 이야기를 판정 입력에서 제외하는 수정을 승인했다.

`docs/PARAGRAPH-SUMMARY-DIALOGUE-OPERATIONAL-POLICY-V3-2026-09-18.md`를 따른다.
1차/2차 모두 중심 이야기를 제외한다. 상세 관계는 저정보 질문의 접근 참고로만 남기며
중심축 밖의 요구를 추가할 수 없다. 누락 판정의 축 직접 인용을 기록하되 이를 의미적 적절성의
보장으로 오인하지 않는다. 학생의 자발적 오류와 축 밖 설명의 단순 누락을 구분한다.

축 골드와 문제 풀이 V3는 그대로 유지한다. D-0009 계약 재시도 결정은 유지한다.
D-0004의 선택적 상세 활용 구조는 계승하고, 판정 범위와 자료별 권한을 이 결정으로 좁힌다.

  `36644737-3bf8-4584-9a35-7b748646b3bc` (mRNA 2문단).
- 사용자 승인: 버전 업데이트·수정 및 현재 문단 대상 API 시험 승인.
- 표적 실험: `docs/experiments/dialogue-axis-v3-mrna-2026-09-18/REPORT.md`.
- 정책 승인은 구현의 의미 품질 승인과 구별한다. 첫 12호출에서는 축 밖 질문과 누락·오류
  미탐지가 남았다. 코드 기본값 V3 수정은 완료했으나 실행 서버 재시작·공개 배포 확인은 하지 않았다.
- 재검토: 다른 지문에서 축 의미의 누락·오류를 놓치거나 추가 필수 요건을 요구하는 경우.
