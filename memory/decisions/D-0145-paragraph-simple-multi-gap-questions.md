# 단순 형식 문단: 찾은 구멍을 모두 묻는 번호 질문과 핵심 공개 마무리

## 결정

구멍(GAP) 갈래와, 질문을 거친 뒤의 마무리를 바꾼다. 질문 횟수 상한(문단당 2회), 행동 이름, 처음부터 오류 2개 이상이면 질문 없이 바로잡기는 그대로다. 원칙: 질문을 한 번이라도 거쳤으면 마무리에 항상 문단 핵심을 공개한다. 첫 응답에서 바로 핵심을 잡은 경우만 칭찬으로 끝난다.

1. **질문:** 첫 응답(또는 다시 쓴 응답, 교정 뒤)에서 찾은 구멍을 모두, 한 말풍선에서 번호 질문으로 묻는다. 질문은 최대 2개이고, 각 질문은 방향만 묻는다(답이 되는 개념어·관계 미포함, 반복 금지). D-0139의 나머지 규칙(전체 관계 방향, 답 노출 금지, 반복 금지)은 유지한다.
2. **리액션:** 질문 앞에 응답에 대한 리액션을 둔다. 응답이 사실이어도 중심 내용이 아니면 중심 내용이 아니라고 분명히 말한다("~는 짚었네"처럼 인정하지 않는다).
3. **답 판정:** 물은 항목마다 채웠는지 본다. 묻지 않은 것으로 평가하지 않는다.
   - 모두 채움 → 핵심 공개(모델의 판단임을 드러낸 도입 + 핵심 상자) + 칭찬.
   - 일부 빠짐(오류 없음) → ① 핵심 공개(모델이 쓴 도입 + 핵심 상자) → ② 무엇을 잡았는지 짧게 인정 + "아직 빠진 부분은 ~야". 중요도를 비교하지 않는다. 지문 표시는 빠진 부분의 근거 문장(사용자 형식 확정, 2026-10-17: "무엇을 잡았는지 간단히 인정").
   - 오류 있음 → 지금과 같은 바로잡기(도입 → 오류별 → 문단 핵심), 질문 없음.
4. 첫 응답만으로 핵심을 잡은 경우는 지금처럼 짧은 칭찬만 한다(핵심 상자 없음).
4-1. **확인 질문에 한 답(AFTER_CORRECTION)** (사용자 동의, 2026-10-17):
   - 고침 + 핵심 잡음 → 핵심 공개 + 칭찬(3의 "모두 채움"과 같은 마무리).
   - 고침 + 구멍 남음 → 1의 번호 질문(두 번째 질문) → 이후 3과 같다.
   - 못 고침 → 지금과 같은 바로잡기.
   - 첫 응답에 오류 하나와 구멍이 함께 있으면 지금처럼 확인 질문을 먼저, 구멍 질문은 따로 한다(한 목록으로 묶지 않는다: 성격이 다른 질문이 섞이고, 오류 해결 판정이 다음 행동을 정하는 순서가 무너진다).
5. 사용자가 준 문구 예시는 방향 예시다. 프롬프트에 문구 틀로 넣지 않는다.

## 근거

- 관찰(2026-10-16~17, 공손룡 문단 2): 질문 하나 규칙 때문에 두 구멍 중 하나만 묻고, 학생이 물은 쪽에 맞게 답해도 묻지 않은 쪽으로 빠진 내용 마무리가 되어 "다른 게 더 중요해"라는 말이 나왔다. 같은 문단에서 빠진 쪽이 번갈아 "가장/더 중요"로 불렸다(일대일 10/16, 혼란 방지 10/17). 원인 일부는 Claude가 사용자 예시를 프롬프트 문구 틀로 넣은 것.
- 사용자 지시(2026-10-17): 찾은 구멍을 여러 질문으로 나눠 한 말풍선에 제시, 학생은 모두 답, 2차 피드백은 핵심 공개 후 평가. "질문의 기회가 늘어나는건 아냐". 핵심이 아닌 응답은 명확히 핵심이 아니라고 말하기. 모두 채웠을 때 핵심 상자(Claude 권고에 "동의"). 구멍 답의 오류는 기존 바로잡기 유지(사용자 확인).
- Claude 의견(사용자 수용): 질문 목록이 답의 뼈대를 드러낼 수 있어 최대 2개·방향만. 학생이 칸 채우기식으로 짧게 답하는지는 사용 중 관찰.

## 보완 v4.1 (2026-10-17)

v4 사용 중 번호 질문에 조각으로 답한 오류("다대다 대응. / 유연한 소통이 가능.") 중 둘째를 놓쳤다. 모델이 답을 질문과 떼어 읽었고(사용자 진단), 질문 뒤 바로잡기에서 오류 아닌 못 채운 항목은 응답을 받지 못했다. 사용자 승인("오케이", "진행")으로 다음을 더한다.

- 구멍 질문 답은 물은 항목마다 질문과 답을 합친 완결 문장(`targetGapReadings`)으로 읽고 그것으로 판정한다. 질문의 틀까지만 채우고 덧붙이지 않는다. 비었거나 모호하면 빈 문자열.
- 물은 항목의 답이 원문과 어긋나면 핵심 오류로 세고 항목 번호(`errors[].gapIndex`)를 적는다.
- 물은 항목은 모두 응답받는다: 질문 뒤 바로잡기에서 오류도 채움도 아닌 항목은 "빠진 내용" 말풍선(`missingNote`)과 지문 표시.
- 재구성 요약도 질문과 합쳐 읽은 뜻으로 쓴다.
- 시험: 루나 3사례 각 1회 3/3 기대대로(`docs/review/simple-holistic-dev-ui-feedback-2026-10-16/README.md` v4 사용 메모 1). 프롬프트 `paragraph-simple-holistic-prompt-v4.1.md`, 인계 `docs/handoffs/2026-10-17-paragraph-simple-holistic-v4.1.md`.
