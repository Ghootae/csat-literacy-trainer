# 원문 분할·JEV 선택 골드 생성 흐름 중단

## 결정

원문 분할 후보 생성 → JEV 선택 → L2 → 자동 병합 → 감사기(v1~v3)로 이어지는 문단 골드 생성 흐름을 골드 생성 방향에서 제외한다. 실험 결과, 스크립트, 결정 기록(D-0066~D-0089 계열)은 그대로 보존한다. 이후 문단 골드는 중심 이야기 기반 생성을 기반으로 개선한다([D-0095](./D-0095-central-story-two-stage-generation.md)).

이 흐름에서 정한 다음 규칙은 새 방향으로 가져간다.

- 일반 문단은 실질 설명 기준 최소 2축(D-0086 규칙 2를 수정한 D-0088). 원문 한 문장의 소개·연결은 실질 설명에서 뺀다.
- 문단 기능 판정과 보수적 기본값(불확실하면 일반 문단)
- 같은 질문인지는 공통 소재나 서술 연속성이 아니라 학생이 답해야 할 관계로 판단한다.

## 근거

- 사용자 판단(2026-10-07): "jev를 사용한 이 실험은 굳이 유지할 필요가 없고, 오히려 이전 중심 스토리를 이용한 버전이 차라리 낫겠단 생각", "그 방향으로 진행해". 명료화 답변: "중단·결과 보존".
- Claude 검토 의견(사람 판정 아님):
  - 후보 생성 75회와 JEV 180회를 써도 초기 선택은 71축으로 과분해됐고, 이후 단계는 주로 이 과분해를 수습하는 역할이었다.
  - 공손룡5의 고유명사 유형과 도파민2의 첫 문구 손실은 선택 단계에서 생겨, 감사기 v1~v3가 복원하지 못했다.
  - 실험본이 운영 골드보다 나았던 이점은 주로 원문 대조로 세부를 복원한 데서 나왔으며 JEV 선택 자체의 효과로 보기 어렵다.
  - 근거 문서: `docs/experiments/axis-auto-merge-audit-five-passages-2026-10-02/OPERATIONAL-VS-AUDIT.md`, `docs/experiments/axis-audit-v3-substantive-min-two-2026-10-07/REPORT.md`
- D-0036의 JEV 제품 적용 연구 보류와는 별개다. 이 결정은 JEV를 오프라인 골드 후보 선택에 쓰는 것에 관한 결정이다.

## 폐기한 대안

- 보류(parked): 사용자가 중단을 선택했다.
- 감사기 개선 계속(v4 등): 감사기 위에 단계를 계속 쌓는 구조가 선택 단계의 손실을 복원하지 못했다.

## 재검토 조건

- 중심 이야기 기반 두 단계 생성이 원문의 핵심 관계·정의·조건 보존에서 사람 검토상 반복적으로 실패할 때
- 중심 이야기 자체를 만들 수 없는 새 자료 유형에서 원문 직접 분할이 필요해질 때
