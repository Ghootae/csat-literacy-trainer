# 표제의 추상화 보상 판정을 보류

## 결정

표제 단계에서 의미 보존과 명백한 누락은 계속 판정하지만, 의미를 보존한 추상화의 질을 별도
보상으로 일반 평가하는 작업은 보류한다. 안전한 보상을 놓치는 false negative는 허용하고,
의미를 잃은 표현에 보상을 주는 false positive는 허용하지 않는다.

## 근거

프롬프트 변형과 생성기 실험에서 사람에게도 갈리는 의미 포섭 판단이 재현되지 않았다. 손으로
맞춘 기준은 통과했지만 답을 기준에 심은 과적합이었다.

## 폐기한 대안

- 이 사례만을 위해 새로운 중요도·weight 체계를 도입
- 프롬프트에 특정 포섭 관계를 적어 넣어 통과율을 높임

## 재검토 조건

골드에서 파생되는 일반 신호로 추상화 축의 무게가 정해지거나, 별도 힌트 없이 의미 포섭 판정이
독립 표본에서 재현될 때 다시 연다.
