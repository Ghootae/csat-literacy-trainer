# 분석 골드 점검표 v2·지도/입장 지시문 v2, 새 지문 2개로 다시 맞춰 보기

## 결정

[D-0151](./D-0151-analysis-gold-standard-procedure.md) 첫 묶음 맞춰 보기 결과(동결 통과, 입장 실패)를 반영한다. 전문: [`docs/ANALYSIS-GOLD-PROCEDURE-2026-10-20.md`](../../docs/ANALYSIS-GOLD-PROCEDURE-2026-10-20.md) 3·4·5·9절.

1. **동결 점검표 v2.** 원문 흐름(접속 표지·변화 흐름·주체 구분·절차 단위·평평한 나열 감점), 근거 관계, 최상위 한정·양보, 쪼개기 감점, 진단 해상도를 먼저 보고 다수안은 동점일 때만 쓴다.
2. **입장 점검표 v2.** 목적·의도가 든 명제는 행위와 함께여도 인물, 행위만이면 필자. 인물이 부각한 내용은 인물. "보았다" 문장 안 관형절 전제는 따로 표시가 없으면 필자. 판단 뒤 목적·귀속 표지를 원문에서 찾아 빠짐을 점검한다.
3. **지도 지시문 v2**(`docs/experiments/analysis-gold-calibration-2-2026-10-21/MAP-PROMPT-v2.md`)와 **입장 지시문 v2**(같은 폴더 `STANCE-PROMPT-v2.md`). v1 파일은 그대로 둔다. 같은 규칙을 생성 쪽에도 넣어 처음부터 그 방향으로 나오게 한다. 지문별 문구가 아니라 일반 규칙으로 썼다.
4. **다시 맞춰 보기.** 새 지문 2개(의미 내재주의와 의미 외재주의, 가상 공간의 자기 정체성과 명예훼손)로 동결과 입장을 함께 맞춘다. 기준은 D-0151과 같다. 맞춰 보는 동안 동결본·입장 확정본은 사용자 판단으로 만든다(D-0151 보완 2).

## 근거

- 동결: 4지도 모두 Claude 선택 "써도 됨", 회차 일치 2/4. 다른 2건에서 사용자는 원문 흐름("그러나… 예를 들어", 실행 주체 변화), 근거 관계, 쪼개기를 봤고 Claude는 다수안을 먼저 봤다. 사용자는 네 지도 모두에서 쪼개기를 지적했다(`docs/experiments/analysis-gold-calibration-2026-10-20/calibration/USER-freeze.md`, `FREEZE-COMPARE.md`).
- 입장: 명제 일치 147/149, 인물 귀속 불일치 2건(ga P4-3 관형절 전제, na P3-3 목적 누락)으로 실패. sol 원본의 틀린 4건은 모두 목적·의도·부각 내용을 필자로 둔 것(`calibration/STANCE-COMPARE.md`).
- 사용자(2026-10-21): 생성기를 사용자 선택 방향으로 고치자는 제안("그 다음 작업은 일관적으로 내가 선택한 방향이 나오도록 하는 일반화된 지도 생성기로 수정해야하는거 아냐?"), 단계 정리 확인 뒤 "일괄 실행".
- 새 지문 선정: 수능 DB에서 앞선 실험(공손룡·도파민·표본 14·검증 6·첫 묶음)에 쓰지 않았고, 인물·학파 귀속과 목적 표지가 많아 입장 점검에 쓸모 있는 단일 지문 2개(평가원·수능 계열 우선, 4~5문단).

외부 전송 승인(사용자 "승인", 2026-10-21), 모두 `gpt-6.1-sol` medium, 재시도 없음(응답 없는 오류만 1회 재전송):
- A. 둘째 묶음 2지문 원문, 지도 v2 지문당 3회(6요청), 상한 $1.5.
- B. 동결 뒤 둘째 묶음 입장 v2, 원문·동결본 명제, 지문당 1회(2요청), 상한 $0.3.
- C. 첫 묶음 동결본 4개 관계 유형 분류 v3, 원문·동결 지도(4요청), 상한 $0.5.

## 포함하지 않는 것

다리 층, 학생 이해 지문 집계, 관계 유형 지시문 수정, 운영·UI 변경. 공손룡·도파민·첫 묶음 동결본을 v2로 다시 만들지 않는다.

## 재검토 조건

둘째 묶음도 통과하지 못하면 점검표를 다시 고치기 전에 실패 유형이 규칙 공백인지 적용 실수인지 나눠 본다. 지시문 v2에서 세 회차가 첫 묶음보다 더 갈리거나 구조 검증 실패가 늘면 v2 변경을 다시 본다.
