# 중심 이야기 기반 두 단계 골드 생성 실험

## 결정

[D-0094](./D-0094-source-jev-gold-flow-stopped.md)에 따라, 중심 이야기 기반 L1·L2 공동 생성([D-0073](./D-0073-current-gold-generation-name.md))을 기반으로 다음 두 단계 생성을 별도 실험으로 시험한다.

1. **중심 이야기 보강(문단당 1회):** 기존 중심 이야기, 대상 문단 원문(코드가 문장 단위로 나눠 번호를 붙인 것), 지문 문맥을 입력한다.
   - 모델은 빠진 핵심 관계·정의·조건만 보충한다. 부수 세부는 넣지 않는다.
   - 보충마다 근거가 된 원문 구절을 정확히 인용한다.
   - 문단 기능(도입·정리·일반, 불확실하면 일반)을 판정한다.
   - 원문의 각 문장을 실질 설명 단위나 소개·연결에 배정한다.
   - 기존 문장은 지우거나 바꾸지 않고 덧붙이기만 한다. 이는 코드로 검사한다.
2. **축 생성(문단당 1회):** 보강된 중심 이야기로 기존 생성 지침(candidate-2)에 따라 L1·L2를 만든다.
   - 일반 문단이고 실질 설명 단위가 2개 이상이면 최소 2축을 두며, 이 규칙은 기존의 묶음 규칙보다 우선한다.
   - 원문은 이 단계에 넣지 않는다.

**범위와 운용:**
- 대상: mRNA를 제외한 5지문 25문단 전체. 최대 50회 호출, 재시도 없음.
- 결과는 별도 실험 폴더에만 저장한다. 운영 골드(`conditional-meta-gold-v1`)와 개발자 UI 자산은 바꾸지 않는다. 교체 후보로 올릴지는 사람 검토 뒤 따로 결정한다.
- 진행 순서: Claude가 인계 문서 작성 → Codex 구현·API 없는 사전 검증 → Claude가 diff 검토 → 전송 승인을 따로 받은 뒤 실행([D-0092](./D-0092-claude-codex-work-division.md)).

## 근거

- 사용자 명료화 답변(2026-10-07): "5지문 25문단 전체 재생성", "두 단계 생성 방식으로 진행", "별도 실험으로 진행", "그 순서로 진행".
- 운영 골드의 약점(`docs/experiments/axis-auto-merge-audit-five-passages-2026-10-02/OPERATIONAL-VS-AUDIT.md`, Claude 의견):
  - 중심 이야기를 거치며 정의·조건·기전이 빠졌다.
  - 본론 문단 1축이 여럿이어서, 1축은 도입·정리 문단 정도로 제한적이라는 사용자 원칙과 맞지 않는다.
  - 생성 지침의 묶음 규칙(인과사슬 한 축, 원리와 적용 한 축 등)이 1축 문단을 만드는 원인으로 보인다.
- 사람 판정(`docs/experiments/axis-audit-v2-min-two-2026-10-06/HUMAN-REVIEW.md`): 표면 장력3·정보 비대칭2는 1축이 적당하고, 공손룡3은 경계다.

## 폐기한 대안

- 원문 직접 한 번 생성: 이전 시험에서 사람 경계와 완전히 일치한 문단이 8개 중 1~3개로 불안정했다.
- 원문과 중심 이야기를 한 호출에 넣는 방식: 모델이 중심 이야기를 건너뛰고 원문을 바로 쪼갤 위험이 있다.
- 기존 축 위에 분할까지 허용하는 감사기: 단계를 쌓는 구조를 반복한다.
- 7문단만 재생성: 원문 대조로 세부를 복원하는 효과를 2축 이상인 문단에서 볼 수 없다.

## 재검토 조건

- 보강 단계가 부수 세부를 반복적으로 추가하거나, 축 L1이 크게 길어져 요구 범위를 넓힐 때
- 문장 배정이 실질 설명을 소개·연결로 반복해서 잘못 분류할 때
- 최소 축 규칙이 같은 질문을 억지로 나누는 사례가 사람 검토에서 반복될 때
