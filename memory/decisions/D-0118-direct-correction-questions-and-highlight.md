# 교정 질문은 더 직접적으로, 근거 구절은 지문에 표시한다

## 결정

사용자 확정(2026-10-13, UI 메모장 7·12번)이다. 상세는 `docs/review/v4-dev-ui-feedback-backlog-2026-10-11.md`의 "7번 상세" A·B에 있다.

1. **질문 작성 규칙(판정 지시문).**
   - 학생이 틀린 그 주장을 직접 겨냥한다. 학생이 말하지 않은 전제를 대신 묻지 않는다.
   - 추상적인 분류 대신 지문의 구체적인 사실과 낱말로 묻는다.
   - 형식은 학생 주장에 따라 두 갈래 질문(학생 생각 / 원문 사실) 또는 짧은 직접 질문이다.
   - 정답 번호와 정답 선지 문장을 넣지 않는 것, 다른 선지를 지워 정답을 좁히지 않는 것은 유지한다.
   - [D-0105](./D-0105-correction-question-covers-choice-deciding-relation.md)(선지 정오를 가르는 관계까지 한 질문으로)는 유지한다.
2. **근거 구절 표시(화면).**
   - 교정 질문 단계에서 지금 묻는 오류의 원문 근거 인용을 지문·보기에 미색으로 칠하고 그 위치로 스크롤한다.
   - 화면에는 위치만 보낸다.
3. **감수.** 정답·오류 정보가 더 드러나고 두 갈래는 찍어서 맞힐 수 있다. 교정 성공을 이해의 증거로 읽지 않는다.

4. 구현(2026-10-13): 인계 `docs/handoffs/2026-10-13-v5-direct-questions-highlight-unverifiable-note.md`. Claude diff 검토를 통과했고 테스트는 442/442다. 실모델 확인 전이다.

## 근거

- 사용자 직접 사용(2026-10-12): 교정 질문이 해석하기 어려웠다. 예: "의무가 이미 부과된 대상과 추가로 제안된 대상 중 어느 쪽"이라는 추상 분류로 물었다. 사용자는 "AI로 제품을 사용했나, 광고했나" 같은 직접 질문을 제안했다.
- [48세션 재검토](../../docs/experiments/v5-diverse-48-2026-10-12/REVIEW-claude.md) 3절 I-A1: 학생이 말하지 않은 전제를 물었다.

## 보완: 원문 기준이 아닌 이유를 든 경우 (2026-10-13, 사용자 "수정안의 규칙엔 동의 … 예시는 삭제", 검토 항목 12)

- 실모델 시험에서 V-I(I-A1 근거 "과장 광고니까 걸릴 것 같아요")의 질문이 3/3 학생 이유를 건너뛰고, 선지를 가르는 다음 사실(플랫폼 의무가 시행 중인지)만 물었다.
- 질문 규칙에 다음 문장을 넣었다. 예시는 과적합을 막기 위해 넣지 않는다(사용자 지시).
  > 학생이 원문이 기준으로 삼지 않은 이유를 판단 근거로 들었으면, 원문이 실제로 무엇을 기준으로 삼는지를 학생의 이유와 나란히 놓고 묻는다. 학생의 이유를 건너뛰고 선지를 가르는 다음 사실만 묻지 않는다.
- 재시험(`docs/experiments/v5-live-check-2026-10-13-r5/`, 17세션, 0.59달러):
  - V-I 3회 중 2회는 "과장 광고라는 점만으로 정해질까, 플랫폼에 의무가 부과됐는지 확인해야 할까?"처럼 학생 이유와 원문 기준을 나란히 놓았다.
  - 1회는 여전히 의무 대상만 물었다.
  - 회귀 확인에서 R 7/8 질문과 F군 A2·A3·B2 질문은 이전과 같은 대상을 겨냥했다. 자동 검사 위반은 0건이다.

## 다시 볼 조건

- 실모델 확인에서 정답 누출이나 선지 좁히기가 늘거나, 표시 위치가 질문과 맞지 않는 경우가 반복되면 재검토한다.
