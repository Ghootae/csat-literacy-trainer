# 첫 집중 타겟은 상위권 중등

## 결정

사용자가 제시한 타겟(문해력을 걱정하는 중등 학부모, 일찍 수능을 완성하려는 상위권 중등, 고1 일반)
가운데 첫 단계는 상위권 중등에 집중한다. 이에 따라 지문 레벨을 고1 학평 모의고사까지 넓힐 필요가
있다는 데 합의했으나 작업 범위·시점은 정하지 않았다(사용자: 실제 작업은 나중).

## 근거

- 사용자 결정(2026-10-14): "상위권 중등에 먼저 집중하자."
- 사용자 판단: 고3은 이런 훈련을 하기에 너무 바쁘다. 마케팅 구상은 "6개월 훈련 뒤 중3 수능 1등급".
- Claude 의견: 현재 콘텐츠(수능 비문학 6지문)와 가장 맞고, 문해력 걱정 집단은 수능 지문이 첫 진입
  장벽이라 낮은 난도 사다리가 먼저 필요하다.

## 폐기한 대안

- 세 집단 동시 대응: 문해력 걱정 집단에는 지금 콘텐츠 난도가 맞지 않는다.
- 고3 중심: 사용자 판단으로 제외.

## 재검토 조건

외부 학생 검증에서 상위권 중등의 이탈·난도 부적합이 확인되거나, 학부모·학원 채널이 다른 집단을
먼저 요구할 때.
