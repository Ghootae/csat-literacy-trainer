Q-0028 후속 설계(2026-10-01): [D-0049](./decisions/D-0049-stem-polarity-normalization-deferred.md)로 발문 극성을 세션 시작 시 한 번 정규화하고, 선택이 뜻하는 판정·학생 추론·근거의 파생 결론·내용 정확성을 분리하기로 했다. 설계만 승인했으며 다른 문제 풀이 수정 사안과 함께 구현하기 전까지 현행 v3 동작을 유지한다.

Q-0029 후보 기록(2026-10-01): [D-0050](./decisions/D-0050-reasoning-reconstructability-gate-deferred.md)으로 주장·관계·충돌을 먼저 보존하고, 일관된 경로일 때만 선지 결론을 파생하는 게이트를 후속 구현 후보로 채택했다. 파편적·모순적·복수 해석이면 결론을 `UNKNOWN`으로 보류한다. 상태명은 후보이며 D-0049와 같은 수정 묶음에서 구현할 때 확정한다.
