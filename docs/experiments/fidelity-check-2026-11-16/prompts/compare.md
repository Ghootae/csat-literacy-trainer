# 구조 충실도 비교

생성된 수능 독서 지문 한 편이 목표로 한 짜임(하위 구조)대로 쓰였는지 판정한다. 비유하면, 설계도를 모르는 검사관이 지문을 보고 그린 평면도(구조 추출)를 설계도(목표 하위 구조)와 겹쳐 보는 일이다. 글의 질, 사실의 정확성, 문항을 낼 여지는 판정하지 않는다.

## 입력
- 1차 유형 목록: 코드, 이름, 하는 일.
- 목표: 1차 유형(코드, 이름, 하는 일, 가르는 기준)과 하위 구조(code, name, array, axes, issue_logic, choose_when, hooks). array는 수능 기출에서 끌어낸 문단 기능의 추상적 배열이다. "×n"은 그 기능이 한 문단 이상 이어질 수 있다는 뜻, 괄호는 두 번째 기능, "…"는 아무 기능이나 올 수 있는 자리다.
- 평면도: 목표를 모르는 분석기가 생성 지문에서 뽑은 구조. 글 전체의 목적과 논리(화제어 없이), 중심 물음이 처음 드러나는 문단, 문단마다 말하고자 하는 바(point), 내용의 움직임(move), 통일 어휘 기능(label, label2), 구조 특징(여는 방식, 깔아 두는 곳, 펼치는 순서, 규칙·식·범위, 사례, 끝맺음, 그 밖), 만나는 곳, 비워 둔 곳.
- 코드 대조: 문단 라벨 배열과 array를 코드로 정렬한 결과. 라벨 글자만 본 것이라 참고용이다. 라벨이 달라도 하는 일이 같으면 맞음으로, 라벨이 같아도 하는 일이 다르면 바뀜으로 고쳐 판정한다.

## 할 일
1. array의 요소마다 생성 지문의 어느 문단이 그 일을 하는지 찾고, 맞음 / 바뀜 / 빠짐 중 하나를 붙인다. 문단 수와 ×n의 반복 횟수는 달라도 된다. 요소의 순서가 뒤바뀌었으면 바뀜이다.
   - 맞음: 그 자리에서 그 기능을 하는 문단이 있다.
   - 바뀜: 그 자리에 문단은 있으나 하는 일이 다르거나, 순서가 다르다.
   - 빠짐: 그 일을 하는 문단이 없다.
2. array의 어느 요소에도 대응하지 않는 문단이나 문단 안의 덩어리는 덧붙음으로 적는다. 무슨 일을 하는지, 그것이 짜임을 바꾸는지(큰 전개의 순서나 끝맺음, 판정의 자리를 바꾸는지) 적는다. 한두 문장짜리 연결이나 배경은 덧붙음으로 적되 짜임을 바꾸지 않는다고 적는다.
3. axes의 축마다 평면도의 값이 같은지 판정한다. 같음 / 다름 / 판단 어려움. 다르면 평면도에서는 어떤지 한 문장으로 쓴다.
4. hooks(만나는 곳과 비워 둔 곳이 놓이는 자리)가 평면도의 만나는 곳·비워 둔 곳과 맞는지 판정한다. 같음 / 일부 / 다름.
5. 종합 판정을 하나 고른다.
   - 따름: 배열의 요소가 모두 맞음이고, 축이 모두 같거나 판단 어려움이며, 짜임을 바꾸는 덧붙음이 없다.
   - 대체로 따름: 이 하위 구조를 같은 유형의 다른 하위 구조와 가르는 요소와 축은 맞다. 바뀜·빠짐·짜임을 바꾸는 덧붙음이 합쳐 한 곳 이하다.
   - 절반: 앞부분이나 뒷부분 가운데 한쪽은 따르지만, 이 하위 구조를 가르는 요소나 축 가운데 하나 이상이 다르거나, 짜임을 바꾸는 덧붙음이 있다.
   - 따르지 않음: 배열의 뼈대가 다르다. 다른 하위 구조나 다른 유형의 짜임에 더 가깝다.
6. 목표와 다르게 쓰인 부분이 1차 유형 목록의 다른 유형이 하는 일을 닮았으면 그 유형 코드와 이유를 적는다. 없으면 null.

## 규칙
- 판정의 근거로 문단 번호를 든다. 생성 지문의 문장을 옮기지 않는다.
- 평면도가 틀렸을 수 있다. point와 move가 label과 어긋나면 point와 move를 따른다. 그래도 판단이 어려우면 notes에 적는다.
- 지어내지 않는다. 평면도에 없는 것은 "판단 어려움"으로 둔다.

  "additions": [ { "paragraphs": ["문단 번호"], "what": "하는 일", "changes_structure": true, "why": "한 문장" } ],
  "axes": [ { "axis": "축 이름", "target": "목표 값 요약", "status": "같음|다름|판단 어려움", "actual": "다르면 평면도의 값 한 문장, 아니면 null" } ],
  "hooks": { "status": "같음|일부|다름", "why": "한 문장" },
  "verdict": "따름|대체로 따름|절반|따르지 않음",
