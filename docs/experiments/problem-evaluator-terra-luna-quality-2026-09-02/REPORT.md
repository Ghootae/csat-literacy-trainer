# 전체 골드 Terra–Luna 품질 우선 비교 보고서

실행일: 2026-09-02

## 목적

오리지널 전체 골드를 사용하는 근거 판정에서 `gpt-5.6-luna / medium`이 `gpt-5.6-terra / medium`보다 품질이 낮지 않은지 먼저 검증하고, 품질 결과가 확인된 뒤 토큰·비용·지연을 비교한다.

## 수행 작업

- 원본 5문항 `c-gold.json`은 수정하지 않았다.
- 전체 골드에서는 기존 `itemInference`를 가능한 모든 경로의 완전 목록으로 취급하지 않고, 승인 원문·보기 사실만으로 성립하는 대안 경로도 인정하는 코드 소유 `sufficiencyPolicy`를 추가했다.
- 학생이 핵심 인과와 선택 결론을 명시했다면 중간 용어를 그대로 재현하지 않아도 인정하고, 정확 핵심과 틀린 비결정 부가 설명은 별도 finding으로 평가하도록 정책을 고정했다.
- 기존 6개 위험 유형·7개 프로브를 각 3회 사용했다. 동일한 전체 골드·학생 근거·프롬프트를 Terra와 Luna에 각각 21회 입력해 총 42회를 실행했다.
- 우선순위는 기대 assessment, anchor별 관계·결정성·필수 source ref, 상세 통과, 계약 오류 순으로 고정했다. 비용과 지연은 그 뒤에 비교했다.
- 가격은 2026-09-02 공식 단가인 Terra 입력/캐시 입력/출력 `$2.00/$0.20/$12.00`, Luna `$0.20/$0.02/$1.20` per 1M tokens를 사용했다. [Terra 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-terra), [Luna 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-luna)

## 결과

### 품질

| 지표 | Terra medium | Luna medium |
|---|---:|---:|
| 기대 assessment | 19/21 | **20/21** |
| 기대 anchor finding | 20/21 | 20/21 |
| assessment+finding 상세 통과 | 19/21 | **20/21** |
| 계약·전송 오류 | 0 | 0 |

- 두 모델은 assessment 20/21쌍, finding signature 20/21쌍이 같았다.
- 대안 표현, 정확 핵심+틀린 부가 설명, 관련 비결정 사실, 복수 전제 일부 누락, `CONTRADICTS`와 `DOES_NOT_JUSTIFY` 구분은 두 모델 모두 전부 통과했다.
- 차이는 수소 신규 대안 경로 한 유형에만 있었다. `전환율 차이 + 공통 2:3 몰비`를 Terra는 1/3, Luna는 2/3 인정했다.
- 두 모델 모두 첫 반복에서는 부반응을 별도 필수 조건으로 요구해 `INSUFFICIENT`로 판정했다. Terra는 두 번째 반복에서도 같은 이유로 실패했고, Luna는 두 번째·세 번째 반복에서 대안 경로를 정확히 인정했다.
- Luna가 이번 표본에서 한 건 더 정확했지만 표본이 21회이고 차이가 한 유형의 반복 변동에 집중되어 있으므로, 품질 우위가 확정됐다고 해석하지 않는다. 다만 Luna가 Terra보다 열등하다는 증거는 없었다.

## 다음 작업 추천

품질 우선 기준에서 Luna는 후속 검증 후보로 충분하지만 아직 운영 모델을 교체하지 않는 편이 안전하다.

1. 결과가 갈린 수소 신규 대안 경로를 모델별 최소 10~30회 반복해 1/3 대 2/3 차이가 실제 안정성 차이인지 확인한다.
2. 기존 일반 30개 정답·대표 오답 프로브도 전체 골드로 Terra와 Luna에 같은 입력을 주어 Luna가 쉬운 기준선을 유지하는지 검증한다.
3. Luna의 더 긴 출력이 품질에 필요한지 확인하고, finding 수와 reason 길이를 제한해도 품질이 유지되는지 별도 실험한다.
4. assessment와 필수 source-ref 품질이 Terra보다 낮지 않고 신규 근거 반복 안정성도 확보될 때 Luna로 운영 전환한다.
