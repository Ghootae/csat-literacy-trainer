# v5 다양한 수준·경로 48세션 실제 피드백 기록

사용자 확정(2026-10-12): 최신 v5, 앱에 연결된 6문항 전부, 문항마다 정답·근거 불충분 2세션과 오답 선지 2개×각 3세션, 최초 피드백부터 종료까지 기록. 사용자가 사례 구성을 Codex에 맡겼으며 마지막으로 “직접 진행”하여 이번 실험의 별도 Claude 인계 없이 직접 구성·실행하는 예외를 승인했다. 기존 인계의 17경로 시험 재실행이 아니다.

## 실행 조건

- `loadProblemSolvingBundle`이 현재 앱에서 읽는 원문·보기·선지·정답·공식 해설·기호 범위·원자료 이미지를 그대로 사용한다. 구조화 문제 골드와 기호 해석본은 넣지 않는다.
- 실제 `ProblemFeedbackV4Controller`와 기본 `OpenAIFeedbackEvaluator`를 사용한다. 선택 정답 luna / 오답 sol, REPAIR luna, 종료 설명은 마지막 선택 정오에 따라 배정, 모두 medium. 모델 덮어쓰기는 하지 않는다.
- 소스와 빌드 산출물을 함께 해시 고정한다. 코드·지시문·제품 변경, 커밋·푸시는 범위 밖이다.
- 최초 48개 학생 응답과 후속 행동 의도는 API 전 `CASES.json`에 고정한다. 같은 입력의 반복 안정성 시험이 아니라 서로 다른 48개 가상 학생 세션이다.
- 후속 학생 답은 실제로 제시된 질문을 읽은 Codex가 사례 의도에 맞게 직접 작성한다. 작성한 답·대응 질문·작성 이유를 actions 파일과 세션 단계에 남긴다. 학생 응답 생성용 추가 API는 호출하지 않는다.
- 경로를 강제로 만들거나 판정을 교체하지 않는다. 예정과 다른 판정·질문·종료를 보존하고 그 상태에서 허용되는 실제 명령만 보낸다. ITEM_REVIEW는 시스템이 정한 검토 종료로 남긴다.
- 평가 오류는 원자료와 함께 기록한다. 기본 평가기 재시도 후 실패한 제출은 RESUME으로 평가만 재개한다. 성공한 과거 제출은 기록된 모델 호출을 재생하여 실행기 상태를 복원하므로 재개 때 같은 제출을 다시 과금하지 않는다. 런타임 세션 ID는 재생 복원마다 달라지고, 지속 식별자는 사례 ID이다.

## 문항당 구성

| 사례 | 최초 수준 | 후속 행동 의도(실제 분기에 따라 적용) |
|---|---|---|
| CT | 정답·관련 소재만 언급 | 질문 시 내용 없는 답 |
| CP | 정답·관련 사실이나 법칙만 언급 | 질문 시 국소 보완·설명 요청 |
| A1 | 오답 A·막연한 근거 | 질문해도 확인 불가 |
| A2 | 오답 A·명시적 오류 | 국소 수정·정답과 충분 근거 재선택 |
| A3 | 오답 A·복합 오류 | 첫 오류는 수정하되 다음 오류 유지 |
| B1 | 오답 B·근거 없음 | 근거 요청에도 미제출 |
| B2 | 오답 B·명시적 오류 | 짧게 수정·코칭 요청 |
| B3 | 오답 B·옳은 판단과 선택 행동의 충돌 | 불일치 인정·재선택도 오답 |

A3가 첫 질문에서 여러 오류를 함께 묻거나 나중 질문이 생기지 않으면 실제 질문 범위와 실제 종료를 기록한다. 같은 후속 문구를 다른 질문에 무조건 재사용하지 않는다. B3는 내용 오해와 선택 행동의 차이를 확인하는 사례다.

## 기록과 확인

`sources.json`, `CASES.json`, `FROZEN.json`, `actions/`, 사례별 상태 JSON·전체 원장 JSONL, 요청 JSON·원응답 JSON, START/END 요청 원장, `RESULTS.json`, 전체 대화 기록, 요약 보고서를 남긴다. 원문과 학생 주장 보존, 국소 교정, 재선택과 종료 코칭은 각각 검토한다. 최종 정답이나 프로그램 통과를 이해 교정의 증거로 대신 쓰지 않는다.

호출 제한은 sol 160요청·추정 8달러, luna 240요청·추정 1달러다. 단가는 이전 실행기와 같은 입력/출력 sol 2/10, luna 0.10/0.50 달러/100만 토큰이며 캐시 할인 없이 계산한다. 현재 청구 단가를 재확인한 금액이 아닌 실행 기록용 추정치다. 실패 요청은 비용 미확정으로 예약액을 별도 보존한다.

합성 학생의 후속 응답은 실험자가 질문과 원문을 보며 작성한다. 따라서 실제 학생 회복률·학습 효과·운영 품질 비율을 측정하는 시험이 아니다. 사람(Codex)의 의미 검토는 모델의 자동 판정과 분리하여 기록한다.

## 실행 일정 보완

최초 평가는 세션별 순차 실행했다. 후속 단계는 `scripts/run-v5-diverse-48-concurrent.mjs`로 독립 세션 최대 2개를 함께 진행한다. 각 세션 내부 순서·저장된 평가 재생·운영 모델·입력·지시문은 그대로이며, START/END와 한도 판정은 같은 메모리의 공용 원장 하나가 담당한다. 첫 요청을 예약하기 전 두 번째 요청을 허용하지 않는 모의 테스트 1/1 통과. 파일 해시는 `CONCURRENT-RUNNER.json`에 별도로 고정한다. 순차 최초 평가와 동시 후속 평가의 대기 시간을 동일한 실행 조건의 속도 비교로 취급하지 않는다.
