# 실제 모델 호출 전송 범위

## 목적지와 본문

- 목적지: `https://api.openai.com/v1/responses`. 현재 `.env`를 적용하여 생성한 SDK client의 `baseURL`을 확인했다(값만 출력, 키와 `.env` 본문은 출력하지 않았다).
- 모델: 기존 운영 코드가 배정하는 `gpt-6-luna`와 `gpt-6.1-sol`, reasoning medium, `store:false`.
- 보내는 내용: 이 저장소의 v5 판정 지시문 또는 종료 설명 지시문, 앱에 연결된 6문항의 원문·발문·보기·선지·정답·공식 해설·기호 위치, mRNA 보기의 원자료 이미지 URL 1개, Codex가 작성한 가상 학생 응답, 해당 가상 대화의 오류 기록·질문·교정 답변 등 운영 입력.
- 이 요청의 입력에는 실제 학생 대화나 실제 학생 개인정보가 없다. 저장소 코드 파일·Git 기록·다른 실험 결과·`.env` 파일 본문은 모델 입력에 포함하지 않는다. API 키는 SDK 인증에 사용된다.
- 실제 전송 본문 예시는 `requests/*.request.json`, 최초 학생 입력 48개는 `INPUT-PREVIEW.md`, 원문 묶음은 `sources.json`, 운영 지시문은 `packages/pipeline/experiments/problem-solving/source-direct-problem-feedback-v5.md`에서 검토할 수 있다.

## 호출과 비용

48개 세션을 최초 피드백부터 종료까지 진행하므로 요청은 48회로 고정되지 않는다. 최초 판정·교정·재선택·종료 설명·계약 재시도에 따라 추가 요청이 발생한다. 실행기의 전체 상한은 sol 160요청·추정 8달러와 luna 240요청·추정 1달러다. 예산은 과거 저장소 단가를 사용한 실행기 추정이며 실제 청구를 보장하는 금액이 아니다.

샌드박스 첫 시도는 42개 모델 요청 시도가 모두 `Connection error.`로 닫혔고 응답은 0개였다. 6개 근거 미제출 세션은 모델 호출 전 근거 요청 단계에 있다. 실패한 요청의 예약 비용 추정 합계 4.5556066달러는 실제 지출이 아니며, 사용량이 없는 실패 요청의 비용 불확실성을 보수적으로 남긴 값이다.

## 자동 승인 검토 차단

네트워크 재개 명령이 자동 승인 검토에서 거절되었다. 사유: 48개 외부 요청이 사적인 지문/프로젝트 자료를 전송할 수 있으나, 사용자 승인은 v5 실행에 관한 것이며 구체적인 payload와 외부 목적지 전송에 대한 승인으로 인정되지 않았다는 판단이다.

우회 실행하지 않았다. 위 전송 범위를 사용자에게 확인한 뒤 동일한 실행기를 재개해야 한다. 이미 수락된 학생 제출은 RESUME으로 평가만 재개하며 최초 학생 답을 다시 입력하지 않는다.

사용자 승인(2026-10-12): 위 목적지·자료·전체 실행·추정 상한을 명시한 요청에 사용자가 “승인”으로 답했다. 승인된 범위로 같은 실행기를 재개한다.
