# 정답 근거 충분성 경계 Luna 검증

## 목적

정답 근거의 `SUPPORTED` 허용 범위를 세 경로로 고정하고, 수소 C4를 위한 문구 예외가 아니라 일반적인 충분성 경계로 Luna medium의 안정성을 검증한다.

- 승인된 충분 근거 집합
- 의미적으로 동일한 압축 인과관계
- 승인된 완전 제거 경로

선택 결론 재진술, 연결되지 않은 관련 사실 하나, 일부 경쟁 선지 제거, 출처 없는 `MATCHES`는 단독 근거로 인정하지 않는다.

## 수행 작업

- 모델 입력의 `sufficiencyPolicy`에 허용 경로 3종과 단독 불인정 유형 4종을 코드 소유 값으로 추가했다.
- 대표 `itemInference`는 가능한 모든 유효 경로의 체크리스트가 아니며, 학생이 말한 승인 전제만으로 결론이 성립하면 다른 대표 전제를 추가 요구하지 않도록 프롬프트를 보강했다.
- candidate 골드의 완전성이나 문항 타당성을 학생 근거 판정 단계에서 재감사하지 않도록 결정권 경계를 재확인했다.
- 수소 C4의 원 응답·대안 압축·단일 관련 사실·부분 제거·결론 재진술과 승인된 완전 제거 경로를 대조했다.
- 최초 수소 완전 제거 사례는 C5의 `DOES_NOT_JUSTIFY`를 직접 반박으로 취급해 승인된 경로가 아니었다. 이를 FTA C1에서 C2~C4의 비함의와 C5의 직접 모순으로 네 경쟁 선지를 모두 제거하는 유효 사례로 교체했다.

## 실행 결과

Luna medium으로 6개 논리 프로브를 각 3회씩 두 번 실행했다.

| 실행 | assessment | 기대 finding | 상세 | 오류 | 게이트 |
| --- | ---: | ---: | ---: | ---: | --- |
| v1 | 10/18 | 14/18 | 9/18 | 0 | 실패 |
| v2 | 14/18 | 13/18 | 13/18 | 1 | 실패 |

v2의 프로브별 assessment는 다음과 같다.

| 프로브 | 기대 | 결과 |
| --- | --- | ---: |
| 수소 C4 원 압축 | `SUPPORTED` | 2/3 |
| 수소 C4 대안 압축 | `SUPPORTED` | 1/3 |
| 관련 사실 하나 | `INSUFFICIENT` | 3/3 |
| 일부 경쟁 선지 제거 | `INSUFFICIENT` | 3/3 |
| 선택 결론 재진술 | `INSUFFICIENT` | 3/3 |
| FTA 승인 완전 제거 | `SUPPORTED` | 2/3, 계약 오류 1회 |

거부 경계는 총 9/9로 안정적이었다. FTA 완전 제거도 세 원출력 모두 최종 판단은 `SUPPORTED`였지만, 한 번은 학생의 “경로를 반대로 썼다”라는 올바른 메타 판단을 `CONFLICTS`로 잘못 라벨링하여 런타임 계약 검증이 거부했다.

수소 C4 대안 압축의 첫 실행은 올바르게 `SUPPORTED`였고 두 개의 결정적 `MATCHES`와 실제 출처를 제시했다. 다만 채점 corpus가 결론 문자열 자체를 finding으로 요구해 상세 실패로 센 것은 finding anchor의 위음성이다. 이 오류를 제외해도 assessment가 1/3이므로 게이트 실패 결론은 바뀌지 않는다.

Luna는 같은 승인된 전환율 비교와 2:3 화학량론 경로를 한 번은 충분하다고 보고 두 번은 부반응 전제가 빠졌다고 판단했다. 원 C4에서도 같은 변동이 2/3 발생했다. 즉 불충분 사례 거부는 안정적이지만 압축된 정답 근거 인정은 현재 Luna medium에서 안정적이지 않다.

두 실행의 캐시 반영 추정 비용은 각각 `$0.036632`, `$0.030809`, 합계 약 `$0.067440`이다.

타입 빌드, 관련 계약 테스트 8/8과 `git diff --check`가 통과했다. 전체 회귀는 649/650이 통과했고, 유일한 실패는 기존부터 누락된 Hegel `.omc` 실험 산출물을 직접 읽는 무관한 테스트다.

## 판정

충분성 계약 구현은 완료됐지만 Luna 경계 게이트는 실패했다. 품질 우선·조건부 실행 순서에 따라 기존 표적 24회, Luna 기본 60회, Terra 60회와 60쌍 비교는 실행하지 않았다.

수소 문구를 직접 예시로 주어 통과시키는 추가 프롬프트 수정은 과적합 위험이 크다. 다음 실험은 동일 계약에서 Terra가 이 18회를 안정적으로 판정하는지 비교하거나, 모델이 판정할 sufficient set을 사람이 명시적으로 골드에 추가하는 방향이 적절하다.
