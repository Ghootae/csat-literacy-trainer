## 해석

1. 과학·기술 생성 지문에서는 지문의 결론 문장이 정답 선지의 반대말 또는 재진술로 연결되는 사례가 반복된다. 같은 생성기로 기출 지문에 문항을 만들었을 때보다 7/12 대 3/12라는 기존 분류와 방향이 맞는다. 지문 구조를 맞췄지만 주제·내용·골드 지도도 다르므로 과설명의 인과 효과가 입증되었다고 쓰지 않는다.
2. 법 생성 지문은 4/4가 직접 정리 문장 유형이 아니고, B-V2는 다단계 적용 사례다. 그러나 A-V1·A-V2의 법정 철회권 범위 착각 중복과 4-solve 검사 이슈는 문항 묶음의 다양성 검토를 요구한다. 정답 깊이와 세트 다양성을 구분한다.
3. 실제 기출도 도플러 11⑤처럼 직접 대조형을 포함한다. ‘기출은 모두 복잡하고 생성은 모두 단순하다’는 결론은 자료와 맞지 않는다.
4. 현재 자료는 출제 문항의 논리·표현 검토다. 학생 변별력·난이도·학습 효과는 측정하지 않았다.
