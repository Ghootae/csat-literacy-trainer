# 3.3 판정: 생성 지문 vs 기출 지문, 같은 문항 생성기(deep-item v4.1) (2026-11-17, 웹 Claude 1인 판정)

기준은 정답 선지(변별을 맡은 선지)만 본다.
- 문단: 정답 판정에 이어야 하는 지문 문단 수
- 정리 문장: 지문의 정리·대조 문장 하나를 찾아 옮기면 풀리나 (예/아니요)
- 설계 문제: 생성기 4-solve의 자동 설계 검사 건수(〈보기〉만으로 풀림, 함정 중복 등)

## 결과 요약

| 짝 | 생성 지문 정리 문장 "예" | 기출 정리 문장 "예" | 설계 문제 (생성 / 기출) |
|---|---|---|---|
| S1-1 혈액 응고 / 도플러 혈류계 | 3/4 | 1/4 | 3 / 1 |
| S5-3 수돗물 소독 / mRNA 백신 | 4/4 | 2/4 | 7 / 2 |

평균 이어야 할 문단 수는 생성 1.9, 기출 1.6으로 차이가 없다(청약 철회가 날짜 계산 문항으로 끌어올림). 풀이 일치는 24/24.

## 해석
- 과학·기술(T1, T2) 생성 지문은 과설명이 문항을 얕게 만든다. 정답 선지가 지문의 정리 문장과 거의 그대로 맞물린다. 예: T1 "효소는 … 소모되는 재료가 아니므로 여러 기질 분자에 잇따라 작용"(2문단) → A-V1 정답, "피브린은 효소가 아니라 구조물을 이루는 재료"(5문단) → A-V2 정답, T2 "예상되는 염소 소모를 반영하여 투입량을 조절"(6문단) → B-V1 정답.
- 법(T3)은 차이가 없다. 정리 문장이 있어도 규칙을 사례에 적용(유형 판별, 기간 계산)해야 해서 문항이 얕아지지 않았다.
- 생성 지문 쪽 자동 설계 문제가 3배다. 〈보기〉만으로 풀리거나 V1·V2가 같은 착각을 겨누는 일이 잦다 = 지문이 함정 거리를 적게 남긴다.
- 결론: 계획의 판정 기준("정리 문장으로 풀림이 뚜렷이 많으면 과설명이 원인")에 해당한다. 단 과학·기술형에 한정된 신호다.
