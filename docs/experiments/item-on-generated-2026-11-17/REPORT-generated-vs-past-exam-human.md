# 생성 문항과 실제 기출 비교 — 인간 보고서 (2026-11-17)

## 1. 개요

### 목적

생성 지문 3편에서 만든 깊은 〈보기〉 문항 12개가 실제 기출의 〈보기〉 문항과 얼마나 가까운지 살폈다. 주 비교인 **같은 생성기·다른 지문** 24문항 판정은 [JUDGE.md](./JUDGE.md)에 이미 있다. 이번 비교는 계획의 부가 과제인 **생성기 문항·실제 사람 출제 문항** 비교다. 출제자와 지문이 동시에 달라지므로 원인 실험으로 읽지 않는다.

### 결과

- **기출에 가까운 가능성:** 생성 청약 철회 B-V2는 거래 유형, 철회 기간, 반환 비용을 연달아 판단하게 한다. 혈액 응고 B-V2도 앞 단계의 촉매와 뒤 단계에서 직접 작용하는 물질을 구분하게 한다.
- **주된 차이:** 혈액 응고 A-V1·A-V2, 수돗물 소독 A-V1·B-V1은 정답을 가르는 관계가 지문 속 설명 문장에 이미 가깝게 적혀 있다. 실제 기출 mRNA 19번은 혼합·투석이라는 새 공정에 지문의 pH 규칙을 적용하고, 소수성에 관한 별도 설명까지 대조해야 한다.
- **기출도 모두 깊은 것은 아니다:** 도플러 11번 정답 ⑤는 지문의 산란체 크기 규칙을 사실상 반대로 쓴 선지다. 따라서 기출이라는 이유만으로 문항마다 생성 문항보다 깊다고 보지 않았다.
- **판정 제한:** 실제 기출 〈보기〉 4문항(도플러 11·12번, mRNA 19번, 공시 의무 12번)과 생성 지문 문항 12개를 비교했다. 정답 일치 24/24는 생성 문항의 기본 일관성이지 학생 변별력 증거가 아니다. 학생 풀이 자료는 없다.

### 다음 스텝

과학·기술 지문의 정리 문장을 덜 직접적으로 쓰는 **새 지문 조건**을 별도로 만들어, 현재 지문 조건과 같은 생성기로 비교한다. 기존 24문항과 동결 지도를 기준 조건으로 재활용할 수 있는지 지시문·모델·입력 일치를 먼저 확인한다. 현행 생성기 지시문이나 지문 규칙을 이번 판정만으로 바꾸지는 않는다.

## 2. 본문

### 비교 범위와 읽는 기준 (해결)

| 지문 짝 | 생성 지문 문항 | 실제 기출 〈보기〉 | 생성기·기출 지문 대조 문항 |
|---|---:|---|---:|
| 혈액 응고 / 도플러 혈류계 | A·B 각 V1·V2, 4개 | 11번(경로 도식), 12번(도플러 변위 그래프) | 4개 |
| 수돗물 소독 / mRNA 백신 | 4개 | 19번(복합체 제조 공정·도식) | 4개 |
| 청약 철회 / 공시 의무 | 4개 | 12번(회사·임직원·정보수령자 사례) | 4개 |

정답 선지에 대해 ① 지문 문단을 어떻게 적용하는지, ② 〈보기〉를 다시 해석해야 하는지, ③ 지문의 정리 문장 하나로 판단 가능한지를 보았다. 그림은 원자료의 로컬 이미지까지 확인했다. 문단 개수는 보조 지표다. 그래프의 부호 전환이나 법적 지위 판별은 한 문단을 써도 단순 옮기기와 다르다.

### 과학·기술: 결론 재진술과 새 자료 해석의 차이 (해결)

**혈액 응고 A-V1 정답 ④**는 복합체가 한 개 소모될 때마다 활성 제X인자 한 분자가 생긴다고 말한다. 지문 2문단은 효소가 소모되는 재료가 아니며 여러 기질에 작용한다고 직접 설명한다. **A-V2 정답 ③**도 피브리노젠을 효소의 비활성 전구체로 묶지만, 지문 5문단은 그것이 피브린의 재료라고 이미 구별한다. 〈보기〉가 긴 실험 서사를 제공해도 정답 판단은 이 명시된 구별에 가까워진다. 반면 **B-V2 정답 ②**는 제X인자 활성화부터 피브리노젠 절단까지 중간 산물을 추적해야 해 이 지문에서 상대적으로 낫다.

도플러 기출 **12번 정답 ②**는 그래프에서 ⓐ의 음수 구간과 ⓒ의 양수 구간을 읽고, 도플러 변위 부호를 혈류 방향에 대응해야 한다. 단일 문단 규칙을 사용하지만 그래프를 단순 문장으로 바꾼 것은 아니다. 다만 **11번 정답 ⑤**는 적혈구의 크기가 클수록 산란이 많다는 부분이 지문 3문단의 ‘산란체가 작을수록’과 직접 충돌한다. 기출 내부에도 직접 대조형이 있다.

**수돗물 소독 A-V1 정답 ④**는 크립토스포리디움 난포낭이 잔류 염소로 잘 소독된다고 하지만, 지문 3문단은 염소에 잘 견딘다고 바로 설명한다. **B-V1 정답 ④**의 염소 소모 예상 역시 지문 6문단의 투입량 조절 설명에 가깝다. 기존 판정은 이 지문의 네 정답 모두를 ‘정리 문장 하나로 풀림’으로 보았다. 4-solve 검사에서는 같은 자외선 잔류 착각의 반복과 〈보기〉만으로 판단되는 선지도 지적했다. 이 검사는 품질의 자동 신호이지 확정된 문항 결함 개수가 아니다.

mRNA 기출 **19번 정답 ⑤**는 ‘pH를 높이면 이온화 지질의 소수성이 약해진다’는 새 주장을 넣는다. 지문 5문단의 pH에 따른 **전하** 변화와 3문단의 지질 **소수성** 설명을 구분하고, 〈보기〉의 혼합·투석 공정에 적용해야 한다. 이 문항은 정답 선지를 고르는 경로에서 새 공정이 실제로 쓰인다. 다만 실제 기출 19번에도 선지별 근거 명확성 논의가 가능하므로, 이를 무결한 기준 문항으로 취급하지 않았다.

### 법: 생성 문항의 적용력과 함정 반복 (판단 필요)

청약 철회 **A-V1 정답 ④**는 예약과 매매 합의를 구별해 거래 유형을 판단한다. **B-V2 정답 ⑤**는 거래 방식 교환, 요청일 변경, 반환 비용을 함께 계산한다. 과학·기술 두 생성 지문과 달리 네 정답 모두 지문의 정리 문장 한 줄을 그대로 옮겨 풀 수 없다는 기존 판정과도 맞는다. 법 지문에 대해 같은 과설명 결론을 확대하지 않는다.

공시 의무 기출 **12번 정답 ⑤**는 B(회사 임원)에게서 직접 정보를 받은 C가 **1차 정보수령자**인지, 다시 1차 정보수령자에게서 받은 사람인지를 구별해야 한다. 같은 〈보기〉의 다른 선지는 공시 누락, 미공개 정보가 실제 거래에 영향을 주었는지 등 서로 다른 규칙을 시험한다. 생성 청약 철회 문항은 적용 단계가 좋지만, A형 두 버전은 일반 매장 거래에 법정 철회권을 넓히는 유사 함정을 반복한다는 자동 검사 지적이 있다. 법 지문의 **정답 깊이**와 **문항 묶음의 다양성**을 따로 판단할 필요가 있다.

### 수치 해석과 설계 판단 (판단 필요)
