# 3.3 생성 지문으로 문항 만들기 (2026-11-17)

## 묻는 것
생성 지문이 "이해한 학생과 못 한 학생을 가르는 문항"을 기출만큼 낼 수 있나? v3 평가(EVAL.md)의 공통 결함인 과설명(정리 문장 반복)이 문항 여지를 줄이는지가 핵심이다.

## 지문
| 구조 | 생성 지문 | 기출 대조군 |
|---|---|---|
| S1-1 직렬처리형 | v3 T1-1 혈액 응고 | 소속 기출(달팽이관, 후각, 가스 센서, 적외선 분석기, 도플러 혈류계) 중 분석 골드 지도가 이미 있는 것, 없으면 도플러 혈류계 |
| S5-3 연쇄재보완 | v3 T2-2 수돗물 소독 | 이차 전지, mRNA 백신, 주택임대차보호법, 해수 담수화 중 같은 기준 |
| S6-2 분기별 규율 | v3 T3-1 청약 철회 | 공시 의무, 범죄 성립과 죄수, 법의 효력, CISG 위험 부담 중 같은 기준 |

## 순서
1. 분석 골드 지도 만들기: 생성 지문 3편(+지도 없는 대조 기출). 세트 E 때 쓴 저장소의 골드 지도 절차 그대로(3회 생성 → 하나 골라 굳힘, 지문당 약 $0.3).
2. 깊은 〈보기〉 문항: deep-item-v4.1 그대로(A 먼저, B 나중). 지문 6편 × A·B.
3. 판정(웹): 문항마다
   - 풀려면 몇 문단을 이어야 하나
   - 지문 속 정리 문장 하나를 찾아 옮기면 풀리나 (예/아니요)
   - 4-solve의 설계 문제·막히는 문장 수
   생성 지문과 기출 대조군을 같은 기준으로 비교한다.
   - 참고: 기출 3편의 실제 문항도 같은 기준으로 판정한다(비용 없음). 생성기가 사람 출제자에 얼마나 가까운지 보는 덤 자료다. 주 비교는 "같은 생성기, 다른 지문"이다(지문과 출제자를 한꺼번에 바꾸면 원인을 가를 수 없음).

## 읽는 법
- 생성 지문 문항이 "정리 문장으로 풀림"이 대조군보다 뚜렷이 많으면 → 과설명이 원인. 생성기 공통 규칙(W6·점검·교정의 명시 압력)을 고친다.
- 비슷하면 → v3 지문을 문항 파이프라인에 그대로 쓴다. 다음은 오개념 학생 응답으로 판정기 구별력 확인(Codex 제안).
- 지시문은 이 실험에서 고치지 않는다.
