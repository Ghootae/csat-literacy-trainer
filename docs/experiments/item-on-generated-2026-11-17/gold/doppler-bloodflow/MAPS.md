      - P1-5: 일반적으로 매질을 통해 측정 대상에게 보낸 초음파의 송신 주파수와 대상에서 반사되어 돌아온 수신 주파수는 같다.
      - P1-6: 도플러 효과는 측정 대상이 이동할 때 초음파의 송신 주파수와 수신 주파수가 달라지는 현상이다.
