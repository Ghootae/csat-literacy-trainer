# 기술 지문 v3 문항 검토

## 1. 개요

**기본 문항의 정확성은 좋다. 다만 8개 모두를 ‘깊은 문항 생성 성공’으로 보기는 어렵다.** 가장 좋은 것은 오디오 B-V1과 데이터 A-V1이다.

제시된 정답은 의도한 해석에서 모두 맞았다. 단, 오디오 계산형2개는 ‘재생 눈금’의 의미를 명시해야 다른 선지가 참으로 읽힐 가능성을 막을 수 있다. 이 문제는 기존 독립 풀이 원문에서도 지적됐으므로 ‘정답8/8 일치’만 보고 통과시키면 안 된다.

논리 연결과 예상 매력도를 중심으로 한 내 순위는 다음과 같다. 매력도는 실제 학생 선택률이 아닌 검토 예상이며, 인접 순위의 작은 차이까지 확정적이지는 않다.

| 순위 | 문항 | 정답 | 판정 | 핵심 이유 |
|---|---|---|---|---|
| 1 | 오디오 B-V1 | ④ | 고치면 씀 | 눈금 의미만 명시하면, 일부 조건을 되돌려 다른 판단까지 잇는 가장 좋은 구조 |
| 2 | 데이터 A-V1 | ③ | 쓸 수 있음 | 임시 후보선과 자료를 대표하는 선을 혼동하는 함정이 좋음 |
| 3 | 오디오 B-V2 | ③ | 고치면 씀 | 차폐되지 않아도 안 들릴 수 있다는 대비가 좋음. 눈금 의미 보완 필요 |
| 4 | 오디오 A-V2 | ⑤ | 쓸 수 있음 | 대역폭과 비트 배정 기준을 혼동하는 그럴듯한 함정 |
| 5 | 데이터 B-V2 | ② | 고치면 씀 | 절차 연습으로 타당하지만 깊은 추론은 약하고 V1과 중복 |
| 6 | 데이터 B-V1 | ④ | 고치면 씀 | 개수와 기준을 비교하면 풀려 비례 추론까지 필요하지 않음 |
| 7 | 데이터 A-V2 | ④ | 고치면 씀 | ‘후보 둘 모두 최종 선택’이라는 정답의 잘못이 쉽게 드러남 |
| 8 | 오디오 A-V1 | ④ | 고치면 씀 | 보기에 제거 규칙까지 있어 지문을 우회해 정답을 찾을 수 있음 |

다음은 새 생성을 늘리기보다 눈금 전제를 보완하고, 좋은 정답 구조와 일반 연습용 구조를 나눠 검토하는 것을 권한다. 원본·생성 규칙은 바꾸지 않았고 추가 API 호출도 하지 않았다.

## 2. 본문

### 오디오 계산형의 수치 의미 (미해결)

오디오 B-V1은 처음의10−2=8과 변경 후12−8=4를 비교한다. 그런데 ‘재생 눈금’이 단순한 볼륨 조절 번호라면 눈금 차이가 곧 소리 크기의 차이라고 보장되지 않는다. B-V2도 같은 문제가 있다.

두 보기에는 다음 한 줄을 넣는 것이 좋다.

> 재생 눈금은 소리 크기를 동일한 간격으로 나타내며, 모든 소리에 공통으로 적용된다.

이것은 어려운 문항을 쉽게 만드는 힌트가 아니라, 숫자가 무엇을 뜻하는지 고정하는 조건이다.

### 가장 좋은 문항은 무엇을 연결하게 하나 (해결)

오디오 B-V1의 정답④는 ‘주파수를 처음으로 되돌렸으니 비트 수도 같겠지’라는 생각을 흔든다.

**주파수 복원 → 들리기 시작하는 기준도2로 복원 → 크기는12로 유지 → 차이는 최초8보다 큰10 → 비트를 더 배정.**

한 단계에서 얻은 결과를 다음 판단에 써야 한다. 이런 구조는 깊은 문항의 좋은 사례다.

데이터 A-V1은 약2단계여도 좋다. ‘임시로 그은 선에서 멀다’와 ‘자료를 대표하는 선에서 멀다’를 혼동하게 한다. 깊이 숫자가 작다는 이유로 버릴 문항이 아니다.

### 길고 조건이 많아도 깊은 사슬은 아닐 수 있다 (판단 필요)

오디오 B-V2의 정답③은 ‘고음이면 대역폭이 넓다’와 ‘구간 밖의 갑도 들리지 않아 제거된다’를 함께 말한다. 각각 맞지만, 앞의 결론을 이용해야 뒤의 결론이 나오는 사슬은 아니다.

데이터 B-V1도 비가6/5에서12/10으로 유지된다고 설명하지만, 학생은6>5와12>10만 각각 확인해 풀 수 있다. 해설을 길게 쓸 수 있다는 것과 긴 추론이 반드시 필요하다는 것은 다르다.

따라서 식이 없는 지문에서 계산형을 전부 포기할 필요는 없다. 오디오 B-V1처럼 **중간 상태를 구해 다음 판단에 써야 하는지**를 기준으로 고르는 것을 권한다.

### 보기의 힌트와 문항 간 중복 (미해결)

오디오 A-V1은 보기에 ‘안내음은 기준을 넘었다’와 ‘기준보다 작은 소리를 뺐다’를 모두 준다. 지문을 이해하지 않아도 안내음은 제거하지 않는다고 판단할 수 있다. 관측 결과는 남기고 판단 규칙의 재설명은 덜어내는 편이 좋다.

데이터 B-V1·V2는 최초 두 점 누락, 평균 간격과 최대 개수 혼동, 문턱값과 허용 거리 혼동, 큰 좌표와 이상치 혼동을 반복한다. 각각 타당한 연습 문제지만 서로 다른8개 성공 사례로 넓게 일반화할 근거는 약하다.

| 다음 할 일 | 외부 전송 | 사용자 판단 |
|---|---|---|
| 오디오 B형2개 눈금 전제 보완 | 없음 | 보완 문구 |
| 상위 문항의 좋은 연결 구조 확인 | 기존 출력 재검토는 없음 | 논리 순위·매력도 |
| 일반 연습과 깊은 문항 후보 구분 | 없음 | 사용할 목적 |
| V1·V2 중복과 보기의 힌트 정리 | 편집 자체는 없음 | 남길 고리·삭제할 설명 |
| 다음 생성 규칙 수정 여부 결정 | 새 생성은 별도 계획 | 규칙 채택·실험 범위 |
