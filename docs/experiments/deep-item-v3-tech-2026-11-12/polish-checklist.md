# 사후 수정(다듬기) 점검표 v1 (2026-11-12)

다듬기는 표현만 고친다. 정오, 정답 번호, 선지가 노리는 연결 고리, 난도는 바꾸지 않는다.
고치면 정오가 흔들릴 것 같은 곳은 고치지 않고 '논리 메모'에 적는다. 문항을 버리거나 쉽게 만들지 않는다.
(명료성 관문·이의 제기 검사는 이 단계에 없다. 얕은 문항만 남길 위험이 있어 넣지 않기로 함 — Ghootae, 2026-11-12.)

1. 역접·대조 연결어: '~면서도', '~지만', '반면', '~와 달리', '그런데'로 이은 두 절이 실제로 맞서는지 본다. 맞서지 않으면 연결어를 바꾸거나, 맞서는 축(누구 대 누구, 무엇 대 무엇)을 문장에 드러낸다.
2. 지시 관계 줄여 쓰지 않기: 이름·기호 → 그것이 가리키는 대상 → 그 대상의 속성, 이 단계를 건너뛰지 않는다. ('기호가 나타내는 구조' X → '기호가 지칭하는 물질의 구조' O)
3. 행위 주체 숨기지 않기: 조건절('~한다면'), 피동('~쓰일 수 있겠군', '~해소되겠군'), 명사화('~삼는 데서')로 누가 하는지 흐리지 않는다. 누가 하는지 주어로 세우고, 조건절과 주절의 주어를 맞춘다.
4. 풀어쓰기 줄이기: 〈보기〉에서 풀어쓰기는 선지가 노리는 핵심 개념에만 남긴다. 핵심이 아닌 용어를 풀어 쓴 곳은 지문 표현으로 되돌린다. 〈보기〉는 공백 제외 300자 이하.
5. 선지가 〈보기〉에서 숨긴 핵심 개념을 지문 용어로 다시 불러 주지 않는지 본다(옮기기는 학생 몫). 다시 불러 준 곳은 〈보기〉 표현으로 되돌린다.
6. 문장 끝맺음과 조사: 선지 끝맺음('~겠군', '~군')을 통일하고, 조사 하나로 정오가 갈리는 곳은 그 조사가 의도한 뜻으로만 읽히는지 본다.
