## 기본 지표
- 8문항 모두 독립 풀이 답 = 출제 정답. 〈보기〉 174~237자(전부 300자 이하). 다듬기 수정 문항당 6~7곳.
- 토큰 합계: 입력 137,850 / 출력 205,622 (4실행).

## v3 규칙이 먹힌 곳
- 사건 인과 연결(규칙 13·B7): 8개 〈보기〉 모두 "목적 → 조작 → 결과" 한 장면. '검토하는 방안' 나열 없음.
- 지문 예시 옮기기 금지(14·B8): 프로 선수 연봉, 축음기 등 지문 사례 재사용 없음.
- 단정어 거짓 금지(15·B17): 거짓 선지 32개 중 '~만으로/반드시'로 만든 것 없음.
- 정답 매력도: 오디오 A-V2 ⑤(임계대역 폭 → 비트 수 혼동), 데이터 A-V1 ③(이상치에서 출발한 후보 직선에서 먼 점 = 이상치로 착각), 데이터 A-V2 ④(최종 후보 둘 다 선택).
- 다듬기 논리 메모가 실제 쟁점을 짚음: 오디오 B '재생 눈금' 차이를 소리 크기 차이로 다루는 전제, 데이터 A-V2 ② '점에서 먼 것'과 '직선에서 먼 것'의 거리 기준 차이. 고치지 않고 메모만 남김(설계대로).

## 안 먹힌 곳 (v3.1 후보)
1. **V1·V2 오답 뼈대 중복(규칙 16·B20 위반)**: 정답 고리는 다르지만 오답이 거의 같은 틀로 반복.
   - 데이터 B: V1 ①③⑤ ≈ V2 ①④⑤ (처음 두 점 빠뜨리기, 문턱값 낮추면 띠 안 점이 늘어남, L 위의 큰 좌표 점 = 이상치), V1 ② ≈ V2 ③(평균 간격 기준).
   - 오디오 A: V1 ①②⑤ ≈ V2 ①②④ (같은 자릿수, 경계를 정하는 두 요소, 구간별 자릿수).
   - 원인 추정: 두 버전을 한 호출에서 만들어 재료를 나눠 씀. 대안 = V2를 별도 호출로 만들고 V1의 선지 고리 목록을 "쓰지 말 것"으로 넘김.
2. **계산 양식이 산수로 기움**: 두 기술 지문 모두 식이 없어 B형이 눈금 뺄셈(12−8=4 < 8), 개수 세기(2+4=6>5), 비(6/5=12/10)로 정오가 갈림. P1 때 지적한 '산수화'와 같은 계열. B형 정답 4개 중 사례 건너뛰기 연결은 오디오 B-V2 ③(배경음 고음화 → 임계대역 확대 + 구간 밖이어도 최소가청강도 미달)이 가장 가까움.
   - 질문: 식이 없는 지문(절차·기준값 지문)에 B형을 쓸지, A형만 쓸지.
3. 선지 문장 길이: B형 선지가 길다(조건 2~3개 겹침, 예: 오디오 B-V1 ④, 데이터 B-V1 ②). 다듬기 점검표에 '선지 한 문장에 조건 둘까지' 같은 항목을 넣을지 판정 후 결정.
