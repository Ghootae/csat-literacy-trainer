# 조립 재료 v3 (개념 연결 양식)

## A. 출제 규칙 (출제자 시뮬레이션 + 판정에서 나온 것)

1. 〈보기〉에서 선지의 핵심이 되는 지문 개념은 이름 대신 정의나 구체적 모습으로 풀어 써서, 학생이 지문 개념으로 되돌려 옮기게 한다. 단, 풀어쓰기는 핵심 개념에만 한다. 모든 용어를 바꾸거나 새 이름(예: 'ㄱ 묶음', '갑 서류')을 지어내지 않는다. 일반 명사·주변 용어는 지문 표현을 그대로 써도 된다.
2. 〈보기〉 문장 하나하나가 선지의 고리가 되게 쓴다.
3. 〈보기〉 디테일은 특정 오해를 일부러 부르도록 고른다(겉모습이 다른 개념과 닮게).
4. 선지들이 지문의 핵심 개념·문단을 고루 덮게 한다. 같은 포인트를 반복하지 않는다.
5. 참 선지도 단순 내용 확인으로 두지 않는다. 〈보기〉 표현을 지문 개념으로 옮기는 한두 단계를 요구한다.
6. 거짓 선지 채택 기준:
   - 부정어만 붙여 바로 틀린 게 보이면 버린다.
   - 상식만으로 틀린 게 보이면 버린다.
   - 같은 문단·이웃 문장 한 구절로 바로 반박되면 버린다.
   - 좋은 거짓 선지 = 지문의 한 부분만 읽으면 참처럼 보이고, 서로 다른 문단의 내용을 통합해야 거짓이 되는 선지. 이름·겉모습이 닮은 이웃 개념 쌍을 섞는 것이 가장 좋다.
7. 정오는 미리 정하지 않는다. 참으로 먼저 쓰고, 위 기준을 통과하는 거짓 버전이 있을 때만 거짓 후보로 둔다. 정답은 마지막에 고른다.
8. 오류를 여러 개 겹친 선지는 각 오류가 지문 문장으로 분명히 반박되어야 한다. 하나라도 해석에 따라 맞을 수 있으면 빼거나 고친다.
9. 지문 밖 법률·사실이 판단에 필요하면 안 된다. 수치 계산이 정오를 가르면 안 된다(수치를 쓰더라도 대소·유무 판단까지만).
10. 〈보기〉 길이: 공백 제외 150~260자, 5문장 이하를 목표로 하고 300자를 넘지 않는다(기출 〈보기〉 128개: 중앙 209자, 75% 261자, 90% 310자, 문장 중앙 5개). 수능은 상황을 장황하게 쓰지 않는다.
11. 깊이는 〈보기〉를 해독하는 수고가 아니라, 선지에서 지문의 여러 개념·문단을 연결하는 데서 나와야 한다. 〈보기〉가 길어졌는데 선지가 한 문장 확인으로 풀리면 실패다.
12. 선지가 〈보기〉에서 숨긴 개념을 다시 이름 붙여 주지 않는다(예: 〈보기〉에서 정의로만 풀어 쓴 대상을 선지에서 '…한 몫인 ○○'처럼 지문 용어로 다시 불러 주지 않는다). 옮기기는 학생 몫이다.

## v3 추가 (2026-11-12, 표면 장력·인문 판정에서)

13. 〈보기〉의 사건들은 하나의 상황 안에서 원인·동기로 이어지게 쓴다(무엇 때문에 다음 일이 생겼는지). 서로 관계없는 사건이나 '검토하는 방안'을 나열하지 않는다. 병렬로 붙이더라도 같은 장면·같은 목적 안에서 붙인다.
14. 지문의 예시 사례(사고 실험, 예로 든 사건·대상)를 이름만 바꿔 옮기지 않는다. 지문의 원리를 지문에 없는 새 상황에 적용하게 한다.
15. '~만으로 확정할 수 있다', '~해야만 한다', '반드시', '오직' 같은 단정어를 붙여 거짓을 만들지 않는다. 거짓은 지문 개념을 잘못 연결해서 생겨야 한다.
16. 두 버전(V1, V2)은 〈보기〉 사례뿐 아니라 정답이 노리는 착각과 〈보기〉의 짜임(등장 대상 수, 사건 흐름)도 서로 달라야 한다. 같은 틀에 소재만 바꾸면 실패다.
17. 정답은 깊이와 매력도 두 축으로 고른다. 깊이(연결해야 하는 개념 수)가 낮아도, 지문을 대충 읽은 학생이 쉽게 걸려드는 착각이면 좋은 정답이다.
