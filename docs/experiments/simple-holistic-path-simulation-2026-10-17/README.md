# 단순 형식 문단 전체 경로 시뮬레이션 (2026-10-17)

현재 규칙(프롬프트 v4.1, D-0140·D-0144·D-0145 + 보완 v4.1)의 전체 경로 29개를 문단 두 개에 적용한 기대 대화 58개. 다음 단계에서 UI 없이 같은 학생 응답을 모델에 넣어, 결과가 기대와 **질적으로** 같은지 검증하는 데 쓴다(사용자 지시 2026-10-17).

- `build.mjs`: 생성기. 문단별 재료(학생 발화, 오류, 질문, 핵심)와 경로 조립 규칙. 고칠 때는 이것을 고치고 다시 실행한다.
- `cases.json`: 실험 스크립트용. 사례마다 학생 응답 순서와 단계별 기대값(`expect`), 방향 예시 문구(`exampleTutor`).
- `SIMULATION.md`: 사람이 읽는 기대 대화.
- 경로 번호 P01~P29는 전체 경로 수형도 아티팩트(https://claude.ai/artifact/JivxbidCQbSLA4HdS7TCxd)와 같다.

## 비교 기준

질적 동일 = 단계별 `category`·`action`, `targetErrorResolved`, 구멍 질문의 빈 곳 수와 내용(A/B), `targetGapsFilled`와 오류의 `gapIndex`·내용(A/B), `missingNote` 유무, 마무리 말풍선 구성, 지문 표시 문장(A/B), `points`의 방향. `exampleTutor` 문구는 방향 예시이며 비교 대상이 아니다.

실험 때는 모델이 실제로 낸 `gaps`를 다음 단계 `targetGaps`로, 튜터 말풍선(번호 질문 포함)을 대화에 이어 붙인다. 앞 단계가 기대와 달라 경로가 갈라지면 그 지점에서 멈추고 갈라짐으로 기록한다.

## 기대값이 판단에 따라 갈릴 수 있는 곳 (Claude 메모)

- A만 말한 응답(`onlyA`)을 GAP으로 본다. 메모 6(이미 말한 관계를 구멍으로 보는 문제)과 경계가 가깝다. 모델이 CAPTURED로 보면 기대와 다르지만 오판이라고 단정하기 어렵다.
- 구멍 하나 질문에 "그렇게 하는 게 맞으니까"/"운동이랑 관련이 있어"를 모호한 못 채움(GAP)으로 본다. 모델이 IRRELEVANT로 보면 행동(CLOSE_GAP)은 같다.
- 지문 표시 문장은 A/B 근거 문장을 기대값으로 두었지만, 모델은 같은 내용을 담은 다른 문장을 고를 수 있다(특히 도파민 B 문장은 A 내용도 담고 있다).
