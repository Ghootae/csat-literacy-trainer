# 1. 탐색·검사 집계

본문과 제공된 명제 지도만 사용했다. 명제 지도는 탐색용으로 활용하고, 최종 판단과 인용은 본문을 기준으로 했다.

| 항목 | 수 |
|---|---:|
| 훑은 명제 쌍·셋 | **48개** |
| 만든 후보 | **48개** |
| (a) 부분 독해에서도 참처럼 보일 근거가 약해 탈락 | 10개 |
| (b) 지문을 통합해도 명백히 거짓이라고 확정할 수 없어 탈락 | 12개 |
| (c) 지문 없이 상식만으로 거짓임이 드러나 탈락 | 0개 |
| (d) 참이 되는 해석이나 모호성이 남아 탈락 | 8개 |
| **최종 통과** | **18개** |

- 탈락 수는 **대표 탈락 사유 하나로만 집계**했다. 특히 참이 되는 해석이 있는 후보는 (b)와 중복하여 세지 않고 (d)에 배정했다.
- (c)의 0개는 검사 생략을 뜻하지 않는다. 이번 후보군에서는 상식만으로 거짓임을 판별할 수 있다는 점이 **주된 탈락 사유**가 된 후보가 없었다.
- 아래의 ‘통과’는 **참인 진술이라는 뜻이 아니라, 헷갈리기 쉬우면서도 통합 독해로 명확히 반박되는 거짓 진술**이라는 뜻이다.

## 반박에서 특히 구분해야 할 지점

- **1번:** 인간이 확정하는 것은 실들 사이의 차이에 대한 **구별**이지, 실 자체의 분화가 아니다.
- **6번:** 사명은 **그 명이 가리키는 대상 수**를 제한한다. 그 대상에 붙일 수 있는 **다른 명의 수**까지 제한하지 않는다.
- **7번:** 흰 말을 두 명으로 지시할 수 있어도, ‘말’은 검은 말도 지시한다. **겹치는 대상이 있음**과 **지시 범위 전체가 같음**은 다르다.
- **16번:** 두 학 사례의 구조는 **하나의 명 → 서로 다른 두 실**이다. 반대 방향의 원칙을 반박하는 사례로 바꾸면 안 된다.
- **18번:** 한 개체를 지시한다는 기능적 공통성이 두 유형을 모두 **고유명사**로 만들지는 않는다.
