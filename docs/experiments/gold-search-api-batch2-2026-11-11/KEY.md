## 웹 스레드 메모 (빠르게 본 것, 정밀 검산 전)

- 정답은 독립 풀이와 6/6 일치. 풀이자가 지적한 흔들림: 의미 V1 ④('설명 자체'를 '설명이 가리키는 구조'로 읽으면 맞아 보임), 의미 V2 ②('지침'을 보조 기준으로 읽으면 가능), 공손룡 V1 〈보기〉의 '파란 잔 요청'을 손님이 '잔 요청'이라 바꿔 말함(정답엔 영향 없음).
- 〈보기〉 길이는 모두 160~188자로 규칙 안. 법인 때 장황함은 고쳐졌다.
- 선지 평균은 53~63자로 기출 중앙(48자)보다 조금 길지만 90%(70자) 안이다. 의미 V2가 가장 길다(63자).
- 같은 지문 V1·V2가 거의 같은 틀이다. 공손룡은 '모양 같은 두 물건 + 수식어 붙은 요청 + 별칭 + 나중에 하나만 가리키기로 약속'이 잔/북으로 그대로 반복, 의미는 '두 대상 + 내부 구조 + 기호 + 전문가 안내'가 반복. 지문당 1문항만 쓰거나, V2는 다른 구역을 쓰도록 강제해야 할 듯.
- 의미 지문 〈보기〉는 지문의 쌍둥이 지구·금 사례를 이름만 바꾼 모습에 가깝다(액체/구조, 금속/본질). 적용 거리가 짧을 수 있다.
- 정보 비대칭은 '실명확인 사건 다수·소수 의견', '미국 플랫폼 규제' 등 지문 여러 문단을 고루 덮는다(개념 연결형에 잘 맞음).

## 웹 순위·총평 (2026-11-12 05:03 UTC, Ghootae 순위 듣기 전에 봉인)

순위: 의미 V1 > 정보 V2 > 공손룡 V2 > 정보 V1 > 의미 V2 > 공손룡 V1
- 의미 V1: 1·2·4문단 연결, 언어적 노동 분업이 지문 안의 함정. 문장 수정 필요하지만 깊이 최고.
- 정보 V2: 자연스러움·난도 균형 최고, '자율' 이웃 개념 혼동.
- 공손룡 V2: ⑤ 정답이 공손룡/후기 묵가 구분 + '하나의 실' 착각으로 깊고, ③(형태 유지 ≠ 분류 유지)도 좋음. 〈보기〉가 V1보다 조금 덜 나열식.
- 정보 V1: 정답 ④ 얕지만 매력 높음, ③ 문장 수정 필요.
- 의미 V2: 정답 ② 오류 축이 V1 ④와 같은 계열이면서 더 약함, 문체 문제 2개.
- 공손룡 V1: 〈보기〉 나열이 가장 심하고 V2와 거의 같은 틀.
총평: 6문항 모두 수정하면 사용 가능 수준. 개념 연결 양식은 인문·사회에서도 통함(이웃 개념 혼동, 문단 넘는 연결을 잘 찾음). 약점은 생성보다 표현: ① 〈보기〉 사건 나열(동기 없음) ② 행위 주체 숨기는 문장 ③ 같은 지문 V1·V2 틀 반복 ④ 지문 사례 복제(의미). ①③은 생성 규칙, ②는 사후 수정 단계로.
