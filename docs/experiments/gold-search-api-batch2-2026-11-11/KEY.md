## 웹 스레드 메모 (빠르게 본 것, 정밀 검산 전)

- 정답은 독립 풀이와 6/6 일치. 풀이자가 지적한 흔들림: 의미 V1 ④('설명 자체'를 '설명이 가리키는 구조'로 읽으면 맞아 보임), 의미 V2 ②('지침'을 보조 기준으로 읽으면 가능), 공손룡 V1 〈보기〉의 '파란 잔 요청'을 손님이 '잔 요청'이라 바꿔 말함(정답엔 영향 없음).
- 〈보기〉 길이는 모두 160~188자로 규칙 안. 법인 때 장황함은 고쳐졌다.
- 대신 선지가 길어졌다. 정보 비대칭 선지는 기출 90%(70자)를 넘는 것이 많다. 깊이가 〈보기〉에서 선지로 옮겨 가면서 선지가 무거워진 것일 수 있다.
- 같은 지문 V1·V2가 거의 같은 틀이다. 공손룡은 '모양 같은 두 물건 + 수식어 붙은 요청 + 별칭 + 나중에 하나만 가리키기로 약속'이 잔/북으로 그대로 반복, 의미는 '두 대상 + 내부 구조 + 기호 + 전문가 안내'가 반복. 지문당 1문항만 쓰거나, V2는 다른 구역을 쓰도록 강제해야 할 듯.
- 의미 지문 〈보기〉는 지문의 쌍둥이 지구·금 사례를 이름만 바꾼 모습에 가깝다(액체/구조, 금속/본질). 적용 거리가 짧을 수 있다.
- 정보 비대칭은 '실명확인 사건 다수·소수 의견', '미국 플랫폼 규제' 등 지문 여러 문단을 고루 덮는다(개념 연결형에 잘 맞음).
