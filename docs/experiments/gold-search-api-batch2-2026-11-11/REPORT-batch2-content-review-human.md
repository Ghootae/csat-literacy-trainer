# 새 지문 3개·6문항 내용 검토 — 인간 보고서

날짜: 2026-11-12. KEY·생성 해설은 열지 않았다. 원지문 3개와 사용자가 붙인 판정지만 대조한 Codex 자문이며 실제 학생 난이도 측정이나 사용자 최종 판정이 아니다.

## 1. 개요

### 목적
6문항의 정오, 선지별 깊이와 품질, 보기 길이 규칙 이후의 완성도를 검토했다. 깊이는 낮음(대상 식별 뒤 규칙 하나 대조), 중간(두 관계 또는 혼동하기 쉬운 기준 구별), 높음(여러 관계·조건 조정)으로 구분한다. 용어 치환과 문장 길이는 깊이에 더하지 않는다. 낮은 깊이도 좋은 개념 함정을 가질 수 있다.

### 결과
우선 추천은 정보 비대칭 V2, 의미 내재·외재주의 V2, 공손룡 V1이다. 의미 V1과 공손룡 V2도 사용 가능하다. 정보 V1은 수정 후 사용을 권한다. 독립 정답 판단은 정보 V1④/V2③, 의미 V1④/V2②, 공손룡 V1④/V2⑤다. 이는 KEY와 대조한 결과가 아니다.

법인 때보다 대체로 좋아졌다. 특히 불필요한 용어 우회가 줄고, 상황 속 개념 구별이 늘었다. 다만 지문이 달라진 비교이므로 규칙 v2의 효과만으로 인과 해석할 수 없다. 세 지문 모두 V1·V2가 같은 핵심 관계를 상당 부분 공유하므로, 여섯 가지 독립적 사고 구조를 얻었다고 볼 수는 없다.

### 다음 스텝
사용자 판정 후 필요한 문항만 수정한다. 길이 규칙은 유지할 만하나, 다음 검토에서는 보기의 각 문장이 실제 판단에 쓰이는지와 같은 지문 두 문항의 사고 구조 중복을 함께 본다. 새 규칙 채택·생성은 이번에 하지 않았다.

## 2. 본문

### 정보 비대칭 V1 — 수정 후 사용 (판단 필요)

| 선지 | 깊이 | 평가 | 한 줄 |
|---|---|---|---|
| ① | 낮음 | 보통 | 거짓 정보의 과다 공급·정책 판단 왜곡을 비판론의 근거에 대응시킨다. |
| ② | 중간 | 양호 | 갑의 경쟁 중심 입장을 일반적 헌재 입장과 연결하고 소수 의견과 구별한다. |
| ③ | 중간 | 좋음 | 토론에 대한 불신이 사업자의 선행 조치까지 배제하는 것은 아님을 구별한다. |
| ④ | 낮음 | 약함 | 지문이 비판론도 표현의 자유를 기본권으로 고려한다고 명시하므로 바로 반박된다. |
| ⑤ | 중간 | 좋음 | 사업자의 선행 조치라는 공통점과 정부 후속 개입이라는 차이를 함께 본다. |
| 문항 전체 | 중간 | 고치면 씀 | 비교할 관계는 좋지만 정답④가 지나치게 직접적으로 틀렸다. |

④ 원문: “표현의 자유의 기본권 인정 여부로 갈리는 … 차이”. 두 입장은 정부 개입의 필요성·방식에서 다르지 기본권 인정 자체에서 갈리지 않는다. ③·⑤의 좋은 구별을 충분히 하지 않고도 정답을 찾을 수 있다. 또 마지막 ‘갑도 운영 원칙을 스스로 정할 수 있다’는 문장은 ⑤를 위한 부연처럼 느껴진다.

| ② | 낮음 | 양호 | 조작 정보가 유권자 판단에 쓰이는 상황을 공동 규제의 근거와 연결한다. |

③ 원문: “운영자가 스스로 하는 조치이므로 … 소수 의견의 취지와 어긋나겠군.” 소수 의견은 토론 등 자율적 교정의 한계를 지적한다. 비판론은 사업자의 자율적 선행 차단과 정부 후속 규제를 함께 인정한다. ‘자율적’이라는 단어만 보고 모두 같은 방식으로 묶으면 틀린다. 지문에 밀착한 좋은 함정이다.

### 의미 내재·외재주의 V1 — 사용 가능 (판단 필요)

| 선지 | 깊이 | 평가 | 한 줄 |
|---|---|---|---|
| ① | 낮음 | 보통 | 일상적 설명을 기술구로 알아보고 내재주의 정의를 적용한다. |
| ② | 중간 | 좋음 | 기록 기호의 동일성과 대상 구조의 동일성은 다르다는 점을 가른다. |
| ③ | 낮음 | 좋음 | 전문가에게 의존하는 언어 사용과 사용자의 전문적 판별 능력을 구별한다. |
| ④ | 중간 | 좋음·표현 점검 | 전문가 설명의 권위와 의미를 결정하는 대상 자체를 혼동시킨다. |
| ⑤ | 낮음 | 보통 | 동일한 생각보다 대상의 구조에 의미 근거를 둔다는 중심 주장을 재확인한다. |
| 문항 전체 | 중간 | 쓸 수 있음 | 보기는 쌍둥이 지구와 비슷하지만 정답은 전문가 설명과 의미 근거를 새로 구별하게 한다. |

④ 원문: “조사단의 설명 자체를 의미의 최종 결정 근거로 삼는다면 … 문제를 해소”. 설명이 실제 본성을 알려 주는 수단인 것과 설명 자체가 최종 결정 근거인 것은 다르다. 현재 문장에서는 ‘자체·최종’ 때문에 거짓으로 읽힌다. 다만 전문가가 밝혀낸 실제 본성을 받아들이는 행위까지 잘못이라고 오해하지 않도록 표현을 점검할 만하다. 정답 불성립·복수정답으로 확정한 것은 아니다.

|---|---|---|---|

| ② | 중간 | 매우 좋음 | 개인 밖에서 마련된 사회적 기준과 지시체 자체의 실제적 본성을 구별한다. |
| ③ | 중간 | 좋음 | 다른 기호를 썼다는 사실보다 기호가 가리키는 구조를 확인해야 한다. |
| ④ | 낮음 | 좋음 | 언어 사용자의 전원 전문지식 없이도 전문가 의존이 가능하다. |

### 공손룡 V1 — 사용 가능, 가장 추천 (판단 필요)

| 선지 | 깊이 | 평가 | 한 줄 |
|---|---|---|---|
| ① | 낮음 | 양호 | 서로 다른 두 개체를 한 이름으로 부르는 것을 엄격한 일대일 원칙과 대조한다. |
| ② | 낮음 | 보통 | 흰 말 사례의 용법 차이를 파란 잔에 적용한다. |
| ③ | 중간 | 매우 좋음 | 같은 개체를 두 이름으로 지시할 수 있어도 두 이름의 범위가 같은 것은 아니다. |
| ④ | 중간 | 매우 좋음 | 이름 하나가 개체 하나만 지시한다는 것과 그 개체를 이름 하나로만 불러야 한다는 것을 구별한다. |
| ⑤ | 중간 | 좋음 | 같은 ‘잔’의 지시 대상이 여럿에서 하나로 바뀌면 이름의 분류도 달라진다. |
| 문항 전체 | 중간 | 쓸 수 있음 | 보기 속 행동과 약속이 서로 다른 개념 경계를 실제로 판단하게 한다. |

④ 원문: “‘여울’을 파란 것 하나에만 쓰는 약속을 지키려면 … ‘잔’으로도 지시한 … 표현을 고쳐야”. 여울이 파란 잔 하나만 지시한다고 해서 그 잔을 잔이라고 부르는 것을 금지하지 않는다. 하나의 실에 여러 명이 대응할 수 있다는 후기 묵가의 주장을 정확히 읽어야 한다. 방향이 다른 두 ‘하나’ 조건을 혼동시키는 좋은 함정이다.

### 공손룡 V2 — 사용 가능 (판단 필요)

| 선지 | 깊이 | 평가 | 한 줄 |
|---|---|---|---|
| ① | 낮음 | 보통 | 큰 북과 북의 요청 용법 차이를 백마 사례에 대응시킨다. |
| ② | 중간 | 좋음 | 같은 작은 북을 두리와 북으로 부를 수 있는지 일대다 지시 관계를 적용한다. |
| ③ | 중간 | 좋음 | 단어 형태가 아니라 실제 지시 범위 변화로 유명·사명을 나눈다. |
| ④ | 중간 | 좋음 | 상위 이름으로 큰 북을 지시할 수 있음과 이름의 범위 동일성을 구별한다. |
| ⑤ | 중간 | 좋음 | 같은 종류라는 것을 하나의 개체와 혼동하여 공손룡의 일대일 원칙을 우회한다. |
| 문항 전체 | 중간 | 쓸 수 있음 | V1과 비슷한 품질이나 ‘후기 묵가와 마찬가지’가 명시적 학파 대립을 떠올리는 단서다. |

⑤ 원문: “모두 한 종류로 묶인다는 점에서 … 하나의 대상에 대응”. 이 지문에서 공손룡의 실은 분화된 각각의 개체다. 두 북을 한 종류로 묶어도 두 개체라는 사실은 사라지지 않는다. 다만 V1④보다 지문의 명시적 대립으로 반박하기 쉬워 V1을 조금 앞에 둔다.

### 보기 길이와 수능 문항다운 정도 (판단 필요)

공백·문장부호 포함, 인용 표시를 제외한 첨부 보기의 실제 글자 수:

| 지문 | V1 | V2 |
|---|---:|---:|
| 정보 비대칭 | 250 | 247 |
| 의미 내재·외재주의 | 250 | 247 |
| 공손룡 | 213 | 242 |

모두 150~260자 범위다. 길이뿐 아니라 개념 식별에 필요한 표현만 남긴 점에서 법인 가·다보다 자연스럽다. 다만 수능다운 정도는 내용 검토 의견이다. 정보 V1의 마지막 운영원칙 문장, 의미 V1의 마지막 안내서 문장, 의미 V2의 마지막 회의 문장은 특정 선지를 위해 덧붙인 흔적이 있다. 공손룡은 요청·별칭·사용 약속의 변화 자체가 판정 대상이어서 구성의 응집성이 더 좋다.
