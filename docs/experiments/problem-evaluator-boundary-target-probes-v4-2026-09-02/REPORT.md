# Luna 경계 판정 안정화 표적 게이트

## 목적

기본 20개 논리 프로브에서 드러난 다음 두 문제를 특정 문구에 과적합하지 않는 일반 계약으로 수정하고, 전체 60회 재실행 전에 작은 표적 게이트로 안정성을 확인한다.

- 동시에 참일 수 있는 두 명제를 직접 모순으로 과단정하는 문제
- `DECISIVE + MATCHES`가 실제 근거 ID 없이 반환되는 구조 계약 문제

## 변경 사항

- 같은 대상·조건·시간·범위·양태를 공유하면서 한 명제가 다른 명제의 부정을 직접 도출할 때만 `CONFLICTS`를 허용했다.
- 비율과 총량, 가능성과 실제, 적용과 혜택처럼 함께 참일 수 있는 명제는 연결이 부족하다는 이유만으로 `CONFLICTS`로 판정하지 않게 했다.
- 선택지 번호나 “적절하다”라는 선택 결론의 재진술은 독립 근거가 아니라는 정책을 입력에 명시했다.
- 입력이 사용할 수 있는 정확한 `allowedSourceRefs`를 선언하고, 선언 목록과 실제 전체 골드 또는 슬라이스 manifest가 다르면 런타임 검증에서 거부한다.
- `MATCHES | CONFLICTS`의 `sourceRefs` 최소 1개 조건을 애플리케이션 후검증뿐 아니라 공급자 JSON Schema에도 표현했다.
- FTA 원 실패, 수소 압축 근거, 서로 다른 비함의 4종, 직접 모순 대조군 2종으로 8개 논리 프로브를 만들고 Luna medium으로 각 3회 실행했다.

## 실행 조건

| 항목 | 값 |
| --- | --- |
| 모델 | `gpt-5.6-luna` |
| reasoning effort | `medium` |
| 입력 | `BASELINE_FULL_GOLD` |
| 논리 프로브 | 8개 |
| 반복 | 프로브당 3회 |
| 총 호출 | 24회 |
| 최종 프롬프트 | `selected-option-model-quality-prompt-v4` |
| 엄격 게이트 | assessment, 기대 finding, 구조 계약을 모두 24/24 통과 |

## 결과

| 지표 | v2 | v3 | v4 |
| --- | ---: | ---: | ---: |
| assessment | 21/24 | 20/24 | 21/24 |
| 기대 finding | 22/24 | 19/24 | 20/24 |
| 상세 통과 | 20/24 | 17/24 | 18/24 |
| 구조·실행 오류 | 1 | 2 | 0 |
| 엄격 게이트 | 실패 | 실패 | 실패 |

v4에서 확인된 긍정적 결과는 다음과 같다.

- 기존 FTA C3 비함의 실패는 3/3 `INSUFFICIENT`로 복구됐다.
- 추가 FTA 비함의 두 종류도 각각 3/3이었다.
- FTA와 열팽창의 직접 모순 대조군은 모두 3/3 `CONTRADICTED`였다.
- 잘못된 문단 ID 참조와 빈 `sourceRefs`를 포함한 구조 계약 오류는 0건이었다.
- API·전송 오류도 0건이었다.

남은 실패는 다음과 같다.

- 수소 C4 압축 근거는 3회 모두 `INSUFFICIENT`였다. 학생 답변은 C3을 배제하는 전환율 비교와 B의 부반응만 말하고, C4의 핵심인 동일 공급량의 수소 생성량 비교 또는 A와 B의 부반응 대비를 직접 연결하지 않는다. 선택 결론 재진술을 근거에서 제외하는 현재 계약에서는 기대값 `SUPPORTED`와 충돌한다.
- 열팽창 C3은 assessment 3/3이었지만 1회가 결론 claim을 finding으로 분리하지 않았다.
- 수소 C5는 assessment 3/3이었지만 2회가 “B에서만”이라는 배타 claim을 finding으로 분리하지 않았다.

v4 사용량은 평균 입력 8,485.8 토큰, 평균 캐시 입력 5,168.9 토큰, 평균 출력 822.9 토큰, 평균 지연 9.06초였다. 실행 당시 비교에 사용한 Luna 단가로 계산한 캐시 반영 추정 비용은 24회 합계 약 `$0.042101`이다. v2~v4의 전체 72회 추정 비용은 약 `$0.112523`이다.

타입 빌드, 관련 계약 테스트 7/7과 `git diff --check`가 통과했다. 전체 회귀는 648/649가 통과했고, 유일한 실패는 기존부터 누락된 Hegel `.omc` 실험 산출물을 직접 읽는 무관한 테스트다.

## 판정

이번 변경으로 FTA의 `CONTRADICTED` 과단정과 근거 없는 구조 출력은 재발하지 않았다. 그러나 엄격 게이트는 18/24에 그쳐 통과하지 못했다.

특히 수소 C4는 프롬프트를 더 관대하게 만드는 것으로 해결하면 “선택 결론 재진술은 근거가 아니다”라는 일반 계약을 훼손할 수 있다. 따라서 기대 라벨을 임의로 바꾸거나 해당 문구만 예외 처리하지 않았다. Luna 전체 60회와 Terra 60회 비교는 조건부 순서에 따라 실행하지 않았다.

## 다음 작업

1. 수소 C4 응답을 사람이 `SUPPORTED` 또는 `INSUFFICIENT`로 재판정하고, 어떤 생략까지 최소 충분 근거로 인정하는지 계약을 확정한다.
2. finding이 학생 근거의 모든 결정적 claim을 덮어야 하는지, 아니면 최종 assessment와 최소 한 개의 결정적 finding이면 되는지 채점 계약을 확정한다.
3. 확정된 계약으로 표적 24회를 다시 실행해 24/24를 확인한다.
4. 표적 게이트 통과 후 Luna 기본 60회를 재실행하고, 그 절대 게이트를 통과할 때만 Terra 60회와 60쌍 비교를 수행한다.
