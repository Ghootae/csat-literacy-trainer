# 기본 20개 논리 프로브 Luna 품질 게이트 보고서

## 1. 목적

기존 5문항의 기본 학생 응답을 현재 4방향 라우팅과 `SUPPORTS | CONTRADICTS | DOES_NOT_JUSTIFY` 계약으로 다시 고정하고, 오리지널 전체 골드에서 `gpt-5.6-luna / medium`의 절대 품질을 먼저 검증한다. Luna가 사전 품질 게이트를 통과할 때만 같은 60회를 Terra로 실행해 모델 차이를 비교한다.

## 2. 입력과 기대 계약

- 대상: 5문항 × 4개 논리 프로브 = 20개
- 카테고리: `accurate`, `negativeAccurate`, `representativeWrong`, `lowInformation` 각 5개
- 반복: 프로브당 3회, Luna 총 60회
- 입력 골드: 2026-09-02 ExplanationAudit 사이클의 원본 `c-gold.json`
- 입력 모드: `BASELINE_FULL_GOLD`
- 모델 외 고정 요소: 프롬프트, structured output, 기대 라벨, 학생 응답, 골드 해시

과거 카테고리는 기대 라벨이 아니다. 학생 문장과 승인 근거를 현재 계약으로 다시 읽어 다음처럼 고정했다.

| 기대 assessment | 논리 프로브 |
|---|---:|
| `SUPPORTED` | 10 |
| `CONTRADICTED` | 6 |
| `INSUFFICIENT` | 4 |

`lowInformation` 5개 중 수소와 FTA는 실제로 근거가 부족하므로 `INSUFFICIENT`다. 보증 계약·확산 모델·열팽창은 짧더라도 승인 근거와 직접 충돌하는 명제를 말하므로 `CONTRADICTED`다. 수소 C5와 FTA C3의 대표 오답은 부정까지 도출되는 직접 모순이 아니라 비함의이므로 `INSUFFICIENT`다.

사전 게이트는 다음 조건을 모두 요구한다.

- 상세 통과 57/60 이상
- 모든 논리 프로브 2/3 이상
- 모든 카테고리 14/15 이상
- API·구조 계약 오류 0건

## 4. 실패 감사

### FTA C3 대표 오답 2회

학생은 역내 원산지로 인정되면 상품에 관세가 적용되고 총관세 수입이 증가한다고 설명했다. 승인 골드는 관세 혜택이 부여된다는 사실만으로 총관세 수입의 증가나 감소를 도출할 수 없다고 명시한다.

Luna는 2회에서 `관세가 적용된다`와 `관세 혜택이 부여된다`를 직접 모순으로 처리해 `CONTRADICTED`를 출력했다. 그러나 낮아진 관세가 적용되는 경우 두 명제는 함께 참일 수 있다. 총관세 수입 증가도 확립되지 않으므로 기대값 `INSUFFICIENT`가 맞다. 나머지 1회만 이를 올바르게 구분했다.

### 수소 정확 근거 1회

학생은 A의 전환율이 B보다 높고 B에는 상당한 부반응 물질이 생긴다는 사실과 ④가 적절하다는 결론을 제시했다. Luna는 2회 이를 `SUPPORTED`로 인정했지만 1회는 A의 부반응 전제와 동일 공급량의 수소 생성량 관계를 더 명시해야 한다며 `INSUFFICIENT`로 판단했다.

같은 출력에서 `④가 적절하다`를 `DECISIVE MATCHES`로 분류하면서 `sourceRefs`를 비워 structured output 후속 계약도 위반했다. 이 실행은 의미 판정과 구조 계약 모두 실패로 계산했다.

## 6. 결론

Luna는 기본 프로브에서 95%의 상세 통과율을 보였고 세 문항은 12/12였다. 그러나 직접 모순과 비함의를 구분하는 FTA 경계에서 2/3 과잉 모순 판정이 발생했고, 정확 근거에서도 구조 계약 오류가 1건 발생했다.

합의한 조건부 실행 순서에 따라 Terra 60회는 실행하지 않았다. 따라서 이번 결과는 Luna 절대 품질 게이트 실패 체크포인트이며 Terra–Luna 60쌍 비교 결과가 아니다.

다음 단계는 FTA의 `관세 적용`과 `관세 혜택` 비동치 회귀, `MATCHES | CONFLICTS`의 빈 `sourceRefs` 방지를 프롬프트 또는 출력 계약에 보강한 뒤 해당 두 프로브를 표적으로 반복하는 것이다. 표적 안정화 후 전체 Luna 60회를 새 버전으로 재실행해야 한다.

타입 빌드와 관련 집중 회귀 60/60은 통과했다. 전체 회귀는 647/648이 통과했으며, 유일한 실패는 기존부터 누락된 Hegel `.omc` 실험 산출물을 직접 읽는 무관한 테스트다.
