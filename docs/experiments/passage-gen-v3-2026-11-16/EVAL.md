### 공통 결함 (유형과 무관하게 6편 모두)
1. 문장이 잘고 많다. 평균 문장 44~54자(기출 67.6), 문장 수 31~36(기출 중앙 25, T1-1은 최대 36에 닿음). 기출은 한 문장에 조건·관계를 겹쳐 넣어 밀도가 높다.
2. 원리 문단의 개념을 단계마다 다시 대입해 준다(T1-1 "이때 제X인자는 … 기질에 해당한다", T2 5문단의 재진술). 독자가 할 적용을 지문이 대신해서 비워 둔 곳이 줄어든다 = 문항 여지 감소.
3. 범위·가정 안내 문장 과다(T3-1 1문단 가정 3문장, T3-2 1·2문단). 해설서·교과서 말투.
4. 두 번 돌린 결과가 내용까지 수렴(T2-1, T2-2 모두 크립토스포리디움 + 자외선 + 병용). 다양성 낮음.
→ 1~3은 유형별 요령 부족이라기보다 공통 규칙(W6 기전을 결과까지 직접 쓰기, C 점검, 6단계 교정)이 "빠짐없이 명시"를 밀어서 생긴 것으로 의심. 즉 시뮬레이션을 늘리기 전에 공통 규칙의 과설명 경향을 먼저 볼 가치가 있음.

### 편별
- T1-1 (중상): 조직 인자-VIIa → Xa → 트롬빈 → 피브린, 구체적 인자 이름이 기출다움. 효소·기질 재진술 과다, 6문단 3문장으로 얇고 1문단과 겹침.
- T1-2 (중): 3문단이 "활성화된 효소는 다른 응고 단백질의 활성화를 촉진한다", "이 활성 효소 등"처럼 이름을 피해 속이 비었다. 4문단 증폭(한 효소가 여러 분자)이 비워 둔 곳으로 좋음.
- T2-1 (중상, 1위): 1문단에서 두 과제를 세우고 3·5문단에서 각각 회수하는 짜임이 수능답다. 4문단 자외선량-흡수 조건이 6문단에서 회수됨. 재진술이 길다.
- T2-2 (중상): T2-1과 거의 같은 내용. 투과율 → 유효 조사량 → 6문단 조절로 이어지는 고리 좋음.
- T3-1 (중): 사실은 맞음(전자상거래 7일·소비자 부담, 방문판매 14일·사업자 부담, 포장 훼손 예외). 1문단 가정 과다, 6문단이 새 사례(온라인 예약+매장 수령)를 꺼내고 "이 두 경우를 구별해야 한다"로 끊김. 결론 없는 끝맺음.
- T3-2 (중상): 사실 맞음(불리한 약정 무효). 법정 권리와 약정 구별을 1문단에 깔고 3·6문단에서 회수하는 고리가 좋다. 가정 문장 과다, 6문단 의문문 시작은 기출에 드묾.

# 맞춰 보기 (2026-11-17)

Ghootae는 우열을 가리기 어려워 Codex 평가를 따르기로 함. Codex 평가 요지:
- 구조 구현 6편 모두 양호. 독해 훈련 가치: T1-1·T2-1·T2-2·T3-2 높음, T1-2·T3-1 중상.
- T1-2는 3문단 중간 고리가 추상화되어 물을 수 있는 관계가 덜 구체적. T3-1 끝 문단 미완결. T3-2 끝 문단은 새 규율 추가로 앞 구조와 다소 분리. T2 두 편은 추론 구조가 비슷하고 결론에서 관계를 거의 다 설명.
- 공통 문제: 설명이 너무 완결적. 핵심 구별을 정리 문장으로 반복해 줘서, 학생이 통합하지 않고 정리 문장을 찾아 옮길 수 있음.
- 권고: 생성기를 지금 크게 고치지 말고, 지문으로 문항과 학생 응답 진단을 만들어 "이해한 학생과 못 한 학생을 구별하는가"를 검증할 것.

## 같은 점
- 공통 결함 = 과설명(Claude: 원리 재진술로 비워 둔 곳 감소 / Codex: 정리 문장 반복으로 통합 불필요).
- T1-2 3문단 추상화, T3-1 끝 문단 미완결, T2 두 편 수렴을 둘 다 잡음.
- T2가 가장 잘 됐다는 데 동의(Claude 1위 T2-1).

## 다른 점
- Claude는 원인을 공통 규칙(W6 기전을 결과까지 직접 쓰기, C 점검, 6단계 교정)의 "빠짐없이 명시" 압력으로 의심했고, 문장 길이 수치(평균 44~54자 vs 기출 67.6자)를 근거로 듦. Codex는 원인을 따지지 않고 문항 쪽 검증을 먼저 하자고 함.
- Codex는 T3-1 끝 사례를 "적용 유도로 좋다"고도 봄. Claude는 끝맺음 결함으로만 봄.

## 결론
- v3는 구조 생성 실험을 통과한 후보로 둔다. 지시문은 지금 고치지 않는다(한 번 관찰로 문구 더하지 않는다는 원칙과도 맞음).
- 과설명이 실제로 문제인지는 문항을 만들어 보면 드러난다. "통합해야 풀리는 문항"이 기출보다 적게 나오면 그때 공통 규칙을 고친다.
