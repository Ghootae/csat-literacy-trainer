# v3.1 생성 문항 vs 실제 기출 문항 (2026-11-18, 웹 Claude 1인 판정)

- 생성: v3.1 지문(혈액 응고 T1-1, 수돗물 소독 T2-1)에 deep-item v4.1로 만든 8문항 (out-gen31).
- 기출: 같은 구조 대조군 지문에 실제로 딸린 문항. 도플러 혈류계(고3 2024년 5월 교육청) 4문항, mRNA 백신(고2 2023년 3월 교육청) 5문항. 어휘 문항 1개(도플러 13번)는 비교에서 뺐다 → 8문항.
- 주의: 대조군이 둘 다 **교육청** 모의고사다. 여기서 "기출 수준"은 평가원·수능이 아니라 교육청 수준이다.

## 한눈에

| | v3.1 생성 8문항 | 실제 기출 8문항 |
|---|---|---|
| 정답이 지문 한 문장으로 풀림 | 3/8 | 4/8 |
| 문항 유형 | 8개 모두 〈보기〉 적용(연구자 실험·정수장 사례) | 일치 1, 세부 이해 3, 〈보기〉 도식·그래프·과정 3, 이유 추론 1 |
| 정답이 지문에 없는 결과를 추론하게 함 | 3/8 (T1 B-V1, T1 A-V2, T2 B-V2) | 3/8 (mRNA 16·19·20) |
| 〈보기〉 길이(공백 포함) | 235~310자, 글만 | 167자 + 그림 1개 / 그림·그래프만 2개 |
| 선지 평균 길이 | 74.5자(최대 130) | 50.6자(최대 83) |
| 정답 번호 | ④ 4번, ③ 2번, ② 2번 | ⑤ 4번, ② 3번, ① 1번 |

## 판단

### 1. 깊이: 생성 쪽이 밀리지 않는다
- 한 문장으로 풀리는 정답은 생성 3/8, 기출 4/8이다. 기출 쪽 4개는 일치·세부 이해 문항(도플러 10·11번, mRNA 17·18번)이라 원래 얕게 만든 문항이다.
- 〈보기〉 적용 문항끼리만 보면 비슷하다. 기출은 3개 중 1개(도플러 11번 도식: 산란체 크기 반대로)가 한 문장으로 풀리고, 생성은 8개 중 3개다.
- 기출에서 가장 좋은 문항은 mRNA 20번(이유 추론)과 19번(〈보기〉 과정)이다. 20번은 "엔도솜 막은 세포막에서 왔다(5문단) → 인산기는 음전하(3문단) → 산성에서 이온화 지질은 양전하(5문단)"를 이어야 "양이온 지질이 막 인산기와 결합해 막이 무너진다"는 지문에 없는 결론이 나온다.
- 생성 쪽에도 같은 급이 있다. **T1 B-V1**(프로트롬빈 제거 → 트롬빈 없음 → 피브리노겐 절단 없음, 3→4→5문단 연쇄)과 **T2 B-V2**(유기물이 유리 염소를 소비 → 암모니아와 반응할 염소 감소 → 모노클로라민 생성 조건 재점검)는 지문에 적히지 않은 결과를 추론하게 한다. 깊이로는 mRNA 19·20번과 견줄 만하다.

### 2. 전형성: 생성 쪽이 뚜렷이 밀린다 (이번 비교의 핵심)
- **유형이 한 가지뿐이다.** 기출 세트는 일치 → 세부 → 〈보기〉 적용 → 추론으로 쉬운 것부터 어려운 것까지 섞는다. 생성 8문항은 모두 "윗글을 바탕으로 〈보기〉를 이해한 내용으로"다. deep-item은 원래 고난도 1~2문항용이라 당연하지만, 세트로 팔려면 나머지 유형 생성기가 따로 필요하다.
- **〈보기〉가 길고 모두 같은 틀이다.** 생성 〈보기〉는 전부 "연구자는 … 갑·을 … 했다. 그러자 …" 같은 실험 서사이고 235~310자다. 기출 〈보기〉는 도식(탐촉자-피부-연부 조직-혈액-적혈구), 그래프(도플러 변위-시간), 공정 그림+짧은 설명(167자)이다. 기출은 **지문 내용을 다른 형식으로 바꿔 보여 주고**, 생성은 **지문 내용을 다시 이야기로 써 준다.** 앞의 판정에서 나온 "〈보기〉가 지문 표현을 그대로 옮긴다"는 문제와 같은 뿌리다.
- **선지가 길다.** 생성 74.5자, 기출 50.6자. 생성 선지는 "~했다면, ~더라도, ~하겠군" 같은 조건을 두세 겹 단다. 기출 선지는 조건 하나에 판단 하나다(예: "ⓑ보다 ⓒ가 송신 주파수와 수신 주파수의 차이가 크다고 볼 수 있겠군").
- **오답을 만드는 방식이 다르다.** 기출 오답은 짧은 뒤집기다(크기 작을수록 → 클수록, 원인을 pH 대신 mRNA 결합으로, 저장 장소를 탐촉자 대신 영상 장치로). 생성 오답도 뒤집기가 있지만(T1 A-V2 ③ 효소 혼동은 기출 18번과 같은 결), 가정 상황을 더 얹어 길어진다.
- 정답 번호: 생성은 ④가 8개 중 4개다. 표본이 작아 단정할 수 없지만, 대량 생성 때 번호 섞기를 확인할 거리다.

### 3. 품질 결함
- 생성: 자동 설계 검사 지적 9개(〈보기〉만으로 판단 가능, V1·V2 같은 착각, 〈보기〉 정보 부족). 사실 오류는 없다.
- 기출: 교육청 문항답게 엄밀하지 않은 곳이 있다. mRNA 19번 정답 해설은 "중성이 되면 소수성이 강해진다"에 기대는데, 지문에 그렇게 적혀 있지 않다. 생성 쪽 설계 검사였다면 걸렸을 지점이다.

## 결론
- **깊이는 교육청 기출과 비슷하거나 낫다.** v3.1 지문 + deep-item으로 지문에 없는 결과를 추론하게 하는 문항이 나온다.
- **모자란 것은 전형성이다.** 문항 유형 다양성, 〈보기〉 형식(도식·그래프·짧은 과정), 선지 길이. 학생이나 모의고사 회사가 보면 "수능 같다"보다 "실험 서사가 긴 문제집 같다"고 느낄 가능성이 크다.
- 다음 손질 순서 제안: ① deep-item 〈보기〉를 "지문 내용을 다른 형식(표·도식·그래프 설명·짧은 과정)으로 바꿔 보여 주기"로 고치고 길이 상한을 둔다(기출 〈보기〉 길이 분포는 BOGI-LENGTH.md에 이미 있음). ② 선지를 조건 하나·판단 하나로 줄인다. ③ 세트 판매를 목표로 하면 일치·세부·추론 유형 생성기를 따로 둔다.

## 한계
기출 쪽이 교육청 2세트, 판정자 1인. 평가원·수능 대조는 아직 없다. 그림·그래프 〈보기〉는 생성기가 그림을 못 만들어서 같은 조건 비교가 아니다(글로 된 표·과정 설명은 가능).

## 바로잡기 (2026-11-18, set-pattern-2026-11-18/SET-PATTERN.md)
158세트 3점 〈보기〉 문항으로 다시 재 보니 〈보기〉 글 길이 중앙값은 293자(95~565), 평가원·수능은 308자다. 위에서 "생성 〈보기〉가 길다(235~310자 vs 167자)"고 한 것은 교육청 2세트에 치우친 비교라 틀렸다. 생성 〈보기〉 길이는 정상 범위다. 선지는 생성 74.5자 vs 기출 3점 평균 58.9자(평가원·수능 63.6자)로 여전히 길지만 차이는 작다. 남는 차이는 〈보기〉 갈래(생성은 실험·운영 서사뿐, 기출은 사례 32%·그림·표 39%·외부 글 19%·실험 6%)다.
