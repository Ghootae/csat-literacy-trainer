# 세 갈래 독해 품질 검토 · 2026-11-18

자료는 같은 폴더의 READ-three-way.md이며 사용자 첨부본과 바이트 단위로 일치한다. 지문 v3.1과 심화 문항 v4.1, 고3 2024년 5월·고2 2023년 3월 교육청 전사본을 사용했다. 생성물은 A·B 두 양식의 버전 V1·V2이다. 새 호출 모델 생성이나 학생 실험은 수행하지 않았다. 정답표가 포함된 자료의 내용 감사다.

## 측정

생성 혈액·수돗물은 각각 6문단 390·409어절, 기출 도플러·백신은 4·5문단 355·420어절이다. 문단 본문만 공백 분리해 셌다. 선지 번호·양끝 공백을 제외한 선지 평균 길이는 생성 지문 조건 40선지 74.5자, 기출 지문 생성 조건 40선지 64.0자, 교육청 45선지 47.2자다. 생성 16문항 모두 텍스트 보기이며 기출 9문항 중 3문항에 도식·그래프·과정 자료가 있다. 생성 4개 지문 모두 A-V1과 B-V1의 키는 ④다. 번호 배열에 대한 관찰이며 출제기 전반의 편향 추정은 어렵다.

## 풀이 감사

표의 번호는 전사본 의도 답과 대조했다. 문항별로 충분한 풀이 한 가지를 제시하며 실제 학생의 풀이 시간·선택률은 미측정이다.

## 해석과 한계

정답 25개 모두 의도한 키와 일치한다. 선지별 입증 강도는 다르다. 백신 기출 18번 ④의 혈장 단백질 전하는 본문에서 직접 명시하지 않고, 19번 ②의 유량 조절과 균일도 관계도 첨부 자료에서 간접적이다. 19번의 소수성 변화 역시 추가 추론을 요구한다. 복원본만으로 공식 시험 오류를 단정하기 어렵다.

앞선 COMPARE-REAL-ITEMS.md는 생성 지문 조건과 기출을 비교하며 어휘를 제외했다. 이번에는 기출 지문에 생성한 8문항까지 포함했다. 기존 보고서에서 높게 평가한 소독 B-V2는 인과 연결 자체는 타당하나 답에 그 연결이 풀어 쓰여 있고 관찰 결과가 필수가 아니므로, 백신 기출 20번과 추론 부담이 동등하다고 판정할 근거가 부족하다.

두 주제 짝은 같은 지문을 출처만 바꾼 통제 실험이 아니다. ②와 ③만 동일 지문 비교다. 생성 심화 유형과 기출 혼합 세트의 역할 차이, 기출의 학년 차이, 그림 전사, 작은 표본이 남는다. 지문별 성취, 실험 정보 제거 대조 사례, 다음 단계 선택지는 동반 인간 보고서에 제시했다. 후속 검증 후보는 같은 지문과 목표 유형을 맞춘 학생 풀이 및 오답 선택 근거 수집이다.
