# 4단계 3회차(v6.2) 결과 — 사람용 요약 (2026-11-24)

## 1. 개요
1) **목적**: 1·2회차에서 v6·v6.1 문항은 '수능 같음' 0/16이었다. 평가자가 반복해서 적은 원인은 "오답이 지문의 개념 정의를 선지 안에서 뒤집어서 〈보기〉를 안 봐도 지워진다"였다. 그래서 v5에는 있었는데 v6에서 빠진 옛 C23을 생성 기준 GN1로 되살리고(〈보기〉 없이 풀리는 선지는 많아야 1개, 쉬움 자리에만 / 정의를 뒤집어 거짓을 만들지 않음) 같은 4칸을 다시 만들었다. (이름은 그래프 갈래에 이미 G1이 있어 GN1로 썼다.)
2) **결과**
- 4문항 모두 결함·수리·재생성 없음. 비용 $1.94(상한 $3).
- v6.2 평균 1.562, 같은 회차 v5 평균 1.000, 차이 +0.562. 기준 ① 수능 아님 2회↑ 0개 / ② +0.562 / ③ 수능 같음 3회↑ **3개**(공시 A, 공시 B, 의미 B) / ④ 결함 0개.
- '수능 같음'은 9/16(1·2회차는 0/16).
- 〈보기〉 없이 풀리는 선지(판정자 표시) 문항당 평균: v5 1.25 → v6 2.00 → v6.1 2.75 → **v6.2 1.50**. 평가자 ㉯ 표시 횟수도 2.25 → 3.00 → 1.00으로 내려갔다.
- 단, 이번 회차에서 v5와 기출의 평균도 같이 내려갔다(v5 4문항 평균 4단계 1.375 → 이번 1.000). 같은 회차 비교(+0.562)와 회차 사이 절대값 비교는 읽기가 다를 수 있다.
3) **다음 스텝**: 웹이 PROPOSAL-v62의 "넷 다 지킴 → 채택" 갈래에 해당하는지, v5 흔들림을 어떻게 볼지 판단한다.

## 2. 본문
### 2-1. 반영 (해결)
문제: v6에서 C23이 빠졌다. 과정: rules-common-v6.md에 GN1 문단과 '생성 기준' 층 행, run.mjs 3단계 4번에 한 문장을 넣었다. 검사기·수리 기준은 안 건드렸다. 결과: 테스트 11/11, v5 경로 지시문 바이트 동일. (문안을 그대로 옮겨서 '옛 C23'이라는 글자가 모델 지시문에 남는다.)

### 2-2. 공시 A·B에서 올랐다 (관찰)
공시 A: 1회차 v6 1.00, 2회차 v6.1 1.00, 이번 v6.2 **1.75**(수능 같음 3회). 평가자 이유는 "사모 가정을 적용한 뒤 지난 분기와 이번 분기의 신고서·정기 공시 의무를 비교해야 오류가 드러난다"로 바뀌었다. 판정자 표시 '지문만' 선지도 2 → 1로 줄었다.
공시 B: 1.00 → **1.75**, ㉯ 4회 → 1회.

### 2-3. 의미 A는 그대로 (미해결·관찰)
의미 A는 4회 모두 '중'(평균 1.00)이다. 이유는 모두 "같은 표본이라는 설정 때문에 핵심 판단이 쉬워진다"로 같다. GN1이 겨냥한 '정의 뒤집기'와는 다른 약점으로 읽힌다.

### 2-4. 의미 B는 올랐지만 ㉯가 남음 (관찰)
평균 0.75 → 1.75, 수능 같음 3회. 그래도 ㉯가 3회 표시됐고 판정자 '지문만' 선지는 2개다.

### 2-5. 평가자·비교 기준의 흔들림 (판단 필요)
v5 4문항 평균: 4단계 1.375, 2회차 1.375, 이번 1.000. 공시 v5 A는 2.00 → 1.25로 내려갔다(같은 문항). 기출 23번도 1.75 → 1.25. 이번 회차는 평가자가 전체적으로 엄했을 수 있고, 그러면 v6.2의 절대 평균이 회차 간 비교에서 더 높게 읽힌다. 같은 회차 비교(v6.2 대 v5 +0.562)와 기출 비교(v6.2 평균 1.562 대 기출 두 문항 1.625)를 함께 볼 필요가 있다.
