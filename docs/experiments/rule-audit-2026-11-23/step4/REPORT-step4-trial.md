## 3. 2문항 이상 반복된 결함과 원인(평가자 이유 기준, 관찰)

- ㉯(〈보기〉 없이 풀리는 선지 2개 이상): 가·다·마·바·사·차 6문항(생성 5, 기출 1). v6 4문항 중 3문항(가·다·차). 평가자 이유는 "오답이 지문의 기본 개념을 뒤집은 것이라 〈보기〉 없이 배제됨"(다·차), "정답 대입 한 번으로 끝남"(가).
- 이 판정은 표시 판정의 M4와 방향이 다르다. 판정자 다수값으로는 v6 생성 4문항의 M4 위반이 0이다(2절 c 표). 평가자 ㉯와 판정자 M4가 서로 다른 것을 재고 있을 수 있다(관찰, 미확인).
- ㉳(정답 시비): 바 1문항(3회).
- 관찰: v6 4문항의 등급이 모두 정확히 1.0이고 4명 모두 '중'(표준편차 0)이다. 평가자가 v6 문항을 한결같이 '중'으로 본다. 원인은 이 데이터로 가를 수 없다.
- 관찰: 의미 기출 23번은 4회 등급이 2·1·2·1(수능 같음 2/4)로 갈렸다. PLAN 3절 '평가 정상 확인'은 의미 기출만 흔들리면 기록하고 계속이다. 공시 기출 12번은 4/4 수능 같음.
