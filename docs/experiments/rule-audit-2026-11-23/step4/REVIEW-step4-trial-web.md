## 3. 왜 그런가 (해석, 측정과 구분)

### 3-1. v6가 고른 선택 전략은 깊이를 만들지 않는 것들이었다 (측정)

| v6 문항 | 고른 전략 |

| 의미 A | S1, **S9**, **S19** |

### 3-2. 해석
- 감사는 "기출이 늘 지키지는 않는 규칙"을 의무에서 선택으로 내렸다. 맞는 판단이지만, 선택권을 모델에 주자 모델은 지키기 쉬운 전략으로 칸을 채웠다. 기출은 문항마다 서로 다른 깊이 장치를 쓰는데, "아무거나 1~3개"는 "깊이 장치 하나 이상"을 보장하지 못한다.
- 그래서 고칠 곳은 층 나누기 자체가 아니라 **선택 규칙**이다. 깊이 장치 가운데 하나는 반드시 고르게 해야 한다.

### 3-3. 평가자 결함 표시 ㉯는 옛 C23 기준이다 (측정 도구 문제)
- 블라인드의 ㉯ 정의는 "〈보기〉를 안 봐도 풀리는 선지 2개 이상"으로, 감사가 지운 C23과 같다. v6 3문항이 ㉯를 받았고, 기출 23번도 ㉯ 3회를 받았다.
- 판정자 표시로는 '지문만' 선지 수가 v6 2.0, v5 1.25, 본 감사 기출 1.88, 확인용 기출 2.71이다. v6는 기출 범위 안이다. M4(지문만 + 내용 확인 ≤1) 위반은 v6 0이다.
- 즉 ㉯는 이제 결함이 아니라 기출에도 흔한 모습이다. 다만 등급이 ㉯ 때문에 내려갔는지는 가를 수 없다. 평가자 이유("오답이 지문 기본 개념을 뒤집은 것이라 〈보기〉 없이 배제됨")는 '지문만'보다는 '오답이 얕다'를 가리킨다. 이것은 3-1과 같은 방향이다(S4 미선택).
- 다음 블라인드부터 ㉯를 M4 뜻("지문 문장 확인만으로 풀리는 선지 2개 이상")으로 바꾸는 안이 있다. 단, 같은 회차 안의 v5·v6 비교에는 영향이 같아서 이번 결론을 뒤집지는 않는다.
