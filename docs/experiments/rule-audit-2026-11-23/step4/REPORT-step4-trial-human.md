# 규칙 감사 4단계 시험: 사람용 보고 (2026-11-24)

## 1. 개요

1) **목적.** 규칙을 v5에서 v6로 줄이고 층을 나눴을 때(규칙 수 58→44 등) 만들어지는 문항이 떨어지지 않는지 본다. 같은 지문·같은 1·2단계에서 3단계부터만 v5·v6로 갈라 만들었다(공시 사례 2 + 의미 관점 2, 각 A·B형 V1). 확인용 기출 7개로 새 검사기(e3)가 기출을 괴롭히지 않는지도 봤다.

2) **결과.**
- v6 4문항은 평가자 4명 모두에게 '중'(평균 1.0)이었다. 수능 아님은 0회. v5 4문항 평균은 1.375, 차이 −0.375(PLAN 기준 0.5 안쪽). 지문별로는 공시 −0.75, 의미 0.0.
- 결함으로 끝난 v6 문항은 없다(재생성 0, 수리 0).
- '지문만으로 풀리는 선지'(표시 판정): v6 2.0개/문항, v5 1.25개, 확인용 기출 2.71개, 본 감사 기출 1.88개. 즉 v6가 v5보다 적지 않았다(M4가 작동한 신호는 이 표본에선 안 보임).
- 확인용 기출 7개 중 4개가 수리 대상(관점·기타 4개 전부). 새 e3도 기출을 꽤 잡는다.
- 비용 $3.46(상한 $6).
- **정정:** 확인용 기출 목록의 `2024-09-평가원-16`은 오기이고 `2024-06-평가원-16`이 맞다(웹이 정정). 7개로 돌렸다.

3) **다음 스텝.** 웹이 v6 채택·e4(수리) 유지·순서표를 판단한다(아래 표).

## 2. 본문

### 문제 1. v6가 v5보다 나빠졌는가 (판단 필요)
**어떤 문제가:** 규칙을 줄이면 등급이 떨어질 수 있다.
**과정:** 공시 A·B, 의미 A·B를 v6로, 의미 2개를 v5로 새로 만들고(공시 v5 2개는 재사용), 기출 12·23번을 섞어 평가자 4명이 출처 없이 판정했다.
**결과:** 아래 표. v6는 전부 '중', v5는 수능 같음이 섞였다.

| 문항 | 4회 등급 | 평균 |
|---|---|---|
| 공시 v5 A | 2 2 2 2 | 2.00 |
| 공시 v5 B | 2 1 1 2 | 1.50 |
| 공시 v6 A | 1 1 1 1 | 1.00 |
| 공시 v6 B | 1 1 1 1 | 1.00 |
| 의미 v5 A | 1 2 2 2 | 1.75 |
| 의미 v5 B | 0 1 0 0 | 0.25 (정답 시비 ㉳ 3회) |
| 의미 v6 A | 1 1 1 1 | 1.00 |
| 의미 v6 B | 1 1 1 1 | 1.00 |
| 기출 공시 12 | 2 2 2 2 | 2.00 |
| 기출 의미 23 | 2 1 2 1 | 1.50 |

직관으로 말하면, v6 문항은 "정답은 맞고 깔끔하지만 수능이라고 하기엔 한 단계 모자란" 문항으로 읽혔다. v5 의미 B의 0.25는 정답 시비 때문이라 v6 의미 B(1.0)와의 차이는 문항 우연일 수 있다. 판단은 웹.

### 문제 2. 지문만으로 풀리는 선지가 줄었는가 (미해결)
사례: v6 공시 B(`S05`)는 지문만으로 정해지는 선지가 ②·④ 2개(판정자 다수값)이고 둘 다 '내용 확인'은 아니라 M4는 통과다. 반면 평가자는 같은 계열 문항에 ㉯(〈보기〉 없이 풀리는 선지 2개 이상)를 4번 줬다. 두 잣대가 다르게 센다. 이 표본에선 v6 쪽이 더 적다는 신호가 없다.

### 문제 3. 새 e3가 기출을 괴롭히는가 (판단 필요)
확인용 7개 중 수리 대상 4개: 2024-06-평가원-16(M2·M3), 2025-11-수능-16(M3·M4), 2025-11-수능-17(M2·M3·M4), 2024-06-평가원-14(M3·M5). 사례·표 3개는 안 걸렸다. e3와 판정자 다수값은 M2~M4 33칸 중 26칸(79%) 같고, 불일치 7건 중 3건이 2025-11-수능-17에서 났다. PLAN 4-3은 "기출 2개 이상 수리 대상이면 기준 다시 보기"다.
