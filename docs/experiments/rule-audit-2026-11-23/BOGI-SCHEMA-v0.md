# 〈보기〉·문항 단위 표시표 v0 (규칙 감사 2단계 2회)

- 작성: 웹 스레드 "규칙 점검 방향 이어가기", 2026-11-23 22:0x (Ghootae "추천대로"). 선지 표시표(MARKING-SCHEMA-v2)로 잴 수 없는 〈보기〉 작성 규칙·선지 배치 규칙을 잰다.
- 이 표는 판정자에게 그대로 준다. 판정자는 문항이 기출인지, 출처, 이전 평가를 모른다.
- 따로 시범을 하지 않는다. 이번 판의 칸별 일치율이 0.75 미만인 칸은 준수율 집계에서 뺀다(PLAN 8절).

## 판정자에게 주는 안내

너는 고등학교 국어 독서 문항을 분석한다. 문항마다 지문, 〈보기〉, 발문, 선지 다섯 개를 받는다.

1. 먼저 문항을 직접 풀고 답 번호를 적는다(`answer`).
2. 그다음 문항 하나에 아래 칸 B1~B11을, 선지마다 O1을 표시한다. 정해진 값 중에서만 고른다. 어느 값도 맞지 않으면 "애매"를 고르고 `note`에 이유를 한 줄 쓴다.
3. 문항이 좋은지 나쁜지는 평가하지 않는다. 문항이 어떻게 만들어졌는지만 표시한다.
4. 외부 지식은 쓰지 않는다. 지문과 〈보기〉, 선지에 적힌 내용만으로 판단한다.
5. 용어: **판정 라벨** = 선지가 "〈보기〉의 이것은 지문의 ○○에 해당한다/○○이다"라고 판정할 때 쓰는 지문의 개념어. **〈보기〉 사실** = 〈보기〉가 전하는 낱개의 상태·사건·값·발화 하나.

## 문항마다 표시하는 칸

| 칸 | 이름 | 값 | 표시 방법 |
|---|---|---|---|
| B1 | 〈보기〉가 이름을 비운 판정 라벨 수 | 0 / 1 / 2 / 3 이상 / 애매 | 선지들이 판정에 쓰는 지문 개념어 가운데 〈보기〉에는 나오지 않는(학생이 스스로 붙여야 하는) 것의 수 |
| B1a | 〈보기〉가 이미 쓴 판정 라벨 수 | 0 / 1 / 2 이상 / 애매 | 선지들이 판정에 쓰는 지문 개념어 가운데 〈보기〉가 그 이름을 그대로 쓴 것의 수 |
| B2 | 목적·까닭·판정 결론 진술 | 없음 / 있음-정오에 안 쓰임 / 있음-정오에 쓰임 / 애매 | 〈보기〉에 목적("~하려고", "~위해"), 까닭 풀이("~ 때문에", "그래서 ~하기로"), 판정 결론("~에 해당했다", "~ 대상이 되었다") 중 하나라도 있는가. 있으면, 그 문장이 어느 선지의 정오를 가르는 데 직접 쓰이는가 |
| B3 | 정답을 가르는 관계의 직접 진술 | 아니오 / 예 / 애매 | 정답의 정오를 가르는 대응·순서·소속 관계(무엇이 무엇을 가리키는지, 무엇이 먼저인지, 무엇이 어느 관점의 기준에 걸리는지)를 〈보기〉 문장이 그대로 말해 주는가 |
| B4 | 〈보기〉 주체 수 | 1 / 2 / 3 이상 / 해당 없음 / 애매 | 〈보기〉에서 행동하거나 상태가 바뀌는 사람·기관·대상의 수. 표·그래프만 있는 〈보기〉는 해당 없음 |
| B4b | 서로 독립된 사안 수 | 1 / 2 / 3 이상 / 애매 | 서로 원인·순서로 이어지지 않는 사건 흐름·사례·관점의 수. 한 주체의 이어지는 일들은 1, 나란히 놓은 두 사례는 2 |
| B5 | 선지가 쓰지 않는 〈보기〉 사실 | 0 / 1 / 2 이상 / 애매 | 어느 선지의 정오 판정에도 쓰이지 않는 〈보기〉 사실의 수. 대상을 소개하는 배경 문장도 센다 |
| B6 | 평가자·평가 대상의 출처 | 〈보기〉는 평가자만 / 〈보기〉는 대상만 / 〈보기〉가 둘 다 / 해당 없음 / 애매 | 선지가 "A의 입장에서 B를 평가"하는 꼴일 때, 평가자(관점·이론·인물)와 평가 대상(사례·주장) 중 무엇을 〈보기〉가 주는가. 그런 꼴이 아니면 해당 없음 |
| B7 | 지문 예외·단서의 활용 | 지문에 없음 / 있음-〈보기〉가 씀 / 있음-〈보기〉가 안 씀 / 애매 | 지문에 예외·단서 문장("다만", "~라도", "이때에도", "~인 경우에는 제외")이 있는가. 있으면 〈보기〉에 그 경계에 걸리는 사실이 있는가 |
| B8 | 지문 예시와 〈보기〉의 관계 | 지문에 예시 없음 / 구조가 다름 / 이름만 바꾼 꼴 / 애매 | 지문이 사례·사고 실험·대표 예를 들었는가. 들었다면 〈보기〉가 그 예와 대상 수·성립 조건·결과 방향 중 하나 이상이 다른가 |
| B9 | 〈보기〉 인물의 발화 | 발화 없음 / 행동·판단·근거만 / 지문 원칙과 맞대는 선언 있음 / 애매 | 〈보기〉 인물이 말하는가. 말한다면 자기 판단·근거만 말하는가, "이는 ○○ 관점과 같다"처럼 지문의 원칙·관점과 직접 맞대어 말하는가 |
| B10 | 관찰·측정 결과의 제시 | 해당 없음 / 결과까지 있음 / 행위만 있는 문장 있음 / 애매 | 〈보기〉에 관찰·측정·실험 문장이 있을 때, 그 결과(값·상태)까지 적혀 있는가, "~을 측정했다"처럼 행위만 있고 결과가 없는 문장이 있는가 |
| B11 | 결론만 반대인 선지 짝 | 없음 / 있음 / 애매 | 같은 대상·같은 비교를 두고 결론만 반대인 두 선지(같다/다르다, 많다/적다)가 있고, 그중 하나가 정답인가 |

## 선지마다 표시하는 칸

| 칸 | 이름 | 값 | 표시 방법 |
|---|---|---|---|
| O1 | 근거 문단 | 문단 번호 목록 (예: [2, 5]) / 지문 근거 없음 | 그 선지의 정오를 확정하는 데 쓰는 지문 문단의 번호. 지문에 문단 번호가 없으면 위에서부터 센다 |

## 출력 형식 (판정자)

문항마다 JSON 한 줄:

```json
{"packet_id": "M07", "answer": 3, "B1": "1", "B1a": "2 이상", "B2": "없음", "B3": "아니오", "B4": "2", "B4b": "1",
 "B5": "0", "B6": "해당 없음", "B7": "있음-〈보기〉가 씀", "B8": "구조가 다름", "B9": "발화 없음", "B10": "해당 없음", "B11": "없음",
 "O1": {"1": [2], "2": [3, 5], "3": [4], "4": [1], "5": [5]}, "note": ""}
```

## 판정자 없이 스크립트로 세는 것 (CLI)

- C8·A22·B25: 선지마다 문장 수, "~라면/~면/~ㄹ 경우" 가정 표현 수.
- C9: 정답 선지의 글자 수 순위(1 = 가장 긺, 같으면 같은 순위).
- C10: 정답 번호.
- A15·B17: 단정어(모든, 반드시, 항상, 오직, 전혀, 결코, ~만) 수를 선지마다. 선지 표시의 F1(참·거짓) 다수값과 함께 적는다.
