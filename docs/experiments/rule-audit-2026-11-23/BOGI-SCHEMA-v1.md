## 판정자에게 주는 안내

너는 고등학교 국어 독서 문항을 분석한다. 문항마다 지문(문단 번호), 〈보기〉(문장 번호 b1, b2, …), 발문, 선지 다섯 개, 그리고 스크립트가 찾아 둔 후보 목록을 받는다.

1. 먼저 문항을 직접 풀고 답 번호를 적는다(`answer`).
2. 아래 칸 K1~K4를 표시한다. 정해진 값 중에서만 고른다. 어느 값도 맞지 않으면 "애매"를 고르고 `note`에 이유를 한 줄 쓴다.
3. 문항이 좋은지 나쁜지는 평가하지 않는다. 외부 지식은 쓰지 않는다.

## 칸

| 칸 | 이름 | 값 | 표시 방법 |
|---|---|---|---|
| K1 | 목적·까닭 표지 (후보마다) | 서술자 풀이 / 인물·학자의 말 / 표지 아님 / 애매 | 후보 목록 `cand_bogi`의 각 후보(〈보기〉 문장 번호 + 표지 글자)에 대해 고른다. **서술자 풀이** = 〈보기〉를 쓴 사람이 누가 무엇을 하려고 했는지, 일이 왜 일어났는지를 설명함. **인물·학자의 말** = 〈보기〉 속 인물의 발화나 새 관점 글(학자의 주장·근거) 안에 있음. **표지 아님** = 글자는 같지만 목적·까닭의 뜻이 아님(예: "~를 위해 쓰이는 장치"처럼 용도를 말하는 명사구) |
| K2 | 선지가 판정하는 지문 개념어 (선지마다) | 낱말 목록 (0~3개) | 선지가 "〈보기〉의 무엇은 ○○에 해당한다 / ○○이다 / ○○로 볼 수 있다 / ○○가 성립한다 / ○○를 충족한다"처럼 **판정하는 자리**에 놓은 지문 개념어 ○○를 적는다. 지문에 나온 꼴 그대로, 조사를 떼고 명사(구)만 적는다. 인물·이론 이름(평가자)과 〈보기〉 대상 이름은 적지 않는다. 없으면 빈 목록 |
| K3 | 〈보기〉 문장이 쓰이는 선지 (〈보기〉 문장마다) | "소개" / 선지 번호 목록 | 〈보기〉 문장 b1, b2, …마다, 그 문장이 없으면 정오를 확정할 수 없게 되는 선지 번호를 적는다. 대상을 소개만 하는 문장(무엇이 등장하는지, 표가 무엇을 잰 값인지)은 "소개". 어느 선지에도 필요 없으면 빈 목록 |
| K4a | 지문 예외·단서·경계 (후보마다) | 예 / 아니오 / 애매 | 후보 목록 `cand_passage`의 각 후보(지문 문단·문장 + 표지 글자)가 원칙에 대한 예외·단서이거나, 경계가 있는 기준("이상/미만", 기간, 선후)인가 |
| K4b | 그 경계에 걸리는 〈보기〉 문장 (K4a가 "예"인 후보마다) | 〈보기〉 문장 번호 하나 / 없음 / 애매 | 〈보기〉에서 그 예외·단서의 조건이나 기준의 경계에 걸리는 사실·값을 담은 문장 |

## 출력 형식 (판정자)

문항마다 JSON 한 줄:

```json
{"packet_id": "M07", "answer": 3,
 "K1": {"c1": "서술자 풀이", "c2": "인물·학자의 말"},
 "K2": {"1": ["외부 효과"], "2": [], "3": ["공공재"], "4": ["외부 효과"], "5": []},
 "K3": {"b1": "소개", "b2": [1, 4], "b3": [2], "b4": []},
 "K4a": {"p1": "예", "p2": "아니오"}, "K4b": {"p1": "b3"},
 "note": ""}
```

## 스크립트가 하는 일 (CLI, 판정자 없음)

- 〈보기〉를 문장 단위로 나눠 b1, b2, …를 붙인다. 표는 안내 글 문장 + 표의 행 하나를 한 단위로 센다. 그래프 읽기 판은 줄 하나를 한 단위로 센다.
- `cand_bogi`(K1 후보): 〈보기〉에서 "하려고", "하려", "위해", "위하여", "려는", "알아보려", "때문에", "때문이", "탓에", "그래서", "따라서", "덕분에" 를 찾아 c1, c2, …로 번호를 붙인다(문장 번호와 앞뒤 10자 포함).
- `cand_passage`(K4 후보): 지문에서 "다만", "단,", "이때에도", "이 경우에도", "라도", "더라도", "경우에는", "예외", "제외", "이상", "이하", "미만", "초과", "이내", "이전", "이후", "기간" 을 찾아 p1, p2, …로 번호를 붙인다(문단·문장 번호와 문장 전체 포함). 한 문장에 여럿이면 후보 하나로 합친다.
- R2 준수 계산: K2 다수 목록의 낱말이 〈보기〉 원문에 글자 그대로 나오는지 맞춰 본다.

## 일치율과 준수 계산 (집계)

- K1: 후보마다 세 판정자 값의 일치(쌍 일치율 평균). 문항 준수 = 다수값이 "서술자 풀이"인 후보가 없음.
- K2: 선지마다 세 판정자 목록의 자카드 평균(셋 다 빈 목록이면 1). 다수 목록 = 둘 이상이 적은 낱말. 문항 준수 = 다수 목록의 낱말이 하나도 〈보기〉에 그대로 나오지 않음.
- K3: 〈보기〉 문장마다 자카드 평균("소개"는 "소개"끼리만 일치). 문항 준수 = "소개"가 아닌 문장 중 다수 목록이 빈 문장이 없음.
- K4a: 후보마다 쌍 일치율. K4b: K4a 다수값이 "예"인 후보마다 쌍 일치율. 문항 적용 = K4a "예" 후보가 하나 이상, 문항 준수 = 그중 하나 이상의 K4b 다수값이 문장 번호.
- 기준: 칸별 0.75 이상이면 그 칸으로 준수율을 센다(PLAN 2-2). 못 넘으면 그 규칙은 작성 규칙(R) 또는 선택 전략(S)으로 두고 더 재지 않는다(PROPOSAL 5-5).
