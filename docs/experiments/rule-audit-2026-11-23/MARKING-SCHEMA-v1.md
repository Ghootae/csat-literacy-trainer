# 선지 표시 항목 표 v1 (규칙 감사 1단계 시범 2회차용)

- 작성: 웹 스레드 "규칙 점검 방향 이어가기", 2026-11-23. 바탕은 인계서 `2026-11-23-rule-audit-direction.md` 2절 4번(코덱스 2차 수정안).
- 이 표는 판정자에게 그대로 준다. 판정자는 문항이 기출인지 생성인지, 출처, 이전 평가를 모른다.
- v0 → v1 (2026-11-23, 시범 1회차 결과, Ghootae "추천대로"): F4를 작업 종류(F4)와 근거 수(F4b)로 나눔, F6은 〈보기〉가 필요한 선지에만 물음, F3은 주된 값 하나 + 필요하면 하나 더, '정의·주장'의 뜻을 좁힘.

## 판정자에게 주는 안내

너는 고등학교 국어 독서 문항을 분석한다. 문항마다 지문, 〈보기〉, 발문, 선지 다섯 개를 받는다.

1. 먼저 문항을 직접 풀고 답 번호를 적는다(`answer`).
2. 그다음 선지마다 아래 칸 F1~F8을 표시한다. 정해진 값 중에서만 고른다. 어느 값도 맞지 않으면 "애매"를 고르고 `note`에 이유를 한 줄 쓴다.
3. 문항이 좋은지 나쁜지는 평가하지 않는다. 선지가 어떻게 만들어졌는지만 표시한다.
4. 외부 지식은 쓰지 않는다. 지문과 〈보기〉, 선지에 적힌 내용만으로 판단한다.

## 선지마다 표시하는 칸

| 칸 | 이름 | 값 | 표시 방법 |
|---|---|---|---|
| F1 | 내용상 참·거짓 | 참 / 거짓 / 판정 불가 / 애매 | 발문 방향과 관계없이 선지 진술 자체가 지문·〈보기〉에 비추어 참인지 |
| F2 | 최소 충분 근거 | 지문만 / 〈보기〉만 / 둘 다 / 둘 없이도 가능 / 판정 불가 / 애매 | F1을 확정하는 데 꼭 필요한 최소 자료. **"지문만"은 선지에 이미 적힌 조건·자료를 사실로 받아들인 상태에서 지문만 보면 된다는 뜻이다.** 거짓 선지는 거짓이 처음 확정되는 곳까지만, 참 선지는 모든 부분이 확인되는 곳까지 본다 |
| F2a | 근거 위치 | 자유 기술 한 줄 | 예: "지문 3문단 둘째 문장 + 〈보기〉 둘째 사실". 결정적 관계를 한 구절로 덧붙인다 |
| F3 | 내용의 기능 (주된 값 1개 + 필요하면 1개 더) | 정의·주장 / 조건·범위·예외 / 이유·인과 / 비교·귀속 / 개별 사실 / 애매 | F1을 가르는 바로 그 구절이 글에서 하는 역할. **정의·주장은 개념의 뜻 전체나 인물·이론의 기본 입장 그 자체에서 정오가 갈릴 때만** 고른다. 정의 안의 조건·범위 한 부분에서 갈리면 조건·범위·예외, 둘 이상의 대상·관점을 견주거나 누구의 것인지에서 갈리면 비교·귀속, 원인·근거에서 갈리면 이유·인과, 수치·명칭 같은 낱개 정보에서 갈리면 개별 사실. 출력은 `F3` = 주된 값 문자열, `F3b` = 둘째 값 문자열 또는 빈 문자열 |
| F4 | 작업 종류 (하나) | 내용 확인 / 짝짓기 / 원리 적용 / 애매 | 내용 확인 = 선지 진술이 지문(또는 〈보기〉)의 진술과 같은지 대조하면 끝. 짝짓기 = 〈보기〉의 대상·사례가 지문의 어느 개념·범주·관점에 해당하는지 정하면 끝. 원리 적용 = 지문의 원리·인과·규칙을 〈보기〉 상황에 돌려 지문에 직접 적히지 않은 결과를 끌어내야 함. 셋이 섞이면 가장 뒤의 것(원리 적용 > 짝짓기 > 내용 확인)을 고른다 |
| F4b | 함께 써야 하는 근거 수 | 1 / 2 / 3 이상 | F1을 확정하는 데 동시에 써야 하는 근거 단위의 수. 근거 단위 = 지문의 원리·조건·사실 하나, 또는 〈보기〉의 사실 하나. 거짓 선지는 거짓이 처음 확정되는 데 필요한 수만 센다 |
| F5 | 비튼 방식 (거짓 선지만) | 뒤집기 / 범위 넓히기 / 조건 바꾸기 / 원인 바꾸기 / 대상 바꾸기 / 단계 바꾸기 / 귀속 바꾸기 / 예외 만들기 / 짝 바꾸기 / 복수 / 기타 / 애매 / 해당 없음(참 선지) | 뜻은 아래 표. 독립된 거짓 지점이 둘 이상이면 "복수"를 고르고 `note`에 각각 적는다 |
| F5a | 참으로 고친 최소 문안 (거짓 선지만) | 자유 기술 | 거짓 선지를 참으로 만드는 가장 작은 고침. 참 선지는 비운다 |
| F6 | 〈보기〉 정보의 선지 내 제시 | 전부 / 일부 / 없음 / 해당 없음 / 애매 | **F2가 '〈보기〉만' 또는 '둘 다'일 때만** 표시하고, 나머지는 '해당 없음'. 전부 = 선지만 읽고 〈보기〉를 다시 보지 않아도 정오가 갈림. 없음 = 판정에 필요한 〈보기〉 정보가 선지에 전혀 적혀 있지 않음. 그 사이는 일부 |
| F7 | 새 가정 | 없음 / 사실 변경 / 추가 / 애매 | 선지가 〈보기〉에 없는 상황을 가정하는가. 사실 변경 = 〈보기〉의 사실 하나를 바꿈, 추가 = 〈보기〉에 없는 사실을 더함 |

F5 비튼 방식의 뜻 (rules-common C5 목록 그대로):

| 방식 | 뜻 |
|---|---|
| 뒤집기 | 방향·대소·유무를 반대로 |
| 범위 넓히기 | 일부에만 해당하는 것을 전부로, 한 항목의 효과를 다른 항목까지 |
| 조건 바꾸기 | 성립 조건을 다른 조건으로 |
| 원인 바꾸기 | 결과는 맞고 원인·근거만 다른 것으로 |
| 대상 바꾸기 | 주체·대상을 다른 것으로 |
| 단계 바꾸기 | 한 단계의 결과를 다른 단계(또는 최종 결과)로 |
| 귀속 바꾸기 | 한 사람·관점의 주장을 다른 사람·관점의 것으로, 갈리는 둘을 "모두"로 묶기 |
| 예외 만들기 | 지문에 없는 예외를 만들거나, 지문의 예외를 원칙으로 |
| 짝 바꾸기 | 지문이 짝으로 설명한 두 개념을 맞바꾸기 |

## 출력 형식 (판정자)

문항마다 JSON 하나:

```json
{"packet_id": "P07", "answer": 3,
 "options": [
  {"n": 1, "F1": "참", "F2": "둘 다", "F2a": "...", "F3": "조건·범위·예외", "F3b": "", "F4": "원리 적용", "F4b": "2",
   "F5": "해당 없음", "F5a": "", "F6": "일부", "F7": "없음", "note": ""}
 ]}
```

## 판정자가 표시하지 않는 것 (CLI가 따로 적음)

- 출제 정답 번호, 출처(평가원·수능·생성), 학년도, 지문 번호, 사용 이력, 갈래, 발문 방향.
- 판정자 답이 출제 정답과 다르면 그 판정자의 그 문항 표시는 일치율 계산에 넣되 따로 표시한다(답이 다르면 F1이 갈리기 때문이다).

## 뺀 칸

- "지문 요지만 아는 사람이 풀 수 있나": 판정자마다 상상하는 사람이 달라 뺐다(코덱스 2차).
- 문항 좋고 나쁨, 매력도, 난도: 이번 감사는 구성 방식만 센다.
