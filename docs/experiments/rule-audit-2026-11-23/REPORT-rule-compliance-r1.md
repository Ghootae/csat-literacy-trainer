## 3. 함께 본 것

- **사례 A(부정 발문) 기출은 문항당 '지문만' 선지가 3.0개**다. 시범 대조에서 '문제 생성' 묶음과 같은 수준이다. 그러나 그 선지의 작업은 짝짓기 52%·원리 적용 29%·내용 확인 5%로, 문제 생성의 '지문만' 선지(내용 확인 47%)와 다르다. 결함 신호는 '지문만' 선지의 개수가 아니라 **'지문만 + 내용 확인'**일 가능성이 크다. 시범 대조는 문제 생성 5개 중 4개가 긍정(B) 발문이라 발문 차이가 섞여 있었다.
- 거짓 선지의 비튼 방식(F5)은 관점 B(1문항)를 빼면 모든 묶음에서 **뒤집기가 가장 많다**(사례 A 43%, 사례 B 56%, 관점 A 60%, 자료 B 50%, 기타 B 75%).
- 시범 대조에서 보인 "기출 거짓 선지는 이유·인과를 비튼다"는 본 감사에서 약해졌다. 사례 B 38%, 관점 B 50%, 자료 B 50%로 많지만, 사례 A는 14%, 관점 A는 20%다.
