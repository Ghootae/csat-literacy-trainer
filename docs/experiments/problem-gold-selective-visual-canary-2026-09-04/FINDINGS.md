# SEVP v01.01 선택적 근거 검증 카나리 해석

실행일: 2026-09-04 KST

정식 명칭: `Selective Evidence Verification Protocol (SEVP) v01.01`

## 결론

논의한 방식은 알려진 세 오류를 모두 발견하고 최종 정답과 핵심 선지 논리를 바로잡는 데에는
효과가 있었다. 그러나 자동 수리 1회와 독립 재감사까지 모두 통과한 문항은 3개 중 2개였다.
따라서 현 단계 판정은 `REVIEW_REQUIRED`다.

- 볼록렌즈: 최종 재감사 `PASS`
- 준거가격: 최종 재감사 `PASS`
- 내진설계: 최종 재감사 `REPAIR_REQUIRED`

세 문항의 최종 정답은 각각 ③, ④, ⑤로 모두 공식 정답과 일치했다. 정답 번호 일치만으로
통과시키지 않고 모든 선지의 원자 주장과 효과 분류를 재감사했기 때문에 내진설계의 남은 오류를
차단할 수 있었다.

## 실행량

- 최초 계약 실행: API 응답 14회
- 계약 결함 수정 후 v2 추가 실행: API 응답 10회
- 누적 API 응답: 24회
- 입력 토큰: 최초 170,794 + v2 134,540
- 출력 토큰: 최초 36,783 + v2 23,897
- 프로젝트의 2026-09-02 가격 스냅샷 기준 누적 추정 비용: `$1.338828`
- 자동 재시도: 0회
- API 타임아웃·호출 오류: 0회

최초 실행은 풀이 스키마에 없는 출처 태그를 감사기가 요구하고, 감사가 이미지 누락을 발견해도
이미지 단계로 돌아갈 수 없는 계약 문제가 있었다. 이 실행을 폐기하지 않고 실패 증거로 보존한 뒤
v2에서 두 계약을 수정했다.

## 문항별 결과

### 볼록렌즈

텍스트 라우터는 보기 문장에 거리 비율이 적혀 있다는 이유로 최초에 `IMAGE_NOT_REQUIRED`로
판정했다. 이미지 없이 생성한 최초 풀이는 과거 실패와 똑같이 P2의 거리를 P0의 절반으로 뒤집어
②와 ③을 모두 거짓으로 만들고 ②를 답으로 선택했다.

독립 감사는 다음 두 문제를 발견했다.

1. `P0의 거리는 P2 거리의 절반`을 `P2의 거리는 P0의 절반`으로 뒤집었다.
2. C·D·E의 배치와 C-D 거리의 의미를 확정하려면 그림이 필요한데 라우터가 이를 생략했다.

v2에서는 감사 결과에 따라 MEDIA1로 되돌아가 C·D·E의 위치 관계를 시각 명제로 추출했다.
수리 결과는 P2 거리를 P0의 2배, 비점 격차를 4배로 고치고 ③만 거짓으로 판정했다. 최종 독립
재감사는 모든 의미 축을 `PASS`로 판정했다.

최종 감사에는 승인 명제 locator의 source ID에서 숫자 일부가 빠진 사소한 오타 1건이 남았다.
의미와 정답은 훼손하지 않아 감사기는 `PASS`로 처리했지만, 운영 스키마에는 locator 존재 여부를
코드로 검사하는 정적 게이트가 추가되어야 한다.

### 준거가격

라우터는 지문 이미지가 선지 판정에 쓰이지 않는다고 보고 `IMAGE_NOT_REQUIRED`로 판정했다.
이는 최종 감사에서도 유지됐다.

최초 풀이는 ④가 잘못된 핵심 방향을 이미 발견했지만 다음 두 층을 충분히 분리하지 않았다.

- 내부준거가격이 할인 가격보다 높을 때 거래비효용이 생긴다는 일반 효과 규칙: 지문과 반대
- 갑에게 실제 거래비효용이 발생했는지와 그것이 속상함의 원인인지: 지문만으로 확정 불가

수리 결과는 일반 효과 규칙을 `CONTRADICTED`, 사건 발생과 감정 원인을 각각
`NOT_JUSTIFIED`로 분리했다. 최종 재감사는 issue 0건으로 `PASS`했다.

### 내진설계

라우터는 문제 풀이에 필요한 MEDIA2만 선택하고, 지진파 경로를 보여 주지만 이 문항에는 필요 없는
MEDIA1은 제외했다. (가)=제진, (나)=면진, (다)=내진의 대응도 정확히 추출했다.

최초 감사는 ③의 손상 정도 비교를 직접 모순으로 단정하지 말고 `NOT_JUSTIFIED`로 바꾸라고
요구했고, 자동 수리는 이를 반영했다. 그러나 최초 감사가 같은 유형인 ①의 지진력 감소량 비교를
놓쳤다. 최종 독립 재감사가 이를 새로 발견했다.

남은 수정은 좁고 명확하다.

```text
C1-A1 verdict
CONTRADICTED → NOT_JUSTIFIED

기존 취지
제진구조보다 면진구조가 지진력을 더 줄이므로 ①은 반대다.

수정 취지
지문은 제진구조와 면진구조의 초점을 구분하지만 실제 지진력 감소량의 우열을 직접
제시하지 않으므로, (가)가 더 많이 줄인다는 비교는 지문만으로 정당화되지 않는다.
```

정답 ⑤, ④의 두 원자 주장 분리, ③의 효과 분류는 올바르게 수리됐다. 자동 수리 1회 한도에
도달했으므로 추가 자동 수리를 하지 않고 인간 검토 대상으로 남겼다.

## 방법에 대한 판단

선택적 이미지 방식은 경제성 면에서 유효했다. 세 문항에 연결된 이미지 네 개를 모두 분석하지
않고 실제 풀이에 필요한 두 개만 분석했다. 준거가격 이미지는 생략했고, 내진설계에서는 두 이미지
중 문제 도식 하나만 선택했다. 볼록렌즈는 최초 라우팅이 실패했지만 감사 후 이미지 단계로 복귀해
회복했다.

반면 한 번의 감사와 한 번의 자동 수리만으로 모든 효과 분류가 안정된다는 증거는 얻지 못했다.
내진설계에서 첫 감사가 ③만 발견하고 같은 문제인 ①을 놓친 것은 독립 감사 자체도 완전하지 않다는
뜻이다. 따라서 다음 생산선에는 다음 조건이 필요하다.

1. 텍스트 라우팅 뒤 감사가 이미지 필요성을 다시 열 수 있어야 한다.
2. 자동 수리는 1회로 제한하고 이후 새 오류가 나오면 인간 검토로 보낸다.
3. 모든 비교 선지를 같은 묶음으로 다시 검사하여 한 선지만 고치고 유사 선지를 놓치지 않게 한다.
4. 의미 감사와 별도로 evidence locator가 실제 존재하는지 코드로 검증한다.
5. 상세 해설의 출처 경계 분류는 감사 출력에서 담당하고, 풀이 스키마에 없는 태그를 요구하지 않는다.

이번 결과는 새 방식이 기존 세 오류를 모두 자동 해결했다는 증거가 아니라, 두 문항은 자동 해결했고
한 문항은 올바르게 차단하여 사람에게 넘겼다는 증거다. 이 동작은 잘못된 골드를 자동 승인하는 것보다
안전하지만, 전체 24문항 확대 전에 내진설계 수정안을 승인하고 고위험 비교 선지 표본을 추가로
검증할 필요가 있다.
