# 선택 선지 슬라이스 위험 프로브 동일성 보고서

실행일: 2026-09-02

## 목적

기존 30개 응답에서 전체 골드와 선택 선지 슬라이스가 30/30으로 일치한 결과를 더 어려운 근거 유형에 일반화할 수 있는지 확인한다. 최종 라벨만 비교하지 않고 학생 인용 anchor별 `MATCHES | CONFLICTS | NOT_ESTABLISHED`, 결정성, 필수 source ref까지 동일성·정확성을 검증한다.

## 수행 작업

다음 6개 위험 유형을 7개 고정 프로브로 구성하고 각 3회, 전체 골드와 `SELECTED_OPTION_COMPLETE` 슬라이스에 각각 실행해 총 42회를 비교했다.

1. 골드 대표 표현과 다른 유효한 정답 근거
2. 핵심 근거는 맞지만 부가 설명이 틀린 응답
3. 관련 있지만 결정적이지 않은 사실만 제시한 응답
4. 복수 전제 중 하나만 제시한 응답
5. `CONTRADICTS`와 `DOES_NOT_JUSTIFY` 구분 쌍
6. 현재 슬라이스 밖 `MP4`를 사용하는 새로운 유효 근거

프로브 corpus는 기대 assessment뿐 아니라 quote anchor, 관계, 결정성, 직접 근거가 되어야 하는 source ref를 고정했다. 모델이 학생의 모든 실질 주장을 분리하고, 입력에 없는 사실을 추론 결론이나 정답 키로 보충하지 않도록 위험 프로브 전용 프롬프트를 사용했다.

첫 실행에서 출력 계약이 `DECISIVE MATCHES` finding 하나만 있어도 전체 `INSUFFICIENT`를 금지해, `ALL_OF` 일부 전제만 맞는 응답을 계약 오류로 만들었다. 이는 잘못된 제약이다. 결정적 전제 일부가 맞아도 충분 집합이 완성되지 않으면 `INSUFFICIENT`일 수 있게 수정하고 관련 회귀를 추가한 뒤 동일 42회를 v2로 재실행했다. 첫 실행 산출물은 별도 디렉터리에 보존했다.

## 결과

|---|---:|---:|
| 기대 assessment 통과 | 16/21 | 15/21 |
| 기대 anchor finding 통과 | 18/21 | 12/21 |
| assessment+finding 상세 통과 | 14/21 | 12/21 |
| 평균 입력 토큰 | 6,857.3 | 2,778.6 |
| 평균 입력 JSON 바이트 | 21,652.0 | 6,246.7 |
| 계약·전송 오류 | 0 | 0 |

- 평균 입력 토큰은 59.5% 감소했다.
- 최종 assessment는 21쌍 중 20쌍이 같았다.
- anchor 관계·결정성 signature는 21쌍 중 14쌍만 같았다. 따라서 근거 판정 동일성은 성립하지 않았다.

| 위험 유형 | 전체 골드 상세 통과 | 슬라이스 상세 통과 | 판정 |
|---|---:|---:|---|
| 대안 표현의 유효 근거 | 3/3 | 3/3 | 동등 |
| 정확 핵심+틀린 부가 설명 | 1/3 | 0/3 | 양 군 정책 불안정+슬라이스 coverage 결손 |
| 관련 비결정 사실만 제시 | 3/3 | 0/3 | 최종 라벨은 같지만 근거 관계 비동등 |
| 복수 전제 중 하나 누락 | 3/3 | 3/3 | 계약 수정 후 동등 |
| 직접 모순과 비정당화 구분 | 4/6 | 6/6 | assessment는 양 군 6/6, 전체 골드의 finding 누락 2건 |
| 슬라이스 밖 신규 유효 근거 | 0/3 | 0/3 | 슬라이스 coverage와 자동 sufficient set 모두 실패 |

확인된 원인은 세 종류다.

1. **실제 슬라이스 coverage 결손**
   - 혼합 근거의 틀린 부가 설명을 판정하는 `SF2`가 슬라이스에 없다.
   - 관련 비결정 사실의 `MP1/MP2`가 없어 전체 골드는 `MATCHES`, 슬라이스는 `NOT_ESTABLISHED`가 됐다.
   - 새 유효 경로의 화학량론 `MP4`가 없어 전체 골드는 이를 `MATCHES`, 슬라이스는 3/3 `NOT_ESTABLISHED`로 판정했다.

2. **근거 참조 의미 오류**
   - 슬라이스 모델은 `b가 a보다 얇다`는 부가 주장이 틀렸음을 판단하면서, 실제 동일 두께 근거 `SF2`가 없자 무관한 온도 사실 `SF3`를 3/3 충돌 근거로 인용했다. 허용 ID·인용 존재만 검사하는 구조 검증으로는 이 오류를 차단할 수 없고, anchor별 필수 source-ref 검사가 포착했다.

3. **충분 근거 집합의 보수 파생 한계**
   - 수소 문항의 `전환율 차이 + 공통 2:3 몰비`는 공식 해설과 원문으로 성립하는 대안 경로다. 전체 골드 모델도 두 전제를 정확히 `MATCHES`로 보았다.
   - 그러나 현재 sufficient set은 기존 `I4`에서 보수적으로 파생되어 부반응 전제를 추가 요구했다. 그 결과 전체 골드와 슬라이스 모두 최종 assessment를 3/3 `INSUFFICIENT`로 만들었다. 이는 입력 축소만의 문제가 아니라 명시적 대안 sufficient set이 골드에 없다는 문제다.

혼합 근거에서도 학생이 “힘이 소멸될 때의 곡률도 더 크다”는 결론을 직접 적었지만 모델이 중간 연결을 생략했다고 엄격하게 보아 전체 골드는 1/3, 슬라이스는 0/3만 인정했다. 정답 근거의 최소 충분성 정책도 추가 보정이 필요하다.

관련 집중 회귀 60/60과 타입 검사가 통과했다. 전체 회귀는 647/648이 통과했고, 유일한 실패는 기존부터 누락된 Hegel `.omc` 실험 산출물을 직접 읽는 무관한 테스트다.

## 다음 작업 추천

현재 슬라이스를 운영 provider projection에 연결하면 안 된다. 권장 순서는 다음과 같다.

1. 골드에 사람이 검토한 명시적 `sufficientGroundSets`를 추가하고, 수소 문항의 `MP3 + SF1 + MP4` 대안 경로를 별도 충분 집합으로 등록한다.
2. 학생 근거에서 언급된 실질 주장을 먼저 추출하고, 그 주장에 연결된 원문·보기 근거의 dependency closure를 기본 선택 선지 슬라이스에 추가하는 2단계 확장기를 구현한다.
3. finding이 참조한 source ref가 단순히 허용 ID인지뿐 아니라 해당 finding의 claim/ground set에 연결된 ID인지 검증하도록 출력에 target claim 또는 ground-set ID를 요구한다.
4. 정확 핵심과 틀린 비결정 부가 설명이 섞인 경우 핵심 충분성이 유지되면 `SUPPORTED`를 보존하는 최소 충분성 회귀를 강화한다.
5. 같은 42회를 다시 실행해 assessment·anchor signature·필수 source ref가 모두 21/21일 때만 운영 전환을 검토한다.
