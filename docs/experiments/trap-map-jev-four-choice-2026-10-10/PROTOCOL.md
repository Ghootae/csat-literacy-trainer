# 사용자 직접 승인: 네 오답 선지 JEV 실험

2026-10-10 대화에서 사용자가 정답 선지·정답 번호·공식 해설 제외를 확인하고, 이후 질문을 아래로 바꾼 뒤 인계 문서 없이 직접 실행하라고 지시했다. 기존 5선지 실험의 다른 실행 조건을 유지한다. 이 문서는 실행 조건 기록이며 별도 인계 절차가 아니다.

정확한 질문:

> 아래 지문과 문항을 읽고, 제시된 네 선지 중 이 문항의 정답일 가능성이 가장 높은 선지를 고르라.

- 원래 발문·지문·보기·그림 대체 alt 텍스트와 네 오답 선지를 입력한다. 모두 오답이라는 별도 고지는 없다.
- 원래 선지 번호와 C 라벨은 유지하고 정답 선지는 state와 criteria에서 모두 제거한다. 번호 누락은 관측할 수 있다.
- BARE: 함정 분석 없음. TRAP: 남은 네 선지의 sol 1회차 transformType, attractionTags, attractionMechanism만 첨부한다. 정답 분석·예상 선택 비율·실제 학생 비율은 제외한다.
- 분석 원문을 다시 쓰지 않는다. 분석에는 오답 여부의 단서나 원래 정답에 대한 언급이 남을 수 있다. 따라서 TRAP은 정답 정보를 보지 않고 생성한 분석을 쓰는 조건과 다르다.
- 6문항 × 2조건 × 5회 = 60칸, 사전 호출 별도. USED 5문항만 주 지표에 쓰고 날짜 불일치 공손룡 후보는 별도 표로 남긴다.
- 실제 학생 오답 선택 비율을 네 오답 합으로 나누어 100%로 환산한다. 정답률 MAE는 산출하지 않고 네 선지 분포 MAE를 산출한다.
- 실제 시험은 정답을 포함한 5선지였으므로 네 선지 판단 확률과 직접 같은 모집단 분포로 간주하지 않는다. 선행 실험 대비 질문과 선지 수, 정답 정보 제공을 함께 바꿨다.
- 요청 시작 간격 7초 이상, 429는 60초 후 같은 요청 1회 재시도, 최대 75시도. 제한된 네트워크에서 실패한 최초 연결 시도도 원장 상한에 포함한다.
- 이전 실험과 원자료, packages/**, memory/, .env는 수정하지 않는다. 커밋·푸시는 수행하지 않는다.
