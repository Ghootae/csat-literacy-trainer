## 판정

### 1. 최대 위험이었던 `암묵적` 프로브가 통과했다

`evidenceRole`의 `relation` 정의가 **역할 배정**이므로, 함축적 표현을 `entity_identification`으로
오분류하면 병치 보존(E2 유형)이 무너진다. 이것이 이번 회귀의 핵심 위험이었다.

```
공시 [암묵적]      "공모는 증권 신고서 제출, 사모는 신고서 제출 불요"  → 관계보존 ×4 ✓
광합성P4 [암묵적]  "고온에 취약한 C3, 고온에서도 잘 자라는 C4 연구"     → 관계보존 ×4 ✓
```

둘 다 **관계어 없이 병치만으로** 조건–결과·문제–해결을 나타낸 응답인데 관계보존을 유지했다.
"병치만으로 인정"이라는 확립 원칙(§8)이 훼손되지 않았다.

### 2. 조건·예외 유형(공시)이 완전 무변이다

`relation` 정의에 "조건–결과"가 들어 있어 영향 가능성이 있었으나 6개 프로브 전부 기준선과 동일.

### 3. 인문 `Bd1` — 예측이 틀렸고, 기대값 쪽이 의심스럽다

**사전 예측**: "하나의 실과 여러 명, 흰 말과 검은 말"은 순수 명사구 나열이므로
`entity_identification` → `주제만`으로 교정될 것.

**실제**: gen1·gen2는 `주제만`으로 교정됐으나 오라클·gen3는 `관계보존` 유지. 과대평가 잔존.

오라클 팔의 관계 질의 판정을 열어 보면:

```
q4 (relation_structure, requiredForRelation=True)
   preserved / implicit / evidenceRole = relation
   증거: "하나의 실과 여러 명"
```

**분류기 판단이 타당하다.** "하나의 실과 여러 명"은 `엽육 세포와 유관속초 세포` 같은 단순
나열이 아니라 **1:N 대응이라는 관계 자체**를 담는다. 그리고 그것이 `real_to_names` 영역의
핵심 관계다(q4 수용 기준: "하나의 실이 여러 명으로 지시될 수 있다는 **방향**을 나타내면 인정").

예측이 틀린 이유는 프로브 텍스트를 "명사구 나열"로 잘못 읽었기 때문이다. 앞부분이 개수
대비(하나 ↔ 여러)를 담고 있다.

→ **기대값 `주제만` 자체가 재검토 대상이다.** N2-c(P5 `조직만`)와 같은 유형의 후보다.
다만 **이번에 고치지 않는다** — 판정이 안 맞는다고 기대값을 손보면 기준선이 사라진다.
gen1·gen2가 `주제만`을 낸 것은 그쪽 질의 분해가 이 표현을 방향 진술로 인정하지 않았다는
뜻이고, 네 세트가 갈리므로 N2-c처럼 "전원 일치"라는 정정 근거도 없다. **미결로 남긴다.**

### 4. 2변수 항목 (evidenceRole 단독 귀속 불가)

법인 `B` gen3, 광합성 P4 `주제만` gen2·gen3의 변이는 **생성기도 v0 → v1로 바뀌어** 질의셋이
새로 생성됐으므로 evidenceRole 탓으로 단정할 수 없다. 모두 **과소평가 방향**이고 오라클 팔은
기준선과 동일하다.
