- 2문단(중합 → 공유 결합 정의 → 단일/이중 → 결합력 → 8개 규칙 → 탄소). r1과 r3는 문장 묶음이 같다({문장1}{문장2}{문장3~4}{문장5~6}). r1만 공유 결합 두 묶음 위에 C2-4 층을 하나 더 둔다. r2는 문장2를 가른다. 앞절 "단위체들은 공유 결합으로 연결"(P2-2)은 C2-1(중합)에, 뒷절 공유 결합 정의(P2-3)는 C2-2에 넣었다. 문장이 묶음 경계에 걸리는 것은 둘째 묶음 맞춰 보기에서 사용자가 지적한 유형이다. 하위 층 다수안 r1·r3.
- 3문단: r1·r3 같음(P3-1 | C3-2[C3-1 구조, P3-5 약한 결합]). r2는 C3-1에 P3-2~P3-5를 평평하게 둔다. 다수안 r1·r3.
- 4문단(되풀이 절차: 개시 → 성장 되풀이 → 종결 → 결과). 한 회 단위 묶음 C4-5(C4-3 불안정 탄소가 다시 반응 + C4-4 사슬 성장)는 r1과 r3가 같다. r1은 개시 두 묶음(C4-1 개시제 분해, C4-2 첫 결합)을 C4-7로 한 번 더 묶었고, r3는 C4-1, C4-2, C4-5, C4-6, P4-12를 G4 바로 아래에 둔다. r2는 문장1 P4-1을 따로 떼고, 성장 단계 C4-2에 P4-5~P4-9 다섯 명제를 한 층에 늘어놓는다. 하위 층 다수안 r1·r3.
- 5문단("그래서" 결정 영역 → 비율 조절·물성 → 많아질수록 단점 "지만" 장점 → 활용). r1과 r3 묶음이 같다(C5-1 | C5-6[C5-2, C5-5[C5-3 단점, C5-4 장점], 활용]). r2는 문장3을 갈라 P5-3(조절)을 C5-5에, P5-4(물성 영향)를 C5-4에 둔다.
- 종합: 점검표 2의 기준(접속 표지, 변화, 주체, 되풀이 한 회, 평평하지 않음)으로는 r1과 r3가 동점이다. r1의 C4-7·C2-4 층은 깊이가 더 있지만 기준 위반을 가르는 차이는 아니다. r2는 뒤처진다.

**3. 근거 관계** — 세 회차 모두 "그래서" P5-1→P5-2, "그러면" 개시 결합→홀로 남은 전자, 약한 결합→개시 반응(P3-5→P4-3), 8개 규칙→7개 불안정(r1·r3 P2-8→P4-2, r2는 없음), 종결 조건, 활용 근거를 남겼다. r3는 "유연성이 낮아 → 충격에 약하고", "밀도가 높아져 → 단단해지고"를 명제 둘과 인과 관계(P5-5→P5-6, P5-9→P5-10)로 남겼다. r1은 이 둘을 한 명제(P5-5, P5-8) 안에 두어 관계가 따로 없다. r3 ≥ r1 > r2.

**4. 최상위** — 대립 관점이 없는 설명문이다. 5문단 장단점 교환("~지만")은 세 회차 G5에 방향까지 남았다. r1·r3 TOP은 "달라져/달라지는"으로만 쓰고 방향을 뺐고, r2 TOP만 감소/증가를 적었다. 판정에는 영향이 적다.

**5. 감점** — r1 P4-3/P4-4가 같은 목적구("안정해지기 위해")를 두 명제에 되풀이한다(행위가 달라 거의 같은 뜻의 반복은 아님). r2 P5-7(가공성+불투명), P5-10(화학+열)은 서술이 다른 둘을 한 명제에 합쳐 다른 성질 명제들과 쪼갠 정도가 고르지 않다. r3는 뚜렷한 감점이 없다.

**6. 진단 해상도(결정 항목)**

- r3: 5문단에서 기제와 결과를 갈랐다. 유연성 저하(P5-5) → 충격에 약함(P5-6), 밀도 증가(P5-9) → 단단해짐(P5-10). 성질도 하나씩 갈랐다(P5-7 가공성, P5-8 불투명, P5-11 화학, P5-12 열). "결정 영역이 많을수록 밀도가 낮아져 단단해진다"처럼 기제만 바꿔친 선지를 따로 잡는다.
- r1: 4문단 개시 결합을 "약한 결합을 끊는다"(P4-3)와 "한쪽 탄소와 단일 결합한다"(P4-4)로 갈랐다(r3는 P4-3 한 명제). 대신 5문단 기제–결과는 합쳤다.
- 5문단은 성질 바꿔치기 선지가 가장 많이 나올 곳이고 r3가 그 단위를 둘 더 가졌다. 점검표 6이 명시한 "기제와 결과"이기도 해 r3를 고른다.

**7. 다수안** — 쓰지 않았다. 참고로 첫 묶음 기준 다수안이 없는 문단은 5개 중 2개(2·4문단: r1·r3가 하위 층에서만 같음)다.

### r3 관찰(고치지 않음)

- P4-3이 원문 문장3의 두 행위(약한 결합을 끊음, 한쪽 탄소와 단일 결합)를 한 명제에 담는다.
- G4 아래에 C4-1, C4-2, C4-5, C4-6, P4-12가 같은 층에 있다. 개시 단계(C4-1+C4-2)를 묶은 상위 노드가 없다(r1에는 C4-7로 있음).
- TOP이 5문단 성질 변화의 방향(감소/증가)을 적지 않고 "달라지는"으로만 쓴다. 방향은 G5·C5-5에 있다.
- 2문단 문장6이 C2-4(P2-9, P2-10)와 C2-5(P2-11, P2-12)에 걸쳐 나뉜다. 세 회차 공통이고 상위 C2-6은 하나다.
- 관계 C4-4→P5-1(사슬 성장 → 분자가 길다)은 원문 표지 없이 이은 문단 간 연결이다.

### 6절 넘김: 해당 없음(근소)

- r1과 r3는 원문 흐름 동점, 진단 해상도에서 r3가 근소하게 앞선다. 진단 해상도로 갈렸으므로 넘김 조건 "진단 해상도로도 갈리지 않음"에는 해당하지 않는다.
- 확신: 중. r1의 4문단 개시 단계 묶음(C4-7)과 P4-3/P4-4 분리를 더 중시하면 r1도 합리적이다. 사용자가 다시 볼 곳은 4문단(r1 C4-7)과 5문단(r3 P5-5~P5-12) 두 곳이다.

## 4. audio-perceptual-coding → r1 (closeCall)

세 회차의 명제가 사실상 같다(40개, 같은 ID에 같은 원문 구간). 차이는 합성 노드 배치뿐이다.

### 문단별 비교

**2. 원문 흐름**

- 1문단(축음기 절차 → 저장 원리 → 아날로그): 세 회차 같음.
- 2문단: 첫 묶음 {문장1}{문장2~4}{문장5~6}은 같다. r3만 문장3의 두 명제(P2-3 16비트, P2-4 이진수 값)를 C2-1로 한 번 더 묶어 덜 평평하다. r1·r2는 C2-1 아래 P2-2~P2-5를 한 층에 둔다.
- 3문단: r1·r2는 최소가청강도 정의(C3-2)와 주파수별 차이·"예를 들어"(C3-3)를 C3-4로 묶는다. r3는 C3-2, C3-3을 G3 바로 아래 둔다. 다수안 r1·r2. 세 회차 모두 "예를 들어" 예시(P3-8, P3-9)를 주장 P3-7과 묶었다.
- 4문단("한편" 차폐 → 주파수 조건 → 임계대역 정의 → 임계대역 폭 → 차폐 문턱값 → 지각부호화가 이용). 첫 묶음은 세 회차가 모두 다르다. 하위 층에서 r1·r2는 {주파수 조건(문장2) + 임계대역 정의(문장3)} | {폭(문장4)}, r3는 {주파수 조건} | {임계대역 정의 + 폭}이다. 문장3은 문장2의 "차폐가 일어나는 범위"를 이름 붙인 것이라 r1·r2 묶음도 원문 흐름이고, r3 묶음은 개념(임계대역) 단위로 깔끔하다. 우열을 가르기 어렵다. r2는 차폐 문턱값(P4-8)까지 C4-5에 넣고 "이런 성질들을 이용"(P4-9)만 따로 둔다.
- 5문단(구간 나누기·문턱값 → 비트 할당 → "므로" 제거 → "즉" 종합). r1·r3 같음(C5-1 | C5-3 | P5-6). r2는 C5-1, C5-3 위에 C5-4를 한 층 더 둔다.
- 문단을 넘는 층: r1은 X2 안에 3~5문단(지각부호화 전부)을 둔다. r2·r3는 X2에 3~4문단(청각 특성)만 두고 G5(절차)를 TOP 바로 아래 둔다.
- 종합: 2문단은 r3, 3문단은 r1·r2, 4문단은 판단 보류, 5문단은 r1·r3. 동점.

**3. 근거 관계** — "따라서" P2-6→P2-7, "므로" P5-4→P5-5, "즉" →P5-6, "예를 들어" P3-7→P3-8/P3-9, 4문단 끝→5문단 절차(P4-9→G5)가 세 회차 모두 있다. 회차별 덧붙임: r1 P4-8→P5-4(문턱값 정의 → 문턱값보다 작은 소리는 안 들림), r2 P2-5→P5-3(비트가 많을수록 원음 → 비트를 많이 할당해 손실을 낮춤), r3 C3-2→C4-1("한편" 전환). 동점.

**4. 최상위** — 대립 관점 없음. 세 TOP 모두 압축 필요성, 두 청각 특성, 문턱값, 제거와 차등 할당, 품질 유지를 담았다. 동점.

**5. 감점** — 명제가 같아 쪼개기 감점도 같다(P3-5/P3-6 들림/안 들림, P4-3/P4-4 주파수 가까움/멂 등은 서술이 달라 허용 범위). 몰아넣기는 r1·r2 C4-2(차폐 조건 + 임계대역 정의)를 관찰로만 적는다. 동점.

**6. 진단 해상도** — 명제 층 단위가 같아 바꿔칠 수 있는 단위의 분리는 같다. 합성 층에서 r3가 "임계대역(정의+폭)"을 한 노드 C4-3에 모은 것이 약간 낫지만, 같은 문단에서 r3는 3문단 C3-4 층이 없다. 동점.

**7. 다수안(결정 항목)** — 하위 층까지 보면 r1은 2문단(r1·r2), 3문단(r1·r2), 4문단 임계대역 묶음(r1·r2), 5문단(r1·r3)에서 모두 다수안에 든다. r2는 5문단, r3는 2·3·4문단에서 소수다. r1을 고른다.

### r1 관찰(고치지 않음)

- C4-2가 차폐 발생 조건(P4-3, P4-4)과 임계대역 정의(P4-5)를 한 묶음에 담고, 임계대역 폭(C4-3)은 따로 있다. 임계대역 개념이 두 묶음에 나뉜다.
- 2문단 C2-1 아래 P2-2~P2-5 네 명제가 한 층에 있다(문장3의 P2-3/P2-4를 묶은 층 없음).
- P1-2 "축음기의 원리는 간단하다"가 독립 명제다(세 회차 공통, 소개 문장 포함 규칙에 따름).
- X2가 3~5문단을 모두 담아 TOP 바로 아래가 X1, X2 둘뿐이다.

### 6절 넘김: 해당 없음

- 2~6이 동점이어서 점검표 7(다수안)으로 골랐다. 다수안이 분명히 있으므로 "고르기 어려움"은 아니다. 첫 묶음 기준 다수안 없는 문단은 1/5(4문단).
- 확신: 중상(선택 자체). 명제 층이 세 회차 같아 어느 회차를 동결해도 명제 눈금은 달라지지 않는다. 회차 선택이 판정에 주는 영향이 네 지도 중 가장 작다.

## 묶음 전체 관찰

- 6절 넘김 조건은 네 지도 모두 해당하지 않는다. 지도 3회 모두 구조 검증 통과, 다수안 없는 문단은 첫 묶음 기준 ga 1/4, na 0/4, plastic 2/5, audio 1/5로 모두 절반 이하. 입장·관계 유형 조건은 이 단계 밖이다.
- closeCall 둘(plastic, audio)은 사용자가 원하면 볼 곳을 위에 적었다(plastic 4·5문단, audio 4문단).
- 둘째 묶음 맞춰 보기에서 Claude가 놓친 "문장이 묶음 경계에 걸리는지"를 갈린 문단마다 확인했다. 선택 회차에서 걸리는 곳은 plastic 2문단 문장6(세 회차 공통)뿐이다. 떨어진 회차에서는 plastic r2 2문단 문장2·5문단 문장3, ga r1 4문단 "하지만" 앞뒤(문장은 안 걸리고 접속 표지가 걸림)가 걸린다.
