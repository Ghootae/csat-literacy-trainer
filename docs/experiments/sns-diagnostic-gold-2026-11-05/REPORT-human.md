# SNS 진단 세트 E 자료 만들기: 인간 보고서

## 1. 개요

**1) 목적.** 진단 기본 세트 E(의식과 인지·경마식 보도·플라스틱·오디오, 16문항, D-0201)를 진단평가에 쓸 수 있게 자료를 만든다. 세 가지가 필요하다.
- 판정용 원자료 묶음(③′): 개발자 판정 경로가 읽는 지문·문항·정답. 이것만 있어도 판정은 돈다.
- 분석 골드(③): 지문을 명제 → 묶음 → 요지로 쪼갠 지도. 결과 화면의 "독해 패턴" 재료.
- 선지 연결(④): 선지마다 참·거짓과 비튼 방식(비틂 14종), 지도의 어느 명제를 비틀었는지. 결과 화면의 "걸린 함정" 재료.

**2) 결과.** 세 가지 모두 끝났다. 사람이 판단할 일로 넘긴 것은 없다(절차 6절 조건 해당 없음).
- 지도 4개는 세 번 생성해 하나씩 골라 고치지 않고 굳혔다.
- 입장(누구의 주장인가)은 1건만 고쳤다. 관계 유형 120개 중 "기타"는 1개다.
- 선지 80개를 연결했다. 규칙 위반 0, 판단이 갈린 선지 0, EBSi 해설과 이유가 다른 선지 1(아래 2-3).
- 비용 합계 약 $3.1(지도 $1.14, 입장·관계 $0.30, 선지 연결 $1.64).

**3) 다음 스텝.** ⑤ 품질 확인(아래 2-4)을 보고 괜찮으면, Q-0042(선택률 출처·이용 범위)를 정한 뒤 ⑥ 진단평가 연결(화면·백엔드) 설계로 간다.

## 2. 본문

### 2-1. 오디오 17번 〈보기〉가 표 그림뿐이라 입력이 막힘 (해결)
- 문제: 〈보기〉가 "소리 A~D의 주파수·크기·최소가청강도·차폐 문턱값" 표 그림이다. 그림은 글로 옮긴 전사가 고정 파일에 있어야 선지 연결에 넣을 수 있는데 없었다. 실행 에이전트가 보내기 전에 멈췄다(전송 0).
- 과정: 코드 에이전트가 원본 그림을 보고 표를 전사했다. 기존 고정 파일은 지난 실행이 해시로 묶고 있어, 이 실험 폴더에 사본(`supplement-fixed.json`)을 만들어 한 항목만 더했다.
- 결과: 이후 정상 실행.

### 2-2. 3회차 3지문이 응답 없이 실패 (해결)
- 문제: 플라스틱은 29분 뒤 시간 초과, 오디오·경마식은 연결 오류. 승인한 12요청을 다 써서 재전송이 범위를 넘었다.
- 과정: 사용자 "3요청 재전송 승인". 스크립트의 재전송 방식은 4지문을 모두 다시 보내서, 실패한 3지문만 담은 대상 파일로 보냈다.
- 결과: 3/3 성공, $0.28. 2회차까지만으로 돌린 잠정 동결에서 판단이 갈렸던 4선지(플라스틱 10번 ①②⑤ "짝 바꾸기 vs 방향 뒤집기", 오디오 17번 ④ "인과 바꾸기 vs 정도")가 3회차 다수결로 모두 풀렸다.

### 2-3. 의식과 인지 15번 ①의 해설 불일치 (해결, 덮어쓰지 않음)
- 선지: "감각과 지각 모두 물질세계에서 이루어지기 때문에"(㉡ "지각과 감각은 서로 구분되지 않는다"의 이유로 적절하지 않은 오답).
- EBSi 해설: "물질세계에서 이루어진다고 보는 것은 객관주의 입장의 일부이며, 그 입장도 감각과 지각을 구분한다."
- 선지 연결(3회 모두): "원문에 없는 이유를 덧붙인 것(ADDED_CONTENT)". 원문 (나)에는 감각·지각이 어느 세계에서 일어나는지 규정한 문장이 없다.
- 판단: 오답이라는 결론은 같고 이유 설명만 다르다. 원문 근거로는 연결 쪽이 맞아 그대로 두었다.

### 2-4. ⑤ 품질 확인 (판단 필요: 확인만)
- 결함 문항 신호(정답이 애매하거나 해설과 연결이 정면으로 맞서는 경우)는 없다.
- 비틂 분포(거짓 선지의 비튼 조각 수):

| 지문 | 분포 |
|---|---|
| 의식과 인지 | 부정 11, 바꿔치기 3, 주장 주체 바꾸기 3, 내용 덧붙이기 2 |
| 플라스틱 | 짝 바꾸기 3, 바꿔치기 2, 부정·범위 넓히기·방향 각 1 |
| 오디오 | 8종 13조각(바꿔치기 4, 부정 3, 방향 2 등) |
| 경마식 | 방향 5, 부정 4, 바꿔치기 1 |

- 의식과 인지는 "부정"이 많다. 이는 인문 지문의 "~가 아니라 ~이다" 대조 문장이 많아서다. 진단 결과에서 "부정형 함정에 약함"이 이 지문 쪽으로 쏠릴 수 있다는 점만 적어 둔다. 지문 교체 사유로는 보지 않는다.
- 추천: 세트 E를 그대로 쓴다.
