# Dialogue v5 교차 문단 소규모 검증 — 2026-08-25

## 목적

헤겔 5건의 판정 일치는 회귀 테스트 통과로만 해석한다. v5가 헤겔 문단의 대응·종합 구조에
과적합됐는지 확인하기 위해 관계 성격이 다른 세 문단에서 소수 응답을 검토했다. 일반적 정확도를
추정하는 통계 실험은 아니다.

## 대상과 방법

| 문단 | 관계 성격 | 분석 모델의 core | 사람 정제 후 core |
| --- | --- | ---: | ---: |
| `corporate-law-p2` | 법적 지위·권한·허가 조건·목적 제한 | 9 | 3 |
| `surface-tension-laplace-p2` | 압력 이동·수축 작용·완화 인과 연쇄 | 5 | 3 |
| `information-asymmetry-free-marketplace-p2` | 문제 발생·현행 규제·규제 확대 주장·개입 논쟁 | 6 | 4 |

- 문단 분석: OpenAI `gpt-5.6-sol`, effort `medium`, `paragraph-analysis-prompt-v1`
- 학생 응답 평가: OpenAI `gpt-5.6-terra`, effort `medium`, `dialogue-prompt-v5`
- 문단마다 정확·부분 이해·모호·명시적 오류·복수 오류 응답을 한 건씩 사용했다.
- 각 학생 응답은 재시도 없이 한 번만 호출했다.
- 사람 검토 차원은 판정, `targetIssue`, 질문 유도성으로 제한했다.
- 정확한 질문 문구는 oracle로 취급하지 않았다.

모델의 문단 분석은 법인 문단의 세부 규칙을 core 9개로 과도하게 분해했고, 수익 활동의 범위와
보고 의무는 중심 이야기에서 상대적으로 약하게 처리했다. 따라서 분석 결과를 그대로 평가 골드로
사용하지 않고, 중심 이야기를 복원하는 데 필요한 관계 묶음으로 사람이 정제했다.

contradicted 관계와 CORRECTIVE 질문을 반환했다.

| 정확 | PASS, target 없음 | 질문 없음 — 적절 |
| 부분 이해 | UNCLEAR, `MR1` | 법인 성격과 법인격 귀속을 묻고 정답을 노출하지 않음 — 적절 |
| 모호 | UNCLEAR, `MR2` | 이사회와 관할 기관의 역할을 구별하게 함 — 적절 |

| 복수 오류 | ERROR, `MR1`; 오류 파생 `MR1`, `MR2` | “비영리 재단 법인”을 먼저 제시해 교정 범위를 상당 부분 좁힘 — 경계선 |

| 사례 | 판정·target | 질문 검토 |

정보 비대칭 단일 오류 응답은 현행 의무 대상과 확대 주장 대상의 경계를 잘못 말했다. `MR2`와
`MR3`가 의미상 맞닿아 있어 어느 하나를 contradicted로 잡는 것이 가능하며, 평가기는 `MR2`를
선택했다. 사람이 보기에도 판정과 교정 target은 타당하므로 정확한 contradicted ID 집합을
단일 oracle로 강제하지 않았다.

## 결론

- v5는 법률 규칙, 과학 인과, 정책 논쟁에서도 기대 판정과 상태별 target 계약을 유지했다.
- 이 결과만으로 일반적 정확도를 주장할 수는 없지만, 헤겔의 대응·종합 구조에만 맞춘 명백한
  과적합 징후는 발견되지 않았다.
- 다음 문제는 판정 정확도보다 질문의 비유도성이다. 12개 질문 중 2개가 정답 관계를 먼저
  노출했고 2개는 경계선이었다.
- 이번 단계에서는 prompt나 기능을 즉시 변경하지 않는다. 유도 질문의 공통 패턴이 다른 문단에서도
  반복되는지 사례를 조금 더 모은 뒤, 질문 규칙만 독립적으로 수정할지 결정한다.
