## 실행과 비교
범위: 혈액 응고 / 도플러 한 짝만(Ghootae 결정, 2026-11-17). 좋으면 수돗물 소독 / mRNA로 넓힌다.

2. T1-1에 골드 지도 → deep-item v4.1 A·B → 4문항. 대조는 v3 T1-1 문항 4개와 도플러 문항 4개(이미 있음).
3. 판정은 JUDGE.md와 같은 기준(정답 선지가 정리 문장 하나로 풀리나, 이어야 할 문단 수, 자동 설계 문제 수).

## 통과 기준
- 정리 문장으로 풀림: v3 3/4 → 1/4 이하(도플러 1/4).
- 자동 설계 문제: v3 T1-1 3건 → 도플러 수준(1건) 쪽으로 줄어듦.
- 4문항으로 보는 신호라 판정은 방향 확인이다. 통과하면 수돗물 소독 / mRNA로 넓혀 다시 잰다.
- 충실도 유지, 사실 오류 없음.
- 실패하면 원인을 나눈다: 지문에 정리 문장이 여전히 많은가(규칙이 안 먹힘) / 지문은 바뀌었는데 문항이 여전히 얕은가(문항 생성기 쪽).
