## 2. 멈춤 ②를 어떻게 읽나

멈춤 ②는 "평가가 고장 났는지" 보려는 장치다. 이번에는 고장 신호가 아니다.
- 정답 일치 5/5문항 × 4명 모두 맞음, 평가자 JSON 4/4.
- 평가자 3명이 기출에 준 이유가 같다: "공급자 80원·수요자 120원만 구분하면 풀려 3점으로 얕다". 엉뚱한 이유가 아니다.
- 교육청 7월 문항이라 평가원 기출(① 칸 정보 13번·공손룡 12번, 4/4 '같음')보다 실제로 쉬울 수 있다.

그래서 이번 기출은 **"평가자 기준을 재는 앵커"로 약하다**는 쪽으로 읽는다. 다만 이것은 해석이라, 약속을 바꾸지 말고 비용 없이 확인하는 길을 추천한다.

| 선택 | 무엇을 | 비용 | 장단 |
|---|---|---|---|
| **(가) 앵커를 더해 다시 판정 (추천)** | 같은 블라인드에 ① 칸의 정보 비대칭 지문 + 기출 13번(두 회차 모두 '같음' 4/4)을 더해 평가자 4명이 다시 판정 | API 비용 없음(codex) | 평가자가 정상인지 다른 기출로 확인한 뒤 약속대로 판정한다. 등급이 회차마다 흔들릴 수 있다 |
| (나) 지금 판정 | 12번이 얕다는 이유를 받아들여 지금 숫자로 두 칸 'L2 통과(잠정)' | 0 | 빠르지만 미리 정한 약속을 결과를 보고 바꾸는 셈이다 |

- 13번이 '같음' 2회 이상이면 평가는 정상으로 보고, 12번은 '얕은 기출'로 기록한다. 칸 판정은 **2회차 등급**으로 PLAN 5절 기준을 적용한다.
- 1회차와 2회차의 판정 이름이 다르면 **낮은 쪽**을 적고 '흔들림'으로 기록한다.
- 13번도 '같음' 2회 미만이면 판정 보류로 두고 멈춘다.

## 3. 그래프 모양 (관찰, 지금 고치지 않음)

- 두 생성 그래프는 수요·공급 곡선과 교점이 아니라 **값 선 그래프**(세액·시점에 따른 가격)였다. kind-graph-v6는 "지문에 적힌 관계를 그래프로"만 요구하므로 규칙 위반은 아니다. B-V2는 그 모양으로 '같음' 4/4를 받았다.
- 그림 탓 등급 이유는 0건이다. 한 줄 평의 지적(읽기 판 '접함' 부정확, 기호 겹침, 선 끝 이름 잘림)은 보기 흉함 수준이다.
- 곡선·교점형이 왜 안 나왔는지(T3 한계, 교점 좌표를 직접 계산해야 하는 부담 등)는 지금 1회 표본이다. **기록만 한다.** 순서표 4번째 묶음(생성 경제 지문 L3)에서 다시 0/2이면 그때 렌더 수정안(교점 자동 표시, 두 선 사이 구간)과 함께 본다.

## 4. CLI가 메운 공백 (확인)

| 공백 | 웹 판단 |
|---|---|
| 지문 등록에서 원문 `[A]` 상자 표시 뺌 | 괜찮음. 생성 문항이 [A]를 가리키지 않았고, 기출 12번도 [A]와 무관. 등록 메모에 한 줄 적는다 |
| 기출 12번에 원본 이미지 + 같은 렌더러 읽기 판(기울기는 지어냄) | 괜찮음. 출처 감추기용이고 원본 이미지를 함께 줬다. 값이 같아 정답에 영향 없음 |
| 평가 요청문에 '그래프 한 줄 평' 추가 | 좋음. 등급 이유와 그림 평을 갈라 볼 수 있었다. 앞으로 그래프 칸에서 유지 |
| 재생성 생략(생성 점검 경고 2개) | 괜찮음. 평가자가 그 지점을 결함으로 잡지 않았다 |
