- 평가자 4명은 같은 모델(codex gpt-6.1-sol)이고 회차 사이 차이는 순서·임시 폴더뿐이라, 두 회차 평균이 같게 나온 것은 평가 흔들림이 작았다는 뜻이지 독립 표본 8개라는 뜻이 아니다.

- 생성 두 문항은 수리·재생성을 거치지 않은 1회 생성본이다.
