# 순서표 ④ 2단계 쉬운 보고 (2026-11-25)

## 1. 개요
**목적.** 기출이 아니라 생성기가 쓴 지문(도덕적 운, 가격 상한제)으로도 〈보기〉 문항이 수능 수준으로 나오는지 봤습니다.
**결과.** 문항 8개를 만들어 평가자 4명이 순서를 바꿔 2번씩 채점했습니다. 칸 평균은 인문 관점 1.44, 인문 사례 1.06, 사회 표 1.63입니다. 기출 지문일 때(L2)와 비교하면 관점·표는 비슷하거나 약간 높고, 사례만 0.25 낮습니다. 평가 이유 64건 중 지문 탓은 0건이고 문항 탓이 35건이었습니다. 다만 사회 표 2회차는 같이 섞은 기출(조세 귀착 12번)이 1.0으로 기준 1.5에 못 미쳐 그 회차는 ‘멈춤’입니다. 판정은 웹이 합니다. 비용은 $4.575(상한 $7).
**다음 스텝.** 웹의 칸별 판정을 받습니다.

## 2. 본문
### 인문 관점 — B형은 만점, A형은 한 문장 문제 (판단 필요)
A형 관점 문항은 정답이 “㉮는 결과에 따른 비난을 더하지 않는다” 한 문장만 읽어도 정해진다고 평가자 4명 모두 두 회차에 지적했습니다(평균 0.88). B형은 “위험을 줄이는 것과 완전히 막는 것”을 구별하게 해 8명 모두 ‘수능 같음’(2.00)을 줬습니다. 둘의 평균이 1.44입니다.

### 인문 사례 — 오답이 너무 티 난다 (판단 필요)
A·B 사례 문항 모두 정답 선지는 맞지만 오답 선지가 뚜렷이 틀려 쉽게 걸러진다는 지적이 거의 전부였습니다(평균 1.06). 지문의 운반대 사례를 이름만 바꾼 문제(㉮)는 0건이라 그 우려는 나타나지 않았습니다.

### 사회 표 — 4문항 평균 1.63, 단 기출 한 회차가 낮음 (판단 필요)
B형 두 문항과 A형 둘째 문항은 1.5~2.0입니다. A형 첫 문항(가격 구간 포함 비교)은 1.0으로, 계산이 단순하고 쓰이지 않는 정보가 있다는 지적이 있었습니다. 같이 섞은 조세 귀착 12번이 r1 1.75, r2 1.00으로 갈렸습니다(r2 멈춤).

### 지문 탓 vs 문항 탓 (해결)
평가 이유를 제가 읽고 나눴습니다. 지문이 기준을 안 준다는 지적은 0건, 문항 쪽 문제 35건, 애매 1건입니다.

### 실행 중 문제 (해결)
평가 도구가 요청 한도(429)로 11건이 실패해 5분 간격으로 다시 돌렸습니다. 재시도 스크립트의 zsh 단어 분리 버그로 파일 이름이 잘못 붙은 것을 바로잡았고, 16건을 모두 모았습니다. 생성 중 OpenAI 과부하 1회는 같은 명령으로 재실행해 해결했습니다.
