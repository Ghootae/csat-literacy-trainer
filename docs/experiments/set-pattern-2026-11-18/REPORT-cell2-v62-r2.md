## 관찰
- 같은 문항의 등급이 회차 사이에 크게 움직였다: 표 B-V1·그래프 B-V2는 4/4 '같음'에서 각각 2/4, 0/4로, 그래프 A-V2는 0/4에서 3/4로. 같은 문항 묶음이 아니라(6문항, 지문 둘, 순서 변경) 표본 4명의 변동과 맥락 효과를 가르지 못한다.
- 생성 문항 4개 모두 두 회차에서 '수능 아님' 0회. 정답은 전부 일치.
- 이유 읽어서 센 값 — '정답이 〈보기〉 한 단계로 정해짐': 표 A-V1 1(넓게 보면 2), 기출 12번 3, 나머지 생성 문항 0. 기출 13번은 〈보기〉가 아니라 "지문 한 문장(위헌 결론)으로 바로 정해짐" 3명, ㉲ 3회.
- 그림·읽기 판을 탓한 등급 이유 0건. 한 줄 평: 그래프 A-V2 4/4가 ⓒ·ⓓ 표기 겹침 또는 '접함' 표현 부정확, 그래프 B-V2는 "수요·공급 곡선이 아님에 주의", 기출 12번 1명이 읽기 판 '시작→끝' 군더더기.
- `aggregate.py`에 `r2` 인자 추가(인자 없으면 1회차 출력 바이트 동일 확인). 2회차 출력의 "5문항 전체" 제목은 실제 6문항.
