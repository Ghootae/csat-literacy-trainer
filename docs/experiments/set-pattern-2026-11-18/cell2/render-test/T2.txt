[그래프 읽기 판]
가로축: 수량(개). 세로축: 가격(원).
세로축에 값이 적힌 눈금: 500, 600.
곡선 위 표시(가로축 왼쪽부터): ㉡(S₂ (이동 후)), ㉠(S₁ (이동 전)).
가로축에 값이 적힌 눈금: 40개, 50개.
D:
- 시작 → 끝: 감소
S₁ (이동 전):
- 시작 → ㉠(500): 증가
- ㉠(500) → 끝: 증가
S₂ (이동 후)(점선):
- 시작 → ㉡(600): 증가
- ㉡(600) → 끝: 증가
D와 S₁ (이동 전)는 가로축 50개에서 만남(교차).
D와 S₂ (이동 후)는 가로축 40개에서 만남(교차).
