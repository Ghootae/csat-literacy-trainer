6번은 광고의 제작·게시 주체와 정치적 글의 내용·게시 방식을 읽고 → 표시 의무의 적용 범위, 자유 시장 이론과 비판론, 위헌 결정에 각각 대응시켜야 한다.  
이어 학생이 직접 ‘규제 필요성을 뒷받침하는 사례’와 ‘실제로 법적 제재가 가능한 경우’를 구별해야 하므로, 여러 문단의 관계가 풀이에 필요하다.
