# 인간 보고서: 과학 사례(고체 촉매) B형 재생성 + 블라인드 2회 (순서표 ③-d, 2026-11-25)

## 1. 개요
1) **목적**: 새로 정한 칸 판정 기준 4-3(칸 평균 ≥1.5 통과, 1.0~1.5 거의, 1.0 미만 미달, 블라인드마다 자격 기출이 단독 1.5 이상)을 기록에 반영하고, 미달이 된 과학 사례 칸의 B형만 한 번 다시 만들어 본다.
2) **결과**: B형을 새로 만든 칸 평균은 **1.09**(두 회차 평균)로, 4-3으로는 '거의' 구간이다. 다만 회차별로 0.88과 1.31로 흔들렸다. 새 B형은 오히려 평균 0.81로 낮았고, 그중 B-V2는 첫 회차에서 평가자 4명 모두 '수능 아님'이었다가 둘째 회차에는 모두 '중'이었다. 기존 A형은 1.38. 자격 기출(플라스틱 10번)은 두 회차 모두 2.00이라 평가 잣대는 정상이다. 비용 $0.96.
3) **다음 스텝**: 웹이 사례 칸을 판정한다(PROGRESS-hard 과학 사례 결과 줄은 그때 고친다). 이어서 ③-2 실험(kind-experiment-v6 초안 결정).

## 2. 본문
### 기록 반영 (해결)
4-3 소급 문구를 PROGRESS-hard(사회 관점·사회 그래프·과학 그래프·과학 사례 4곳)와 CURRENT_STATE에 넣었다. 지시문 문안 그대로이며 과학 사례 결과 줄은 건드리지 않았다.

### 새 B형 두 문항 (판단 필요)
- **B-V1(고체 촉매의 금속 입자 표면)**: 평가자 8명 중 7명이 '중'. 이유는 "정답 판단이 정의 확인에 가깝다"(㉲ 4회). 수능 같음은 1명.
- **B-V2(적정 범위에 수치 대입)**: r1 4명 모두 '수능 아님', r2는 4명 모두 '중'. 이유는 "①·④가 〈보기〉 없이 지문 정의만으로 탈락하고, 수치를 범위에 대입하면 정답이 드러난다"(㉯ 8회). 같은 문항이 회차에 따라 0.00과 1.00이 된 것은 평가 흔들림이거나 문항이 경계선이라는 뜻이다. 한 번 더 재서 가를 수도 있다.
- 생성 단계에서 검사기가 이미 M2(〈보기〉만으로 정오가 정해지는 선지)를 두 문항 모두에 경고했고 수리는 돌지 않았다.
