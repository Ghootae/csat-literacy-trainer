# REPORT-cell3e-experiment-human (인간 보고서, 2026-11-25)

## 1. 개요

1) 작업의 목적: 지난번 웹 결정(카드 "(가) 초안 채택 + 수리 강제")대로 규칙·코드를 넣고, 표면 장력 지문에서 실험 〈보기〉 두 문항(B형)을 만들어 수능 같은지 보는 것.
   - 실험 〈보기〉는 예를 들어 "잉크 두 가지를 같은 프린터로 시간 간격을 두고 찍어 본 관찰"처럼, 지문의 원리를 관찰 결과에서 거꾸로 짚게 하는 〈보기〉다.
2) 작업의 결과:
   - 규칙 3곳(실험 갈래 새 파일, R1·R5 예외 한 줄씩), 코드 3곳(run.mjs, classify-v6.mjs, 시험)을 바꿨고 시험은 13/13 통과했다.
   - 생성 2문항은 평가자 4명 × 2회 모두 "수능 같음"(평균 2.00)이었다. 자격 기출(플라스틱 10번)은 1.75로 기준(1.5) 위였다.
   - 같은 지문의 진짜 기출 16번은 "중"(평균 1.00)이었다. 생성 문항이 기출보다 높게 나온 것이다. 평가 잣대가 흔들린다는 신호일 수 있다.
   - 비용은 $1.29(상한 $2.5).
3) 다음 스텝: 웹에서 칸 판정(평균 2.00, 수능 아님 0회)과 아래 두 가지 판단을 본다.

## 2. 본문

### 규칙·코드 반영 (해결)
어떤 문제가: 실험 〈보기〉는 목적 없이도 "확인해 보니 더 끈적끈적해서 첨가제를 넣었다"처럼 계기를 쓰고, 마지막 결과를 비우기도 한다. 기존 R1(목적·까닭 금지)·R5(결과까지 쓰기)와 부딪쳤다.
어떤 과정: 실험 갈래에만 예외 한 줄씩을 R1·R5 아래에 달았다. 검사기는 방식 위반이 하나여도 수리하도록 바꿨고(관점은 제외), 형식 점검에 "맨 끝 줄에 (단, …)" 확인을 더했다.
어떤 결과: 해결. 건조 실행에서 지시문에 실험 문단과 예외 줄이 들어간 것을 확인했다.

### 수소 저장 12번 대조 (판단 필요)
세 번째 평가원 실험 기출(수소 저장)을 실험 규칙에 대 보니, 비교 하나·괄호(KX1), 수치 없음(KX2), 목적 없음(KX4)을 모두 어긴다("수소 기체를 얻고자 실험을 수행", 10몰·6몰 수치). 압전·표면 장력 두 문항만 규칙에 맞는다. 이 문항은 원래 "구체적 사례 적용"으로 분류돼 있다. 규칙은 고치지 않았다. 갈래의 범위를 "관찰 결과를 되짚는 형식"으로 좁혀 둘지는 웹 판단이다.

### 생성과 블라인드 (결과 나옴)
문제: 표면 장력 지문에서 실험 B형 두 문항을 만든다.
과정: 지문 등록 → 골드 지도 3회 → 생성. 두 문항 모두 결함·방식 위반이 없어 수리가 돌지 않았다. 한 문항(B-V2)만 검사기 경고 둘이 있었다(핵심 관찰을 가려도 정답이 남음, 경쟁 선지 판단이 다름).
- B-V1 예: 두 프린터 노즐과 방울을 같은 배율로 찍은 사진에서 "㉯의 구멍이 더 컸고 방울 크기는 같았다". 정답은 "오네소르게 수는 ㉯가 작고, 방울의 압력 차는 같다"(⑤).
- B-V2 예: 한 프린터가 시간이 지나며 "잉크가 안 나옴 → 방울이 표시 안에만 → 작은 점이 많이 남음"으로 변했다. 정답은 "밀도 두 배·지름 절반이면 오네소르게 수는 실제 값과 같다"(①).
결과: 평가자 8번(4명 × 2회) 모두 "수능 같음". 이유는 "노즐 지름과 방울 반지름을 구별해 두 식에 각각 대응시킨다", "점도 변화와 밀도·지름 상쇄를 함께 판단한다"였다.

### 기출 16번이 "중"으로 나온 일 (판단 필요)
같은 지문의 진짜 기출 16번이 8번 모두 "중"이었다. 평가자 이유는 "정답이 〈보기〉 없이 지문의 곱 관계(밀도×노즐 지름이 일정)만으로 정해진다"(㉲ 3번). 생성 문항이 기출보다 높은 점수를 받은 것이므로, 칸 평균 2.00이 곧 기출 수준이라는 뜻이 아니다. 판정에 이 기출을 어떻게 반영할지는 웹 판단이다.

### 확인된 흠 (판단 필요)
- `strategies-v6.md` 표의 S18 줄이 "사례·표·그래프"로 남아 있다. 코드는 실험에서 S18을 허용한다. 모델이 표를 보고 S18을 피할 수 있다(이번에는 두 문항 모두 S18을 고르지 않았다). 이 파일은 이번 지시문의 수정 목록에 없어 손대지 않았다.
- 새 수리 기준(방식 위반 하나여도 수리)은 이번에 시험되지 않았다. 방식 위반이 0개였기 때문이다.
