### 두 칸을 겹쳐 본 진단 (웹)
- 기출에도 ㉯·㉱ 표시가 붙는다(이번 기출 2문항 모두). 즉 "〈보기〉 없이 풀리는 쉬운 선지"는 기출과 생성을 가르는 차이가 아니다.
- 갈리는 곳은 **정답 선지**: 기출은 정답을 고르려면 〈보기〉에서 한 단계 끌어내야 한다(도깨비 반례 → 외재주의가 설명 못 함, 1차 정보수령자 = 임원에게서 직접 받은 C). 생성은 판정에 필요한 사실을 〈보기〉가 적어 둔다(의미 다 "세척 전후 내부 구조가 같다"를 명시).
- K-S8(사례)·K-E6(관점)이 같은 원칙을 갈래별로 적은 것. 두 칸 모두 여기서 멈춤 → 갈래 공통 원칙으로 rules-common에 올리는 것이 다음 후보(공통 규칙 변경 = AUTO-LOOP 멈춤 지점 ⑤, Ghootae 결정).
