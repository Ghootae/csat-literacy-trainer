## 설명

- **목적:** 도덕적 운 지문의 두 칸(인문 관점, 인문 사례)이 '거의'였다. 정해 둔 규칙대로 약한 문항만 한 번 다시 만들어, 이번엔 통과하는지 본다. 사회 표(가격 상한제)는 이미 통과라 건드리지 않는다.
- **방법:** 약했던 A형 두 문항(관점·사례)과 B형 사례 문항을 새로 만들고, 잘 나온 B형 관점 문항(2.00)은 그대로 둔다. 기출(공손룡 12번)을 섞어 평가자 4명이 순서를 바꿔 2번 본다.
- **판정(웹, 4-3):** 칸 평균 1.5 이상 통과, 1.0~1.5 거의, 1.0 미만 미달. 다시 만들어도 '거의'면 더 돌리지 않고 웹에서 원인(특히 사례 문항의 '정답 선지가 너무 티 남')을 규칙 쪽으로 검토한다.
- **다음 스텝:** 결과를 보고 ④를 마무리(인계서)하거나, 사례 칸을 규칙 검토로 넘긴다.
