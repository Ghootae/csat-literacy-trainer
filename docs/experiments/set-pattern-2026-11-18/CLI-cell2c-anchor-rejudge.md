## 설명

- **목적:** 1회차에서 비교용 기출 12번이 '수능 같음'을 1번만 받아 판정이 막혔다. 평가자가 이상한지, 12번이 원래 쉬운 문항인지 가르려는 것이다.
- **방법:** 같은 블라인드에 이미 두 번 4명 모두에게 '수능 같음'을 받은 정보 비대칭 기출 13번을 넣고, 평가자 4명이 다시 판정한다. 새로 만드는 문항은 없다.
- **다음 스텝:** 13번이 '같음' 2회 이상이면 평가는 정상이다. 그때는 2회차 등급으로 두 칸을 판정한다(1·2회차가 다르면 낮은 쪽). 13번도 낮으면 판정 보류로 두고 다시 상의한다.
- **커밋·CLI 시점:** 이번에는 커밋하지 않는다. 판정이 나오면 기록(PROGRESS-hard 두 칸)과 함께 커밋하는 마무리 지시문을 드린다.
