가장 수능다운 문항은 **3번**, 가장 못한 문항은 **2번**이다.  
3번은 ‘X가 금속 표면에 붙음’과 ‘입자의 합체가 감소함’을 읽고 → 지문의 증진제·지지체 작용에 대응시키고 → 소결 억제라는 결과가 같아도 금속이 X의 표면에 분산된 것은 아니라는 판단을 내려야 한다.
