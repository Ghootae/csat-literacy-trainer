3번은 ‘X 원자가 금속 표면에 떨어져 붙었다’는 배치를 읽고 → 증진제의 표면 구조 변화와 지지체의 분산 작용에 각각 대응시켜 → 소결 억제라는 결과가 같아도 작용 원리는 다르다고 판단해야 한다.  
또한 X 추가 공급 뒤의 변화는 전자 밀도·흡착 세기 조절로 따로 해석해야 한다.  
1번은 실리카의 성질과 금속 분산을 읽고 → 지지체에 대응시킨 뒤 → 소결을 억제하는 물질이 소결을 일으킨다는 ④를 배제하면 되어, 학생이 구성해야 할 추론이 짧다.
