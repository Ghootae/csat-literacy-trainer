가장 수능다운 문항은 **2번**, 가장 못한 문항은 **4번**이다.  
2번은 ⓒ·ⓓ의 농도와 증가량을 읽고 → 그늘진 쪽에 옥신이 더 많다는 개념에 대응시키고 → 고농도인 그늘 쪽의 생장 촉진이 오히려 작다는 판단을 학생이 내려야 한다.  
4번은 세 곡선의 반응 시작점을 읽고 → 기관별 감수성에 대응시키고 → ⓒ의 감수성이 더 낮다고 판단하면 ⑤를 고를 수 있다.
