| 문항 | 답 | 판정 | 이유 | 결함 | 그래프 평 |
|---|---|---|---|---|---|
| 1 | ① | 수능 같음 | 인쇄 양상과 점도 변화에서 시점별 오네소르게 수의 관계를 추론하고, 밀도·노즐 지름의 변화가 상쇄되는 조건까지 적용해야 한다. |  |  |
| 2 | ③ | 중 | 정답 선지가 밀도와 노즐 지름의 상쇄 조건을 자체적으로 제시하여, 〈보기〉의 경과를 해석하지 않아도 정답을 확정할 수 있다. |  |  |
| 3 | ⑤ | 수능 같음 | 관찰된 노즐·방울의 크기를 각각 오네소르게 수와 라플라스 관계에 대응시켜, 서로 다른 두 압력·인쇄 조건을 구별해야 한다. |  |  |
| 4 | ③ | 수능 같음 | 사슬 구조의 차이를 결정 영역의 비율로 해석하고, 이를 화학 물질에 대한 민감성과 용도 선택으로 연결하는 적용 과정이 명료하다. |  |  |

가장 수능다운 문항은 **3번**, 가장 못한 문항은 **2번**이다.  
3번에서는 같은 배율의 사진을 읽고 → 노즐 지름과 방울 반지름을 구별하여 두 개념에 각각 대응시키고 → 큰 노즐에서는 오네소르게 수가 작지만, 같은 크기의 방울에서는 내외부 압력 차이가 같다고 판단해야 한다.  
2번에서도 인쇄 경과를 읽고 → 점도 변화와 적정 범위를 대응시키는 과정은 가능하지만 → 정답 ③을 고르는 데에는 그 과정을 거칠 필요가 없다.  
③에 제시된 밀도 두 배와 노즐 지름 절반을 지문의 곱 관계에 대입하면 곧바로 확정되므로, 두 문항의 차이는 **〈보기〉의 관찰 정보를 해석하는 단계가 정답 도출에 필수적인가**에 있다.
