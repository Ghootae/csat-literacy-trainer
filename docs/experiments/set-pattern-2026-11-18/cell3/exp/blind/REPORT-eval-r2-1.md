가장 수능다운 문항은 **3번**, 가장 못한 문항은 **2번**이다.  
3번은 사진의 크기 정보를 읽고 → 노즐 구멍은 오네소르게 수에, 방울 크기는 라플라스 식에 대응시키고 → 노즐이 커도 같은 크기의 방울에서는 압력 차이가 같다는 판단을 스스로 내려야 한다.  
2번은 정답 선지의 조건을 읽고 → 밀도와 노즐 지름의 곱에 대응시키고 → 두 배와 절반이 상쇄된다고 판단하면 끝나므로, 시간에 따른 인쇄 사례를 읽지 않아도 정답을 확정할 수 있다.  
2번의 ㉰는 두 색의 노즐 모양·크기가 동일하다는 조건이 선지 판단에 쓰이지 않기 때문이며, 〈보기〉 없이 풀리는 선지가 두 개 이상은 아니므로 ㉯는 표시하지 않았다.
