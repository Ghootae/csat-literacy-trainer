4번은 가지형·직선형 사슬의 배열 가능성을 읽고 → 지문의 결정 영역 개념에 대응시키고 → 어느 소재의 결정 영역 비율이 높을지 판단해야 한다.

따라서 4번은 구조에서 물성을 거쳐 용도까지 판단을 이어 가지만, 3번은 지문 사례의 반복과 주어진 수치 관계의 확인에 풀이가 집중된다.
