- **목적:** 평가자(codex)의 '수능 같음' 등급이 실제 수능 기출을 기출답게 보는지 잰다. ③에서 평가원 기출이 '수능 아님'을 받아 판정이 멈췄으므로, 잣대부터 확인한다. 함께 ③-1을 '판정 보류'로 기록한다.
