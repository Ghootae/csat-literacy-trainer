## 1. 지금 기준의 문제

지금 L2 통과 조건은 "두 문항 모두 '수능 아님' 1회 이하 **그리고** 한 문항 이상 '수능 같음' 3회 이상"이다. 평가자가 4명이라 이 조건은 한 사람의 마음에 달려 있다.

- ② 표 B는 같은 문항인데 1회차에 '같음' 4명, 2회차에 2명이었다. 그래프 B는 4명에서 0명, 그래프 A는 0명에서 3명이 됐다.
- ① 앵커 정보 A(같은 문항)도 '같음' 4명에서 0명이 됐다.
- ② 판정 보류도 이 방식에서 나왔다. 기출 12번이 '같음' 1명이라 "기출 '같음' 2회 미만 → 보류"에 걸렸다.

**바로잡을 점 하나:** ② 인계서와 검토는 앵커 13번이 "① 칸에서 2.00·2.00"이었다가 1.25로 떨어졌다고 적었다. ① 보고서를 다시 보니 13번은 ① 두 회차 모두 **1.50**(같음 2·중 2)이었다. 4명 모두 '같음'은 그 전의 gen62 블라인드 값이다. 그래서 ②에서 13번이 움직인 폭은 −0.25뿐이다. "지문을 섞어 기준이 엄해졌다(맥락 효과)"는 추정은 근거가 약해진다. 보류를 일으킨 것은 점수 하락이 아니라 '같음' 1명이라는 횟수 기준이었다.

## 2. ①·② 점수로 다시 계산

D = (그 칸 생성 2문항 평균) − (같은 블라인드 기출 평균).

| 칸 | 회차 | 생성 A / B | 칸 평균 | 기출 | **D** |
|---|---|---|---|---|---|
| 사회 관점 (정보) | 1 | 1.00 / 1.25 | 1.125 | 13번 1.50 | **−0.375** |
| | 2 (새로 생성) | 2.00 / 1.00 | 1.50 | 13번 1.50 | **0.00** |
| 인문 사례 (공손룡) | 1 | 1.50 / 1.00 | 1.25 | 12번 2.00 | **−0.75** |
| | 2 (새로 생성) | 1.50 / 1.25 | 1.375 | 12번 2.00 | **−0.625** |
| 사회 표 (조세) | 1 | 1.25 / 2.00 | 1.625 | 12번 1.25 | **+0.375** |
| | 2 (같은 문항) | 1.50 / 1.50 | 1.50 | 12번 1.25 | **+0.25** |
| 사회 그래프 (조세) | 1 | 1.00 / 2.00 | 1.50 | 12번 1.25 | **+0.25** |
| | 2 (같은 문항) | 1.75 / 1.00 | 1.375 | 12번 1.25 | **+0.125** |
| (참고) 앵커 v5 정보 | 1 / 2 | 2.00·1.00 / 1.00·1.00 | 1.50 / 1.00 | 1.50 | 0.00 / −0.50 |
| (참고) 앵커 v5 공손룡 | 1 / 2 | 1.50·0.75 / 1.50·0.50 | 1.125 / 1.00 | 2.00 | −0.875 / −1.00 |

읽는 법:
- **문항 하나는 회차 사이 1.00까지 움직였지만, 칸의 D는 많아야 0.5 움직였다**(6쌍 중 4쌍은 0.125). 같은 문항을 다시 평가한 ② 두 칸은 0.125씩만 움직였다.
- D는 칸끼리 순서도 그럴듯하게 가른다. 공손룡 v5 앵커(〈보기〉 없이 풀리는 선지 ㉯ 4회가 두 번 재현된 문항)가 가장 낮고, ② 표·그래프가 가장 높다.

## 3. 제안 기준

칸마다(생성 A·B 2문항) 다음 순서로 본다. 경계 0.5·1.0은 WORKING-RULES 4-1의 구간 그대로다.

| 순서 | 조건 | 결과 |
|---|---|---|
| ① 평가 정상 | 같은 블라인드 기출 평균 1.0 이하 | **멈춤**(평가 이상이거나 대조 기출이 맞지 않음). 1.25면 '대조 기출 낮음' 주의를 붙이고 계속 |
| ② 바닥 | 생성 문항 중 '수능 아님' 2회 이상인 것이 있음 | **미달** |
| ③ 주 기준 | D > −0.5 **그리고** 칸 평균 ≥ 1.25 | **L2 통과** |
| | D > −0.5 이지만 칸 평균 < 1.25 | 거의 통과 |
| | −1.0 < D ≤ −0.5 | 거의 통과 |
| | D ≤ −1.0 | 미달 |

- **칸 평균 ≥ 1.25**를 둔 이유: 기출이 얕게 나온 회차(②의 12번 1.25)에는 D만으로는 '전부 중'(1.00)인 칸도 통과한다. 평가자 4명 × 2문항 = 8표 중 '같음'이 2표 이상은 있어야 통과로 친다.
- **블라인드 2회:** 같은 문항 묶음을 순서만 바꿔 2번 평가하고, D와 칸 평균은 두 회차 평균으로 낸다. 평가자는 codex(ChatGPT 계정)라 API 비용이 없다. 시간만 한 번 더 든다.
- **지문 하나씩:** 한 요청에 지문 하나만 넣는다. 앵커(지난 판 문항)는 같은 지문일 때만 넣는다.
- **'수능 같음' 횟수:** 보고서에 계속 적지만 판정에는 쓰지 않는다.
- 그 뒤 갈래는 지금과 같다. 거의 통과 → 그 칸만 1회 재생성 → 결과와 상관없이 기록하고 넘어감. 미달 → 멈추고 웹 검토.

## 4. ①·②에 소급하면

두 회차 평균으로 계산했다(①은 회차마다 다른 문항이라 회차별로도 적음).

| 칸 | 지금 기록 | 새 기준 | 바뀜 |
|---|---|---|---|
| 사회 관점 (정보) | L2 통과(표본 1, 앵커 흔들림 주의) | 1회차 거의(평균 1.125), 2회차 통과. 두 회차 평균 D −0.19, 칸 평균 1.31 → **통과** | 이름 그대로, 주의 문구는 뺄 수 있음 |
| 인문 사례 (공손룡) | 거의 통과(v6.2) | D −0.75·−0.625 → **거의 통과** | 그대로 |
| 사회 표 | 판정 보류 | D +0.31, 칸 평균 1.56 → **통과** (대조 기출 낮음 주의) | 보류 → 통과 |
| 사회 그래프 | 판정 보류 | D +0.19, 칸 평균 1.44 → **통과** (대조 기출 낮음 주의, 생성 그래프 2/2가 값 선 그래프) | 보류 → 통과 |

- 걸리는 점: 이 기준은 ② 결과를 본 뒤에 만들었다. 그래서 ② 두 칸은 "통과(소급)"로 적고, 이유(대조 기출이 교육청 문항이고 1.25로 낮음)를 같이 적는다.
- 그래프 칸은 통과로 바뀌어도 "곡선이 만나는 그래프"는 아직 한 번도 안 나왔다. 이건 판정과 별개로 남는 숙제다(③ 과학 그래프 재시험에서 함께 본다).
