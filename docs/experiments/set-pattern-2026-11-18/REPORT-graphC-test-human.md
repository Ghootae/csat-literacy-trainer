# 그래프 첫 실전 — 쉬운 설명 (2026-11-25)

## 1. 개요
1) **목적:** 새로 만든 그래프 도구(생성기가 먼저 "그래프 계획"을 쓰고 서버가 확인하는 방식)가 실제 문항 만들기에서 잘 쓰이는지 처음 시험했다. 가격 상한제 지문으로 그래프 문항 2개(A형·B형)를 만들고, 기출 문항과 섞어 평가자 4명이 2회 풀고 판정했다.
2) **결과:** 계획 확인은 둘 다 통과했다. 점수는 A형이 1.75(수능 같음 6번), B형이 0.88이다. 두 문항 평균 1.31로, 기출 지문 그래프(1.44)보다 0.13 낮다. B형이 낮은 이유는 평가자 8명이 전부 같은 곳을 짚었다. 그림과 글로 옮긴 읽기 판이 서로 다르다는 것이다.
3) **다음 스텝:** 웹이 판정한다. B의 결함이 그림 만드는 코드 쪽인지 생성 쪽인지 확인하는 일이 남았다. 이번에는 코드를 고치지 않는 조건이라 보지 않았다.

## 2. 본문
### 문제 1. A형: 네 선이 한 점에서 만나는 그래프 (대체로 해결)
- **어떤 문제가:** 지문이 "가격이 오르면 수요량은 줄고 공급량은 늘어 격차가 좁아진다"고 했다. 이 관계에서 두 시장 A·B의 수요·공급 곡선 네 개를 그려야 했다.
- **과정:** 생성기가 계획에 변수(가로 가격, 세로 수량)와 계열마다 모양 말을 적었고, 서버 확인을 통과했다. 그림은 계획대로 수요는 내려가고 공급은 올라가며 한 점 E에서 만났다. P₁·P₂·P₃ 기호 눈금과 세로 점선, 교점 E 표시도 선지가 부르는 곳에 있었다.
- **결과:** 평가자 8명 중 6명이 '수능 같음', 2명이 '중'. '중'을 준 두 명은 "부족량 40개와 70개만 비교해도 정답이 드러난다"는 문항 쪽 이유를 들었다. 그림 탓 이유는 없었다. 남은 흠은 곡선 이름이 선에 닿는 것, 범례에서 수요·공급이 같은 실선이라 구별이 안 되는 것이다.

### 문제 2. B형: 읽기 판이 그림과 다름 (미해결)
- **어떤 문제가:** "수요의 가격 탄력성"을 가로축으로 하는 그래프다. 세 시장 갑·을·병의 선 세 개.
- **과정:** 생성기의 계획과 서버 확인은 통과했다. 그런데 그림 옆의 글(읽기 판)이 "병은 ⓔ(100)에서 ⓑ로 증가"라고 적었다. ⓑ는 갑의 끝점이고, 병의 끝점(120)에는 표시가 없다. 문항을 푸는 데는 영향이 없었지만(정답 일치 8/8) 평가자 8명이 모두 이를 짚었다.
- **결과:** 평점 0.88. 이유 8건이 전부 그림·읽기 판 탓이다. 점 ⓐ·ⓒ 표시 겹침, 세로 눈금에 120이 없는 것, 선이 납작한 것도 기록했다. 서버 확인이 이런 불일치는 못 잡는다는 점이 드러났다.
