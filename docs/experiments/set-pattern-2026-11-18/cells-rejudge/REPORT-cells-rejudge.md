## 4. 해석 (측정과 구분)

1. **과학 사례**: 6문항이 거의 같은 점수(1.0~1.125)다. 평가자 이유는 거의 모두 "정답이 한 문장 대응이거나(㉲), ①·④가 〈보기〉 없이 배제된다(㉯)"로 같은 지점이다. 예전의 "미달"은 절대 기준 1.5 때문이었고, 새 기준에서는 바닥 0개·G−M −0.417로 통과선(−0.4) 바로 아래다. M이 높게 나온 것은 K06·K38·플라스틱이 2.0 근처인 탓이다. 이 칸이 "거의"인 것은 지문 탓만은 아니다: 고체 촉매 지문 기출(K17, 0.000)을 M에서 빼고 보면 M 1.725, G−M −0.704로 여전히 "거의"다.
2. **사회 관점**: M이 1.000으로 낮은 것은 KV-효율성(0.000)이 끌어내린 영향이 크다. 효율성은 화법과 작문 묶음(〈보기〉가 (다)를 쓴 뒤 모은 자료)이라 **관점 갈래가 아니다**(지시문의 "관점 갈래가 아니면 CLI가 보고에 적는다"). 또 평가자 이유(r1-1·r2-1)가 모두 "(가)(나)(다)와 [A] 표시가 풀이지에 없어 그대로 출제하기 어렵다"여서, 0.000은 문항의 질이 아니라 **자료 변환 때 표시가 빠진 탓**으로 읽힌다. 효율성을 뺀 M 1.250으로 다시 보면 G−M −0.156으로 결론(통과)은 같다.
3. **사회 그래프**: 기출 앵커가 KG 2개 + 조세 1개뿐이라 M(1.208)의 폭이 넓다. KG-관세는 〈보기〉 그림이 "표"이고 발문이 "활동1"로 지문 밖 활동 맥락을 가정하며(풀이지에 활동 표시 없음, ㉰ 8/8), KG-소비 r2-1도 "[A]의 범위가 본문에 표시되지 않았다"를 지적했다. 즉 두 KG 앵커도 표시 빠짐의 영향으로 낮을 수 있다. 조세 1개(1.750)만 기준으로 해도 G−M −0.188로 통과다.
4. 세 칸 모두 정답 일치 8/8 — 평가자가 풀 수 없어서 낮은 점수가 나온 문항은 없다.

## 5. 한계·정정

- KV/KG 새 앵커는 `passage_db`로 만든 지문이라 (가)(나)(다)·[A]·활동 같은 표시가 빠졌다(생성 문항 쪽은 원래 "윗글" 형식). 이는 앵커 점수를 낮추는 방향의 비대칭이다. 비대칭을 풀려면 표시를 넣은 판을 따로 재야 하는데, 이번 지시에는 없다.
- KG 풀이지는 읽기 판을 만들지 않으므로, 그림 판 문안 중 "읽기 판도 적혀 있어" 부분만 "읽기 판은 없어"로 바꿨다(사실과 맞추기 위한 최소 변경). 생성 그래프 문항 SG-A2·SG-B2는 읽기 판이 있는 원래 문안 그대로다. 그림 유무·읽기 판 유무가 점수에 미치는 영향은 이번에 분리하지 않았다.
- 칸마다 생성 문항 수(6·4·2)와 앵커 수(6·5·3)가 달라 불확실성이 다르다. 사회 그래프는 생성 2문항뿐이다.
- 사회 관점 생성 문항의 1회차·2회차는 같은 칸의 별개 문항이라 독립 4문항으로 썼다.

## 6. 열린 질문·제안 (웹이 정할 것)

- 과학 사례 "거의"(−0.417)를 칸 판정으로 어떻게 기록할지(PROGRESS-hard는 고치지 않았다).
- KV-효율성을 앵커에서 뺄지(갈래 불일치 + 표시 빠짐). 빼도 사회 관점 결론은 같다.
- 표시를 보존한 앵커 판이 필요한지.
