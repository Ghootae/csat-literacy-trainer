- **두 판단을 따로 내려야** 한다. 거래 원인과 행위자 지위를 나누고, 본성 발견 시점과 의미 성립 시점을 나눈다.

- 〈보기〉가 개념 분류를 이미 해 줌(㉴, 의미 6.1 B: "갑의 근거 = 기술구, 을 = 실제적 본성").
