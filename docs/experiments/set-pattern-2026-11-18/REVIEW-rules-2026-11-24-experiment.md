## 3. 걸리는 점
- 기출 2문항 모두 **B형(긍정 발문)** 이다. A형 실험 기출은 평가원·수능에 없다(INVENTORY: 실험 애매 4개 중 A형은 공포 소구 1개, 인문). A형으로 만들 때의 깊이는 근거가 없으므로, 시험은 B형부터 한다.
- 표본 2문항이라 KX1~KX3도 '기출 2/2'일 뿐이다. 칸 시험 결과를 보고 다시 본다(한 번 본 실패로 문구 규칙을 더하지 않음).
- 코드: run.mjs의 KIND 목록(case·table·view·graph)에 experiment를 더해야 한다(KIND_NAME, 형식 점검: 글자 수·"(단," 괄호 유무). eval-repair·classify-v6가 갈래 이름을 쓰는지 CLI가 grep으로 확인. API 비용 없음.
