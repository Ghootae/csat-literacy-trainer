## 2. 고난도(3점) 문항의 형태

**3점 174문항 중 171개(98%)가 〈보기〉 문항이다.** 지문 구조와 상관없이 그렇다. 그러니 "고난도를 어떤 형태로 낼까"는 실제로는 **"〈보기〉에 무엇을 담을까"**의 문제다.

- 발문: "적절하지 않은 것은?" 142, "가장 적절한 것은?" 29
- 〈보기〉에 그림·그래프·표가 들어간 문항: 67/171 (39%)

- **법·제도(S6 요건과 규율)는 사례 판별이 기본**이다(11/16). 갑·을 사례를 주고 어느 요건·갈래에 드는지 묻는다.
- **절차·계산(S3)은 거의 다 그림·표**다(12/12). 단계 도식이나 수치 표를 주고 따라가게 한다.
- **작동 원리(S1)와 조건·효과(S2), 대조(S4)는 그림·그래프 비중이 절반 이상**이고, 나머지가 사례·실험이다.

- 남는 차이는 길이보다 **갈래**다. 생성 8개는 실험 서사 5개, 정수장 운영 사례 3개이고 그림·표나 외부 글은 없다. 기출에서 실험·관찰 갈래는 6%뿐이고, 그림·표가 39%다.

## 3. 생성기에 주는 뜻

1. **세트 뼈대**: 일치·세부 1 → 밑줄 대상 이해 또는 이유 추론 1 → 〈보기〉 3점 1(필요하면 〈보기〉 하나 더) → 어휘 1. 복합 지문은 앞에 (가)(나) 비교를 붙이고 6문항.
2. **고난도는 〈보기〉 하나로 충분**하다. 대신 〈보기〉 갈래를 지문 구조에 맞춰 고른다.
   - 법·제도(S6) → 갑·을 사례 판별
   - 절차·계산(S3) → 표·단계 도식
   - 작동 원리·조건(S1, S2, S4) → 그래프·도식 또는 사례
   - 관점·입장(S7, S8, P) → 외부 글·관점 또는 사례
3. **그림이 필요한 몫이 39%**다. 생성기가 그림을 못 그리므로 우선은 글로 된 표(행·열)와 단계 목록으로 대신한다. 그래프는 "값이 이렇게 바뀐다"는 짧은 수치 표로 바꿀 수 있다.
4. deep-item은 지금 A(개념 연결)·B(계산) 양식이 대부분 실험·운영 서사로 수렴한다. 갈래를 입력으로 받게 하는 것이 다음 손질 1순위다.
