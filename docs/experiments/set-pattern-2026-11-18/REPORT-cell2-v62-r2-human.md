# 순서표 ② 2회차 결과 — 쉬운 설명 (2026-11-24)

## 1. 개요
1) **목적:** 1회차에서 비교용 기출 12번이 '수능 같음'을 1번만 받아 판정이 막혔다. 평가자가 까다로운 건지 12번이 원래 쉬운 문항인지 가르려고, 이미 두 번 4명 모두에게 '같음'을 받은 정보 비대칭 기출 13번을 섞어 다시 평가했다(API 비용 0).
2) **결과:** 13번도 이번에는 '같음'을 1명에게만 받았다(1회차 판정 규칙의 기준은 2명 이상). 즉 **"평가자가 정상"이라고 확인되지 않았다.** 게다가 같은 문항의 등급이 크게 흔들렸다. 표 B와 그래프 B는 4명 모두 '같음'이었다가 2명, 0명으로 내려갔고, 그래프 A는 0명에서 3명으로 올라갔다. '수능 아님'은 두 회차 모두 0번이다.
3) **다음 스텝:** 웹이 판정 보류를 이어 갈지, 평가자 4명의 변동이 크다는 점을 감안해 방식을 바꿀지(예: 평가 인원·반복 늘리기) 정한다.

## 2. 본문
### 평가 방식이 흔들린다 (판단 필요)
- 사례: 표 B-V1이 1회차에는 "같은 세액·같은 가격 변동인데 과세 대상에 따라 부담이 뒤집힌다"며 4명 모두 '같음'. 2회차에는 2명이 "같은 계산의 반복이라 얕다"며 '중'.
- 앵커 13번도 3명이 "위헌 결론 한 문장으로 바로 정해진다"며 '중'. 앵커가 낮으면 평가자가 까다로운 쪽으로 기운 회차라고도 볼 수 있지만, 이번 값만으로는 구별되지 않는다.
- 그림 탓은 여전히 0건(등급 이유). 그래프 A는 'ⓒ·ⓓ 표기 겹침, 접함 표현'을 한 줄 평에서 4명 모두 지적.
