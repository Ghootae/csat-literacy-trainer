- 다에서는 오류 수·가격·열람 권한을 읽고 정보 비대칭과 역선택의 조건에 대응시켜야 한다.
- 그러나 ‘가격이 더 낮다 → 역선택이 아니다’라는 연결에 필요한 기준이 빠져 있어, 학생의 추론보다 출제자의 가격 해석을 맞히는 일이 된다.
