**지문 1 — 가장 수능다움: 라 / 가장 못함: 다**

라는 광고를 만든 사람·판매자·플랫폼의 역할과 실명 확인 여부를 읽고 → 생성물 표시 의무의 적용 범위와 실명확인 규정에 대한 위헌 결정에 대응시켜야 한다.  
학생은 광고가 문제라는 사실과 해당 주체를 제재할 법적 근거가 있다는 판단을 구별하고, 위헌으로 결정된 규정에 따라 실제 제재할 수 있는지도 판단해야 한다.  
다는 검수 결과의 공개 범위·오류 수·가격을 읽고 → 완전 정보와 역선택의 요건에 대응시킨다.  
그러나 낮은 품질의 서비스를 더 낮은 표시 가격에 샀다는 사실만으로 역선택을 부정하려면 가격 비교 기준이 확정되어야 하므로, 풀이의 핵심에서 불필요한 해석 부담이 생긴다.

**지문 2 — 가장 수능다움: 차 / 가장 못함: 사**

차는 갑의 해명과 을의 반응을 읽고 → ⓐ의 필요한 빨간 옷, ⓑ의 특정 옷, ⓒ·ⓓ의 일반적인 옷을 구별해야 한다.
