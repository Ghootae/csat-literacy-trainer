**지문 1 — 가장 수능다운 문항: 마 / 가장 못한 문항: 다**

마: 반박 글 이후에도 허위 주장이 지속되고, 플랫폼이 새 불법 글을 차단하는 과정을 읽는다.  
→ 이를 각각 ‘토론에 의한 자율적 교정’과 ‘공동 규제의 첫 단계인 사전 차단’에 대응시킨다.  
→ 두 조치의 주체와 작동 방식이 다르므로, 토론의 실패가 사전 차단의 부적절성을 뜻하지는 않는다고 스스로 판단해야 한다.  
다: 오류 수·가격·정보 공개 범위를 읽고 정보 비대칭과 역선택에 대응시키지만, 낮은 표시 가격만으로 ‘상대적으로 비싼 가격’이 아니라고 확정하는 단계에는 해석의 여지가 남는다. ②는 두 서비스의 표시 가격을 직접 비교한다는 해석에서 고른 답이다.

**지문 2 — 가장 수능다운 문항: 차 / 가장 못한 문항: 사**

차: 갑의 마지막 해명을 읽고, ⓐ는 필요한 빨간 옷을, ⓓ는 특정 색을 한정하지 않은 옷을 뜻함을 복원한다.  
→ 이를 명의 지시 대상과 속성 구별이라는 공손룡의 개념에 대응시킨다.
