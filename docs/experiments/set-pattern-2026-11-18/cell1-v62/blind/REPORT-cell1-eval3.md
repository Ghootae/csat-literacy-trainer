**지문 1 — 가장 수능다움: 다 / 가장 못함: 가**

다는 ‘재접수 → 공개 대기 → 열람 불허 → 이용자 화면에 나타나지 않음’을 읽고, 접수와 유통을 구별해야 한다.  
이를 ‘플랫폼의 사전 조치가 미흡할 때 정부가 사후 개입한다’는 조건에 대응시켜, 이미 차단된 글에 정부 조치가 필요한지 스스로 판단한다.  
가는 ‘반박에도 조작 글이 재등장했고, 언론사가 불법 글을 차단했다’를 읽고 비판론의 규제 방안에 대응시킨다.  
그러나 정답 선지는 지문이 지지한 차단을 규제 방안에서 제외한다고 하므로, 사건의 세부 관계를 충분히 해석하지 않아도 배제하기 쉽다.
