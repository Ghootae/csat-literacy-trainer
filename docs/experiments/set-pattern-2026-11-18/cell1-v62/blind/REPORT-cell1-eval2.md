**지문 1 — 가장 수능다운 문항: 다 / 가장 못한 문항: 가**

- **다:** 예산서 게시 → 삭감 주장 재접수 → 공개 대기 → 열람 불허의 순서를 읽고, ‘주장의 교정’과 ‘유통의 제한’을 구별해야 한다.
- 이를 지문의 자율적 토론과 플랫폼의 사전 규제에 대응시키고, 이미 공개가 차단된 글에도 정부 조치가 필요한지 스스로 판단해야 한다.
- **가:** 반박 실패와 조작 글 차단을 읽고, 차단을 비판론이 인정하는 규제 방식에 대응시키면 된다.
- 그러나 ④는 반박이 실패했다는 이유로 차단까지 배제한다고 하여, 규제 강화 논리를 뚜렷하게 거꾸로 제시한다. 다보다 오답을 배제하는 부담이 작다.

**지문 2 — 가장 수능다운 문항: 사 / 가장 못한 문항: 자**

- **사:** 대화의 정정 과정을 읽고, ⓐ는 필요한 빨간 옷, ⓓ는 옷 일반, ⓑ는 손에 든 특정 옷을 가리킨다고 복원해야 한다.
