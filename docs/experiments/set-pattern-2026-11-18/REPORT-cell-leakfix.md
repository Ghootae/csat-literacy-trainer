# 칸 보고: 노출 수리 시험 (leak-fix, LEAK-FIX.md 4절) — 2026-11-20

**결과: 통과 기준 미달(고친 문항 중 두 평가자 모두 '수능 같음' 0개), 등급 하락 0.** 노출을 고친 문항에서 ㉴(판정까지 〈보기〉가 말함) 표시는 사라졌지만, 등급은 '중'에 머물렀다. 남은 결함은 ㉯(〈보기〉 없이 지워지는 선지)다.

- **판정 모델 = gpt-6.1-sol(생성 모델과 같음).** ChatGPT 계정 codex에서는 gpt-6.2-sol·gpt-6.2-luna·gpt-6.1-luna·gpt-6.1-astra·gpt-6.1·기본값 gpt-6.2-astra가 모두 "not supported"로 거부되어 대체할 수 없었다. 생성과 평가는 별도 호출·새 세션으로 분리했지만, 같은 모델이다.

## 1. 채택 수
leak-fix가 바꾼 문항은 8개 중 2개다(의미 A-V1, 정보 B-V1). 두 문항 모두 다시 풀기에서 정답이 같았고 하나로 정해져 채택되었다. 〈보기〉 길이 변화는 +4.4%, +3.1%였다.
- 의미 A (8): "씻기 전과 후의 내부 구조가 같다는 결과" → "보고서의 '씻은 후 내부 구조' 항목에 '씻기 전' 항목의 설명이 그대로 실렸다"
- 정보 B (3): "소비자 정보가 양이 적고 질이 낮았다" → "판매자는 검사 기록 전체를, 소비자는 항목 누락·수치 오류가 있는 기록을 열람했다"

나머지 6개(공시 A·B, 공손룡 A·B, 의미 B, 정보 A)는 L1(노출 찾기)에서 "노출 없음"으로 판정되어 원본을 유지했다. 그래서 블라인드에는 사례 지문이 들어가지 않았다.

## 3. 반복 결함 (2문항 이상)
- **㉯ 〈보기〉 없이 지워지는 선지**: 고친 후 2문항 모두에서 나왔다(평2는 둘 다, 평1은 정보). 두 평가자의 이유도 같다. "①·③·④(정보는 ③·⑤)가 개념 확인에 머물러 3점 문항의 추론 부담이 낮다."
- 노출(㉴)은 고친 뒤 0건이다. 병목은 노출보다 **선지 구조(오답 선지가 개념 대응만 묻는 것)**에 있다. 이는 LEAK-FIX.md 4절의 "등급 변화 없음 → 병목은 다른 곳(구조 설계)" 경우에 해당한다.
- 따로 볼 점: L1이 6/8을 "노출 없음"으로 판정했다. 직전 판정에서 ㉴가 표시된 문항이 거의 없었으므로 이 판정과 맞는다. 다만 L1이 너무 관대한지는 이번 자료로 확인할 수 없다.

- leak-fix API: gpt-6.1-sol 10회 호출(L1·L2 8회 + L3 다시 풀기 2회)이다. 입력 49,226토큰, 출력 10,217토큰(추론 포함)으로 약 **$0.20**이다(단가 입력 $2·출력 $10 /1M, 캐시 쓰기 가산 제외). 추산 $2보다 낮은 이유는 6문항이 L1에서 끝났기 때문이다.
