5번은 대화의 정정 과정을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷 한 벌, ⓓ는 옷 일반을 가리킨다고 해석해야 한다.  
이를 두 학파의 명실 관계와 유명·사명에 대응시키고 → 특히 ⓓ와 ⓔ의 지시 대상이 같다는 ④의 전제가 틀렸음을 스스로 판단해야 한다.  
2번은 두 작품의 손상과 복원 차이를 읽지만 → 통제 원칙이 비난의 근거를 통제 가능한 선택에 한정한다는 개념만으로 → ④의 ‘손상을 입힌 일도 비난한다’를 배제할 수 있어 사례 해석의 필요성이 작다.
