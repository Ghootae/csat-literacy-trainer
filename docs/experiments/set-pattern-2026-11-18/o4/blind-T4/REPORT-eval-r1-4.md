가장 수능다운 문항은 **5번**, 가장 못한 문항은 **2번**이다.  
5번은 갑의 해명까지 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷 한 벌, ⓓ는 특정 색을 한정하지 않은 옷을 가리킨다고 해석해야 한다.  
이를 명실 대응과 유명·사명 개념에 대응시키고 → ⓓ와 ⓔ의 지시 대상이 같다는 ④의 전제가 틀렸다고 스스로 판단해야 한다.
