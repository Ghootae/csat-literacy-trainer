1번은 대화를 읽고 → ⓐ는 빨간 옷, ⓑ는 특정한 한 벌, ⓓ는 옷 일반을 가리킨다는 차이를 파악해야 한다.  
이를 명실 대응·유명과 사명·속성 지정의 개념에 대응시키고 → ⓓ와 ⓔ의 지시 대상이 같다는 ④의 전제가 잘못되었다고 스스로 판단해야 한다.  
3번은 손실 회복에 관한 ③을 읽고 → 지문의 ‘회복 뒤에도 해명 요구의 근거가 남는다’에 대응시키면 → 〈보기〉의 인과관계와 피해 종류를 분석하지 않고도 정답을 확정할 수 있다.
