가장 수능다운 문항은 **1번**, 가장 못한 문항은 **3번**이다.  
1번은 갑의 해명까지 읽고 → ⓐ는 빨간 옷, ⓓ는 특정 색을 한정하지 않은 옷을 가리킨다고 복원해야 한다.  
이후 지문의 명·실 대응 원칙에 연결하고 → 같은 ‘옷’이라는 표현도 지시 대상이 다르며, ⓓ와 ⓔ 역시 같은 대상을 지시하지 않는다고 스스로 판단해야 한다.  
3번은 〈보기〉의 인과관계와 보호 이익을 따지기 전에 → 지문의 “손실이 이미 회복되었더라도” 해명을 요구할 근거가 있다는 문장만으로 ③을 고를 수 있어, 사례 적용 과정이 정답 결정에 필요하지 않다.
