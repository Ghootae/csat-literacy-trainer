5번은 ‘옆에서는 읽히지만 실제로는 정면에서 읽었다’를 읽고 → ‘위험을 줄일 실행 가능한 조치’와 ‘방치한 위험의 실제 피해 발생’에 대응시켜야 한다.  
이어 게시물 삭제 가능성까지 구별하여 → 예방의 불완전성이 갑의 책임을 없애는지, 별도의 부작위도 비난할 수 있는지를 학생이 판단해야 한다.
