[그래프 읽기 판]
가로축: 송신 주파수(MHz). 세로축: 도플러 변위(Hz).
세로축에 값이 적힌 눈금: −600, 0, 200.
곡선 위 표시(가로축 왼쪽부터): ⓐ(㉠, 가로축 아래), ⓓ(㉡, 가로축 아래), ⓑ(㉠, 가로축 아래), ⓒ(㉠, 가로축 아래), ⓔ(㉡, 가로축 위).
가로축 구간 경계: t1, t2, t3.
㉠:
- ⓐ(−600) → ⓑ: 증가
- ⓑ → ⓒ: 증가
- 가로축 기준 부호: 전 구간 음(−)
- 기울기 크기(가파른 순): ⓐ~ⓑ = ⓑ~ⓒ
㉡(점선):
- ⓓ → ⓔ(200): 증가
- t2(ⓑ와 같은 가로 위치)에서 가로축(0)을 지남(음→양)
- 가로축 기준 부호: 시작~t2(ⓑ와 같은 가로 위치) 음(−), t2(ⓑ와 같은 가로 위치)~끝 양(+)
