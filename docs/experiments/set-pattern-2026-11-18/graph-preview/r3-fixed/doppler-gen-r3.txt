[그래프 읽기 판]
가로축: 도플러 각도(°). 세로축: 주파수(kHz).
세로축에 값이 적힌 눈금: 2000, 2001, 2001.5, 2002.
곡선 위 표시(가로축 왼쪽부터): ⓐ(㉠ 공통 송신 주파수), ⓑ(㉠ 공통 송신 주파수), ⓒ(㉡ A의 수신 주파수), ⓓ(㉡ A의 수신 주파수), ⓔ(㉢ B의 수신 주파수).
가로축에 값이 적힌 눈금: 45°, 60°, 140°.
㉠ 공통 송신 주파수:
- ⓐ(2000) → ⓑ(2002): 증가
- ⓑ(2002) → ⓓ(2002): 일정
㉡ A의 수신 주파수(점선):
- ⓐ → ⓑ: 증가
- ⓑ → ⓒ: 감소
- ⓒ → ⓓ(2001.5): 증가
- ⓑ: 최고점
- ⓒ: 최저점
㉢ B의 수신 주파수:
- 시작(2002) → ⓒ: 감소
- ⓒ → ⓔ(2001): 증가
- ⓒ: 최저점
㉠ 공통 송신 주파수와 ㉡ A의 수신 주파수는 가로축 60°와 ⓒ 사이에서 만남(교차).
