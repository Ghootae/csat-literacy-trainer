[그래프 읽기 판]
가로축: 세포 단면의 가로 위치. 세로축: 표지 신호의 세기.
세로축에 값이 적힌 눈금: 0, 2, 4.
곡선 위 표시(가로축 왼쪽부터): ⓐ(㉠ 막, 가로축 위), ⓑ(㉠ 막, 가로축 위), ⓒ(㉠ 막, 가로축 위), ⓓ(㉠ 막, 가로축 위).
㉠ 막:
- 시작(0) → x=0.8(0): 일정
- x=0.8(0) → ⓐ(4): 증가
- ⓐ(4) → x=1.2(0): 감소
- x=1.2(0) → x=3.8(0): 일정
- x=3.8(0) → ⓑ(4): 증가
- ⓑ(4) → x=4.2(0): 감소
- x=4.2(0) → x=5.8(0): 일정
- x=5.8(0) → ⓒ(4): 증가
- ⓒ(4) → x=6.2(0): 감소
- x=6.2(0) → x=8.8(0): 일정
- x=8.8(0) → ⓓ(4): 증가
- ⓓ(4) → x=9.2(0): 감소
- x=9.2(0) → 끝(0): 일정
- ⓐ: 최고점(4)
- ⓑ: 최고점(4)
- ⓒ: 최고점(4)
- ⓓ: 최고점(4)

- x=4.4(0) → x=5(2): 증가
- x=5(2) → x=5.6(0): 감소
- x=5.6(0) → x=6.7(0): 일정

- x=8.3(0) → 끝(0): 일정

- x=7.5: 최고점(2)
