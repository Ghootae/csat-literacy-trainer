[그래프 읽기 판]
가로축: 시간(t). 세로축: 가격(원).
곡선 위 표시(가로축 왼쪽부터): ⓐ(실시간 추정 순자산가치), ⓑ(시장 가격), ⓒ(실시간 추정 순자산가치), ⓓ(시장 가격), ⓔ(시장 가격).
가로축에 값이 적힌 눈금: t₁, t₂, t₃, t₄, t₅.
시장 가격:
- 시작 → ⓑ: 증가
- ⓑ → 가로축 t₃(ⓒ와 같은 가로 위치): 감소
- 가로축 t₃(ⓒ와 같은 가로 위치) → ⓓ: 증가
- ⓓ → ⓔ: 증가
- ⓔ → 끝: 감소
- ⓑ: 최고점
- 가로축 t₃(ⓒ와 같은 가로 위치): 최저점
- ⓔ: 최고점
실시간 추정 순자산가치(점선):
- 시작 → ⓐ: 증가
- ⓐ → 가로축 t₂(ⓑ와 같은 가로 위치): 감소
- 가로축 t₂(ⓑ와 같은 가로 위치) → ⓒ: 증가
- ⓒ → 가로축 t₅(ⓔ와 같은 가로 위치): 감소
- 가로축 t₅(ⓔ와 같은 가로 위치) → 끝: 증가
- ⓐ: 최고점
- 가로축 t₂(ⓑ와 같은 가로 위치): 최저점
- ⓒ: 최고점
- 가로축 t₅(ⓔ와 같은 가로 위치): 최저점
시장 가격와 실시간 추정 순자산가치는 가로축 t₂에서 만남(접함).
시장 가격와 실시간 추정 순자산가치는 가로축 t₄에서 만남(교차).
시장 가격와 실시간 추정 순자산가치는 가로축 t₅ 이후에서 만남(접함).
