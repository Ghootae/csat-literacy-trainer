[그래프 읽기 판]
가로축: 옥신의 농도(M). 세로축: 생장 반응 정도.
세로축에 기호가 적힌 눈금: +, 0, −.
가로축에 값이 적힌 눈금: M₁, M₂.
ⓐ:
- 시작 → x=18.8: 증가
- x=18.8 → 끝: 감소
- x=18.8: 최고점
- 가로축 M₁에서 가로축(0)을 지남(양→음)
- 가로축 기준 부호: 시작~가로축 M₁ 양(+), 가로축 M₁~끝 음(−)
ⓑ:
- 시작 → 가로축 M₁: 증가
- 가로축 M₁ → 끝: 감소
- 가로축 M₁: 최고점
- 가로축 M₂에서 가로축(0)을 지남(양→음)
- 가로축 기준 부호: 가로축 M₁ 이전~가로축 M₂ 양(+), 가로축 M₂~끝 음(−)
ⓒ:
- 가로축 M₁ → x=48: 증가
- x=48 → 끝: 감소
- x=48: 최고점
- 가로축 M₂ 이후에서 가로축(0)을 지남(양→음)
- 가로축 기준 부호: 가로축 M₁~가로축 M₂ 이후 양(+), 가로축 M₂ 이후~끝 음(−)
ⓐ와 ⓑ는 가로축 M₁ 이전에서 만남(교차).
ⓑ와 ⓒ는 가로축 M₁와 가로축 M₂ 사이에서 만남(교차).
