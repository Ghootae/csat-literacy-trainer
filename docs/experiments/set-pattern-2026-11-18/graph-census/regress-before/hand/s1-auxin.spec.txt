[그래프 읽기 판]
가로축: 옥신의 농도(M). 세로축: 생장 반응 정도.
세로축에 값이 적힌 눈금: 0.
곡선 위 표시(가로축 왼쪽부터): ⓜ(ⓑ, 가로축 위), ⓝ(ⓒ, 가로축 위).
가로축에 값이 적힌 눈금: M₁M, M₂M.
ⓐ:
- 시작(0) → x=18.8: 증가
- x=18.8 → 끝: 감소
- x=18.8: 최고점
- 가로축 M₁M(ⓜ와 같은 가로 위치)에서 가로축(0)을 지남(양→음)
- 가로축 기준 부호: 시작~가로축 M₁M(ⓜ와 같은 가로 위치) 양(+), 가로축 M₁M(ⓜ와 같은 가로 위치)~끝 음(−)
ⓑ:
- 시작(0) → ⓜ: 증가
- ⓜ → 끝: 감소
- ⓜ: 최고점
- 가로축 M₂M(ⓝ와 같은 가로 위치)에서 가로축(0)을 지남(양→음)
- 가로축 기준 부호: ⓜ 이전~가로축 M₂M(ⓝ와 같은 가로 위치) 양(+), 가로축 M₂M(ⓝ와 같은 가로 위치)~끝 음(−)
ⓒ:
- ⓜ(0) → ⓝ: 증가
- ⓝ → x=48: 증가
- x=48 → 끝: 감소
- x=48: 최고점
- 가로축 M₂M 이후에서 가로축(0)을 지남(양→음)
- 가로축 기준 부호: 가로축 M₁M(ⓜ와 같은 가로 위치)~가로축 M₂M 이후 양(+), 가로축 M₂M 이후~끝 음(−)
ⓐ와 ⓑ는 ⓜ 이전에서 만남(교차).
ⓑ와 ⓒ는 가로축 M₁M와 ⓝ 사이에서 만남(교차).
