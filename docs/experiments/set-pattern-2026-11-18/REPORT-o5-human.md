## 1. 개요

**1) 목적.** 세트로 묶기 전에, 아직 우리 지문으로 시험하지 않은 어려운 문제 칸(과학 그래프·표·실험·사례, 사회 관점)이 기출 수준인지 확인하는 것입니다. 수돗물 소독, 혈액 응고, 청약 철회 지문에 문제 12개를 만들고, 같은 갈래 기출 7개와 함께 하나씩 따로 평가했습니다.

**2) 결과.**
- 사회 관점만 통과했습니다. 나머지 과학 칸은 "거의" 또는 "미달"입니다.
- 우리 문제는 대부분 "중"(1점)에 몰렸습니다. 평가자가 가장 자주 지적한 것은 "정답이 지문 한 문장으로 바로 정해진다"와 "〈보기〉 없이도 풀리는 선지가 있다"입니다.
- 과학 실험은 문제 하나(수돗물 B형, 0.25점) 때문에 "바닥 미달"입니다.
- 앞서 멈췄던 그래프 문제 두 개는 읽기 판(그림을 글로 옮긴 설명)을 고쳐서 문제 없이 다시 검사를 통과했습니다.
- 세트 재료로 쓸 만한 문제(1.5점 이상)는 하나뿐입니다(혈액 응고 실험 B형).
- **정정:** 이전 중간 보고에서 "나머지 4실행 비용 약 $2.1"이라고 했는데 틀렸습니다. 실제는 $4.57입니다. 전체 비용은 $8.06으로 상한을 넘었습니다(아래 비용 참고).

**3) 다음 스텝.** 과학 실험의 TW-B-exp(0.25점) 하나만 새로 만들어 칸을 다시 재볼지, 그래프·표의 "거의"를 어떻게 볼지 정해야 합니다(5절).

## 2. 본문

### 2-1. 그래프 문제가 "정답을 못 정한다"로 멈췄던 문제 (해결)
- **어떤 문제가:** 수돗물 그래프 문제 두 개가 "정답이 하나로 안 정해진다"는 검사에 걸렸습니다.
- **과정:** 그림(SVG)에는 정보가 있었는데, 그림을 글로 옮긴 읽기 판이 빠뜨렸습니다. 검사 모델은 읽기 판만 봅니다. 예를 들어 B형은 "㉠: t₀ → t₂ 감소, ㉡: t₀ → t₂ 감소"뿐이라 어느 선이 기준선 P 위에 있는지 알 수 없었습니다. A형에는 내부 좌표 "x=3"이 그대로 찍혀 있었습니다.
- **고친 것:** 읽기 판 만드는 코드만 고쳤습니다. 이제 눈금마다 선의 높이("t₁에서 ㉠은 P보다 아래, ㉡은 P보다 위; 높은 쪽부터 ㉡ > ㉠"), 기준선과 만나는 곳("㉠: t₀~t₁ 사이에서 P 아래로 내려간다"), 표시점의 가로 위치를 적습니다. 그림 코드는 안 건드렸고, 기존 시험 43개에 새 시험 6개를 더해 49개가 모두 통과합니다.
- **결과(해결):** B형은 재검사 통과, A형은 정답 유일성 결함이 사라졌습니다(방식 위반 2건은 남음). 새로 만들 필요가 없었습니다.

### 2-2. 과학 실험 (판단 필요)
- **어떤 문제가:** 수돗물 B형 실험 문제(TW-B-exp)가 평가자 8명 중 6명에게서 "수능 아님"(0점)을 받았습니다.
- **과정:** 평가자 8명 모두 "선지 ⑤가 맞지만 선지 ①도 맞게 읽혀 정답이 둘이 될 수 있다"(정답 시비 위험)고 썼습니다. 생성 단계 검사는 통과시켰는데 평가자와 달랐습니다.
- **결과(미해결):** 같은 지문의 혈액 응고 실험 문제(BL-B-exp)는 1.50점으로 괜찮았습니다. 그래서 칸 평균(0.88)이 낮아지고, 바닥 규칙("수능 아님 4/8 이상인 문제가 하나라도 있으면 미달") 때문에 미달입니다.

| 방안 | 내용 | 비용 |
|---|---|---|
| A. 그대로 미달로 두기 | 규칙대로 | 0 |
| B. TW-B-exp만 새로 만들어 다시 재기 | 정답 유일성 문제를 겨냥해 한 번 더 | 약 $1 |
| C. 실험 문제를 더 만들어 평균을 다시 보기 | 표본 2개는 적음 | 약 $3 |
추천: B. 칸 판정이 문항 하나에 크게 좌우되므로 표본을 늘리기 전에 이 문제가 우연인지 확인하는 게 싸고 빠릅니다.

### 2-3. 과학 그래프·표 "거의" (판단 필요)
- **어떤 문제가:** 예전에는 기출 지문에서 통과·확정이었는데 우리 지문에서는 "거의"입니다.
- **과정:** 그래프 M(기출 평균)은 열팽창 기출이 2.00점이라 1.58로 올랐고, 표 M은 약물·오디오 기출이 2.00점이라 1.69입니다. 우리 문제는 모두 1.0~1.1 근처입니다.
- **결과(판단 필요):** 기출 앵커가 같은 칸 안에서 0.00~2.00으로 크게 퍼져서, M이 어떤 앵커를 고르느냐에 크게 흔들립니다. 그래프 읽기 판은 "가로축 위"가 "축선 위 vs 축 위쪽"으로 헷갈린다는 지적과, 그림에서 ㉠ 표시가 가로축 제목과 겹친다는 지적이 있습니다(이번 수정 범위 밖).

### 2-4. 과학 사례·사회 관점
- **과학 사례(거의):** 혈액 응고 사례 문제 1개, 1.00점. 고체 촉매 6개와 합친 7개 평균은 1.02입니다. 기출 평균 1.44보다 0.44 낮아 "거의" 경계(0.4)를 막 넘었습니다.
- **사회 관점(통과):** 청약 철회 관점 문제 2개 평균 0.94, 기출 1.00과 0.06 차이입니다.
- **덤(사회 사례):** 청약 철회 사례 2개 모두 1.00. 참고용입니다.
