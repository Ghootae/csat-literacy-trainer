가장 수능다운 문항은 **1번**, 가장 못한 문항은 **2번**이다.  
1번은 두 주문과 실제 배송 결과를 읽고 → 형체·색을 부르는 명의 용법에 대응시키고 → ㉡의 색만 바뀌면 주문별 대체 가능성이 달라진다고 스스로 판단해야 한다.  
특히 실제로 같은 견본을 받았다고 해서 두 주문의 지시 범위까지 같아지는 것은 아니라는 구별이 필요하다.  
2번은 금이 간 탈의 이동을 추적하고 → ‘마루’와 ‘다래’가 한 실을 지시함을 파악하는 과정이 가능하지만, 정작 ②가 ‘나래’와 ‘나래’로 쓰여 그 과정을 거치지 않아도 틀린 선지로 드러난다. 이 표기 결함은 제시된 ㉮~㉴에 직접 해당하지 않아 결함 칸은 비웠다.
