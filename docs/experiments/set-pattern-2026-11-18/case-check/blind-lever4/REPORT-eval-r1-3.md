가장 수능다운 문항은 **2번**, 가장 못한 문항은 **1번**이다.  
2번은 주문 내용과 실제 배송 결과를 읽고 → 지문의 형체·색 및 명의 용법 구분에 대응시키고 → ㉡이 푸른 네모판으로 바뀌면 갑의 주문에는 부합하지만 을의 주문에는 부합하지 않는다고 판단해야 한다.  
실제 선택 결과가 같아도 두 주문의 허용 범위는 다를 수 있다는 관계를 학생이 스스로 밝혀야 한다.  
1번은 탈의 이동과 명의 사용을 읽고 → ‘마루’와 ‘다래’가 같은 실을 지시함을 확인하고 → 별개의 탈을 지시하는 ‘나래’의 대응에는 변화가 없다고 판단하면 된다.
