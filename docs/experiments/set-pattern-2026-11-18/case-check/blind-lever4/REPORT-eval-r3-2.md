가장 수능다운 문항은 **3번**, 가장 못한 문항은 **1번**이다.  
3번은 주문표와 실제 배송을 읽고 → 색·형체에 따른 명의 구분과 요청 가능한 대상의 차이에 대응시키고 → ㉡의 색만 바뀌면 두 주문의 대체 가능성이 달라지는지 스스로 판단해야 한다.  
특히 실제로 같은 견본을 받았다는 사실만으로 두 주문의 요구 범위까지 같다고 볼 수 없음을 가려야 한다.
