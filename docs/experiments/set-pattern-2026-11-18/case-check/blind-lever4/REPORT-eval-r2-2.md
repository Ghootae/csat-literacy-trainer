가장 수능다운 문항은 **4번**, 가장 못한 문항은 **2번**이다.  
4번은 갑의 해명까지 읽고 → ⓐ는 빨간 옷, ⓑ는 들고 있는 한 벌, ⓓ는 옷 일반에 대응시키고 → ⓓ와 ⓔ가 같은 대상을 지시한다는 ④의 전제가 틀렸다고 판단해야 한다.  
이 과정에서 학생이 발화의 지시 범위를 복원하고, 같은 명의 여러 대상 지시와 특정 속성의 추가를 구분해야 한다.  
2번은 탈의 이동을 읽고 → 왼쪽 탈에는 ‘마루·다래’, 오른쪽 탈에는 ‘나래’를 대응시키고 → 오른쪽 탈의 명실 대응에는 변화가 없다고 판단하면 된다.
