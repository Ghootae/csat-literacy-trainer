4번은 갑의 해명과 을의 반문을 읽고 → ⓐ는 필요한 빨간 옷, ⓑ는 손에 든 한 벌, ⓓ는 일반적인 옷에 대응시켜야 한다.  
이를 지문의 명·실 대응과 유명·사명 개념에 연결한 뒤 → ⓓ와 ⓔ의 지시 대상이 같다는 ④의 전제가 틀렸음을 학생이 판단해야 한다.  
1번은 탈의 이동을 읽고 → ‘마루’와 ‘다래’가 같은 실을 지시함을 파악하는 과정이 가능하지만, 실제 ②는 ‘나래’와 ‘나래’를 비교하므로 그 과정을 거치지 않아도 문구 오류로 배제할 수 있다.
