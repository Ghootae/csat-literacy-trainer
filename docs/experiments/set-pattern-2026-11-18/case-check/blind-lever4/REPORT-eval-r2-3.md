가장 수능다운 문항은 **1번**, 가장 못한 문항은 **3번**이다.  
1번은 주문표·배송·발화를 구분해 읽고 → 색과 형체에 따른 명의 지시 범위에 대응시켜야 한다.  
이어 ㉡의 색이 바뀌면 두 주문에서 대체 가능성이 어떻게 갈리는지 학생이 직접 판단해야 한다.
