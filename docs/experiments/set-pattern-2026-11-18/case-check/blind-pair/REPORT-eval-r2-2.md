가장 수능다운 문항은 **2번**, 가장 못한 문항은 **4번**이다.  
2번은 갑의 해명과 을의 반응을 읽고 → ‘옷’의 문맥별 지시 대상을 명실 관계에 대응시키고 → ⓓ는 일반적인 옷, ⓔ는 빨간 옷을 가리키므로 같은 대상이 아니라고 판단해야 한다.  
또한 ⓑ는 특정한 한 벌을 가리킨다는 점을 따로 파악하여, 같은 단어도 사명으로 쓰일 수 있음을 적용해야 한다.
