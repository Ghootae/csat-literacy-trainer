|문항|답|판정|이유|결함|그래프 평|
|---|---|---|---|---|---|
|1|④|수능 같음|대화 속 ‘옷’의 실제 지시 대상을 구분하고, 명·실의 대응과 유명·사명을 각각 적용해야 한다.|||
|2|②|수능 같음|화면과 일지에서 ‘등잔’의 지시 범위가 달라짐을 파악해, 같은 단어도 유명과 사명으로 달리 쓰임을 판단해야 한다.|||
|3|②|중|섬 배치를 복원해야 하지만, ④가 두 명이 한 실을 가리킨다는 핵심 관계를 밝혀 정답 판단을 상당 부분 돕는다.|||
|4|②|중|표식으로 대상의 동일성을 확인하고 이름의 중복을 찾으면 풀려, 3점 문항으로서 개념 적용의 깊이가 얕다.|||

가장 수능다운 문항은 **1번**, 가장 못한 문항은 **3번**이다.  
1번은 갑의 해명을 읽고 → ⓐ는 빨간 옷, ⓑ는 손에 든 한 벌, ⓓ는 옷 일반에 대응시켜 → 동일한 표현의 지시 대상과 명·실 관계를 스스로 구분해야 한다.  
특히 ④에서는 ⓓ와 ⓔ가 같은 대상을 지시한다는 선지의 전제부터 틀렸음을 판단해야 한다.  
3번은 위치와 명명 순서를 읽고 → ㉡에 ‘별’과 ‘달’이 겹침을 일대일 대응 원칙에 연결하면 되는데 → 그 핵심 관계를 ④가 이미 명시하여 독립적으로 추론할 몫이 줄어든다.
