가장 수능다운 문항은 **2번**, 가장 못한 문항은 **1번**이다.  
2번은 갑의 해명을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷 한 벌, ⓓ는 일반적인 옷을 지시함을 복원하고 → 명의 지시 범위와 유명·사명 개념에 대응시켜야 한다.  
그 뒤 학생이 직접 ⓓ와 ⓔ의 대상이 같지 않음을 판단해야 하므로, 같은 단어의 반복에 끌리는 오독을 개념 적용으로 바로잡게 한다.
