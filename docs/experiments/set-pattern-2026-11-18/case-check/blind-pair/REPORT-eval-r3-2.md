가장 수능다운 문항은 **1번**, 가장 못한 문항은 **3번**이다.  
1번은 갑의 해명까지 읽고 → ⓐ는 빨간 옷, ⓓ는 옷 일반을 가리킨다고 복원하고 → 명의 동일성과 지시 대상의 동일성을 구별해야 한다.  
이를 두 학파의 명실 관계에 대응시켜 → ⓓ와 ⓔ의 대상이 같다는 ④의 전제가 잘못되었다고 스스로 판단한다.  
3번은 사진을 넣은 위치와 명명 순서를 읽고 → ‘별’과 ‘달’이 모두 ㉡을 가리킨다고 복원하고 → 공손룡의 일대일 대응에 어긋난다고 판단한다.  
3번은 배치 추적이 풀이 부담의 큰 부분을 차지하여, 그 부담이 명실 관계를 깊이 이해하는 판단으로 충분히 이어지지 않는다.
