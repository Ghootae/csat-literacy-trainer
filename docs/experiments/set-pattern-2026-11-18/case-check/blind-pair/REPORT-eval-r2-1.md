2번은 대화의 해명을 읽고 → ⓐ의 ‘필요한 빨간 옷’, ⓑ의 ‘들고 있는 한 벌’, ⓓ의 ‘옷 일반’을 구별하고 → 각각을 명실 대응과 유명·사명 개념에 대응시켜야 한다.  
그 뒤 학생이 직접 ⓓ와 ⓔ의 지시 대상이 같다는 ④의 전제를 부정해야 하므로, 문맥 해석이 철학적 판단으로 이어진다.
