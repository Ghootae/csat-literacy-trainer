4번은 화면과 일지를 읽고 → 각각의 ‘등잔’을 지문 마지막 문단의 유명·사명 구분에 대응시키고 → 같은 단어라도 지시 대상의 수에 따라 분류가 달라짐을 스스로 판단해야 한다.  
특히 화면에서 확인한 ‘등잔’의 분류를 일지에도 그대로 적용하면 ②의 오류를 놓치므로, 문맥을 바꾸어 개념을 적용하는 능력을 묻는다.
