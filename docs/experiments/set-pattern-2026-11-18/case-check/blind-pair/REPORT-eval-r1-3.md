가장 수능다운 문항은 **1번**, 가장 못한 문항은 **3번**이다.  
1번은 갑의 첫 발언과 해명을 읽고 → ⓐ·ⓓ·ⓔ의 지시 범위를 각각 복원하고 → 공손룡과 후기 묵가의 명실 관계에 대응시켜야 한다.  
특히 같은 ‘옷’이라는 표현도 지시 대상이 달라질 수 있음을 파악하고, ④의 ‘같은 대상’이라는 전제를 학생이 직접 검증해야 한다.  
3번은 ◇ 접시는 ‘별’, ○ 접시는 ‘달’이라는 기록을 읽고 → ‘달’을 ‘별’로 바꾸면 한 명이 두 실을 지시한다고 대응시키고 → 일대일 원칙 위반이라고 판단하면 된다.  
3번에도 적용은 있지만, 정답을 가르는 과정이 한 원칙의 단순 적용으로 끝나므로 1번보다 추론의 층위가 얕다.
