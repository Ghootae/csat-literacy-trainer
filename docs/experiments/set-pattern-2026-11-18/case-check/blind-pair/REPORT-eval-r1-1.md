| 문항 | 답 | 판정 | 이유 | 결함 | 그래프 평 |
|---|---|---|---|---|---|
| 1 | ④ | 수능 같음 | 대화의 해명을 통해 같은 ‘옷’의 지시 대상을 구분하고 두 학파의 관점을 적용해야 하므로, 개념 이해와 맥락 해석이 함께 요구된다. | | |

| 3 | ② | 중 | 명칭을 바꾼 뒤 지시 대상이 충돌하는지 판단하게 하지만, 나머지 선지는 명시된 사실에 개념을 대응하는 수준이어서 추론의 깊이가 얕다. | | |
| 4 | ② | 수능 같음 | 화면과 일지에서 ‘등잔’이 지시하는 범위를 따로 파악해야 하므로, 같은 명도 사용 상황에 따라 유명과 사명이 달라짐을 적용하게 한다. | | |

가장 수능다운 문항은 **1번**, 가장 못한 문항은 **2번**이다.  
1번은 갑의 해명을 읽고 → ⓐ·ⓔ는 빨간 옷, ⓓ는 특정 색을 한정하지 않은 옷에 대응시킨 뒤 → ④의 ‘같은 대상’이라는 전제가 틀렸음을 스스로 판단해야 한다.  
이 과정에서 학생은 대화 속 지시 대상을 먼저 확정하고, 이를 공손룡의 명·실 대응 원칙과 연결해야 한다.  
2번은 위치와 명명 순서를 읽고 → ㉡에 ‘별’과 ‘달’이 함께 붙었음을 복원한 뒤 → 일대일 대응 위반을 판단한다. 개념 적용에 앞선 배치 해독의 비중이 커서, 철학적 이해를 평가하는 힘은 상대적으로 약하다.
