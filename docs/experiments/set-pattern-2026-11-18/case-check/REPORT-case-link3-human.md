# 결합 선지 탐색 3판 — 사람용 요약
1. 두 원리를 억지로 엮게 하고(결합 의무), 헷갈림 이유·짝 양쪽 근거·판정 이름 금지·전제 보존 가드를 더해 청약 A형을 두 번 만들고 같은 블라인드에서 3회 비교했습니다.
2. 새 평균 0.96은 지난 link(0.75)보다 +0.21, 옛 청약(1.54)보다 −0.58입니다. 미리 정한 기준(+0.4, 옛 이상)에 못 미쳐 "효과 있음 아님", 종합은 "채택 안 함 → A형은 옛 순서로 닫음"입니다.
3. 좋아진 점: 정답 시비(㉳)와 사건 나열(㉱)이 두 문항 모두 0이 됐습니다. 〈보기〉가 이어진 사건이 되고 근거가 확실해졌다는 뜻입니다.
4. 안 된 점: 두 원리를 함께 써야 풀리게 하려 했지만 codex 평가자는 둘 다 지문 규칙 1개로 풀었고 〈보기〉만으로 반박했습니다(결합 실현 0/2). 정답이 "포장인가 부품인가"를 가르는 쉬운 문제로 남았고 블라인드는 "중"(1점)에 몰렸습니다.
5. 참고: 〈보기〉 첫 문장에 "방문판매로"가 또 들어갔습니다(labels에 안 적혀 서버가 못 봄). link3b는 첫 시도가 연결 오류로 끊겨 한 번 다시 돌렸습니다. 비용 $1.15. 이 경로의 마지막 시험이라는 약속대로 판단은 Ghootae 몫입니다.
