# 생성 A형 재확인 + 단계 수 — 쉬운 설명 (2026-11-27)

**가(생성 A형 위치)**: 생성 A형이 보통 기출 수준 (A형 칸 통과로 볼 수 있음) — 생성 6개 평균 1.146, 보통 기출 3개 1.000, 상위 기출 3개 1.875. 지문별 생성 최고점 3개 평균 1.333도 같은 판정. (기출 흔들림 기준에는 걸리지 않아 보류 없음: 6개 중 0.5 넘게 달라진 것 0개, 건축만 2.0→1.625.)
**나(단계 수)**: 약한 관계 (전체 20문항 ρ +0.229). "보기+결합 단계 수"는 단계 수로 설명 안 됨 (ρ +0.133).

## 무엇을 봤나
- (가) 생성 A형 6개를 기출 A형(상위 3: 공손룡·공시·건축 / 보통 3: 과징금·상계·집합건물)과 한 형식(문항 하나씩 단독, 출처 가림)으로 평가자 4명 × 2회차가 매겼다. 기출 점수는 예전과 거의 같아(공손룡·공시 2.0, 과징금·상계·집합건물 1.0) 잣대는 안정적이었다.
- (나) 따로 연 새 세션에서 "정답 선지를 확정하는 데 꼭 필요한 판단이 몇 단계인가"를 20문항 × 2회 세어 점수와 비교했다.

## 결과
- 생성 중 높은 것은 공손룡 옛 A(1.875)뿐이고 상위 기출 수준이다. 나머지는 1.0 안팎: 청약 1.0, 1.0, 도덕 1.0, 1.125, 0.875. 도덕 o4regen(0.875)은 정답이 지문 마지막 문장을 뒤집은 것이라 〈보기〉를 안 봐도 풀린다는 평(㉯·㉲)이 대부분이다.
- 생성 A 평균이 보통 기출과 비슷하다는 말이다. 상위 기출(2.0)에 닿는 문항은 공손룡 하나다.
- 웹 예측("보통 기출 수준")은 맞았다.

## 단계 수가 말해 주는 것
- 단계가 적을수록 낮은 점수가 나오는 경향은 약하게 있다: 단계 1짜리(도덕 o4regen, 선거공보, 재판매는 단계 1~2, 〈보기〉 없이 풀림 noBogi)는 모두 0.875~1.0이다. 하지만 청약 두 문항은 단계가 5~6으로 많은데도 점수가 1.0이다. 그래서 전체로는 약한 관계(ρ +0.229)다.
- 기출 14개만 보면 ρ +0.525(단계 수), +0.416(보기+결합)으로 더 뚜렷하다. 즉 기출에서는 단계가 많을수록 높게 보지만, 생성 문항에는 단계가 많아도 높게 안 보는 것들이 있다. 단계를 늘리는 것만으로는 부족하다는 뜻이다(평가자 이유로 보면 "한 문장 대입" 인상, ㉯·㉲).
- 웹 예측 중 "약한 관계 이상"은 맞았고, "보기+결합 쪽 ρ가 더 높을 것"은 맞지 않았다(전체 +0.133 < +0.229).
