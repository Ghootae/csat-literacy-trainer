2번은 대화의 오해와 해명을 읽고 → ⓐ·ⓔ의 빨간 옷, ⓑ의 특정 옷, ⓒ·ⓓ의 옷 일반을 구별하고 → 공손룡의 일대일 대응과 후기 묵가의 유명·사명에 대응시켜야 한다.
