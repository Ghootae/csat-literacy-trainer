# 선별기 무료 검증 — 사람용 요약
1. 블라인드에서 이미 점수가 나온 8문항에 검사 3종(정답 헷갈림, 참 선지 근거, 지름길)을 codex로 돌렸습니다. 비용은 0원입니다.
2. 미리 정한 판정은 "선별기로 쓰기 어려움"입니다. 블라인드 1.5 이상 문항(공손룡 기출 선별 1.00)이 1.0 미만 문항(link1 2.00, A안 청약 3.00)보다 낮게 나와 "가름"이 불성립했습니다.
3. link1의 ① 시비는 두 평가자 모두 짚었습니다. 다만 link2의 "판단 단순"은 짚지 못했습니다(헷갈림 "강", 지문 규칙 필요로 판정).
4. 점수와 블라인드 순위의 Spearman은 −0.43으로 반대 방향입니다. 두 평가자가 모든 항목에서 똑같이 답해 평가자 잡음은 알 수 없습니다.
5. 이 검사 구성으로는 "후보 여러 개 만들고 고르기"의 선별기로 쓰기 어렵습니다. 다음 방향은 Ghootae 판단입니다.
