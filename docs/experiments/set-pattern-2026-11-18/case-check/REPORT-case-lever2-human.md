# 갈림 사실 순서 보완 — 사람용 요약
1. 지난번 A형(적절하지 않은 것) 문항이 옛 판과 같은 착각을 정답으로 다시 낸 문제를 고쳤습니다. 사례 버전에는 예전 "정답 후보" 재료를 아예 주지 않고, 〈보기〉의 헷갈리는 짝에 이름(pair)을 붙여 정답이 그 짝을 쓰는지 서버가 확인합니다.
2. A형만 다시 만들었더니 서버 확인은 한 번에 통과했고, 새 정답은 "눈을 다친 두 사람의 부상 경위를 섞은 것"으로 옛·지난번 정답(손실이 회복되면 해명 근거가 없다)과 다른 착각입니다.
3. 블라인드 3회: 새 A는 0.83(지난번) → 1.42, "정답이 지문 한 문장" 표시는 12/12 → 0/12. 칸 평균은 새 칸 1.54, 옛 칸 0.63으로 +0.92라 기준(1.5 이상, +0.5)을 3회 합으로는 넘었습니다. 다만 r3에서는 1.375입니다.
4. 조심할 점: 새 칸은 문항 2개(새 A 1개 + 지난번 B 1개)이고, 옛 판이 이번 블라인드에서 지난번보다 낮게 나와(1.04 → 0.63) 차이가 부풀었을 수 있습니다.
5. 비용 약 $0.54(상한 $2 이내). 판정은 웹 몫입니다.
