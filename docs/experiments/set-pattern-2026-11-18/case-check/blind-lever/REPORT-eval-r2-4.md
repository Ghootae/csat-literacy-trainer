가장 수능다운 문항은 **4번**, 가장 못한 문항은 **1번**이다.  
4번은 대화의 정정 내용을 읽고 → ⓐ·ⓔ는 빨간 옷, ⓑ는 특정 한 벌, ⓒ·ⓓ는 옷 일반에 대응시켜야 한다.  
이어 지시 대상의 동일성과 명의 사용 관계를 지문의 개념에 연결하여 → ④가 ⓓ와 ⓔ를 같은 대상으로 잘못 묶었다고 스스로 판단해야 한다.  
1번은 ③의 가정을 읽고 → 지문의 ‘손실이 회복되어도 해명 요구의 근거가 남는다’에 대응시키면 끝나므로, 보기의 인과관계와 의무 범위를 판별하는 단계를 건너뛰어 정답을 고를 수 있다.
