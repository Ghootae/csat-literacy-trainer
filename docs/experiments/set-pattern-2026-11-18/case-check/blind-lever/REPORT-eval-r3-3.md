가장 수능다운 문항은 **5번**, 가장 못한 문항은 **3번**이다.  
5번은 갑의 해명과 을의 반응을 읽고 → ⓐ는 빨간 옷, ⓓ는 옷 일반을 가리킨다고 복원하고 → 두 표현이 같은 대상을 지시하는지 스스로 판단해야 한다.  
또한 ⓑ의 특정 개체 지시를 사명에, ⓒ와 ⓔ의 관계를 속성의 추가에 대응시켜 선지별 해석을 검증해야 한다.  
3번은 을의 부상과 보상 사실을 읽고 → 피해 회복과 해명 요구의 구별에 대응시키면 → 지문에 명시된 결론을 뒤집은 ③을 바로 고를 수 있어, 다른 사례 조건을 충분히 활용하지 않아도 풀린다.
