가장 수능다운 문항은 **5번**, 가장 못한 문항은 **3번**이다.  
5번은 대화의 정정과 지시 표현을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷, ⓓ는 옷 일반에 대응시켜야 한다.  
이어서 이를 명실 대응과 유명·사명 개념에 연결하고 → ⓓ와 ⓔ가 같은 대상을 지시한다는 ④의 전제를 학생이 직접 부정해야 한다.  
3번은 ③을 읽고 → 지문의 ‘손실이 회복되어도 해명을 요구할 근거가 남는다’에 대응시키면 → 곧바로 부적절하다고 판단할 수 있어, 다른 피해들의 원인과 보호 범위를 구별하는 풀이가 필요하지 않다.
