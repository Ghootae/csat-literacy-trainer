가장 수능다운 문항은 **3번**, 가장 못한 문항은 **1번**이다.  
3번은 갑의 해명과 을의 반응을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷, ⓒ·ⓓ는 일반적인 옷에 대응시킨 뒤 → 각 표현의 지시 관계를 스스로 확정해야 한다.  
이후 공손룡의 일대일 대응과 후기 묵가의 유명·사명 개념을 적용해 → ⓓ와 ⓔ가 같은 대상을 지시한다는 ④의 전제가 틀렸음을 판단한다.  
1번은 접수 당시 이미 얼룩이 있었다는 사실을 읽고 → 방치한 위험이 실제로 일으킨 피해만 추가 비난한다는 조건에 대응시키면 → 최초 얼룩의 발생은 갑의 책임이 아니라는 ①이 쉽게 정해지며, 얼룩이 번지는 과정까지 분석할 필요가 작다.
