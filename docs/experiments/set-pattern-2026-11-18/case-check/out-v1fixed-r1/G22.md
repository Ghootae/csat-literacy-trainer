- A: 수요량 증가분 0.4Q, 공급량 감소분 0.2Q → 부족량 0.6Q
- B: 수요량 증가분 0.2Q, 공급량 감소분 0.6Q → 부족량 0.8Q

① **참 / fact_sensitive: true**  
두 번째 B의 상한 가격은 균형 가격보다 높으므로, 시장 가격은 1,000원에서 상승을 멈춘다.  
바꾼 사실 → 두 번째 B의 상한 가격을 800원으로 바꾸면 상한에 닿아 상승을 멈추므로 **거짓**이 된다.

② **참 / fact_sensitive: true**  
첫 적용 A의 수요량 증가분 0.4Q는 B의 공급량 감소분 0.6Q보다 적다.  
바꾼 사실 → 첫 적용 B의 공급 탄력성을 1로 바꾸면 공급량 감소분이 0.2Q가 되어 **거짓**이 된다.

③ **거짓 / fact_sensitive: true**  
A의 수요량 증가분은 더 크지만, 부족량은 A가 0.6Q, B가 0.8Q이므로 A가 더 작다.  
바꾼 사실 → 첫 적용 B의 공급 탄력성을 1로 바꾸면 B의 부족량이 0.4Q가 되어 **참**이 된다.

④ **참 / fact_sensitive: true**  
A의 두 번째 거래량은 Q이고, 첫 적용의 수요량은 1.4Q이므로 전자가 더 적다.  
바꾼 사실 → 첫 적용 A의 상한 가격을 1,200원으로 바꾸면 첫 적용 수요량도 Q가 되어 **거짓**이 된다.

⑤ **참 / fact_sensitive: true**  
첫 적용에서는 두 시장 모두 상한에서 초과 수요가 남지만, 두 번째에는 균형 가격에 도달하여 초과 수요가 사라진다.
