# A형 전제형 시험 — 사람용 요약
1. A형(적절하지 않은 것)을 "〈보기〉 관계 + ~이므로 + 판정" 모양으로 만드는 CASE_FLOW=premise를 켤 때만 도는 스위치로 넣고, 청약 철회·공손룡에서 한 번씩 만들었습니다.
2. 서버 확인(L8 포함)은 둘 다 처음에 통과했고 수리 뒤 위반은 없었습니다.
3. 청약은 전제형 1.42 대 옛 1.33으로 차이 없음, 공손룡은 전제형 1.00 대 옛 2.00으로 옛 순서 나음입니다(기출 둘 다 2.0, 블라인드 유효).
4. 미리 정한 종합 판정은 "채택 안 함"입니다. 비용 $1.58, 판단은 Ghootae 몫입니다.
