# A안(짝 카드 3판) — 사람용 요약
1. 짝 카드에 "맥락을 정하는 〈보기〉 사실(decider)"을 더한 A안을, 옛 A형 점수가 낮았던 두 지문(청약 철회, 도덕적 운)에서 한 번씩 만들어 같은 블라인드에서 옛 판 두 개씩과 3회 비교했습니다.
2. 도덕적 운은 A안 1.83 대 옛 평균 0.88로 +0.96(A안 나음, 세 회차 모두)입니다.
3. 청약 철회는 A안 0.75 대 옛 평균 1.46으로 −0.71(옛 나음)입니다.
4. 미리 정한 종합 판정은 한 지문이 "옛 나음"이라 "채택 안 함(A형은 옛 순서로 닫음)"입니다. 같은 지문의 옛 판 두 개도 서로 0.4~0.75 차이가 나서 잡음이 큽니다.
5. 비용 $1.43(상한 $3 이내). 판단은 Ghootae 몫입니다.
