# 연결 원리 탐색 질의 검토 기록

## 기존 측정

입력은 같은 부정 발문의 A형 두 문항이다. pair3 블라인드는 평가자 4명 × 3회, 0~2점 척도다. 평균은 도덕적 운 1.833, 청약 0.750, 옛 청약 두 문항은 1.083과 1.833, 기출 둘은 각각 2.000이다. A안 두 문항의 정답 일치는 각각 12/12였다. 사건 나열은 질의서의 보고가 11/12다. 정답 시비에 대한 독해 검토는 표 수와 별개다. 이번 회신은 저장된 자료의 검토이며 새 생성·평가는 수행하지 않았다.

## 해석과 실행 전 제안

1. 우산 장면 삭제 뒤에도 물통 정답이 유지된다. 나열의 직접 증거다. 단일 원리 선택이 그 원인인지는 식별되지 않는다. 같은 지문의 기존 고득점 문항을 통제로 재사용한다.
2. L10b의 hooks 자기보고를 합격 근거로 쓰지 않는다. 핵심 선지의 사실·적용 원리·결론에 대해 단일 사실 교체 전후의 실제 판단을 적는다.
3. 판정 결합은 핵심 선지에서 확인한다. 열흘째 포장만 훼손한 유인 방문판매에서 구매 과정을 바꾸거나, 훼손 대상을 바꾸면 각각 철회 가능성이 뒤집힌다. 제안 원안처럼 기능 부품이 이미 훼손된 경우 기간 판단이 무력화된다.
4. 한 사건의 복수 당사자는 허용한다. 짝 하나를 기본으로 두고 둘째 짝에는 참 선지 역할과 단독 오독 시의 판정 근거를 확인한다.
5. 이번에는 자동 복원 없이 최종 거짓 전제의 명시·암시·소실을 원문으로 기록한다. Dice는 보조 지표다. 정답 타당성은 별도 검토한다.
6. 블라인드 유효 조건과 기존 문턱을 후보 선별용으로 유지한다. 통과해도 한 지문 두 생성이다. 둘의 결합 성공 여부를 개별 보고한다. 새 평균과 재평가한 옛 평균·A안의 차이, 회차별 변동을 함께 기록한다.
7. 대안은 핵심 선지 초안 두 개의 최소 사실 변경 대조다. 단일 사건 지시만 켠 조건이 있어야 원리 탐색의 추가 기여를 비교할 수 있다.
8. 도덕적 운 ③은 기존 얼룩의 발생 귀속으로 읽으면 거짓이다. 미보호에 관한 항의는 성립한다. ⑤의 실제 지출과 부담 의무를 분리한다. 구체 수정문은 인간 보고서 Q8에 있다.
