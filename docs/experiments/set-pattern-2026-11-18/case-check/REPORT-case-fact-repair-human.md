# 사례 칸 재시험 — 사람용 요약
1. 검사기에 "〈보기〉 사실을 바꾸면 정오가 뒤집히나?"(M6)를 넣었고 시험 18개가 모두 통과했습니다.
2. 고체 촉매 사례: M6은 B 두 문항에서 걸렸고, 수리 뒤 평균이 0.84 → 1.375로 올랐습니다(이전 1.094). 하지만 기준 1.5에는 아직 못 미칩니다.
3. 도덕적 운 사례는 M6이 하나도 안 걸렸고(검사기는 모두 "사실에 달림"으로 봄) 평균은 그대로 0.688입니다. 평가자들은 "정답이 지문 문장을 그대로 뒤집은 것", "오답 일부는 사례 없이 지워짐"을 이유로 들었습니다. 검사기와 평가자의 판단이 어긋난 곳입니다.
4. 자격 기출은 네 회차 모두 2.0이라 평가 자체는 믿을 만합니다.
5. 비용은 약 $1.2 추정(상한 $3 이내), 판정은 웹 몫입니다.
