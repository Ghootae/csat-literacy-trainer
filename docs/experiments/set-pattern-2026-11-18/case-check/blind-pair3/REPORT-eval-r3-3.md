|8|③|수능 같음|접수 전후의 얼룩을 비교해 의무 위반으로 생긴 피해를 가려내고, 비용 지급과 해명 요구의 근거를 구별해야 한다.|||
|9|③|수능 같음|부상의 원인과 보호 의무의 범위를 각각 확인한 뒤, 결과에 대한 비난과 손실 회복 후의 해명 요구를 판단해야 한다.|||

가장 수능다운 문항은 **6번**, 가장 못한 문항은 **1번**이다.  
6번은 대화의 오해와 정정을 읽고 → 각 ‘옷’이 가리키는 대상을 복원하고 → 명실의 대응 관계와 유명·사명 개념에 연결해야 한다.  
이어 학생이 ⓓ와 ⓔ의 지시 대상이 실제로 같은지 판단해야 하므로, 개념 적용에 앞서 사례 자체를 해석하는 단계가 필요하다.  
1번은 ③을 읽고 → ‘손실이 회복되어도 직접 해명을 요구할 근거가 있다’는 문장에 대응하면 → 곧바로 부적절하다고 판단할 수 있어, 물·안경·병의 사고를 분석할 필요가 없다.
