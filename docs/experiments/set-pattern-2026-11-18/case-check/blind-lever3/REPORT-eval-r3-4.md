가장 수능다운 문항은 **2번**, 가장 못한 문항은 **4번**이다.  
2번은 가지형·직선형 사슬의 배열 가능성을 읽고 → 지문의 결정 영역에 대응시키고 → 결정 영역의 비율에 따른 물성을 추론해 → 화학 물질과 접촉하는 용기에 적합한 소재를 스스로 선택한다.  
4번은 작은 입자가 합쳐졌다는 관찰을 읽고 → 소결과 전체 표면적 감소에 대응시키고 → 개별 입자의 표면적 증가와 전체 표면적 감소가 양립한다고 판단한다.
