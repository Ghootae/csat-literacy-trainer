가장 수능다운 문항은 **3번**, 가장 못한 문항은 **2번**이다.  
3번은 가지형·직선형 사슬의 배열 가능성을 읽고 → 지문의 ‘결정 영역’에 대응시키고 → 결정 영역의 비율에 따른 물성 차이를 도출해야 한다.  
그다음 화학 물질과 접촉하는 용기에 필요한 성질을 스스로 판단하여 ③을 고른다. 〈보기〉가 용도 적합성까지 알려 주지는 않는다.  
2번은 적정 범위와 측정값을 읽고 → 8은 과도한 흡착, 4는 적정 흡착에 대응시키면 → 곧바로 ⑤가 정해진다.
