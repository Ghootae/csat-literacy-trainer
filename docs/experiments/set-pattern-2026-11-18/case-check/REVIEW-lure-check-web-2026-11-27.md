2. 그러니 "칸 평균 ≥1.5" 기준은 **기출 A형 스스로도 대부분 못 넘는 기준**이다. 앞서 쓴 자격 기출(공시 12·공손룡 12, 둘 다 2.0)은 A형 중 높은 쪽만 고른 셈이었다.
3. 생성 문항 위치: link3 원본 1.0 = 기출 A형 하위 무리(과징금·상계·선거공보·재판매·공유물·집합건물 모두 1.0)와 같음. 앞 시험의 A형 옛 순서 1.54는 기출 A형 평균(1.27)보다 높다.
4. 미끼(N형) 갈래 자체는 점수를 올리지 않는다 → "decider가 미끼를 지웠다" 가설은 이 잣대로 지지 안 됨. decider는 이 지문에선 필수(지문이 기준을 정의하지 않으므로).
