가장 수능다운 문항은 **4번**, 가장 못한 문항은 **3번**이다.  
4번은 가지형·직선형 사슬의 배열 가능성을 읽고 → 지문의 결정 영역 개념에 대응시켜 그 비율을 비교하고 → 화학 물질과 접촉하는 용기에 적합한 소재를 스스로 판단해야 한다.  
〈보기〉는 배열의 차이를 제공하지만, 결정 영역의 비율과 용도 적합성까지 대신 판정하지는 않는다.
