가장 수능다운 문항은 **3번**, 가장 못한 문항은 **4번**이다.  
3번은 가지형·직선형 사슬의 배열 가능성을 읽고 → 지문의 ‘결정 영역’에 대응시키고 → 결정 영역이 많은 소재의 화학 물질 민감성이 낮다는 점에서 용기의 적합성을 판단해야 한다.  
이때 〈보기〉가 직접 말하지 않은 결정 영역의 상대적 비율을 학생이 먼저 추론해야 한다.  
4번은 초기 8·후반 4와 적정 범위 3~5를 읽고 → 강한 흡착·적절한 흡착에 대응시키면 → 곧바로 ⑤를 고를 수 있어, 나머지 관찰을 연결하는 풀이가 필요하지 않다.
