가장 수능다운 문항은 **3번**, 가장 못한 문항은 **4번**이다.  
3번은 사슬의 배열 가능성을 읽고 → 지문의 ‘결정 영역’에 대응시키고 → 결정 영역의 비율에 따른 물성을 추론해야 한다.  
이어 화학 물질이 닿는 용도에 어떤 물성이 유리한지 학생이 판단하여 ③을 고른다.  
4번은 입자가 합쳐진 시점·장소와 흡착 수치를 읽고 → 소결의 정의와 적정 범위에 각각 대응시키면 된다.
