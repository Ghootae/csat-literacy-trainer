4번은 가지형·직선형 사슬의 배열 가능성을 읽고 → 지문의 결정 영역 개념에 대응시켜 → 두 소재의 결정 영역 비율을 추론해야 한다.  
이어 결정 영역과 화학 물질에 대한 민감성의 관계를 적용해 → 화학 물질과 접촉하는 용기에 적합한 소재를 스스로 골라야 한다.
