# v6.5 1단계 재검증 — 사람용 요약
1. 새 질문 문장을 넣고 31문항을 다시 돌렸더니 일치율이 86~88% → 74%로 떨어졌고, 기출 K1·K5까지 걸려서 멈춤 조건에 걸렸습니다. 그래서 API 실행(도덕·고체 재시험)은 하지 않았습니다.
2. 그런데 풀이지 오류를 찾았습니다. 지난 무료 검증에서 13문항(G13~G25)에 엉뚱한 지문이 붙어 있었습니다(도덕적 운 문항에 공손룡 지문 등). 이번에 고쳤습니다. 그래서 하락이 새 문장 탓인지 지문 수정 탓인지 아직 모릅니다.
3. 가르는 방법: 옛 질문을 고친 풀이지로 한 번 더 돌립니다(0원, 약 25분). 해 둘까요?
4. 코드(e3f 별도 호출, 발문 보존, 결함 표시)는 만들어 두었고 시험 20/20 통과했습니다. 커밋은 아직 안 했습니다.

## 추가: v3(함정 위치) 질문 결과
5. v3 질문은 일치율이 58~61%로 더 떨어졌고 기출 K3·K5·K6이 새로 걸렸습니다. codex가 거짓 선지의 78%를 "지문 원리를 거꾸로 알아서"로 분류해서, 손 분류의 '보기를 잘못 읽어서' 선지까지 지문 쪽으로 몰립니다. 도덕 G21·고체 G13은 잡았지만 G20은 여전히 놓쳤습니다.
6. 통과 조건 미달이라 v6.5 이어가기(API 실행)는 하지 않았고, 무료 검증 파일만 커밋·푸시했습니다. 다음은 지시문대로 검사기로 잡는 길을 접고 생성 3단계(〈보기〉 조립)에서 거짓을 〈보기〉 쪽에 두게 하는 방법 검토입니다. 판정은 웹 몫입니다.
