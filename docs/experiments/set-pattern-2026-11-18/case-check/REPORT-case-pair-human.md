# 짝 카드 시험 — 사람용 요약
1. 〈보기〉를 쓰기 전에 헷갈리는 짝을 지문 개념 구분에서 먼저 고르게 하는 PAIR_CARD를 켤 때만 도는 스위치로 넣고, 공손룡 A형을 한 번 만들었습니다.
2. 서버가 처음엔 짝 줄에 "왼쪽"이 들어간 것을 잡아 한 번 다시 불렀고, 재호출 뒤 통과했습니다. 짝은 "두 명과 실의 대응"(개념)이 됐습니다.
3. 불만이던 "위치·순서 추적" 이유는 전제형 10/12에서 짝 카드 0/12로 사라졌습니다(짝 문제 해결).
4. 그러나 점수는 짝 카드 1.00, 전제형 1.00, 옛 1.92로 그대로라 미리 정한 점수 판정은 "효과 없음"입니다(기출 2.0, 블라인드 유효). 짝 카드 정답은 "~다면" 가정형이 됐습니다.
5. 비용 약 $0.6. 청약 철회 확인과 채택 여부는 Ghootae 판단입니다.
