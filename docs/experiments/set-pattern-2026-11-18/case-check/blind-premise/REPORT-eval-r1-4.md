또한 ⓑ의 사명 사용과 ⓒ·ⓔ의 관계를 함께 검토하면서, 같은 단어의 맥락별 쓰임과 두 학파의 차이를 연결하게 한다.  
8번은 배치 순서를 읽고 → ㉠=솔, ㉡=별·달, ㉢=해를 복원한 뒤 → 한 실에 두 명이 대응하므로 공손룡의 원칙에 어긋난다고 판단하면 된다.
