가장 수능다운 문항은 **1번**, 가장 못한 문항은 **6번**이다.  
1번은 갑의 해명까지 읽고 → ⓐ는 필요한 빨간 옷, ⓓ는 옷 일반을 가리킨다고 복원하고 → 명·실 대응과 속성 구분에 연결해야 한다.  
그 뒤 학생이 직접 ⓓ와 ⓔ의 지시 대상이 같은지를 판단해야 하므로, 표현의 문맥적 의미와 철학적 개념을 함께 다룬다.  
6번은 호출과 이동을 읽고 → ‘마루·다래＝왼쪽 탈’, ‘나래＝오른쪽 탈’로 대응시키고 → 왼쪽 탈의 명이 늘어도 오른쪽 탈의 대응은 바뀌지 않는다고 판단한다.  
6번도 추적은 필요하지만, 1번보다 지시 의미의 해석과 개념 간 구별이 적어 3점 문항으로서 변별력이 약하다.
