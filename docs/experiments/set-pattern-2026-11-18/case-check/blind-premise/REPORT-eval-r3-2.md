6번은 사전 매도 계획과 B→C의 정보 전달을 읽고 → 정보가 거래에 미친 영향과 내부자·정보수령자 구분에 대응시키고 → A의 매도와 C의 매도에 적용할 규제를 각각 판단해야 한다.  
특히 C가 정보를 전달받았다는 사실만으로 분류하지 않고, 전달자인 B의 지위부터 확인해야 한다.
