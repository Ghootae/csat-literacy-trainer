# 공손룡 사례 lever 확인 — 사람용 요약
1. 새 순서를 인문 사례(공손룡)의 A-V1·B-V1에 적용해 한 번씩 만들고, 옛 최종본과 한 블라인드에서 3회 비교했습니다.
2. 서버 확인은 둘 다 처음에 통과했고, B는 M2 검사에 걸려 수리 뒤 통과했습니다.
3. 새 칸 평균은 1.29로 옛 칸 1.50보다 0.21 낮아 기준(1.5 이상, +0.5)에 못 미칩니다.
4. 두 문항이 정반대입니다. 새 B는 1.00에서 2.00(기출 수준)으로 올랐고, 새 A는 2.00에서 0.58로 떨어졌습니다. 옛 A가 이미 만점이라 올라갈 여지가 없었습니다.
5. 비용 $1.24(상한 $2.5 이내). 판정은 웹 몫입니다.
