① **거짓 / 지문** — 결정 영역이 많아질수록 유연성이 낮아지고 충격에 약해지므로, 유연한 소재로는 ㉮가 적합하다.

③ **참** — 결정 영역이 많아질수록 화학 물질에 대한 민감성이 감소하므로, 화학 물질이 닿는 부분에는 ㉯가 적합하다.  
④ **거짓 / 지문** — 결정 영역이 많아질수록 밀도가 높아지므로, ㉮보다 ㉯의 밀도가 높다.
