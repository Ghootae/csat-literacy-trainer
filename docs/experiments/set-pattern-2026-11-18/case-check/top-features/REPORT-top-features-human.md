# 기출 A형 상위 특성 4개 확인 — 쉬운 설명 (2026-11-27)

**가(특성이 상위를 가르나)**: 특성이 상위를 못 가름 (차이 +0.053, 특성 수 ≥3인 기출이 1문항뿐이라 상위 절반−하위 절반으로 대체)
**나(특성별)**: F1(〈보기〉 사실 둘 이상을 엮어 정체를 정함) 쓸 만함*, F2(그 정체를 〈보기〉가 말하지 않음) 쓸 만함*, F3(새 사실 하나로 정해지지 않음) 약함, F4(선지마다 판단이 다름) 약함. 표시 불안정한 특성은 없음(일치율 92~100%).
다(생성 8 참고): ρ +0.458 (판정 없음).
(*F1·F2는 기출 26개 중 1문항(공시 12번)만 해당이라 "쓸 만함"은 표본 1개에 기댄 기계적 판정이다.)

## 무엇을 봤나
- 웹이 점수를 보고 손으로 뽑은 4가지 특성이 정말 상위 점수를 가르는지, 점수를 모르는 다른 세션의 평가자 2명이 문항마다 예/아니오로 표시하게 해 확인했다(끼워 맞춤 점검). 기출 26문항 + 생성 8문항.

## 결과
- 기출 26개 중 4가지를 거의 다 갖춘 것은 공시 12번(점수 2.0) 하나였고, 특성 수 ≥3이 1개뿐이어서 두 묶음 비교가 성립하지 않았다. 대신 반으로 갈라 보니 점수 차이는 +0.053, ρ +0.256으로 거의 없다.
- 점수 2.0인 기출 중 공손룡 12번은 특성 1.5, 공시 12번은 4, 혈압 2.0은 특성 2에 그쳤다. 즉 높은 점수가 이 네 특성에서 나온다고 보기 어렵다.
- F1·F2는 아예 기출에서 거의 안 나타난다(1문항). 이것이 상위의 핵심이라는 웹의 가설과 달리, 기출 대부분(25/26)은 F1을 안 갖추고도 평균 1.24점이다.
- 생성 8개는 오히려 F1·F2를 갖춘 것이 4개(청약 2, 도덕 pair3, 공손룡 옛 A; 평가자가 갈린 청약 3b 1개 더)인데, 공손룡 옛 A(1.875)를 빼면 점수가 1.0 안팎이다. 특성을 갖춘 것이 점수를 올리지 않았다.
- 웹 예측("가름 또는 약하게 가름", "F1·F3이 쓸 만", "F4 표시 불안정")은 맞지 않았다: 못 가름, F3 약함, F4 일치율 96%로 안정적.
