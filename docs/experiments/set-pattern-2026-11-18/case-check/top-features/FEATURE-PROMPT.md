작업 폴더의 BLIND.md 에 지문 하나와 〈보기〉 문항 1개가 있어. 출처는 가렸어. 이 폴더 파일 말고는 열지 말고 인터넷도 쓰지 마. 문항이 좋은지 나쁜지는 판정하지 말고, 먼저 직접 풀어 정답을 고른 뒤 아래 네 가지를 예/아니오로 표시해.
F1 정답 선지의 틀린 곳을 확인하려면, 〈보기〉 속 둘 이상의 사실(사람·말·수치 사이의 관계)을 엮어 어떤 대상의 정체(지문의 어느 개념·범주에 드는지)를 먼저 정해야 한다. 〈보기〉 문구 하나, 또는 지문 문장 하나와 맞대는 것만으로는 틀린 곳이 드러나지 않는다.
F2 F1 의 그 정체(개념·범주 이름)를 〈보기〉가 직접 말하지 않는다. (F1 이 아니오면 F2 도 아니오.)
F3 정답 선지가 "~라면/~했다면/~한 경우" 등으로 〈보기〉에 없는 새 사실을 들여오고 그 새 사실 하나로 판정이 정해지는 문항이 아니다. (새 사실을 들여오지 않거나, 들여와도 판정이 〈보기〉 자료와 지문 관계를 계산해야 정해지면 예.)
F4 다섯 선지를 판정하는 데 필요한 정체·관계 판단이 선지마다 다르다. 한 가지 판별(예: 대상 하나의 유형 판정)로 세 선지 이상이 함께 풀리면 아니오.
출력: 각 항목 한 줄 근거, 마지막에 ```json 블록 하나: {"answer":"③","F1":true,"F2":false,"F3":true,"F4":true,"why":{"F1":"...","F2":"...","F3":"...","F4":"..."}}. 파일은 쓰지 마.
