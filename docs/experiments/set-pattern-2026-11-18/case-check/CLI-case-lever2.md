- **B-V2(긍정 발문): 성공.** 1.25 → 1.75(수능 같음 9/12), ㉯ 5 → 0. 웹 손 분류로 오답 4개는 이렇다.

  - ④: 여분 잔에는 덮개를 씌움 → 보기형
  - ⑤: 을은 밖에서 기다림 → 보기형

  - 결과적으로 원리형은 0~1/4이다. 옛 판은 4개 모두 '~라면' 가정 + 원리형이었다.

  - 새 정답 ③ "사진을 돌려받은 뒤에는 을도 병처럼 … 해명을 요구할 근거가 없겠군"은 옛 정답 ③ "손실이 모두 회복되었다면 … 근거는 남지 않겠군"과 같은 착각이다.

## 설명 (쉬운 말)

- **무엇이 됐고 무엇이 안 됐나:** "가장 적절한 것" 문항(B)은 새 순서로 크게 좋아졌습니다. 1.25에서 1.75가 됐고, 오답 넷이 거의 모두 〈보기〉 사실을 잘못 읽은 것이 됐습니다. "적절하지 않은 것" 문항(A)은 정답이 옛 판과 같은 착각("손실이 회복되면 해명 근거가 없다")으로 다시 나왔습니다. 이것은 지문 원리를 뒤집은 것이라 점수가 그대로였습니다.
- **왜 A만 실패했나:** 두 가지로 봅니다.
  1. 다시 만들 때 예전에 지문에서 뽑아 둔 "정답 후보"가 재료로 들어가, 모델이 그것을 다시 골랐습니다.
  2. B는 "오답 넷이 서로 다른 사실을 써야 한다"는 기계 확인이 있었지만, A의 정답 하나에는 그런 확인이 없었습니다.
- **어떻게 고치나:**
  1. 사례 버전에는 그 재료를 아예 주지 않습니다.
  2. 〈보기〉의 "헷갈리는 짝"에 이름을 붙이게 하고, 부정 발문의 정답은 그 짝을 쓰는지 서버가 확인합니다.
- **시험:** A만 다시 만듭니다(약 $0.75). 옛 판, 지난번 판, 새 판을 한 블라인드에 넣어 평가자 4명이 3회 봅니다(0원).
- **그다음:** 새 칸 평균(새 A + 지난번 B)이 1.5 이상이고 옛 판보다 0.5 이상 높으면 통과입니다. 그러면 공손룡·고체 촉매 사례로 넓힙니다.
