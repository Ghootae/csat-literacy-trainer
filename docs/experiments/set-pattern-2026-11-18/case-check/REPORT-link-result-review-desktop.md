## 해석과 재검토 조건

1. 자동 탐색의 미채택은 유지한다. 두 원리를 강제로 실제 결합했을 때의 품질 효과는 식별되지 않는다. 문항 내 다른 원리의 단순 등장은 구별한다.
2. 실험 조건에서만 서로 다른 규칙의 결과 의존성 또는 공동 필요성을 요구한다. 카드 수·짝 수로 대체하지 않는다.
3. 오독의 유인 구절과 교정 근거를 별도로 적는다. B삭제 입력에서 선지 자체가 행위자를 재제공한다. 삭제판 불일치를 모델 능력이나 결합 유무 하나로 환원할 수 없다.
4. 양쪽 분류의 근거를 기록한다. 위치만으로 포장인지는 확정할 수 없다. 구체적인 구성 사실 한 줄로 바꿀 수 있다.
5. M2 전면 면제나 전제형 폐기를 지지할 자료가 없다. 기출 공시 ⑤의 신분 분류처럼 반박에 지문이 필요한지를 본다. M2 잔존은 문항 단위이며 잔존 표시만으로 수리 전후 지름길이 동일하다고 단정할 수 없다.
6. 운영 권고는 옛 순서로 마감. 다른 칸 이전의 전제는 그 칸의 기존 실패가 같은 원인인지 확인하는 것이다. 미채택 권고와 사용자의 운영 결정은 구별한다.
7. 연구 목적은 전체 생성 표본, 제품 목적은 선별 후 블라인드와 채택당 비용을 쓴다. 기존 표본으로 선별기를 먼저 점검한다. 현재 자료로 후보 다수 생성의 비용 우위는 미측정이다.
