자료: 단독 블라인드 점수가 있는 기출 A형 사례 14개(lure-check 150f2127, a-recheck 4601facc).

**주의:** 점수를 본 뒤 읽었으므로 끼워 맞춤 위험이 있다. 아래 특성은 가설이고, 점수를 가린 판정으로 검증해야 한다(5절).

## 1. 정답의 틀린 곳이 어디서 드러나나 (가장 뚜렷한 차이)
- 상위: 〈보기〉 문구와도, 지문 한 문장과도 바로 맞대어지지 않는다. 〈보기〉 안의 관계(누가 누구에게서 정보를 받았나, 어떤 말이 무엇을 가리키나, 수치 여러 개)를 읽어 **정체를 먼저 정해야** 지문 정의와 어긋남이 보인다.
  - 공시 ⑤ "C는 1차 정보수령자로부터 받은 정보" → 〈보기〉의 B(임원)→C 경로를 따라가야 C가 1차 수령자임을 안다.
  - 공손룡 ④ "ⓓ와 ⓔ가 같은 대상" → 대화 맥락으로 ⓓ = 옷 일반, ⓔ = 빨간 옷.
  - 건축 ① "층고를 높였으니 규모를 늘린 증축" → 높이·층별 면적 같고 층수 줄어든 수치를 지문의 '규모' 정의에 대야 한다.
  - 전지 ② → 함량비를 지문의 성질 관계(니켈↑ 용량↑ 수명·안정성↓)로 바꿔 두 물질을 비교.
- 하위: 한 번 맞대면 끝난다.
  - 〈보기〉 문구와 대조: 과징금 ③(〈보기〉에 "전년도 총매출 금액을 기준으로"가 그대로 있음), 공유물 ⑤(〈보기〉 "면적 조정" ↔ 선지 "지분 조정").
  - 지문 규칙 한 문장: 상계 ③(동의 필요 → 규칙 뒤집기), 재판매 ③, 선거공보 ⑤.

## 2. 〈보기〉가 정체에 이름을 붙여 주나
- 상위: 안 붙인다. 공시 〈보기〉는 C가 몇 차 수령자인지, 공손룡 〈보기〉는 ⓐ~ⓔ가 무엇을 가리키는지, 건축 〈보기〉는 증축·개축을 말하지 않는다.
- 중간·하위: 허가 (가)(나)(다)는 상황 설명이 사실상 개념 이름(법률요건 충족 / 중대한 공익 / 원칙적 금지)을 말해 준다. 과징금은 산정 근거를 〈보기〉가 적어 준다.

## 3. 선지가 판정 사실을 스스로 들여오나
- 하위·중간: 선지가 "~했다면" 새 사실을 들여오고 그 사실 하나로 정해진다(선거공보 ③④⑤, 재판매 ①~⑤, 보증 ③~⑤, 상계 ①④). 〈보기〉는 무대만 깐다.
- 상위: 선지 조건이 있어도(전지 "~을 중시한다면") 그것은 기준일 뿐이고, 판정은 〈보기〉 자료와 지문 관계로 계산해야 한다.

## 4. 한 번 판별로 다섯 선지가 같이 풀리나
- 상위: 아니다. 공손룡은 선지마다 다른 쌍(ⓐ·ⓑ, ⓐ·ⓓ, ⓑ, ⓓ·ⓔ, ⓔ·ⓒ)의 지시 판단, 공시는 A·B·C·갑 각각 다른 규정.
- 생성 청약 cell5(1.0): 거래 유형 판별 하나로 여러 선지가 풀림 → 평가자 "거래 유형 판별을 여러 선지가 반복".
- 생성 공손룡 옛 A(1.88): '등잔'이 화면에선 유명, 일지에선 사명 → 1·2·4 특성을 가짐.

## 5. 검증 제안 (0원, codex)
- 기출 A형 사례 27개 중 아직 점수 없는 13개를 단독 블라인드로 점수 매김(8회씩).
- 따로 연 세션이 점수를 모른 채 27개 + 생성 12개에 특성 1~4를 예/아니오로 표시(2회).
- 미리 정할 판정: 특성 3개 이상 문항 평균 − 1개 이하 문항 평균 ≥ +0.5 → "특성이 상위를 가름". 통과하면 특성 판정을 생성 후보 고르기 검사로 쓴다(후보 여럿 생성 → 특성 많은 것 선택).
