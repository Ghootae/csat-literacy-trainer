|4|③|수능 같음|권유·유인·신청의 순서로 거래 유형을 확정하고, 수령 장소만 바뀐 경우와 신청 경로가 바뀐 경우를 구별해야 한다.|||

|8|③|중|사업장으로 유인한 뒤 신청받아도 방문판매라는 규칙은 적용하지만, 사례 해석과 조건 결합의 부담이 작다.|||

가장 수능다운 문항은 **2번**, 가장 못한 문항은 **6번**이다.  
2번은 대화를 읽고 → ⓐ의 필요한 빨간 옷, ⓑ의 특정 옷, ⓓ의 일반적인 옷을 구별하고 → 이를 명실 대응 및 유명·사명에 연결해야 한다.  
학생은 같은 단어라도 지시 대상이 달라질 수 있음을 판단하고, ⓓ와 ⓔ가 같은 대상을 지시한다는 ④의 전제를 스스로 반박해야 한다.  
6번은 두 받침의 위치와 기능을 읽고 → 포장 훼손과 물품 훼손에 대응시켜야 하지만 → 상자에 붙은 받침이 포장인지 물품인지 확정할 근거가 부족하다.
