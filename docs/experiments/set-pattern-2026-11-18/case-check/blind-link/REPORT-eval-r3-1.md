5번은 접수 사진과 수거 때의 얼룩을 읽고 → 새로 발생한 피해인지 기존 손실인지 가리고 → 갑이 방치한 위험과 실제 피해의 인과관계를 판단해야 한다.  
이어 이를 지문의 주의 의무와 해명 요구의 근거에 대응시켜 → 병의 위험 노출에 대한 항의와 기존 얼룩의 발생에 대한 책임 추궁을 구별해야 한다.
