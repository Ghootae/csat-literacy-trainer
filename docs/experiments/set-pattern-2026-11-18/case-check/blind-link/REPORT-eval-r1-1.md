- 이를 지문의 ‘의무 위반’과 ‘그 위반으로 발생한 피해’에 대응시키고 → 복원비 지급과 별개로, 병에게 **그 얼룩의 발생**에 대한 해명을 요구할 근거가 있는지 판단해야 한다.
