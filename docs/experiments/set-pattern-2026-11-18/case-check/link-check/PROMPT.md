# 결합·전제 점검 요청문 (codex gpt-6.1-sol, 평가자 2명, 새 청약 두 문항)
입력 파일 6종/문항(in-link{n}-A삭제.md, -B삭제.md, -전체.md, -전제.md)을 그대로 준다. 지문은 주지 않고 문항과 질문만 준다(〈보기〉만으로 정오를 정할 수 있는지 보는 것이 목적).
a. A삭제·B삭제: linkPlan의 factA/factB에 가장 가까운 〈보기〉 문장(Dice 매칭, match.json)을 지운 판에서 coreChoice 선지의 정오를 정할 수 있는가. 두 판 모두 평가자 2명 다 '아니요'면 "결합 살아 있음".
b. 전체: 정답을 고르는 가장 짧은 풀이와 쓴 〈보기〉 문장.
c. 전제: 정답 선지 세 시점 문장 각각의 거짓 전제 상태(명시/암시/소실)와 구절.
