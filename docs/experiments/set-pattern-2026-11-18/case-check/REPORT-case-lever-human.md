# 사례 갈림 사실 순서 시험 — 사람용 요약
1. 사례 문항을 "원리 고르기 → 〈보기〉에 갈림 사실 심기 → 오답은 그 사실을 잘못 읽은 결론"으로 만드는 순서(CASE_FLOW=lever)를 넣고, 도덕적 운 사례 두 문항을 새로 만들었습니다. 서버의 확인은 한 번에 통과했고 다시 만들 일은 없었습니다.
2. 블라인드 3회 결과 새 판 칸 평균은 1.33, 옛 판은 1.04로 기준(1.5 이상, 옛 판보다 +0.5)에는 못 미쳤습니다. 회차별 차이도 +0.6 / +0.25 / 0으로 흔들립니다.
3. 문항별로는 B형이 1.25 → 1.75로 크게 올랐고 "〈보기〉를 안 봐도 풀림(㉯)" 표시가 10건 → 1건으로 줄었습니다. A형은 0.83 → 0.92로 그대로고, "정답이 지문 한 문장으로 정해짐(㉲)"이 12/12로 남아 있습니다.
4. 한계: 3단계 직후에는 표와 〈보기〉가 맞았지만, 다듬기·교정이 〈보기〉를 고쳐서 최종본에서는 표의 사실 문장 4~5개가 〈보기〉와 글자가 달라졌습니다.
5. 비용 약 $1.49(상한 $3 이내). 판정은 웹 몫입니다.
