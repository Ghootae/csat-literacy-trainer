# 미끼 가설 잣대 확인 + decider 빼기 대조 — 쉬운 설명 (2026-11-27)

**가(잣대 확인)**: 잣대가 두 갈래를 가르지 않음 (N 1.312 vs P 1.229, 차이 +0.083)
**나(decider 빼기 대조)**: 3a·3b 모두 decider 필요 (둘 다 1.000 → 0.000, 차이 −1.000)

## 무엇을 봤나
- (가) 기출 A형 사례 12문항을 둘로 나눠 평가자(codex)에게 출처 없이 보여 주고 "수능 같음(2)/중(1)/수능 아님(0)"으로 매기게 했다. N형 = 〈보기〉 미끼를 지문 구분의 틀린 쪽에 묶은 것, P형 = 규칙·방향을 뒤집은 것. 평가자가 N형을 더 높게 보면 "미끼 가설"이 맞다는 뜻이다. 평가자 4명 × 2회차 = 문항당 8회.
- (나) 우리가 만든 청약철회 두 문항(3a 조명, 3b 의자)에서 〈보기〉의 정체를 못 박는 문장(decider)을 빼고, 원본과 비교했다.

## 결과
- (가) N형 6문항 평균 1.312, P형 6문항 평균 1.229. 차이는 +0.083으로 기준(0.4)에 한참 못 미친다. 법끼리만 비교해도(N 6 vs P 법 5) 1.312 vs 1.125, 차이 +0.188. 평가자는 두 갈래를 가르지 못했다. 기출 12문항 중 8회 모두 "수능 같음"을 받은 것은 N형 건축(2.0) 하나뿐이고, 나머지는 대부분 "중"이었다(한 문장 대입으로 풀린다는 이유 ㉲가 P형에 33회, N형에 15회).
- (나) 3a·3b 모두 원본은 "중"(1.0)이고 정답 불일치는 0이었다. decider를 빼자 두 문항 모두 16회 전부 "수능 아님"(0.0)이 됐고, 이유는 전부 정답 시비(㉳ 0→8): "찢은 덮개/끈이 포장인지 물품 일부인지 판단할 근거가 없다". 정답 일치 수는 8/8로 그대로다(평가자는 같은 답을 골랐지만 그 답이 유일하지 않다고 봤다).

## 웹 예측과 맞았나
- 예측: "decider를 빼면 깊어지기보다 ㉳가 늘고 정답 일치가 떨어질 것". → ㉳ 증가(0→8, 두 문항 모두)는 맞았다. 정답 일치 하락은 맞지 않았다(8/8 유지).
- 미끼 가설(가): 이 평가자 잣대로는 확인되지 않았다. 미끼형을 따로 높게 보지 않는다.

(0원: 유료 호출 없음, codex 128회. 자세한 수치·평가자 이유는 `REPORT-lure-check.md`.)
