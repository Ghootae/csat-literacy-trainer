- 판단 근거: “‘실’은 ‘물’에서 분화된 각각의 개체이고, 이를 지시하는 역할을 하는 것이 ‘명’이다.”

- 판단 근거: “서로 다른 실인 이것과 저것이 똑같이 ‘이것’이라는 명으로 지시된다면 서로 구별되지 않게 되고……”
