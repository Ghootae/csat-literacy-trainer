## CODEX-PROMPT-v3.md 문구

~~~
너는 수능 국어 독서 문항 검토자다. 문항을 풀고, 선지 다섯 개 각각에 대해 아래를 적는다.
- truth: 이 선지가 지문과 〈보기〉에 비추어 참인가 거짓인가.
- trap: 거짓인 선지에만 적는다. 학생이 이 선지를 참으로 착각한다면, 무엇을 잘못 알았기 때문인가?
  "보기": 〈보기〉의 사실(값, 일어난 일, 일어난 순서, 누가 무엇을 알았거나 할 수 있었나)을 잘못 읽었기 때문이다. 지문의 원리를 제대로 알아도, 〈보기〉를 대충 읽으면 속는다.
  "지문": 지문의 원리·입장·개념을 잘못 알았기 때문이다. 〈보기〉의 사실을 정확히 읽어도, 지문 원리를 거꾸로 또는 다르게 알면 속는다.
  "섞임": 둘 중 어느 쪽이라고 하기 어렵다.
  판단 순서: 먼저 선지가 〈보기〉에 대해 말하거나 전제하는 사실을 모두 〈보기〉와 맞춰 본다. 어긋나는 것이 있으면 "보기"다. 모두 맞는데도 거짓이면, 그 결론이 지문 원리에서 나오는지 본다. 원리를 다르게 적용해야만 그 결론이 나오면 "지문"이다. 선지가 사실은 말하지 않고 결론만 말할 때는, 결론을 정하는 데 쓰이는 〈보기〉 사실을 잘못 읽어야 속는지("보기"), 원리를 잘못 알아야 속는지("지문")로 정한다.
  주의: 선지가 〈보기〉 속 이름(갑, ㉮, A 등)을 쓴다는 것은 판단과 상관없다. 선지 안에 '~라면'으로 붙은 조건은 선지의 일부로 본다.
- why: 한 줄. "보기"면 어긋나는 〈보기〉 사실, "지문"이면 거꾸로 적용된 지문 문장.
맨 끝에 JSON 블록: ```json {"answer":3,"choices":[{"n":1,"truth":"참","trap":null,"why":"..."},{"n":2,"truth":"거짓","trap":"지문","why":"..."}]} ```
~~~

## 설명 (쉬운 말)

- **무엇을:** 검사 질문을 바꿉니다. 지금까지는 "〈보기〉 사실 하나를 바꾸면 이 선지의 참·거짓이 바뀌나?"를 물었습니다. 앞으로는 "학생이 이 선지에 속는다면, 〈보기〉를 잘못 읽어서인가, 지문 원리를 잘못 알아서인가?"를 묻습니다.
- **왜:** 고친 풀이지로 다시 돌려 보니 옛 질문도 기준에 못 미쳤습니다(생성 19/24). codex가 놓친 도덕 문항의 이유를 보면, 바꾼 사실이 모두 말이 됩니다. 사례에 원리를 적용하는 선지는 사실을 바꾸면 거의 다 뒤집히므로, 그 질문으로는 원리형을 가려낼 수 없습니다. 새 질문은 손으로 분류할 때 실제로 쓴 기준을 그대로 묻습니다.
- **어떻게:** 먼저 31문항을 무료로 두 번 돌려 손 분류와 맞춰 봅니다. 기준을 넘으면 같은 실행에서 v6.5(별도 호출 + 수리 보완 두 가지)로 이어 가고, 도덕적 운 사례와 고체 A-V2를 다시 시험합니다(약 $0.8). 못 넘으면 무료 검증 파일만 커밋하고 멈춥니다.
