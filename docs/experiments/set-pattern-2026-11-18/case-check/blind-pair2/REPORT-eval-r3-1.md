가장 수능다운 문항은 **4번**, 가장 못한 문항은 **3번**이다.  
4번은 대화의 오해와 해명을 읽고 → ⓐ의 ‘옷’은 필요한 빨간 옷, ⓑ는 손에 든 한 벌, ⓓ는 일반적인 옷에 대응시키고 → 각 용법을 두 학파가 어떻게 판단할지 스스로 결정해야 한다.  
특히 ④에서는 ⓓ와 ⓔ의 지시 대상이 같다는 선지의 전제부터 학생이 검토해야 한다.  
3번은 탈을 걸고 글자를 확대하는 행동을 읽고 → ‘여울’을 탈과 글자에 각각 대응시켜 → 두 번째 ‘여울’과 ‘마루’가 같은 실을 지시하는지 판단하게 한다.
