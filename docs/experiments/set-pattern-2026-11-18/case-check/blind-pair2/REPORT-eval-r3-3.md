|문항|답|판정|이유|결함|그래프 평|
|---|---|---|---|---|---|
|1|②|중|‘달’을 ‘별’로 바꾸면 한 명이 두 접시를 지시한다는 단순 대응만으로 풀려, 3점 문항으로는 추론 부담이 작다.|||
|2|②|수능 같음|화면의 ‘등잔’과 일지의 ‘등잔’을 구별하고, 일지에서는 특정 개체를 가리키므로 사명이라는 판단을 내려야 한다.|||
|3|②|수능 같음|두 번째 ‘여울’이 가리키는 이름표의 글자와 ‘마루’가 가리키는 탈을 구별하여, 두 명의 대응이 일대일 원칙에 어긋나지 않음을 판단해야 한다.|||
|4|④|수능 같음|대화에서 ‘옷’의 지시 범위를 복원해야 하며, ⓓ의 옷 일반과 ⓔ의 빨간 옷은 지시 대상이 같지 않다.|||

가장 수능다운 문항은 **3번**, 가장 못한 문항은 **1번**이다.  
3번은 탈을 거는 행동과 글자를 확대하는 행동을 읽고 → ‘여울’의 지시 대상을 각각 탈과 글자로 구별하고 → 이를 명·실의 대응에 연결해야 한다.  
학생은 같은 표현도 요청에 따라 지시 대상이 달라진다는 사실과, 두 번째 ‘여울’과 ‘마루’는 서로 다른 대상을 가리킨다는 판단을 스스로 내려야 한다.  
1번은 ㉠의 두 접시를 확인하고 → ‘달’을 ‘별’로 바꾸어 보고 → 한 명이 두 실을 지시하므로 공손룡의 원칙에 어긋난다고 판단하면 되어 풀이 경로가 짧다.
