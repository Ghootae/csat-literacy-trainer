|---|---|---|---|---|---|
|1|②|중|표식으로 대상의 동일성을 확인하면 대부분 일대일 대응 원칙을 기계적으로 적용할 수 있어 추론의 깊이가 얕다.|||
|2|②|수능 같음|같은 ‘등잔’도 화면과 일지에서 지시 범위가 달라짐을 구별하고, 일지에서는 사명으로 쓰였다고 판단해야 한다.|||
|3|②|수능 아님|의도된 답은 ②지만, 글자를 확대했다는 행동만으로 두 번째 ‘여울’의 지시 대상을 이름표로 확정하기 어려워 정답 시비가 남는다.|㉳||
|4|④|수능 같음|대화에서 생략된 지시 범위를 복원하고, 같은 명의 복수 지시와 서로 다른 명의 관계를 구별해야 한다.|||

가장 수능다운 문항은 **4번**, 가장 못한 문항은 **3번**이다.  
4번은 갑의 해명을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷 한 벌, ⓓ는 옷 일반에 대응시킨 뒤 → 명의 일대일 대응과 유명·사명 개념을 적용해야 한다.  
학생은 같은 ‘옷’이라는 표현도 지시 범위가 다름을 스스로 복원하여, ⓓ와 ⓔ가 같은 대상을 지시한다는 ④를 배제한다.  
3번은 글자를 확대하고 붙이는 행동을 읽고 → 두 번째 ‘여울’을 탈이 아닌 이름표나 글자에 대응시켜야 하지만 → 그 행동이 곧 지시 대상의 변경을 뜻하는지는 확정되지 않아, 풀이가 불안정한 언어 해석에 의존한다.
