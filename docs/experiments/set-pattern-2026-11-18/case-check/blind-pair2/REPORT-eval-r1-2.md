가장 수능다운 문항은 **4번**, 가장 못한 문항은 **3번**이다.  
4번은 갑의 해명과 을의 반응을 읽고 → ⓐ는 필요한 빨간 옷, ⓑ는 손에 든 개별 옷, ⓓ는 옷 일반에 대응시키고 → 같은 단어의 지시 대상이 같은지와 사명 여부를 학생이 판단해야 한다.  
특히 ④에서는 ⓓ와 ⓔ의 지시 대상이 같다는 전제부터 학생이 검토하여, 공손룡의 설명을 적용할 수 있는 상황인지 가려야 한다.  
3번은 탈을 거는 행동과 글자를 확대하는 행동을 읽고 → ‘여울’을 각각 탈과 이름표에 대응시키도록 유도하지만 → 글자 확대가 곧 지시 대상의 변경인지는 확실하지 않다.  
또 ‘여울’의 두 사용 전체를 고려하면 하나의 명이 여러 실을 지시한 것으로도 읽혀, ②의 판정이 판단 범위에 따라 흔들린다.
