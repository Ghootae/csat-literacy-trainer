# 연구: 사례 A형(부정 발문)이 왜 안 풀리나 — 기출 27문항 전수 읽기 (웹, 0원)

작성: 2026-11-27 02시대 KST, 스레드 "사례 A형이 안 풀리는 이유 연구하기". 저장소 기준 483e6cb2.

## 1. 결론 먼저

1. **기출 A형 정답의 주된 모양은 "〈보기〉 속 미끼를 지문 구분의 틀린 쪽에 묶기"다.** 27개 중 17개다(아래 N형). 〈보기〉에는 겉으로 보면 한쪽에 들 것 같은 말이나 사실(미끼)이 일부러 들어 있다. 지문의 구분 기준을 적용하면 그것은 반대쪽이다. 정답 선지는 미끼의 겉모습대로 판정한다.
   - 예: 건축법 K37 — 〈보기〉 "층고만 높인" → 정답 "규모를 늘렸으므로 증축". 지문 기준으로 층고는 규모(면적·층수·높이)에 들지 않는다.
   - 예: 공유물 분할 K24 — 〈보기〉 "분할 면적을 **조정**" → 정답 "**지분**을 조정". 같은 낱말 '조정'이 미끼다.
   - 예: 과징금 K21 — 〈보기〉에 "민원", "경영 악화"가 실제로 있다 → 정답 "경영 악화를 근거로 산정". 진짜 근거(전년도 총매출)도 〈보기〉에 있다. 한 칸에 맞는 사실과 미끼 사실을 같이 둔다.
2. **나머지 10개(P형)는 지문 규칙을 뒤집거나 예외를 지운 것이다.** 규칙 한 문장으로 정해지기 쉽다. 우리 평가자는 이 갈래 기출을 낮게 본다: 고체 촉매 K17("실리카가 소결한다", 〈보기〉가 지문 설명을 거의 그대로 옮김)은 단독 블라인드 **0.0**이다. 반면 N형인 공시 K05·공손룡 K19는 **2.0**이다.
3. **생성 A형은 거의 P형이었다.** 청약 새 A ③("떨어뜨리지 않았다면… 제한 사유")은 〈보기〉 사실을 지우고 원리만 남겼다(0.58). 점수가 높았던 두 생성 A형은 N형이다: 공손룡 옛 A ②("'새벽'은 사명이지만 '등잔'은 사명이 아니다", 2.0), 도덕적 운 A안(얼룩이 접수 전인가 후인가, 1.83).
4. **지난 결합 탐색(link)이 "중"에 멈춘 이유에 대한 새 가설:** 정답 시비를 없애려고 넣은 "짝 양쪽 decider(정체 근거)"가 〈보기〉 안에서 정체를 못 박아 **미끼를 지웠다.** 기출은 판정 기준을 **지문 정의**에 두고, 〈보기〉는 반대쪽처럼 보이는 겉모습을 준다. 시비는 지문 정의가 막는다. 우리는 시비를 〈보기〉 문장으로 막았고, 그래서 헷갈릴 거리가 사라졌다(codex: "포장인가 부품인가 한 규칙으로 풀림").
5. **지난 가설 두 개는 기출과 맞지 않는다(고쳐 적음).**
   - "정답에 가정형(~라면) 금지": 기출 정답 27개 중 6개가 가정·조건형이다(K12, K25, K44 등). 문제는 가정형 자체가 아니라, 가정이 〈보기〉 사실을 지워 원리만 남기는 것이다. 기출 가정은 〈보기〉 사실(날짜, 함량, 가격)을 그대로 쓴다.
   - "〈보기〉는 하나로 이어진 사건": 기출 A형 27개 중 약 7개가 서로 다른 사례를 나란히 둔다(K25 갑 소득세 + 을 상속세, K37 A·B, K41 갑·을, K04 (가)(나)(다), K28 (가)(나)). 평가자는 청약 A안의 나열을 ㉱로 깎았지만, 나열 자체보다 사례마다 미끼가 없어 "규칙 반복 대입"이 된 것이 문제였을 수 있다.

## 4. 가설과 다음 시험 후보

**가설:** A형이 "중"을 넘으려면 정답이 **경계 사례**를 써야 한다. 지문이 나누는 두 개념과 그 기준을 고르고, 〈보기〉에 겉으로는 A쪽처럼 보이지만 기준으로는 B쪽인 사실(미끼)을 넣는다. 정답 선지는 미끼의 겉모습대로 A로 판정한다. 시비는 〈보기〉 문장이 아니라 지문 정의가 막는다.

| 후보 | 무엇 | 비용 | 얻는 것 |
|---|---|---|---|
| ① 잣대 확인(먼저, 추천) | 기출 N형 6개 + P형 6개를 섞어 codex 블라인드(4명 × 2회) | 0원(codex) | 평가자가 정말 N형을 높게 보는지. 아니면 가설이 평가 잣대와 안 맞음 |
| ② 경계 사례 카드 생성 시험 | 스위치 하나(예: CASE_FLOW=boundary): 지문 구분·기준 → 미끼 사실 → 〈보기〉 → 정답(미끼대로 판정) → 참 선지 4개도 〈보기〉 사실 필요. 서버 검사: 미끼 문구가 〈보기〉에 있는가, 정답 판정이 미끼 문구를 쓰는가, 정체를 못 박는 decider 문장이 없는가 | 약 $1.5(청약·공손룡 A 각 1회 + 블라인드) | 생성 A형이 "중"을 넘는지 |
| ③ 대조 확인 | link3 문항에서 decider 문장만 지운 판을 같은 블라인드에 | 0원(문장 편집 + codex) | decider가 깊이를 깎았는지 직접 확인 |

판정 기준(②, 미리 적음): 새 A 평균 ≥1.5 AND 옛 A보다 +0.4 이상 → 효과 있음. 같은 블라인드에 자격 기출 2개(공시 12, 공손룡 12), ㉳ 4/12 미만.
