# v6.5 마무리 재시험 — 사람용 요약
1. 검사기 v6.5(M6 별도 호출·옛 질문, 수리가 발문을 바꾸면 되돌림, 결함 문항은 최종본에서 제외)를 마무리하고 도덕 A·B, 고체 A에 돌렸습니다.
2. 결과: 5문항 모두 M6에 안 걸렸고 수리도 한 건도 없었습니다. 도덕 문항도 파이프라인 안에서는 "사실에 달림"으로 답해 놓쳤습니다(무료 검증에서는 잡았던 문항입니다).
3. 그래서 문항이 그대로인데도 블라인드를 다시 보았더니 고체 칸 평균이 1.375 → 0.938로 떨어졌습니다(도덕 0.688 → 0.812). 코드가 바뀐 게 아니므로 평가 잡음이 ±0.4쯤 된다는 뜻입니다.
4. 판정에서 조심할 점: 지난번 고체 수리 효과(0.84 → 1.375)도 이 잡음 안에 일부 들어 있을 수 있습니다. 같은 블록 안의 수리 전·후 비교(B-V2 0.125 → 1.125)는 잡음보다 커서 방향은 믿을 만합니다.
5. 도덕 칸은 이 검사기로 고쳐지지 않았습니다. 다음은 지시문에 적힌 대로 생성 3단계(〈보기〉 조립)에서 거짓을 〈보기〉 쪽에 두는 방법 검토입니다. 비용은 약 $0.5~0.6 추정입니다.
