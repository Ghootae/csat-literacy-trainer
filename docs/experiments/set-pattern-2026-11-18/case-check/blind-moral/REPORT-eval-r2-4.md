가장 수능다운 문항은 **3번**, 가장 못한 문항은 **2번**이다.  
3번은 대화의 정정 내용을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷 한 벌, ⓓ는 일반적인 옷을 지시한다고 복원해야 한다.  
이를 명·실의 대응 관계와 유명·사명에 대응시키고 → ⓓ와 ⓔ가 같은 대상을 지시한다는 ④의 전제가 틀렸음을 스스로 판단해야 한다.
