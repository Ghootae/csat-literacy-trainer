가장 수능다운 문항은 **3번**, 가장 못한 문항은 **2번**이다.  
3번은 대화의 해명과 지시 상황을 읽고 → ⓐ는 빨간 옷, ⓑ는 특정 옷 한 벌, ⓓ는 옷 일반에 대응시킨다.  
이후 명실 대응 및 유명·사명 개념을 적용해 → ⓓ와 ⓔ의 지시 대상이 같다는 ④의 전제가 잘못되었다고 스스로 판단해야 한다.  
2번은 손실 회복을 언급한 ③을 읽고 → 지문 마지막의 해명 요구 근거에 대응시키면 → 〈보기〉의 인과관계와 보호 범위를 분석하지 않아도 정답을 고를 수 있다.
