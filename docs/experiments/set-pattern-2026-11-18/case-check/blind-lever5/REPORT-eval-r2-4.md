가장 수능다운 문항은 **5번**이다. 실제 함량과 광고·계약 내용을 읽고 → ‘광고 또는 계약과 다른 공급’에 대응시켜 → 두 시계 모두 별도 철회 사유가 있음을 판단해야 한다.  
이어 공급 시점과 분석표 열람 가능 시점을 읽고 → **3개월·30일을 모두 충족해야 한다는 조건**에 대응시켜 → ㉮만 기간을 충족한다고 판단한다. 실제로 열어 본 날과 알 수 있었던 날도 구별해야 한다.  
가장 못한 문항은 **4번**이다. 계약과 다른 밝기 조절 단계를 읽고 → 별도 철회의 반환 비용 규정에 대응시켜 → 일반 철회 기간 안이어도 사업자가 부담한다는 ④를 고를 수 있다.  
그러나 ③의 이동도 5문단이 명시한 ‘사업장 밖 권유 후 함께 사업장 안으로 이동’에 들어맞는다. 신청이 이동보다 앞섰다는 사실만으로 **그 이동 자체가 유인이 아니라고 단정할 근거는 부족**하다. 학생의 규정 적용 능력보다 문구 해석이 정답을 가른다. 함께 작업대를 쓴다는 사실도 쓰이지 않는다.
