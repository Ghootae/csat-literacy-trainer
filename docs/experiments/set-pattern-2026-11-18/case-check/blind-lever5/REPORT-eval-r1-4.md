5번은 같은 광장에서 이루어진 두 거래를 읽고 → 장소 대신 권유·신청 방식에 대응시켜 → 갑은 통신판매이고 을의 신청 후 이동은 5문단의 유인에 해당하지 않는다고 판단해야 한다.  
이어 갑의 계약 내용과 실제 기능을 비교하고 → 별도 철회 규정에 대응시켜 → 일반 철회 기간이 남아 있어도 사업자가 반환 비용을 부담한다고 판단해야 한다.  
3번은 사업장 밖 권유와 사업장 안 신청이라는 조건을 읽고 → 5문단의 방문판매 포함 규정에 대응시키면 → ③의 ‘7일’이 틀렸다고 곧바로 판단할 수 있어, 풀이 단계의 결합이 상대적으로 약하다.
