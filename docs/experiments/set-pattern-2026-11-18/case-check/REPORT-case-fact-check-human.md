# 사실 바꾸기 검사 무료 검증 — 사람용 요약
1. 일치율: 결정 선지 74개에서 손 분류와 r1 86%, r2 88%(두 회차 같은 답 69/74). 비용 0원.
2. 기출 걸림은 K2·K4뿐이었다(두 회차 모두, K 선지 일치 r1 12/12·r2 11/12). 생성 문항 걸림 일치는 r1 22/24, r2 23/24로 기준 20/25 이상 충족.
3. 점수 차: 걸림 평균 약 1.0(손 0.94, codex 1.01~1.04), 안걸림 약 1.56~1.61 — 걸린 문항이 약 0.55점 낮다.
4. 가장 많이 어긋난 갈래: 정보 비대칭 지문 G6(5건)·G3·G7의 선지(사실을 하나 바꿔 결론을 뒤집을 수 있는지에서 갈림). G16·G18·G20의 입장형 선지 3개는 codex가 null을 내 판정 불가(G18 걸림 불일치는 이 때문).
5. 판정은 웹 몫(통과 기준: 기출 K2·K4뿐 + 생성 20/25 이상 → 둘 다 충족).
