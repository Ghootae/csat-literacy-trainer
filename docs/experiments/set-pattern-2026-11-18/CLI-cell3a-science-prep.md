## 설명

- **목적:** 두 가지다. (1) 방금 정한 판정 기준을 진척표에 소급해 적는다. (2) ③-1에 쓸 기출 과학 지문 두 편(관점 〈보기〉가 있는 것, 축 그래프 〈보기〉가 있는 것)의 후보를 모은다.
- **방법:** CLI가 문제은행 158세트 중 과학·기술 지문만 훑는다. 관점 〈보기〉 3점 문항과 그림 〈보기〉 3점 문항을 찾고, 그림은 직접 열어 축 그래프인지 본다. 진척표·현재 상태 문서는 위에 적은 문안 그대로 고친다.
- **다음 스텝:** 웹이 후보 표에서 미리 정한 기준대로 P1·P2를 하나씩 고르고, 유료 지시문 `CLI-cell3b`(지도 2편 + 8문항 생성 + 블라인드 2회, 상한 $7)를 쓴다. 축 그래프 후보가 없으면 그래프 칸은 mRNA(pH-전하)로 가는 안을 다시 묻는다.
- **커밋 시점:** 이 지시문 끝에서 문서만 커밋·푸시한다(판정 기준 결정이 다른 작업에 덮이지 않게 미리 남김).
