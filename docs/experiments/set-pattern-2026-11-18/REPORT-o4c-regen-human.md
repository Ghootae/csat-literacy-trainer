# 순서표 ④ 3단계 쉬운 보고 (2026-11-25)

## 1. 개요
**목적.** 도덕적 운 지문에서 ‘거의’였던 두 칸(관점·사례)을 규칙대로 한 번 다시 만들어, 이번엔 1.5를 넘는지 봤습니다.
**결과.** 인문 관점 칸은 1.500(2단계 1.438)으로 올랐습니다. 다만 새 관점 문항은 모두 ‘중’(1.00)이고, 점수는 그대로 둔 옛 B 관점 문항(2.00)이 받쳐 줍니다. 인문 사례 칸은 0.688로 오히려 내려갔습니다(2단계 1.062, 기출 지문일 때 1.31). 새 A형 사례 문항은 ‘수능 아님’을 4번 받았습니다. 평가자들은 “정답이 ‘손실이 회복돼도 해명을 요구할 수 있다’는 지문 문장을 뒤집은 것이라 사례를 분석하지 않아도 고른다”고 했습니다. 지문 탓 지적은 0건입니다. 기출 공손룡 12번은 두 회차 모두 2.00이라 평가 잣대는 정상입니다. 비용 $1.441(상한 $3.5).
**다음 스텝.** 판정은 웹이 하고, 사례 칸은 규칙 쪽 검토로 넘어갈 가능성이 큽니다.

## 2. 본문
### 인문 관점 — 1.5 도달, 새 문항은 ‘중’ (판단 필요)
새 A형 관점 문항의 정답은 “㉯는 관람객이 다쳤는지와 관계없이 음량 상한을 설정하지 않은 선택을 비난할 수 있으므로 …”입니다. 옛 문항은 정답이 한 문장으로 정해진다는 지적이 8번이었는데 이번엔 1번으로 줄었습니다. 그러나 평가자 8명 모두 ‘중’을 줬고 이유는 “선택 비난과 결과 비난의 기본 구분을 확인하는 수준”이었습니다.

### 인문 사례 — 더 나빠짐 (미해결)
- 새 A형: 정답 “을의 손실이 모두 회복되었다면 … 해명을 요구할 근거는 남지 않겠군.” 지문의 한 문장을 뒤집은 것이라 한 문장으로 정해졌고(㉲ 8회), 평균 0.50.
- 새 B형: 기존 얼룩과 이후 확대를 시간 순서로 나누면 정답이 드러나고 오답이 쉽게 걸러진다는 지적(평균 0.88).
방식 위반이나 수리는 없었고 정답 선지도 고치지 않았으니, 규칙이 허용한 범위 안에서 같은 약점이 되풀이된 셈입니다.

### 실행 중 문제 (해결)
B형 실행 명령이 zsh 때문에 한 번 실패(API 호출 전이라 비용 없음)해 스크립트를 고쳐 다시 돌렸습니다. 평가 429는 이번엔 없었습니다.
