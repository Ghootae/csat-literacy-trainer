## 목적

골드 분석이 존재하는 8개 문단에 대해 최상·중상·중간·하위 응답을 하나씩 고정하고,
v2의 `required/error_only` 구분과 v7 판정 계약이 다음 기대 구조를 유지하는지 확인했다.

| 수준 | 설계 | 기대 판정 |
| --- | --- | --- |
| 최상 | 모든 중심 관계를 정확히 표현 | PASS |
| 중상 | required는 표현하되 error_only 또는 세부 내용 생략 | PASS |
| 중간 | 일부 required 관계가 확인되지 않음 | UNCLEAR |
| 하위 | 중심 관계를 명시적으로 뒤집음 | ERROR |

이 실험은 수준별로 한 응답만 사용한 회귀 실험이며 일반적 정확도 추정이 아니다.

## 설정

- 문단: 헤겔 1개, 도파민 4개, 법인·표면 장력·정보 비대칭 각 1개

- 학생 응답 판정: `gpt-5.6-terra`, medium, `dialogue-prompt-v7`
- 호출 재시도: SDK 자동 재시도 없음
- 입력 fixture:
  `packages/pipeline/fixtures/experiments/dialogue/eight-paragraph-four-level-v2-2026-08-25.json`

기존 v2 골드 3개를 재사용하고 헤겔·도파민 5개를 새로 분석했다. 8개 모두 사람이
`required/error_only` 역할과 한 상태·한 오류·한 질문 단위를 검토한 뒤 사용했다.

## 질문 검토

비통과 16건의 질문을 다음 기준으로 사람이 검토했다.

- target 관계 하나만 다루는가
- 질문만 읽어도 정답 관계나 방향을 알 수 있지 않은가
- 학생의 실제 오류 지점만 지적하고 정답을 대신 말하지 않는가

정답 관계나 방향을 직접 노출한 질문은 없었다. 15건은 적절했고, 헤겔 중간 응답의
“직관, 표상, 사유는 서로 어떤 관계를 이루나요?”는 target인 종합 관계를 확인할 수는
있지만 범위가 넓어 경계선으로 분류했다. 판정과 target 선택 자체는 타당하다.

## 결론

이번 고정 응답 집합에서는 v2의 핵심 목적이 모두 관찰됐다.

1. 완전한 응답과 error_only를 생략한 응답을 모두 PASS로 구분했다.
2. required의 단순 미확인은 ERROR가 아니라 UNCLEAR로 유지했다.
3. 명시적으로 뒤집은 관계만 ERROR로 잡았다.
4. 상태별 target과 질문 유형 계약을 32건 모두 지켰다.

따라서 v2는 사람 검토형 골드 생성과 소규모 대화 실험에 사용할 수준이다. 다만 32/32는
미리 설계한 단일 응답 회귀 결과다. 실제 학생 표현의 다양성, 역할 배정 반복 안정성, API
타임아웃 운영 정책은 별도의 검증 대상이다.
