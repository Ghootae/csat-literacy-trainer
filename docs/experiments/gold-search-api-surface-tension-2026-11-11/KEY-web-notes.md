### 라 수정안 (웹)

〈보기〉: 프린터 을의 잉크는 점도가 작아 오네소르게 수가 적정 범위보다 낮았다. 연구자는 같은 노즐에서 이 잉크로 크기가 다른 구형 방울 두 개를 만들어 같은 기압 아래에서 관찰했다. 이후 첨가제를 넣어 잉크를 더 끈적거리게 했더니, 이번에는 잉크가 노즐 밖으로 나오지 않았다. 연구자는 잉크의 밀도를 높이는 방법과, 폐포의 확장을 쉽게 하는 물질과 같은 작용을 하는 물질을 잉크에 넣는 방법을 검토하고 있다.

① 처음 상태에서 잉크를 알맞은 정도로만 더 끈적거리게 했다면, 위성 잉크 방울로 인한 오염을 줄이며 안정적으로 인쇄할 수 있었겠군. (참: 결과는 지나쳤지만 방향은 맞음 → 이야기 결과에 끌려 거짓으로 볼 함정)
② 크기가 다른 두 방울 가운데 반지름이 작은 방울의 내부 압력이 더 높겠군. (참)
③ 두 방울 모두 내부 압력이 외부 압력보다 높다는 사실만으로는 방울이 계속 커진다고 볼 수 없겠군. (참)
④ 끈적거림은 그대로 둔 채 밀도만 알맞게 높이면, 잉크가 다시 노즐 밖으로 나와 안정적으로 인쇄될 수 있겠군. (참)
⑤ 폐포의 확장을 쉽게 하는 물질과 같은 작용을 하는 물질을 넣으면, 잉크의 오네소르게 수가 적정 범위로 돌아오겠군. (거짓·정답: 그 물질 = 표면 장력↓ → 오네소르게 수↑ → 더 멀어짐)

바꾼 점: 변수 이름 풀어쓰기는 '끈적거림' 하나만 남김(나머지 지문 용어 그대로). '검토하는 방안' 나열 → 시간 순 장면(낮음 → 첨가제 → 지나쳐서 안 나옴 → 다음 방법). 폐포 연결은 '계면 활성제'라는 이름을 숨기고 "확장을 쉽게 하는 물질"로만 줘서 3단계 연결 유지.
