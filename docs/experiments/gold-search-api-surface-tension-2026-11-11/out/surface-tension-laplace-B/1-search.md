# 4. 탈락 예시 5개

| 후보 진술 | 탈락 검사 | 탈락 이유 |
|---|---|---|
| 계면 활성제에 단백질이 포함되어 있으므로 단백질의 양이 많을수록 잉크의 점도가 커진다. | **(a)** | “지질과 단백질로 구성된 계면 활성제”와 점도의 정의 사이에는 단백질 함량에 따른 점도 변화가 제시되지 않는다. 부분 독해의 혼동이라기보다 **새로운 물성 관계의 추가**이다. |
| 폐포와 구형 잉크 방울은 모두 라플라스 식을 적용하여 설명할 수 있다. | **(b)** | 2문단과 4문단을 통합해도 참이다. 헷갈리는 연결 자체는 있지만 **거짓 진술이 아니다**. |
| 폐포로 들어온 공기는 잉크젯 프린터의 노즐을 통과해 잉크를 종이까지 운반한다. | **(c)** | 인체의 호흡 기관과 프린터를 직접 연결하는 내용이다. 지문의 개념 관계를 이해하지 않아도 상식으로 배제할 수 있다. |
| 점도와 노즐 지름을 각각 두 배로 하면 두 효과가 상쇄되어 오네소르게 수가 변하지 않는다. | **(d)** | 지문은 점도와 노즐 지름이 미치는 **증감 방향**만 제시한다. 각각 두 배로 했을 때 상쇄되는지는 정확한 식 없이 확정할 수 없어, 분명히 거짓인 후보로 남길 수 없다. |
| 계면 활성제로 표면 장력을 낮추면 폐포의 확장이 어려워진다. | **(d)** | “이에 따라 폐포의 확장이 쉬워진다.”를 사실상 반대로 바꾼 것뿐이다. 다른 명제와의 통합 없이 바로 배제되므로 **인근 개념 사이의 혼동을 탐색하는 후보로는 지나치게 단순**하다. |

핵심적인 혼동은 **평형을 두 압력의 같음으로 읽는 것**, **방울의 크기와 노즐 지름을 바꾸어 읽는 것**, **안정성을 나타내는 수를 클수록 좋은 수로 읽는 것**, **안정 범위 위·아래의 실패 양상을 서로 바꾸는 것**에 집중된다.
