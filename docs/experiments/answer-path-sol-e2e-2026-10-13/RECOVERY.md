# API 오류·복구 기록

실행은 2026-10-13에 시작해 2026-10-14 KST에 완료했다. 동결 입력·지도·실행기는 변경하지 않았다. 오류 요청은 삭제하거나 성공으로 바꾸지 않았으며, 동일한 요청 해시로 재전송했다. 복구 실행 코드도 함께 보존했다.

| 요청 | 사례/반복 | HTTP 상태 | 이력 | 미확정 예약 USD |
| --- | --- | --- | --- | --- |
| run-N6-r2-72 | N6-r2 | 503 | API_ERROR 유지 | 0.093248 |
| run-N4-r3-107 | N4-r3 | 없음 | API_ERROR 유지 | 0.087818 |
| run-N4-r3-108 | N4-r3 | 없음 | API_ERROR 유지 | 0.087818 |

| 재전송 요청 | 이전 요청 | 결과 | 동일 입력 해시 |
| --- | --- | --- | --- |
| run-N6-r2-73 | run-N6-r2-72 | completed | 일치 |
| run-N4-r3-108 | run-N4-r3-107 | API_ERROR | 일치 |
| run-N4-r3-109 | run-N4-r3-108 | completed | 일치 |

N6-r2는 첫 재전송에 성공했고, N4-r3는 첫 재전송 실패·두 번째 재전송 성공이었다. 복구 요청도 채점 120요청 상한에 포함했다. 형식 재시도는 0회다. HTTP 상태 없는 오류의 원인은 확인되지 않았다. API 실패 3회분의 미확정 예약 $0.268884는 계속 비용 상한에 포함하며 실제 청구액으로 간주하지 않는다.

보존 실행 코드: `recover-n6-r2.mjs`, `recover-n4-r3.mjs`, `recover-n4-r3-second.mjs`. API 키는 각각 `node --env-file-if-exists=.env`로만 로드했다.
