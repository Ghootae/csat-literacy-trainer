## 규칙을 지킨 방법

- 한 세트 한 문항: 같은 세트가 여러 후보에 있을 때 "뽑힌 것"만 세트를 차지하게 했다. table 순번 13(탈락, 도식)과 19(뽑힘)는 같은 세트(수치예보)이고, 29(탈락, 도식)와 34(뽑힘)도 같은 세트(인장 시험)다. 17·23(둘 다 탈락)도 같은 세트(옥신)다. 앞 문항이 뽑히지 않았으므로 "두 번째 문항 건너뛰기"에 해당하지 않는다. 뽑힌 22문항의 세트 id는 모두 다르다(스크립트가 검사).
- 순서는 건너뛰거나 되돌리지 않았다. case는 1~4, view는 1~12, table은 새 순서 1~34를 차례로 판정했다.
- case 5·6, view 14·15는 1차 때 〈보기〉가 화면에 보였으나 목표를 이미 채운 뒤라 판정·선택에 쓰지 않았다. table 35~38은 확인하지 않았다.
