### 3.1 질문문 전문 (`CODEX-PROMPT-<n>.md`, n = 묶음 번호, {N}은 문항 수)

```
작업 폴더의 BLIND-<n>.md를 풀고 선지마다 표시해 줘. 지문이 {N}개이고 지문마다 〈보기〉 문항이 하나씩, 모두 {N}문항이야. 출처는 알려 주지 않아. 이 파일 말고 다른 파일은 열지 마. 인터넷·API도 쓰지 마.

문항마다 먼저 직접 풀어 답(①~⑤)을 고른다. 그다음 선지 ①~⑤마다 아래를 적는다. 서로 비슷한 문항이 있어도 문항마다 따로 판정해.
- A. 〈보기〉 필요: 〈보기〉를 가리고 발문·지문·선지 문장만 읽고 이 선지 내용의 참·거짓을 근거 있게 확정할 수 있으면 "아니오", 〈보기〉에 적힌 사실·값·관찰을 하나라도 읽어야 확정되면 "예". 선지의 한 부분이 지문과 어긋나서 그것만으로 거짓이 확정되는 경우도 "아니오"로 친다. 짐작으로만 맞힐 수 있는 경우는 "예"다.
- B. 지문 근거 수: A가 "아니오"일 때만, 확정에 쓴 지문 근거가 한 문장(한 사실)이면 "하나", 둘 이상을 이어야 하면 "여럿". A가 "예"이면 빈칸.
- C. 근거 한 줄

출력: 먼저 마크다운 표(문항|답|선지|A|B|C, 한 줄에 선지 하나), 마지막에 같은 내용을 ```json 블록 하나로: [{"item":"가","answer":3,"choices":[{"n":1,"needsBogi":"아니오","facts":"하나","why":"..."}, ...]}, ...]. 파일은 쓰지 말고 답으로만 내 줘.
```

### 3.2 블라인드 파일 (`BLIND-<n>.md`) 머리말

```
# 풀이지 {n}: 〈보기〉 문항 {N}개

지문이 {N}개 있고 지문마다 〈보기〉 문항이 하나씩 있습니다. 출처는 알려 드리지 않습니다. 문항마다 직접 풀어 답을 고른 뒤, 선지마다 질문문의 A·B·C를 적어 주세요.
```

- 묶음마다 case·view·table이 고르게 들어가게 나눈다(각 3~4). 문항 기호는 묶음 안에서 가, 나, 다 … 순서.
- 정답표 `KEY.md`(묶음·기호 → id, 세트, 원래 번호, 정답, 갈래)는 코덱스 작업 폴더 밖에 둔다. 코덱스 작업 폴더 `codex/<n>/`에는 `BLIND-<n>.md`와 `CODEX-PROMPT-<n>.md`만 둔다.
