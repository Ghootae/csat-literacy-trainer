# 블라인드 점검 (BLIND-CHECK)

`scripts/check_blind.py`가 만든다.

- 묶음 1: 문항 11개, 갈래 {'case': 4, 'view': 3, 'table': 4} → 통과
  - 지문·발문·〈보기〉·선지 글자 일치: 통과
- 묶음 2: 문항 11개, 갈래 {'case': 3, 'view': 4, 'table': 4} → 통과
  - 지문·발문·〈보기〉·선지 글자 일치: 통과

## 출처 누출 점검

- 금지어(학년도·평가원·수능·교육청·모의평가), 세트 id(전체·앞 8자), 지문 제목(meta.json title), 정답 표기: 없음 → 통과

## 지문 본문에 원래 들어 있는 제목 문구(보고만)

- BLIND-2: 지문 제목 문구 "초임계 유체를 이용한 결정화 공정"가 원래 지문 본문 안에 1회 있음(bt-69c014cb). 우리가 넣은 것이 아님
