# 교사 시연 튜토리얼 각본 시험 — 인간 보고서

## 1. 개요

1) **목적**: 선생님이 튜토리얼에서 그대로 따라 입력할 답(각본)이 매번 같은 반응을 내는지 확인했습니다. 정보 비대칭 지문 5문단과 13번 문제로, 판정기의 세 반응(바로 칭찬, 빠진 곳 질문, 틀린 곳 교정 질문)을 한 번씩 겪게 하는 각본입니다.

2) **결과**: 고친 각본은 **모든 칸이 3회 중 3회 기대대로** 나왔습니다.
   - 문단 1: 빠진 곳 질문 → 보충 → 칭찬
   - 문단 2~4: 바로 칭찬
   - 문단 5: 틀린 곳 교정 질문 → 고침 → 칭찬
   - 문제: ② 선택 → 교정 질문 → 고침 → ⑤ 다시 선택 → "근거도 정확해"
   
   처음 각본에서는 두 칸이 어긋났는데, 판정기가 아니라 각본 문장 탓이었습니다(아래 본문).

3) **다음 스텝**: 고친 각본으로 전체를 한 번 더 돌려 튜토리얼 캡처를 일관되게 찍고, 그 캡처로 튜토리얼 웹 페이지를 만듭니다.

## 2. 본문

### 문단 1 보충 답이 부족했음 (해결)
- **문제**: 판정기가 "정부는 공급자에게 어떤 조치를 강제해?"라고 물었는데, 각본 답은 "정보 비대칭 해소"였습니다. 개입의 목적만 되풀이한 답이라, 판정기가 3회 모두 "구체적인 조치는 아직 빠져 있어"라며 정답을 보여 주고 끝냈습니다. 판정은 맞았습니다.
- **처리**: 답을 "정부가 공급자한테 성분이나 효능 같은 정보를 소비자에게 알려 주도록 강제해."로 바꿨습니다.
- **결과**: 3회 모두 칭찬으로 끝났고, 해당 핵심에 "질문 후 캐치"가 표시됐습니다.

### 문단 5에서 교정 질문이 나오지 않았음 (해결)
- **문제**: 각본 요약 "다수 의견은 합헌, 소수 의견은 위헌"에는 틀린 곳이 **두 개**였습니다. 문단 판정은 틀린 곳이 하나면 질문하고, 여럿이면 바로 고쳐 주고 끝내도록 설계돼 있어서 3회 모두 질문 없이 끝났습니다.
- **처리**: 틀린 곳을 하나(다수 의견 "합헌")만 남겼습니다.
- **결과**: 3회 모두 "다수 의견은 위헌 여부를 어떻게 판단했어?" 같은 교정 질문이 나왔고, "다시 보니 위헌이라고 했어"로 답하자 칭찬으로 끝났습니다.

### 문제 풀이 경로 (해결, 처음부터 안정)
- ② 선택 → "ⓐ의 의무는 무엇을 제공하는 사업자에게 부과돼?" → 답 → [다시 선택] → ⑤ → "정답이야! 근거도 정확해" 경로가 3회 모두 같았습니다. 질문 문구만 조금씩 달랐습니다.

### 문단 1이 가끔 바로 칭찬으로 끝남 (판단 필요, 작음)
- 스크립트 오류로 중단된 시험 1회에서는 문단 1 첫 요약이 질문 없이 바로 칭찬을 받았습니다(4회 중 1회).
- 튜토리얼에 "질문 없이 칭찬이 나오면 그대로 [다음 문단]을 누르세요"라는 한 줄을 넣는 것을 권합니다.

### 시험 중 발견한 화면 버그 (해결, 커밋 대기)
- 오늘 커밋(입력 기호 버튼)부터 `/dialogue/lab`이 빈 화면으로 깨져 있었습니다. 한 줄로 고쳤고, 화면이 정상으로 뜨는 것을 확인했습니다. 선생님 시연 전에 꼭 필요한 수정입니다.
