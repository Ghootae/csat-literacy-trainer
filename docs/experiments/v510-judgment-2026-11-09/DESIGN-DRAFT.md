## 2. 전략

### 2.1 바꿀 방향 (문장은 나중에, 기대 판정 확정 뒤)

171행 "모든 주장 지지"를 웹 논의 후보 2(체크포인트 `2026-11-07-feedback-overfitting-candidates.md` "해결 후보" 2)로 바꾼다.

- 참인 선지: 학생 근거가 선지를 참으로 만드는 원문 사실·관계를 짚고, 그것으로 이 선지를 고를 이유가 성립하면 충분하다.
- 선지 문장이 이미 말하는 결론·연결은 학생이 다시 말하지 않아도 된다(P1).
- 결론만 말하거나(선지 되풀이), 원문과 맞지만 이 선지를 고를 이유가 되지 않는 사실만 들면 부족이다.

## 6. 위험

- **가상 근거는 코드 에이전트가 썼다.** 규칙 방향(2.1)을 아는 쪽이 쓴 사례라 유리하게 쓰였을 수 있다. 사용자가 문구를 고치거나, 규칙을 모르는 하위 에이전트에게 유형 정의만 주고 다시 쓰게 할 수 있다(판단 필요 ⑤ → 사용자 검토로 결정). "못 가름" 근거는 원문에 있는 사실로 썼다(경마 1문단 공정성 저해, 오디오 1문단 축음기, 의식 (나) 객관주의 철학 확인).

- **오디오 16 UNKNOWN은 이 시험으로 안 풀린다.** 다른 관문 문제다.
- **H는 판정기가 힌트를 모르는 상태의 시험이다.** 2부에서 힌트를 판정 입력에 넣기로 하면 H를 다시 돌려야 한다.
