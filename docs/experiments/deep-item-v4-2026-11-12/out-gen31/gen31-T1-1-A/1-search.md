## 1. 탐색·검사 결과

지문이 **6문단**이므로, 제시된 1~5문단 조합뿐 아니라 **6문단이 포함된 조합도 모두 탐색**했다.

| 항목 | 수 |
|---|---:|
| 훑은 기본 명제 쌍 | **51쌍** |
| 문단 간 탐색 | 15개 문단 조합 × 3쌍 = 45쌍 |
| 같은 문단 안 대조 | 문단별 1쌍씩, 6쌍 |
| 만든 후보 | **51개** |
| (a) 부분 독해만으로도 그럴듯하지 않아 탈락 | 14개 |
| (b) 통합해도 거짓임을 확정할 근거가 부족하여 탈락 | 10개 |
| (c) 상식만으로 거짓이 드러나 탈락 | 0개 |
| (d) 합리적인 참의 해석이 남거나 표현이 모호하여 탈락 | 6개 |
| **최종 통과** | **21개** |

※ 탈락 수는 중복을 피하기 위해 **대표 탈락 사유 하나로만 집계**했다. 기본 쌍만으로 판단하기 어려운 경우에는 보조 명제를 함께 확인했다.  
※ 아래의 **통과 진술은 모두 ‘통합적으로 읽으면 거짓인 진술’**이다.

### 특히 주의할 경계

- **11번:** 활성형 X 인자가 *트롬빈을 만드는 반응에 작용한다*는 것과, 활성형 X 인자 *자신이 트롬빈으로 바뀐다*는 것은 다르다.
- **15·21번:** 지문은 **피브린 중합 → 섬유 → 얽힌 그물 → 그물 속 분자들의 공유 결합 연결**을 구별한다. ‘연결된다’는 공통 표현만으로 단계들을 합치면 안 된다.
- **16번:** 트롬빈의 **간접적 기여**를 부정하는 진술이 아니다. 지문이 제시한 공유 결합 형성의 **직접 촉진 주체**를 잘못 지정한 진술이다.

| 탐색 ID | 탈락 후보 | 탈락 검사 | 이유 |

| **T06** | 응고 반응에 관여하는 단백질은 모두 조직 인자와 같은 보조 단백질이다. | **(a)** | “응고 반응에는 여러 종류의 단백질이 관여하며”라는 부분은 단백질의 **다양성**만 제시한다. 이것만 읽고 모든 단백질을 보조 단백질로 받아들일 만한 연결 고리가 약하다. ‘일부 이해에서 생기는 인접한 착각’보다 근거 없는 분류에 가깝다. |

| **T11** | 피브리노겐은 혈장 바깥에는 절대로 존재할 수 없다. | **(b)** | “생성된 트롬빈이 작용하는 대상 가운데 하나는 혈장에 존재하는 단백질인 피브리노겐이다.”는 **존재 위치**를 알려 줄 뿐, 다른 위치에서의 존재 가능성을 전면 배제하지 않는다. 근거 없는 단정이지만, 지문만으로 그 단정이 거짓임을 확정할 수도 없다. |
| **T38** | 트롬빈이 피브린 섬유를 형성한다. | **(d)** | 트롬빈이 섬유를 직접 중합한다는 뜻이라면 잘못이지만, 피브리노겐을 절단하여 섬유의 재료를 제공한다는 **간접적 형성**의 뜻이라면 참이 될 수 있다. ‘형성한다’의 범위가 불명확하다. |
| **T45** | 중합된 피브린 분자들은 이미 서로 연결되어 있다. | **(d)** | “이렇게 생긴 피브린 분자들이 서로 이어지는 중합 과정을 거치면 긴 피브린 섬유가 형성된다.”에 따르면 일반적인 ‘이어짐’의 뜻으로는 참이다. ‘활성형 안정화 인자가 만드는 공유 결합으로 연결되어 있다’는 뜻을 임의로 넣어야 거짓이 되므로 탈락시켰다. |
