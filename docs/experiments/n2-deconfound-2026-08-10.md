# 순환·분업 정책의 교락 해소 — 프로브 2개 추가

- 날짜: 2026-08-10 / 모델: `claude-opus-4-8` / effort `medium`
- 원시 출력: `n2-deconfound-2026-08-10.log`
- 계기: 코덱스 학생 역할 테스트(2026-08-09)가 제안한 회귀 픽스처 검토

## 문제 — 두 변수가 붙어 다녔다

N2 세트가 "순환에서는 중간 생략 허용, 분업에서는 불허"를 잰다고 했지만, 프로브를 뜯어보니
결정 변수를 가릴 수 없는 배치였다.

```
P3 프로브        3탄당(중간산물)   되먹임(RuBP 재생)   기대
관계보존              있음            있음          관계보존
구체적                있음            있음          관계보존
순환중간생략           없음            없음          부분관계
```

**관계보존을 만든 것이 되먹임인지 3탄당인지 이 배치로는 알 수 없다.** 결과적으로
**원칙 F("명명된 중간산물의 조건부 생략 허용")의 허용 쪽이 회귀에 잠겨 있지 않았다** —
평가기가 엄격해져 "3탄당을 안 쓰면 부분관계"가 되어도 깨지는 테스트가 없다.

P5도 같다. `한쪽공간만`이 부분관계인 것이 **공간이 하나라서**인지 **연결이 없어서**인지
구분되지 않는다.

## 추가한 프로브

```
[순환-중간산물생략]  되먹임 O, 중간산물 X   기대 관계보존
  "이산화 탄소가 RuBP와 결합해 포도당을 만들고 RuBP가 재생되어 이 과정이 반복된다"

[분업-양끝점만]      두 공간 역할 O, 이동 X  기대 부분관계
  "C4 식물은 엽육 세포에서 PEP와 이산화 탄소를 결합시키고, 유관속초 세포에서 포도당을 만든다"
```

코덱스가 제안한 나머지 둘은 넣지 않았다. **D**(4탄당 연결 보완 → 관계보존)는 기존
`관계보존` 프로브와 사실상 같고, **B**(C3 명칭 근거)는 focal이 다른 영역이라 별도 설정이
필요하며 `주제만` 프로브가 이미 인접하다.

### 정책이 실증됐다

교락이 풀리자 결정 변수가 드러난다.

```
순환   되먹임 O + 중간산물 X  →  관계보존     ← 새 프로브
       되먹임 X              →  부분관계
       ⇒ 결정 변수는 되먹임이지 중간산물이 아니다

분업   한 공간 + 역할        →  부분관계
       두 공간 + 역할, 연결 X →  부분관계     ← 새 프로브
       두 공간 + 역할 + 연결  →  관계보존
       ⇒ 결정 변수는 연결이지 공간 개수가 아니다
```

이제 "중간 단계의 필수성은 개수나 표면적 세부성이 아니라 **그 단계가 목표 관계의 위상
구조를 연결하는 데 필요한지**로 정해진다"가 회귀로 고정됐다.
