# 문항별 양식 분류 (items.md)

판정: 코드 에이전트(Claude Code 메인 세션)가 지문·문항·정답을 직접 읽고 한 번 판정. 정답 출처: csat-literacy-trainer/data/enrichment/records.

열: 번호 / 정답 / 양식(주, 부) / <보기> 제시 방식 / 깊이 / 정답 선지의 함정. "적절한 것" 문항은 함정 칸에 정답(참 선지)을 가리는 데 필요한 연결과 대표 오답을 적었다.

양식 코드: A 개념 연결+적용, B 계산·대입, C 관점 비교·평가, D 구조·전개, E 내용 확인, F 어휘·문맥, X 새 양식(아래 X1), ? 판정 불가.
X1 = 기전 사슬 추적: 지문의 여러 단계 인과 사슬(호르몬·신경 등)을 따라 증감·방향을 전파한다. <보기> 값을 대입하는 B와 달리 지문 안의 사슬 자체를 끝까지 따라가는 것이 깊이의 원천이다.
