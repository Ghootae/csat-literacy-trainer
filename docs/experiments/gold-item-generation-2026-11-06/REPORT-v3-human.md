# E1 v3 "관계 먼저 설계" 결과 (인간 보고서)

## 1. 개요

1) **목적**: 생성 문항이 기출만큼 "두 내용을 이어야 풀리는" 선지를 만들 수 있는지 봤습니다. 그런 깊이를 골드 지도(B)가 지도 없는 방식(A′)보다 더 잘 만드는지도 봤습니다.

2) **결과**: 미리 정한 기준을 넘지 못했습니다.
- 깊은 관계 선지(문장을 넘거나 추론해야 아는 연결, 50선지 중): 기출 18, B v3 11, A′ v3 12. B는 v2와 같은 11이고, A′만 7에서 12로 올랐습니다. 깊이를 끌어올린 것은 지시였고 골드는 아니었습니다.
- 정확성은 모든 조건이 천장(10/10)입니다. 맞는 선지에 지어낸 관계도 0입니다.
- 기출과의 차이는 거의 "추론" 단계에 있습니다(기출 16 대 생성 2~4). 기출은 지문의 원리를 새 상황에 적용합니다. 예를 들어 표면 장력 기출은 라플라스 식을 합쳐져 커진 새 기포에 적용해 압력 차이가 더 작다고 판단하게 합니다. 생성 문항은 지문이 이미 말한 관계를 옮기는 데 머뭅니다.

3) **다음 스텝**: 사전 기준대로 E1을 정리할지, "원리 적용형 선지"를 새로 시도할지 정해 주셔야 합니다. E2 보류 여부도 함께입니다.

**정정**: v2 보고의 "기출 24, B v2 13"은 판정자 한 명이 낸 값입니다. 이번 판정자는 같은 문항을 기출 22, B v2 19로 셌습니다. 이번 보고는 50문항을 한 판정자가 판정한 값만 씁니다.

## 2. 본문

### 깊이 (미해결)

| 묶음 | 깊은 관계 | 추론 | 맞는 선지에 지어낸 관계 |
|---|---|---|---|
| 기출 | 18 | 16 | 0 |
| A′ v3 | 12 | 3 | 0 |
| B v3 | 11 | 4 | 0 |
| B v2 | 11 | 2 | 0 |
| A′ v2 | 7 | 3 | 0 |

기준은 B v3가 기출의 80%(14.4)이고 A′ v3보다 많아야 하는 것이었습니다. 결과는 61%이고 A′보다 적어서 미달입니다.

### 새 부작용 (판단 필요)

"적절한 것" 자리에 틀린 관계 선지를 넣으라는 규칙 때문에, A′와 B 모두 법인 문항에서 오답 4개가 "A가 아니라 B" 꼴이 됐습니다. 정답만 평범한 서술이라 형식으로 티가 났습니다.

### 판단이 필요한 것

| 방안 | 내용 | 비용 |
