## 판정
- 형식이 핵심 차이만 남게 짧아졌다. 기호 3개 이하 9/9, '…' 사용 9/9, 대표 문장 굵게 9/9. Ghootae가 원한 모양(S-58 r3)과 같다.
- 습관 판단은 v2.3과 같다(형식 쓰는 방식만 바뀜).
- `changed`: 뺀 말만 짧게(“가장 효율적인 방법”, “투표 마감 시각까지”)가 대부분. 일부는 “X → Y”. otherCases의 changed는 가끔 설명 문장.

## 고친 것 (v2.4.1, 검토 부분만)
- 검토는 학생에게 보이는 것과 result 판단만 본다. 화면에 안 나오는 perEntry 서술만으로 FAIL하지 않는다. S-23 r2 같은 거짓 숨김을 막는다. 생성 부분은 v2.4와 같아서 다시 돌리지 않았다.
