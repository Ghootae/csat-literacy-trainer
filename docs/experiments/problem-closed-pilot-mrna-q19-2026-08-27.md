# mRNA 19번 클로즈드 파일럿 안정화 — 2026-08-27

## 파일럿 결과

동일한 mRNA 백신·지질 나노 입자 19번에서 수준별 시뮬레이션 10회를 실행했다.

- 전체 최종 정답: 10/10
- 최초 정답: 3/3, 불필요한 질문 없이 종료
- 최초 오답: 7/7, 오류 교정 뒤 정답으로 재선택
- 진단 질문: 실제 불확실성이 존재할 때만 사용
- 질문 상한: 최대 추가 진단 1회와 교정 질문 1회, 코드 예산 2회 이내
- 진단 질문의 정답 번호·판단 방향 노출: 0건
- 최소 개입: 10회 중 9회 완전 충족, 재선택 문구 1회 위반

`pH 7 = 친수성`, `투명한 액체 = 소수성 아님`, `mRNA 양전하·지질 음전하`처럼 학생 발화에서 오류가 명확한 경우 추가 진단 없이 해당 관계만 교정했다. “에탄올 pH가 7이라 혼합 용액이 산성이 아닐 것 같다”처럼 다른 처방이 가능한 경우에는 판단을 먼저 구별한 뒤 국소 교정으로 이동했다.

## 발견 사항과 수정

### P0 — 직접 코칭 뒤 재선택 UI 정지

관찰된 세션에서는 서버가 `AWAITING_RESELECTION`으로 전환됐지만 브라우저의 긴 POST 응답이 완료되지 않아 `busy` 상태가 유지됐다. 새로고침하면 진행된 서버 상태가 복원됐다. 터널 시작 과정에서도 일시적인 DNS timeout이 기록되어, 상태 손실보다 긴 응답 전달 실패에 안전하게 대응해야 한다고 판단했다.

수정:

- mutation POST를 중복 재시도하지 않는다.
- 15초가 지나면 GET으로 현재 서버 스냅샷을 조회한다.
- 서버 상태가 이전 화면보다 진행됐으면 해당 스냅샷으로 UI를 복구한다.
- 직접 코칭 확인 → 재선택 활성화를 새로고침 없이 검증하는 E2E를 추가했다.

### P1 — 교정 결과 라벨 분리

신규 완료 세션은 다음 결과를 구분한다.

- `CORRECTIVE_QUESTION_CORRECTION`: 최초 근거만으로 오류가 명확해 바로 교정 질문
- `DIAGNOSTIC_THEN_CORRECTION`: 진단 질문 뒤 교정 질문
- `DIRECT_COACHING_CORRECTION`: 직접 설명 뒤 재선택

기존 `DIAGNOSTIC_CORRECTION`은 과거 기록 호환을 위해 스키마에 남기되 신규 재선택 완료 경로의 기본값으로 사용하지 않는다.

### P1 — 재선택 문구 범위

프롬프트와 코드 계약이 `각 선지`, `모든 선지`, `전체 선지` 재검사를 요구하는 재선택 문구를 거부한다. 학생에게는 방금 수정한 개념이나 관계만 반영해 다시 선택하도록 안내한다.

### P2 — 질문 예산 표시

학생 화면의 `진단 0/2`를 `추가 진단 질문 0/2`로 변경했다. 최초 선택 근거와 교정 질문은 이 예산에 포함되지 않는다는 의미가 명확해졌다.

### P2 — 지연 대응

실제 운영 계측의 최근 `gpt-5.6-terra / medium` 성공 호출 18건:

- 평균: 13.646초
- 중앙값: 14.679초
- p95: 19.696초
- 최소/최대: 2.609초 / 19.696초
- 입력 토큰: 239,072
- 출력 토큰: 22,974
- 프롬프트 캐시 읽기 발생: 16/18건

학생 화면에는 1초 단위 경과시간을 표시하고, 15초 이후 서버의 완료 상태를 자동 확인하고 있음을 안내한다.

`gpt-5.6-terra / low`는 mRNA 블라인드 4건을 모두 통과했지만 평균 세션 지연이 34.459초로 기존 기준 실행의 31.241초보다 줄지 않아 채택하지 않았다. `gpt-5.6-luna / medium` canary는 명확한 pH 오류에서 불필요한 진단 질문을 추가해 품질 기준을 통과하지 못했다. 운영 기본값은 `gpt-5.6-terra / medium`으로 유지한다.

## 배포 판단

UI 상태 복구, 결과 라벨, 최소 재선택 문구, 질문 예산 표시와 대기 피드백을 반영했다. 전체 회귀가 통과하면 동일 mRNA 문항에 대한 제한된 클로즈드 파일럿을 재개할 수 있다.

다만 이 결과로 문제 풀이 모듈 전체의 일반화를 주장하지 않는다. 다음 내용 확장 검증은 법 해석, 조건 추론과 선지 간 비교처럼 구조가 다른 문항에서 진행한다.
