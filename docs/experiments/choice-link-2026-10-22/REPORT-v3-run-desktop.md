# 선지 연결 v3 3회 실행과 비틂 목록 초안 — 논의용 보고 (Desktop Claude 대상)

작성 2026-10-22. 근거 결정: D-0162 보완 3, D-0163(보고 형식). 앞선 실행 보고: `REPORT-v2-run-desktop.md`. 측정은 결과 파일에서 계산한 값이고, 해석은 Claude 메인 세션의 판단이다.

## 1. v2 → v3 변경 (설계)

1. 선지 정오는 정답 번호와 발문 극성에서 정해 입력 `truth`로 준다. 출력의 `truth`·`answerConflict`를 빼고 `readingGap`(NONE / IMPLICIT_PREMISE / STRICT_READING)을 더했다.
2. 〈보기〉 조각에 기호 표시 `marks`를 넣었다. 공손룡 q12의 ⓐ~ⓔ 5개이고, 6지문 중 유일하다. 위치는 DB 오프셋을 조각 안 위치로 바꾼 것이고, slice 일치를 확인했다.
3. 규칙을 바꿨다.
   - `NONE` 조각에 `contextIds`를 허용한다.
   - `APPLY`는 〈보기〉 id와 지도 id를 둘 다 근거(비틂이면 대상+맥락)에 넣는다.
   - 〈보기〉 적용 선지의 바뀐 곳: 〈보기〉 사실을 다르게 옮겼으면 〈보기〉 조각, 원리를 잘못 적용했으면 지문 단위.
   - 서술 방식 선지: 지문에 없으면 `NONE`과 `TOP`.
   - `INFER`면 `inferenceBasisIds` 필수를 강조했다.
4. 지시문은 `CHOICE-LINK-PROMPT-v3.md`, 인계는 `docs/handoffs/2026-10-22-choice-link-generator.md` 보완 v3다.
5. 구현 테스트는 새 묶음 21개와 기존 82개가 모두 통과했다. dry-run은 외부 요청 0, exampleAllPass true였다.

| 지표 | v2 | v3 |
|---|---:|---:|
| 검증 위반 합계 | 76 | **3** |

v3 위반 3건은 모두 공손룡 q11②의 `INFER without inferenceBasisIds`(r1·r2·r3)다. 해석: 이 조각은 근거 없는 추가(5-1)라 `source: NONE`·`INFER`로 표기됐다. 그런데 NONE 규칙은 inferenceBasisIds를 비우라고 하고, INFER 규칙은 채우라고 한다. 규칙끼리 충돌한다. 해결안: `NONE`이면 `INFER`의 inferenceBasisIds 필수를 면제한다.

검토 표시: NOTE 155, READING_GAP 76, NONE_TWIST 48, MULTI_TWIST 13, EXPLANATION_DIFFER 4(v2 30).

## 5. readingGap (측정)

선지×회차 360건 중 IMPLICIT_PREMISE 55, STRICT_READING 21, NONE 284다. NONE이 아닌 선지는 28개이고, 그중 24개는 2회 이상이다.

v2에서 정답과 어긋났던 선지는 모두 3회 일관되게 표시됐다.

| 선지 | 표시 |
|---|---|
| 법인 q10① | STRICT ×3 |
| mRNA q18④ | IMPLICIT ×3 |
| mRNA q19② | IMPLICIT ×3 |

mRNA q20③·⑤는 v3에서 FALSE 입력에 5-1 비틂으로 연결되고 gap 없음이다.

나머지 표시는 다단계 추론 선지에 몰린다.

- IMPLICIT 예: 표면 q15① "기포 안의 공기는 큰 기포에서 작은 기포로 이동한다". note는 "두 기포의 표면 장력·외부 압력이 같다는 전제, 반지름→압력 차이→이동 방향의 다단계 추론"이다.
- STRICT 예:
  - 도파민 q13④ "차단": 〈보기〉는 "억제"라고 한다.
  - 표면 q16⑤ "생성될 수": 원문은 "작으면 생긴다"이고 "그 경우에만"이라고 하지 않았다.

해석: 모델은 IMPLICIT_PREMISE를 "원문에 없는 상식 전제"보다 넓게 쓴다. "여러 단계를 거쳐야 하는 추론"에도 쓴다. 이 표시는 정답 판정의 문제가 아니라 학생에게 추론 부담이 큰 선지라는 신호로 쓸 수 있다. 현행 정의를 유지할지, `MULTI_STEP`을 따로 둘지는 열린 질문(Q3)이다.

## 6. 회차 간 안정성 (측정)

FALSE 선지 57개를 셋으로 나눴다.

| 분류 | 수 |
|---|---:|
| 3회 모두 바뀐 곳이 비어 있음 (`NONE` 비틂만, 근거 없는 추가) | 12 |
| 바뀐 곳이 있고 3회 교집합이 비지 않음 | 36 |
| 교집합이 빔 | 9 |

교집합이 빈 9개의 내역:

- 일부 회차만 NONE (3): 공손룡 q11②, mRNA q20④·⑤. 같은 선지 안에 "없는 내용 추가"와 "원문 내용 바꿈"이 함께 있어, 회차마다 어느 쪽을 비틂으로 잡는지가 갈렸다.
- 이웃 단위 사이 흔들림 (6):
  - 도파민 q10④: P2-11,12 / P2-14
  - 도파민 q12①: P4-6 / R28
  - 도파민 q12④: P3-16 / P3-9
  - 표면 q15①: P2-3 / P1-9
  - 표면 q15②: R1 / P1-3
  - 표면 q16②: P6-3 / P5-5

해석: 바뀐 곳이 있는 선지 45개 중 36개(80%)가 세 회차 공통 대상을 가졌고, 3개는 NONE 섞임, 6개는 이웃 단위 흔들림이다. 이웃 단위 흔들림 6개는 합집합 보관으로 감당할 수 있다. 자동 요약의 "모든 회차 교집합이 비지 않음 36/57(63%)"은 NONE-only 12개를 실패로 세는 지표라 과소평가다. 다음 요약에서는 NONE-only를 따로 센다.

`TWIST-LIST-DRAFT-v1.md`. 틀린 선지 57개를 5갈래 14종으로 묶었다(선지당 주된 비틂 하나).

한계: 목록은 6지문 57선지에서 귀납했다. 1개짜리 종류(2-3, 3-2, 4-3)는 표본이 적다. D-0162 계획대로 맞춰 보기 6지도 문항으로 검증해야 한다.
