# 선지 연결 v5 UI 6지문 재생성 — 인간 보고서

## 1. 개요

### 1) 작업의 목적

확정한 비틂 목록(14종, 정의 5곳 다듬음)으로 UI 6지문 선지 연결을 다시 만들었어요. 나중에 학생 피드백 실험에 쓸 **오프라인 골드의 재료**예요. 두 가지를 함께 확인했어요.

1. 다듬은 정의가 원래 지문에서도 잘 작동하는가.
2. v3에서 제가 손으로 묶었던 분류와 모델이 목록에서 고른 분류가 맞아떨어지는가.

### 2) 작업의 결과

- 18건을 모두 받았어요. 비용은 $2.08이에요.
- **기타 0개.** 틀린 선지 57개를 모두 14종 안에서 설명했어요.
- **회차 일치:** 두 회차 이상 같은 종류를 고른 선지가 56/57(98%)이에요. 세 회차가 완전히 같은 선지는 42개예요.
- **제 검토로 종류가 맞은 선지: 56/57(98%).** 새 지문 검증(91%)보다 높아요. 이번 6지문은 목록을 만들 때 본 지문이라 높게 나오는 게 자연스러워요.
- **형식 위반 3건:** 모두 인용 글자가 조금 어긋난 경우예요(각주 표시 `*` 누락 등). 연결 자체는 맞았어요.
- 다듬은 정의는 효과가 있었어요. 예를 들어 "글에 없는 서술 방식"은 이제 정보 비대칭 10번(글의 서술 방식 묻는 문항)에만 쓰였어요. 맞춰 보기에서처럼 "처리 절차"에 잘못 붙는 일은 없었어요.

예를 하나 볼게요. 손으로 분류한 것보다 모델이 더 정확했던 경우예요.

> 표면 장력 지문: "공기가 압력이 높은 곳에서 낮은 곳으로 이동하기 때문이다."
> 선지(15번 ③): 접해 있는 두 기포 간에 공기의 이동이 이루어지는 것은 두 기포 내부의 압력이 동일하기 때문이다.
> 제 초안: 긍정·부정 뒤집기 → 모델 ×3: **원인·근거 바꿔치기** ("이동의 원인인 압력 차이를 압력 동일로")

이 선지는 "~때문이다"의 이유 자리를 바꾼 것이라, 피드백으로는 "원인을 바꿨어"가 더 정확해요.

### 3) 다음 스텝

1. **세 회차를 하나의 골드로 확정할 방법 결정 (판단 필요).** 본문 3)에 적었어요.
2. 확정 결과로 피드백 비교 실험을 준비해요. 이건 별도 설계가 필요해요.
3. 지금까지 작업(v4·v5)을 커밋해요(승인 필요).

## 2. 본문

### 1) 회차마다 다른 종류를 고른 1개 (미해결, 확정 때 해결)

> 도파민 지문: "다만 모든 도파민성 뉴런에 DAT가 있는 것은 아니기 때문에 DAT가 없는 도파민성 뉴런에서 분비된 도파민은 뉴런 밖에서 분해된다."
> 선지(10번 ④): 도파민성 뉴런에서 분비된 도파민 중 도파민 수용체에 결합하지 않은 것은 **모두** 뉴런 밖에서 분해된다.
> 모델: 전칭·절대화 / 조건 옮기기 / 적용 범위 넓히기 (회차마다 다름)

세 이름 모두 "일부를 전체로 넓혔다"는 점은 같게 봤어요. 하지만 "모두"라는 한정어를 바꾼 것이니 **전칭·절대화**가 맞아요. 확정할 때 이 회차를 고르면 돼요.

### 2) 형식 위반 3건 (해결 가능)

| 위치 | 내용 |
|---|---|
| 법인 13번 ② 2회차 | 원문 "정관*이나"에서 각주 표시 `*`를 빼고 인용 |
| 법인 12번 ① 3회차 | 원문과 정확히 일치하지 않는 인용 (1·2회차는 정확) |
| mRNA 16번 ③ 3회차 | 선지에서 바뀐 부분을 조각 범위보다 길게 잡음 |

셋 다 다른 회차에는 정상 결과가 있어요. 확정할 때 위반 없는 회차를 고르면 사라져요.

### 3) 세 회차를 하나로 확정하는 방법 (판단 필요)

지금은 선지마다 세 회차 결과가 따로 있어요. 골드는 한 벌이어야 하니 하나로 정해야 해요. 법인 10번 ③을 예로 들게요.

> 선지: 주식회사의 자본금과 재단 법인의 기본 재산은 어떠한 경우에도 감액이 금지되어 있다.
> 1·2·3회차 모두: 전칭·절대화, 바뀐 곳 P4-6·P2-13

이런 선지(42개)는 고민할 게 없어요. 회차마다 바뀐 곳이 이웃 문장으로 갈린 선지(11개)가 문제예요.

| 방안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (추천)** | **선지마다 대표 회차를 골라요.** 조건은 다수 종류와 같고, 세 회차가 공통으로 짚은 곳을 포함하고, 위반이 없는 회차예요. 다른 회차가 짚은 이웃 문장은 "대안 위치"로 따로 남겨요. | 선지마다 가장 믿을 만한 결과를 써요. 코드로 자동 처리하고, 제가 손볼 건 도파민 10번 ④ 하나예요. | 한 지문 안에 여러 회차 결과가 섞여요(선지 단위라 문제는 없어요). |
| B | 회차 하나를 통째로 골라요. | 가장 단순해요. | 어느 회차를 골라도 몇 선지는 소수 의견이 들어가요. |
| C | 선지 안의 조각까지 회차별로 합쳐요. | 가장 정밀해요. | 회차마다 조각을 나눈 방식이 달라 합치는 규칙이 복잡해요. |

**추천은 A예요.** 회차 간 다수결의 장점을 살리면서 규칙이 단순해요.
