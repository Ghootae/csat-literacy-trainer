## 추가 출처 확인

Cools & D’Esposito 2011, https://pubmed.ncbi.nlm.nih.gov/21531388/ , DOI 10.1016/j.biopsych.2011.03.028. 공개 초록·도식 설명 확인. 역 U자, baseline 의존 및 인지 과정/뇌 영역별 차이를 뒷받침. 약물의 모든 개인별 반응을 단일 함수로 확정하는 근거 아님. Mehta·Daniels·Volkow·Farah 원문 전체를 이번에 새로 재검증했다고 주장하지 않음.

## 관찰 / 평가 / 제안

1. 정상 기능 ‘범위’, 진단 삭제, 시냅스 틈, Mehta 관측 변수 명칭, ㉰ 과정 평가로의 축소는 개선. Mehta 소개 문장 자체의 v2 문제는 해소. 이후 ‘평소 상태가 낮음’은 여전히 변수 불명.
2. 3문단 ‘기능 차이는 작고 약물 이익도 크게 다르지 않을 것’은 실측 단정에서 추정으로 바뀌었을 뿐, 추론 근거 부족. 역 U자에서 유사 수행은 유사 도파민 상태/반응의 충분조건이 아님. 반대쪽 상태 가능. 두 사람의 효과도 유사하다는 사고 실험 조건으로 명시 권고. 그런 사례가 불가능하다고 주장하는 것이 아님.
3. 새 ㉯①의 반응 차이→상태 차이는 가능한 해석이나, →정상 기능 경계 양쪽에 위치→경계 유효성→차등 접근 정당화는 성립하지 않음. 두 사람이 모두 정상 범위 안에 있을 가능성을 배제하지 않음. ㉮는 개인차를 부정하지 않아 상태 차이 확인만으로는 반박되지 않음. 특정 입장에 귀속된 논증이 논쟁적일 수는 있으나, 신뢰할 판정 원리로 쓰려면 본문 내 근거가 필요.
4. 권고 A: ㉯①은 모호한 경계 사례/명백한 기능 손상의 구별이라는 제한적 반박으로 복원. ㉯②에 기초 상태별 효과 차이·부정적 효과 가능성 활용. 대안 B: 반응 기반 분류로 입장 재설계(더 큰 변화). 둘 다 미채택.
5. 2문단 낮은 기초 신호+증가→적정 접근은 증가 폭 조건 필요. 과량이면 넘을 수 있음. ‘적정에 가까워지는 경우/지나치게 넘는 경우’ 조건문 권고. 역 U자를 설명으로 표지하는 것만으로 설명을 벗어난 함의가 참이 되지 않음. 인지 수행 전체보다 작업 기억 등 범위 제한 권고.
6. ㉰는 귀속에서 노력 평가로 바뀌어 논리 연결 개선. 특정 입장의 규범으로 적절히 귀속. 같은 결과만으로 출발 어려움은 통제되지 않음. 가상 수치 10→7 대 비복용 3은 비교 논리 반례이며 실제 심리 척도/연구 결과 아님. ‘복용=덜 노력’ 선지에는 기준상 실제 어려움이나 비교 조건이 필요.
7. 독서실·강의도 어려움 감소→동일 판정은 기준의 일관된 적용/함의이지 자동 반례 아님. 반박에는 추가 평가 전제 및 동등한 조건 필요. 지루함·이해 난도 등 어려움 종류도 구분해야 함.
8. 예상 고리 ‘②만 너무 강해도 수행 감소와 연결’은 현 본문과 불일치. ①도 낮은 신호/적정 상태 반응 차이에서 출발. A 수정 후 논거 역할 분리 가능.
9. 관측/기전 오귀속 선지는 가능하나, 본문에서 보고한 것과 실제 연구가 전혀 측정하지 않은 것을 구별. 현 본문은 연구 방법을 전부 제시하지 않으므로 실제 측정 부재를 외부 지식으로 요구하지 말 것. ‘본문이 보고한 결과’에 범위를 한정하거나 검증된 방법을 명시해야 함.
10. 재흡수 기전은 도파민 증가에 대한 배경 근거가 됨. 그러나 운반체 차단 세부를 삭제·대체해도 윤리 판단이 같다면 세부 기전이 필수 추론 자원인 것은 아님. 모든 배경 문장이 필수여야 한다는 과도한 기준은 권하지 않음.
11. 규칙 W15(출처의 관측 범위), W16(연결표-본문 일치), W17(개념 일관성)은 유용. 점검 질문에 역추론·규범적 도약·사고 실험 가정을 추가 권고. 채택된 정책으로 기록하지 않음.
12. W14(구조 모방 방지)의 생성 과정 독립성은 문항 품질/사용자 선호와 다름. 생성 기록과 원본 대비가 필요하며 이번에는 미검증.
