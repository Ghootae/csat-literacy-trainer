## 의뢰 조건 (W1)
- 분야: 뇌과학 / 융합 필수 / 글 유형: 관점 대립형
- 문항 2개: 고난도 〈보기〉 적용 1 + 쉬운 입장 이해 1
- 제외: 기존 지문과 겹치는 주제 (뇌 과학과 법, 트롤리 딜레마 fMRI, 분리 뇌, 창의성과 뇌, 언어 습득, 기억 저장)

## 추천: C
- 같은 편 쪼개기와 배경 고리가 둘 다 자연스럽게 서고, 둘이 서로 엮인다 (기저 의존 효과 → 공정성 반대가 약해지는 조건).
- 도파민 지문(은행)과 같은 개념을 쓰지만 질문이 다르다 (기전 이해 → 사회적 판단).
- 위험: 기전 사실(역U 곡선, 기저 의존)은 연구마다 결과가 갈림. 지문에서 "일부 연구에 따르면" 수준으로 써야 하고 출처 대조 필수.
