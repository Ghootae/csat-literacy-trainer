# API 생성 지문과 v3 비교 — 인간 보고서

2026-11-13. 사용자 메시지의 새 5문단과 앞선 v3를 비교했다. API 생성 조건·모델·프롬프트·반복 결과는 제공되지 않아 생성 방식의 우열은 평가하지 않는다. 새 문항 생성과 학생 검증은 하지 않았다.

## 1. 개요

**정답 근거의 안정성은 새 지문이 더 좋다. 다만 수능 독서 지문으로서의 자연스러운 논증보다 조건 적용용 규칙표에 가까워진 면이 있다.** 다음 수정의 바탕으로는 새 지문을 권하지만, 현재 문장을 그대로 최종본으로 삼는 것은 권하지 않는다.

이번 글은 v3의 단순한 문장 수정이 아니다. 정상 기능·치료/향상·노력 가치의 논쟁에서, 안전·정보·직접 선택을 전제한 약물 허용 제도의 논쟁으로 쟁점을 바꿨다. 이전 결함 상당수는 같은 문제를 해결했다기보다 해당 쟁점을 다루지 않게 되어 사라졌다.

| 항목 | v3 | 새 지문 |
|---|---|---|
| 개념 일관성 | 기능·도파민 수준의 혼용이 남음 | 개인 내 수행/경쟁상 지위를 구별해 개선 |
| 논증의 안정성 | 상태 차이→분류 경계 정당화 비약 | 개인의 이익과 타인의 기회 감소가 연결됨 |
| 과학 표현 | 낮은 신호→개선의 조건이 불충분 | 일부 과제·평균 효과·개인차로 범위를 제한 |
| 사례 적용 근거 | 해석을 보충할 부분이 많음 | 명시적 조건이 많아 비교적 안정적 |
| 지문 전개 | 철학적 쟁점이 넓지만 연결이 약함 | 쟁점은 집중됐으나 규정 나열·반복이 많음 |
| 문항 깊이 | 비약을 깊이로 오인할 위험 | 조건 개수를 깊이로 오인할 위험 |

## 2. 본문

### 가장 큰 개선: 개인의 개선과 경쟁에서의 불이익을 분리했다 (해결)

> 자신의 점수가 그대로여도 다른 사람의 점수가 달라지면 자신의 순위와 선발 가능성이 바뀔 수 있다.

이 구별은 글 전체에서 실제로 사용된다. ㉮는 충분한 정보에 따른 직접 선택, ㉯는 실질적인 이용 기회, ㉰는 비사용자의 선발 기회를 판단 기준으로 삼는다. 특히 ‘모두 이용할 수 있다’가 ‘이용하지 않아도 불이익이 없다’를 뜻하지 않는다는 연결이 좋다. 이전의 반응 차이로 치료/향상 경계를 정당화하던 논거보다 명료하다.

본문 사례에서는 세 입장의 결론도 분명하다. ㉮·㉯는 허용하고 ㉰는 불허한다. 다만 이 사례만으로는 ㉮·㉯의 차이를 시험하지 못하므로 후속 문항에서는 접근 조건을 바꾼 사례가 필요하다.

### 과학 사실과 가정의 구분은 좋아졌다 (개선)

일부 과제의 평균 효과를 말하고, 실제 선발 상황의 점수 상승은 별도의 가정으로 제시했다. 실험실 과제의 결과에서 입시 점수 상승을 곧바로 도출하지 않은 점이 좋다. 제한된 기간의 무위해성도 현실 사실이 아니라 논쟁 범위를 좁히는 가정으로 명시했다.

처방 자극제가 건강한 사람의 억제 조절 등 일부 기능에서 작은 평균 개선을 보였다는 표현은 Ilieva 등(2015)의 메타분석 초록과 부합한다. 이 연구는 메틸페니데이트와 암페타민을 다루므로 바로 앞의 단일 약물 기전과 연구 종합의 범위를 구별해야 한다. [논문 초록](https://pubmed.ncbi.nlm.nih.gov/25591060/)

이번 글의 전체 사실 출처 목록은 제공되지 않았으므로 모든 문장의 원자료 대응을 검증한 것은 아니다. 세포 밖 도파민 증가와 ‘작용 강도’를 직접 같은 측정값으로 읽게 하지 않는 편이 좋다. 과제 이름인 ‘반응 억제’는 짧게 풀어 쓰면 접근성이 좋아진다.

### 명료해진 대신 조건표 대조로 풀릴 위험이 커졌다 (판단 필요)

㉯는 ‘매 평가마다 약물·상담·개인별 효과 확인을 동일한 무료 조건으로 제공’이라는 목록을, ㉰는 ‘점수 사전 공표·정원 무제한·기준 상향 금지’라는 목록을 제시한다. 이러한 조건은 채점하기 좋다. 하지만 조건을 하나씩 빼는 보기만 만들면 독자는 논증을 이해하지 않고도 정답을 찾을 수 있다.

수능형 깊이는 조건 수가 아니라, 사례의 표현을 본문의 개념으로 바꾸고 여러 관계를 연결해야 하는 데서 생긴다. 비교 기준은 앞선 보고서에서 확인한 2024학년도 6월 평가원 확장 인지 지문의 정의 적용, 2026학년도 수능 인격 동일성 지문의 부분 동의/반박 구조다. 이번에 새 기출 표본 조사는 하지 않았다.

㉯에서 왜 약물뿐 아니라 효과 확인도 보장해야 하는지의 설명은 유지할 가치가 있다. 반면 ‘매 평가마다’, ‘무료’라는 세부 형식이 왜 유일한 기준인지까지는 설명되지 않는다. 이는 그 입장이 특별히 채택한 정책일 수 있지만 동등 접근의 개념 자체에서 필연적으로 나오는 것은 아니다.

### ㉰의 세 절차는 비사용권의 유일한 구현인가 (미해결)

> 다음 세 조건을 모두 충족할 때만 사용을 허용한다.

고정된 절대 기준과 인원 제한 없는 통과 방식은, 제시된 가정 아래 사용자의 점수 상승 때문에 비사용자의 통과 여부가 바뀌는 일을 막는다. 그러나 비사용자의 기회를 보호하는 제도가 반드시 이 세 절차 하나뿐이어야 한다는 근거는 없다. 별도 선발 등의 대안이 성공하는지는 추가 설계에 달렸지만, 적어도 본문이 모든 대안을 배제한 것은 아니다.

입장이 강한 정책을 채택하는 것 자체가 논리 오류는 아니다. 문제는 ‘비사용권을 보호해야 한다’라는 원칙과 ‘세 절차를 갖춘 제도에서만 허용한다’라는 특정 정책 선택 사이의 설명이 부족하다는 것이다. 결론도 그 평가에서의 통과 기회 보호로 한정해야 한다. 이후 취업·자격 경쟁 전체의 불이익까지 사라진다는 뜻은 아니다.

| 방안 | 효과 | 권고 |
|---|---|---|
| 현재 목록 유지 | 명료한 제도 규칙 적용 문항을 만들기 좋음 | 규칙 적용 실험 목적이면 가능 |
| 원칙을 제시하고 세 조건을 구현 사례로 배치 | 왜 그런 제도가 필요한지 추론할 여지가 생김 | 수능 독서 지문 목적이면 권고 |

원칙 중심의 예시: ‘이 입장은 다른 사람의 약물 사용이 비사용자의 통과 기회를 낮추지 않는 평가에서 사용을 허용할 수 있다고 본다. 이를 구현하는 방안으로, 약물 도입 전 정한 기준을 유지하고 그 기준을 넘은 사람을 인원 제한 없이 통과시키는 방식을 제안한다.’ 이는 논지 재설계 제안이며 현재 본문의 의미와 완전히 같은 문장으로 취급하면 안 된다.

형식적 문제도 하나 있다. ‘충족할 때만 허용’은 필요조건을 명시한다. 모든 조건을 충족한 새 사례에서 반드시 허용한다는 답을 요구하려면, 그 조건이 충분하기도 하다는 점을 밝혀야 한다. 현재 상대평가 사례의 불허 결론에는 이 문제가 없다.

### 세 입장은 단순한 단계적 강화가 아니다 (판단 필요)

㉰는 ㉯의 무료 접근 조건을 계승한다고 쓰지 않았다. 따라서 ‘㉮ 조건+접근 조건=㉯, 여기에 비사용권 조건 추가=㉰’라는 표를 만들면 본문보다 강해진다.

공통 전제가 충족된 경우에 한해, 무료 접근이 부족하면 ㉯는 불허한다. 비사용자 통과 기회가 보호되는지 여부는 별도의 축이다. ㉰가 그 경우 반드시 허용하는지는 위 필요/충분조건 문제를 먼저 정리해야 한다. 이 두 축을 교차한 보기는 한 조건씩 삭제하는 보기보다 유망하다.

또한 ㉮의 ‘제재 없음’과 ㉰의 ‘경쟁 압박’은 모순이 아니다. 전자는 기관이 비사용을 이유로 별도로 부과하는 벌칙, 후자는 다른 응시자의 성적 변화가 만드는 불이익으로 읽을 수 있다. 이 구별을 명확히 하면 좋은 출제 자원이 된다.

### 반복을 줄일 여지가 크다 (미해결)

2문단에서 무료 접근의 세 항목과 상대평가 사례를 모두 제시한 뒤, 4문단에서 세 항목을 다시 열거한다. 각 입장 끝에서는 앞 사례의 허용/불허까지 알려 준다. 설명문으로는 친절하지만 독해 시험에서는 판단을 대신해 주는 분량이 크다.

권고는 2문단에는 공통 전제와 개인/경쟁 구별만 두고, 구체 사례는 입장 설명 뒤나 문항의 보기로 옮기는 것이다. 본문에 예시를 유지해도 되지만 세 입장의 적용 결론을 모두 반복할 필요는 없다. 과학 기전은 여전히 배경 역할이 크므로, 윤리 문항에 더 연결하려고 내용을 추가하지 말고 간결하게 유지하는 편이 낫다.

보고서 두 파일만 추가했다. 원문·생성기·규칙·기존 미커밋 보고서는 변경하지 않았다. 단일 결과만으로 API 방식이 이전 방식보다 우수하다고 결론 내리지 않는다. 세션은 계속을 권한다.
