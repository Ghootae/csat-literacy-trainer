# 도파민 지도 3회 비교와 동결 권고 (Claude)

1단계 산출물(`MAPS.md`, `runs/`) 비교. 사실(구조 대조)과 Claude 의견(권고)을 나눠 적는다. 동결 선택은 사용자가 한다([D-0146](../../../memory/decisions/D-0146-analysis-map-dopamine-generalization.md)).

## 1. 통과 기준 ① 판정

기준: 3회 모두 구조 검증 6항목 통과, 문단 요지와 문단 안 큰 묶음이 3회 중 2회 이상 같음.

- 검증 6항목: r1·r2·r3 모두 통과. 비용 $0.4060.
- 큰 묶음: 네 문단 모두 r1과 r3가 같거나(p1·p2·p3) 한 묶음만 둘로 나뉜 차이(p4)다. **기준 통과.**

## 2. 구조 대조 (사실)

| 문단 | 명제 수 r1/r2/r3 | 묶음 | 판단 |
|---|---|---|---|
| X·TOP | – | 세 번 모두 X1 = 1·2문단(도파민 합성·수용체·조절), X2 = 3·4문단(운동 경로와 도파민) | 안정 |
| p1 | 17/17/17 | r1 = r3: 기능·합성 장소 / 섭취 도파민 불통과 / 시냅스 전·후 / 합성 경로 / 저장·분비·결합. r2는 앞의 두 묶음을 하나로 합침 | 안정 |
| p2 | 14/17/14 | r1 = r3: D1·D2 구분 / 자가 수용체 / DAT 재흡수 / DAT 없는 뉴런. r2는 명제를 더 잘게 나누고 D2 위치를 D1·D2 구분 묶음에 넣음 | 안정 |
| p3 | 17/19/17 | r1 = r3: 수의적 운동·두 경로 / 가바성 뉴런 / 직접 경로(선조체→창백핵 억제, 시상→운동 시작 두 단계) / 간접 경로. r2는 앞의 두 묶음을 합침 | 안정 |
| p4 | 8/8/8 | r1: 연결 / 수용체 배치 / 효과. r3: 효과를 "직접 활성·간접 억제"와 "운동 촉진"으로 나눔. r2: 연결+배치를 합침 | 거의 안정 |

공손룡과 비교: 공손룡은 5문단 중 3문단이 세 번 같았고 p5 묶음이 세 번 모두 달랐다. 도파민은 네 문단 모두 두 회차(r1·r3)가 같거나 거의 같다. r2는 세 문단에서 묶음을 더 크게 잡는 쪽으로 일관되게 달랐다.

## 3. 동결 권고 (Claude 의견)

**r3를 수정 없이 동결.**

- r1과 r3는 p4 하나만 다르다. r3는 "도파민이 직접 경로를 활성화하고 간접 경로를 억제한다"(기제)와 "그래서 운동 시작이 수월해져 운동을 촉진한다"(결과)를 따로 둔다. 학생이 결과(운동 촉진)만 말하고 기제를 놓쳤는지, 기제를 거꾸로 말했는지(시험 응답 E11 "두 경로 모두 활성화")를 노드로 갈라 볼 수 있다.
- 수정이 없으면 관계 선과 충돌할 일이 없다(공손룡에서 수정 권고를 접은 이유).

대안: r1 그대로(p4 효과 묶음 하나). r2는 묶음이 커서 판정 해상도가 낮다.
