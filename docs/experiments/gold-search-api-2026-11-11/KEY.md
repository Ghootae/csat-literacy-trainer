## 웹 스레드 메모

- API 쪽 2단계(모델 선별)는 very good #2·#3·#4와 같은 진술을 골랐고, #1(무상 증자에 주주 총회 필요) 대신 감액 금지 절대화(good #10형)를 골랐다. 사람 선별과 4개 중 3개 일치.
- API 〈보기〉는 용어 풀어쓰기가 더 철저하다: 주식→'증서', 액면가→'한 장당 기재 금액', 주식회사→'돈을 낸 사람들의 모임이 별도 법적 주체'. 학생이 옮길 단계가 하나씩 더 많다.
- 반대로 API 선지는 옮기기를 대신 해 주는 곳이 있다: 가⑤ '…곱해 기록한 몫인 자본금', 가③ '이익 잉여금의 활용 범위', 다⑤ '감액이 금지되는 자본금'. 〈보기〉에서 숨긴 용어를 선지가 다시 알려 줘서 깊이가 깎일 수 있다.
- API는 법인격·권한(1~3문단) 선지도 넣어 덮는 범위가 넓다(가①, 다①). 다만 다①은 '결정권 ↔ 법적 통제' 한 구절 확인이라 얕아 보인다.
- 다의 〈보기〉는 '현금 배당을 임원 회의에서만 확정하려 한다'를 미리 깔아 두어, 정답 ④를 〈보기〉가 직접 부른다. 독립 풀이에서 지문 요건과 어긋나는 계획이라는 지적이 있었다(요건을 어기는 계획을 서술한 것이라 성립은 함).
- 다와 라는 같은 착각(#3형)을 정답으로 썼다. 같은 재료에서 두 방식이 같은 정답 지점을 고른 셈.
- 비용: API 약 12분, 입력 28.8k·출력 39.1k 토큰(첫 시도 시간 초과 3회분은 별도로 과금됐을 가능성).
