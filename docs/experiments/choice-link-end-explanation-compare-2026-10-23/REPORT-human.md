# 마지막 설명 좌표 비교 실험 — 인간 보고서

## 1. 개요

### 1) 작업의 목적

선지 지도(비튼 방식, 근거 원문)를 튜터에게 주면 마지막 설명이 좋아지는지 확인했어요. 같은 42개 가상 세션에서 두 설명을 비교했어요.

- 기존 설명: 지금 v5가 실제로 썼던 설명(지난 시험 출력 재사용)
- 지도 설명: 같은 상황에 지도를 더해 새로 만든 설명

### 2) 작업의 결과

- 비용은 **$0.58**이에요. 42건 중 41건을 받았고, 1건은 서버 과부하로 응답이 없었어요.
- 제 블라인드 판정은 **지도 설명 우세 35, 기존 우세 1, 비슷 5**(41쌍)예요.
- 안전 기준
  - 학생 생각 단정: 0건
  - 형식 위반: 0건
  - 원문과 어긋난 표현: 지도 설명 쪽 1건

차이는 대부분 지도 설명이 덧붙인 두 문장에서 나왔어요.

> 도파민 지문 ②: "(나)는 효소의 작용을 억제하여 흑질에서 합성된 도파민의 작용 기간을 연장할 수 있겠군."
>
> **기존 설명:** "…카르비도파가 억제하는 것은 레보도파를 도파민으로 합성하는 효소의 작용이야. 이미 합성된 도파민의 분해를 막는 작용이 아니므로, 이를 근거로 도파민의 작용 기간이 길어진다고 볼 수는 없어."
>
> **지도 설명:** "(같은 설명) … **②는 약물이 작용하는 범위를 흑질까지 넓히고, 원문에 없는 작용까지 덧붙였어. 이런 선지는 약물이 어디에서 작용하고 어떤 효소를 억제하는지 각각 확인하면 걸러낼 수 있어.**"

### 3) 다음 스텝

1. **사용자 판정 6쌍 (판단 필요).** 제 판정에는 약점이 있어요. 가린 조건이 사실상 드러났어요(본문 2). 그래서 직접 봐 주시는 게 꼭 필요해요.
2. 제 판정과 맞으면 운영 v5의 마지막 설명에 지도를 넣는 반영안을 설계해요.

## 2. 본문

### 1) 지도를 넣어도 위험한 일은 생기지 않았어요 (해결)

가장 걱정했던 건 "너도 방향을 거꾸로 생각했지?" 같은 학생 생각 단정이었어요. 41쌍 모두에서 없었어요.

> 표면 장력 ⑤를 근거 없이 고른 학생
> **지도 설명:** "⑤를 고른 이유는 확인할 수 없어서, 선지 내용과 원문을 비교해 볼게. … ⑤는 수가 커지는 상황에, 수가 너무 작을 때 생기는 '위성 잉크 방울'을 연결한 게 문제야."

선지에 대한 사실로만 말하고 학생 생각은 추측하지 않았어요.

원문과 어긋난 표현은 1건 있었어요. 정답·근거 약함 세션(luna)에서 지도 설명이 "오네소르게 수가 점도에 **비례**하고"라고 썼어요. 원문은 "점도가 **클수록 크고**"예요. 지도에 준 원문 문장은 정확했으니 지도 탓은 아니고 luna의 실수로 봐요. 그래도 반영할 때 이 금지 규칙을 한 번 더 강조할게요.

### 2) 제 판정의 약점: 어느 쪽이 지도 설명인지 거의 보였어요 (판단 필요)

지도 설명에는 "이런 선지는 …확인하면 걸러낼 수 있어"라는 문장이 거의 늘 붙어요(41개 중 34개). 기존 설명에는 한 번도 없었어요. 그래서 가려도 조건이 드러났고, 제 "우세" 판정도 이 문장이 있느냐와 거의 겹쳐요.

결국 판정의 핵심 질문은 이거예요. **이 두 문장(어떻게 바꿨는지, 어떻게 걸러내는지)이 학생에게 도움이 되나요?**

제 의견은 "도움이 된다"예요. 다만 아래처럼 너무 일반적인 경우도 있어요.

> "이런 선지를 볼 때는 자산 운용 권한의 근거가 무엇인지, 법인격을 부여받는 대상이 누구인지 각각 확인하면 돼."

→ 이 문제에만 맞는 말이라, 다른 문제에 옮겨 쓸 요령으로는 약해요.

그래서 6쌍을 직접 판정해 주시면 좋겠어요.

- **파일:** `docs/experiments/choice-link-end-explanation-compare-2026-10-23/run/USER-PAIRS.md`
- **판정 방법:** 쌍마다 설명 X·Y를 읽고, 판정표에 "더 도움이 되는 쪽(X/Y/비슷)"만 적어도 충분해요. 이유는 한 줄이면 돼요.
- **포함된 세션:** 오답 5쌍(근거 막연 2쌍 포함), 정답 1쌍
- 제 판정은 일부러 보여 드리지 않았어요. 판정해 주시면 맞춰 볼게요.

## 4. 전체 41쌍 판정 결과 (추가)

"이해가 잘 되는가"를 기준으로 41쌍을 판정해 주신 결과예요.

- 지도 설명 20, 기존 설명 18, 비슷 3이에요. **차이가 없어요.**
- 왼쪽·오른쪽 쏠림도 없었어요(X 18, Y 20).
- 판정을 가른 건 지도가 아니라 쓰는 방식이었어요. 많이 꼽힌 이유는 문단 나눔(9), 결론을 분명히 닫기(6), 함정을 한 문장으로 짚기(6), 간결함(6)이에요.
- 제 판정과의 일치는 20/41로, 우연 수준이에요. 이해 용이성은 제가 대신 판정하기 어렵다는 뜻이에요.

**결론:** 지도는 운영 v5에 넣지 않아요. 대신 이유들에서 마지막 설명을 더 이해하기 쉽게 만드는 규칙 후보가 나왔어요.
