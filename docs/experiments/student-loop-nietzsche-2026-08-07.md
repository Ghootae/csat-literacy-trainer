## 골드

문장 7 / 명제 12 / 합성 노드 4 / 슬롯 3(`c3`·`c6`·`p12`) / 평가 영역 3 · 질의 11.

```
r1  니체: 삶이 가치의 근원이자 가치 평가의 기준            S1~S2   ★q2 ★q3
r2  전통 형이상학: 삶을 도덕적 선의 수단으로 삼아 …         S3~S6   ★q6 ★q7
r3  니체의 비판: 삶은 그 자체로 목적이며 …                 S7      ★q10
```

## 사이클

학생은 구조화 섹션 인터페이스(§2.1)로 3개 섹션을 썼다.

| | 섹션 1 | 섹션 2 | 섹션 3 |
|---|---|---|---|
| **v1** | 니체가 보는 삶과 가치의 관계 | 전통 형이상학은 도덕적 선을 절대적으로 봄 | 니체는 형이상학에 반대함 |
| **v2** | 〃 | 〃 | 니체는 **삶을 수단으로 간주하는** 형이상학의 사유에 반대함 |
| **v3** | 〃 | 〃 | 니체는 형이상학에 반대함 (되돌림) |

**v1 → v2는 학생이 §2.1대로 영역 하나(r3)를 골라 다듬은 것이고, v2 → v3은 강등을 강제로
만들기 위해 구성한 삭제 케이스다.**

```
              v1          v2            v3
r1  S1~S2     ○ 주제만  →  ○ 주제만   →  ○ 주제만      불변
r2  S3~S6     ○ 주제만  →  ◐ 부분관계  →  ○ 주제만      ↑ 그리고 ↓
r3  S7        ○ 주제만  →  ● 관계보존  →  ○ 주제만      ↑ 그리고 ↓
```

## 발견

### 1. 한 섹션 수정이 다른 영역을 **정당하게** 움직인다

`v1 → v2`에서 학생은 **섹션 3만** 고쳤는데 `r2`가 `주제만 → 부분관계`로 올랐다.
섹션 3에 들어온 *"삶을 수단으로 간주하는 형이상학"*이 `r2`의 관계 질의를 충족했기 때문이다.
섹션 2 텍스트는 한 글자도 바뀌지 않았다.

**부분 재평가였다면 `r2`는 `주제만`으로 남았다** — 학생이 실제로 쓴 내용에 대해 더 낮은
평가를 받는다. 부분 재평가의 위험으로 예상했던 "한 섹션이 여러 영역을 뒷받침한다"가
첫 사이클에서 바로 재현됐고, 방향은 학생에게 유리한 쪽이었다.

### 2. 강등도 전부 설명됐다 — **부당한 강등 0건**

`v2 → v3`에서 `r2`·`r3`가 함께 내려갔다. 지워진 *"삶을 수단으로 간주하는"*이 두 영역을
모두 받치고 있었으므로 정확한 판정이다.

건드리지 않은 `r1`은 **세 번 내내 불변**이었다. 편집이 증거를 건드리지 않은 영역에서
판정만 흔들리는 일(= 단조 유지가 막으려던 것)은 **한 번도 일어나지 않았다.**

뒷받침: 3축 실험의 `regionSemanticVerdict` 반복 안정성 100%(`query-3axis-2026-07-25.log`).

> **⚠ 정정 (2026-08-08).** 이 뒷받침은 **틀렸다.** 100%는 법인 문단 하나에 손 질의로 잰 값인데
> 니체 문단의 자동 생성 질의에 적용했다. 측정해 보니 영역 판정이 2/9에서 갈렸다
> (`repeat-stability-nietzsche-2026-08-08.md`). **부당한 강등은 실재한다** — 아래 "발견 2"의
> "0건"은 이 실행에서 관찰되지 않았다는 뜻일 뿐, 일어나지 않는다는 뜻이 아니다.
> §2.1은 그에 따라 개정됐다(겨냥한 영역만 정직하게 표시).
그리고 구조화 섹션 UI가 편집을 국소화한다 — 다른 영역이 영향받으려면 **고친 섹션이 그 영역을
실제로 뒷받침하고 있었어야** 하고, 그때의 변화는 정당하다.

### 3. 단조 유지는 화면이 답안과 어긋나게 만든다

`v3`에 단조 유지를 적용하면 `r3`는 `max(○, ●, ○) = ●`이므로 **관계보존 + 정답 + 명제 공개**가
뜬다. 그런데 학생 답안에는 그 내용이 없다.

```
화면   "삶을 수단화하는 사유에 반대하는 관계를 잘 포착했습니다" ●
답안   "니체는 형이상학에 반대함"
```

정독 훈련에서 학생이 **"내 답안이 이걸 담고 있다"고 잘못 배운다.**

역으로 **강등을 보여주는 것이 학습적이다** — 칸이 나뉘어 있으면 "섹션 = 독립된 답"으로
착각하기 쉬운데, 3번을 고쳐 2번이 내려가는 것을 보면 요약이 하나로 연결된 글임을 배운다.

## 결정

| | |
|---|---|
| 재평가 범위 | **전체 응답 · 전체 질의** |
| 판정값 표시 | **그대로** (단조 유지 없음) |
| 직전 결과 | 보관 — 변화 알림용 |
| 상승/강등 | `○ → ●` 축하 / "이전에 있던 내용이 빠졌어요" 사유 표시 |

`evaluateQueries`는 질의 개수와 무관하게 1회 호출이므로 **부분 재평가는 비용을 아끼지 못한다.**
반면 새 모순을 놓쳐 하드 게이트가 조용히 실패한다.

## 부수 관찰 (미결 등록)

### 관계 서술어가 있는데 `주제만`이 나왔다

`v1` 섹션 3 *"니체는 형이상학에 반대함"* — **"반대함"이라는 관계 서술어가 있는데** `주제만`이다.

`q10`이 두 가지를 요구하기 때문이다: *"니체는 삶을 **어떻게 규정하며**, **무엇에 반대하는가**?
그 **대조 관계**는?"*. 학생은 "반대한다"만 썼고 **삶=목적 vs 삶=수단의 대조**가 없다.

판정은 기준대로다. 다만 **학생 입장에서는 "관계를 썼는데 왜 주제만이지?"** 싶을 수 있다.
힌트 문구가 그 간극을 메우는지 실제 학생 테스트에서 확인할 대상이다.

### 표본이 작다

수정 2회 · 문단 1개다. "부당한 강등이 없다"를 단정하기엔 이르다.
**부당한 강등을 관찰 대상으로 등록**하고, 실제로 나오면 그때 단조 유지를 도입한다.
