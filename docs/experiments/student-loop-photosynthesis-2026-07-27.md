## P3 — 암반응 / 캘빈 회로 (순환형)

손 영역 구성 (오라클 양식):

| 영역 | label | scope | relation(critical) | argument |

| `dark_reaction` | 암반응의 투입과 산출 | 무엇에 관한 부분인가 | 명반응의 화학에너지 + 흡수한 CO₂ → 포도당(부산물 물) | — |
| `calvin_cycle` | 캘빈 회로의 순환 | 〃 | CO₂가 RuBP와 결합(루비스코 촉진)해 3탄당이 되고, 3탄당이 포도당이 되며 **남은 화합물이 RuBP로 재생되어 결합이 다시 진행**된다 | 루비스코=촉매, 3탄당=탄소 3개 |

### 경로 A — 관계보존

> 학생: "암반응은 명반응이 만든 화학 에너지와 기공으로 흡수한 이산화 탄소로 포도당을 만드는
> 단계다. 이산화 탄소가 RuBP와 결합해 3탄당이 되고, 3탄당이 포도당이 되며 남은 화합물은
> 다시 RuBP로 돌아가 이 과정이 반복된다. 이렇게 광합성하는 대부분의 식물을 C3 식물이라 한다."

| 영역 | 판정 |
|------|------|
| dark_reaction | 관계보존 |
| calvin_cycle | **관계보존** (되먹임 명시) |
| cycle_condition | 미포착 |
| c3_naming | 관계보존 |

`buildFeedback`(relation_preserved 분기)을 그대로 돌리면:

> 핵심 관계 「CO₂가 RuBP와 결합해 3탄당이 되고 … 다시 진행된다」를 잘 포착했습니다.
> 원문에는 **루비스코 촉매, 3탄당의 탄소 수, 물이 부산물, CO₂ 농도 조건, 적정 온도 조건,
> 결합률 저하, 효율 저하**도 제시됩니다 (참고 — 더 구체적으로 표현할 수 있으나 감점 요소는
> 아닙니다).

→ **N1(아래) 발생.** 참고 세부가 7개로 늘어나 "감점 아님"이라는 문구에도 불구하고 결손 목록처럼 읽힌다.
반론형 P2~P4(명제 4~6개)에서는 0~2개라 드러나지 않았던 문제.

### 경로 B — 주제만

> 학생: "암반응과 캘빈 회로, C3 식물"

전 영역 주제만/미포착. focal 판정 = 주제만. 소프트 넛지:

> 「캘빈 회로의 순환」의 화제는 짚었지만, 핵심 관계가 아직 드러나지 않았습니다.
> 요소들이 어떻게 연결되는지 관계로 표현해 보세요.

1차 시뮬레이션과 동일하게 작동. 게이트 없음, 다음 단계 진행 가능.

### 경로 C — 중간 단계 생략 ★ 신규 케이스

> 학생: "암반응에서는 이산화 탄소를 이용해 포도당이 만들어지고, 이 과정이 계속 반복된다."

`calvin_cycle`의 관계는 **되먹임**(산물의 일부가 투입물 RuBP로 재생)이다. 학생 응답은
투입(CO₂)·산출(포도당)·반복성은 있으나 **무엇이 되돌아가는지가 없다**. 즉 "반복"은 있고
"순환"은 없다.

- 주제만 아님 — 투입→산출 관계가 실제로 보존됨.
- 관계보존 아님 — 순환을 순환이게 하는 축이 빠짐.
- → **`partial_relation_preservation`** (판정축 5번째 값).

여기서 중요한 대비가 나온다. **같은 "중간 생략"이라도 P4에서는 관계보존이다.**
P4 오라클 `q4`의 수용 기준은 이미 이렇게 쓰여 있다:

> "단계 일부를 압축하더라도 원인(고온·기공 폐쇄)과 결과(생장·생산 저하)를 방향대로 이으면 인정."

선형 인과 연쇄는 **양 끝이 방향대로 이어지면** 중간 기제를 버려도 좋은 추상이다.
순환은 **되먹임 간선 자체가 관계**이므로 버릴 수 없다. → **N2.**

### 경로 D — 방향 역전 (하드 게이트)

> 학생: "암반응에서 만들어진 화학 에너지를 명반응이 이용해 포도당을 만들고, 3탄당이 분해되어
> 이산화 탄소와 RuBP가 된다."

| 영역 | 판정 |
|------|------|
| dark_reaction | **모순** (명반응↔암반응 방향 역전) |
| calvin_cycle | **모순** (회로 역방향) |
| c3_naming | 미포착 |

하드 게이트 동작 — 두 항목 차단, 재제출 필수.
모순 피드백은 1차 시뮬레이션의 "원문 문구 그대로 짚어 재확인" 스펙을 그대로 적용:

> 「암반응의 투입과 산출」에서 관계를 잘못 이해했습니다. 원문은 "암반응은 **명반응에서 생성된**
> 화학 에너지와 … 이용하여"라고 되어 있습니다. **어느 쪽이 어느 쪽의 산물을 쓰는지** 다시
> 확인해 보세요.

**과정형은 모순 되물음이 대립형보다 쉽다.** 대립형(명실론)에서는 "몇 개인가?"처럼 논지를
건드리지 않는 우회 질문을 짜내야 했지만, 과정형은 **원문의 방향 표현(…에서 생성된, …로
이동한 후, 다시)을 그대로 인용하는 것만으로** 정답을 주지 않고 교정이 유도된다. H2 유지 +
과정형에서 구현 난도 하락.

### 경로 E — 불명확 ★ H6 검증

> 학생: "암반응은 여러 물질이 관여하는 복잡한 순환 과정을 거쳐 포도당을 만든다."

"순환 과정"이라는 **원문 용어를 복창**했으나 무엇이 순환하는지 확인 불가.

- 경로 C(부분관계)와 **다르다**: C는 관계의 한 축이 실제로 보존됨. E는 보존 여부 자체를 판정할 수 없음.
- 명실론 P3 항목②("가리키나 내용이 안 잡힌")와 **동형** → unclear는 지문 유형과 무관하게 재현됨.

**위치 결정의 근거가 여기서 나온다.** unclear를 `regionSemanticVerdict`의 6번째 값으로 넣으면
게이트 규칙·점수 롤업·`overallCategory`가 전부 갈라진다(모순도 미포착도 아닌 값에 대해
차단할지 말지를 새로 정의해야 함). 반면 **질의 층위**에서는 자연스럽다 — `q(calvin_cycle
relation)`의 evidence가 "가리켰으나 미확정"이고, 영역 판정은 `topic_only`로 접힌 뒤
피드백 레이어에 `clarify` 신호가 실린다:

> 「캘빈 회로의 순환」에서 "순환"을 짚었습니다. **무엇이 무엇으로 되돌아가는지** 써 보면
> 관계가 분명해집니다.

게이트는 소프트(미포착과 동일). → **H6 유지, 위치는 "질의 층위 evidence 5번째 상태 +
피드백 clarify 신호", 판정축 확장 없음.**

### 경로 F — 부분 정답 보존 (H7)

> 학생: "암반응은 명반응이 만든 화학 에너지와 이산화 탄소로 포도당을 만드는 단계다.

## P4 — C3 한계 → C4 연구 (실제 오라클 좌표계)

영역: `c3_limit`(C3의 고온 한계) / `mechanism`(한계의 인과 과정) / `c4_solution`(C4 연구의 필요성, focal).

### 경로 A — 인과 사슬 압축 (H/N2 확인)

> 학생: "C3 식물은 고온·건조하면 잘 자라지 못해서, 고온에서도 잘 자라는 C4 식물을 연구한다."

- `mechanism`: 기공 폐쇄·수분 배출·포도당이 **전부 생략**됐지만 원인(고온·건조)과
  결과(생장 저하)를 방향대로 이었다 → `q4` 수용 기준 2항에 의해 **관계보존**.
- `c4_solution`: 문제-해결 연결 명시 → **관계보존**.
- 명제 evidence: p1 evidenced / p2·p3·p4 not_evidenced / p5 supported_by_abstraction /
  p8·p9·p10 evidenced.

`npm run assess` 회귀의 `[암묵적]` 프로브("고온에 취약한 C3, 고온에서도 잘 자라는 C4 연구")가
실제 API로 관계보존을 4/4 세트에서 받은 것과 일치 — **손 시뮬레이션과 실측이 어긋나지 않음.**

### 경로 B — 문제와 해결의 주체 뒤바꿈 (하드 게이트)

> 학생: "C4 식물이 고온에 약한 한계가 있어서 C3 식물 연구가 활발하다."

`c4_solution` = 모순. 실측 로그에서도 4/4 세트가 모순 판정
(`assess-generalize-2026-07-25.log`). 명실론의 "공손룡↔묵가 주장 뒤바꿈"과 **동형** — 문제-해결형의
주체 뒤바꿈은 대립형의 입장 뒤바꿈과 같은 자리에 놓인다. H1 유지.

### 경로 C — 회귀 로그의 불안정 프로브 재검

`assess-generalize` 요약의 유일한 불안정 1/12는 공시 지문 `[주제만]`이었고, 광합성은
12/12 안정이었다. 이번 손 시뮬레이션에서도 P4에서 판정이 갈리는 경계 응답을 만들지 못했다
(문제-해결 관계는 두 항이 명시적이라 경계가 좁다). **P4는 학생 루프 관점에서 안정 구간.**

### 경로 A — 두 공간 뒤바꿈 (하드 게이트)

> 이동해 분해된다."

`two_space` = 모순. P3 경로 D(방향 역전), P4 경로 B(주체 뒤바꿈)와 함께
**"순서·주체·공간의 뒤바꿈"이 과정형 모순의 3대 형태**로 정리된다. 모두 하드 게이트.

### 경로 B — 조직만 포착 (부분관계 재현)

> 학생: "C4 식물은 두 개의 공간에서 광합성이 진행되어 효율이 높다."

- `two_space`: 두 공간이라는 조직은 있으나 **무엇이 어디서 무엇으로 되는지**가 없음 →
  경로 C(P3)와 같은 자리 = **부분관계**.
- `concentration`: "효율이 높다"는 있으나 **농축**이라는 근거가 없음 → 주제만.

부분관계가 P3(순환)과 P5(공간 분업) 두 곳에서 독립적으로 필요해졌다. **과정형에서
`partial_relation_preservation`은 예외가 아니라 상시 발생 판정이다** — 1차 시뮬레이션 노트가
4값(미포착/주제만/관계보존/모순)만 나열한 것은 대립형 편향이었다.

### 경로 C — 좋은 추상 (관계보존)

> 학생: "C4는 엽육 세포에서 이산화 탄소를 4탄당으로 붙잡아 두었다가 유관속초 세포로 보내 그곳의
> 이산화 탄소 농도를 높게 유지하기 때문에, C3보다 광합성 효율이 높다."

PEP·루비스코·4탄당의 탄소 수 등 명명은 생략됐지만 두 공간 분업 + 농축 + 효율이 방향대로
이어짐 → `two_space` 관계보존, `concentration` 관계보존. 참고 세부는 3개(PEP, 4탄당 명명 근거,
캘빈 회로 동일성) — 여기서도 N1의 나열 길이 문제가 재발.

## 2단계 — 지문 전체 표제 ★ H5 부분 반증

1차 시뮬레이션의 결론은 "2단계는 별도 평가기가 아니라 `regionSemanticVerdict`를 지문 최상위
조직 관계에 적용한 것"이었다. 프레임 동형성은 이번에도 유지된다:

> "광합성의 과정과 C3·C4 식물" → **주제만**
> "C3 식물은 고온에서 광합성 효율이 떨어지는 한계가 있어, 다른 방식으로 광합성하는 C4 식물이
> 대안으로 연구된다" → **관계보존**
> "C4 식물의 광합성 효율이 낮아 C3 식물이 대안으로 연구된다" → **모순** (하드 게이트)

문제는 다음 표제다.

> "C4 식물은 이산화 탄소를 유관속초 세포에 농축하는 방식으로 광합성하기 때문에 C3 식물보다
> 고온에서 효율이 높다."

이것도 **정당한 표제**다. 그러나 앞의 관계보존 표제와 **다른 최상위 관계**를 고르고 있다.

- (a) **문제→해결**: C3의 한계 때문에 C4를 연구한다 (P4 → P5 → P6 축)
- (b) **대조·기제**: C3와 C4는 광합성 방식이 다르고 그래서 효율이 다르다 (P1 도입 질문 → P3 → P5 축)

지문 도입부가 "이들의 광합성 방식은 일반적인 식물과 어떤 차이가 있을까?"로 (b)를 예고하고,
결말부(P6)가 기후 위기 대응으로 (a)를 닫는다. **두 축 모두 지문이 실제로 조직한 관계**다.

명실론(대립형)은 최상위가 "두 입장의 대립" 하나뿐이라 이 문제가 드러나지 않았다.
`overallCategory(regions, focalId)`는 **focal 영역 단수**를 전제하므로
(`assessment.ts:163`), (b)를 고른 우수 응답이 (a)를 focal로 잡은 채점에서
`region_not_evidenced`로 떨어진다. → **N3.**

## 신규 발견

### N1 — 참고 세부 나열의 길이 상한이 필요 (코드 수정 근거)

`assessment.ts:141-149` `relation_preserved` 분기는 `not_evidenced`·`supported_by_abstraction`
명제를 **전부** 나열한다. 반론형 문단(명제 4~6개)에서는 0~2개라 무해했지만, 과정형 문단은
명제가 10개 이상이라 우수 응답에도 참고 세부가 5~7개 붙는다. "감점 요소는 아닙니다"라는
문구가 있어도 목록이 길면 결손표로 읽히고, 이는 1차 시뮬레이션의 **H4(수정 보상은 시각적
전환으로, 텍스트보다 강함)** 결론과 충돌한다 — 잘한 응답에 가장 긴 텍스트가 붙는다.

- 스펙: 참고 세부는 **최대 2~3개**, 선택 기준은 문단 층위 우선순위
  (`packages/core/src/weights.ts`의 `globalWeight` 상위) 또는 critical 관계에 인접한 명제. 나머지는 결과 화면의 수형도 오버레이(○)로만 표시.
- 근거: 텍스트는 상한, 시각 오버레이는 전량 — 정보를 버리지 않으면서 텍스트 부담만 제거.

### N2 — 과정형 관계는 하위 유형별로 압축 허용도가 다르다 (오라클/생성기 규범)

| 하위 유형 | 예 | 중간 생략 시 |
|-----------|-----|--------------|
| 선형 인과 연쇄 | 고온→기공 폐쇄→포도당 저하→생장 저하 (P4) | **관계보존** — 양 끝이 방향대로 이어지면 인정 |
| 순환(되먹임) | 캘빈 회로 (P3) | **부분관계** — 재생 간선이 관계 자체, 생략 불가 |
| 공간·주체 분업 | 엽육/유관속초 (P5) | **부분관계** — 두 항의 병치가 관계 자체 |

P4 손 오라클의 `q4`는 이미 1번 규범을 명문화하고 있으나(`acceptanceCriteria` 2항), 이는
손으로 쓴 것이다. **v0 생성기 프롬프트에는 이 구분이 없다** — 생성기가 순환 관계에 대해
선형 연쇄와 같은 수용 기준을 쓰면 경로 C 같은 응답을 관계보존으로 과대평가한다.
(확인: `query-gen.ts`의 원칙 A~F 중 수용 기준 관련 조항은 F "판정 가능하게" 하나뿐이며,
관계 하위 유형별 압축 허용도에 대한 언급이 없다.)
`assess-generalize`의 과대평가 0건은 **순환·분업 관계를 한 번도 걸지 않은 결과**일 수 있다 —
두 지문의 focal이 각각 조건→결과(공시 `obligation`)와 문제→해결(광합성 `c4_solution`)로
모두 비순환형이었다.

- 후속 실험 제안: **P3(순환)·P5(분업)에 대한 손 오라클을 만들고 v0 생성기와 대조** —
  기존 `npm run assess` 틀 그대로, 프로브에 "중간 생략" 유형을 추가.
  이것이 v0 생성기의 첫 실질적 반증 시도가 된다.

### N3 — 2단계 표제는 최상위 관계 **후보 집합**으로 채점해야 한다 (H5 수정)

- 현재: `overallCategory(regions, focalId)` — focal 단수.
- 필요: 지문 조직 유형에 따라 최상위 관계가 복수일 수 있음(문제-해결 축 / 대조-기제 축).
  **후보 중 하나 이상에서 관계보존이면 인정**, 모순은 후보 중 어느 하나와 어긋나도 하드 게이트
  (모순은 후보 무관하게 원문 위반이므로).
- 대립형에서는 후보가 1개라 기존 규칙이 특수해로 성립 → 스펙 변경은 상위 호환.
- 남은 결정: 후보 집합을 **골드에서 어떻게 도출**할지. 지문 층위 골드가 아직 없다(현재 골드는
  문단 단위 `titleId` 하나). 지문 층위 노드(문단 표제들의 상위 조직)를 만드는 작업이 선행돼야 함.
