# 의뢰 조건 B

- 분야: 뇌과학 (인지 신경 과학)
- 주제: 의식적 결정보다 앞서는 뇌 활동에 관한 실험과 자유 의지 논쟁
- 융합: 필수. 생명과학Ⅰ(신경계, 뉴런의 신호)과 윤리와 사상 또는 생활과 윤리(자유 의지, 도덕적 책임) 개념을 엮는다.
- 글 유형: 관점 대립형
- 분량: 5문단 내외, 문단당 4~7문장 (수능 독서 한 지문 분량)
- 문항 의도 (문항은 쓰지 않음): 고난도 1개 = 〈보기〉 사례(변형 실험 등)를 여러 입장의 판정 기준으로 해석, 쉬운 1개 = 입장별 이해
- 제외: 기존 지문과 겹치는 주제 (뇌 과학과 법, 트롤리 딜레마와 fMRI, 분리 뇌, 창의성과 뇌, 언어 습득, 기억 저장)
