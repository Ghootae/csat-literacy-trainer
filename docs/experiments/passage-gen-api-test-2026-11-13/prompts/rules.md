# 수능 독서 지문 집필 규칙 (2026-11-13 웹 파일럿에서 도출)

이 규칙은 뇌과학 전공자의 집필 시뮬레이션과, 생성 지문을 네 번 고친 경험에서 나왔다. 규칙을 지키는 것보다 규칙이 막으려는 실패를 피하는 것이 목적이다.

## A. 출발과 주제 거르기
- W1. 백지에서 시작하지 않는다. 의뢰 조건(분야, 융합 여부, 글 유형, 문항 의도)에서 출발한다.
- W2. 교과 개념(노드) 후보를 2~3개 내고 융합 충족으로 거른다. 한 교과만 깊게 파는 주제는 어렵게 낼 수 있어도 융합 의뢰에서는 탈락이다.
- W3. 설명 비용으로 한 번 더 거른다. 핵심 근거가 복잡한 실험·데이터 해석을 요구해 지문 분량 안에서 설명되지 않으면 탈락이다.
- W4. 주제를 정하면 글 유형(관점 대립 / 원리 적용 / 계산)이 거의 정해진다.
- W5′. 문항은 지문과 별도로 만든다. 지문 단계에는 "어떤 고난도 문항이 나올 수 있게 쓸지"라는 의도만 남긴다. 지문에 문항을 쓰지 않는다.

## B. 입장과 근거 (관점 대립형)
- W6. 앞 1~2문단은 배경, 뒤 문단은 입장. 배경은 짧게, 입장 문단마다 근거를 밝힌다.
- W7. 한 입장의 근거가 한 축뿐이면 문제가 단순해진다. 같은 편 안에서도 근거의 축(예: 과학적 한계 vs 개념적 분리)을 다르게 해 둘로 나눈다.
- W8. 한 입장 안의 근거가 2개 이상이면 서로 다른 대상을 겨냥하게 쓴다.
- W9. 마지막 입장 문단은 의의나 남는 물음으로 끝내되 새 정보를 넣지 않는다.
- W11. 배경 문단에 뒤 입장과 엮일 구분을 하나 심고, 그 구분이 성립하는 근거 문장을 같이 쓴다.
- W12. 입장마다 배경의 과학 사실을 근거로 쓰거나 다르게 해석해야 한다. 배경 문단을 지워도 입장이 그대로 서면 실패다. 단, 모든 과학 문장을 억지로 입장에 엮을 필요는 없다. 배경 설명으로만 쓰이는 문장도 허용한다.
- W13. 입장마다 고유한 개념 장치(정의된 판정 기준 하나)를 준다. 슬로건("공정하지 않다", "노력이 중요하다")은 사례에 적용할 수 없다. 기준은 사례에 넣으면 판정이 나오는 형태여야 한다.
- W14. 기존 지문의 문단 배치를 흉내 내지 않는다. 구조는 쟁점의 논리에서 나온다. 예: 기준 제시 → 과학 사실이 기준을 흔듦 → 해석이 갈림 → 다른 차원의 문제.

## C. 문장과 사실
- 과학 사실은 출처가 실제로 관측한 변수와 범위까지만 쓴다. 이론적 설명은 "~라는 설명이 있다", "이 설명에 따르면"으로 표시한다.
- 사고 실험에 필요한 조건은 앞 문단에서 끌어내지 말고 "~라고 가정해 보자"로 준다.
- 1문단에서 세운 개념 기준은 끝까지 같은 이름, 같은 척도 방향으로 쓴다. 다른 기준을 끌어오면 둘의 관계를 본문에서 밝힌다.
- 고등학생이 읽을 수 있는 문장으로 쓴다. 어려운 용어로 깊이를 만들지 않는다. 깊이는 입장과 근거를 나누는 데서 나온다.

## D. 생성 후 점검 질문 (C1~C7)
- C1. 가정, 이론적 예측, 관측 결과를 구별했는가? 관측은 출처가 잰 변수와 범위까지만 썼는가?
- C2. 비슷한 결과(수행)에서 비슷한 원인(기전)을 추정하지 않았는가?
- C3. 상태의 차이에서 분류나 처우의 정당성을 바로 끌어내지 않았는가?
- C4. "설명에 따르면"을 붙인 문장이 그 설명에서 실제로 도출되는가? 조건(증가 폭, 적용 범위 등)이 빠지지 않았는가?
- C5. 1문단의 기준이 끝까지 같은 이름과 같은 척도로 쓰였는가?
- C6. 연결표와 예상 고리가 본문 문장으로 확인되는가? 연결표가 본문보다 강하게 말하고 있지 않은가?
- C7. 모든 과학 문장을 문항 추론에 억지로 엮지 않았는가?
