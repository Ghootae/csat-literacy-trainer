# API 지문 생성 검증 결과

작성: 2026-11-13. 계획: PLAN.md. 판정지: REVIEW-blind.md. 열쇠: KEY.md.

## 결론: 통과

규칙(W1~W14)과 점검 질문(C1~C7)만 받은 API(gpt-6.1-sol, high)가 쓸 만한 지문을 냈다. 사람 피드백은 없었다. API 지문 4개가 모두 "조금 고치면"이다. C 주제 API 지문 C-1은 v1뿐 아니라 v4보다도 순위가 높다.

## 판정 방법

- 1차: Ghootae 블라인드 판정. 그런데 한 문장에서 받은 나쁜 인상이 지문 전체 평가로 번졌다. 정보량이 많으면 사람이 지문을 고르게 판단하기 어렵다.
- 공식 판정: **Codex 블라인드 판정을 채택했다.** Codex는 출처 표시 없이 지문 6개만 받았고, 생성 실험이라는 맥락도 몰랐다. 보고서: `docs/reports/REPORT-six-neuroscience-ethics-passages-{human,desktop}-2026-11-13.md`.
- Ghootae 판정은 아래 표에 참고로 남긴다. 읽기 흐름에 관한 지적은 수정 목록으로 쓴다.
- 블라인드 한계: Ghootae는 라(v4)와 바(v1)를 앱에서 본 지문으로 알아봤다. Codex 판정은 6개 모두 블라인드다.

## 미리 정한 기준과 대조

- **API 지문 4개 중 2개 이상이 "조금 고치면" 이상:** 4개 모두 해당한다. 충족.
- **C 주제 API 지문 하나 이상이 v1보다 순위가 높음:** C-1(1위)과 C-2(4위) 모두 v1(6위)보다 높다. 충족.
- 두 조건을 모두 충족하므로 통과다. B 주제(사람이 다듬은 기준 지문 없음)에서도 쓸 만한 지문이 나왔으므로, 규칙이 주제를 바꿔도 작동했다고 본다.

## 관찰

1. **논리 정확도는 규칙만으로 나왔다.** 웹 파일럿에서는 v2→v4까지 검토 두 바퀴를 돌려야 했던 수준이다. Codex와 Ghootae 모두 가에서 확정적인 오류를 찾지 못했다. 마의 2문단 출처 구별은 Codex가 "드물게 신중하다"고 평했다.
2. **남은 결함은 읽기 흐름이다.** 판정자 둘이 같은 지점을 지적했다. Codex는 "반복되는 조건문을 줄이라", "조건 목록을 압축하라"고 했고, Ghootae는 "불필요한 조심", "갑자기 뉴런 이야기", "문장이 복잡"이라고 했다.
   - "~만으로는 ~할 수 없다", "~이지 ~은 아니다" 같은 단서 문장이 지문당 5~7개다. v4에는 1개, v1에는 0개다(정규식으로 센 근사치).
   - 평균 문장 길이는 API 74~81자, v4 76자로 비슷하다. 길이보다 한 문장에 단서와 조건을 겹쳐 넣는 것이 문제다.
   - 과학 배경을 연결 문장 없이 넣었다. 4개 모두 1문단을 "~을 '…기준'이라 하자"로 시작한다.
3. **점검 단계(3-check)는 거의 바꾸지 않았다.** 지문마다 1~2문장만 고쳤다. C1~C7은 정확도만 보므로, 범위를 더 좁히라는 쪽(단서를 더 넣는 쪽)으로만 작동한다. 읽기 흐름을 보는 단계는 없다.
4. **마가 1위인 이유:** 서로 다른 과학 증거(운반체 점유, 자극제 메타분석의 작은 평균 효과, 역 U자 설명)가 세 입장의 허용 기준을 실제로 가른다. 다는 과학을 주로 "이것만으로는 입증 안 됨"이라는 한계로 썼다. 역 U자 설명이 없다.
5. **나는 가의 변주다.** 같은 주제를 두 번 돌리면 구조가 겹칠 수 있다.

## 사실 확인

- 3-check.md 사실 목록에서 "출처 모름"이나 확신 "낮음"인 항목은 B-1, B-2, C-1에서 모두 본문에 가정으로 제시한 문장뿐이다. C-2에는 "출처 모름"이 1개 있는데, 화학적 시냅스 전달이라는 교과서 사실이다.
- Codex가 출처를 대조했다: Libet 외 1983, Schurger 외 2012, Volkow 외 1998, Ilieva 외 2015, 건강한 성인 메틸페니데이트 단회 투여 종설. 개별 쪽수와 투여 조건까지는 대조하지 않았다.

## 비용

12번 호출, API 시간 약 26분, 입력 6.4만 토큰, 출력 9.1만 토큰(out/usage.json). 13:37~13:47 사이에 실행이 한 번 끊겼다가 다시 시작됐다. 끊길 때 진행 중이던 호출이 있었다면 그 비용은 기록에 없다.

## 다음 단계

1. **표적 수정 (Codex 권고 순서: 마 → 가 → 라).** 다는 대안으로 남기고, 나는 '의식적 개시'만 다루는 문항이 필요할 때만 고친다. 바는 쓰지 않는다.
   - 마: "사전에 정한 허용 한도·안전 한도"를 누가 어떤 목적으로 정하는지 밝힌다. 개인의 목표 과제 개선을 단회로 확인하는지 반복해서 확인하는지 정한다. 조건 목록을 압축한다.
   - 가: "강한 선결정론"이 이 글에서 설정한 입장임을 밝힌다. "이후의 의도는 … 관여하지 못한다"는 가정 아래의 결론으로 유지한다. 반복되는 조건문을 줄인다. Ghootae의 문장 지적(시계 표시 설명, '통제 조건' 용어, 주술 호응, 결론 보강)도 반영한다.
2. **문항 생성.** 수정한 지문에 기존 파이프라인(골드 지도 탐색 → 선별 → 〈보기〉 조립)을 돌린다. 정답 유일성과 고등학생 이해도는 아직 검증하지 않았으므로 이 단계에서 본다.
3. **다음 생성 때 지시문 보완 후보** (지금 바로 고치지는 않는다):
   - 한계 문장은 어느 입장이 근거로 쓸 때만 본문에 넣는다.
   - 과학 문단 앞에는 그 과학이 왜 필요한지 잇는 문장을 둔다.
   - 판정 기준의 빈칸(누가 정하는지, 어떻게 확인하는지)을 채운다.
   - 과학을 한계로만 쓰면 W12를 충족한 것으로 보지 않는다.
   - 수능 지문이 ㉮ 같은 기호를 본문 주어로 쓰는지 기출로 확인한다.
   - 같은 주제를 여러 번 생성하면 구조가 겹칠 수 있다(가·나).
