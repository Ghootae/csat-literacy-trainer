## 1. 목적과 불변조건

- 문항별 TypeScript 상수로 골드를 작성하지 않았다.
- `OpenAI Responses API → strict JSON Schema → ProblemQuestionGoldSchema`의 실제 경로를 사용했다.
- 공식 해설은 생성 입력에서 제외하고 정답 키만 제공했다.
- 최초 공급자 응답은 파싱·수정 전에 `first-generation-response.json`으로 보존했다.
- 최초본, 독립 감사, 교정 응답, 교정본, 학생 응답과 반복 평가를 서로 다른 파일로 보존했다.

## 4. 오류 유형

1. 골드 주변 계약 오류
   - 대표 오답 경로 scope, 경로 step 역할, 보충 해설 정책처럼 `itemInference` 외부 필드에서 반복됐다.
   - 새 방향성 규칙은 잘 일반화됐지만 전체 ProblemQuestionGold 불변식이 프롬프트에 충분히 설명되지 않았다.

2. 전제 과잉
   - 확산 모델에서 하나의 결론에 관련 보기 사실을 넓게 연결했다.
   - 인격 동일성에서는 같은 결론에 필요하지 않은 사례 사실이 섞였다.

3. 선지 양태 강화
   - FTA에서 “얻을 수 있다”를 “보장된다”로 바꿔 반박했다.

4. 지문만으로 완결되지 않는 정답 키 경계
   - 수소·법 문항은 정답 키와 공식 출제 의도는 분명하지만, 생성된 기본 골드만으로 일부 적용 조건을 완결하기 어려웠다.
   - 이를 출처 사실로 꾸미지 않고 `ANSWER_KEY_CONSTRAINED + ANSWER_KEY` 예약 전제로 분리하도록 계약을 보완했다.

5. 공식 해설 역수입
   - 공식 해설을 생성 입력에서 차단했으며 독립 감사에서도 passage proposition 역수입은 발견되지 않았다.

## 6. 학생 응답 반복 평가

각 문항에 정확한 근거, 부정·거부형 정확한 근거, 대표 오답 근거, 저정보 응답을 만들고 각각 3회 평가했다.

초기 저정보 생성문 일부가 구체적 오개념을 포함했기 때문에, 저정보 항목은 “잘 모르겠지만 n번 같습니다.”로 통제하여 별도 재실행했다. 아래 결과는 통제 재실행을 반영한 합계다.

| 확산 모델 | 2/3 | 3/3 | 3/3 | 3/3 | 11/12 |
| FTA 원산지 | 3/3 | 3/3 | 3/3 | 3/3 | 12/12 |

### 해석

- 대표 오답은 24/24에서 현재 선택 선지의 오류로 국소화됐다.
- 통제된 저정보 응답은 23/24에서 `UNCERTAIN + ASK_DIAGNOSTIC`으로 남았다.
- 저정보 실패 1건은 “1번 같습니다”를 답 번호 선택이 아니라 “1번 선지 내용이 참이다”로 읽어 부정 발문 오류를 확정한 경우다.
- 수소의 정확 근거는 승인된 출처 전제가 비어 있어 모두 `UNCERTAIN`이었다. 이는 오진보다 안전하지만 해당 골드가 기본 골드만으로 정답 근거를 검증하지 못한다는 뜻이다.
- 보증 계약·도덕 논리·확산 모델·인격 동일성의 일부 정확 근거는 빠른 평가의 자연어 태도와 구조화 `optionStance` 모순 방어가 두 번 발동해 `UNCERTAIN`으로 폴백했다. 잘못된 `CLEAR_ERROR`는 막았지만 검증 회수율이 낮아졌다.

## 7. 결론

새 프롬프트의 외삽 성능은 **정답 선택과 방향성 itemInference 생성에는 강하지만, 무수정 운영 골드 생성기로는 아직 부족하다.**

- 강점: 정답 8/8, 방향성 37/38, 효과 일치 37/38, 역수입 0건, 대표 오답 진단 24/24.
- 약점: 최초 전체 스키마 통과 0/8, 전제 최소성 11/38 실패·경고, 정답 키 제약 문항의 근거 검증 공백, 빠른 평가의 부정 표현 모순 방어 과민 반응.

다음 개선 우선순위는 다음과 같다.

1. 범용 생성 프롬프트에 reference path·representativeWrongPath·supplemental policy의 교차 필드 자기 검사를 추가한다.
2. `ANSWER_KEY_CONSTRAINED`를 출처 기반 판단과 명확히 분리하고, 이 상태의 정답 근거를 `SUPPORTED`로 승격하지 않는 정책을 유지한다.
3. “n번 같다”를 선지 명제 수용으로 해석하지 않도록 저정보 발화 규칙을 보강한다.
4. 빠른 평가의 의미 모순 검사를 단순 부정어 탐지보다 대상 주장·발문 극성 단위로 좁힌다.
