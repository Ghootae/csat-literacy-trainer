# 마지막 설명 새 레이아웃 — 사람용 보고

## 1. 개요

### 1) 작업의 목적

정답을 골랐지만 근거가 모자란 학생에게 보이는 마지막 설명 첫 칸이 "그래서 뭐가 빠졌다는 거지?"에 답하지 못했습니다.

예: 학생이 "출연했다고 권한이 생기는 건 아님."이라고 썼는데, 첫 칸은 "네가 말한 '…'은 원문과 맞아."에서 끝났습니다.

원인은 판정기가 이미 써 둔 진단("원문 사실 없이 결론만 부정했다")이 설명 생성기(M4)에 넘어가지 않았다는 데 있었습니다. 대신 서버가 경우 이름 두 개를 넘겼는데, 두 이름이 서로 다른 규칙을 걸었습니다. 그래서 진단 글을 넘기고 규칙은 칸 유형별 레이아웃 정도로 줄였습니다(사용자 제안).

### 2) 작업의 결과

- 같은 학생 입력 12건으로 마지막 설명만 다시 만들었습니다. 판정은 저장된 것을 그대로 썼고, 비용은 $0.064입니다.
- **12건 중 11건이 좋아지거나 받아들일 만하다는 판정**을 받았습니다(사용자 판정).
  - 앞서 문제였던 1번(결론만 씀)과 7번(무슨 말인지 모름)이 해소됐습니다.
  - 6번(학생 말 그대로 인용, "왜 맞는지")은 "많이 좋아짐, acceptable"입니다.
  - 새로 넣은 오답 사례 3건과 판단 방식 사례 1건은 모두 "좋은 해설"입니다.
- 남은 1건(5번 도파민 XS)은 설명이 아니라 **판정**의 문제입니다. 판정기가 "분해되지 않고 남는다"를 "작용 기간 연장"보다 센 읽기로 잘못 분류했고, 설명이 그걸 따라 썼습니다.

### 3) 다음 스텝

1. 새 레이아웃을 마지막 설명의 기본값으로 채택할지 정해 주세요(추천: 채택).
2. 판정기의 선지 읽기 분류를 보강합니다(D1). 풀어 쓴 읽기는 "같은 읽기"로 봅니다. 외부 전송이 필요하므로 승인을 요청드릴 예정입니다.
3. 채택하면 개발자 서버를 재빌드합니다.

## 2. 본문

### 2-1. "무엇이 빠졌는지"를 말하지 못하던 문제 (해결)

- **문제**: KC 학생 "출연했다고 권한이 생기는 건 아님."에 대해 기존 첫 칸은 "…은 원문과 맞아."에서 끝났습니다. 그런데 칸 끝 고정 문장은 "네 근거에서 빠진 부분이 이해됐으면…"이었습니다.
- **과정**: 판정기의 진단 글을 넘기고, 근거 부족 칸은 "맞은 것 → 빠진 것(선지의 말 인용)" 두 단계로 정했습니다. 결론만 되풀이했으면 "방향은 맞다"까지만 인정하게 했습니다.
- **결과**: "출연과 자산 운용 권한이 바로 연결되는 건 아니라고 본 방향은 맞아. … 네 말은 재산을 냈다는 점만 짚고 있어. 주식회사의 법인격이 누구에게 부여되는지, 갑의 권한은 어디에서 생기는지까지는 아직 설명되지 않았어." → 사용자 "괜찮음, 좋아짐".

### 2-2. 학생 말을 그대로 옮기던 문제 (해결)

- **문제**: K4-r3 첫 칸이 "네가 말한 '주식회사 법인격의 부여 대상은 단체, not 개인'은 원문과 맞아. 다만 ②가 왜 맞는지 보려면…"이라고 썼습니다.
- **과정**: 학생 말은 뜻을 풀어 말하고, 적절하지 않은 선지를 "맞다·맞는지"로 부르지 않게 했습니다.
- **결과**: "네가 주식회사의 법인격이 개인이 아니라 구성원 단체에 부여된다고 짚은 건 맞아. 다만 선지의 '주주들에 의해'는 …" → "acceptable". 12건 모두 학생 말을 그대로 옮긴 곳이 없습니다.

### 2-3. 오답 쪽 긴 설명 (해결)

- 풀어 쓰기 원칙으로 오답 칸은 길어졌습니다. 예를 들어 S-A1은 네 문단입니다(짐작 밝히기 → 원문 → 아까 질문 결과 → 선지가 틀린 지점).
- 10·11·12번 모두 "좋은 해설"입니다.

### 2-4. 도파민 XS (미해결, 다음 과제)

- **문제**: 학생은 "②는 흑질 도파민이 분해되지 않고 계속 남는다는 말"이라고 읽었습니다. 사용자 판단으로는 "작용 기간 연장"과 사실상 같은 뜻입니다. 그런데 새 판도 "더 강한 뜻이라 선지와 차이가 있어"라고 썼습니다.
- **원인**: 판정기가 이 읽기를 "더 세게 읽음"으로 분류했고, 진단 글에도 그렇게 적었습니다.
- **정정**: 앞서 "같은 분류 때문에 다른 두 번의 실행에서는 교정 질문까지 나갔다"고 했는데 틀렸습니다. 그 두 번의 교정 질문은 다른 오류(근거가 다룬 도파민이 다름, 원문의 '저장되거나 분해'를 '분해'로만 말함) 때문이었습니다.
- **제안**: 판정 지시문에서 "선지 말을 풀어 쓴 읽기는 같은 읽기"로 정의를 보강하고, XS·G-B3를 각 3회씩 다시 돌려 확인합니다.

### 2-5. 판단 방식 근거 (판단 필요, 급하지 않음)

- C-CT 학생은 "②가 답 같아요. 법인격에 관한 내용이어서요."라고 썼습니다. 새 판은 "법인격을 다루는 선지라는 점을 짚은 건 맞아"로 시작했습니다.
- 예전 결정(D-0159)은 이런 판단 방식을 맞는 근거처럼 인정하지 말자는 것이었고, 이번에 그 전용 규칙을 뺐습니다. 하지만 사용자 판정은 "좋은 해설"이었습니다.
