# 반복 안정성 측정 — 같은 입력, 여러 번 평가

- 날짜: 2026-08-08 / 모델: `claude-opus-4-8`
- 코드: `npm run repeat -- nietzsche-p1 5` (`cli/repeat.ts`, **캐시 미사용**)
- 목적: 하루 전 결정(§2.1 "단조 유지를 하지 않는다")의 근거가 성립하는지 검증

## 왜 돌렸나 — 반례가 먼저 나왔다

학습 UI 서버를 붙이는 중, **캐시 키가 동일한 두 호출이 다른 판정을 냈다.**
키가 같다는 것은 문단·응답·질의셋·요청 지문이 전부 같다는 뜻이므로 **입력이 완전히 같다.**

```
키 v2-65c8dc8cbafa7e55274fcd82d76d8411
  q6   adhoc  preserved / relation
       server not_evidenced / none      ⚠
  → r2 판정이 부분관계 ↔ 주제만로 갈림
```

이는 §2.1이 근거로 든 *"3축 실험의 `regionSemanticVerdict` 반복 안정성 100%"*와 충돌한다.
그 100%는 **법인 문단 하나에 손 질의로** 잰 값(16응답 × 3반복)이고, 니체 문단의 **자동 생성
질의**에는 적용되지 않았다. n=1 반례로 정책을 뒤집는 것도 성급하므로 측정했다.

## 결과 — 프로브 3개 × 5회

```
프로브      r1        r2                  r3
혼합       주제 ×5 ✓  부분×4 / 주제×1 ⚠   보존 ×5 ✓
화제만     주제 ×5 ✓  부분×1 / 주제×4 ⚠   주제 ×5 ✓
충실       보존 ×5 ✓  보존 ×5 ✓           보존 ×5 ✓

영역 판정이 갈린 경우: 2/9
```

## 발견

### 1. 반복 변동은 실재한다 — 100%가 아니다

§2.1의 근거가 무너졌다. 같은 입력에 같은 판정이 나온다는 전제를 쓸 수 없다.

### 2. 변동이 한 영역에 몰렸다

`r1`·`r3`는 각각 **15회 전부 안정**이었다. 무작위 잡음이 전 영역에 퍼진 것이 아니라
**`r2`가 경계에 걸려 있다.**

### 3. 경계는 `부분관계 ↔ 주제만` 하나뿐

보존↔부분, 주제↔미포착, 모순 경계에서는 흔들리지 않았다. 이는 N2-d(순환·분업 문단의
불안정이 전부 `주제만↔미포착` / `관계보존↔부분관계` 경계였다)와 같은 양상이다.

### 4. 명확한 응답은 완전히 안정적이다

"충실" 프로브는 9/9 보존. **흔들리는 것은 진짜 애매한 답이다** — `r2` 텍스트
*"전통 형이상학은 도덕적 선을 절대적으로 봄"*은 핵심 질의의 *목적* 부분만 답하고
*재단* 부분을 빠뜨려 실제로 경계에 있다.

### 5. 양방향으로 흔들린다

"화제만" 프로브에서는 `주제만`이 1회 `부분관계`로 **올라갔다.** 한쪽으로 치우친 편향이 아니다.

## 결정 — §2.1 개정

**부당한 강등이 실재한다.** 학생이 `r3`를 고쳤는데 건드리지도 않은 `r2`가 ◐ → ○로 떨어질 수
있고, 색이 다르므로 학생 눈에 보이며, **설명할 방법이 없다.**

그렇다고 전면 단조 유지를 쓰면 학생이 내용을 지웠을 때도 안 내려가 **화면이 답안과
어긋난다**(2026-08-07 로그의 v2→v3 케이스). 그리고 **모델 변동인지 학생이 근거를 지운
것인지 밖에서 구분할 수 없다** — 같은 현상으로 보인다.

```
학생이 "다듬기"로 고른 영역   →  판정 그대로 (올라가든 내려가든)
그 외 영역                   →  상승만 반영 (내려간 것은 표시하지 않음)
예외: 모순은 언제나 표시      →  하드 게이트가 조용히 실패하면 안 된다
```

- 겨냥 안 한 영역을 가리는 것은 **부당한 강등이 측정됐으므로** 정당하다.
- 겨냥한 영역은 정직하게 남으므로 **"지웠는데 ● 로 남는" 최악은 생기지 않는다.**
- 거짓이 남는 곳은 겨냥하지 않은 영역뿐이고, 학생이 의도적으로 건드린 곳이 아니다.

완벽하지 않다. `v2→v3`처럼 학생이 `r3`를 지워 `r2`가 **실제로** 내려간 경우 `r2`는 낡은 ◐로
남는다. **트레이드오프를 감수한 선택이다.**

## 남는 것

- **경계 응답의 재현성**이 근본 문제다. 표시 규칙은 증상을 가릴 뿐이다. 생성기가 수용 기준을
  더 날카롭게 쓰면(예: "목적만 답하고 재단이 없으면 주제만") 경계가 줄어든다 — 생성기 v2 항목.
- 표본이 **문단 1개 · 프로브 3개 · 5회**다. 다른 문단에서 변동 폭이 다를 수 있다.
- `regionSemanticVerdict` 반복 안정성은 **문단·질의셋마다 따로 재야 한다.** 한 번 잰 값을
  다른 문단에 적용하면 이번과 같은 오류가 반복된다.
