# Dialogue v6 질문 비유도성 검증 — 2026-08-25

## 목적

Dialogue v5의 판정 구조와 상태 계약을 기준선으로 유지하고 질문 생성 규칙만 수정했다. v5 교차
문단 검증에서 질문이 생성된 기존 비통과 사례 12건을 동일 조건으로 한 번씩 재실행하여 판정과
target 회귀, 질문의 유도성을 사람이 검토했다.

## 변경 범위

- 유지: PASS/UNCLEAR/ERROR 판정 원칙, relation state, targetIssue 상태 계약, 파생
  `explicitErrors`, schema version `dialogue-evaluation-openai-v4`
- 변경: 질문 규칙만 `dialogue-prompt-v6`로 갱신
- DIAGNOSTIC은 대상 명칭을 언급할 수 있지만 올바른 관계·방향·원인·결과·대응·조건·목적을
  질문에 포함하지 않는다.
- CORRECTIVE는 학생의 충돌 지점을 특정하지만 올바른 답 자체는 제시하지 않는다.
- 한 질문은 target 관계 하나만 확인한다.
- 질문 자체는 다음 턴의 학생 증거가 아니며, 질문을 읽는 것만으로 target이 supported가 되어서는
  안 된다.

## 실행 조건

- 입력: `cross-paragraph-review-2026-08-25.json`의 비통과 12건
- 모델: OpenAI `gpt-5.6-terra`
- effort: `medium`
- 각 응답은 SDK 재시도 없이 한 번만 호출
- 비교 기준: v5 교차 문단 원시 결과

target이 바뀐 한 건은 정보 비대칭 모호 응답이다. v5는 현행 표시 의무 대상인 `MR2`를, v6는
생성형 AI와 광고 판별 어려움의 관계인 `MR1`을 선택했다. 응답에는 “AI 광고의 정보 비대칭
문제”만 있고 세부 관계는 없으므로 둘 다 unknown이다. `MR1`은 중심 문제의 인과를 확인하는
합리적인 정보 이득 질문으로 판단했다. 이는 질문 규칙의 회귀라기보다 모호 응답에 존재하는 복수의
타당한 target 중 하나를 선택한 것으로 본다.

## 기존 유도 질문의 변화

### 법인 단일 오류

- v5: “원문에서는 ... 관할 기관의 허가가 필요하다고 합니다.”
- v6: “방금 말한 기본 재산 처분·용도 변경과 관할 기관의 관계를 원문에 맞춰 다시 확인해
  설명해 볼래요?”

v6는 오류가 발생한 관계를 지목하지만 올바른 허가 관계를 먼저 말하지 않는다.

### 정보 비대칭 부분 이해

- v5: 정보 제공자와 플랫폼에도 표시 의무를 부과해야 한다는 주장을 질문에서 먼저 제시했다.
- v6: “정보 제공자와 플랫폼 사업자의 표시 의무를 어떻게 다루고 있나요?”

v6는 관련 대상을 언급하지만 의무 확대라는 관계와 방향은 학생이 직접 구성하게 한다.

target relation을 supported로 바꿀 수는 없다.

## 결론

- 판정 구조는 v5 기준선을 유지했다.
- 질문 규칙만 분리한 v6에서 기존 유도 질문 2개가 모두 개선됐다.
- 새 12개 질문에서는 정답 관계 또는 방향을 먼저 노출한 사례를 발견하지 못했다.
- 현재 범위에서는 문단이나 기능을 더 늘리지 않고 v6를 질문 생성 기준선 후보로 둘 수 있다.
- 자동 문단 분석은 계속 후보 생성기로만 사용하며, 초기 운영 흐름은
  `모델 분석 → 사람의 core 관계 검토·정제 → 판정 골드 확정`으로 유지한다.
