# 정답 근거 충분성 경계 Terra–Luna 비교

## 목적

Luna medium에서 불안정했던 동일 18개 충분성 경계 판정을 Terra medium으로 그대로 실행하여, 문제가 Luna 고유의 모델 한계인지 확인한다.

## 동일성 조건

두 실행은 모델을 제외하고 다음 조건이 같다.

- corpus hash: `sha256:19f11d4b964c1932ba9c8acebc6a3f6d274153026f725b18309a1b2d89fc022a`
- prompt hash: `sha256:a313cfc32d9f06bbb44503a9ce3dca90ad0a7d66595a6537049a383bf5ee2a5e`
- reasoning effort: `medium`
- 입력: 원본 전체 골드 `BASELINE_FULL_GOLD`
- 논리 프로브: 6개, 각 3회

## 결과

| 지표 | Luna medium | Terra medium |
| --- | ---: | ---: |
| assessment | 14/18 | 16/18 |
| 원시 finding 채점 | 13/18 | 15/18 |
| 원시 상세 통과 | 13/18 | 13/18 |
| 감사 보정 상세 통과 | 14/18 | 16/18 |
| 계약 오류 | 1 | 0 |
| 비용 | `$0.030809` | `$0.198419` |
| 평균 지연 | 11.94초 | 7.96초 |

프로브별 assessment는 다음과 같다.

| 프로브 | Luna | Terra |
| --- | ---: | ---: |
| 수소 C4 원 압축 | 2/3 | 1/3 |
| 수소 C4 명시적 대안 압축 | 1/3 | 3/3 |
| 관련 사실 하나 거부 | 3/3 | 3/3 |
| 일부 경쟁 선지 제거 거부 | 3/3 | 3/3 |
| 선택 결론 재진술 거부 | 3/3 | 3/3 |
| FTA 승인 완전 제거 | 2/3, 오류 1 | 3/3 |

Terra의 대안 압축 3회는 모두 `SUPPORTED`였고 전환율 비교와 공통 화학량론을 각각 실제 출처가 있는 결정적 `MATCHES`로 보존했다. 그러나 corpus 채점기는 학생 문장 끝의 “Ⓑ의 수소가 더 적다” 자체를 별도 finding으로 요구했다. 모델은 그 결론을 reason에 반영하고 실제 근거 전제들을 finding으로 분해했으므로 세 실패는 채점 anchor의 위음성이다. 같은 위음성 1건이 Luna에도 있다. 이를 감사 보정 상세 통과에 반영했다.

Terra는 명시적 대안 압축, 완전 제거, 불충분 거부에서는 Luna보다 안정적이었다. 반면 사람이 `SUPPORTED`로 확정한 원 C4 압축은 Terra 1/3, Luna 2/3으로 둘 다 안정적이지 않았다. 두 모델 모두 실패 시 `Ⓐ의 부반응이 거의 없다`는 대비를 독립 필수 전제로 요구했다.

타입 빌드, 관련 계약 테스트 8/8과 `git diff --check`가 통과했다. 전체 회귀는 649/650이 통과했고, 유일한 실패는 기존부터 누락된 Hegel `.omc` 실험 산출물을 직접 읽는 무관한 테스트다.

## 결론

원 C4의 불안정성은 Luna 고유 문제가 아니다. Terra로 교체하는 것만으로 해결되지 않는다. Terra는 전체적으로 더 안정적이지만 원 C4에서는 오히려 한 건 덜 인정했고, 비용은 이번 표본에서 Luna의 약 6.44배였다.

다음 단계는 모델 추가 비교보다 사람이 승인한 압축 경로를 구조적으로 입력하는 것이다. 예를 들어 C4에 대해 `MP3 + SF1 + SF3` 조합이 압축 인과로 충분하며 `MP6`의 명시적 반복은 요구하지 않는다는 인간 검토 계약을 evaluator 입력에 전달해야 한다. 그 후 같은 18회를 다시 실행해 두 모델이 계약을 따르는지 확인하는 것이 적절하다.
