# 문단 기능 어휘 만들기

수능 독서 기출 158세트, 문단 990개에서 문단마다 자유롭게 붙인 기능 이름을 모았다. 같은 일을 하는 문단에 서로 다른 이름이 붙어 있다. 이 이름들을 묶어 모든 문단에 붙일 수 있는 통일 어휘를 만든다. 이 어휘는 두 곳에 쓰인다. 기출 지문의 문단 기능 배열을 서로 비교하는 데 쓰고, 새 지문을 설계할 때 문단 기능표를 쓰는 데 쓴다.

## 입력
- 기능 이름 목록: 이름, 주된 기능으로 쓰인 횟수(function), 두 번째 기능으로 쓰인 횟수(secondary)
- 글 종류 목록: (가)(나) 세트의 글마다 붙인 종류(kind)와 횟수

## 규칙
1. 기능은 그 문단이 글 전체에서 하는 일이다. 화제어 없이 쓴다.
2. 기능은 25~40개로 만든다. 한 문단에 두 기능이 똑같이 맞을 만큼 겹치면 합친다. 문단 배열을 비교하거나 지문을 설계할 때 구별할 가치가 있으면 나눈다.
   - 예(틀이 아니다): '기본 원리 제시'와 '기초 원리 제시'는 합친다. '원리 설명'(왜 그렇게 되는가)과 '과정 설명'(어떤 순서로 일어나는가)은 나눌 만하다.
3. 이름이 대상과 행위로 되어 있어도 행위가 같다고 묶지 않는다. 그 문단이 글에서 하는 일로 묶는다. 예: '대안 제시'와 '한계 제시'는 둘 다 '제시'지만 하는 일이 다르다.
4. 기능을 5~8개 묶음으로 나눈다. 묶음은 기능이 하는 일의 종류다. 예(틀이 아니다): 글을 여는 일, 개념·원리를 깔아 두는 일, 관점을 세우고 다투는 일, 적용하고 넓히는 일, 맺는 일.
5. 기능마다 다음을 적는다.
   - name: 2~8자
   - definition: 이 기능의 문단이 글 전체에서 하는 일 한 문장
   - versus: 가장 헷갈리기 쉬운 다른 기능과 어떻게 다른지 한 문장
   - examples: 입력 이름 중 이 기능에 드는 대표 이름 3~5개
6. 글 종류(kind)는 4~8개로 묶고, 종류마다 name, definition, examples를 적는다.
7. 어휘 어디에도 넣기 어려운 입력 이름은 hard_to_place에 적는다.

## 출력 (JSON 하나만)
{
  "groups": [
    { "group": "묶음 이름", "about": "이 묶음의 기능들이 하는 일 한 문장",
      "functions": [ { "name": "", "definition": "", "versus": "", "examples": ["", ""] } ] }
  ],
  "kinds": [ { "name": "", "definition": "", "examples": ["", ""] } ],
  "hard_to_place": ["", ""]
}
