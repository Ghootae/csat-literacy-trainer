- **meetings**: [1,3] 비정상 세포 제거를 통한 신체 방어 — 1문단이 제시한 방어 기능을 3문단이 바이러스 감염 세포의 인식과 제거 경로로 구체화한다.; [2,3,4] 실행 카스파제와 DNA 분해 — 2·3문단의 서로 다른 경로가 실행 카스파제의 활성화로 합류하고, 4문단은 그 공통 작용 이후의 변화와 처리를 이어 설명한다.; [1,4] 세포자멸사와 괴사의 구별 — 1문단이 죽음의 발생 방식으로 두 현상을 구별하고, 4문단은 잔해 처리 과정으로 염증 반응의 차이까지 설명한다.; [1,5] 세포자멸사의 생리적 가치 — 1문단의 조직 정비와 신체 보호라는 의의가 5문단에서 환기되며 질병 치료에 활용할 가치로 확장된다.
