## P1 관점 대조 (14편, 하위 구조 5개, 묶이지 않은 지문 2편)

같은 대상이나 물음에 대해 글들이 서로 다른 전제·기준·해석을 내놓고, 각 관점의 설명과 귀결이 어떻게 달라지는지 드러낸다.

### P1-1 정초·반박 병치
- 문단 기능 배열: 갈래 A: 개념 규정 → 조건 명시 → 귀결 제시 ｜ 갈래 B: 비판 반박 ×n → 대안 제시 → 특성 설명 → 의의 평가 (두 갈래의 선후는 정하지 않음)
- 맞는 쟁점 논리: 같은 물음에 답하려면 한쪽은 성립 근거와 인정 조건을 세워야 하고, 다른 쪽은 당연시된 전제를 무너뜨려 다른 답을 정립해야 하는 경우에 맞는다.
- 하위 축 값:
  - 여는 방식: 한 갈래는 개념과 원리를 세우고, 다른 갈래는 비판할 선행 전제를 내놓는다. 필요한 배경은 각 갈래의 앞에 둔다.
  - 글 사이 배치: 조건을 정립하는 갈래와 전제를 반박하는 갈래를 글별로 묶는다. 두 갈래의 선후는 고정하지 않는다.
  - 펼치는 순서: 한쪽은 개념에서 성립 조건과 귀결로 나아가고, 다른 쪽은 반박에서 대체 입장의 성격과 의의로 나아간다.
  - 끝맺는 방식: 각 입장이 확보한 가능성이나 의의를 밝히며 닫는다.
- 만남 지점과 비워 둔 곳: 개념 규정–조건 명시–귀결 제시 사이에 앞선 규정으로 뒤의 인정 범위를 제한하는 연결이 놓인다. 비판 반박–대안 제시–특성 설명 사이에는 기존 전제를 거부한 뒤 무엇을 새로 인정하는지 보충할 자리가 생긴다. 두 갈래의 조건 명시와 비판 반박을 교차시키는 추론도 남는다.
- 예시 기출:
  - 고3 2025년 7월 교육청 모의평가 4~9번 〈로고스와 정치적 자유, 법의 정당성〉
  - 고3 2024년 3월 교육청 모의평가 4~9번 〈사유와 독립한 존재의 실재성 (메야수와 굿맨)〉
  - 소속 2편
- 이 구조를 고를 조건: 두 입장의 차이를 구체적인 실행이나 사례별 판정보다 정초 방식에서 드러내려 할 때 고른다. 비판 뒤에도 대체 입장의 성격을 설명하여 독립된 관점으로 완결할 수 있어야 한다.

### P1-2 기준·적용 대조
- 문단 기능 배열: 글마다: 입장 제시 → 개념 규정 → 관계 설명 → 조건 명시 → 사례 적용(비판 반박) → 귀결 제시 (끝의 적용이 적어도 한 글에서 전개의 핵심)
- 맞는 쟁점 논리: 입장의 차이를 선언하는 것만으로는 부족하고, 각 입장이 마련한 기준을 실제 판정에 사용해야 차이가 드러나는 문제에 맞는다.
- 하위 축 값:
  - 여는 방식: 서로 다른 기본 입장이나 총괄 기준을 먼저 내놓는다.
  - 깔아 두는 곳: 후반의 판정에 필요한 개념 구분과 적용 조건을 앞과 중간에 단계적으로 쌓는다.
  - 펼치는 순서: 설명 틀을 마련한 뒤 앞서 소개한 입장이나 경계적인 경우로 돌아가 적용한다. 이 회수는 적어도 한 글에서 전개의 핵심을 이룬다.
  - 규칙·사례의 위치와 하는 일: 규칙과 조건이 후반의 사례 적용을 통제한다. 사례는 이해를 돕는 데 그치지 않고 인정 여부나 판정의 차이를 가른다.
  - 끝맺는 방식: 기준의 적용 범위 또는 그 기준에서 따라 나오는 최종 함의를 확인한다.
- 만남 지점과 비워 둔 곳: 입장 제시–조건 명시–사례 적용 사이에 처음의 주장을 나중의 기준으로 재해석하는 연결이 놓인다. 개념 규정–관계 설명 사이에는 서로 구별한 층위의 연결을, 조건 명시–귀결 제시 사이에는 적용 범위가 과도하게 넓어지지 않도록 제한하는 추론을 남길 수 있다.
- 예시 기출:
  - 고3 2025년 5월 교육청 모의평가 4~9번 〈쇼펜하우어의 표상과 의지, 가브리엘의 신실재론〉
  - 고3 2026년 5월 교육청 모의평가 4~9번 〈러셀과 리오타르의 지식론 — 대응론적 진리관과 언어 게임〉
  - 소속 2편
- 이 구조를 고를 조건: 앞부분에서 세운 설명 틀을 후반에 다시 작동시키려 할 때 고른다. 기존 입장이나 경계 사례를 같은 기준에 되돌려 대입하는 장면이 있어야 한다.

### P1-3 전제·실천 대조
- 문단 기능 배열: (가) 입장 제시 → 근거 뒷받침(원리 설명) ×n → 귀결 제시(방법 설명) ｜ (나) 입장 제시 → 원리 설명 ×n → 귀결 제시(대안 제시)
- 맞는 쟁점 논리: 같은 요소를 어떻게 이해하느냐에 따라 그것을 다루는 방식과 지향해야 할 방향이 달라지는 문제에 맞는다.
- 하위 축 값:
  - 여는 방식: 같은 대상의 성격이나 역할을 다르게 규정하는 기본 입장에서 출발한다.
  - 깔아 두는 곳: 각 글의 앞부분에서 출발 전제를 세우고, 뒤의 방향 선택에 필요한 근거를 글 안에서 따로 마련한다.
  - 펼치는 순서: 기본 입장과 그 근거를 설명한 뒤, 그 입장에서 요구되는 방법이나 태도로 내려온다. 한쪽의 근거 설명이 더 길어져도 대응 관계는 유지된다.
  - 규칙·사례의 위치와 하는 일: 사례는 주로 중간에서 전제나 기제를 이해시키며, 독립적인 판정 절차를 이루지는 않는다.
  - 끝맺는 방식: 방법, 대안, 실천 방향을 제시하여 전제의 차이를 행동상의 차이로 완결한다.
- 만남 지점과 비워 둔 곳: 입장 제시–귀결 제시 사이에 처음의 전제가 최종 방향으로 회수되는 연결이 놓인다. 원리 설명–방법 설명 또는 대안 제시 사이에는 설명에서 권고로 넘어가는 이유를 보충할 자리가 생긴다. 두 글의 귀결 제시를 교차하면 한쪽의 방법을 다른 쪽이 받아들이기 어려운 이유를 추론할 수 있다.
- 예시 기출:
  - 고2 2025년 10월 교육청 모의평가 16~21번 〈데카르트와 하이데거의 선입견과 교육에 대한 관점〉
  - 고3 2024년(2025학년도) 9월 평가원 모의평가 12~17번 〈영화 이론: 리얼리즘과 정신분석학〉
  - 고1 2024년 9월 교육청 모의평가 16~20번 〈하이데거와 사르트르의 죽음에 대한 관점〉
  - 소속 3편
- 이 구조를 고를 조건: 관점 차이를 개념 설명에 머물게 하지 않고 서로 다른 방법이나 태도로 연결하려 할 때 고른다. 두 글의 끝부분을 나란히 읽으면 출발 전제의 차이가 다시 드러나도록 설계한다.

### P1-4 집중·분화 병치
- 문단 기능 배열: 집중하는 글: 입장 제시 → 개념 규정 → 특성 설명 → 귀결 제시 ｜ 분화하는 글: 배경 제시(입장 제시) → 유형 분류 → 특성 설명(예시 구체화) ×n
- 맞는 쟁점 논리: 하나의 일관된 설명을 깊게 추적하는 방식과, 공통 기반 안의 여러 변형을 펼쳐 보이는 방식을 함께 써야 하는 내용에 맞는다.
- 하위 축 값:
  - 여는 방식: 공통 대상이나 기반을 마련한 뒤, 한쪽은 중심 입장으로 좁혀 들어가고 다른 쪽은 여러 갈래를 포괄하는 틀을 제시한다.
  - 깔아 두는 곳: 집중하는 쪽은 핵심 개념을 앞에 모으고, 분화하는 쪽은 공통 기반을 먼저 둔 뒤 갈래별 배경과 근거를 필요할 때 나눈다.
  - 펼치는 순서: 한쪽은 하나의 논리 사슬을 길게 추적한다. 다른 쪽은 내부 갈래를 차례로 설명하며 갈래별 특징과 귀결을 대응시킨다.
  - 규칙·사례의 위치와 하는 일: 분화하는 쪽의 사례는 공통 틀을 여러 방향으로 구체화하고 갈래 사이의 차이를 드러낸다.
  - 끝맺는 방식: 마지막 갈래의 설명에서 끝낼 수도 있고, 갈래들의 관계나 전체 의의를 별도로 정리할 수도 있다. 종합의 유무보다 분화 전개가 핵심이다.
- 만남 지점과 비워 둔 곳: 집중하는 쪽에서는 개념 규정–귀결 제시 사이에 의미 확장이나 조건 구별을 보충할 자리가 생긴다. 분화하는 쪽에서는 배경 제시·유형 분류–특성 설명 ×n 사이가 공통 틀과 개별 갈래의 만나는 곳이다. 두 글 사이에서는 귀결 제시와 각 갈래의 특성 설명을 교차하여 공통점과 차이를 찾게 된다.
- 예시 기출:
  - 고3 2023년(2024학년도) 11월 수능 12~17번 〈노자 사상에 대한 다양한 해석〉 · 세 번 중 2
  - 고1 2026년 3월 교육청 모의평가 18~23번 〈문화에 대한 화이트와 반 퍼슨의 이론〉
  - 고1 2025년 6월 교육청 모의평가 16~20번 〈자유주의와 공화주의의 시민관〉
  - 소속 3편
- 이 구조를 고를 조건: 한 관점은 개념에서 귀결까지 집중적으로 설명하고, 다른 관점은 내부 차이를 보여 주어야 할 때 고른다. 여러 갈래를 단순 열거하지 않고 공통된 질문이나 설명 항목으로 묶을 수 있어야 한다.

### P1-5 구성·작용 대조
- 문단 기능 배열: (가) 입장 제시 → 구조 설명 → 특성 설명 → 조건 명시 ｜ (나) 입장 제시 → 구조 설명(개념 규정) → 과정 설명(사례 적용) → 귀결 제시
- 맞는 쟁점 논리: 같은 대상을 서로 다르게 나누어 설명하고, 그 구분의 차이가 작용 방식과 도달 결과의 차이로 이어지는 내용에 맞는다.
- 하위 축 값:
  - 여는 방식: 서로 다른 기본 전제나 일반 원리를 글별로 제시한다.
  - 깔아 두는 곳: 작용을 설명하기 전에 구성 요소, 구분, 관계의 기본 틀을 앞부분에 마련한다.
  - 펼치는 순서: 전제에서 구성으로, 구성에서 요소들의 작용과 성립 조건으로 나아간다. 후반에는 조정·통합·적용의 과정을 통해 결과를 설명한다.
  - 규칙·사례의 위치와 하는 일: 조건은 요소들의 작용이 원하는 결과로 이어지는지를 가른다. 사례는 이미 마련한 구성과 원리를 구체적인 활동에서 작동시킨다.
  - 끝맺는 방식: 올바른 작동 조건이나 여러 요소가 결합한 결과를 제시한다.
- 만남 지점과 비워 둔 곳: 구조 설명–특성 설명·과정 설명 사이에 앞서 나눈 요소의 역할을 회수하는 연결이 놓인다. 개념 규정–조건 명시–귀결 제시 사이에는 특정 요소를 받아들이거나 조정해야 하는 이유를 보충할 자리가 생긴다. 두 글의 구조 설명과 후반의 작용 설명을 각각 대응시키면 명시되지 않은 차이를 추론할 수 있다.
- 예시 기출:
  - 고1 2025년 9월 교육청 모의평가 16~21번 〈샤프츠베리와 듀이의 미적 경험론〉
  - 고1 2023년 3월 교육청 모의평가 28~33번 〈프로이트와 융의 정신분석이론〉
  - 소속 2편
- 이 구조를 고를 조건: 대조의 중심이 주장에 대한 찬반보다 설명 체계의 구성과 작동에 있을 때 고른다. 앞에서 소개한 요소들을 뒤의 조건이나 과정에서 다시 사용하도록 설계할 수 있어야 한다.

## P2 공통 논지 보완 (5편, 하위 구조 1개, 묶이지 않은 지문 3편)

서로 다른 입장·사례·경로가 공유하는 문제의식이나 설명 방향을 여러 측면에서 보완한다. 글 사이의 차이는 대립을 판정하기보다 공통 논지의 여러 면을 드러내는 데 쓰인다.

### P2-1 관점평가와파급설명
- 문단 기능 배열: (가) [관점 조정 / 한계 지적] → [과정 설명 / 방법 설명 / 원리 설명] ×n → 의의 평가 ｜ (나) [배경 제시 / 개념 규정] → [근거 뒷받침 / 개념 규정] → [범위 확장 / 귀결 제시 / 변화 설명] ×n → [원리 설명 / 대안 제시]
- 맞는 쟁점 논리: 대상이 성립하고 달라지는 과정을 하나의 관점만으로 충분히 설명하기 어려운 문제에 맞는다. 조정된 관점의 설명력과 별도 접근의 파급을 나누어 제시하면 공통 논지의 서로 다른 층위를 보완할 수 있다.
- 하위 축 값:
  - 여는 방식: 앞 글은 기존 대립을 조정하거나 그 한계를 드러내며 열고, 뒤 글은 변화의 배경이나 새로운 관점의 정의로 연다.
  - 깔아 두는 곳: 앞 글은 도입에서 중심 관점을 정하고 중간에서 설명을 보충한다. 뒤 글은 앞부분에 배경·개념·근거를 마련한 뒤 후반의 파급 설명에 사용한다.
  - 펼치는 순서: 앞 글은 조정된 관점의 세부 설명에서 평가로 나아가고, 뒤 글은 새로운 규정에서 출발하여 여러 측면의 변화와 귀결로 넓어진다.
  - 글 사이의 역할 분담: 한 글은 관점 자체의 설명력과 의의를 검토하고, 다른 글은 설명의 다른 층위를 보태 그 파급을 펼친다.
  - 사례의 위치와 하는 일: 주로 중간의 설명과 후반의 귀결에 붙어 추상적 관계를 구체화하며, 하나의 정답을 가르는 판정 절차를 구성하지는 않는다.
  - 끝맺는 방식: 앞 글은 의의 평가로 닫고, 뒤 글은 추가적인 귀결이나 대응 가능성으로 논의를 열어 둔다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞 글의 관점 조정·한계 지적과 의의 평가 사이, 두 글의 과정 설명·원리 설명과 근거 뒷받침·귀결 제시 사이에 놓인다. 비워 둔 곳은 근거 뒷받침에서 일반적 관계를 도출하는 자리, 귀결 제시·변화 설명에서 드러난 차이의 방향을 추론하는 자리, 변화 설명을 마지막 대안 제시와 연결하는 자리에 놓인다.
- 예시 기출:
  - 고2 2025년 6월 교육청 모의평가 38~42번 〈역사학의 객관성과 언어로의 전환〉 · 세 번 중 2
  - 고3 2026년 7월 교육청 모의평가 4~9번 〈기든스의 구조화 이론과 벡의 위험사회론〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 한 글에서는 중심 관점의 작동 방식과 가치를 설명하고, 다른 글에서는 새롭게 규정된 상태가 여러 측면에 미치는 영향을 펼치려 할 때 고른다. 두 글의 결론을 직접 대결시키기보다 설명의 초점과 수준을 달리하려는 경우에 적합하다.

## P3 토대와 구체화 (10편, 하위 구조 3개, 묶이지 않은 지문 3편)

한 글이 개념·원리·전체 윤곽을 세우고, 다른 글이 그것을 토대로 특정 대상·제도·상황의 세부를 설명하거나 적용한다.

### P3-1 세부운용분기
- 문단 기능 배열: (가) [개념 규정 / 유형 분류] → [원리 설명 / 특성 설명] → … ｜ (나) [개념 규정 / 비교 대조] → {조건 명시 → 절차 설명} ×n → [기준 설정 / 예외 제시] → …
- 맞는 쟁점 논리: 전체의 목적이나 구성만으로는 그 안의 한 부분이 실제로 어떻게 운용되는지 알기 어려운 내용에 맞는다. 공통 요건과 후속 단계, 예외를 구별해야 구체적인 처리 결과를 이해할 수 있다.
- 하위 축 값:
  - 여는 방식: 앞 글은 전체의 개념이나 유형을 마련하고, 뒤 글은 그 안의 한 부분을 별도 설명 대상으로 꺼낸다.
  - 깔아 두는 곳: 전체 윤곽은 앞 글에 두고, 세부 운용에 필요한 구별과 요건은 뒤 글의 해당 단계마다 나누어 둔다.
  - 펼치는 순서: 전체의 성격과 작동 방식 → 한 부분의 구별 → 공통 요건과 처리 단계 → 조건별 분기와 보완
  - 규칙·사례의 위치와 하는 일: 뒤 글의 중간과 끝에 집중되며, 이해를 돕기보다 적용 가능 여부와 후속 처리를 가른다.
  - 끝맺는 방식: 세부 장치의 의의를 전체 목표에 연결하거나, 마지막 예외와 적용 범위를 밝히고 끝낸다.
- 만남 지점과 비워 둔 곳: 앞 글의 개념 규정·원리 설명·특성 설명이 뒤 글의 개념 규정과 절차 설명에 연결된다. 비워 둔 연결은 조건 명시와 후속 절차 설명 사이, 공통 요건과 예외 제시 사이에 주로 놓이며, 앞 단계의 요건이 뒤 단계에서도 유지되는지 판단하게 한다.
- 예시 기출:
  - 고3 2024년 5월 교육청 모의평가 4~9번 〈자유 무역 협정과 원산지 결정 기준〉 · 세 번 중 2
  - 고2 2023년 9월 교육청 모의평가 20~25번 〈언론 매체 접근·이용권과 반론권〉
  - 고1 2026년 6월 교육청 모의평가 11~15번 〈선거관리기관과 선거공보〉 · 세 번 중 2
  - 소속 3편
- 이 구조를 고를 조건: 앞 글에서 전체 윤곽을 확보한 뒤, 뒤 글에서는 한 부분의 이용 조건이나 처리 경로를 상세히 설계하려 할 때 고른다. 단계의 선후 관계와 조건별 분기가 설명의 중심이어야 한다.

### P3-2 대상심화와의의
- 문단 기능 배열: (가) [배경 제시 / 개념 규정] → 방법 설명 → [범위 확장 / 변화 설명] ｜ (나) 개념 규정 → [특성 설명 / 원인 해명] → [원리 설명 / 유형 분류] → 의의 평가
- 맞는 쟁점 논리: 넓은 관점이나 지향이 특정 대상에서 어떤 고유한 방식으로 드러나는지 설명하는 내용에 맞는다. 대상의 내부 장치와 구현 양상을 알아야 그 효과와 의의도 이해할 수 있다.
- 하위 축 값:
  - 여는 방식: 앞 글은 넓은 배경이나 개념에서 출발하고, 뒤 글은 연결되는 특정 대상을 다시 정의하며 시작한다.
  - 깔아 두는 곳: 앞 글에서 관점과 실천의 큰 방향을 마련하되, 특정 대상의 성립 조건과 고유한 장치는 뒤 글에서 보충한다.
  - 펼치는 순서: 넓은 배경과 접근 방식 → 특정 대상의 규정 → 고유한 장치나 구현 양상 → 효과와 의의
  - 규칙·사례의 위치와 하는 일: 뒤 글의 중간에 놓여 대상의 고유한 성격과 앞선 방향의 구현을 보여 준다. 처리 가능 여부를 판정하는 기능은 중심이 아니다.
  - 끝맺는 방식: 뒤 글에서 설명한 장치나 구현 양상을 효과와 역할의 변화로 묶어 의의를 평가한다.
- 만남 지점과 비워 둔 곳: 앞 글의 방법 설명·범위 확장·변화 설명이 뒤 글의 개념 규정·원리 설명·유형 분류에 이어진다. 비워 둔 연결은 특성 설명과 원리 설명 사이, 구현 양상을 제시하는 문단과 의의 평가 사이에 놓여, 구체적 장치가 앞선 방향을 어떻게 실현하는지 연결하게 한다.
- 예시 기출:
  - 고3 2025년(2026학년도) 9월 평가원 모의평가 4~9번 〈영화와 SF의 사회적 의미와 장르적 특성〉
  - 고1 2024년 6월 교육청 모의평가 16~20번 〈아방가르드와 비디오 아트〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 앞 글을 특정 대상의 배경과 이해 방향을 마련하는 데 쓰고, 뒤 글을 그 대상 자체의 심화 설명으로 구성하려 할 때 고른다. 세부 절차나 이론의 타당성 검토보다 성립 방식과 구현 효과를 밝히는 것이 중요할 때 적합하다.

### P3-3 확장과한계보완
- 문단 기능 배열: (가) 개념 규정 → [비교 대조 / 규칙 제시] → [원리 설명 / 근거 뒷받침] → [특성 설명 / 방법 설명] ｜ (나) 범위 확장 → 원리 설명 → [범위 설정 / 한계 지적] → [반론 대응 / 예외 제시]
- 맞는 쟁점 논리: 기본 설명을 더 넓은 대상이나 복잡한 경우에 옮기면 설명력과 함께 새로운 난점도 생기는 내용에 맞는다. 확장의 가능성뿐 아니라 어디까지 성립하고 무엇을 보완해야 하는지를 다룬다.
- 하위 축 값:
  - 여는 방식: 앞 글은 핵심 개념과 기본 설명을 마련하고, 뒤 글은 설명 대상이나 적용 범위를 넓히며 시작한다.
  - 깔아 두는 곳: 확장에 사용할 개념과 원리는 앞 글에 두고, 확장하면서 추가되는 조건과 난점은 뒤 글에서 제시한다.
  - 펼치는 순서: 기본 설명의 정립 → 범위 확장 → 확장된 설명의 작동 방식 → 경계나 한계 확인 → 대응 또는 예외
  - 규칙·사례의 위치와 하는 일: 확장된 설명 뒤에 놓인 구별과 사례가 설명의 성립 범위와 부담을 드러낸다.
  - 끝맺는 방식: 확장된 설명을 그대로 확정하지 않고, 보완 설명이나 예외를 제시하여 유효한 범위와 남는 제약을 함께 밝힌다.
- 만남 지점과 비워 둔 곳: 앞 글의 개념 규정·원리 설명·근거 뒷받침이 뒤 글의 범위 확장과 원리 설명에서 재사용된다. 비워 둔 연결은 범위 설정과 원리 설명 사이, 한계 지적과 반론 대응·예외 제시 사이에 놓여, 제외되는 경우나 보완 이후에도 남는 제약을 추론하게 한다.
- 예시 기출:
  - 고3 2023년 3월 교육청 모의평가 4~9번 〈모방의 기제와 밈 이론〉
  - 고1 2024년 10월 교육청 모의평가 16~21번 〈불법행위와 손해배상 책임〉
  - 소속 2편
- 이 구조를 고를 조건: 뒤 글을 앞 글의 단순한 사례가 아니라 확장된 설명의 검토 과정으로 만들려 할 때 고른다. 적용 범위의 제한, 반론에 대한 대응, 예외적 처리 가운데 하나가 결말의 핵심이어야 한다.

## P4 비판적 재검토 (10편, 하위 구조 4개, 묶이지 않은 지문 1편)

한 글이 제시한 견해·기준·해석을 다른 글이 검토 대상으로 삼아 타당성과 한계를 따지고, 방어·수정하거나 새 설명으로 바꾼다.

### P4-1 원리선행분지비판
- 문단 기능 배열: (가) 대상 도입 → … ｜ (나) 개념 규정(원리 설명) → … → 비판 반박 ×n → …
- 맞는 쟁점 논리: 검토 대상의 여러 특징이나 그에 대한 해석이 하나의 상위 원리와 양립하는지가 쟁점인 경우에 맞는다. 같은 원리를 서로 다른 측면에 적용하여 기존 견해의 타당성과 인정 범위를 따진다.
- 하위 축 값:
  - 여는 방식: 앞 글은 검토할 대상의 성립·변화·작동을 설명하고, 뒤 글은 검토에 사용할 원리나 개념을 먼저 마련한다.
  - 깔아 두는 곳: 뒤 글의 앞부분에 공통 검토 원리를 모아 두고, 개별 비판에 필요한 보조 기준은 해당 자리에서 보충한다.
  - 펼치는 순서: 검토 원리 마련 → 대상의 여러 측면에 나누어 적용 → 각각의 불일치나 과장 지적
  - 규칙·사례의 위치와 하는 일: 앞서 설명한 특성과 원리가 뒤의 비판에서 판정 자료와 기준으로 다시 쓰인다.
  - 끝맺는 방식: 비판을 재확인하거나 비판의 범위를 조정한다. 난점을 해소하는 별도의 설명 체계를 단계적으로 구축하지는 않는다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞 글의 특성 설명·변화 설명과 뒤 글의 비판 반박 사이, 뒤 글의 개념 규정·원리 설명과 개별 비판 반박 사이에 놓인다. 비워 둔 연결은 일반 원리를 개별 비판에 적용하는 단계나, 앞서 긍정된 특성을 반대 평가의 근거로 바꾸는 단계에 주로 놓인다.
- 예시 기출:
  - 고3 2025년 10월 교육청 모의평가 4~9번 〈천재 미학과 가다머의 철학적 해석학〉
  - 고3 2025년 3월 교육청 모의평가 4~9번 〈쇤베르크의 12음 기법과 현상학적 미학〉
  - 소속 2편
- 이 구조를 고를 조건: 대상에 대한 설명을 먼저 제공한 뒤, 검토 원리를 밝히고 두 갈래 이상의 비판을 펼치려 할 때 고른다. 새 설명의 구축보다 기존 견해의 불일치·과장·적용 범위를 밝히는 데 중심을 둘 때 적합하다.

### P4-2 난점해소재구성
- 문단 기능 배열: (가) 입장 제시 → … ｜ (나) 문제 제기(비판 반박) → 대안 제시(개념 규정) → 사례 적용 → …
- 맞는 쟁점 논리: 기존 구분이나 기준을 유지하면 설명하기 어려운 경우가 생기지만, 대상의 성격·범위·작용 방식을 다시 구분하면 그 난점을 해소할 수 있는 문제에 맞는다.
- 하위 축 값:
  - 여는 방식: 앞 글은 기존 입장과 구분을 마련하고, 뒤 글은 그것으로 처리하기 어려운 사례나 충돌을 내놓는다.
  - 깔아 두는 곳: 새 설명에 필요한 개념과 조건을 난점이 드러난 뒤 차례로 마련한다.
  - 펼치는 순서: 기존 설명의 난점 → 구분이나 범위의 재설정 → 새 설명 구성 → 출발점의 난점 재해명
  - 규칙·사례의 위치와 하는 일: 사례나 추론이 단순한 이해 보조가 아니라 기존 설명을 시험하고 새 설명의 성립을 확인하는 역할을 한다. 앞의 사례를 뒤에서 다시 다룬다.
  - 끝맺는 방식: 새 설명이 난점을 해소하는 방식을 확인하고, 필요하면 성립 조건이나 확장 의의를 덧붙인다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞 글의 입장 제시·개념 규정과 뒤 글의 문제 제기·비판 반박 사이, 뒤 글의 대안 제시·개념 규정과 사례 적용 사이에 놓인다. 비워 둔 연결은 기준 설정·개념 규정에서 예시 구체화·사례 적용으로 넘어갈 때의 분류 관계, 조건 충족 여부, 기존 기준과 새 기준의 판정 차이에 놓인다.
- 예시 기출:
  - 고3 2024년(2025학년도) 6월 평가원 모의평가 12~17번 〈도덕 문장의 성격과 논리적 타당성〉
  - 고2 2024년 10월 교육청 모의평가 16~21번 〈예술작품의 질료와 형상, 기술적 지지체〉
  - 소속 2편
- 이 구조를 고를 조건: 비판을 새 개념 구성의 출발점으로 삼고, 처음의 난점이나 사례를 새 틀로 다시 설명해야 할 때 고른다. 기존 설명의 실패와 새 설명의 성과를 같은 시험 대상에서 보여 주려 할 때 적합하다.

### P4-3 다갈래후속전개
- 문단 기능 배열: (가) 입장 제시 → … ｜ (나) 한계 지적 → 전개 안내 → 입장 제시(대안 제시) ×n → …
- 맞는 쟁점 논리: 기존 논의의 대상 범위·접근 방식·평가 기준에 공통된 한계가 있고, 이를 넘어서는 방향이 하나로 수렴하지 않는 경우에 맞는다. 후속 관점들은 같은 한계를 다른 측면에서 보완하거나 서로 다른 탐구 과업을 맡는다.
- 하위 축 값:
  - 여는 방식: 앞 글은 기존 논의의 배경과 대표 입장을 설명하고, 뒤 글은 그 논의가 공유하는 한계에서 출발한다.
  - 깔아 두는 곳: 뒤 글의 앞부분에 전환의 공통 이유와 후속 논의의 갈래를 제시하고, 갈래별 개념과 근거는 필요한 자리에서 설명한다.
  - 펼치는 순서: 공통 한계 확인 → 복수의 후속 관점·접근 예고 → 갈래별 설명과 대안의 순차 제시
  - 규칙·사례의 위치와 하는 일: 사례는 각 갈래의 설명 방식이나 대안적 가치를 구체화한다. 하나의 출발 사례를 끝에서 다시 해결하는 순환은 필수적이지 않다.
  - 끝맺는 방식: 여러 갈래의 공통 의의를 평가하거나, 마지막 갈래의 대안적 가치·실천 방향을 제시한다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞 글의 입장 제시·원리 설명·기준 설정과 뒤 글의 한계 지적 사이, 뒤 글의 전개 안내와 각 갈래의 입장 제시·대안 제시 사이에 놓인다. 비워 둔 연결은 앞선 설명에서 후속 비판의 대상을 찾아 대응시키는 자리, 대안의 근거에서 구체적 실행 조건이나 판정 차이를 이끌어 내는 자리에 놓인다.
- 예시 기출:
  - 고2 2025년 9월 교육청 모의평가 16~21번 〈푸코의 생명 권력과 신유물론〉
  - 고2 2023년 11월 교육청 모의평가 16~21번 〈기술철학의 관점〉
  - 고1 2023년 11월 교육청 모의평가 16~21번 〈모더니즘과 포스트모더니즘 건축〉
  - 소속 3편
- 이 구조를 고를 조건: 하나의 대체 설명을 완성하기보다 여러 후속 관점과 개선 방향을 펼쳐 보여 주려 할 때 고른다. 각 갈래를 서로 논박시키지 않고, 공통 문제의식 아래 차례로 소개할 수 있을 때 적합하다.

### P4-4 양면교차검토
- 문단 기능 배열: (가) 입장 제시 ×n → … ｜ (나) 개념 규정(기준 설정) → … → 의의 평가(비판 반박) → 의의 평가(한계 지적)
- 맞는 쟁점 논리: 새 기준이 기존 설명의 약점을 드러내지만, 그 기준 역시 다른 설명 과제나 정당화 요구 앞에서는 부담을 갖는 문제에 맞는다. 비판의 근거로 쓰인 것을 다시 평가 대상으로 돌리는 논리이다.
- 하위 축 값:
  - 여는 방식: 앞 글은 검토할 입장과 판단 근거를 마련하고, 뒤 글은 새로운 원리나 판단 기준을 도입한다.
  - 깔아 두는 곳: 새 기준의 의미와 근거를 평가에 앞서 설명하여, 뒤의 비판과 재검토가 함께 사용할 토대를 만든다.
  - 펼치는 순서: 새 기준 도입 → 기존 입장에 대한 효용·비판 → 새 기준의 수용이나 그 기준을 채택한 입장이 지는 부담 검토
  - 규칙·사례의 위치와 하는 일: 같은 기준이나 귀결이 한쪽에서는 정당화의 근거가 되고 다른 쪽에서는 한계의 근거가 된다.
  - 끝맺는 방식: 이점과 부담을 함께 남기거나 비판한 입장 자체의 한계를 드러낸다. 승자나 통합안을 확정하지 않는다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞 글의 입장 제시·기준 설정과 뒤 글의 의의 평가·비판 반박 사이, 뒤 글의 개념 규정·근거 뒷받침과 후반의 한계 지적 사이에 놓인다. 비워 둔 연결은 앞의 해명이 새 조건에서도 유지되는지 확인하는 자리, 서로 다른 기준을 같은 사례에 적용하여 판정 차이를 도출하는 자리에 놓인다.
- 예시 기출:
  - 고3 2023년 10월 교육청 모의평가 12~17번 〈미적 속성의 실재성과 수반론〉
  - 고2 2026년 3월 교육청 모의평가 18~23번 〈생명 중심 윤리(테일러)와 생태 중심 윤리(레오폴드)〉
  - 소속 2편
- 이 구조를 고를 조건: 앞선 입장에 대한 일방향 반박을 넘어서, 그 반박을 가능하게 한 기준이나 입장까지 검토하려 할 때 고른다. 어느 기준도 비용 없이 채택하거나 거부할 수 없음을 보여 주려 할 때 적합하다.

## P5 변화와 대응 (5편, 하위 구조 1개, 묶이지 않은 지문 3편)

한 글이 변화나 문제 상황의 흐름을 설명하고, 다른 글이 그에 맞물린 해석·개혁 구상·제도적 대응을 다룬다.

### P5-1 변천후대조종합
- 문단 기능 배열: (가) [대상 도입 / 배경 제시] → 변화 설명(귀결 제시) ×n ｜ (나) 문제 제기 → [입장 제시 / 대안 제시] ×2 → [관점 조정 / 종합 정리]
- 맞는 쟁점 논리: 한 대상에 대한 이해나 실제 상태가 달라지는 흐름과, 그 대상을 설명하거나 재편하려는 경쟁 입장을 함께 다루는 논리이다. 입장 사이의 차이를 드러내는 데서 그치지 않고 양쪽을 아우르는 이해나 공통 목표를 밝혀야 할 때 맞는다.
- 하위 축 값:
  - 여는 방식: 앞 글은 대상과 배경을 마련하고, 뒤 글은 서로 다른 설명이나 방안이 필요한 공통 문제를 제기한다.
  - 깔아 두는 곳: 변화 이전의 이해를 앞에 마련하고, 뒤 글에서는 공통 쟁점을 먼저 제시한 뒤 각 입장에 필요한 근거와 조건을 나누어 설명한다.
  - 펼치는 순서: 앞 글은 시간에 따른 변화를 추적한다. 뒤 글은 두 입장이나 방안을 병렬적으로 검토한 뒤, 둘을 함께 포괄하는 이해나 공통 지향을 도출한다.
  - 끝맺는 방식: 앞 글은 변화의 결과를 밝히고, 뒤 글은 두 입장의 관계를 다시 묶어 종합한다.
- 만남 지점과 비워 둔 곳: 변화 설명과 입장 제시·대안 제시 사이에서 같은 요소가 변화의 양상과 설명·판단의 근거로 다시 연결된다. 입장 제시·대안 제시 상호 간에는 조건과 적용 범위의 차이를, 관점 조정·종합 정리에서는 두 입장을 함께 묶을 수 있는 이유와 그 종합이 뜻하지 않는 범위를 추론할 자리로 둔다.
- 예시 기출:
  - 고3 2024년 7월 교육청 모의평가 4~9번 〈음악의 정서 표현과 감정 미학〉 · 세 번 중 2
  - 고3 2023년(2024학년도) 9월 평가원 모의평가 12~17번 〈조선 후기 신분제 변화와 개혁론〉
  - 소속 2편
- 이 구조를 고를 조건: 변화의 흐름을 먼저 독립적으로 설명하고, 이어 공통 문제에 대한 두 입장이나 방안을 비교하려 할 때 고른다. 두 입장의 직접적인 계승 관계보다 차이와 종합 가능성을 보여 주는 것이 중요해야 한다.

## P6 기능 분담 (3편, 하위 구조 1개, 묶이지 않은 지문 1편)

하나의 체계가 성립하고 작동하는 데 필요한 서로 다른 기능이나 단계를 글마다 나누어 설명해 전체를 완성한다.

### P6-1 원리와 유형 분담
- 문단 기능 배열: (가) [개념 규정 / 배경 제시] → [원리 설명 / 조건 명시 / 기준 설정] … ｜ (나) [필요성 제시 / 배경 제시] → [과정 설명 / 기준 설정] → 유형 분류 → [비교 대조 / 사례 적용 / 방법 설명] …
- 맞는 쟁점 논리: 하나의 체계를 이해하려면 그것이 성립·작동하는 원리나 요건과, 그 안에서 구별되는 유형들의 차이와 역할을 함께 알아야 하는 경우에 맞는다. 두 글은 서로 다른 설명 과제를 맡되 공통 기능이나 기준을 통해 연결된다.
- 하위 축 값:
  - 글 사이의 분담: 한 글은 성립·작동의 원리와 요건을, 다른 글은 유형별 차이와 역할·활용을 맡는다.
  - 깔아 두는 곳: 각 글이 필요한 공통 틀을 따로 마련한다. 유형을 다루는 글에서는 공통 경로나 비교 기준을 분류보다 앞에 둔다.
  - 펼치는 순서: 한 갈래는 공통 틀 아래 세부 원리·요건을 차례로 설명하고, 다른 갈래는 공통 기준에서 유형 분류로 나아간 뒤 차이와 역할을 구체화한다.
  - 규칙·사례의 위치와 하는 일: 조건과 기준은 세부 설명에 앞서거나 그 안에 나누어 둔다. 분류 뒤의 사례와 활용은 유형별 차이가 실제로 어떻게 드러나는지 보여 준다.
  - 끝맺는 방식: 전체를 다시 종합하기보다 세부 조건의 설명, 유형 간 차이의 구체화 또는 활용으로 마친다.
- 만남 지점과 비워 둔 곳: 글 사이는 개념 규정·배경 제시의 공통 틀에서 만나거나, 원리 설명과 사례 적용·비교 대조가 대응하는 자리에서 만난다. 글 안에서는 유형 분류와 비교 대조·사례 적용 사이, 기준 설정과 방법 설명 사이에 연결이 집중된다. 비워 둔 곳은 원리 설명·조건 명시의 관계를 추론하거나, 앞의 기준을 뒤의 비교 대조·방법 설명에 결합해야 하는 자리다.
- 예시 기출:
  - 고2 2024년 9월 교육청 모의평가 32~37번 〈햅틱 장치와 촉각 인지 과정〉
  - 고2 2026년 6월 교육청 모의평가 11~15번 〈무역계약과 정형 거래 조건 (비엔나 협약 및 인코텀스)〉
  - 소속 2편
- 이 구조를 고를 조건: 한 글에는 원리·요건의 순차적 해명을, 다른 글에는 공통 기준에 따른 분류·비교와 활용을 맡길 수 있을 때 고른다. 뒤 글이 앞 글의 설명을 전제로만 진행하지 않고 자체적인 설명 틀을 갖출 수 있어야 한다.

## P7 근거 종합 논증 (3편, 하위 구조 1개, 묶이지 않은 지문 1편)

앞의 설명 글들이 원리와 판단 기준을 제공하고, 마지막 글(건의하거나 논증하는 글의 초고)이 그것을 근거로 구체적 선택이나 개선 요구를 정당화한다.

### P7-1 효용·위험 종합형
- 문단 기능 배열: 설명 글 둘: {필요성 제시 → 특성 설명 → 귀결 제시}, {원리 설명(원인 해명) → 조건 명시(대안 제시)} ｜ 건의하는 글: 목적 제시(실천 권고) → 문제 제기(한계 지적) → 대안 제시(근거 뒷받침) → 반론 대응 → …
- 맞는 쟁점 논리: 유익하거나 필요한 실천이 현재의 여건 때문에 충분히 이루어지지 않아 개선이 요구되지만, 그 개선에도 부작용이 예상되는 문제다. 필요성을 뒷받침하는 근거와 위험을 다루는 근거를 함께 마련해야 한다.
- 하위 축 값:
  - 여는 방식: 설명부는 개념이나 현상의 도입에서 출발하고, 마지막 글은 개선을 요구하는 목적이나 행동을 먼저 밝힘.
  - 깔아 두는 곳: 앞의 두 설명 글에 실천의 효용·필요성과 위험의 발생 원리·대응 조건을 나누어 마련함.
  - 펼치는 순서: 설명부의 근거들을 현장의 문제 진단과 개선안 정당화에 연결한 뒤, 예상되는 부작용에 대응함. 설명 글의 제시 순서와 근거를 활용하는 순서는 달라도 됨.
  - 규칙·사례의 위치와 하는 일: 앞의 원리와 조건은 뒤의 문제 진단 및 반론 대응을 판단하는 기준이 됨. 마지막 글의 구체적 상황과 사례는 개선의 필요성이나 기대 효과를 뒷받침함.
  - 끝맺는 방식: 반론 대응으로 수용 가능성을 높이며 끝내거나, 개선에 따른 기대 효과를 덧붙임.
- 만남 지점과 비워 둔 곳: 필요성 제시·특성 설명·귀결 제시와 마지막 글의 문제 제기·한계 지적·대안 제시가 만난다. 원리 설명·원인 해명·조건 명시와 반론 대응도 연결된다. 일반적 설명이 구체적 한계를 판정하는 이유, 대안이 앞의 조건을 구현하는 방식, 대응책이 위험의 원인을 줄이는 관계가 주로 생략된다.
- 예시 기출:
  - 고2 2026년 3월 교육청 모의평가 24~27번 〈주민 참여 예산 제도와 공유지의 비극 / 건의하는 글 초고〉
  - 고2 2026년 6월 교육청 모의평가 24~27번 〈공유 자원과 텀블러 세척기 설치 건의〉
  - 소속 2편
- 이 구조를 고를 조건: 현재의 한계를 고칠 방안을 제안하면서 그 방안의 실행 가능성까지 설득해야 할 때 고른다. 앞의 설명들을 마지막 글에서 문제 진단·대안 정당화·반론 대응의 서로 다른 자리에 활용할 수 있어야 한다.
- 주의: 작문 통합형(건의하는 글)이다. 독서 지문 생성기의 대상이 아니다.
