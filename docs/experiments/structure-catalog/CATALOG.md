# 구조 목록 (CATALOG)

작성: 2026-11-14 22:55. 수능·평가원·교육청 독서 기출 158세트(2023~2026년)에서 끌어낸 문단 기능 배열의 목록이다. 생성기의 설계 단계가 쟁점 논리에 맞는 짜임을 고를 때 쓴다.

구조 목록은 문단 기능의 추상적 배열이다. 특정 기출의 배치나 문장을 따라 하게 하는 자료가 아니다. 지문 원문은 어느 파일에도 없다.

- 이 문서: 쓰는 법, 색인(하위 구조 53개), 닮은 구조, 입장 대립형과 과학 배경, 잡지 못하는 것
- 항목 본문(9절 형식): CATALOG-S1-S3.md, CATALOG-S4-S6.md, CATALOG-S7-S9.md, CATALOG-P.md
- 만든 과정: PLAN.md. 1차 유형은 TYPES.md, 하위 구조 원본과 묶이지 않은 지문은 SUBSTRUCTURES.md

## 1. 쓰는 법

1. 설계 단계는 2절 색인에서, 쓰려는 쟁점 논리에 맞는 후보 2~3개를 고른다. 유형의 "고를 때"와 하위 구조의 "맞는 쟁점 논리"를 본다.
2. 후보마다 항목 본문의 "이 구조를 고를 조건"과 대 보고, 이유를 대며 하나를 정한다.
3. 이전 실행에서 쓴 구조는 피한다. 3절에 함께 묶은 닮은 구조도 같은 구조로 보고 피한다.
4. 배열은 문단 기능의 순서다. 문단 수는 내용에 맞게 늘이거나 줄인다. ×n은 되풀이해도 된다는 뜻이다.
5. "만남 지점과 비워 둔 곳"은 고리를 어디에 둘지 정하는 데 쓴다. 비워 둔 곳은 앞 원리로 독자가 채우게 둘 자리다.
6. 끝맺음은 고른 구조의 "끝맺는 방식" 값을 따른다. 참고로 단일 지문 108편 가운데 마지막 문단의 주된 기능이 정리하는 기능(의의 평가 8, 실천 권고 3, 종합 정리 2, 후속 과제 1)인 것은 14편(13%)이다. 나머지 94편은 마지막 문단에서도 비교 대조, 원리 설명, 대안 제시, 방법 설명 같은 내용 기능을 한다.
7. 예시 기출은 짜임을 확인하는 데만 쓴다. 그 기출의 문단 배치나 문장을 따라 하지 않는다.
8. P7(작문 통합형)은 독서 지문 생성기의 대상이 아니다.

배열 표기: → 문단 순서, 괄호는 두 번째 기능, ×n 되풀이, … 생략된 부가 설명, ｜ 글의 경계, [A / B] 둘 중 하나, {A → B} ×n 묶음째 되풀이.

## 3. 닮은 구조

유형이 달라도 배열의 뼈대가 같은 것들이다. 이전 실행의 구조를 피할 때 한 묶음으로 본다. Claude가 배열을 대 보고 묶었다.

| 묶음 | 하위 구조 | 같은 뼈대 |
|---|---|---|
| 한계가 다음 방식을 부른다 | S3-3, S4-3, S5-3 | 방식 → 한계 → 다음 방식 (→ 남는 한계) |
| 공통 기반 뒤 경우를 차례로 | S2-3, S4-1, S6-2 | 공통 원리·기준 → 경우 ×n |
| 비교틀을 짧게, 한 갈래를 깊게 | S4-4, S5-4, S6-4 | 구별·분류 → 한쪽의 세부 조건과 처리 |
| 기초를 먼저 세우고 뒤에서 쓴다 | S1-5, S3-2, S5-2 | 원리·기준 구간 → 작동·실행·선택 |
| 요건을 쌓아 경계를 판별 | S4-5, S6-1 | 개념 → 조건·예외 누적 |

같은 유형 안에서는 S1-1과 S1-5의 배열이 거의 같다. 둘은 축 값으로 갈린다(S1-1은 단계 사이의 전달, S1-5는 독립된 원리 구간과 끝의 파생 성질). 그 밖의 하위 구조는 같은 유형 안에서 배열이 서로 다르다.

## 4. 입장 대립(S7)과 과학 배경

- S7 소속 8편에는 과학을 배경으로 깐 지문이 없다. 생성기가 만드는 "과학 배경 + 입장 대립"에 직접 대응하는 기출은 2023~2026년 158세트 안에 없다.
- 그래서 S7 하위 구조 4개마다 "과학 배경을 둘 자리"를 S1·S2의 깔아 두는 방식에서 빌려 적었다(CATALOG-S7-S9.md). 기출 근거가 아니라 설계 제안이다. 어느 자리든, 과학 내용은 입장 하나의 근거나 판정 조건으로 다시 쓰여야 한다.
- S7은 앞부분보다 뒷부분이 하는 일로 갈렸다: 사례로 다시 대조(S7-1), 앞의 여러 논거를 한꺼번에 재검토(S7-2), 반론 뒤에 근거 보충(S7-3), 입장마다 전제와 귀결을 덩어리로(S7-4).
- 인수인계에 적은 입장 소개 방식은 8편에서 반박 사슬 5편, 차례로 2편, 한꺼번에 1편이다(Claude가 문단 기능 배열을 읽고 셈). 하위 구조를 가르는 기준이라기보다 하위 구조 안에서 고르는 값이다.
- 끝 문단은 관점 조정 2편(한 편은 두 번째 기능), 실천 권고 2편, 사례로 끝 2편, 설명으로 끝 2편이다. 인수인계의 끝맺는 방식 가운데 "종합"으로 끝난 지문은 없다. 종합으로 끝나는 짜임은 (가)(나)의 P5-1 변천후대조종합에 있다.

## 5. 이 목록이 잡지 못하는 것

- M4(다른 교과 노드로 건너가기)는 문단 기능에 드러나지 않아 잡지 못했다. M7(설명 생략)은 "비워 둔 곳"으로 일부 잡았다. 교과 노드를 엮는 일은 생성기의 소재 설계가 맡는다.
- 하위 구조 53개 가운데 37개는 소속이 2편이다(3편 11개, 4편 4개, 5편 1개). 같은 짜임이 기출에 두 번 이상 나왔다는 뜻이지, 흔한 짜임이라는 뜻은 아니다.
- 묶이지 않은 지문 30편(19%)은 같은 짜임의 다른 지문이 없어 목록에 넣지 않았다. 한 편만 보고 만든 구조는 그 기출을 따라 하게 만든다. 지문마다 까닭은 SUBSTRUCTURES.md에 있다.
- 2023~2026년 기출만 봤고, 158세트 가운데 127세트가 교육청 모의평가다.
