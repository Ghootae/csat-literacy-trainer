### 역분해 4지문

| 지문 | 경로·기능 | 만나는 곳 | 비워 둔 곳 |
|---|---|---|---|
| 법인 | M1(1) → M2(2·3) → M3(4) → M6(5)와 맞는다 | [4,5] 잉여금 = 역분해의 "고리가 생긴 곳". [1,5] 통제 필요성 = 외부 유출 기준이 왜 중요한지. 원칙-예외(잉여금으로 손실을 못 메우면 자본금 사용)는 rules에 있다 | 역분해에도 없다 |
| 표면 장력 | M3 → M4 → M7 → M3 → M6과 맞는다. "사례를 나란히 늘어놓다가 마지막만 깊게 판다"를 other에 잡았다 | [1,2,3] 기포 합침, [1,4] 잉크 방울. **놓침**: 표면 장력이 라플라스 식([1])과 오네소르게 수([5])에서 반대로 작용하고, 계면 활성제([2])가 표면 장력을 바꾸는 곳. 역분해에서 블라인드 1위 문항의 정답 자리다 | [3] 기포 합침 = 역분해의 M7 |
| 정보 비대칭 | M4(3) → M5(4) → 판례(5)와 맞는다 | [1,3,4] 완전경쟁 가정 = 역분해의 첫 고리. [3,5] 판례의 의견 대응 | **놓침**: 다수 의견 쪽 관점은 본문에 없이 추론하게 둔 것. notes에는 적었지만 left_to_reader는 비웠다 |
| 의미 | M5(2) → 통제 사고 실험(3) → M3(4)와 맞는다. [3]의 move가 "인식은 같게, 대상만 다르게"를 잡았다 | [1,3] 기술구, [2,4] 외부 대상 | **놓침**: 내재주의라면 두 '물'의 의미를 같다고 볼 것이라는 판정. 본문에 없이 추론하게 둔 것이다 |

만나는 곳은 같은 것을 다시 쓰는 곳은 잘 잡았다. 같은 것이 다르게 작용하는 곳은 표면 장력에서 놓쳤다. 다만 큐비즘의 부피감처럼 잡은 경우도 있다. 비워 둔 곳은 이유를 생략한 것만 잡았고, 한쪽 판정을 추론하게 둔 것은 2편에서 놓쳤다. 지시문이 left_to_reader를 "결과나 판정만 주고 이유는 채우게 둔 것"으로 좁게 정의한 탓으로 본다. 10편 중 left_to_reader가 있는 세트는 3개뿐이다.

## 그 밖에

- 분야 어휘가 섞였다. 입력에 분야가 있던 5편은 DB 코드(social_culture 등)를 그대로 옮겼고, 없던 5편은 한국어(사회, 과학 등)로 썼다.
- features는 화제어를 쓴 긴 서술이다. 4단계(하위 구조)에서 다시 추상화해야 하지만, 확인하기 쉬워서 그대로 둔다.
- features.other는 구조의 특이점을 잘 잡았다.
  - 공손룡: 두 입장의 설명 순서가 비대칭이다. 한쪽은 원칙 → 논변, 다른 쪽은 반론 → 개념 배경 순이다.
  - 의미: 기존 입장은 짧게 두고 대안에 분량을 몰았다.
  - 세포자멸사: 두 경로가 합류해서, 후속 과정은 한 번만 설명한다.
  - 하위 구조를 나누는 축이 될 만하다.
- 전처리(extract.mjs)는 PLAN.md 5절대로 되어 있다. 낱말 풀이를 빼고, 표·그림 제목을 표시하고, (가)(나) 번호를 붙였다. 밑줄 기호는 본문 텍스트에 없고 annotations 위치 정보로만 있었다. 지시문 파일은 PLAN.md 6절과 같다.
- 비용: 10편에 185초, 입력 2.4만·출력 3.4만 토큰이 들었다. 158편이면 약 40분이다.

## 고칠 것 (지시문 2차)

| # | 칸 | 고칠 내용 |
|---|---|---|
| A | function, secondary | 화제어 없이 10자 안팎으로 쓴다. 다른 지문에서 같은 일을 하는 문단에 그대로 붙일 수 있는 이름이어야 한다. 그 지문에 맞춘 내용은 point에 쓴다 |

| C | left_to_reader | 지문이 밝히지 않고 앞 내용으로 추론하게 둔 것으로 넓힌다. 이유를 생략한 것, 한쪽 판정만 밝히고 다른 쪽은 추론하게 둔 것, 방향이나 대응 관계를 밝히지 않은 것. 앞 내용으로도 채울 수 없는 빈 곳은 notes에 적는다 |
| D | field | 입력 분야와 상관없이 인문, 사회, 과학, 기술, 예술 중 하나나 둘 |
| E | texts | 글마다 종류와 목적을 적는다: { "가": { "kind": "…", "purpose": "…" } } |

## 다시 돌린 뒤 볼 것

1. 표면 장력: meetings에 [2]와 [5]·[6]이 표면 장력을 두고 만나는 곳이 들어오는가.
2. 정보 비대칭, 의미: left_to_reader에 추론하게 둔 판정이 들어오는가.
3. 기능 이름: 1차보다 짧아지고, 화제어가 빠지고, 서로 같은 이름이 생기는가.
4. left_to_reader: 넓힌 정의 때문에 지문의 아무 서술이나 들어오지 않았는가.
5. 1차에서 잘 잡은 것(경로, rules, other, (가)(나) 관계)이 나빠지지 않았는가.

다섯 가지가 되면 158편 전체를 돌린다. 1·2를 하나라도 다시 놓치면, 한 번 실행의 우연인지 지시문의 한계인지 보려고 해당 지문만 한 번 더 돌린다.
