|---|---|---|---|

| 방법 설명 | 목표를 달성하거나 과업을 수행하는 데 쓰는 수단과 실행 방식을 설명한다. | 절차 설명이 수행 순서를 조직한다면, 방법 설명은 무엇을 이용해 어떤 방식으로 수행하는지를 밝힌다. | 방법 설명, 방법 구체화, 구현 방식 설명, 해석 방법 소개, 활용 방식 설명 |
