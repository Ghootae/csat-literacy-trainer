### 역분해 4지문

| 지문 | 기능 배열 | 역분해 문서와 대조 |
|---|---|---|
| 법인 | 배경 제시 → 규칙 제시 → 논의 전환 → 구조 설명 → 비교 대조 | [4] 구조 설명 = M3(자산 항목 3분). [2]·[3]이 같은 원리를 두 사례(장학 재단, 주식회사)에 적용하는 M2인데, [3]이 "논의 전환"으로 붙어 사례 대비가 약하게 보인다. [5]는 외부 유출 여부로 절차가 갈리는 판정 규칙(M6)이다. 무상 증자와 배당의 대비가 커서 비교 대조로 갔다. 두 번째 기능에도 조건 명시나 규칙 제시가 없다. 기능 하나로는 "대비를 판정 규칙으로 가른다"를 다 담지 못한다 |
| 표면 장력 | 원리 설명 → 사례 적용 ×3 → 기준 설정 → 조건 명시 | 잘 맞는다. M3 원리 → M4·M7 적용 → 판단 지표 → 적정 범위. "원리를 깔고 사례를 늘어놓다 마지막에 판정 지표"가 배열로 보인다 |
| 정보 비대칭 | 배경 제시 → 문제 제기 → 입장 제시 → 한계 지적 → 예시 구체화 | 대체로 맞는다. [3] 입장 제시 = M4(정보 비대칭 이론을 표현의 자유에 옮김). [4] 한계 지적(+대안 제시) = M5 비판. [5] 판례는 예시 구체화로 갔다. 판례가 두 입장을 실제 의견에 대응시키는 자리라 사례 적용으로 볼 수도 있다 |
| 의미 | 입장 제시 → 대안 제시 → 근거 뒷받침 → 기준 설정 → 의의 평가 | 잘 맞는다. [3] 근거 뒷받침 = 통제 사고 실험. [4] 기준 설정 = 지시 대상을 정하는 기준(실제적 본성, 노동 분업) |

기능 배열은 문단 하나에 기능 하나만 남기므로, 대비와 판정이 겹친 문단(법인 [5])은 한쪽만 보인다. 이런 겹침은 1단계의 meetings, rules와 2단계의 label2에 남아 있다. 4단계(하위 구조)에서 함께 본다.
