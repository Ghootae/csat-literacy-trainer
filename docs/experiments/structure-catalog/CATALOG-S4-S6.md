# 구조 목록: S4~S6

CATALOG.md의 항목 본문이다. 쓰는 법과 색인은 CATALOG.md에 있다. 배열·쟁점 논리·축·만남 지점·고를 조건은 4단계 모델 출력(substructures/*.json)을 그대로 옮겼다. 배열 표기를 맞춘 것(｜ 글 경계, [A / B] 둘 중 하나, {A → B} ×n 묶음 반복, 괄호는 두 번째 기능), 예시 기출의 시험 표시, 과학 배경을 둘 자리, 닮은 구조, 주의는 Claude가 더했다. 예시 기출은 짜임을 확인하는 데만 쓴다. 그 기출의 문단 배치나 문장을 따라 하지 않는다.

## S4 유형·방식 대조 (15편, 하위 구조 5개, 묶이지 않은 지문 2편)

같은 범주나 기능을 공유하는 여러 유형·방식을 같은 기준 위에 놓고, 서로 다른 점과 각각의 성격을 밝힌다.

### S4-1 공통원리병렬
- 문단 기능 배열: 대상 도입(개념 규정) → 원리 설명(특성 설명) → 원리 설명(방법 설명) ×n
- 맞는 쟁점 논리: 같은 결과를 얻는 여러 방식이 개입 대상이나 작동 경로에서 갈리는 내용에 맞는다. 공통 원리를 알면 각 방식의 차이를 이해할 수 있지만, 한 방식의 한계가 다음 방식의 도입을 반드시 이끌지는 않는다.
- 하위 축 값:
  - 여는 방식: 공통 대상이나 현상을 도입하고 여러 방식을 이해할 기초 원리를 마련한다.
  - 깔아 두는 곳: 공통 기반은 앞에 두되, 개별 방식에 필요한 조건과 세부 원리는 해당 설명에 나누어 둔다.
  - 펼치는 순서: 공통 기반에서 출발하여 같은 결과에 이르는 서로 다른 개입 지점이나 작동 경로를 차례로 설명한다.
  - 규칙·사례의 위치와 하는 일: 각 방식의 설명 안에서 작동 조건과 구현 수단을 구체화한다.
  - 끝맺는 방식: 마지막 방식의 설명을 끝내거나 공통 선택 근거·적용 한계를 덧붙인다. 방식들의 우열을 종합 판정하지는 않는다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞의 원리 설명·특성 설명과 뒤의 개별 원리 설명 사이, 또는 서로 다른 방법 설명 사이에 놓인다. 비워 둔 곳은 앞에서 제시한 관계를 개별 조건에 적용하거나 관계의 변화 방향을 뒤집어 읽는 원리 설명·조건 명시 사이에 주로 놓인다.
- 예시 기출:
  - 고3 2023년 3월 교육청 모의평가 14~17번 〈초임계 유체를 이용한 결정화 공정〉
  - 고3 2025년 10월 교육청 모의평가 14~17번 〈연소의 원리와 소화 방식〉 · 세 번 중 2
  - 소속 3편 (예시 밖 1편)
- 이 구조를 고를 조건: 공통 기반을 먼저 설명하여 반복을 줄이고, 각 방식은 독립된 설명 단위로 차례로 펼치려 할 때 고른다. 방식마다 필요한 조건이나 세부 원리를 설명 도중에 보충할 수 있어야 한다.
- 닮은 구조: S2-3, S6-2 (공통 기반을 앞에 두고 경우를 차례로 편다)

### S4-2 항목대응대조
- 문단 기능 배열: 대상 도입(유형 분류) → {개념 규정(원리 설명) → 특성 설명(절차 설명)} ×n → 비교 대조(귀결 제시)
- 맞는 쟁점 논리: 공통 목적을 지닌 대상들이 목적의 구체화, 작동 과정, 성립 조건, 결과에서 어떻게 다른지 대응시켜야 하는 내용에 맞는다. 따로 읽으면 비슷해 보이는 설명도 동일한 항목 위에 놓으면 차이가 드러난다.
- 하위 축 값:
  - 여는 방식: 공통 목적이나 구분 틀을 먼저 제시한다.
  - 깔아 두는 곳: 공통점은 앞에 마련하고, 각 대상의 개념·작동·조건은 해당 설명 묶음 안에 배치한다.
  - 펼치는 순서: 대상별 설명 묶음을 차례로 제시하되 대응하는 항목을 반복하고, 마지막에는 같은 항목을 직접 맞대어 차이를 선명하게 한다.
  - 규칙·사례의 위치와 하는 일: 개별 설명에서 마련한 조건을 공통 상황이나 성능 항목에 연결하여 결과 차이를 드러낸다.
  - 끝맺는 방식: 마지막 대응 항목의 차이나 결과 차이를 밝힌다. 종결 대조는 마지막 대상의 설명 안에 통합될 수도 있다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 서로 다른 대상의 개념 규정·특성 설명·절차 설명 사이와, 이 설명들이 마지막 비교 대조로 회수되는 자리에 놓인다. 비워 둔 곳은 개별 조건을 공통 상황에 겹쳐 적용하여 결과 차이를 도출하는 비교 대조·귀결 제시 사이에 주로 놓인다.
- 예시 기출:
  - 고2 2024년 10월 교육청 모의평가 30~34번 〈지상권과 지역권〉
  - 고1 2025년 3월 교육청 모의평가 34~38번 〈형사법과 민사법의 목적과 소송 절차〉
  - 고1 2023년 9월 교육청 모의평가 34~38번 〈디지털 이미지 워터마킹〉
  - 소속 3편
- 이 구조를 고를 조건: 각 대상을 독립적으로 설명할 필요가 있으면서도, 설명 항목을 대응시켜 읽게 하고 싶을 때 고른다. 뒤의 직접 대조가 앞선 개별 설명을 근거로 삼도록 설계한다.

### S4-3 한계매개전환
- 문단 기능 배열: 대상 도입(개념 규정) → 원리 설명(과정 설명) → 한계 지적 → 원리 설명(비교 대조) ×n
- 맞는 쟁점 논리: 같은 과제를 수행하는 방식들의 차이를 기준 방식의 취약 조건이나 성능 제약을 통해 드러내는 내용에 맞는다. 한계는 다음 설명으로 넘어가는 연결 고리이자 여러 방식을 견주는 비교 축이 된다.
- 하위 축 값:
  - 여는 방식: 공통 과제나 목적을 제시하고 기준이 되는 방식으로 들어간다.
  - 깔아 두는 곳: 먼저 설명한 방식의 작동 조건을 뒤의 한계와 비교를 이해하는 기반으로 사용한다.
  - 펼치는 순서: 기준 방식의 작동과 제약을 밝힌 뒤, 다른 조건이나 기준을 채택한 방식으로 이동한다. 필요하면 중간에 보완 방법과 그 한계를 끼운다.
  - 규칙·사례의 위치와 하는 일: 한계를 드러내는 사례와 새 방식의 차이를 설명하는 규칙을 각 전환 지점에 둔다.
  - 끝맺는 방식: 마지막 방식의 차별적 효과·의의 또는 여전히 남는 제약을 밝힌다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞의 원리 설명·과정 설명과 한계 지적 사이, 한계 지적과 뒤의 원리 설명·비교 대조 사이에 놓인다. 비워 둔 곳은 앞의 작동 조건으로 한계의 중간 원인을 보충하거나, 새 방식의 규칙에서 효과와 잔여 제약을 추론하는 자리에 주로 놓인다.
- 예시 기출:
  - 고1 2025년 3월 교육청 모의평가 30~33번 〈식물의 광합성 효율과 C3, C4 식물〉 · 세 번 중 2
  - 고1 2024년 9월 교육청 모의평가 21~25번 〈동형암호의 원리와 특징〉 · 세 번 중 2
  - 소속 3편 (예시 밖 1편)
- 이 구조를 고를 조건: 방식들을 처음부터 대등하게 나열하기보다, 먼저 설명한 방식에서 무엇이 제한되는지 보여 준 뒤 차이를 이해시키려 할 때 고른다. 다른 방식이 바꾼 부분과 그대로 유지한 부분을 함께 드러낼 수 있어야 한다.
- 닮은 구조: S3-3, S5-3 (앞 방식의 한계가 다음 방식을 부른다)

### S4-4 초점축소재분류
- 문단 기능 배열: 개념 규정(절차 설명) → 조건 명시(필요성 제시) → 유형 분류(비교 대조) → 비교 대조(유형 분류) ×n
- 맞는 쟁점 논리: 하나의 갈래 안에서도 구분 기준을 달리하면 서로 다른 유형 체계가 만들어지는 내용에 맞는다. 각 분류가 무엇을 가르고 어떤 차이를 설명하는지 분리하여 보여 주어야 한다.
- 하위 축 값:
  - 여는 방식: 전체를 이해하거나 판단하는 공통 개념과 조건을 먼저 제시한다.
  - 깔아 두는 곳: 뒤의 여러 분류에 공통으로 쓰일 기준은 앞에 마련하고, 개별 분류 기준은 해당 비교 직전에 덧붙인다.
  - 펼치는 순서: 전체의 큰 구분에서 한 갈래로 초점을 좁힌 뒤, 그 갈래를 서로 독립된 기준으로 거듭 나눈다.
  - 규칙·사례의 위치와 하는 일: 앞의 공통 조건을 재사용하여 각 분류의 경계, 조건별 성능, 결과 차이의 근거를 밝힌다.
  - 끝맺는 방식: 마지막 분류 기준에 따른 차이와 그 근거·적용 범위를 설명하며 끝낸다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞의 개념 규정·조건 명시와 뒤의 비교 대조 사이, 상위 유형 분류와 하위 유형 분류 사이에 놓인다. 비워 둔 곳은 공통 조건을 특정 하위 유형에 적용하여 성능 차이의 이유를 보충하거나, 앞서 소개한 인접 유형과의 경계를 완성하는 자리에 놓인다.
- 예시 기출:
  - 고3 2025년 7월 교육청 모의평가 10~13번 〈콘크리트 보강법: 철근 및 프리스트레스트 콘크리트〉
  - 고1 2024년 9월 교육청 모의평가 33~37번 〈형법상 범죄 성립 요건과 과실범〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 전체 체계를 짧게 마련한 뒤 특정 갈래를 깊게 다루고 싶을 때 고른다. 뒤따르는 여러 구분이 연속된 단계가 아니라 별개의 분류 축임을 드러내야 할 때 특히 적합하다.
- 닮은 구조: S5-4, S6-4 (비교틀을 짧게 두고 한 갈래를 깊게 판다)

### S4-5 경계조건누적
- 문단 기능 배열: 대상 도입(배경 제시) → 개념 규정(유형 분류) → {개념 규정(비교 대조) → 조건 명시(예외 제시)} ×n
- 맞는 쟁점 논리: 유사한 유형들을 짧은 정의만으로 구별하기 어렵고, 성립 조건·제외 조건·결과 차이까지 확인해야 경계가 분명해지는 내용에 맞는다. 뒤에서 제시한 기준이 앞의 정의를 한정하거나 완성할 수 있다.
- 하위 축 값:
  - 여는 방식: 친숙한 대상이나 배경에서 출발하여 공통 범주와 개념 체계를 마련한다.
  - 깔아 두는 곳: 상위 범주와 공통 판단 단위는 앞에 두고, 세부 조건·예외·제외 범위는 각 유형을 설명하는 곳에 나누어 둔다.
  - 펼치는 순서: 정의와 대조를 이어 가면서 조건과 예외를 누적하여 유사 유형들의 경계를 완성한다.
  - 규칙·사례의 위치와 하는 일: 정의만으로 판별하기 어려운 경계 사례를 중간중간 배치하여 포함·제외 범위와 결과 차이를 밝힌다.
  - 끝맺는 방식: 마지막 인접 유형의 정의나 적용 범위를 설명하며 끝낸다. 별도의 종합이나 선택 권고는 두지 않는다.
- 만남 지점과 비워 둔 곳: 만나는 곳은 상위 개념 규정과 개별 유형의 조건 명시 사이, 앞의 정의·예외 제시와 뒤의 개념 규정 사이에 놓인다. 비워 둔 곳은 분산된 정의와 조건을 결합하여 경계 사례의 포함 여부나 결과 차이를 추론하는 자리에 주로 놓인다.
- 예시 기출:
  - 고3 2025년 7월 교육청 모의평가 14~17번 〈행정법상의 금지와 허가〉
  - 고1 2025년 9월 교육청 모의평가 22~26번 〈건축법상의 건축 유형〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 여러 유형의 판별 경계를 단계적으로 정교하게 만들고 싶을 때 고른다. 절차를 따라 결론을 산출하기보다, 어떤 대상이 어느 유형에 포함되는지와 인접 유형과 어떻게 다른지를 밝히는 데 적합하다.
- 닮은 구조: S6-1 (요건·조건을 쌓아 경계를 판별한다)

## S5 문제와 보완 (15편, 하위 구조 5개, 묶이지 않은 지문 3편)

문제 상황이나 기존 방식의 결함에서 출발해, 그것을 줄이는 방안이 어떻게 작동하는지 설명하고 남는 한계를 점검한다.

### S5-1 보완후정당화
- 문단 기능 배열: 대상 도입(한계 지적) → 배경 제시 → 방법 설명(대안 제시) → 비교 대조(반론 대응)
- 맞는 쟁점 논리: 기존 방식의 결함을 줄이는 방안이 새로운 우려나 가치 충돌을 낳는 문제에 맞는다. 작동 효과뿐 아니라 그 방안을 받아들일 이유까지 설명해야 하는 논리이다.
- 하위 축 값:
  - 여는 방식: 기존 방식의 성격과 결함을 함께 제시하여 보완의 필요성을 마련함
  - 깔아 두는 곳: 대안의 배경은 앞이나 중간에, 대안의 정당성을 검토할 조건은 실행 방식과 함께 마련함
  - 펼치는 순서: 기존 방식의 결함 → 보완의 배경과 실행 방식 → 보완 자체에 제기되는 비판과 응답
  - 끝맺는 방식: 효과를 정리하기보다 대안의 정당성을 둘러싼 논거를 대조하거나 비판에 응답함
- 만남 지점과 비워 둔 곳: 배경 제시·비교 대조와 방법 설명 사이에서 전제와 실행 방향이 만난다. 방법 설명·조건 명시에서 마련한 수단이나 조건은 뒤의 비교 대조·반론 대응에서 정당화 근거로 다시 쓰이며, 논거로부터 입장이나 판정을 이끌어 내는 연결을 비워 둘 수 있다.
- 예시 기출:
  - 고3 2025년(2026학년도) 9월 평가원 모의평가 10~13번 〈공공 저널리즘의 등장과 특징〉
  - 고3 2023년(2024학년도) 11월 수능 4~7번 〈경마식 보도와 선거 방송 토론회〉
  - 소속 2편
- 이 구조를 고를 조건: 보완책을 소개한 뒤 그 자체에 대한 비판을 별도의 검토 대상으로 삼으려 할 때 고른다. 결말을 남은 기술적 제약보다 정당화 논거의 검토에 두려는 경우에 적합하다.

### S5-2 기준선행선택
- 문단 기능 배열: 대상 도입 → 개념 규정(기준 설정) → 원리 설명(기준 설정) → 대안 제시(한계 지적) → 과정 설명 → 귀결 제시(한계 지적)
- 맞는 쟁점 논리: 목표를 달성하는 여러 경로 가운데 일부가 현실적 제약으로 제한되는 문제에 맞는다. 선택된 대안이 목표를 이루는 과정과 그 대가를 같은 기준으로 설명하는 논리이다.
- 하위 축 값:
  - 여는 방식: 문제 경험이나 전체 작동을 도입하고, 개선 여부를 판단할 기준으로 논의를 좁힘
  - 깔아 두는 곳: 핵심 지표와 관계는 대안 선택 전에 마련하고, 선택된 방식의 세부 원리는 작동 설명에 맞추어 보충함
  - 펼치는 순서: 판단 기준 마련 → 가능한 구성이나 개선 경로 검토 → 제약에 따른 대안 선택 → 작동 과정 → 부담과 미해결 범위
  - 규칙·사례의 위치와 하는 일: 앞의 관계와 지표가 중간의 선택을 뒷받침하고, 뒤에서는 결과나 부담을 도출하는 기준으로 재사용됨
  - 끝맺는 방식: 선택한 방식이 치르는 비용이나 해결하지 못한 범위를 밝힘
- 만남 지점과 비워 둔 곳: 기준 설정과 대안 제시 사이에서 지표가 선택 근거로 전환된다. 앞의 원리 설명·기준 설정은 뒤의 과정 설명·귀결 제시와 만나며, 개별 관계를 전체 결과로 일반화하거나 작동상 손실을 추가 부담으로 연결하는 중간 추론을 비워 둘 수 있다.
- 예시 기출:
  - 고3 2024년 3월 교육청 모의평가 10~13번 〈디지털카메라의 이미지 센서와 ADC〉
  - 고1 2023년 3월 교육청 모의평가 38~42번 〈OLED 스마트폰의 야외 시인성 개선 기술〉
  - 소속 2편
- 이 구조를 고를 조건: 대안의 작동에 앞서 왜 그 경로를 택하는지 납득시켜야 할 때 고른다. 앞에서 정의한 지표나 관계를 마지막 부담 평가에 다시 활용할 수 있어야 한다.
- 닮은 구조: S1-5, S3-2 (기초 원리·기준을 먼저 세우고 뒤에서 쓴다)

### S5-3 연쇄재보완
- 문단 기능 배열: 배경 제시 → 원리 설명 → 한계 지적 → 대안 제시(원리 설명) → 한계 지적 → 대안 제시(조건 명시)
- 맞는 쟁점 논리: 한 번의 대응으로 문제가 닫히지 않고, 개선된 방식의 잔여 제약이나 새 상황이 다음 대응을 요구하는 문제에 맞는다. 각 방안은 독립적으로 나열되는 것이 아니라 앞선 방안의 미해결 부분에서 도출된다.
- 하위 축 값:
  - 여는 방식: 기본 작동이나 대응 필요성을 제시하여 첫 방안을 평가할 토대를 마련함
  - 깔아 두는 곳: 공통 원리는 앞에 두되, 후속 방안을 이해할 조건은 해당 방안이 등장할 때 보충함
  - 펼치는 순서: 앞선 방식의 한계 → 보완책 → 보완책에도 남는 제약이나 후속 상황 → 재보완
  - 규칙·사례의 위치와 하는 일: 각 단계의 조건과 관계가 다음 보완책의 도입 이유가 되며, 같은 기준으로 개선과 제약을 함께 드러냄
  - 끝맺는 방식: 추가 보완 방향을 제시하거나 마지막 보완책에 필요한 제한을 덧붙임
- 만남 지점과 비워 둔 곳: 한계 지적과 다음 대안 제시 사이가 주된 접합부이다. 앞의 원리 설명·조건 명시는 뒤의 한계 지적·예외 제시에서 다시 쓰이며, 조건 변화가 효과를 막는 경로나 추가 보완이 기존 관계를 어떻게 수정하는지의 일부를 비워 둘 수 있다.
- 예시 기출:
  - 고3 2024년 10월 교육청 모의평가 4~7번 〈리튬 이온 이차 전지의 원리와 구성〉

  - 소속 4편 (예시 밖 1편)
- 이 구조를 고를 조건: 둘 이상의 대응을 발전 순서나 적용 상황의 변화에 따라 연결하려 할 때 고른다. 다음 방안이 필요한 이유를 바로 앞 방안의 한계에서 구체적으로 설명할 수 있어야 한다.
- 닮은 구조: S3-3, S4-3 (앞 방식의 한계가 다음 방식을 부른다)

### S5-4 갈래별심화
- 문단 기능 배열: 대상 도입(필요성 제시) → 특성 설명(방법 설명) → 특성 설명(필요성 제시) → 대안 제시 → 규칙 제시(절차 설명)
- 맞는 쟁점 논리: 공통 목표 아래 구별되는 갈래마다 대응 이유와 방식을 달리 설명해야 하는 문제에 맞는다. 갈래들을 같은 비중으로 비교하기보다 하나를 더 깊게 따라가며 실행 수준까지 구체화하는 논리이다.
- 하위 축 값:
  - 여는 방식: 공통의 필요성이나 대상의 범위를 정하고 복수의 갈래를 마련함
  - 깔아 두는 곳: 각 갈래를 설명하는 자리에서 필요한 성격과 기준을 나누어 제시함
  - 펼치는 순서: 첫 갈래의 성격과 대응 → 다음 갈래의 성격과 대응 → 뒤 갈래의 추가 문제나 적용 상황을 심화
  - 규칙·사례의 위치와 하는 일: 갈래별 대응을 설명할 때 선택 기준을 제시하고, 후반에는 실행이나 운영을 제한하는 규칙과 절차를 구체화함
  - 끝맺는 방식: 실행 절차를 완성하거나 공통 운영 규칙을 덧붙여 닫음
- 만남 지점과 비워 둔 곳: 개념 규정·기준 설정에서 마련한 공통 요소가 갈래별 특성 설명·방법 설명에서 재사용된다. 필요성 제시와 대안 제시 사이, 방법 설명과 절차 설명 사이에 선택 이유나 효과의 중간 경로를 비워 둘 수 있다.
- 예시 기출:
  - 고3 2023년(2024학년도) 11월 수능 8~11번 〈데이터의 결측치와 이상치 처리〉 · 세 번 중 2
  - 고2 2025년 9월 교육청 모의평가 34~37번 〈과징금 제도〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 먼저 소개한 갈래는 기본 대응까지 설명하고, 뒤의 갈래는 추가 조건이나 운영 문제까지 확장하려 할 때 고른다. 마지막을 비교의 결론보다 실제 처리·운영 절차로 마무리하려는 경우에 적합하다.
- 닮은 구조: S4-4, S6-4 (비교틀을 짧게 두고 한 갈래를 깊게 판다)

### S5-5 대안선행해설
- 문단 기능 배열: 배경 제시(대안 제시) → 특성 설명(개념 규정) → 원리 설명 → 한계 지적(후속 과제)
- 맞는 쟁점 논리: 대응 방향은 이미 정해져 있지만 그것이 왜 효과를 내는지, 어떤 조건에서는 충분하지 않은지를 설명해야 하는 문제에 맞는다. 한 대안의 작동 경로를 세운 다음 그 경로의 제약을 점검하는 논리이다.
- 하위 축 값:
  - 여는 방식: 기존 방식의 약점이나 대응이 필요한 상황에서 설명할 대안을 일찍 도입함
  - 깔아 두는 곳: 대안의 방향을 먼저 밝힌 뒤 핵심 개념과 성질을 집중적으로 마련함
  - 펼치는 순서: 문제와 대응 방향 → 기초 개념·성질 → 작동 원리와 효과 → 효과가 제한되는 조건
  - 규칙·사례의 위치와 하는 일: 중간의 관계와 사례가 작동 경로를 이해시키며, 필요하면 원리 설명 뒤에 사례 적용을 덧붙임
  - 끝맺는 방식: 기대 효과를 인정한 뒤 성립 조건의 미충족이나 남은 개선 과제를 제시함
- 만남 지점과 비워 둔 곳: 처음의 배경 제시·대안 제시와 마지막 한계 지적 사이에서 같은 평가 기준이나 문제 상황이 되돌아온다. 특성 설명·원리 설명과 뒤의 효과·한계 사이에는 구성 요소의 역할이나 인과 경로의 중간 단계를 추론하도록 남길 수 있다.
- 예시 기출:
  - 고2 2024년 6월 교육청 모의평가 38~42번 〈페로브스카이트 태양전지〉
  - 고1 2023년 3월 교육청 모의평가 19~22번 〈유동성과 금리의 관계〉
  - 소속 2편
- 이 구조를 고를 조건: 대안을 고르는 과정 자체보다 선택된 대안의 원리 해설에 본문의 중심을 두려 할 때 고른다. 끝의 추가 방안은 새 체계로 상세히 전개하기보다 한계에 대한 보완 방향으로 남길 수 있다.

## S6 요건과 규율 (16편, 하위 구조 5개, 묶이지 않은 지문 2편)

무엇이 인정·허용되고 어떤 처리가 뒤따르는지를 요건·규칙·예외·유형 구분으로 체계화한다.

### S6-1 요건 누적 심사
- 문단 기능 배열: 개념 규정 → 조건 명시 ×n → 예외 제시
- 맞는 쟁점 논리: 하나의 인정 여부가 여러 요건의 결합으로 결정되며, 요건 충족 뒤에도 별도의 제한을 확인해야 하는 문제에 맞는다.
- 하위 축 값:
  - 여는 방식: 개념과 기본 작동을 소개하면서 그 필요성이나 효용을 밝힘
  - 깔아 두는 곳: 기본 개념은 앞에 두고, 개별 요건을 이해하는 데 필요한 구분은 해당 요건에서 보충함
  - 펼치는 순서: 함께 충족해야 하는 요건을 차례로 쌓은 뒤, 요건을 갖추어도 적용이 제한되는 경우를 밝힘
  - 규칙·사례의 위치와 하는 일: 각 요건 안에 사례를 배치하여 포함·배제의 경계와 요건 사이의 차이를 가름
- 만남 지점과 비워 둔 곳: 개념 규정과 조건 명시 사이에서 기본 작동이 세부 요건으로 구체화된다. 조건 명시 사이에서는 앞의 구분이 뒤의 요건에 재사용되며, 조건 명시와 예외 제시 사이에서는 요건 충족과 최종 적용을 구별하는 추론이 놓인다.
- 예시 기출:
  - 고3 2024년 10월 교육청 모의평가 8~11번 〈상계의 법적 개념과 요건〉
  - 고2 2023년 11월 교육청 모의평가 22~25번 〈행정법상의 신뢰보호원칙〉
  - 소속 2편
- 이 구조를 고를 조건: 경우들을 병렬로 나누기보다 동일한 대상에 여러 점검을 누적해야 할 때 고른다. 개별 요건의 뜻뿐 아니라 요건 간 결합 관계를 이해시키려는 설계에 적합하다.
- 닮은 구조: S4-5 (요건·조건을 쌓아 경계를 판별한다)

### S6-2 분기별 규율
- 문단 기능 배열: 기준 설정(조건 명시) → 유형 분류 → 규칙 제시(조건 명시) ×n → 범위 설정
- 맞는 쟁점 논리: 같은 목적 아래 놓인 여러 경우가 서로 다른 기준이나 처리에 연결되는 내용에 맞는다. 공통 전제는 유지하되 어느 갈래에 해당하는지를 먼저 판별해야 한다.
- 하위 축 값:
  - 깔아 두는 곳: 여러 갈래에 공통으로 쓰이는 기준과 적용 전제를 앞에 마련함
  - 펼치는 순서: 공통 토대에서 경우들을 나누고, 갈래별 조건과 처리를 차례로 대응시킴
  - 규칙·사례의 위치와 하는 일: 갈래별 설명 안에서 규칙과 예외를 함께 제시하며, 사례는 갈래의 경계를 판별하게 함
  - 끝맺는 방식: 별도 종합 없이 마지막 갈래의 적용 범위를 정하거나, 앞의 기준을 인접한 판단에 재사용함
- 만남 지점과 비워 둔 곳: 기준 설정과 규칙 제시 사이에서 앞의 분류 기준이 실제 처리의 차이로 이어진다. 유형 분류와 각 규칙 제시 사이에는 공통 전제를 다시 적용하는 추론이, 규칙 제시와 범위 설정 사이에는 예외의 적용 여부나 기준의 추가 쓰임을 판단하는 추론이 놓인다.
- 예시 기출:
  - 고3 2025년 3월 교육청 모의평가 10~13번 〈상장 법인의 공시 의무와 미공개중요정보 이용행위 규제〉
  - 고2 2025년 10월 교육청 모의평가 26~30번 〈형법의 범죄 성립 요건과 죄수 판단〉
  - 고1 2024년 6월 교육청 모의평가 26~30번 〈법의 효력〉
  - 소속 4편 (예시 밖 1편)
- 이 구조를 고를 조건: 독자가 공통 기준을 확보한 뒤 경우별 처리표를 구성하게 하려 할 때 고른다. 한 갈래의 성립 요건을 계속 누적하는 내용보다 여러 적용 경로를 구별하는 내용에 적합하다.
- 닮은 구조: S2-3, S4-1 (공통 기반을 앞에 두고 경우를 차례로 편다)

### S6-3 예외 후 보완
- 문단 기능 배열: 문제 제기 → 규칙 제시 → 예외 제시(조건 명시) → 규칙 제시(절차 설명)
- 맞는 쟁점 논리: 일반 규칙을 그대로 적용하면 문제가 생겨 예외가 필요하지만, 예외 하나만으로 전체 처리가 완결되지 않는 쟁점에 맞는다.
- 하위 축 값:
  - 여는 방식: 판단할 상황을 먼저 내놓거나, 기본 요건을 설명한 직후 그 요건에서 벗어난 문제를 드러냄
  - 깔아 두는 곳: 일반적인 처리 기준을 먼저 확보하고, 예외와 보완책의 조건은 도입할 때마다 추가함
  - 펼치는 순서: 일반 규칙에서 특별 처리로 나아간 뒤, 특별 처리만으로 해결되지 않는 경우나 그로 인한 불균형을 보완함
  - 끝맺는 방식: 중심 사례의 판정만으로 닫지 않고 별도 처리 경로나 적용 제외 범위를 덧붙임
- 만남 지점과 비워 둔 곳: 문제 제기와 예외 제시 사이에서 도입 상황을 특별 처리의 조건에 연결한다. 예외 제시와 뒤의 규칙 제시·절차 설명 사이에서는 같은 조건이 서로 다른 처리 경로에 어떻게 작용하는지 비교하게 하며, 도입 사례의 구체적인 최종 판정은 비워 둘 수 있다.
- 예시 기출:
  - 고2 2025년 6월 교육청 모의평가 26~30번 〈민법의 대리제도와 표현대리〉
  - 고1 2025년 6월 교육청 모의평가 21~25번 〈미성년자의 계약 취소와 보호 제도〉
  - 소속 2편
- 이 구조를 고를 조건: 일반 규칙과 예외를 대비시키는 데서 그치지 않고, 예외가 인정되지 않을 때의 처리나 예외로 불리해진 쪽의 보완책까지 설계해야 할 때 고른다.

### S6-4 비교틀과 집중
- 문단 기능 배열: 유형 분류(비교 대조) → 규칙 제시 → 논의 전환 → 규칙 제시(조건 명시) ×n → 귀결 제시
- 맞는 쟁점 논리: 서로 가까운 대상들을 구별해야 하지만 설명의 중심은 그중 하나의 세부 처리에 있는 내용에 맞는다. 나머지 대상은 독립적인 설명 목표이면서도 중심 대상을 이해하는 비교 기준이 된다.
- 하위 축 값:
  - 깔아 두는 곳: 비교할 대상들의 기본 구별을 마련하고, 선택한 대상을 심화할 때 필요한 구성이나 별도 기준을 추가함
  - 펼치는 순서: 여러 대상을 같은 깊이로 병렬 설명하지 않고, 비교틀을 확보한 뒤 한쪽의 세부 조건과 후속 처리에 집중함
  - 규칙·사례의 위치와 하는 일: 앞의 구별은 뒤의 세부 처리 차이를 해명하는 기준으로 쓰이며, 사례는 허용 범위나 처리 결과의 차이를 드러냄
  - 끝맺는 방식: 집중한 대상의 실행 차이·파생 결과·최종 제한 가운데 하나를 밝힘
- 만남 지점과 비워 둔 곳: 유형 분류·비교 대조와 뒤의 규칙 제시 사이에서 앞의 구별이 재사용된다. 규칙 제시와 귀결 제시 사이에는 기본 성질로부터 후속 처리를 도출하는 추론이 놓이며, 앞에서 제시한 제한을 뒤의 구체적 방식마다 반복하지 않을 수 있다.
- 예시 기출:
  - 고3 2025년 10월 교육청 모의평가 10~13번 〈법인의 종류와 자산 운용의 법적 통제〉
  - 고3 2024년(2025학년도) 9월 평가원 모의평가 4~7번 〈재판매 가격 유지 행위와 부당 광고 규제〉
  - 고1 2023년 9월 교육청 모의평가 30~33번 〈법률행위의 무효와 취소〉
  - 소속 4편 (예시 밖 1편)
- 이 구조를 고를 조건: 유사한 대상의 차이를 먼저 확보해야 중심 대상의 조건과 결과를 오해하지 않을 때 고른다. 모든 대상을 대칭적으로 설명할 필요는 없고 한쪽을 더 깊게 펼쳐야 하는 설계에 적합하다.
- 닮은 구조: S4-4, S5-4 (비교틀을 짧게 두고 한 갈래를 깊게 판다)

### S6-5 단계 속 분기
- 문단 기능 배열: 배경 제시 → 절차 설명 → 방법 설명(조건 명시) ×n → 귀결 제시(규칙 제시)
- 맞는 쟁점 논리: 하나의 처리가 여러 단계를 거쳐 완결되며, 그중 특정 단계에서 방식 선택이나 오류 보정이 필요한 내용에 맞는다.
- 하위 축 값:
  - 여는 방식: 기본 관계를 설명하거나 전체 진행 단계를 예고하여 처리의 출발점을 마련함
  - 깔아 두는 곳: 전체 절차를 먼저 잡고, 세부 방식의 선택 조건과 보정 조건은 해당 단계에 배치함
  - 펼치는 순서: 큰 진행 순서를 따라가되 특정 단계 안에서 여러 처리 방식으로 갈라졌다가 최종 처리로 돌아옴
  - 끝맺는 방식: 최종 선택의 기준이나 처리의 완료 경로를 제시하여 전체 절차를 닫음
- 만남 지점과 비워 둔 곳: 절차 설명과 방법 설명 사이에서 전체 단계가 세부 경로로 구체화된다. 방법 설명 사이에서는 공통 조건과 경로별 차이를 비교하게 하며, 앞의 단계 구분이나 배분 기준을 뒤의 보정·완료 처리에 다시 적용하는 추론이 놓인다.
- 예시 기출:
  - 고2 2024년 9월 교육청 모의평가 28~31번 〈공동 소유와 공유물 분할〉
  - 고2 2024년 6월 교육청 모의평가 21~25번 〈조세 채권과 납세 의무〉
  - 소속 2편
- 이 구조를 고를 조건: 독자가 전체 진행 순서와 단계 내부의 조건별 분기를 함께 이해해야 할 때 고른다. 방식들을 독립적으로 열거하기보다 어느 단계에서 어떤 경로를 택하는지 보여 주려는 설계에 적합하다.
