# 구조 목록: S1~S3

CATALOG.md의 항목 본문이다. 쓰는 법과 색인은 CATALOG.md에 있다. 배열·쟁점 논리·축·만남 지점·고를 조건은 4단계 모델 출력(substructures/*.json)을 그대로 옮겼다. 배열 표기를 맞춘 것(｜ 글 경계, [A / B] 둘 중 하나, {A → B} ×n 묶음 반복, 괄호는 두 번째 기능), 예시 기출의 시험 표시, 과학 배경을 둘 자리, 닮은 구조, 주의는 Claude가 더했다. 예시 기출은 짜임을 확인하는 데만 쓴다. 그 기출의 문단 배치나 문장을 따라 하지 않는다.

## S1 작동 해명 (22편, 하위 구조 5개, 묶이지 않은 지문 5편)

대상을 이루는 요소와 단계가 어떻게 이어져 하나의 작용이나 결과를 만드는지 설명한다. 글의 중심은 '어떻게 작동하는가, 어떻게 일어나는가'의 경로다.

### S1-1 직렬처리형
- 문단 기능 배열: 대상 도입(구조 설명) → 원리 설명 → 과정 설명 ×n → 귀결 제시
- 맞는 쟁점 논리: 하나의 입력이 여러 부분을 통과하면서 형태나 의미를 바꾸고 최종 결과에 이르는 내용에 맞는다. 각 부분의 독립적인 성질보다 단계 사이의 전달 관계가 핵심이다.
- 하위 축 값:
  - 깔아 두는 곳: 전체 구성은 앞에서 잡고, 세부 구조와 조건은 해당 단계의 작동을 설명하기 직전에 나누어 둔다.
  - 펼치는 순서: 입력의 유입부터 변환·전달·최종 처리까지 실제 진행 경로를 따른다. 앞 단계의 결과가 다음 단계의 입력이 된다.
  - 규칙·사례의 위치와 하는 일: 변환 관계와 대응 규칙을 각 단계에 배치한다. 마지막 단계에서는 앞서 얻은 정보를 해석하거나 결과로 표현한다.
  - 끝맺는 방식: 최종 처리나 결과의 표현으로 경로를 완결한다. 필요한 경우 후속 대응을 짧게 덧붙인다.
- 만남 지점과 비워 둔 곳: 원리 설명과 과정 설명 사이, 연속된 과정 설명 사이에 연결이 집중된다. 마지막 과정 설명이나 귀결 제시에서는 앞의 대응 관계를 다시 사용하되, 중간 계산이나 여러 대응을 합친 결과는 비워 둘 수 있다.
- 예시 기출:
  - 고2 2024년 3월 교육청 모의평가 16~20번 〈달팽이관의 소리 지각 원리〉
  - 고1 2025년 10월 교육청 모의평가 21~23번 〈비분산형 적외선 분석기〉
  - 고3 2023년 4월 교육청 모의평가 14~17번 〈전기화학식 가스 센서의 원리〉
  - 소속 5편 (예시 밖 2편)
- 이 구조를 고를 조건: 앞 단계에서 무엇을 얻었고 다음 단계가 그것을 어떻게 이용하는지를 연속해서 보여 주려 할 때 고른다. 결말은 출발점으로의 복귀보다 최종 산출의 성립에 둔다.
- 닮은 구조: S1-5 (배열이 거의 같다. S1-1은 단계 사이의 전달로, S1-5는 독립된 원리 구간과 끝의 파생 성질로 가른다)

### S1-2 순환완결형
- 문단 기능 배열: 대상 도입 → 구조 설명 → 원리 설명(기준 설정) → 과정 설명 ×n
- 맞는 쟁점 논리: 한 번의 결과만으로는 작동을 다 설명할 수 없고, 작용 뒤 다시 작동할 수 있게 되는 이유까지 밝혀야 하는 내용에 맞는다.
- 하위 축 값:
  - 깔아 두는 곳: 구성과 기본 성질을 앞에 마련하고, 되돌아갈 기준 상태나 반복의 출발점을 설정한다.
  - 펼치는 순서: 출발 상태에서 변화와 작용을 거친 뒤 출발 조건을 회복하거나, 작용 결과를 다시 입력으로 받아 반복한다.
  - 규칙·사례의 위치와 하는 일: 중간의 조건 관계가 작동 여부나 변화 방향을 정한다. 후반에서는 앞의 원리를 반대 방향에 적용하거나 갱신된 조건에 다시 적용한다.
  - 끝맺는 방식: 복귀 또는 재입력으로 반복 구조를 닫는다. 그 뒤 반복 가능한 작동의 효용이나 활용 가능성을 덧붙일 수 있다.
- 만남 지점과 비워 둔 곳: 앞의 구조 설명·원리 설명과 뒤의 과정 설명이 반복해서 만난다. 복귀를 다루는 과정 설명에서는 앞의 변화 원리를 거꾸로 적용하는 중간 연결을, 재입력을 다루는 과정 설명에서는 갱신된 조건의 효과를 비워 둘 수 있다.
- 예시 기출:
  - 고2 2024년 10월 교육청 모의평가 26~29번 〈정전용량형 근접 습도 센서〉
  - 고1 2023년 11월 교육청 모의평가 22~25번 〈해양 온도차 발전〉
  - 고3 2025년 5월 교육청 모의평가 10~13번 〈자기 유변 유체를 활용한 제진 시스템〉
  - 소속 3편
- 이 구조를 고를 조건: 기준 상태의 회복, 내부 흐름의 복귀, 결과의 재입력 가운데 하나가 전체 작동을 성립시키는 핵심일 때 고른다. 마지막 단계가 앞부분과 다시 연결되도록 설계한다.

### S1-3 경로통합형
- 문단 기능 배열: 관계 설명(대상 도입) → 과정 설명 ×n → 관계 설명(귀결 제시)
- 맞는 쟁점 논리: 하나의 결과를 여러 경로가 함께 만들며, 각 경로를 이해한 뒤에도 이들이 어떻게 연결되는지를 추가로 설명해야 하는 내용에 맞는다.
- 하위 축 값:
  - 깔아 두는 곳: 여러 경로가 공유하는 결정 요인이나 기본 작용을 앞에 마련한다. 각 경로에만 필요한 요소는 해당 경로를 설명할 때 도입한다.
  - 펼치는 순서: 경로들을 나누어 설명한 뒤 합류 지점, 상호 작용, 공통 귀결을 밝혀 전체 작동으로 묶는다.
  - 규칙·사례의 위치와 하는 일: 앞의 공통 관계를 각 경로에서 재사용한다. 경로별 작용 방향이나 단계 차이는 마지막 통합을 준비한다.
  - 끝맺는 방식: 따로 설명한 경로 사이의 관계나 공통 결과를 드러낸다. 통합 뒤 의의나 전망을 덧붙일 수 있다.
- 만남 지점과 비워 둔 곳: 앞의 관계 설명과 각각의 과정 설명, 여러 과정 설명과 마지막 관계 설명이 만난다. 공통 관계를 거치는 중간 단계나 작용 방향을 합성한 최종 효과를 마지막 원리 설명·귀결 제시에서 비워 둘 수 있다.
- 예시 기출:
  - 고3 2025년 3월 교육청 모의평가 14~17번 〈인체의 혈압 조절 기전〉
  - 고3 2024년 7월 교육청 모의평가 14~17번 〈세포자멸사의 원리와 과정〉
  - 고3 2026년 3월 교육청 모의평가 10~13번 〈도파민의 합성, 수용체, 수의적 운동 조절〉
  - 소속 3편
- 이 구조를 고를 조건: 경로를 차례로 소개하는 것만으로 끝내지 않고, 합류·상호 강화·상반된 작용의 결합을 밝혀야 할 때 고른다. 독립적인 구현 방식의 단순 비교와는 구별한다.

### S1-4 요소연계형
- 문단 기능 배열: 대상 도입 → 구조 설명 → 원리 설명(조건 명시) → 특성 설명(관계 설명) ×n
- 맞는 쟁점 논리: 요소를 나열하는 것만으로는 전체 작동을 설명할 수 없고, 한 요소의 조건을 다른 요소가 어떻게 충족하는지 밝혀야 하는 내용에 맞는다.
- 하위 축 값:
  - 깔아 두는 곳: 전체를 이루는 요소와 역할 구분을 먼저 제시한다. 핵심 요소의 성립·작동 조건을 마련한 뒤 다른 요소를 설명한다.
  - 펼치는 순서: 핵심 요소에서 후속·보조 요소로 이동하며, 뒤의 요소가 앞의 조건을 유지·조절하거나 실제 작용으로 이어 주는 관계를 밝힌다.
  - 규칙·사례의 위치와 하는 일: 앞에서 제시한 조건이 뒤 요소의 필요성과 역할을 설명하는 근거가 된다. 사례는 개별 요소의 작용을 이해시키는 데 쓴다.
  - 끝맺는 방식: 마지막 요소의 작용까지 연결하여 전체 설명을 완성한다. 구성의 필수성이나 작동의 성립 범위를 한정할 수 있다.
- 만남 지점과 비워 둔 곳: 구조 설명과 요소별 개념 규정·특성 설명이 만나며, 앞의 조건 명시가 뒤의 방법 설명·원리 설명에서 회수된다. 조건의 훼손이 전체 작용에 미치는 영향이나 조절이 향해야 할 방향을 비워 둘 수 있다.
- 예시 기출:
  - 고3 2023년(2024학년도) 6월 평가원 모의평가 8~11번 〈고체 촉매의 구성 요소와 작용 원리〉
  - 고1 2024년 10월 교육청 모의평가 22~26번 〈블라지의 도덕적 자아 모델〉
  - 소속 2편
- 이 구조를 고를 조건: 진행 경로보다 구성 요소별 역할 분담이 설명의 중심일 때 고른다. 각 요소를 독립적으로 소개하지 않고 앞서 마련한 조건이나 기능적 요구에 연결한다.

### S1-5 원리선행보완형
- 문단 기능 배열: 대상 도입(개념 규정) → 원리 설명 ×n → 과정 설명 ×n → 귀결 제시(조건 명시)
- 맞는 쟁점 논리: 단계만 따라가서는 작동 이유를 이해하기 어려워 일반적 성질과 관계를 먼저 익혀야 하는 내용에 맞는다. 작동을 설명한 뒤에도 그에 따른 성질이나 유효 조건을 밝혀야 한다.
- 하위 축 값:
  - 깔아 두는 곳: 구체적인 작동을 본격적으로 설명하기 전에 기초 개념과 일반 관계를 독립된 설명 구간으로 마련한다.
  - 펼치는 순서: 선행 원리를 구체적인 구조와 단계에 대입하여 작동을 해명한 뒤, 작동 이후의 성질·활용·보완 조건으로 나아간다.
  - 규칙·사례의 위치와 하는 일: 일반 관계는 핵심 과정 앞에 놓고, 중간의 구체적 대상이나 상황으로 그 관계가 구현되는 모습을 보여 준다.
  - 끝맺는 방식: 핵심 과정의 종료 자체보다 그 과정에서 파생되는 성질, 적용 요건, 이익과 부담을 보충하며 마친다.
- 만남 지점과 비워 둔 곳: 선행 개념 규정·원리 설명과 뒤의 구조 설명·과정 설명이 만난다. 후단의 관계 설명·조건 명시·한계 지적에서는 앞의 원리를 다시 사용하며, 단계 사이의 미시적 이유나 작동 조건이 성질·제약으로 이어지는 연결을 비워 둘 수 있다.
- 예시 기출:
  - 고3 2024년(2025학년도) 6월 평가원 모의평가 8~11번 〈플라스틱의 중합 반응과 물리적 성질〉
  - 고2 2025년 9월 교육청 모의평가 22~26번 〈의류 건조기의 원리〉
  - 고1 2026년 6월 교육청 모의평가 16~19번 〈나미브 사막 딱정벌레의 수분 획득 원리와 방법〉
  - 소속 4편 (예시 밖 1편)
- 이 구조를 고를 조건: 기초 원리를 별도로 설명한 다음 구체 작동에 대입하게 하려 할 때 고른다. 마지막에는 같은 원리로 설명할 수 있는 파급 효과나 보완 조건을 연결한다.
- 닮은 구조: S1-1 (위와 같음), S3-2, S5-2 (기초 원리·기준을 먼저 세우고 뒤에서 쓴다)

## S2 조건과 효과 (10편, 하위 구조 4개, 묶이지 않은 지문 1편)

공통 원리 하나를 여러 경우에 적용해, 조건이나 변수의 차이가 결과의 차이를 낳는 까닭을 밝힌다.

### S2-1 응용 성능 판정
- 문단 기능 배열: 원리 설명 → 사례 적용 ×n → 기준 설정 → 조건 명시(관계 설명)
- 맞는 쟁점 논리: 어떤 현상이 성립하는 원리만으로는 그것을 이용한 대상의 실제 성과까지 판단할 수 없는 문제이다. 공통 원리를 적용한 뒤 별도의 지표와 조건을 더해야 한다.
- 하위 축 값:
  - 여는 방식: 정의나 익숙한 현상에서 출발하여 공통 원리로 들어감
  - 깔아 두는 곳: 공통 원리는 앞에 두고, 응용을 평가할 지표와 조건은 중·후반에 보충함
  - 펼치는 순서: 일반 원리 → 구체적 적용 → 응용 대상의 평가 기준 → 조건별 작동과 성능
  - 규칙·사례의 위치와 하는 일: 앞의 사례는 원리의 이해와 적용을 돕고, 뒤의 지표는 실제 성과의 판정을 가름
  - 끝맺는 방식: 변수와 성능의 관계 또는 적절한 작동 범위를 제시함
- 만남 지점과 비워 둔 곳: 만나는 곳은 원리 설명과 사례 적용 사이, 기준 설정과 조건 명시·관계 설명 사이에 놓인다. 비워 둔 곳은 앞의 변수 관계와 뒤의 판정 기준을 결합하여 결과의 변화 방향이나 조절 방향을 추론하는 자리에 놓인다.
- 예시 기출:
  - 고3 2026년(2027학년도) 6월 평가원 모의평가 14~17번 〈표면 장력과 라플라스 식〉 · 세 번 중 2
  - 고3 2025년(2026학년도) 11월 수능 10~13번 〈열팽창과 액추에이터〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 원리의 이해에서 출발하여 구체적 응용으로 나아가되, 마지막에는 성립 여부와 성능의 좋고 나쁨을 구별하게 하려 할 때 고른다.

### S2-2 효용 뒤 제약
- 문단 기능 배열: 과정 설명(구조 설명) → 비교 대조(기준 설정) → 원리 설명 → 관계 설명(한계 지적)
- 맞는 쟁점 논리: 하나의 운영 방식이 이익을 주더라도 다른 평가 항목에서는 손실을 낳거나, 특정 조건에서는 부작용이 커지는 문제이다. 앞에서 설명한 장점을 뒤의 제약과 함께 평가해야 한다.
- 하위 축 값:
  - 여는 방식: 대상의 구성·운영 방식이나 이를 이해할 기본 개념에서 출발함
  - 깔아 두는 곳: 기본 구성은 앞에 마련하고, 평가 항목과 적용 조건은 필요한 대목에서 추가함
  - 펼치는 순서: 기본 체계 → 유형이나 대안의 비교 → 효용의 발생 경로 → 상충 관계나 조건부 부작용
  - 규칙·사례의 위치와 하는 일: 중반의 규칙과 상황 비교는 효용의 근거를 설명하고, 후반의 조건은 그 효용이 제약되는 경우를 가름
  - 끝맺는 방식: 평가 항목 간 상충이나 특정 조건에서 커지는 한계를 남기며, 해결책 없이 끝남
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞의 구조 설명·규칙 제시·기준 설정과 뒤의 관계 설명·원인 해명·한계 지적 사이에 놓인다. 비워 둔 곳이 있는 경우에는 앞서 제시한 적용 범위나 변수 관계를 마지막의 불리한 결과에 연결하는 자리가 된다.
- 예시 기출:
  - 고3 2024년(2025학년도) 9월 평가원 모의평가 8~11번 〈블록체인 기술의 특성〉 · 세 번 중 2
  - 고3 2023년(2024학년도) 9월 평가원 모의평가 4~7번 〈데이터 소유권과 데이터 이동권〉 · 세 번 중 2
  - 고2 2025년 3월 교육청 모의평가 22~26번 〈민사 소송 비용 부담 원칙〉 · 세 번 중 2
  - 소속 3편
- 이 구조를 고를 조건: 대상의 작동과 비교 대상을 먼저 이해시킨 뒤, 장점만으로 선택을 정당화할 수 없음을 후반에 드러내려 할 때 고른다.

### S2-3 조건 선행 적용
- 문단 기능 배열: 대상 도입 → 과정 설명 → 조건 명시(비교 대조) → 사례 적용 ×n → 범위 확장
- 맞는 쟁점 논리: 동일한 원리를 적용하더라도 대상의 유형이나 반응 조건에 따라 결과가 달라지는 내용이다. 차이를 가르는 조건을 먼저 알면 여러 경우를 같은 틀로 해석할 수 있다.
- 하위 축 값:
  - 여는 방식: 대상의 기본 개념이나 역할을 소개함
  - 깔아 두는 곳: 공통 작동 관계와 결과를 가르는 조건·범위를 본격적인 경우별 설명보다 앞에 마련함
  - 펼치는 순서: 공통 기반 → 조건이나 유형의 구분 → 경우별 병렬 설명 → 활용 또는 추가 적용
  - 규칙·사례의 위치와 하는 일: 앞의 계산 관계나 반응 조건이 뒤의 여러 경우를 해석하는 공통 도구가 됨
  - 끝맺는 방식: 설명된 차이를 새로운 적용이나 선택 방향으로 이어 감
- 만남 지점과 비워 둔 곳: 만나는 곳은 앞의 기준 설정·조건 명시와 뒤의 원리 설명·사례 적용 사이에 반복해서 놓이며, 도입의 목적과 마지막 적용도 연결된다. 비워 둔 곳은 앞의 공통 관계를 복합적인 경우에 결합하거나, 설명된 차이에서 활용 방향을 이끌어 내는 자리에 놓인다.
- 예시 기출:
  - 고2 2026년 6월 교육청 모의평가 16~19번 〈옥신의 기능과 식물 생장 조절〉 · 세 번 중 2
  - 고1 2023년 11월 교육청 모의평가 26~30번 〈원가회계와 원가행태〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 공통 관계와 조건별 차이를 먼저 마련한 뒤, 여러 현상이나 유형을 반복 적용으로 설명하려 할 때 고른다. 마지막에 활용 방향이나 추가 기능으로 이어 가기에도 적합하다.
- 닮은 구조: S4-1, S6-2 (공통 기반을 앞에 두고 경우를 차례로 편다)

### S2-4 대조 후 관계 해명
- 문단 기능 배열: 대상 도입(개념 규정) → 원리 설명 ×n → 관계 설명(기준 설정)
- 맞는 쟁점 논리: 조건을 달리한 두 경우의 진행 경로를 설명하는 것과 결과의 크기나 양상을 설명하는 것이 구별되는 내용이다. 두 경로를 먼저 대비한 뒤 추가 관계로 결과의 차이를 해명한다.
- 하위 축 값:
  - 여는 방식: 설명할 현상이나 겉으로 드러난 불일치를 먼저 내놓음
  - 깔아 두는 곳: 경로를 이해할 개념은 앞에 두고, 결과의 정도를 가르는 추가 관계는 대조 뒤에 제시함
  - 펼치는 순서: 기본 원리 → 조건을 달리한 두 경로의 대조 → 추가 변수에 따른 결과의 분화
  - 규칙·사례의 위치와 하는 일: 중반의 대조는 결과가 생기는 경로를 보여 주고, 후반의 변수 관계는 결과의 크기나 양상 차이를 설명함
  - 끝맺는 방식: 차이를 결정하는 관계를 밝힌 뒤 그에 따른 추가 귀결을 제시함
- 만남 지점과 비워 둔 곳: 만나는 곳은 개념 규정·원리 설명과 뒤의 대조적 설명 사이, 중반의 결과와 마지막 관계 설명·기준 설정 사이에 놓인다. 비워 둔 곳은 한쪽 경로에서 다른 쪽의 대응 관계를 복원하거나, 후반의 변수 관계로 앞의 결과를 해석하는 자리에 놓인다.
- 예시 기출:
  - 고3 2026년 5월 교육청 모의평가 10~13번 〈볼록 렌즈와 비점 수차〉 · 세 번 중 2
  - 고3 2024년 7월 교육청 모의평가 10~13번 〈조세 귀착의 경제적 효과〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 독자가 대조되는 경우의 작동을 먼저 이해하게 하고, 그 뒤에 결과의 정도를 좌우하는 변수를 도입하려 할 때 고른다.

## S3 판단·산출 절차 (10편, 하위 구조 4개, 묶이지 않은 지문 1편)

어떤 값이나 판정을 얻으려고 쓰는 지표·기준과 처리 절차를, 그 근거가 되는 원리와 함께 설명한다. 결과의 신뢰성을 확보하는 조건도 다룬다.

### S3-1 시연 뒤 성과 확장
- 문단 기능 배열: 대상 도입 → 근거 뒷받침(원리 설명) → 방법 설명(절차 설명) → 예시 구체화(사례 적용) ×n → 귀결 제시(범위 확장)
- 맞는 쟁점 논리: 방법의 근거만으로는 실제 처리 방식이 충분히 드러나지 않아 구체적인 시연이 필요한 내용이다. 시연에서 확인한 결과를 일반적인 효용이나 신뢰성으로 이어 갈 수 있다.
- 하위 축 값:
  - 여는 방식: 방법의 대상이나 쓰임을 먼저 소개한다.
  - 깔아 두는 곳: 정당화 근거와 기초 원리를 앞에 두고, 세부 개념은 실행 방식을 설명할 때 보충한다.
  - 펼치는 순서: 근거 마련 → 방법 소개 → 구체적 시연 → 성과의 일반화
  - 규칙·사례의 위치와 하는 일: 중후반의 사례가 산출이나 기록 방식을 직접 보여 주어 추상적인 설명을 이해시킨다.
  - 끝맺는 방식: 시연 결과를 넘어 일반적인 성질·효용·적용 범위로 확장한다.
- 만남 지점과 비워 둔 곳: 근거 뒷받침·원리 설명이 예시 구체화·사례 적용에서 재사용되고, 대상 도입은 귀결 제시·범위 확장에서 회수된다. 예시 구체화·사례 적용 안에는 앞의 개념으로 중간 결과를 해석하는 연결이, 귀결 제시 앞에는 개별 결과를 일반화하는 이유가 생략된다.
- 예시 기출:
  - 고3 2025년 5월 교육청 모의평가 14~17번 〈연합형 게임과 섀플리 값〉
  - 고2 2023년 6월 교육청 모의평가 29~32번 〈STR 분석법〉
  - 소속 2편
- 이 구조를 고를 조건: 독자가 처리 예를 따라가며 방법의 의미를 이해하게 하고, 그 예를 넘어서는 성과나 활용 가능성으로 마무리하려 할 때 고른다.

### S3-2 근거 종합 실행
- 문단 기능 배열: 필요성 제시(대상 도입) → 원리 설명 ×n → 기준 설정(조건 명시) → 절차 설명 ×n
- 맞는 쟁점 논리: 하나의 실행 규칙을 정하려면 여러 원리나 대상 간 차이를 먼저 이해해야 하는 내용이다. 그 근거들을 마지막에 결합해야 처리 순서와 조건별 선택이 정당화된다.
- 하위 축 값:
  - 여는 방식: 얻으려는 결과나 처리의 필요를 먼저 제시한다.
  - 깔아 두는 곳: 실행에 필요한 원리·구분·비교 기준을 앞부분과 중간에 누적한다.
  - 펼치는 순서: 목표 제시 → 원리와 차이 설명 → 적용 기준 마련 → 실행 절차 통합
  - 규칙·사례의 위치와 하는 일: 앞과 중간의 사례·비교는 뒤에서 처리 방식이나 기준을 선택하는 근거가 된다.
  - 끝맺는 방식: 앞서 마련한 관계와 조건을 최종 처리 규칙으로 회수하여 산출을 완결한다.
- 만남 지점과 비워 둔 곳: 원리 설명·비교 대조·조건 명시와 마지막 절차 설명 사이에 핵심 연결이 집중된다. 앞의 관계와 구분을 규칙 선택·계산 방향·적용 가능성으로 옮기는 이유가 생략되며, 처음의 필요성 제시·대상 도입은 절차 설명의 완결에서 회수된다.
- 예시 기출:
  - 고3 2025년(2026학년도) 9월 평가원 모의평가 14~17번 〈오디오 신호의 디지털 저장과 지각부호화 압축〉
  - 고1 2024년 10월 교육청 모의평가 27~30번 〈구조물의 하중과 허용응력〉
  - 소속 3편 (예시 밖 1편)
- 이 구조를 고를 조건: 절차부터 제시하면 규칙의 이유가 드러나지 않거나, 대상의 차이와 적용 조건에 따라 실행 방식이 달라질 때 고른다. 마지막 부분이 앞선 설명을 실제 처리로 묶는 역할을 하게 한다.
- 닮은 구조: S1-5, S5-2 (기초 원리·기준을 먼저 세우고 뒤에서 쓴다)

### S3-3 한계 연쇄 보완
- 문단 기능 배열: 필요성 제시 → 방법 설명(원리 설명) → 한계 지적 → 대안 제시(조건 명시) → … → 한계 지적
- 맞는 쟁점 논리: 하나의 방법이나 지표로는 필요한 판단을 모두 수행할 수 없어 보완이 연쇄적으로 필요한 내용이다. 보완책도 적용 범위와 해석상의 한계를 가지므로 단순한 방법 나열로 끝낼 수 없다.
- 하위 축 값:
  - 여는 방식: 판단이나 적용을 수행해야 할 필요를 제시한다.
  - 깔아 두는 곳: 각 방법이나 기준에 필요한 개념과 조건을 해당 항목이 등장할 때 나누어 둔다.
  - 펼치는 순서: 기본 방법 소개 → 부족한 점 확인 → 보완 방법 도입 → 추가 제약 확인
  - 규칙·사례의 위치와 하는 일: 규칙과 사례가 방법별로 분산되며, 기존 방법으로 구별하거나 처리할 수 없는 경우를 드러낸다.
  - 끝맺는 방식: 보완 이후에도 남는 판단 제약을 밝히고, 경우에 따라 문제를 줄이는 방향을 덧붙인다.
- 만남 지점과 비워 둔 곳: 방법 설명·원리 설명과 한계 지적 사이에서 정보의 부족함이 드러나고, 한계 지적과 대안 제시 사이에서 다음 방법의 필요가 성립한다. 앞의 기준 설정·조건 명시는 뒤의 대안 제시·한계 지적에서 다시 쓰이며, 여러 방법의 결과를 함께 읽는 방식이나 보완책의 적용 범위를 연결하는 추론이 생략된다.
- 예시 기출:
  - 고3 2023년 7월 교육청 모의평가 10~13번 〈법의 해석과 흠결 보충〉
  - 고3 2023년 7월 교육청 모의평가 14~17번 〈이중 편파 레이더의 기상 관측〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 여러 방법을 소개하되 각각을 앞선 방법의 부족함에 대한 응답으로 연결하려 할 때 고른다. 최종 판단에 여러 기준의 결합이나 별도의 정당성 검토가 필요할 때 적합하다.
- 닮은 구조: S4-3, S5-3 (앞 방식의 한계가 다음 방식을 부른다)

### S3-4 과정 연계 지표
- 문단 기능 배열: 개념 규정 → 과정 설명(원리 설명) → 기준 설정(개념 규정) → 관계 설명 → 의의 평가(한계 지적)
- 맞는 쟁점 논리: 지표의 뜻이 대상의 단계별 진행이나 기능상의 차이에 의존하는 내용이다. 같은 값이나 관계도 어떤 단계·기능에 대응시키는지에 따라 판단상의 의미가 달라진다.
- 하위 축 값:
  - 여는 방식: 대상을 정의하고 기본 특성이나 구성을 정리한다.
  - 깔아 두는 곳: 지표를 이해하는 데 필요한 단계·역할·관계를 먼저 설명한다.
  - 펼치는 순서: 대상 이해 → 진행 과정과 원리 → 단계·기능에 대응하는 지표 → 지표의 관계와 해석
  - 규칙·사례의 위치와 하는 일: 중후반의 관계식과 지표 정의가 앞서 설명한 과정이나 기능을 수량적 판단으로 바꾼다.
- 만남 지점과 비워 둔 곳: 과정 설명·원리 설명에서 마련한 단계와 역할이 기준 설정·개념 규정·관계 설명에서 재사용된다. 과정 설명과 기준 설정 사이에는 결과와 지표의 대응이, 관계 설명과 방법 설명 사이에는 값의 증감이나 조정 방향을 도출하는 연결이 생략된다.
- 예시 기출:
  - 고2 2025년 6월 교육청 모의평가 16~20번 〈약물의 체내 흡수와 분포〉 · 세 번 중 2
  - 고2 2025년 3월 교육청 모의평가 27~30번 〈열펌프의 원리와 성능〉 · 세 번 중 2
  - 소속 2편
- 이 구조를 고를 조건: 평가 기준을 곧바로 나열하기보다 대상의 진행 과정과 역할을 먼저 이해시켜야 할 때 고른다. 그 설명을 발판으로 지표의 정의·상호 관계·해석 범위를 다룬다.
