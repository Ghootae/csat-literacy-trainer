# 원리 적용형 생성 파일럿 P1 결과 (사람용)

상세는 [Desktop 보고서](./REPORT-p1-desktop.md)에 있다.

## 1. 개요

### 1) 목적

- 기출 표면 장력 15번처럼 상황 하나를 정하고, 그 위에서 여러 선지가 지문의 원리를 적용해야 풀리는 문항을 생성기가 만들 수 있는지 본다.
- 같은 기준으로 기출 31문항이 정말 그런 모양인지도 함께 확인한다.

### 2) 결과

- **생성:** 8문항 중 7문항을 만들었다. 오디오 a는 지문에 쓸 재료(지문이 상황만 깔고 결과는 말하지 않은 대상)가 없어 만들지 않았다. 생성 비용은 3번 실행 합계 $0.71이다.
- **통과:** 7문항 모두 풀이 검증(정답 일치·오류 없음)과 구조 조건(원리 적용 선지가 상황 하나 위에 모임)을 통과했다. 남은 조건은 사용자의 "깊다" 판정 하나다.
- **대비:** 앞선 E1 생성 문항 20개에는 원리 적용 선지가 0개였다.
- **기출:** 원리 적용이 모인 문항은 〈보기〉 문항에 몰려 있다(〈보기〉 문항 7/10, 〈보기〉 없는 문항 2~3/21).
- **주의:** P1 문항은 선지 5개가 모두 계산형이다. 기출은 한 문항 안에 원리 적용, 지문 확인, 연결이 섞인다. 또 〈보기〉 없는 a 문항도 발문에 지문 밖 수치를 넣었다.

### 3) 다음 스텝

- 아래 7문항의 "깊다" 판정(사용자)
- 계산형 수렴과 a 문항의 수치 허용 여부를 웹 에이전트와 논의
- 커밋

## 2. 본문

### 2.1 재료 누락 (해결)

- 1차 실행에서 법인 지문의 재료가 0개였다.
- 지문은 "무상 증자는 주식을 추가로 발행한다"와 "자본금 = 주식 수 × 액면가"를 따로 말하지만, 무상 증자 뒤 자본금이 어떻게 되는지는 말하지 않는다.
- 생성 모델은 무상 증자를 다른 규칙(실행 요건)에서 이미 다뤘다는 이유로 이 자리를 놓쳤다.
- 지시문에 "규칙마다 따로 본다"를 더하자 찾아냈다(기출 법인 12번 ①과 같은 자리).

### 2.2 계산형 수렴 (판단 필요)

- 기출 15번은 수치 없이 크기 비교만으로 푼다.
- P1 문항 다수는 숫자 계산이다. 예: 법인 a "1만 주 × 1,000원 → 300만 원 증자 → 1,300만 원".
- 기출 16·17번(잉크 조건, 소리 표)도 조건·수치형이므로 계산형 자체가 기출에 없는 것은 아니다.
- 다만 P1은 7문항 모두가 그렇다.

### 2.3 a 문항에 지문 밖 수치 (판단 필요)

- 법인 a와 표면 장력 a는 발문 끝 "(단, …)"에 수치를 넣어, 사실상 〈보기〉를 발문 안에 넣었다.
- 원인은 상황 지시문이 a에도 "값을 넣어 계산하라"고만 하고, 지문 밖 값을 금지하지 않은 데 있다.

### 2.4 "깊다" 판정용 문항 (판단 필요)

- 판단은 "기출 15번만큼 생각하게 만드는가" 하나다.
- 기준 문항인 기출 15번 원문과 P1 7문항 원문은 채팅에 함께 보였다.
- 원문 파일은 `runs-v2b/<지문>/item-<a|b>.json`이다.
