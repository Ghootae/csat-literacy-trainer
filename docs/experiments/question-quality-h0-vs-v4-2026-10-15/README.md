# 질문 비교: H0 대 V4 (2026-10-15)

결정: [D-0138](../../../memory/decisions/D-0138-paragraph-fundamental-review-question-quality-first.md)

## 목적

문단 요약 근본 검토의 첫 확인이다. 축 없이 문단 전체를 판정하고 가장 큰 구멍 하나를 묻는 형식(H0)은 33시점 판정에서 V4와 비슷했다(질문 15 대 17, 불필요한 질문 6 대 7, 놓침 2 대 1, [REPORT "같은 계산의 H0 판"](../holistic-verdict-shadow-2026-10-08/REPORT.md)). 질문의 질은 사람이 본 적이 없다. 이 묶음은 같은 시점의 두 질문을 블라인드로 비교한다.

## 자료

- 출처: `docs/experiments/holistic-verdict-shadow-2026-10-08/`의 `comparisons.json`(H0 `raw.question`), `points.json`(다음 시점 대화의 마지막 `tutor_question` = 학생이 실제로 받은 V4 질문), `sources.json`(문단 원문)
- 85시점 중 H0 질문 18, 뒤따른 V4 질문 27, 둘 다 있는 시점 10. 10개 모두 실사용 응답(A 5, B 5)이고 탐침은 없다.
- 생성: `node scripts/build-question-quality-h0-v4-review.mjs` (API 0회, 새 판정 없음)
- 판정 양식: `REVIEW.md` · 출처 열쇠: `KEY.json` (판정 끝날 때까지 열지 않음). A/B는 해시 순서로 5:5 배정했다.

## 판정 기준

질문마다 구멍(예/부분/아니오), 누출(예/아니오), 답 가능(예/아니오)을 적고 사례마다 선택(A/B/비슷)을 적는다.

## 한계

- 10쌍은 작다. 방향을 보는 용도다.
- V4 질문은 사용자가 실제 사용 중에 본 질문일 수 있고 "본문에 따라 설명해 보세요" 같은 문체 단서가 있어 블라인드가 완전하지 않다.
- 후속 사례의 대화에는 앞 사례에서 실제로 던진 V4 질문이 보인다. 그래서 같은 세션은 앞 시점을 먼저 놓았고, 앞 사례로 돌아가 고치지 않도록 안내했다.
- H0 질문은 대화 맥락에 V4 질문이 있는 상태에서 만들어졌다(후속 시점). H0 질문 자체에는 축 정보가 들어가지 않았다.
- H0만 질문한 8시점은 V4 질문이 없어 빠졌다. 늘리려면 V4 2차 질문을 새로 생성해야 한다(API 호출, 별도 승인).

## 결과 읽는 규칙 (Claude 제안, 사용자 확정 전)

단순한 쪽이 동률이면 이긴다는 근거 검토 원칙에 따라 비열등으로 본다.

- H0 선택 수 ≥ V4 선택 수이고, H0 누출 "예" 수 ≤ V4 누출 "예" 수 + 1이면: 단순 형식 방향으로 설계를 진행한다. 조정에 쓰지 않은 새 응답으로 판정·질문을 함께 검증한다.
- H0 선택이 V4보다 적으면: 사례 메모로 차이의 원인(구멍 선택, 누출, 겹질문 등)을 보고 질문 생성만 축 근거로 둘지 다시 논의한다.
