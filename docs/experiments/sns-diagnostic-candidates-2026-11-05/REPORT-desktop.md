# SNS 진단평가 지문 후보 추리기 — Desktop 보고서 (2026-11-05)

Q-0043·D-0200 후속. 사용자 승인("추리기 진행")에 따라 다섯 기준으로 수능 DB에서 진단평가 4지문 후보를 추렸다.

## 기준과 적용

| 기준 | 적용 |
|---|---|
| ① 분야 | 인문·사회·과학·기술에서 하나씩. 분야는 코드 에이전트가 제목으로 분류(`fields.json`, DB `category`는 55세트가 비어 있고 과학·기술을 나누지 않음) |
| ② 시험 출처 | 고3 수능·평가원 30세트만 |
| ③ 문항 유형 | 어휘 문항(꼬리표 "어휘"·"문맥" 또는 발문 "문맥상") 제외 후 남은 문항 수(`usable`) |
| ④ 난이도 | 메가스터디 정답률, 화법과작문(1004)·언어와매체(1005) 탭 평균 |
| ⑤ 문항 품질 | 정답 번호 대조만 함(30세트 모두 trainer 정답과 일치). 결함 문항·비틂 분포는 동결 전이라 미확인 |

## 한계

- 정답률은 메가스터디 이용자 집계다(Q-0042). 분야 분류는 제목 기준 코드 에이전트 판단이다.
- 결함 문항 여부와 비틂 분포(기준 ⑤)는 지문을 동결해야 알 수 있다.

## 파일

- `candidates.json`: 30세트별 분야·문항별 정답·정답률·선택 비율·어휘 여부·정답 대조.
- `fields.json`: 분야 분류. `build_candidates.py`: 표 생성. `parse_rate.py`: 선택률 표 파서.
- `raw/`(커밋 제외): 메가스터디 선택률 표. 이번 요청 18회(311·315·319·326·330·334·341·345·349 × 탭 2), 356은
  `trap-map-v0-external-rates-2026-10-10/raw/`의 2026-10-10 원본을 다시 씀.
