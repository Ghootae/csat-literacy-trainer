부정 발문이므로 **참인 선지는 ‘제거’**, 거짓이 확인되거나 가린 정보 때문에 판단할 수 없는 선지는 ‘남음’으로 표시한다. 두 경우는 근거에서 구별한다.

## V1

| 선지 | 판정 | 근거 |
|---|---|---|
| ① | 제거 | 움직이는 적혈구 때문에 송신·수신 주파수가 달라지는 것은 도플러 효과이다. |
| ② | 남음 | 매질별 밀도의 대소와 두 매질 사이의 밀도 차이를 비교해야 하므로, 가려진 네 밀도 값이 필요하다. |
| ③ | 제거 | 가장 정확한 측정 각도는 0°이지만, 59°는 실제 측정에서 유지해야 하는 60° 미만에 해당한다. |
| ④ | 제거 | 두 부위 모두 탐촉자를 향하므로 빨간색이고, 더 빠른 B가 더 밝게 표시된다. |
| ⑤ | 남음 | **부적절함이 확정된다.** 혈액과 적혈구의 음향 저항 차이를 없애면 혈류 정보 수신에 필요한 산란 신호를 얻는 데 불리하다. 가린 정보는 필요 없다. |

- **선지별 직접 검증에서 남는 후보: ②, ⑤**
- **⑤는 지문만으로 거짓임이 확인되므로 정답에 해당한다.** 다만 ② 자체의 참·거짓은 가린 밀도 값 없이는 확인할 수 없으므로, 직접 검증상 제거하지 않는다.

## V2

| 선지 | 판정 | 근거 |
|---|---|---|
| ① | 남음 | A가 가까워지면 도플러 변위의 값도 A가 더 크고 더 밝지만, 멀어지면 변위의 값은 B가 더 크면서 밝기는 A가 더 밝다. A의 이동 방향이 필요하다. |
| ② | 제거 | B와 C는 방향·송신 주파수·도플러 각도가 같고 C가 더 빠르므로, 도플러 변위의 절댓값은 C가 더 크다. |
| ③ | 제거 | 적혈구 크기가 같고 D의 송신 주파수가 더 높으므로, D에서 산란이 더 많이 발생한다. |
| ④ | 제거 | B의 적혈구는 탐촉자에 가까워지므로 도플러 변위가 양수이다. |
| ⑤ | 남음 | A가 더 빠르므로 더 밝다는 것은 맞지만, A도 파란색인지는 이동 방향이 필요하다. A가 멀어지면 참이고 가까워지면 거짓이다. |

- **남은 후보: ①, ⑤**
- A가 **가까워지면 ⑤**, **멀어지면 ①**이 부적절하다. 따라서 가린 방향 정보 없이는 정답을 확정할 수 없다.
