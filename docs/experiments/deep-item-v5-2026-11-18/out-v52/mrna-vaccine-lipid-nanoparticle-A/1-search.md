## 1. 탐색·검사 결과

판정은 **지문에 제시된 물질의 성질·조건·전달 경로**에 한정했다. 특히 ‘지문에서 확인되지 않음’과 ‘지문에 의해 거짓으로 확인됨’을 구별했다.

| 항목 | 수 |
|---|---:|
| 훑은 명제 쌍·셋 | 48 |
| 만든 후보 | 48 |
| (a) 부분 독해 시 개연성 부족으로 탈락 | 16 |
| (b) 통합해도 명백한 거짓으로 확정되지 않아 탈락 | 5 |
| (c) 지문 없이 상식만으로 거짓임이 드러나 탈락 | 0 |
| (d) 참일 여지·해석의 모호성·지나치게 단순한 뒤집기로 탈락 | 7 |
| **최종 통과** | **20** |

- 각 탐색 항목에서 후보를 하나씩 만들었다.
- 탈락 수는 **(a)→(b)→(c)→(d) 순서로 검사했을 때 처음 탈락한 검사**를 기준으로 집계했다.
- 아래 인용은 원문 그대로이며, 부분 인용은 「 」로 표시했다.
