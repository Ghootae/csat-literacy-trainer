부정 발문이므로 **내용상 참인 선지를 ‘제거’**한다.

① **남음** — A의 이동 방향이 필요하다. A가 가까워지면 도플러 변위가 더 큰 A가 더 밝으므로 참이지만, 멀어지면 도플러 변위가 더 큰 것은 B이고 더 밝은 것은 A이므로 거짓이다.

② **제거** — B와 C는 송신 주파수와 도플러 각도가 같고, 적혈구의 이동 속도는 C가 더 빠르므로 도플러 변위의 절댓값도 C가 더 크다.

③ **제거** — 적혈구의 크기가 같고 송신 주파수는 D가 B보다 높으므로, 지문에 따라 D에서 산란이 더 많이 발생한다.

④ **제거** — B의 적혈구는 탐촉자에 가까워지므로 도플러 변위가 양(+)의 값을 갖는다.

⑤ **남음** — A가 더 빠르므로 D보다 밝게 표시되는 것은 맞지만, A도 파란색으로 표시되는지 판단하려면 A의 이동 방향이 필요하다.

**남은 후보는 ①, ⑤이며, 정답을 확정할 수 없다.** A가 가까워지면 ⑤가 거짓이고, 멀어지면 ①이 거짓이므로 ‘거짓인 선지가 하나’라는 조건으로도 가려진 방향을 결정할 수 없다.
