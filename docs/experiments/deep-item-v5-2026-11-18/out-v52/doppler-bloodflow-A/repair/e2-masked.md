※ 아래의 **‘남음’은 선지별 직접 검증 기준**이며, ‘정보 부족’과 ‘거짓 확인’을 구별해 적는다.

## V1

| 선지 | 판정 | 근거 또는 필요한 정보 |
|---|---|---|
| ① | **제거** | 이동하는 적혈구 때문에 송신·수신 주파수가 달라지는 것은 도플러 효과이므로 적절하다. |
| ② | **남음 — 정보 부족** | 각 매질의 밀도 대소와 경계면의 음향 저항차를 비교하려면, 가려진 A·B의 밀도 값이 필요하다. |
| ③ | **제거** | 가장 정확한 각도는 0°이므로 59°는 이에 해당하지 않지만, 실제 측정에서 유지해야 하는 60° 미만에는 해당한다. |
| ④ | **제거** | 두 부위 모두 탐촉자를 향하므로 빨간색이며, 더 빠른 B가 더 밝게 표시된다. |
| ⑤ | **남음 — 거짓 확인** | ㉡은 적혈구에서 산란되어 돌아오는 유용한 신호이므로, 혈액과 적혈구의 음향 저항차를 없애는 것은 혈류 정보 수신에 유리하지 않다. |

- **선지별 직접 판정상 남음: ②, ⑤**
- 다만 **⑤의 부적절함은 가린 정보 없이 확정**된다. 따라서 제시된 **‘거짓 선지는 하나’라는 조건까지 적용하면 정답은 ⑤**이다. 이는 ②의 가려진 밀도 관계를 직접 확인했다는 뜻은 아니다.

## V2

| 선지 | 판정 | 근거 또는 필요한 정보 |
|---|---|---|
| ① | **남음 — 정보 부족** | 초음파가 수신된 것은 확인되지만, 빨간색 표시 여부를 판단하려면 A의 적혈구 이동 방향이 필요하다. |
| ② | **제거** | B와 C의 도플러 각도·송신 주파수 등이 같고 C의 적혈구가 더 빠르므로, 도플러 변위의 절댓값은 C가 더 크다. |
| ③ | **제거** | 적혈구 크기가 같고 송신 주파수는 D가 B보다 높으므로, D에서 산란이 더 많이 발생한다. |
| ④ | **제거** | B의 적혈구는 탐촉자에 가까워지므로 도플러 변위가 양(+)이다. |
| ⑤ | **남음 — 정보 부족** | A가 D보다 밝다는 것은 확인되지만, 둘 다 파란색인지 판단하려면 A의 적혈구 이동 방향이 필요하다. |

- **남은 후보: ①, ⑤**
- A의 이동 방향이 가려져 있으므로 **정답을 하나로 확정할 수 없다.**
