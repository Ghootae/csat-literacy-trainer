## V1 — 문항

〈보기〉의 그래프는 같은 초음파 도플러 혈류계로 두 혈관 ㉠과 ㉡의 여러 지점에서 얻은 값을 나타내며, ⓐ와 ⓑ의 도플러 각도는 각각 45°와 60°이다.

**윗글을 바탕으로 〈보기〉를 이해한 내용으로 가장 적절한 것은?**

> **〈보기〉**
>
> 가로축은 송신 주파수(MHz), 세로축은 도플러 변위(Hz)이다. ㉠의 실선은 왼쪽부터 ⓐ, ⓑ, ⓒ를 지나며, 가로축 아래에서 오른쪽으로 올라간다. ㉡의 점선은 왼쪽 끝점 ⓓ에서 오른쪽 끝점 ⓔ까지 올라가며, 그사이에 가로축을 지난다. ⓐ와 ⓓ는 같은 세로 눈금선 위에 있다.

① ⓐ와 ⓑ의 도플러 각도는 둘 다 실제 측정에서 오차 값이 적도록 유지해야 하는 범위에 들겠군.  
② ⓐ와 ⓔ의 값이 서로 달라도, 두 지점에서 돌아온 초음파를 수신하는 일은 표시 단계에 속하겠군.  
③ ⓓ의 적혈구가 ⓐ의 적혈구보다 작다면, 적혈구에 의한 초음파의 산란은 ⓓ에서 더 적게 일어나겠군.  
④ ⓑ와 ⓔ는 모두 각 곡선의 왼쪽 끝점보다 높으므로, ⓔ에서처럼 ⓑ에서도 혈류가 탐촉자를 향하겠군.  
⑤ 영상 장치에서 ⓐ와 ⓒ의 혈류는 파란색으로, ⓔ의 혈류는 ⓓ와 달리 빨간색으로 표시되겠군.

## 출제 기록

### 〈보기〉 문장별 설계

| 문장·관찰 | 노린 오해 |
|---|---|
| 두 혈관의 여러 지점을 같은 혈류계로 측정했고, ⓐ와 ⓑ의 각도는 각각 45°와 60°이다. | 60°를 ‘60° 미만’에 포함하는 오해를 노렸다. 최적 각도와 허용 범위를 혼동하는 기존 함정과는 구분했다. |
| 가로축은 송신 주파수이고 세로축은 도플러 변위이다. | 곡선에서 점의 좌우 위치, 높이, 가로축 위아래가 각각 다른 정보를 준다는 점을 구분하게 했다. |
| ㉠은 가로축 아래에서 올라간다. | 변위가 커졌다는 사실을 변위가 양수라는 뜻으로 읽게 하는 유인이다. |
| ㉡은 올라가면서 가로축을 지난다. | 두 곡선이 모두 올라간다는 이유로 두 혈관의 표시 색도 같은 양상이라고 판단하지 않도록 했다. |
| ⓐ와 ⓓ는 같은 세로 눈금선 위에 있다. | 세로 좌표가 달라도 가로 좌표가 같으면 송신 주파수가 같다는 점을 읽어야 산란체 크기의 효과를 따로 판단할 수 있다. |

### 후보 검토 및 검산

| 검토 순서 | 참·거짓 후보와 채택 이유 |
|---|---|
| 범위 | ‘ⓐ만 범위에 든다’와 ‘둘 다 범위에 든다’를 비교했다. 후자를 택해 60°를 상한에 포함하는 오해를 겨냥했다. |
| 한 변수의 방향 | 산란량에는 ‘ⓓ에서 더 많다/더 적다’를, 혈류 방향에는 ‘ⓔ만 탐촉자를 향한다/ⓑ도 탐촉자를 향한다’를 검토했다. 산란량은 크기 효과를 뒤집은 선지를, 혈류 방향은 두 곡선이 모두 올라간다는 맞는 관찰을 앞세운 선지를 남겼다. |
| 여러 변수의 상쇄 | ‘산란체가 작아지는 효과와 송신 주파수가 낮아지는 효과가 상쇄된다’는 후보를 버렸다. 지문은 두 효과의 방향만 제시하므로 산란량의 같고 다름을 확정할 수 없다. |
| 다른 문장과 연결 | 수신을 ‘송수신 단계/표시 단계’에 두는 두 후보 중 후자를 보조 함정으로 택했다. 정답은 **그래프의 부호 → 혈류 방향 → 화면 색**으로 판정을 넘기는 연결을 채택했다. 양수와 음수의 방향 대응을 뒤집으면 ⑤의 색 판정도 뒤집힌다. |
| 버전 간 구분 | 재료 S의 6번은 수신 단계 함정에 활용했다. 8번의 ‘그래프가 올라간다는 사실을 잘못 해석하는’ 유인은 살리되, 밝기나 속도의 절댓값 비교 대신 **상승과 양수의 혼동**을 겨냥했다. 확정 V2의 저장 장치, 각도 정의, 주파수 환산, 귀환 경로, 밀도와 경계면 반사 판단은 쓰지 않았다. |

**자기 검산:** 참은 ⑤ 하나이다. ③·④·⑤는 각각 표시 점 두 개 이상을 비교해야 하며, 지문 없이 그래프만으로 정오가 정해지는 선지는 없다. ④와 ⑤는 부호 관찰을 공유하지만, ④는 기울기로 **방향**을 판단하는 오류를, ⑤는 부호와 방향을 거쳐 **표시 색**을 판단하는 연결을 묻는다. 배수 계산이나 지문 밖 지식은 필요하지 않다.
