## 1. 탐색 범위와 집계

제공된 지문은 **4문단**이므로, 실제로 존재하는 문단 조합 **1-2, 1-3, 1-4, 2-3, 2-4, 3-4와 같은 문단 안 대조**를 모두 탐색했다. 5문단이 필요한 조합은 해당하지 않는다.

| 항목 | 수 |
|---|---:|
| 훑은 명제 쌍·묶음 | 44 |
| 만든 후보 | 44 |
| (a) 부분 독해 시 그럴듯함 부족으로 탈락 | 8 |
| (b) 지문만으로 명확하게 반박하기 어려워 탈락 | 11 |
| (c) 상식만으로 거짓임이 드러나 탈락 | 0 |
| (d) 참이 될 해석이 있거나 너무 단순한 뒤집기여서 탈락 | 8 |
| **최종 통과** | **17** |

- 탈락 수는 **(a)→(b)→(c)→(d) 순서에서 최초로 탈락한 검사**에만 집계했다.
- 수치 비교에서는 다른 측정·표시 조건이 같다고 전제한다.
- 색에 관한 진술은 지문에 제시된 **일반적인 표시 방식**을 적용한다.
- 지문에 없는 도플러 공식이나 산란량 계산식은 사용하지 않았다.

### 특히 주의할 판정 지점

- **8번:** −600→−200은 수치로는 증가하지만, 절댓값은 600→200으로 감소한다. 따라서 더 밝아지는 것이 아니라 **더 어두워진다**.
- **12번:** 두 경계의 음향 저항 차이는 각각 **2와 6**이다. 반사량 판단 기준은 개별 저항값이 아니라 **두 매질 사이의 차이**이다.
- **14번:** “0°가 되기 어렵다”는 **0°를 허용 범위에서 제외한다**는 뜻이 아니다. 지문이 제시한 기준은 **60° 미만**이다.
- **17번:** 더 빠른 이탈 혈류는 **밝은 파란색**, 더 느린 접근 혈류는 **어두운 빨간색**에 해당한다.
