## V1 — 적절하지 않은 것 고르기

| 선지 | 판정 | 근거 |
|---|---|---|
| ① | 제거 | 첫 가동에는 금속 입자만 넣었고 고체 촉매에는 활성 성분이 반드시 있으므로, 그 금속 입자가 활성 성분이다. |
| ② | 제거 | 같은 온도와 시간에 서로 붙어 커진 입자의 비율이 낮았으므로, 소결로 인한 촉매 활성 저하는 첫 가동보다 작았다고 볼 수 있다. |
| ③ | 제거 | 흡착이 지나치게 강하면 흡착된 반응물이 지나치게 안정화되어 표면 반응이 느려지고 촉매 활성이 낮아진다. |
| ④ | 남음 | X 원자가 어디에 붙었는지, 그리고 소결이 줄어든 이유가 금속 입자의 X 표면 분산인지 판단할 정보가 필요하다. |
| ⑤ | 제거 | X를 더 공급하자 활성 성분인 금속의 표면 전자 밀도와 흡착 세기가 달라졌으므로, X는 증진제로 작용했다. |

**남은 후보는 ④뿐이다.** 거짓인 선지가 하나라는 문항의 전제에 따르면 소거법으로 ④가 정답이다. 다만 가려진 정보 없이 ④의 내용 자체가 거짓임을 직접 확인할 수는 없다.

## V2 — 적절하지 않은 것 고르기

| 선지 | 판정 | 근거 |
|---|---|---|
| ① | 제거 | 고체 촉매에서는 반응물이 먼저 활성 성분의 표면에 화학 흡착되며, ㉯의 활성 성분은 금속 입자이다. |
| ② | 남음 | 금속의 총량만으로는 사용 후 활성을 비교할 수 없으므로, 사용 후 표면에서 반응에 관여하는 금속 원자 수의 비교가 필요하다. |
| ③ | 제거 | 두 촉매는 모두 고체이고 생성물은 기체이므로 별도의 분리 공정이 필요 없다. |
| ④ | 제거 | ㉯의 금속 입자를 분산시킨 물질은 지지체이며, 지지체는 소결로 인한 촉매 활성 저하를 억제한다. |
| ⑤ | 남음 | 두 촉매의 흡착 세기는 같지만, 사용 후 반응에 관여하는 표면 금속 원자가 ㉯에 더 많은지는 가려져 있다. |
