# 코덱스에 붙여 넣을 요청 (2026-11-19)

첨부한 blind/BLIND-v52v53.md를 풀고 판정해 줘. 지문 두 개에 〈보기〉 3점 문항이 8개씩 있어. 출처는 가렸어.

1. 문항마다 고른 답, 판정(수능 같음 / 중 / 수능 아님), 한 줄 이유를 표로 적어 줘. 판정 기준은 "평가원·수능 3점 〈보기〉 문항으로 그대로 낼 수 있는가"야.
2. 지난번처럼 두 평가자로 해 줘. 하나는 너, 하나는 첨부 파일만 보는 독립 평가자.
3. 답과 등급을 모두 고정한 뒤에만 blind/KEY-v52v53.md를 열어서 정답을 맞춰 봐.
4. 결과는 blind/REPORT-v52v53-human.md(요약), blind/REPORT-v52v53-desktop.md(독립 평가와 정답표 대조)에 저장해 줘.
