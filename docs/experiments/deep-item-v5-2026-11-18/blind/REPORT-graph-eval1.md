더 수능다운 문항은 **가**다.  
가에서는 ⓐ→ⓑ와 ⓑ→ⓒ가 모두 상승하지만 부호는 음→양으로 바뀐다는 것을 읽고 → 지문의 ‘부호에 따른 혈류 방향’에 대응시켜 → 두 구간의 방향이 반대이므로 ②가 부적절하다고 판단해야 한다.  
다른 선지에서도 절댓값 비교 → 속도 비교 → 밝기 비교, 양의 부호 → 탐촉자로 접근 → 빨간색 표시라는 연결을 학생이 수행한다.  
나에서는 같은 각도의 ⓐ·ⓑ에서 절댓값이 각각 400·200임을 읽고 → 속도와 밝기에 대응시켜 → ⓑ가 더 어둡다는 ⑤를 고른다. 이 비교는 타당하지만, 나머지 선지의 젤·각도·측정 단계가 이 판단과 긴밀하게 연결되지는 않는다.
