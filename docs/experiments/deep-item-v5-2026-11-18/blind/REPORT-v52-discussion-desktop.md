# v5.2 풀이 검사 제안

기준 자료는 이 폴더의 CODEX-DISCUSSION.md, BLIND.md, REPORT-v51-reading-human.md다. 사람의 평정은 질문지에 인용된 다섯 사례로 한정한다. 아래 설계는 미실험이며 성능 수치와 정책 승인은 없다. 조항별 판단·수정 예시·대조군 출처는 REPORT-v52-discussion-human.md에 있다.

| 출력 필드 | 질문과 기록 단위 |
|---|---|
| response_role / truth | 발문 극성과 선지 진릿값을 별도로 기록한다. 참·거짓·판정 불가를 허용한다. |
| proof | 선지마다 판정을 끝내는 가장 짧은 절, 지문 인용, 필요한 표 셀·관찰, 하나를 생략하면 남는 불확실성을 기록한다. |
| shortcut | 본문 한 사실과 선지만으로 판정하는 설명을 시도한다. 실제로 필요한 비교·대입·대상 대응이 있으면 명시한다. |
| survivors | 핵심 관찰을 가린 독립 입력에서 성립하는 근거로 제거 가능한 선지와 남는 후보를 번호로 반환한다. 답 강제는 금한다. |
| rival | 부분 이해자가 택할 후보와 그 학생이 올바르게 읽은 사실, 잘못 적용한 관계, 둘을 가르는 관찰을 기록한다. |
| unique_answer / repair | 전체 자료에서 가능한 정답 집합, 근거 충돌, 고칠 최소 범위를 반환한다. 판정 불가와 복수 정답을 별도 기록한다. |

전체 자료와 가린 버전은 별도 맥락에서 정답·출제 의도 없이 풀린다. 가릴 셀은 후속 검사자가 기존 답을 추측할 수 없는 중립 표식으로 처리한다. 전체 보기 삭제 시 기호와 지시 대상이 사라지면 도출 불가가 자명해지므로 대응 이름·단위는 남긴다. 보기 전체를 가리는 검사와 특정 관찰을 가리는 검사를 구분한다. 가린 뒤에도 이유가 성립하는 유일 후보가 남으면 수리 대상으로 삼는다. 근거가 맞지 않는데 우연히 키와 일치한 경우는 포함하지 않는다. 수리 후 전체 다섯 선지를 새로 풀어 정답 유일성과 경쟁 선지 보존을 확인한다. 이미 보관한 v5.1 입력·결과와 사람 판정을 활용해 ‘한 단계’ 및 ‘보기 불필요’ 판정에서 과잉 탐지와 누락 사례를 각각 검토한다.
