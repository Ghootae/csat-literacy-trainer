# 코덱스에 붙여 넣을 요청 (2026-11-20, 인문·사회 관점형 대조)

첨부한 docs/experiments/deep-item-v5-2026-11-18/blind/BLIND-view-hs.md를 풀고 판정해 줘. 지문 두 개에 〈보기〉 문항이 5개씩 있어. 출처는 가렸고, 기출이 섞여 있을 수 있어.

1. 문항마다 고른 답, 판정(수능 같음 / 중 / 수능 아님), 한 줄 이유, 결함 표시(풀이지 맨 위 ㉮~㉴ 중 해당하는 것)를 표로 적어 줘. 판정 기준은 "평가원·수능 3점 〈보기〉 문항으로 그대로 낼 수 있는가"야.
2. 두 평가자로 해 줘. 하나는 너, 하나는 첨부 파일만 보는 독립 평가자.
3. 답·등급·결함 표시를 모두 고정한 뒤에만 blind/KEY-view-hs.md를 열어서 정답과 출처를 맞춰 봐.
4. 결과는 blind/REPORT-view-hs-human.md(요약: 생성 문항이 같은 지문 기출보다 나은지·비슷한지·못한지, 결함 표시 개수), blind/REPORT-view-hs-desktop.md(독립 평가와 정답표 대조)에 저장해 줘.
5. API 호출은 하지 마(이번 판정은 비용 없이 코덱스 안에서만).
