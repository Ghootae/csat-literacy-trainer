# 인문·사회 사례 재실행 판정 · 2026-11-20

## 1. 개요

평가 기준은 ‘평가원·수능 3점 〈보기〉 문항으로 그대로 낼 수 있는가’였다. 신규 생성 4문항 중 같은 지문 기출과 같은 등급을 받은 문항은 주 평가자 기준 1개(공시 다), 독립 평가자 기준 0개였다. 둘 다 공시 라와 명실 가·나를 기출보다 낮게 평가했다. 기출 두 문항은 두 평가자 모두 ‘수능 같음’이었다. 두 사람 모두 7/7 정답이었고, 등급은 5/7, 결함 기호는 7/7 일치했다.

| 문항 | 출처 | 정답 | 주 평가자 | 독립 평가자 | 결함(공통) |
|---|---|---|---|---|---|
| 공시 가 | 이전 생성 A-V2 | ④ | 수능 같음 | 중 | ㉱ |
| 공시 나 | 기출 12번 | ⑤ | 수능 같음 | 수능 같음 | 없음 |
| 공시 다 | 신규 생성 A-V1 | ② | 수능 같음 | 중 | ㉱ |
| 공시 라 | 신규 생성 B-V1 | ① | 중 | 중 | ㉯㉱ |
| 명실 가 | 신규 생성 B-V1 | ④ | 중 | 중 | ㉯ |
| 명실 나 | 신규 생성 A-V1 | ② | 중 | 중 | ㉯ |
| 명실 다 | 기출 12번 | ④ | 수능 같음 | 수능 같음 | 없음 |

A-V1·B-V1·A-V2는 정답표의 생성본 식별자다. 이전 생성본을 포함한 5문항에서 기출과 같은 등급은 주 평가자 2개, 독립 평가자 0개였다. 기출보다 높은 등급은 없었다.

| 결함 | 신규 생성 4개 | 이전 생성 1개 | 기출 2개 |
|---|---|---|---|
| ㉮ 지문 예시의 이름만 교체 | 0 | 0 | 0 |
| ㉯ 보기 없이 판별 가능한 선지 2개 이상 | 3 | 0 | 0 |
| ㉰ 쓰이지 않는 사실 | 0 | 0 | 0 |
| ㉱ 무관한 사건 나열 | 2 | 1 | 0 |
| ㉲ 지문 한 문장으로 정답 결정 | 0 | 0 | 0 |
| ㉳ 정답 시비 위험 | 0 | 0 | 0 |

숫자는 각 결함을 표시한 문항 수다. 두 평가자의 집계가 같으며, 한 문항에 복수 표시할 수 있다. 주 평가자는 직전 대화에서 공시 가·나와 명실 다를 이미 풀고 출처를 확인했다. 이번 정답표는 두 평가자의 답·등급·결함을 고정한 뒤에 열었다. 독립 평가자는 직전 대화 없이 이번 풀이지만 읽었다. 별도 API 호출은 없었다.

## 2. 본문

### 공시 다의 정보 전달은 기출 수준인가 (판단 필요)

정기 공시에서 누락된 대주주 변동 정보가 임원→갑→을로 전달된다. ②의 을은 실제로 매수했지만 2차 수령자이고, ④의 갑은 직접 매수하지 않았지만 1차 수령자로서 을에게 정보를 이용하게 했다. 주 평가자는 두 사람에게 적용되는 규제를 가르는 이 대조에 ‘수능 같음’을 주었다. 독립 평가자는 ①·③의 사모 채권 문제를 뒤쪽 사건과 따로 풀 수 있다는 점에 무게를 두어 ‘중’을 주었다. 이전 생성본인 공시 가에서도 등급이 같은 방향으로 갈렸다.

### 공시 라와 명실 가·나의 오답 배제 (해결)

세 문항 모두 두 평가자가 ‘중’과 ㉯를 주었다. 공시 라에서 ⑤는 갑이 타인에게 정보를 이용하게 했다는 사실을 선지 안에서 밝히고도 직접 매매하지 않았다는 이유로 면제한다. 명실 가에서는 검은 돌을 치운 뒤 한 개만 남았다는 장면이 ②와 ④에 쓰이지만, ①의 ‘천지 만물은 사명’과 ⑤의 ‘후기 묵가는 한 명으로 두 실을 지시하는 것을 거부’는 장면 없이 배제할 수 있다. 명실 나에서도 ①의 명명 전 분화와 ③의 형체·색 구별이 같은 방식으로 풀린다.

| 다음 검토 | 외부 전송 | 사용자 판단 |
|---|---|---|
| 공시 다를 그대로 채택할 때, ①·③이 정보 전달 사건과 독립적으로 풀리는 점을 허용할지 검토 | 없음 | 채택 기준 |
