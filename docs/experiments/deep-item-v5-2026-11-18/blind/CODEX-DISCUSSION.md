# 코덱스와 논의할 내용 (2026-11-19)

아래를 코덱스에 그대로 붙여 넣으면 됩니다.

---

블라인드 판정 고마워. 내 판정(사람)과 네 판정을 맞춰 보니 약점의 종류는 같고 수준 판단이 갈렸어. 다음 생성기(v5.2) 규칙을 정하기 전에 네 의견을 듣고 싶어.

**배경**
- 생성 문항은 지문 4개 × 4문항. 각 지문에 표 〈보기〉 2개(B형 '가장 적절한 것', A형 '적절하지 않은 것'), 사례 〈보기〉 2개.
- 기출 대조군 2개(도플러 12번, mRNA 19번)는 둘 다 교육청 문항이야.

**갈린 판정**
| 문항 | 사람 | 코덱스 |
|---|---|---|
| 도플러 가 (생성 B형 표) | 수능 같음 | 중 |
| mRNA 가 (생성 B형 표) | 수능 같음 | 중 |
| 도플러 라 (기출 12번) | 너무 쉬움 | 상 |
| mRNA 라 (생성 B형 사례) | 중 | 상 |
| mRNA 마 (생성 A형 사례) | 하 | 중 |

**질문**
1. 기준 차이: 사람은 "전체가 쉬운가"를, 너는 "가장 좋은 함정이 하나라도 있는가"를 더 본 것 같아. 도플러 12번이 '상'인 이유가 ② 함정 하나 때문이라면, 나머지 선지가 쉬운 문항도 상이 될 수 있어? 수능 3점이라면 오답 네 개가 각각 어느 정도여야 한다고 보는지 기준을 말해 줘.
2. 생성 B형 표 둘(도플러 가, mRNA 가)을 '상'으로 올리려면 무엇을 바꾸면 돼? 선지 하나씩 짚어 줘.
3. 네가 좋게 본 함정 두 가지를 생성 규칙으로 옮기려고 해.
   - (기출 12번 ②) 〈보기〉를 바르게 읽은 관찰("선이 올라간다")에서 틀린 결론("방향도 같다")으로 넘어가게 하는 함정
   - (mRNA 라 ①) 실제 관찰에 그럴듯한 다른 원인을 붙여 정답과 경쟁하는 오답

   이 둘을 "원칙 + 점검 질문" 형태로 써 줘. 예시는 이 지문들이 아닌 다른 화제로.
4. 아래 v5.2 규칙 초안에서 빠진 것, 과한 것, 서로 부딪치는 것이 있으면 알려 줘.
   1. 정답은 〈보기〉의 값·관찰을 해석해야 정해진다(〈보기〉를 하나도 해석하지 않고 맞히면 실패).
   2. 선지가 판정 조건을 스스로 주지 않는다(예: mRNA 다 ⑤의 "수용체에 결합하더라도").
   3. 정오는 첫 절(재진술)이 아니라 〈보기〉→지문 연결 지점에서 갈린다(예: mRNA 마 ③).
   4. 〈보기〉 사실과 반대되는 가정을 쓰지 않는다(예: mRNA 가 ③ "표는 함입 없음 → 함입된다면").
   5. 매력 오답은 〈보기〉 관찰은 맞게 쓰고 결론·원인만 틀리게 만든다.
   6. 오답 넷 중 한 단계(지문 한 문장 뒤집기)로 지워지는 것은 많아야 하나.
5. 규칙만으로는 잘 안 지켜져서, 풀이 검사 모델이 위 항목을 잡으면 그 문항만 고쳐 쓰는 수리 단계를 넣으려 해. 검사 모델이 "한 단계로 지워짐"과 "〈보기〉를 안 써도 풀림"을 안정적으로 판별하게 하려면 어떤 출력 필드나 질문이 좋을까?
6. 다음 비교 대조군을 평가원·수능 3점으로 바꾸려 해. 과학·기술 지문 중 표·그래프 〈보기〉 3점 문항으로 추천할 만한 것이 있으면 알려 줘(연도·회차·번호).
