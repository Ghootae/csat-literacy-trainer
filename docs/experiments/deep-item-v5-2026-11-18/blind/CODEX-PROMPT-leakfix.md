작업 폴더의 BLIND-leakfix.md를 풀고 판정해 줘. 지문 두 개에 〈보기〉 문항이 3개씩, 모두 6개야. 출처는 가렸고 기출이 섞여 있을 수 있어. 이 파일 말고 다른 파일은 열지 마. 인터넷·API도 쓰지 마.

문항마다(지문1 가·나·다, 지문2 가·나·다) 직접 풀어서 다음을 정해 줘.
- 고른 답(①~⑤)
- 판정: 수능 같음 / 중 / 수능 아님 (기준: 평가원·수능 3점 〈보기〉 문항으로 그대로 낼 수 있는가)
- 한 줄 이유(판정을 가른 이유)
- 결함 표시: 풀이지 맨 위 ㉮~㉴ 중 해당하는 것(없으면 빈칸)

서로 비슷한 문항이 있어도 문항마다 따로 판정해. 출력은 먼저 마크다운 표(지문|문항|답|판정|이유|결함), 그 아래 같은 내용을 ```json 블록 하나로: [{"passage":1,"item":"가","answer":"⑤","grade":"수능 같음","reason":"...","defects":["㉴"]}, ...]. 파일은 쓰지 말고 답으로만 내 줘.
