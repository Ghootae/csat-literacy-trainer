작업 폴더의 BLIND-graph.md를 풀고 판정해 줘. 지문 하나에 그래프형 〈보기〉 문항이 2개(가, 나)야. 출처는 가렸고 기출이 섞여 있을 수 있어. 〈보기〉의 그림은 첨부한 PNG 두 장이고(문항 가 → graph-가.png, 문항 나 → graph-나.png), 문항에는 같은 그림을 글로 옮긴 그래프 읽기 판도 적혀 있어. 그림과 읽기 판을 같이 보고 풀어. 이 폴더의 파일 말고 다른 파일은 열지 마. 인터넷·API도 쓰지 마.

1) 문항마다(가, 나) 직접 풀어서 정해 줘.
- 고른 답(①~⑤)
- 판정: 수능 같음 / 중 / 수능 아님 (기준: 평가원·수능 3점 〈보기〉 문항으로 그대로 낼 수 있는가)
- 한 줄 이유(판정을 가른 이유)
- 결함 표시: 풀이지 맨 위 ㉮~㉴ 중 해당하는 것(없으면 빈칸)
- 그래프 자체에 대한 한 줄 평(그림이 수능 〈보기〉 그래프로 읽히는지, 어색하거나 불필요한 부분이 있는지)

2) 두 문항 중 더 수능다운 문항을 고르고, 차이를 학생의 풀이 단계(무엇을 읽고 → 지문의 어느 개념에 대응시키고 → 어떤 판단을 스스로 내려야 하는지)로 3~5줄 설명해 줘.

출력: 먼저 1)의 마크다운 표(문항|답|판정|이유|결함|그래프 평), 그 아래 2)의 설명, 마지막에 1)과 같은 내용을 ```json 블록 하나로: [{"item":"가","answer":"⑤","grade":"수능 같음","reason":"...","defects":["㉴"],"graphNote":"..."}, ...]. 파일은 쓰지 말고 답으로만 내 줘.
