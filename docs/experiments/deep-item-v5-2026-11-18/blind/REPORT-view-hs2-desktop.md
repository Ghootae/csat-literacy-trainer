# 인문·사회 관점형 재실행 · 평가자별 판정과 정답 대조

주 평가자는 직전 평가에서 의미 가·나와 정보 다의 문항과 출처를 보았다. 독립 평가자는 대화 이력 없이 이번 풀이지만 읽었다. 두 평가자의 답·등급·결함을 고정한 뒤 정답표를 열었다. 별도 API 호출은 없었다. 자료는 [풀이지](./BLIND-view-hs2.md)와 [정답표](./KEY-view-hs2.md)다. 의미 기출은 원래 비판형 발문을 유지했고 정보 기출은 정답표 설명대로 발문을 표준화하고 참조 기호를 말로 풀었다. 학생 응답 자료는 수집하지 않았다.

## 정답과 출처 대조

| 문항 | 출처 | 정답 | 주 평가자 | 독립 평가자 | 결함 (주/독립) |
|---|---|---|---|---|---|
| 의미 가 | 기출 23번 | ⑤ | 수능 같음 | 수능 같음 | ㉯ / ㉯ |
| 의미 나 | 이전 생성 A-V1 | ⑤ | 수능 같음 | 중 | 없음 / ㉲ |
| 의미 다 | 신규 생성 A-V1 | ⑤ | 중 | 중 | ㉰㉲ / ㉰ |
| 의미 라 | 신규 생성 B-V1 | ② | 중 | 중 | ㉯ / ㉯ |
| 정보 가 | 신규 생성 A-V1 | ④ | 중 | 중 | ㉱ / ㉱ |
| 정보 나 | 신규 생성 B-V1 | ② | 중 | 중 | ㉯㉱ / ㉯ |
| 정보 다 | 기출 13번 | ⑤ | 수능 같음 | 수능 같음 | ㉱ / ㉱ |

A-V1·B-V1은 정답표의 생성본 식별자다. 두 평가자 모두 신규 생성 4문항을 전부 ‘중’, 같은 지문의 기출 2문항을 모두 ‘수능 같음’으로 판정했다. 신규 문항 기준으로 기출보다 높은 문항 0개, 같은 등급 0개, 낮은 문항 4개다. 두 평가자 모두 7/7 정답이었고 등급은 6/7, 결함 조합은 4/7에서 일치했다. 이전 생성본까지 포함한 5문항의 기출 동급/미만은 주 평가자 1개/4개, 독립 평가자 0개/5개였다.

| 결함 | 신규 4개 (주/독립) | 이전 생성 1개 (주/독립) | 기출 2개 (주/독립) |
|---|---|---|---|
| ㉮ 지문 예시의 이름만 교체 | 0 / 0 | 0 / 0 | 0 / 0 |
| ㉯ 보기 없이 판별 가능한 선지 2개 이상 | 2 / 2 | 0 / 0 | 1 / 1 |
| ㉰ 쓰이지 않는 사실 | 1 / 1 | 0 / 0 | 0 / 0 |
| ㉱ 무관한 사건 나열 | 2 / 1 | 0 / 0 | 1 / 1 |
| ㉲ 지문 한 문장으로 정답 결정 | 1 / 0 | 0 / 1 | 0 / 0 |
| ㉳ 정답 시비 위험 | 0 / 0 | 0 / 0 | 0 / 0 |
| ㉴ 학생이 내릴 판정까지 보기가 제시 | 0 / 0 | 0 / 0 | 0 / 0 |

### 석영 문항 두 개의 시간 정보는 어떤 역할을 하는가 (판단 필요)

이전 생성본인 의미 나는 ‘2020년에 구조를 처음 알아냈다’에서 ‘그때 의미가 처음 성립했다’로 넘어가는 ⑤의 추론이 틀렸다. 주 평가자는 발견 시점과 의미 성립을 구별하는 데 출제 가치가 있다고 보았다. 독립 평가자는 지문에 ‘과학적 발견을 통해 알려진다’고 쓰여 있어 두 표본을 대조하지 않고도 ⑤를 지울 수 있다고 보았다. 이전 평가에서 두 평가자 모두 기출과 같은 등급을 준 판단은 이번 초견 독립 평가에서 재현되지 않았다.

신규 의미 다도 석영을 쓰지만, 사람이 씻은 뒤 바뀐 것은 겉모습과 기술구이고 내부 구조는 같다고 보기에서 알려 준다. 1900년과 1980년 사이의 시간차를 빼도 ⑤의 정오는 그대로다. 두 평가자 모두 이 연혁에 ㉰를 표시했다. 의미 라에서는 같은 체험을 한 두 필자가 서로 다른 뜻풀이 근거를 택한 점이 ②에 쓰이지만 ①·③은 원고를 읽기 전에 걸러진다.

### 정보 가에서 토론 실패와 플랫폼의 규제 실패를 가를 수 있는가 (해결)

토론 직후에는 오류가 남았고, 플랫폼이 직접 삭제한 뒤에는 해당 게시물이 사라졌다. ③은 첫 시점에서 소수 의견의 우려를 확인하고 ④는 두 번째 시점에서 정부의 사후 개입 조건이 남았는지 묻는다. 두 평가자 모두 이 구분을 인정했지만, 유료 보고서의 역선택은 게시물 삭제와 연결할 필요가 없어 ‘중’을 주었다. 정보 나의 ②는 가격을 아는 것과 거래 정보를 온전히 아는 것을 구별하지만, ③의 표시 의무와 ⑤의 자율 규제는 선지에 서술된 조건만으로도 배제할 수 있다.

### ㉴의 적용 (해결)

이번 풀이지는 비판 전제 제시를 ㉴에서 명시적으로 제외했다. 의미 가의 도깨비 사례에서 ‘지시체 없이도 의미가 있다’는 전제를 외재주의에 대한 비판으로 연결하는 판단은 학생에게 남아 있다. 두 평가자 모두 이 문항을 포함한 7문항 전체에서 ㉴를 표시하지 않았다. 이 표본의 등급 차이는 주로 불필요한 정보, 따로 풀리는 사건, 보기 없이도 지워지는 선지에서 나왔다.

|---|---|---|
| 이전 생성 의미 나를 기준 문항으로 계속 쓸 경우, 두 표본의 차이를 가려도 ⑤를 배제할 수 있는지 확인 | 없음 | 기준 문항 유지 여부 |
