## 요지

질문을 받은 학생이 **개념어 하나만 대도 통과하는 경우가 많다.** 빈 곳 질문에 학생이 쓰지 않은 관계 요소(문제 상황·대상·조건)가 들어 있고, 판정은 답을 질문과 합쳐 읽으므로 비어 있는 술어 하나("차단", "제한", "보호")만 채우면 담음으로 친다.

## 대표 사례

- **A1·C1·C2 para-21 (2문단, 재확인)**: 엉뚱 요약 "기존 백신은 바이러스 배양해서 만드는 옛날 방식임" → 질문 2개("접종한 mRNA는 … 어떤 과정을 거쳐 면역 반응을 일으켜?", "mRNA가 세포 안으로 들어가기 어려운 점을 해결하려고 … 어떤 방법을 쓰는지") → 답 "1. 단백질 만듦? 2. 지질 나노 입자" → PRAISE [true, true], "흐름을 잘 잡았어". 흡수 안 되는 문제·보호는 질문이 준 것.
- **E1 para-33 (3문단, 재확인)**: AFTER_GAP CLOSE_GAP의 message·corePartSummaries 전부 중국어("你答出了细胞膜会阻挡亲水物质通过这一点…"). 검증 통과, 화면에 그대로 노출.
- C1 para-41: 질문이 "체내"·"투과"를 주고 답 "제한" 한 단어로 통과.
- C2 para-7: "1. 기억 세포 2. 면역"으로 두 부분 모두 통과. para-36: "차단".
- A2 para-27: 3문단 '배열 방향' 요구.
- A1 para-52: 사용자 실제 응답("낮은 산도에서 … 산도를 높여")이 para-50·51은 오류, para-52는 통과.

## 유형별 관찰

- 엉뚱(소재만) 7개 중 다시 써 보기는 1개(para-10)뿐, 6개는 빈 곳 질문으로 감.
- 베끼기 5개는 모두 다시 써 보기 → 자기 말로 다시 써서 통과.
- 답하기 4종은 문단마다 최소 1번씩 나옴.
- 같은 경계 글을 세 번 넣으면 핵심 부분 수가 1개·2개로 갈리고 결과도 통과·빈 곳·오류로 갈림.

## 일반 규칙 수정 후보 (에이전트 제안, Claude 검토 전)

1. 질문 뒤 판정에서 질문이 준 내용은 학생 몫으로 세지 않는다. 빠진 관계의 술어·결과가 학생 말 안에 있어야 담음. 합쳐 읽기는 생략된 주어·대상 이어받기에만.
2. 빈 곳 질문에 학생이 쓰지 않은 관계 요소를 넣지 않고, 둘 중 하나로 맞힐 수 있는 모양을 피한다. "개념어 하나로 답할 수 있는가" 자기 점검 항목.
3. 학생에게 나가는 문장의 한글 비율을 코드로 검사하고 실패면 재요청.
4. 질문 뒤 단계에서도 원문과 반대인 답·남은 오류는 바로잡는다(para-45, 60, 확신 중간).
5. 같은 문단의 핵심 부분을 세션마다 같게 고정(설계 판단 필요: 컨트롤러가 일부러 골드를 읽지 않음).
