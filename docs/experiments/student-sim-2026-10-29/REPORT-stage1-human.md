# 학생 역할 시뮬레이션 1단계(mRNA) — 결과 보고 (2026-10-29)

## 개요

**목적.** 사용자가 직접 써 보다가 우연히 찾던 문제를, 학생 역할로 일부러 다양한 응답을 넣어 미리·한꺼번에 찾는다. 1단계는 mRNA 지문(문단 5개, 19번 문항)으로 검토 방식이 쓸 만한지 확인.

**결과.** 문단 60세션, 문제 12세션, 비용 $0.56. 검토 방식은 쓸 만하다: 어제·0단계에서 본 문제가 다시 걸렸고, 새 문제도 찾았다.
- 가장 크고 흔한 문제: **질문에 답이 거의 들어 있어 개념어 하나·보기 고르기만으로 통과한다.** 문단 빈 곳 질문 27개 중 13개, 문제 교정 질문 6개 모두.
- 새로 찾은 치명적 문제: 문단 마무리가 **통째로 중국어**로 나온 경우 1건.
- 문제 화면은 판정기 판단은 대체로 맞는데, **그 뒤 코드가 쓰는 문장과 결론 재계산**이 판정기와 어긋난다.

**다음 스텝(권고 순서).**
1. 외국어 출력 차단(코드) — 작고 확실.
2. 문제 화면 안내 문장이 판정기 구분을 따르게(코드) — 작고 확실.
3. 질문 흘림 고치기(문단 지시문 v4.9, 문제 판정 v5.7) — 주 과제. 같은 도구로 전후 비교.
4. 문제 결론 재계산 규칙 — 사용자 판단 필요(아래 사례).
5. 2단계(나머지 5개 지문)는 3을 고친 뒤, 고친 것 검증을 겸해서.

## 본문: 사례

### 1. 개념어 하나로 통과 (문단 2문단, para-21)
- 학생 요약(엉뚱): "기존 백신은 바이러스 배양해서 만드는 옛날 방식임"
- 질문: "mRNA가 세포 안으로 들어가기 어려운 점을 해결하려고 이 문단에서 어떤 방법을 쓰는지 설명해 볼래?" 외 1개
- 학생 답: "1. 단백질 만듦? 2. 지질 나노 입자"
- 결과: 만점 칭찬. '흡수되지 않는 문제'와 '보호'는 질문이 알려 준 것.
- 왜: 판정기가 답을 질문과 합쳐 읽어, 질문이 준 내용까지 학생 것으로 센다. → 미해결, 다음 스텝 3.

### 2. 보기 고르기로 통과 (19번, prob-10)
- 학생: "완전 중성까진 모르겠음"
- 교정 질문: "양전하를 유지해, 전기적으로 중성이 돼?"
- 학생: "중성 되나 봄" → "핵심 오류를 잘 고쳤어"
- 교정 질문 6개가 모두 이런 "A야, B야?" 모양. → 미해결, 다음 스텝 3.

### 3. 중국어 출력 (문단 3문단, para-33)
- 마무리: "你答出了细胞膜会阻挡亲水物质通过这一点。…" 핵심 내용 상자도 중국어. 검증 통과. → 미해결, 다음 스텝 1.

### 4. 판정기와 다른 안내 문장 (19번)
- prob-9: 학생 "잘 모르겠음", 판정기도 '확인 불가'로 맞게 봤는데 화면은 틀린 답과 같은 "방금 답도 정확하지 않았어".
- prob-7: 판정기는 "판단 경로 확인됨", 화면은 "어떻게 판단했는지 다 알기 어려웠어". → 미해결, 다음 스텝 2.

### 5. 같은 입력, 다른 결과
- 문단: 경계 글을 세 번 넣으면 통과·빈 곳·오류로 갈림. 사용자 실제 '산도' 응답도 오류 2, 통과 1.
- 문제: 아래 판단 사례.

## 판단이 필요한 곳: 같은 근거가 "정확"과 "연결 부족"으로 갈림 (19번 ⑤)

선지 ⑤: "pH가 높아지면 이온화 지질의 소수성이 약해져 소수성 분자 간의 인력이 감소하므로 더욱 미세한 크기의 mRNA-지질 나노 입자 복합체가 형성되겠군."
원문 3문단: "물은 분자 내 전하가 양극으로 분리된 상태인 극성을 띠거나 분자가 전하를 띠는 물질, 즉 친수성 물질과만 섞이고…" / 5문단: "pH가 높은 용액에서는 … 이온화 지질이 전기적으로 중성이 되므로…"
학생 근거(두 세션 같음): "ph 높이면 … 중성됨 -> 전하 없어지니까 소수성은 오히려 강해짐 …"

- prob-1: "더 이어야 할 연결을 같이 채워 볼게" (판정기: 글은 소수성 변화를 설명하지 않는다)
- prob-11: "근거도 정확해. 잘 풀었어." (판정기 결론은 같은 '부족'인데, 칸 하나가 달라 서버가 '정확'으로 바꿈)

**사용자 판단(2026-10-29): "정확이라고 판단해."** → 원문 정의를 한 단계 적용한 추론은 정확한 근거로 본다.

질문: 원문 정의("전하를 띠는 물질 = 친수성")를 한 단계 적용해 "중성이 되면 소수성이 약해지지 않는다"고 추론한 근거를 **정확한 근거**로 볼까요? Claude 권고는 "정확"입니다(원문이 정의를 주고 학생이 그 정의를 그대로 썼음). 그렇다면 고칠 곳은 판정기가 이런 추론을 '확인 안 됨'으로 두는 쪽이고, 서버 재계산은 판정기와 같은 결론을 내도록 맞춥니다.
