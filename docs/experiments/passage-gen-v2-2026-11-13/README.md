# 지문 생성기 v2 (2026-11-13, 고침 2026-11-15)

결정(Ghootae, 2026-11-13): 규칙을 고친 생성기로 주제 C(마와 같은 주제)를 다시 생성하고, 교정 전후를 본다. 이후 개요 단계를 넣었다.
결정(Ghootae, 2026-11-15): 구조 목록을 설계에 넣고, 교정에 분량 한계를 두고, 기전 설명을 어디서 멈출지 정하고, W6의 예를 다른 주제로 바꾼 뒤, 쟁점을 고정해 두 번 돌린다. 분량은 1,800~2,200자.

## 단계

| 단계 | 지시문 | 하는 일 |
|---|---|---|
| 0 구조 고르기 | prompts/0-structure.md | 의뢰 조건과 구조 목록(../structure-catalog/CATALOG.md)으로 쟁점의 논리를 쓰고, 맞는 하위 구조 후보 2~3개를 고른다. 피할 구조가 주어지면 그 구조와 닮은 구조 묶음은 고르지 않는다 |
| 1 설계 | prompts/1-design.md | 후보의 항목 본문을 보고 구조 하나를 고른다(0절). 노드 거르기, 말하려는 것, 문단 기능표, 입장 설계표, 판정이 갈리는 사례, 사실 목록 |
| 2 개요 | prompts/2-outline.md | 문단마다 말하고자 하는 바 + 문장 단위 항목(하는 일, 내용 요지, 과학의 쓰임) |
| 3 집필 | prompts/3-write.md | 개요의 항목마다 한두 문장으로 쓴다. 개요에 없는 내용은 더하지 않는다 |
| 4 점검 | prompts/4-check.md | C1~C9, 개요 대조, 문단·문장 기능 점검, 흐름, 기준 빈칸, 사례. 문장을 빼거나 옮길 수 있다. 빠진 전환은 메우지 않고 문단 기능표에 적어 넘긴다 |
| 5 연결 채우기 | prompts/5-bridge.md | 멈칫할 곳에 잇는 말을 넣는다. 교과서 수준의 일반 지식, 재진술, 넘어가는 이유처럼 단순한 내용은 새로 채울 수 있다. 채운 내용은 표로 남기고 사실 확인을 붙인다. 문장을 빼거나 바꾸지 않는다 |
| 6 표현 교정 | prompts/6-proofread.md | 한 문장에 너무 많이 담지 않기 → 풀어 쓰기 → 문법 → 접속어·되풀이 → 분량 확인. 새 내용은 넣지 않고 뜻은 그대로 둔다 |

집필 규칙: prompts/rules.md (W1~W19, C1~C9).

설계 단계에 넘기는 구조 목록 항목에서 "예시 기출" 줄은 뺀다. 기출의 시험·제목이 보이면 그 지문을 떠올려 따라 할 수 있기 때문이다.

## 실행

저장소 루트에서, 두 번 돌린다. 두 번째는 첫 번째가 고른 구조와 그 닮은 구조 묶음을 피한다.

```
OUT_DIR=out-r3a node docs/experiments/passage-gen-v2-2026-11-13/run.mjs
OUT_DIR=out-r3b AVOID_FROM=out-r3a node docs/experiments/passage-gen-v2-2026-11-13/run.mjs
```

- 한 번에 7번 호출, 15~20분.
- 사람이 중간에 검토하는 단계는 없다. 개요는 점검 단계가 본문과 대조한다.
- 끝난 단계는 캐시로 건너뛴다. 중간에 끊겨도 다시 실행하면 이어서 한다. 처음부터 다시 하려면 FORCE=1.
- 피할 구조를 직접 줄 때는 AVOID=S7-2 처럼 코드를 쉼표로 이어 준다.

규칙 변경의 근거: API 판정(../passage-gen-api-test-2026-11-13/RESULT.md), 마 수정 과정(같은 폴더 revisions/C-1-rev1, rev2), 첫 실행 결과와 out-r2 검토(out-r2/REVIEW-claude.md).

- W14: 지문이 말하려는 것이 흐름에서 보여야 한다. 문단은 전체 안에서 확실한 기능(말하고자 하는 바)을 가지고, 문장은 그 문단에서 하는 일이 보여야 한다. 점검 질문 5개. 예는 틀이 아니다. 설계는 구조 목록의 짜임에서 출발하되, 특정 기출의 배치나 문장을 따라 하지 않는다.
- W6: 새 화제는 잇는 말과 함께. 첫 문장이 정의일 필요는 없다. 과학 설명은 쟁점의 대상과 단계마다 이어지게 쓰고, 그 연결에 필요한 교과 수준의 일반 지식은 써도 된다. 기전은 작용이 바로 낳는 변화까지 쓰고, 쟁점 대상에 내는 효과는 관측된 만큼만 쓴다.
- W9: 정리는 길이에 맞게 쓰고, 문항에서 물을 것은 남긴다.
- W12: 과학과 입장이 맞물릴 곳이 있으면 되도록 연결한다. 입장마다 쓸 필요는 없고 억지로 엮지 않는다(권고).
- W13: 판정 기준에 빈칸을 남기지 않는다.
- W15: 판정이 갈리는 가정 사례를 둔다. 사례의 자리와 하는 일은 고른 구조가 정한다.
- W16: 지문은 연구 보고서가 아니다.
- W17: 한계는 그 한계를 쓰는 입장의 목소리로 쓴다.
- W18: 입장 기호는 처음 소개할 때만 붙인다.
- W19: 과학 사실이나 이론은 놓인 문단의 기능에 맞게 고르고, 순서를 정하고, 필요한 데까지만 설명한다.
- C9 (새로): 기전 설명이 작용에서 멈추지 않았는가, 작용이 바로 낳는 변화가 있는가, 그 효과를 관측보다 크게 말하지 않았는가.
