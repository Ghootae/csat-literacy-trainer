# r3a·r3b 지문 비교 — 웹 에이전트 논의용

2026-11-15. 자료는 같은 폴더의 commissions/C.md, out-r3a 및 out-r3b의 C-1/structure.txt, after-bridge.md, final-passage.md와 실행 비교 기록이다. 비교 기준은 직전 직장판과 의뢰 C의 관점 대립·융합·쉬운 입장 이해 및 고난도 사례 적용이다. 이번 작업은 기존 출력 검토이며 추가 생성 호출은 없다.

- 사용자가 보고한 경고 0건 및 회피 입력의 후보 배제와 별개로 실제 문단의 논리 및 학생의 추론 기회를 평가했다. 단일 의뢰 두 실행, 호출 모델 비교나 단계 추가의 인과효과 측정은 아님.
- a는 종전 기준 충족 비사용자 전체, 지원 수단, 정규시간, 사전 검증이 조건이다. 105<110으로 비사용자 미달이 확정되어 판정은 안정적이나 최종 문단이 답까지 제공한다. 집단 평균과 종전 기준 충족자 전원을 구별하는 보기에서 확장 가능하다.
- b는 ㉮의 공통 동의·건강 조건, ㉯의 전 직원 사전 수행 기록, ㉰의 향상분 제외 시 동일 산출을 구별한다. 115건 실제 수행은 110건 설정의 독립 근거가 아니다. 현 사례에서 ㉮ 승인, ㉯ 명시된 필요조건 충족, ㉰ 거부. ㉯ 승인 확정에는 충분성 표현 보완. ㉰ 또한 조건 위반에 따른 거부 방향이 명시적이다.
- 직전판에 비해 a는 지원·검증을 통해 상향 허용 가능성을 열고 b는 동등 접근보다 기준 산정의 독립성을 다룬다. 구조 회피는 다른 개념 대립을 만들어 냈으나 두 본문 모두 마지막에 단일 수치 사례를 배치한다.
- 교정은 의미·가독성에서 혼합 결과. a의 고지 대상 명료화는 개선, b 2문단 첫 문장의 효능·건강 관찰 결합은 읽기 부담 증가. 4~7문장이 의뢰 조건이므로 6문장 문단을 보존해도 형식 충족. 7문장 균일성이 생성기 자체의 반복 특성인지는 추가 자료 필요.
- b의 건강 관찰은 사전 심사의 동기로 쓰이며 매월이라는 간격은 제도가 채택한 조건이다. 기전은 주로 배경. 두 본문의 약리 서술 전반에 대한 연구 원문 재검증은 이번 평가 범위 밖이다.
- 권고는 b를 고난도 개발 후보로 보존하고 사례 자료를 재설계하는 것. ‘원칙과 같은 표현의 조건을 골라내기’와 ‘독립 자료에서 비교 기준을 복원하기’를 구별할 것. 실제 문항·풀이·오답률 미확인, 생성기 수정·새 실험 결정 없음.
