**2. 실행안 다섯 곳**

**① 판정자: 조건부 동의.** CLI의 표시를 코덱스 평가자에게 보여 주면 독립 판정이 깨진다. 셋은 같은 원문·표만 받고 따로 표시해야 한다. 출처, 생성 여부, 기존 평가, 수정 의도도 가린다. 정오와 풀이 근거를 먼저 고정하고 출제 정답은 뒤에 대조하자. 웹 에이전트는 갈린 곳의 원문과 각 근거를 보고 조정하되, 처음의 불일치는 남긴다. 해결되지 않으면 ‘애매’를 유지한다. 일치율은 전체 하나보다 칸별로 재고, 드문 값이 전부 누락돼도 높게 나오는지 값별 일치도 함께 본다. 같은 모델 두 명의 합의는 정확성 보증은 아니다.

**② 시험의 자리: 동의.** 넓은 감사의 필요성을 다시 통과시킬 관문은 필요 없다. 시범은 표시 기준·분모·자료 가림 방식이 작동하는지 확인하는 자리다. 6+6은 갈래와 발문을 맞추되, 칸마다 자료가 적으면 그 칸의 빈도로 규칙을 철회하지 않는다. 시범에서 표를 고쳤다면 시범 자료도 새 표로 다시 표시해야 한다. 1차 답의 ‘감사 범위를 가르는 시험’ 제안은 이 안으로 수정한다.

**③ 핵심 규칙: 일부 반대.** 보편 기준이라는 이름은 동의하지만, 준수율만으로 정하면 안 된다. 정답 유일성 같은 문항 성립 조건과 ‘모든 선지가 자료를 쓴다’ 같은 구성상의 빈도 주장을 구별해야 한다. 전자는 반례가 나오면 문항·판정·기준 정의를 먼저 점검하고, 후자는 낮은 준수율이 선택 전략으로 내릴 근거가 된다. 조건부 규칙은 적용 가능한 문항만 분모에 넣고 ‘애매’도 따로 보고한다. ‘3분의 1’은 보편성 재검토를 여는 사전 신호로는 쓸 수 있지만, 자동 철회선으로 쓰지는 말자. 갈래·발문별 차이도 함께 봐야 한다.

**④ 걸린 문항: 일부 반대.** 걸림 비율은 처리 방침의 근거가 되기에 부족하다. 검사기를 느슨하게 해도 비율은 내려간다. 정답 중복·근거 부족처럼 확인된 결함은 다시 생성하고, 정한 횟수 안에 해결되지 않으면 버린다. 선택 전략을 안 쓴 경우는 경고만 기록하고 통과시킨다. 판정이 갈린 경우는 자동 재판정 후에도 미해결이면 보류하고, 배포 대상에서는 제외한다. ‘보류’는 결함이 확정된 ‘버림’과 기록상 구별해야 한다. 새 규칙 평가는 걸림률과 함께 블라인드 품질·결함률·재생성 횟수를 본다.

**⑤ 자료: 동의.** 먼저 문항 고유번호로 중복을 합치고, 규칙 작성·보정에 쓰인 이력을 붙이자. 이미 본 자료는 시범과 반례 확인에 재사용하고, 새 자료 일부는 규칙 수정에 쓰지 않은 최종 확인용으로 남긴다. 교육청 고3은 보충할 수 있지만 평가원·수능과 합친 준수율로 결론 내리지 않는다. 기존 태깅 22개에는 교육청 고1~고3이 섞여 있으므로 그대로 새 표본으로 간주하면 안 된다.

**3. 선지 표시 항목**

가장 먼저 고칠 곳은 **①의 ‘근거 자리’**다. 거짓 선지는 한 부분만 틀려도 거짓으로 확정되지만, 참 선지는 필요한 부분을 모두 확인해야 한다. 이 차이를 표시하지 않으면 부정·긍정 발문 비교가 흔들린다.

- **① 수정:** “선지 전체의 참·거짓을 확정하는 최소 충분 근거: 지문만 / 〈보기〉만 / 둘 다 / 둘 없이도 가능 / 판정 불가.” 지문만은 **선지에 이미 적힌 조건·자료를 허용한 상태**로 정의한다. 근거 문장 위치와 결정적 관계를 한 줄 붙인다. 이름표의 대상 확인과 값·관계의 실제 사용도 구별한다.
- **② 수정:** ‘중심/경계/이유/세부’는 겹친다. 먼저 **내용 기능**을 “정의·주장 / 조건·범위·예외 / 이유·인과 / 비교·귀속 / 개별 사실”로 복수 표시한다. 이어 **요구 작업**을 “명시 내용 확인 / 대응·분류 / 관계 적용 / 조건 결합”으로 표시한다. ‘외우면 되는 세부’는 관찰과 평가가 섞인 말이므로 삭제한다. 중심 정의도 조건 적용을 요구할 수 있다.
- **③ 보완:** C5 목록에 “복수 / 기타 / 애매”를 더하고, 거짓이 되는 부분과 참으로 고친 최소 문안을 붙인다. 하나로 고치라는 규칙을 검증하면서 처음부터 하나만 고르게 하면 반례가 사라진다. 참 선지는 ‘해당 없음’이다.
- **④ 수정:** “판정에 필요한 〈보기〉 정보의 선지 내 제시: 전부 / 일부 / 없음”과 “새 가정: 없음 / 사실 변경 / 추가”로 나눈다. 자료를 옮기면서 가정도 넣을 수 있기 때문이다. ‘담지 않음’과 ‘반드시 봐야 함’은 같은 뜻이 아니다.
- **⑤ 축소:** ‘요지만 아는 사람’을 평가자가 제각각 상상하므로 주관적이다. 유지하려면 전원에게 같은 짧은 요지를 주고 별도로 풀게 해야 한다. 지금은 삭제하고 ②의 ‘명시 내용 확인’ 수를 보고하되, 이를 쉬운 선지 수라고 부르지 말자.
- **⑥ 유지·분리:** 내용상 참/거짓/판정 불가와 출제 정답 여부를 따로 둔다. 문항 단위에는 출처·학년·기존 사용 이력·지문 번호를 추가한다. 선지 다섯 개를 독립 문항 다섯 개처럼 세지 않는다.

**4. 목표**

**방향에는 동의하지만 “기출이 모두 통과”는 고쳐야 한다.** ‘모두 통과’와 ‘대부분 준수’는 다르고, 모든 기출을 통과시키려다 기준이 비거나 예외가 길어질 수 있다. 반대로 드문 기출 구성을 실패로 처리해서도 안 된다.

제안 문안은 다음과 같다.

> 문항 성립 기준은 정답 유일성, 충분한 판정 근거, 판정에 영향을 주는 모호함의 억제로 둔다. 구성 규칙은 기출에서의 빈도와 적용 범위를 확인해 갈래별 방식 또는 선택 전략으로 둔다. 지향점은 출처를 가린 평가에서 좋은 평가원·수능 기출과 견줄 만한 정확성·자연스러움·추론을 갖추는 것이다. 기출보다 강한 제한은 추가 목표로 밝히고, 얻는 이점과 배제하는 정상 구성을 함께 검증한다.

‘좋은 기출’도 현재 규칙을 잘 지킨 기출로 고르면 순환한다. 규칙 준수 평가와 별도로 블라인드 품질 평가를 받아야 한다. 학생을 가르는 힘은 이번 감사에서 확인됐다고 말할 수 없다.
