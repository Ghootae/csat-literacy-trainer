# "원문에 없음" 근거 판정 — 보고서

작성 2026-10-22. 논의용 상세본은 `REPORT-absence-falsity-type-desktop.md`에 있어요.

## 1. 개요

### 1) 작업의 목적
"지문에 근거가 없다"는 학생 근거를, 선지가 실제로 왜 틀렸는지에 따라 다르게 판정하게 했어요(메모장 36번, 사용자 A·B 규칙).

### 2) 작업의 결과
- 2차에서 모든 기준을 통과했어요. 근거 없는 덧붙임 선지(mRNA ⑤)의 "근거 없음"은 근거 충분, 원문과 어긋나는 선지(도파민 ②, 공손룡 ④)의 "없음"은 판단 방식 부족,
  있는 내용을 없다고 한 근거는 오류와 교정 질문으로 나왔어요.
- 1차에서는 A형 두 개가 근거 충분으로 넘어갔어요. 구분 문장을 "원문 사실로 반박되는가"로 바꾸자 해결됐어요.
- 비용은 두 번 합쳐 약 $0.058(luna 26회)이에요.

### 3) 다음 스텝
- 커밋(승인 필요). 다른 문항으로 일반화 확인은 B형 정답이 있는 문항이 생기면 해요.

## 2. 본문

### 1) mRNA ⑤ "근거 없음" (해결)
학생 "ph가 높아지면 소수성이 약해진다는 근거가 없음 → 5번 적절하지 않음" → 1차 3/3, 2차 2/2 근거 충분. 화면은 "근거도 정확해. 잘 풀었어."로 끝나요.

### 2) A형 "없음" (해결, 2차)
1차는 도파민 ②를 "작용 기간 연장이라는 덧붙임"으로 읽어 근거 충분으로 넘겼어요. 2차 문장으로 2/2 판단 방식 부족, 마지막 설명도 D-0159대로 나왔어요.

### 3) K1 흔들림 (미해결, 이번 변경과 무관)
회사법 K1에서 공식 해설에만 있는 조각을 넣는 일이 6번 중 2번 있었어요. 한 번은 근거 부족으로 끝났고, 한 번은 서버 검증 재시도로 근거 충분이 됐어요.
