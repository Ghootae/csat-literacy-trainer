## 해석

- 2차 문장("원문이나 <보기>에 나온 사실로 반박되면 … 판단 방식, 반박되지는 않고 뒷받침만 없을 때 '없음'이 핵심 관계")으로 사용자 A·B 규칙이 재현됐다.
- 1차의 A형 실패는 구분 문장 문제였고 2차에서 해소됐다. 2차는 A·B 각 2회라 표본이 작다.
- 1차 회귀의 L1·S1·U2는 2차 문장 변경 전 결과다. 바뀐 문장은 "없음" 근거에만 걸리므로 영향은 작다고 보지만 2차에서 다시 돌리지 않았다.
- K1 흔들림은 D-0161 "판정에 필요한 조각만" 규칙의 기존 불안정으로 보이며 이번 변경과 무관하다(K1 근거에 "없음" 진술이 없다).
