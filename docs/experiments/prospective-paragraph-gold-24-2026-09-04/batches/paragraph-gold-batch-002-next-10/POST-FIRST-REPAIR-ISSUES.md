# 1차 자동 수리 후 문제 보고

## 1. 전체 맥락

두 번째 배치의 10개 문단은 최초 생성·감사 후 필요한 경우 자동 수리를 한 번만 수행했다.
자동 단계가 끝났을 때 7개가 통과했고 3개가 검토 대상으로 남았다.

## 2. 수행한 작업에 대한 목적

‘1차 수리 후 남은 문제’를 하나로 뭉뚱그리지 않고, 어느 단계에서 무엇이 남았는지 구분해
다음 배치의 중단·보고 기준으로 사용한다.

## 3. 작업 과정

| 구간 | 결과 |
|---|---:|
| 최초 생성 완료 | 10개 |
| 축–관계 매핑 통과 후 감사 진입 | 8개 |
| 최초 감사에서 바로 통과 | 3개 |
| 최초 감사에서 자동 수리 요구 | 5개 |
| 1차 수리·재감사 통과 | 4개 |
| 자동 단계 종료 후 남은 문제 | 3개 |

## 4. 작업 결과

### 구조물의 하중과 허용응력 · 2문단

- 중단 단계: 축–관계 매핑
- 문제: core 관계 MR1의 압축·인장하중 방향 구분이 중심 서사와 중심축에서 빠짐
- 성격: 최초 생성 내부의 중심성 불일치
- 자동 수리 여부: 감사 후보가 만들어지기 전 중단되어 자동 수리하지 않음

### 나미브 사막 딱정벌레 · 4문단

- 중단 단계: 축–관계 매핑
- 문제: 중심 서사와 AX1에 필요한 물방울 병합·낙하 관계 MR2가 supporting으로 분류됨
- 성격: 핵심 관계와 보조 관계의 분류 오류
- 자동 수리 여부: 감사 후보가 만들어지기 전 중단되어 자동 수리하지 않음

### 나미브 사막 딱정벌레 · 5문단

- 중단 단계: 1차 수리 후 재감사
- 최초 감사 문제: 양보 간선 E4의 방향 표기 불일치
- 1차 수리 결과: E4 문제는 해결
- 남은 문제: 원문의 ‘최적화 전략이라 할 수 있다’를 P7에서 ‘최적화 전략이다’로 단정
- 성격: 평가·가능성 양상 강화

## 5. 결과 해석

엄밀한 의미에서 ‘1차 수리 후에도 남은 문제’는 딱정벌레 5문단 한 건이다. 나머지 두 건은
1차 수리 실패가 아니라 그 이전의 매핑 게이트가 생성 불일치를 차단한 사례다.

다음 배치부터는 자동 1차 수리와 재감사까지 끝난 뒤 실행을 멈추고, 이 형식으로 모든 잔여
문제를 먼저 보고한다. 사용자 승인 전에는 반자동 수리를 시작하지 않는다.
