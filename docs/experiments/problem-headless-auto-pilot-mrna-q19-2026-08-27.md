# mRNA 19번 헤드리스 자동 파일럿 — 2026-08-27

## 목적

실제 UI를 사용하지 않고 학생 역할 모델이 공개 문제 세션 API만 보면서 선택, 근거, 후속 답변과 재선택을 수행하게 했다. 문항은 고2 2023년 3월 교육청 모의평가의 「mRNA 백신과 지질 나노 입자」 19번 하나로 제한했다.

학생 역할은 중상, 중, 중하, 하, 최하의 다섯 수준에서 두 명씩 구성했다. 학생에게는 지문·보기·그림·선지와 공개 대화 상태만 제공하고 정답 키, 문제 골드, 대표 오답 경로, evaluator의 가설과 원출력은 제공하지 않았다.

## 실행 구성

- 자율 파일럿: 수준별 2회, 총 10회
- 학생 역할 모델: `gpt-5.6-terra / low`
- 서버 판정기: 실제 문제 풀이 API와 운영 evaluator
- 종료 조건: 공개 세션이 `COMPLETED`가 되거나 실행 한도를 넘는 경우
- 별도 표적 보충: 자율 실행에서 충분히 발생하지 않은 모호한 오답과 무근거 오답 2회

최초 오답 여섯 건은 선택 근거에 오류가 명시되어 있어 추가 진단 없이 교정 질문 또는 직접 코칭으로 이동했다. 시각 자료의 합류를 mRNA 소실로 읽은 경우, pH와 수소 이온 농도의 방향을 뒤집은 경우, pH 7과 친수성을 같은 속성으로 처리한 경우, mRNA와 이온화 지질의 전하를 뒤집은 경우를 각각 국소적으로 다뤘다.

②의 ‘투입 속도 조절’을 시간에 따라 유속을 계속 바꾸는 뜻으로 읽은 중상위권 사례는 학생 오류로 단정하지 않고 문항 해석 경계를 설명한 뒤 재선택시켰다. 다만 완료 결과가 과거 호환 라벨인 `DIAGNOSTIC_CORRECTION`으로 남아 문항 경계 전용 결과 라벨이 필요하다.

## 표적 보충 2회

자율 실행에서는 하·최하위 역할도 우연히 ⑤를 먼저 선택했다. 따라서 이 둘은 자율 10회 통계에 합산하지 않고, 특정 경로를 재현하는 별도 보충 실행으로 고정했다.

| 사례 | 경로 | 추가 진단 | 결과 |
|---|---|---:|---|
| 하위권 모호 근거 | ② → 근거 명료화 → 교정 → ⑤ | 1/2 | `DIAGNOSTIC_THEN_CORRECTION` |
| 최하위권 무근거 추측 | ④ → 근거 요청 → 발문·선택 진단 → ⑤ | 2/2 | `DIAGNOSTIC_THEN_CORRECTION` |

두 사례 모두 한 번에 질문 하나만 제시했고 코드가 관리하는 추가 진단 질문 예산을 넘지 않았다. 최하위권 사례에서는 학생이 ④의 내용은 맞다고 스스로 확인한 뒤 ‘적절하지 않은 것’을 찾아야 한다는 발문 극성을 다시 적용했다.

## 중대 발견

최종 정답 10/10은 진단 품질 10/10을 뜻하지 않는다. `M-CHARGE-HYDROPHOBIC` 사례는 ⑤를 선택하면서 다음 근거를 말했다.

> pH가 높아져 이온화 지질이 중성이 되면 소수성도 약해질 것 같으므로, 소수성 인력이 줄어 복합체 크기가 더 작아진다는 설명이 맞는 것 같습니다.

학생은 정답 번호를 골랐지만 ⑤의 주장 자체를 ‘맞는 설명’으로 승인했다. 발문은 ‘적절하지 않은 것’을 요구하므로 선택과 근거가 서로 충돌한다. 판정기는 이를 `SUPPORTED_RATIONALE_CORRECT`로 종료했다.

이는 정답 선택 후 근거 진단의 P0 의미 판정 결함이다. 정답 번호 일치가 발문 극성·선지 판정과 충돌하는 명백한 근거를 가려서는 안 된다. 실제 학생 파일럿을 확대하기 전에 다음 회귀를 추가해야 한다.

- 정답 번호 + 해당 선지를 참이라고 설명 → 근거 진단 진입
- 부정 발문에서 선택과 근거의 극성 불일치 → `SUPPORTED_RATIONALE_CORRECT` 금지
- 동일 의미의 다양한 표현에서도 선택·근거 일관성 검사

## 해석상 한계

- 학생 역할도 강한 언어 모델이므로 실제 하위권 학생보다 지문을 더 빨리 복원하고 코치 질문에 더 잘 순응할 수 있다.
- 동일 문항 반복 결과이며 문항 유형 일반화나 실제 학습 전이를 검증하지 않는다.
- 최종 정답률은 상태 엔진 완주 지표로만 사용하고, 진단 정확도와 별도로 평가해야 한다.
- 자율 10회에서 진단 질문이 0회였던 것은 선택 근거가 대부분 명시적이었기 때문이다. 모호성과 무근거 경로는 별도 보충 실행에서만 검증했다.

## 피드백 과정 진단

현재 피드백은 학생이 선택한 오답의 최초 오류를 국소적으로 수정하는 데에는 강했다. pH와 수소 이온 농도의 방향 역전, pH 7과 친수성의 속성 혼합, 전하 방향 역전과 Y자 관의 시각적 오독은 관련 관계만 다시 확인하게 했다. 약한 질문으로 수정되지 않은 경우에만 직접 설명으로 개입 수준을 높인 점도 설계와 일치했다.

반면 선택한 오답을 제외한 뒤 실제 정답 ⑤를 왜 부적절하다고 판단했는지는 거의 검증하지 않았다. 최초 오답 여섯 사례가 모두 ⑤로 재선택했지만, 대부분은 ⑤의 결정적 주장인 `pH 상승 → 소수성 약화`를 실제로 반박했는지 확인되지 않았다. 따라서 이 결과는 `선택 오답 수정`과 `정답 근거 확인`으로 나누어 기록해야 한다.

최하위권 보충 사례도 ④가 적절한 설명이라는 점과 부정 발문 적용은 확인했지만, 마지막의 “⑤ 같아요”는 근거가 없는 추측이었다. 이를 완전한 진단·교정 성공으로 해석하면 안 된다. 재선택이 정답이어도 근거를 확인하지 않았다면 `정답 재선택·근거 미검증` 상태를 보존해야 한다.

직접 코칭 뒤 학생 역할이 코치 문장을 거의 그대로 반복한 사례도 있었다. 이는 실제 표상 수정과 단순 복창을 구별하지 못한다. 장기적으로는 `복창`, `자기 언어 재구성`, `현재 문항 재적용`, `새 문항 전이`를 서로 다른 검증 강도로 기록할 필요가 있다.

②의 속도 조절과 ③의 혼합 용액 조건처럼 출제 근거가 약한 부분은 학생의 명백한 개념 오류가 아니라 문항 해석 경계일 수 있다. 이 경우 정답 키를 방어하는 교정으로 기록하지 않고 `ITEM_BOUNDARY_RESOLUTION`처럼 별도 처리해야 한다.

종합하면 현재 시스템은 `선택한 오답 제거`에는 성공했지만 `정답을 올바른 이유로 선택했는지 확인`하는 단계는 약하다. 다음 구현은 질문을 일률적으로 늘리는 대신 다음을 구분해야 한다.

- 정답 선택과 근거·발문 극성의 일관성
- 선택 오답만 수정된 상태와 정답 근거까지 확인된 상태
- 문항 경계 설명과 학생 오류 교정
- 코칭 문장 복창과 독립적인 재적용

## 판정

헤드리스 공개 API 경계, 다중 턴 상태 전이, 질문 예산과 재선택은 정상 작동했다. 그러나 정답 선택의 잘못된 근거를 타당한 근거로 승인한 사례가 있어, 현재 결과만으로 진단 품질 통과를 선언할 수 없다. 다음 우선순위는 선택·근거·발문 극성 일관성 판정과 회귀 테스트다.
