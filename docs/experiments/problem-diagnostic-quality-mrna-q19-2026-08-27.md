# mRNA 19번 진단 품질 검증 — 2026-08-27

## 결론

mRNA 19번의 실제 모델 블라인드 수직 슬라이스 4건은 진단 품질 기준을 모두 통과했다. 문항 단위 판정은 `GO`다. 다만 실제 학생 응답이 아닌 스크립트형 시뮬레이션이며 두 번째 문항 전이 검증 전이므로, 서비스 전체 MVP 판정은 아직 보류한다.

## 평가 계약

각 완료 세션을 다음 기준으로 평가한다.

- 학생의 선택 또는 놓친 정답 경로를 현재 관찰 수준에 맞게 설명했는가
- 승인된 기대 에피소드의 최초 분기층과 일치하는가
- 서로 다른 개입이 필요한 대안 가설의 통제 여부를 올바르게 판정했는가
- 필요한 수보다 많은 진단 질문을 하지 않았는가
- 질문에서 정답 번호나 선택 방향을 노출하지 않았는가
- 재선택과 최종 정오 상태 전이가 코드 계약에 맞는가
- 호출 횟수, 지연시간과 토큰 사용량은 어느 정도인가

실패는 `GOLD`, `PATH_RECONSTRUCTION`, `SUFFICIENCY`, `QUESTION_GENERATION`, `SESSION_TRANSITION`으로 분리한다.

## 정책 결정

진단 질문 기본 상한은 2회를 유지한다. 관찰된 최대 사용량은 1회였지만, 실제 학생의 짧거나 충돌하는 응답을 한 번 더 구별할 여유가 필요하다. 질문은 계속 한 번에 하나만 제시한다.

개입 순서는 다음과 같이 유지한다.

1. 서로 다른 처방을 요구하는 가설이 남을 때만 진단 질문
2. 특정된 최초 오류에 대한 간접 교정
3. 교정 실패 또는 질문 예산 소진 뒤 직접 코칭

문항 경계 설명은 학생 오류를 교정하는 직접 코칭과 별도 성과 유형으로 기록한다.
