- 고른 밑줄 구절: ㉠ '인터넷에 물품의 판매 정보를 올리고 온라인으로 구매 신청을 받는 거래' (지문 속 1회), ㉡ '판매원이 사업장 밖에서 소비자에게 물품 구매를 권유하고 그 자리에서 구매 신청을 받는 거래' (지문 속 1회)

- kind(맞는 선지: 다시 말하기·한 단계 적용 / 틀린 선지: 갈래 가~바): {1: '다(적용·맞대기)', 2: '나(적용·맞대기)', 3: '한 단계 적용', 4: '마(속 바꿔치기)', 5: '마(속 바꿔치기)'}

  - (②) twist: 지문은 내용 확인을 위해 포장만 훼손한 경우를 제한 사유에서 빼는데 선지는 물품 자체를 훼손한 경우까지 그 예외를 넓혔다.
  - (③) twist: 광고와 다른 물품을 이유로 철회하면 사업자가 반환 비용을 부담한다는 공통 기준을 ㉠에 적용했다.
  - (④) twist: 지문은 물품을 건넨 장소를 유형 구분 기준으로 삼지 않는데 선지는 ㉠과 같은 유형인지 판단하는 기준에 그 장소를 넣었다.
  - (⑤) twist: 지문은 계약서면을 먼저 받은 경우 두 유형 모두 물품을 받은 날부터 계산하는데 선지는 ㉡의 기준일을 서면을 받은 날로 바꾸었다.

### C-neg (정답 ①) — 바닥 통과
- ① 풀이 답 [1, 1] / ② 근거 누락 없음 / ③ 맞는 선지를 한 번이라도 '틀림'으로 본 경우 없음
- 고른 밑줄 구절: ㉠ '인터넷에 물품의 판매 정보를 올리고 온라인으로 구매 신청을 받는 거래' (지문 속 1회), ㉡ '판매원이 사업장 밖에서 소비자에게 물품 구매를 권유하고 그 자리에서 구매 신청을 받는 거래' (지문 속 1회)
- 오답 자리 표시(생성기 자기 표시): 끝 반전 0 / 속 바꿔치기 0 / 적용·맞대기 1 / 표시없음 0
- 선지 길이 {1: 66, 2: 72, 3: 72, 4: 60, 5: 68}, 극단어 있는 선지 [4, 5]
- kind(맞는 선지: 다시 말하기·한 단계 적용 / 틀린 선지: 갈래 가~바): {1: '나(적용·맞대기)', 2: '다시 말하기', 3: '다시 말하기', 4: '한 단계 적용', 5: '한 단계 적용'}

  - (①) twist: 지문은 두 유형 모두 물품을 공급받은 날부터 3개월 이내에 철회해야 한다고 했는데, 선지는 ㉡에는 이 요건이 적용되지 않는다고 했다.

  - (⑤) twist: 계약과 다르게 공급된 물품에는 소비자 책임에 따른 일반 철회의 제한 사유가 적용되지 않는다는 원리를 ㉠과 ㉡에서 해당 물품이 소비자의 책임으로 없어진 경우에 적용했다.
