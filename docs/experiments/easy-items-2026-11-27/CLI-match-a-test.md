## 쉬운 설명

- **목적:** 규칙 초안대로 만든 내용 일치 문항이 같은 지문의 진짜 기출 문항만큼 수능다운지 처음 재 본다.
- **방법:** 기출 지문 2편에 발문 두 종류("일치하지 않는 것"·"적절한 것")로 문항 4개를 만든다. 먼저 바닥 검사(정답이 하나인지, 근거 문장이 진짜 지문에 있는지, 겉모양 단서가 없는지)를 하고, 그다음 기출 4문항과 섞어 출처를 가린 채 평가자에게 하나씩 매기게 한다.
- **다음:** 통과면 우리가 만든 지문(혈액 응고, 청약 철회 등)에 같은 시험을 한다. 거의·미달이면 보고서를 보고 규칙을 손본다(웹에서 논의).
