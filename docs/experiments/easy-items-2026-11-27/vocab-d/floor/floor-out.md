### T-B (정답 ③, 꼴 B) — 바닥 통과
- 풀이 답 [3, 3] / 선지 길이 {1: 5, 2: 6, 3: 6, 4: 7, 5: 8} / 꼴 B 다섯 낱말이 걸친 문단 수 5
- 고른 낱말 ⓐ '존재한다' (구절 '액체 성분인 혈장에 존재한다'): 어떤 것이 실제로 어느 곳에 있다.
- 고른 낱말 ⓑ '변화시키는' (구절 '작용하여 변화시키는 대상'): 사물의 성질이나 상태를 달라지게 하는.
- 고른 낱말 ⓒ '출발하는' (구절 '혈관 손상에서 출발하는 이 경로'): 어떤 일이나 과정이 일정한 계기에서 시작되는.
- 고른 낱말 ⓓ '제공한다' (구절 '반응할 자리를 제공한다'): 무엇을 쓸 수 있도록 내어 준다.
- 고른 낱말 ⓔ '형성된다' (구절 '긴 피브린 섬유가 형성된다'): 일정한 형태를 갖춘 것이 이루어진다.
  - ① [맞음] ⓐ: 있다 — sense: 사람이나 사물이 어느 곳에 자리하거나 머무르다. / why: 단백질이 혈장에 자리하고 있다는 뜻이 유지된다.
  - ② [맞음] ⓑ: 바꾸는 — sense: 사물의 성질이나 상태를 이전과 다르게 하는. / why: 효소가 작용하여 기질의 상태를 달라지게 한다는 뜻이 유지된다.
  - ③ [틀림] ⓒ: 떠나는 — sense: 있던 곳에서 다른 곳으로 옮아가는. / why: 장소를 벗어난다는 뜻의 ‘출발하다’는 대신할 수 있지만, 여기서는 혈관 손상이 응고 경로의 시작 계기라는 뜻이다.
  - ④ [맞음] ⓓ: 마련한다 — sense: 필요한 것을 쓸 수 있게 갖추어 놓다. / why: 막 표면이 두 물질이 모여 반응할 수 있는 자리를 갖추어 준다는 뜻이 유지된다.
  - ⑤ [맞음] ⓔ: 만들어진다 — sense: 재료가 결합하거나 가공되어 새로운 것이 생겨난다. / why: 피브린 분자들이 이어져 긴 섬유가 이루어진다는 뜻이 유지된다.

### C-B (정답 ④, 꼴 B) — 바닥 통과
- 풀이 답 [4, 4] / 선지 길이 {1: 10, 2: 11, 3: 11, 4: 11, 5: 11} / 꼴 B 다섯 낱말이 걸친 문단 수 5
- 고른 낱말 ⓐ '본' (구절 '앞서 본 소비자 책임에 따른 제한 사유'): 어떤 내용이나 대상을 살피거나 검토하다.
- 고른 낱말 ⓑ '올리고' (구절 '판매 정보를 올리고'): 글이나 자료를 인터넷에 게시하다.
- 고른 낱말 ⓒ '바뀌어' (구절 '사흘 뒤 마음이 바뀌어'): 생각이나 태도가 이전과 달라지다.
- 고른 낱말 ⓓ '받았다' (구절 '계약서면과 가방을 받았다'): 다른 사람이 주는 물건을 받아 가지다.
- 고른 낱말 ⓔ '이끄는' (구절 '그를 사업장 안으로 이끄는'): 사람을 데리고 어떤 곳으로 가다.
  - ① [틀림] ⓐ: 관람(觀覽)한 — sense: 공연, 경기, 전시 따위를 구경하다. / why: ‘보다’가 공연 등을 구경한다는 뜻일 때는 바꿔 쓸 수 있지만, 여기서는 앞서 제시된 제한 사유를 살폈다는 뜻이다.
  - ② [틀림] ⓑ: 인상(引上)하고 — sense: 가격이나 임금 따위의 수준을 높이다. / why: ‘올리다’가 가격이나 임금의 수준을 높인다는 뜻일 때는 바꿔 쓸 수 있지만, 여기서는 판매 정보를 인터넷에 게시한다는 뜻이다.
  - ③ [틀림] ⓒ: 교체(交替)되어 — sense: 기존의 사람이나 물건이 다른 사람이나 물건으로 대체되다. / why: ‘바뀌다’가 사람이나 물건이 다른 것으로 대체된다는 뜻일 때는 바꿔 쓸 수 있지만, 여기서는 소비자의 생각이 달라졌다는 뜻이다.
  - ④ [맞음] ⓓ: 수령(受領)했다 — sense: 돈이나 물품 등을 받아 가지다. / why: 계약서면과 가방을 판매업자에게서 받아 가졌다는 뜻이 그대로 유지된다.
  - ⑤ [틀림] ⓔ: 주도(主導)하는 — sense: 어떤 일에서 중심이 되어 그 일을 이끌다. / why: ‘이끌다’가 어떤 일을 중심이 되어 진행한다는 뜻일 때는 바꿔 쓸 수 있지만, 여기서는 소비자를 사업장 안으로 데리고 간다는 뜻이다.
