# 어휘 규칙 v3, 바꿔 쓰기 2문제 다시 시험 — 쉬운 말 보고 (2026-11-28)

**판정: 미달(규칙 효과 없음)**

## 1. 개요

### 1) 작업의 목적
우리 지문 어휘 시험에서 "바꿔 쓰기" 문제만 약했다(기출 1.84, 우리 1.00). 원인을 "틀린 낱말이 지문 낱말과 뜻부터 멀어서 낱말만 보고 지워진다"로 보고, 규칙에 "틀린 낱말은 지문 낱말의 다른 뜻과 짝이어야 한다(다른 문장에서는 바꿔 쓸 수 있어야 함)"를 더해(v3) 두 문제를 다시 만들었다.

### 2) 작업의 결과
- 규칙대로 만들어졌다. 생성기가 적은 다른 문장 5개를 모델이 확인했고 모두 "뜻이 같다"였다(예: "주말에 연극을 보았다 = 주말에 연극을 관람했다").
- **그런데 점수는 오르지 않았다.** 새 문제 0.750, 1.000(평균 0.875). 옛 문제를 같은 블라인드에서 다시 채점하니 1.000, 0.875(평균 0.938). 기출 바꿔 쓰기 4개는 평균 1.844.
- "너무 쉬움" 표시가 새 15/16, 옛 14/16으로 그대로다. 평가자 말: "오답의 의미 부적합이 뚜렷해 낱말 대조만으로 쉽게 풀린다."
- 어휘 4문제 합친 G = 1.406은 기준 1.381을 넘었지만, 바꿔 쓰기 조건(B3 ≥ 기출 − 0.4 = 1.444)을 못 채워 판정은 **미달(규칙 효과 없음)**.
- 즉 vocab-c에서 세운 원인 가설("오답이 뜻부터 멀다")은 이번 결과로 확인되지 않았다.
- 작업 중 실수: 표시판 파일을 잘못 덮어써서 일부 풀이지 지문이 옛 낱말이었는데, 평가 전에 잡아 고치고 다시 만들었다(보고서 1절).
- 비용: 실제 **$0.0380**(추정 $0.04, 상한 $0.2).

### 3) 다음 스텝
바꿔 쓰기 오답이 왜 쉬워 보이는지 기출 바꿔 쓰기 4문제의 오답 모양을 낱말 쌍으로 분석한다(0원). 그동안 세트에는 문맥적 의미(꼴 A, 1.94)를 쓴다.

## 2. 본문

### 2.1 (미해결) 오답이 낱말 대조로 풀림
어떤 문제가: 바꿔 쓰기 문제의 틀린 낱말이 평가자에게 "낱말만 봐도 안 맞는다"로 읽힌다.
과정: 규칙을 고쳐 틀린 낱말을 "다른 문장에서는 바꿔 쓸 수 있는 낱말"로 만들었고 그 문장이 맞음을 확인했다. 예: 지문 "혈관 손상에서 **출발하는** 이 경로" 자리에 오답 "떠나는". 다른 문장 "버스가 차고지에서 출발하는 시각 = 버스가 차고지에서 떠나는 시각"은 성립.
결과(미해결): 점수 0.750. 평가자: "'출발하는'은 '시작되는'의 뜻이므로 '떠나는'은 부적절하나, 모든 선지가 단순한 낱말 대조로 풀려 어휘 변별력이 낮다."
해석: 오답이 사전 뜻으로 구별되는 한 평가자는 "쉽다"고 본다. 규칙 조항으로는 안 풀릴 수 있다(가설).

### 2.2 (해결) 규칙 형식·바닥 검사
결과(해결): 두 문제 모두 바닥 검사 통과, other_sentence '아니오' 0개, 정답 일치 8/8.

### 2.3 (판단 필요) 바꿔 쓰기 문제를 계속 다듬을지
기출 바꿔 쓰기도 "너무 쉬움"이 1~2회 붙는다. 우리 문제는 7~8회다. 차이의 원인을 모른다.
