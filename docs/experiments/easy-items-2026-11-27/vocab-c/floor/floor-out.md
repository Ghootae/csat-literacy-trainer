# 바닥 검사 결과 (자동 생성)

### T-B (정답 ③, 꼴 B) — 바닥 통과
- 풀이 답 [3, 3] / 선지 길이 {1: 5, 2: 6, 3: 6, 4: 8, 5: 6} / 꼴 B 다섯 낱말이 걸친 문단 수 5
- 고른 낱말 ⓐ '존재한다' (구절 '혈장에 존재한다'): 어떤 곳에 실제로 있다.
- 고른 낱말 ⓑ '변화시키는' (구절 '작용하여 변화시키는 대상이다'): 대상의 성질이나 상태를 달라지게 하는.
- 고른 낱말 ⓒ '접촉하지' (구절 '혈액과 접촉하지 않던'): 서로 맞닿지.
- 고른 낱말 ⓓ '포함된' (구절 '활성형 X 인자가 포함된 복합체'): 어떤 전체의 일부로 들어 있는.
- 고른 낱말 ⓔ '연결한다' (구절 '분자들을 서로 연결한다'): 떨어져 있는 것들을 서로 이어 붙인다.
  - ① [맞음] ⓐ: 있다 — sense: 사람이나 사물이 어떤 곳에 자리하거나 머무르다. / why: 단백질이 혈장에 존재한다는 것은 그 단백질이 혈장에 있다는 뜻이다.
  - ② [맞음] ⓑ: 바꾸는 — sense: 어떤 것을 이전과 다르게 만드는. / why: 효소가 기질을 변화시킨다는 것은 기질을 이전과 다른 상태로 바꾼다는 뜻이다.
  - ③ [틀림] ⓒ: 스치지 — sense: 가볍게 닿으면서 지나가지. / why: ‘스치다’는 닿으면서 지나가는 것을 뜻하지만, 여기서는 조직 인자와 혈액이 평소에 맞닿지 않았다는 뜻이다.
  - ④ [맞음] ⓓ: 들어 있는 — sense: 어떤 것의 안에 자리하고 있는. / why: 활성형 X 인자가 복합체에 포함되어 있다는 것은 그것이 복합체의 일부로 들어 있다는 뜻이다.
  - ⑤ [맞음] ⓔ: 잇는다 — sense: 따로 있는 것들을 서로 이어 붙인다. / why: 피브린 분자들을 연결한다는 것은 공유 결합을 통해 분자들을 서로 잇는다는 뜻이다.

### T-A (정답 ⑤, 꼴 A) — 바닥 통과
- 풀이 답 [5, 5] / 선지 길이 {1: 25, 2: 21, 3: 24, 4: 20, 5: 22}
- 고른 낱말 ⓐ '맺는' (구절 '효소와 기질이 맺는 관계'): 관계를 이루다.

  - ② [틀림] 토마토가 열매를 맺는 모습이 신기했다. — sense: 식물이 열매를 이루다. / why: 관계를 이루는 것이 아니라 식물에 열매가 생기는 것을 뜻한다.
  - ③ [틀림] 그는 연설을 맺는 말로 감사 인사를 건넸다. — sense: 어떤 일에 끝을 짓다. / why: 관계를 이루는 것이 아니라 연설을 마무리하는 것을 뜻한다.
  - ④ [틀림] 오랜 노력이 결실을 맺는 순간이었다. — sense: 노력한 일이 성과를 내다. / why: 관계를 이루는 것이 아니라 노력 끝에 성과를 거두는 것을 뜻한다.
  - ⑤ [맞음] 여행지에서 새 인연을 맺는 일이 즐겁다. — sense: 관계를 이루다. / why: 새로운 사람과 관계를 이룬다는 뜻으로, 지문의 ‘맺는’과 같은 의미이다.

### C-B (정답 ④, 꼴 B) — 바닥 통과
- 풀이 답 [4, 4] / 선지 길이 {1: 10, 2: 11, 3: 11, 4: 11, 5: 11} / 꼴 B 다섯 낱말이 걸친 문단 수 5
- 고른 낱말 ⓐ '적은' (구절 '계약 내용을 적은 서면'): 말이나 내용을 글자로 써서 나타낸.
- 고른 낱말 ⓑ '가르는' (구절 '거래 유형을 가르는 기준'): 어떤 기준에 따라 서로 다른 종류로 나누는.
- 고른 낱말 ⓒ '돌려보내는' (구절 '물품을 돌려보내는 데 드는 비용'): 받은 물건을 보낸 쪽으로 다시 보내는.
- 고른 낱말 ⓓ '받았다' (구절 '계약서면과 가방을 받았다'): 다른 사람이 주는 물건을 넘겨받았다.
- 고른 낱말 ⓔ '이끄는' (구절 '사업장 안으로 이끄는 것은'): 사람을 데리고 어떤 곳으로 가는.
  - ① [틀림] ⓐ: 전사(轉寫)한 — sense: 이미 쓰인 글을 옮겨 베낀. / why: 글로 쓴다는 점은 같지만, 지문은 계약 내용을 서면에 써 놓았다는 뜻이지 기존 문서를 베꼈다는 뜻은 아니다.
  - ② [틀림] ⓑ: 절단(切斷)하는 — sense: 물체를 잘라 끊는. / why: 나눈다는 점은 같지만, 여기서는 물체를 자르는 것이 아니라 거래의 유형을 구별한다.
  - ③ [틀림] ⓒ: 송환(送還)하는 — sense: 포로나 외국인 등을 본국으로 돌려보내는. / why: 원래 있던 곳으로 보낸다는 점은 같지만, 송환의 대상은 사람이고 여기서 돌려보내는 대상은 물품이다.
  - ④ [맞음] ⓓ: 수령(受領)했다 — sense: 돈이나 물품 등을 받아 거두었다. / why: 소비자가 판매업자로부터 계약서면과 가방을 넘겨받았다는 뜻을 그대로 나타낸다.
  - ⑤ [틀림] ⓔ: 호송(護送)하는 — sense: 보호하거나 감시하면서 데리고 가는. / why: 사람을 데리고 간다는 점은 같지만, 여기서 판매원은 소비자를 보호하거나 감시하는 것이 아니라 사업장 안으로 데려간다.
