## 7. 생성 문항 전문
### T-B — 문맥상 ⓐ～ⓔ와 바꿔 쓰기에 적절하지 않은 것은? (정답 ③, 꼴 B) 표시: ⓐ 존재한다 / ⓑ 변화시키는 / ⓒ 접촉하지 / ⓓ 포함된 / ⓔ 연결한다
- ⓐ '존재한다' 구절 '혈장에 존재한다' — sense: 어떤 곳에 실제로 있다.
- ⓑ '변화시키는' 구절 '작용하여 변화시키는 대상이다' — sense: 대상의 성질이나 상태를 달라지게 하는.
- ⓒ '접촉하지' 구절 '혈액과 접촉하지 않던' — sense: 서로 맞닿지.
- ⓓ '포함된' 구절 '활성형 X 인자가 포함된 복합체' — sense: 어떤 전체의 일부로 들어 있는.
- ⓔ '연결한다' 구절 '분자들을 서로 연결한다' — sense: 떨어져 있는 것들을 서로 이어 붙인다.
- ① ⓐ: 있다 — 맞음 / sense: 사람이나 사물이 어떤 곳에 자리하거나 머무르다. / why: 단백질이 혈장에 존재한다는 것은 그 단백질이 혈장에 있다는 뜻이다.
- ② ⓑ: 바꾸는 — 맞음 / sense: 어떤 것을 이전과 다르게 만드는. / why: 효소가 기질을 변화시킨다는 것은 기질을 이전과 다른 상태로 바꾼다는 뜻이다.
- ③ ⓒ: 스치지 — 틀림 / sense: 가볍게 닿으면서 지나가지. / why: ‘스치다’는 닿으면서 지나가는 것을 뜻하지만, 여기서는 조직 인자와 혈액이 평소에 맞닿지 않았다는 뜻이다.
- ④ ⓓ: 들어 있는 — 맞음 / sense: 어떤 것의 안에 자리하고 있는. / why: 활성형 X 인자가 복합체에 포함되어 있다는 것은 그것이 복합체의 일부로 들어 있다는 뜻이다.
- ⑤ ⓔ: 잇는다 — 맞음 / sense: 따로 있는 것들을 서로 이어 붙인다. / why: 피브린 분자들을 연결한다는 것은 공유 결합을 통해 분자들을 서로 잇는다는 뜻이다.

### T-A — ⓐ와 문맥상 의미가 가장 가까운 것은? (정답 ⑤, 꼴 A) 표시: ⓐ 맺는
