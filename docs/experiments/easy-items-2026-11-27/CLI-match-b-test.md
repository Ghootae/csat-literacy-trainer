## 쉬운 설명

- **목적:** 1차에서 "너무 쉽다"는 평을 받은 원인(맞는 선지가 지문 문장을 거의 그대로 옮김)을 규칙에서 고쳤습니다. 고친 규칙으로 만든 문제가 기출 수준에 가까워졌는지 봅니다.
- **방법:** 같은 지문 2편에 문제 4개를 다시 만듭니다. 1차 문제 4개, 기출 8개와 섞어 출처를 가린 채 채점하므로 1차보다 나아졌는지 한자리에서 보입니다. 이번에는 "적절한 것" 발문 기출도 넣었습니다(1차 기출 4개는 모두 "일치하지 않는 것" 발문이었음). 따로 "이 문제가 실제 기출 같나?"를 물어서, 평가자가 기출을 알아보고 점수를 후하게 주는지도 확인합니다.
- **다음:** 통과면 우리가 만든 지문에서 시험합니다. 거의·미달이면 보고서를 보고 다시 논의합니다. 평가자가 기출을 알아본다고 나오면, 앞으로는 기출 문항 대조 대신 다른 기준을 생각해야 합니다.
