## 3. 해석(가설, 측정과 구별)
1. **v2가 v1보다 나아졌다는 증거는 없다.** G2 = G1 = 1.594, 문항별 점수도 neg 2.000/2.000, pos 1.188/1.188로 같고 ㉳ 표시도 13 대 13이다. 통과 판정(G2 ≥ M−0.4)은 평가자가 v1도 똑같이 높게 줬기 때문이며 규칙 v2의 효과로 읽을 수 없다.
2. **채점이 1차와 크게 달라졌다.** 같은 v1 문항(같은 선지, 같은 머리말·프롬프트)이 1차 블라인드에서 G1 = 0.406(D-neg 0.750, D-pos 0.000, H-neg 0.875, H-pos 0.000), 이번에는 1.594(2.000, 1.250, 2.000, 1.125)다. 달라진 것은 섞인 문항 구성(16개)과 폴더 번호뿐이다. 단독 세션이라 다른 문항의 영향은 구조상 없어야 한다. 원인은 이 시험으로 가려지지 않는다(미확인). 1차의 "생성 4개 모두 ㉳ 8/8"은 이번에 재현되지 않았다(v1 ㉳ 13/32).
3. **기출도 낮게 나올 수 있다.** PD(인격 동일성 14번, 발문 "일치하는 것")는 0.625(수능 아님 3, ㉳ 6/8)다. 기출이 모두 만점이던 1차의 문제는 줄었으나, 기출 평균 M = 1.812는 PD 하나가 끌어내린 값이다.
4. **발문 차이가 크다.** 부정 발문 문항은 생성·기출 모두 2.000, 긍정 발문("적절한/일치하는") 문항은 생성 1.188·기출 M_pos 1.625다.
5. **출처 추정 참고 판정 "평가자가 기출을 알아봄"은 문구대로 나왔으나 해석에 주의가 필요하다.** `remembered=true`의 이유 문장은 "지문은 실제 기출에서 본 기억이 있다"로, **지문**을 기억한다는 뜻이다. 생성 문항도 기출 지문을 쓰므로 생성 v2·v1에서도 remembered가 각각 6/8이다(기출 12/16). 지시문 기준(기출 중 한 번이라도 remembered인 문항 ≥ 4개)은 지문 기억도 센다. 문항 수준에서는 '실제'로 답한 비율이 기출 0.812, 생성 0.000(차 +0.812)이다. 즉 **지문은 알아보고, 문항은 만든 것임을 가려냈다**(이유: "선지를 단순히 뒤집은 구성", "선지 표현·구성이 새로 만든 것으로 보임" 등). 점수를 후하게 준 정황은 보이지 않는다(생성도 높음).

- 같은 문항 묶음을 같은 조건으로 한 번 더 채점해 평가자 재현성을 먼저 잰다(codex 무료). 1차와 이번의 격차가 잡음인지 구성 효과인지 가린다.
- 평가자 점수 외에 사람 판정 표본(긍정 발문 문항 몇 개)을 받는다.
- 출처 추정 질문을 "지문 기억"과 "문항 기억"으로 나눠 다시 묻는다.

## 6. 열린 질문
- 평가자 점수가 실행 사이에 이렇게 움직일 때 "기출 대비 G ≥ M−0.4" 기준을 계속 쓸 수 있는가.
- 긍정 발문에서만 ㉳가 많은 이유(선지 구조인지, 평가자 기준인지).
