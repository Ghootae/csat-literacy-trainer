# 어휘 규칙 v2, 조선 노비제 꼴 A 다시 시험 — 쉬운 말 보고 (2026-11-28)

**판정: 통과(기출 지문에서 기출 수준)**

## 1. 개요

### 1) 작업의 목적
어휘 첫 시험에서 유일하게 크게 떨어진 문제(조선 노비제 꼴 A)는 정답 예문이 지문의 "관심을 두다"를 그대로 써서 낱말 뜻을 구별하지 않아도 풀렸다. 규칙에 "예문은 지문과 같은 말 묶음을 쓰지 않는다"를 더해(v2) 이 문제만 다시 만들었다.

### 2) 작업의 결과
- 새 문제는 낱말 "잃었다"(지문 "운동 본래의 성격을 **잃었다**")로 만들어졌고 정답 예문은 "오래 쓴 수건은 부드러움을 **잃었다**"이다. 지문과 같은 말 묶음("성격을 잃다")이 아니다. 바닥 검사 통과.
- 점수(0~2): **새 문제 1.750**(수능 아님 0/8), 같은 블라인드에 넣은 옛 문제 0.375(수능 아님 5/8), 같은 지문 기출 꼴 A 2.000.
- 어휘 4문제 합친 G = 1.812, 기출 8개 평균 M = 1.812. 차이 0.000, 기준(M − 0.4 = 1.413) 넘음 → 통과.
- 남은 점: 새 문제도 "성격 ↔ 부드러움"의 대응만으로 풀린다는 지적("너무 쉬움")이 2/8 있다.
- 새 문제의 낱말 "잃었다"는 지난 시험의 조선 노비제 꼴 B가 이미 쓴 낱말이다(이번 지시에 "이미 고른 낱말"을 붙이지 않는 조건이었다). 한 세트에 같이 넣으려면 겹침을 막아야 한다.
- 비용: 실제 **$0.0230**(추정 $0.015, 상한 $0.1).

### 3) 다음 스텝
어휘 규칙 v2를 확정하고 우리가 만든 지문에서 시험한다(4절).

## 2. 본문

### 2.1 (해결) 같은 말 묶음 반복
어떤 문제가: 옛 문제의 정답이 지문 구절을 그대로 반복.
과정: 규칙에 금지 조항을 더하고 같은 의뢰로 다시 생성. 생성 직후 코드로 확인(지문 구절 앞 어절 "성격을"이 정답 예문에 없음).
결과(해결): 평가자 이유 — 옛 문제: "'관심을 두다'가 정답 선지에 그대로 반복되어 문맥상 의미를 판단할 필요가 거의 없다." 새 문제: "'본래 지니던 성질이 없어지다'라는 의미가 ②와 일치하며, 다른 선지와의 의미 구별도 명확하다."

### 2.2 (판단 필요) 판정의 근거 범위
옛 문제가 같은 블라인드에서 0.375(지난번 0.125)로 움직였다. 같은 문항의 채점이 실행마다 달라지므로 점수 차이를 규칙 효과의 크기로 읽으면 안 된다. 다만 옛 문제는 8회 모두 "너무 쉬움"이었고 새 문제는 2회였다.
