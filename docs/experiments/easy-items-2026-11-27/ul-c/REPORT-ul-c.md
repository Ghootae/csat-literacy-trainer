## 3. 해석(가설, 측정과 구별)
1. **기계 판정은 "미달(바닥 실패 2개 이상)"이다.** 실패 이유는 두 문항 모두 이번 시험에 추가된 조건 하나(밑줄 구절이 지문에 정확히 한 번 나와야 함)이고, 정답 일치·근거 문장·맞는 선지 판정·겉모양 검사는 모두 통과했다. 그래서 G(바닥 실패 0점) = 1.000이다.
2. **평가자 점수만 보면 기출 수준이다.** 바닥 실패를 0점 처리하지 않은 생성 4개 평균 1.906은 기출 8개 평균 1.875보다 +0.031이다(참고 값이며 판정 문구에 쓰지 않았다). T 두 문항 2.000/2.000, C 두 문항 1.750/1.875. "적절한 것"(pos) 두 문항 평균 1.938은 Mp 1.833 이상이다. 참고 판정 문구는 pos 점수를 바닥 실패 0점 처리로 계산해 "'적절한 것'은 아직 낮음"이 나오지만, 그대로 보면 기준(Mp − 0.4 = 1.433)을 넘는다.
3. **원인은 문항 품질이 아니라 밑줄 위치 지정 방식으로 보인다.** 규칙 v2 원칙 1은 "지문 그대로의 구절"을 target에 적으라고만 하고, 그 구절이 지문에서 한 번만 나와야 한다는 조건이 없다. 생성기는 지문 전체에 반복되는 핵심어 "통신판매", "방문판매"를 target으로 골랐다. T-pos는 "이렇게 생성된 활성형 X 인자"처럼 구절 단위로 골라 한 번만 나왔다. 이번 시험에서 생성기가 위치를 고르게 하자 처음으로 드러난 문제다(기출 지문 시험에서는 위치를 줬다).
4. 첫 등장에 표시한 판에서도 C 문항 평가자는 큰 문제를 지적하지 않았다(㉰·㉲ 없음, ㉳ 1회). 다만 평가자가 본 ㉠·㉡은 첫 문장의 낱말이었고, 문항은 지문 중반(기간·반환 비용·훼손)의 내용을 묻는다. 기출 밑줄은 보통 그 내용이 서술된 구절을 가리키므로 이번 표시 위치가 기출 모양과 다르다. 이것이 점수에 미친 영향은 이 시험으로 가려지지 않는다(미확인).
5. 생성 오답 10개의 자리 표시(생성기 자기 표시)는 적용·맞대기 6, 속 바꿔치기 4, 끝 반전 0으로 규칙을 지켰다. 이 표시는 별도 검증을 하지 않았다.
6. 기출 HY(수소 11번)가 1.000으로 낮은 점은 1·2차와 같다("네 오답이 모두 지문의 명시적 진술을 단순히 뒤집어…").

## 4. 정정·한계
- 위 가정(첫 등장 표시)이 C 문항 평가에 영향을 줬을 수 있다. 바닥 실패는 표시 위치와 무관하다(구절이 4·7회 나오는 사실만으로 실패).
- 지문 2편·문항 4개로 표본이 작다. 평가자는 같은 모델이며 8회가 독립이 아니다.
- 판정 문구와 실제 평가자 점수가 다른 방향이므로 둘을 함께 읽어야 한다(해석 2).

## 5. 제안(웹 논의용)
- 규칙 원칙 1에 "target은 지문에서 정확히 한 번 나오는 구절(핵심어 한 낱말이 아니라 그 개념이 서술된 구절)로 한다"를 더한 `rules-underline-v3`(또는 출력에 문장 번호·시작 위치 필드 추가)를 만들고, C 지문만 다시 시험(유료 약 $0.04, 블라인드는 기존 T 문항·기출과 같이).
- 밑줄 위치 선택을 규칙에서 빼고 코드(서버)가 후보 구절을 지정하는 방안도 비교.
- 이 두 방안 중 어느 쪽이든 "구절이 한 번만 나옴"을 생성 직후 코드로 검사해 재생성 조건으로 쓰는지 결정.

## 6. 열린 질문
- 쌍 문항(㉠·㉡)에서 구절 하나가 아니라 개념을 가리키는 낱말을 밑줄로 쓰는 것을 허용할지(기출은 구절 단위인지, 기출 쌍 밑줄의 길이 분포는 이 시험에서 세지 않았다, 미확인).
- 표시 위치가 점수에 미치는 영향을 어떻게 잴지.

## 7. 생성 문항 전문과 고른 밑줄의 앞뒤 문장
## 고른 밑줄 구절과 앞뒤 문장

T(혈액 응고)
- ㉠ '이렇게 생성된 활성형 X 인자' (지문 속 1회, 첫 등장 앞뒤 문장): …이렇게 생성된 활성형 X 인자가 참여하는 후속 반응은 손상 부위의 활성화된 혈소판 막 표면에서 일어난다.

C(청약 철회)
- ㉠ '통신판매' (지문 속 4회, 첫 등장 앞뒤 문장): …통신판매와 방문판매의 물품 거래 중에서 소비자가 계약 내용을 적은 서면을 정상적으로 받았고, 일반 철회 기간을 더 길게 정한 약정이 없는 경우를 살펴보자.
- ㉡ '방문판매' (지문 속 7회, 첫 등장 앞뒤 문장): …통신판매와 방문판매의 물품 거래 중에서 소비자가 계약 내용을 적은 서면을 정상적으로 받았고, 일반 철회 기간을 더 길게 정한 약정이 없는 경우를 살펴보자.

### T-pos — ㉠에 대해 이해한 내용으로 가장 적절한 것은? (정답 ②) 밑줄: ㉠ = 이렇게 생성된 활성형 X 인자

- ① ㉠은 조직 인자와 응고 효소가 이룬 복합체가 조직 인자의 일부를 절단할 때 생성된다. — 틀림 / 라(속 바꿔치기) / twist: 지문은 복합체가 X 인자를 절단하는데 선지는 조직 인자를 절단한다고 했다.
- ② ㉠은 프로트롬빈 한 분자를 절단한 뒤에도 다른 프로트롬빈 분자에 다시 작용할 수 있다. — 맞음 / 한 단계 적용 / twist: 지문의 효소가 반응에서 소모되지 않는다는 원리를 ㉠이 프로트롬빈을 절단하는 반응에 적용했다.
- ③ ㉠은 XIII 인자의 일부를 절단하여 피브린 그물을 안정화하는 과정에 관여한다. — 틀림 / 다(적용·맞대기) / twist: 지문은 ㉠이 만들어 낸 트롬빈이 XIII 인자를 절단하는데 선지는 ㉠이 XIII 인자를 절단한다고 했다.
- ④ ㉠은 자신이 포함된 복합체와 조직 인자가 혈소판 막 표면에 모일 때 효율적으로 작용한다. — 틀림 / 라(속 바꿔치기) / twist: 지문은 복합체와 프로트롬빈이 혈소판 막 표면에 모이는데 선지는 복합체와 조직 인자가 모인다고 했다.
- ⑤ ㉠은 조직 인자와 마찬가지로 기질을 직접 절단하지 않고 복합체의 작용을 돕는다. — 틀림 / 다(적용·맞대기) / twist: 지문은 조직 인자와 달리 ㉠이 기질을 직접 절단하는데 선지는 ㉠도 조직 인자처럼 기질을 직접 절단하지 않는다고 했다.

### T-neg — ㉠에 대한 이해로 적절하지 않은 것은? (정답 ⑤) 밑줄: ㉠ = 이렇게 생성된 활성형 X 인자

- ① ㉠은 혈장에 있는 X 인자의 일부가 절단되어 생성된다. — 맞음 / 다시 말하기
- ② ㉠은 칼슘 이온과 보조 인자의 도움으로 형성되는 복합체의 구성 성분이다. — 맞음 / 다시 말하기
- ③ ㉠은 절단되기 전의 X 인자와 달리 다른 단백질을 기질로 삼는 효소로 작용한다. — 맞음 / 한 단계 적용 / twist: 지문의 비활성형 단백질이 절단되면 효소로 작용한다는 원리를 ㉠의 활성화에 적용했다.
- ④ ㉠은 손상 부위에서 활성화된 혈소판의 막 표면을 후속 반응의 자리로 이용한다. — 맞음 / 다시 말하기
- ⑤ ㉠은 프로트롬빈의 일부를 절단하여 피브린 섬유의 재료가 되는 단백질을 만든다. — 틀림 / 다(적용·맞대기) / twist: 지문은 ㉠이 프로트롬빈을 절단하여 트롬빈을 만든다고 했는데, 선지는 이 절단으로 피브린 섬유의 재료인 피브린이 만들어진다고 했다.

### C-pos — ㉠, ㉡에 대한 이해로 가장 적절한 것은? (정답 ③) 밑줄: ㉠ = 통신판매 / ㉡ = 방문판매

- ① ㉠은 인터넷에 판매 정보를 올려 온라인으로 구매 신청을 받은 거래라도, 물품을 사업장 밖에서 건네면 ㉡으로 분류된다. — 틀림 / 다(적용·맞대기) / twist: 지문은 물품을 건넨 장소와 무관하게 이런 온라인 거래를 통신판매로 분류하는데 선지는 물품을 사업장 밖에서 건네면 방문판매로 분류한다고 했다.
- ② ㉠은 계약서면을 물품보다 먼저 받으면 물품을 받은 날부터, ㉡은 물품을 계약서면보다 먼저 받으면 물품을 받은 날부터 일반 철회 기간을 센다. — 틀림 / 마(속 바꿔치기) / twist: 지문은 방문판매에서도 계약서면을 먼저 받아야 물품을 받은 날부터 기간을 세는데 선지는 물품을 먼저 받았을 때 그렇게 센다고 했다.
- ③ ㉠은 일반 철회 기간을 계산하기 시작한 날부터 열흘이 지나면 그 기간이 끝나 있지만, ㉡은 열흘이 지나도 그 기간이 남아 있다. — 맞음 / 한 단계 적용 / twist: 지문의 7일과 14일 기준을 ㉠과 ㉡에서 각각 일반 철회 기간의 기산일로부터 열흘이 지난 상황에 적용했다.
- ④ ㉠과 ㉡은 모두 광고 내용과 다른 물품을 공급받아 철회할 때, 단순 변심으로 철회할 때와 같은 쪽이 반환 비용을 부담한다. — 틀림 / 마(적용·맞대기) / twist: 지문은 통신판매에서 광고 내용과 다른 물품을 철회할 때와 단순 변심으로 철회할 때의 반환 비용 부담 주체가 다른데 선지는 두 경우에 같은 쪽이 부담한다고 했다.
- ⑤ ㉠과 ㉡은 모두 소비자가 물품의 내용을 확인하려고 물품 자체를 훼손한 경우에는 그 훼손을 이유로 일반 철회가 제한되지 않는다. — 틀림 / 라(속 바꿔치기) / twist: 지문은 내용을 확인하려고 포장만 훼손한 경우를 제한 사유에서 제외하는데 선지는 물품 자체를 훼손한 경우를 제외한다고 했다.

### C-neg — ㉠, ㉡에 대한 이해로 적절하지 않은 것은? (정답 ①) 밑줄: ㉠ = 통신판매 / ㉡ = 방문판매

- ① ㉠은 온라인에서 판매 정보를 제공하고 신청을 받는 거래를 포함하고, ㉡은 사업장 밖에서 권유해 안으로 동행한 뒤 신청을 받은 거래를 제외한다. — 틀림 / 마(적용·맞대기) / twist: 지문은 사업장 밖에서 권유해 소비자를 안으로 이끈 뒤 신청을 받은 거래도 ㉡에 포함한다고 했는데 선지는 그 거래를 ㉡에서 제외한다.
- ② ㉠과 ㉡은 모두 계약서면과 물품을 같은 날 받았다면 그날부터 일반 철회 기간을 계산한다. — 맞음 / 한 단계 적용 / twist: 지문의 계약서면 수령일 기준을 ㉠과 ㉡에서 계약서면과 물품을 같은 날 받은 경우에 적용했다.
- ③ ㉠은 단순 변심으로 청약을 철회하면 소비자가, ㉡은 같은 이유로 청약을 철회하면 판매업자가 반환 비용을 부담한다. — 맞음 / 다시 말하기
- ④ ㉠과 ㉡은 모두 내용물을 확인하려고 포장을 뜯었을 뿐이라면 이를 이유로 일반 철회가 제한되지는 않는다. — 맞음 / 한 단계 적용 / twist: 지문의 포장 훼손 예외를 ㉠과 ㉡에서 내용물을 확인하려고 포장만 뜯은 경우에 적용했다.
- ⑤ ㉠과 ㉡은 모두 광고와 다른 물품을 받은 지 두 달밖에 되지 않았더라도 그 차이를 안 지 31일이 지났다면 이를 이유로 철회할 수 없다. — 맞음 / 한 단계 적용 / twist: 지문의 두 기한을 모두 충족해야 한다는 기준을 ㉠과 ㉡에서 공급 후 3개월 이내이지만 차이를 안 날부터 30일을 넘긴 경우에 적용했다.
