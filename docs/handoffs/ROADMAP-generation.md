마지막 갱신: 2026-11-28 오후 5시 10분

## 3. 어려운 문제: 분야별 상태

어려운 문제는 "분야 × 〈보기〉 모양"으로 나눠서 하나씩 시험했습니다.

통과 단계:
- **기출 지문에서 통과** = 진짜 기출 지문에 우리가 만든 문제를 붙여 봤더니 괜찮았다
- **우리 지문에서도 통과** = 우리가 만든 지문에 붙여도 괜찮았다 (한 단계 위)
- **확정** = "이 방식으로 간다"고 정식으로 적어 둔 상태. 세트를 만들 때 이 설정을 그대로 씀

| 분야 | 〈보기〉 모양 | 어디까지 |
|---|---|---|
| 인문 | 사례 | ✅ 확정 |
| 인문 | 관점 | ✅ 확정 (아슬아슬) |
| 사회 | 사례 | ✅ 확정 |
| 사회 | 표 | ✅ 확정 |
| 사회 | 그래프 | ✅ 확정 |
| 사회 | 관점 | 🟡 기출 지문에서만 통과 |
| 과학 | 실험 | 🟡 기출 지문에서만 통과 |
| 과학 | 그래프 | 🟡 기출 지문에서만 통과 (그래프가 곡선답지 않음) |
| 과학 | 표 | 🟡 기출 지문에서만 통과 (옛 규칙 기준) |
| 과학 | 사례 | 🟡 기출 지문에서 거의 통과 |
| 과학 | 관점 | — 뺌 (기출에 이런 문제가 없음) |

## 남은 일 (순서대로)

1. ✅ **어려운 문제 확정 기록**: 우리 지문에서도 통과한 5칸을 확정함 (커밋은 CLI가 할 차례)
2. ✅ **쉬운 문제 만들기**: 내용 일치 → 밑줄 이유 → 어휘 순서로. 가장 자주 나오는 것부터.
   - ✅ 내용 일치: 기출 175문항에서 틀린 선지 만드는 방식 10가지를 찾음
   - ✅ 내용 일치: 채점 방법 정함 (기본 검사 + 같은 지문 기출과 비교)
   - ✅ 내용 일치: 기출 지문 2편(데이터 소유권, 수소)에 첫 시험 → **미달**. 정답은 다 하나로 잘 나왔지만, 채점자 전원이 "너무 쉽다(낱말 하나 맞춰 보면 풀린다)"고 봄. 기출은 만점, 우리 것은 평균 0.4점(2점 만점)
   - ✅ 내용 일치: 규칙 고쳐 다시 시험 → **통과**. "일치하지 않는 것" 문제는 기출과 같은 점수, "적절한 것" 문제는 아직 조금 쉬움
   - ✅ "적절한 것" 문제 보강: 기출 9문항을 보니 오답 대부분이 낱말 바꾸기가 아니라 관계(범위, "~할수록", 조건, 역할)를 비틂 → 규칙에 넣음
   - ✅ 내용 일치: 우리 지문 2편(혈액 응고, 청약 철회)에 시험 → **통과**. 우리 1.97, 기출 1.80(2점 만점). "적절한 것" 문제도 기출 수준
   - ✅ 내용 일치 **확정**(Ghootae). 세트를 만들 때 이 규칙을 그대로 씀 (커밋은 CLI가 할 차례)
   - ✅ 밑줄 문제 기출 분석: 평가원은 "㉠의 이유"보다 "㉠에 대한 이해" 문제가 4배 많음 → 목표를 "밑줄 친 대상 이해(이유 포함)"로 넓힘. 정답은 대개 지문의 원리를 ㉠에 한 번 적용한 것
   - ✅ 밑줄 문제: 기출 지문 2편(표면 장력, 정보 비대칭)에 첫 시험 → **거의**(우리 1.50, 기출 1.94). "적절하지 않은 것" 문제는 기출 수준(1.94), "적절한 것" 문제가 약함(1.06): 오답이 지문 문장을 그대로 뒤집어서 낱말 대조로 풀림
   - ✅ 밑줄 문제: 기출 "적절한 것" 오답 60개 다시 보기 → 기출도 절반은 지문을 뒤집은 오답. 다른 점은 뒤집는 자리: 기출은 문장 안쪽(짝 순서, 누가 먼저, 목적)을, 우리는 문장 끝(가능/불가능)을 뒤집음
   - ✅ 밑줄 문제: "문장 끝 뒤집기는 1개까지"로 고쳐 다시 시험 → **통과**. "적절한 것" 문제 2.00점(1차 0.94, 기출 1.83), "너무 쉬움" 표시 0개
   - ✅ 밑줄 문제: 우리 지문 2편 시험 → 판정은 "미달"이지만 점수는 기출 수준(우리 1.91, 기출 1.88). 청약 철회 문제가 여러 번 나오는 낱말("방문판매")에 밑줄을 그어 자리가 안 정해진 것이 유일한 실패
   - ✅ 밑줄 문제: "밑줄은 지문에 한 번만 나오는 구절에"를 넣고 청약 철회만 다시 시험 → **통과**. 우리 지문 4문제 모두 2.00점(기출 1.84). 밑줄은 통신판매·방문판매를 설명하는 구절에 그어짐
   - ✅ 밑줄 문제 규칙 확정 (마무리 커밋 지시문 나옴)
   - ✅ 어휘 문제 기출 분석: 평가원은 두 꼴이 거의 전부. "ⓐ와 같은 뜻으로 쓰인 예문 고르기"와 "ⓐ~ⓔ를 다른 낱말로 바꿔 쓰기". 오답은 같은 낱말의 다른 뜻, 또는 뜻이 비슷하지만 이 자리엔 안 맞는 낱말
   - ✅ 어휘 문제 첫 시험 → "미달". 4문제 중 3문제는 기출 수준(2.00·2.00·1.50)인데, 한 문제가 정답 예문에 지문 표현("관심을 두다")을 그대로 써서 뜻을 몰라도 풀림(0.13)
   - ✅ 어휘 문제: "지문과 같은 말 묶음 금지"를 넣고 다시 시험 → **통과**. 그 문제 1.75점(옛 문제 0.38), 어휘 4문제 평균 1.81 = 기출 1.81
   - ✅ 어휘 문제: 우리 지문 2편 시험 → **통과**(우리 1.47, 기출 1.78, 기준 안). 단 "문맥적 의미"는 1.94로 좋고 "바꿔 쓰기"는 1.00으로 약함(오답 낱말이 뜻부터 멀어 바로 지워짐)
   - ✅ 어휘 문제: "바꿔 쓰기" 보강 시험 → 효과 없음(0.88, 옛 문제 0.94, 기출 1.84). 우리 바꿔 쓰기 문제는 기출과 모양이 비슷한데도 늘 "너무 쉬움"을 받음 → 평가자가 진짜 기출을 알아봐서 기출에만 후한 것일 수 있음
   - ✅ 어휘 문제 규칙 확정(Ghootae). "바꿔 쓰기"는 세트 시험 때 사람이 함께 봄 (마무리 커밋 지시문 나옴)
3. ⬜ **4문항 세트로 묶고 시험** (다음 차례, 새 스레드 추천): 이때 과학 칸과 사회 관점도 우리 지문으로 같이 시험됩니다.
4. ⬜ **(가)(나) 두 편짜리 지문과 6문항 세트**
5. ⏸ **나중에**: 최상위 난이도 문제 노리기
