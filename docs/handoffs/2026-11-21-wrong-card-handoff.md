## 2. 합의된 카드 구조 (Ghootae 결정)

- **1층 (항상 보임)**: 가져갈 한 문장.
  - 내 오답만 다룬다. **정답 선지는 언급하지 않는다**. 마지막은 고른 선지에 대한 결론("그래서 ⑤는 적절하지 않은 내용이야"). 3문장·140자 이내 (11/20).
  - 근거를 쓴 오답은 "너는 …로 읽었어" (학생 근거 기준). 근거 없는 오답은 선지 기준 ("⑤는 …까지는 맞아. 그런데 …").
  - 구분선 아래 **기호 풀이**: 발문·고른 선지·1층 문장에 나온 기호 **전부** (11/20). 2·3층은 기호에 괄호 설명 없음 (11/18).
  - 고른 선지 선택률 작은 줄.
- 카드 제목 아래: 발문 한 줄 + 고른 선지 전문 (작은 글씨).
- **2층 (항상 보임)**: 내 근거(또는 근거 없으면 "선지에서 맞는 부분") → 원문(핵심 구절만 굵게) → 그래서. 정답 선지 칸 + **"정답 해설" 버튼**. 근거 없는 오답은 생성된 자기 점검 버튼 3개.
- **3층 ("자세히 보기"로 접힘)**: 정답률·선택률, 출제자가 노린 것(한 문장), 요약 연결, **"출제자 의도 자세히" 버튼**.
- 정답 해설·출제자 의도 자세히는 **문항 화면에서** 보고, "결과로 돌아가기"로 보던 카드 위치(펼침 상태 포함)에 돌아온다 (11/20).
- `matchesTrap`은 저장만, 화면에 쓰지 않음.
