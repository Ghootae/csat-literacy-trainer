## 3. 배운 것

1. 기출 준수율만으로 생성 규칙의 층을 정하면 안 된다. 기출은 '지문만' 선지도 원리 적용으로 잘 쓰지만, 생성기는 느슨해지면 정의 뒤집기로 간다. 생성 기준(G) 층의 규칙은 **시험 생성 근거가 있어야** 둔다.
2. 감사 표 F4의 '원리 적용'은 "정의를 반대로 말한 선지"와 진짜 적용을 가르지 못한다. 다음 감사 칸 후보(지금은 고치지 않음).
3. 평가자는 회차마다 엄하기가 다르다(3회차 v5 1.375 → 1.000). **같은 회차 안의 비교**가 맞는 잣대다. 새 규칙 시험에는 v5(또는 직전 채택판)를 같은 블라인드에 다시 넣는다.
4. 가설은 한 번에 하나만 바꿔 시험한다. 1회차 해석(전략 고르기)은 틀렸고, 2회차에 바로 드러났다. 틀린 해석은 보고에 그대로 적었다.
5. 알려진 한계: 표본이 작다(지문 2편). 의미 A(v6.2)는 '중' 4회("같은 표본 설정이라 핵심 판단이 쉬움"). R3 준수 1/4.
