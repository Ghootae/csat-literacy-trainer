   - `.omc/logs/problem-feedback-v4/events.jsonl`에서 `session.sessionId`가 `fb4090c8-36be-43b2-b0b5-44c90d024b07`이고 `event: SUBMITTED`, `session.phase: AWAITING_EVALUATION`, `session.evaluationMode: END_EXPLANATION`인 줄의 `session`을 스냅숏으로 쓴다(재구성 불필요).
