# 지문 집필 시뮬레이션 1: 뇌 과학과 법

작성: 2026-11-13 (웹 스레드 "수능형 지문 생성 방식 설계")
입력: Ghootae의 집필자 시뮬레이션 (뇌과학 전문가 가정) + 실제 지문 `2026-11-13-ebs-2023-brain-science-and-law.md` (EBS 2023 수능특강 독서)
상태: 규칙 초안. Ghootae 확인 전.

## 1. Ghootae의 집필 과정 (원문 요약)

1. **의뢰 조건**: 일반 주제 = 뇌과학, 융합 강조, 문항 2개(고난도 적용 1 + 쉬운 이해 1).
2. **교과 노드 후보와 탈락 이유**
   - 생명과학 시냅스 메커니즘: 어렵게 내기엔 좋지만 융합이 아님 → 탈락
   - 윤리 + 트롤리 딜레마 뇌 연구: 융합은 좋지만 fMRI 결과 설명이 복잡 → 탈락
   - 사회(법) + 뇌과학과 법: 채택
3. **주제가 논지를 결정**: "뇌과학과 법" → 논지는 "뇌과학이 법적 판단에 주는 영향 찬반"으로 거의 강제됨.
4. **문항 구성을 흐름보다 먼저 정함**: 고난도 = 두 입장 비교 적용, 쉬운 문항 = 각 입장 이해.
5. **문단 흐름**: 1 서론(전반적 소개) / 2 배경(뇌과학 성과) / 3 반대 ①(뇌 영상으로 좁혀서, 근거 = 인과의 한계·사후성) / 4 반대 ②(철학·윤리 측면, 책임은 생물학적 증거와 분리되고 사회적 상호작용에서 결정) / 5 찬성(증거로서의 가치, 과학 성과의 법 영역 유입) + 마지막 문장에 의의.
6. **고난도 〈보기〉 설계**: 뇌 영상이 범죄 의도 없음을 지지하는 상황 + 그에 대한 반대(정황 증거) + 유죄 결과. 선지 = 〈보기〉 요소가 각 입장을 지지하는지, 반례가 되는지 해석.

## 2. 규칙 초안

| # | 규칙 | 근거 (시뮬레이션) |
|---|---|---|
| W1 | 출발점은 백지가 아니라 **의뢰 조건**(분야, 융합 여부, 문항 수·난도)이다. 생성 입력에 이 조건을 명시한다. | 1 |
| W2 | 교과 노드 후보를 2~3개 내고, **융합 충족**(분야 개념 + 다른 교과 개념)으로 1차 거른다. 단일 교과 심화는 어렵게 낼 수 있어도 융합 의뢰에서는 탈락. | 2 (시냅스) |
| W3 | **설명 비용**으로 2차 거른다. 핵심 근거가 복잡한 데이터·실험 해석을 요구해 지문 분량 안에 설명이 안 되면 탈락. | 2 (트롤리 fMRI) |
| W4 | 주제를 정하면 **글 유형**(관점 대립 / 원리 적용 / 계산)이 거의 결정된다. 유형은 기출 문항 양식(C 관점비교 / A 개념연결 / B 계산)과 대응한다. | 3 |
| W5 | **문항 형식을 문단 흐름보다 먼저 정한다.** 고난도 1개의 양식이 문단 설계를 끌고 간다. | 4 |
| W6 | 앞 1~2문단은 배경, 뒤 문단은 입장. 배경 문단은 짧게, 입장 문단마다 근거를 명시한다. | 5 |
| W7 | **같은 편 입장도 근거의 축을 다르게 해서 둘로 쪼갠다** (과학적 한계 vs 개념적 분리). 이것이 닮은 이웃 쌍이 되어 문항의 혼동 지점이 된다. Ghootae 동기: 구체 선지를 노린 건 아니고, 근거가 하나뿐이면 문제가 너무 단순해질 것 같아서 다른 측면을 추가함 → 규칙: 입장의 근거가 한 축뿐이면 다른 축을 하나 더 찾는다. | 5 (3·4문단), Ghootae 답변 |
| W8 | 한 입장 안의 근거도 2개 이상, 서로 다른 대상을 겨냥하게 쓴다 (인과의 한계 = 영상↔행위 연결, 사후성 = 시점). | 5 (3문단) |
| W9 | 마지막 입장 문단 끝에 의의 한 문장. 새 정보는 넣지 않는다. | 5 |
| W10 | 〈보기〉 사례는 **각 요소가 한 입장에 대응**하게 짠다 (변호 = 도입 근거, 검찰 = 반대 근거, 판결 = 결과). 선지는 요소 → 입장 지지/반례 해석. | 6 |
| W11 | 배경 문단에도 뒤 입장 문단과 엮일 **구분 하나**를 심고, 그 구분이 성립하는 근거 문장을 같이 쓴다 (예: 구조 영상/활동 영상 + "구조 이상은 쉽게 변하지 않는다" → 3문단 사후성 비판의 강약과 연결). 근거 문장 없이 쓰면 이의 제기 위험. | 웹 제안, Ghootae 동의 (2026-11-13) |

## 3. 실제 지문에서 규칙이 만든 깊이 확인

- **1번 ②(오답)**: 가자니가(4문단, 반대 ②)의 "책임은 상호작용 속에 존재"를 ㉮(3문단, 반대 ①)의 말로 붙임. W7로 쪼갠 두 반대 입장이 그대로 혼동 지점이 됨.
- **2번 ①(정답, 적절하지 않은 것)**: 배심원이 PET 영상을 안 받아들인 이유를 "영상이 손상 상태를 못 보여 줌(기술 한계)"으로 해석했지만, 실제로는 손상은 인정하고 "손상 → 의도·계획 능력 상실" 인과를 인정하지 않은 것. W8로 나눈 근거(기술 한계 vs 인과 한계)의 구분이 정답 자리가 됨.
- 결론: 깊이는 "주제" 단계가 아니라 **입장과 근거를 쪼개는 단계(W7, W8)**에서 생겼다.

## 4. 역분해 가설(2026-11-13-passage-reverse-decomposition.md)과 대조

| 가설 | 시뮬레이션 결과 |
|---|---|
| 교과 노드 2개 이상 엮음 | 맞음. 의뢰 조건(융합)이 강제함 (W1, W2) |
| 고리는 두 이동이 같은 개념을 공유하며 만나는 곳 | 관점 대립형에서는 "같은 사례(뇌 영상 증거)를 두 입장이 다르게 해석하는 곳"이 그 자리 |
| 교과 밖 1~2단계 | 맞음. 생명과학 → 뇌 영상 기술 → 법정 증거 |
| (없었음) | **설명 비용 필터** (W3), **문항 먼저** (W5), **같은 편 입장 쪼개기** (W7) 추가 |

## 5. 아직 안 쓰인 고리 (관찰)

2문단의 "CT·MRI = 구조, PET·fMRI = 활동" 구분은 두 문항 어디에도 쓰이지 않았다. 〈보기〉에서 PET로 전두엽 "손상"을 보였다고 하므로, 구조/활동 구분과 엮으면 한 단계 더 깊은 선지를 만들 수 있다. 배경 문단에도 고리를 하나 심어 둘지가 다음 판단 지점.

## 6. Ghootae에게 확인할 것

- 반대 입장을 둘로 쪼갤 때 문항(혼동 선지)을 의식했는지, 내용상 자연스러워서였는지.
- 실제 문장을 쓰는 단계에서 디테일(인물 이름, 예시, 수치)을 넣고 빼는 기준.
- 설명 비용의 감각: "이 정도면 지문 안에서 설명된다"의 한계선.
