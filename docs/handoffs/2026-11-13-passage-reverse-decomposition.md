## 이동 유형 (4지문에서 뽑은 것)

| 기호 | 이동 | 설명 |
|---|---|---|
| M1 | 분류 축 세우기 | 한 개념을 두 기준으로 교차 분류 |
| M2 | 공통 원리 → 두 사례 | 같은 원리가 두 사례에서 다른 결과로 나타남 |
| M3 | 하위 메커니즘으로 내려가기 | 교과 밖 세부 항목·식·절차로 한 단계 내려감 |
| M4 | 다른 교과 노드로 건너가기 | 다른 과목 개념에 적용하거나, 한 과목의 모델을 다른 영역에 은유로 옮김 |
| M5 | 관점 대립 세우기 | 반대 관점과 그 근거, 판례·사고 실험으로 구체화 |
| M6 | 판정 규칙·범위 | 조건에 따라 결과가 갈리는 규칙 (A면 X, B면 Y / 범위 안·밖) |
| M7 | 설명 생략 사례 | 결과만 주고 이유는 앞 원리로 독자가 채우게 둠 |

## 1. 법인과 주식회사 자산 운용

- **출발 교과 노드**: 정치와 법 — 권리 주체(자연인·법인), 권리 능력. 보조 노드: 경제 — 주식회사·주식.
- **이동 경로**
  1. M1: 사단/재단 × 영리/비영리 (1문단)
  2. 원리 도출: 법인은 행위 능력이 없음 → 권한 받은 사람이 운용 → 법적 통제 (1문단)
  3. M2: 장학 재단(관할 기관 허가) vs 주식회사(자체 기관 결정) (2·3문단)
  4. M3: 주식회사 자산 항목 3분 — 자본금·이익 잉여금·자본 잉여금, 항목별 사용 제약 (4문단, 교과 밖 회계)
  5. M6: 자산의 외부 유출 여부 → 무상 증자(이사회만) vs 배당(주주 총회까지) (5문단)
- **고리 지점**
  - 배당 vs 무상 증자: 둘 다 잉여금을 주주에게 넘기는 닮은 이웃. 갈라지는 기준(외부 유출)은 5문단, 그 기준이 왜 중요한지는 1문단 원리.
  - 자본금 vs 자산 총규모: 무상 증자 때 자본금은 늘지만 총자산은 그대로 (4문단 정의 × 5문단 규칙).
  - 원칙-예외: 자본금 감액 금지 vs 손실 보전 불가 시 자본금 사용.
- **고리가 생긴 곳**: M3(항목 정의)과 M6(판정 규칙)이 같은 대상(잉여금)을 공유하며 만나는 곳.

## 2. 표면 장력과 라플라스 식

- **출발 교과 노드**: 화학Ⅰ — 분자 간 인력·물의 표면 장력. 보조 노드: 통합과학·물리 — 압력. 건너간 노드: 생명과학 — 호흡(폐포).
- **이동 경로**
  1. 현상(구형 방울) → 원리 (1문단)
  2. M3: 정성적 비례식 하나 — 압력 차 ∝ 표면 장력, ∝ 1/반지름 (1문단, 교과 밖 식)
  3. M4: 같은 식을 다른 교과 노드에 적용 — 폐포·계면 활성제 (2문단)
  4. M7: 두 기포가 합쳐지는 결과만 주고 이유는 생략 (3문단)
  5. M3 한 번 더: 두 번째 관계식 오네소르게 수 = 점도 / (표면 장력·밀도·지름) (5문단)
  6. M6: 0.1~1.0 범위, 양쪽 이탈 결과 (6문단)
- **고리 지점**
  - 기포 합침: 작은 기포가 내부 압력이 더 높아 공기가 작은 쪽 → 큰 쪽으로. 직관과 어긋나고 이유는 1문단 식으로 채워야 함.
  - 표면 장력이 두 식에 모두 등장: 라플라스에서는 압력 차를 키우고, 오네소르게에서는 분모라 값을 줄임. 계면 활성제(2문단)로 표면 장력이 낮아지면 오네소르게 수는 커진다는 사례 건너뛰기 연결 (11/11 블라인드 1위 문항의 정답 자리).
- **고리가 생긴 곳**: 같은 변수를 공유하는 두 관계식 + 그 변수를 바꾸는 사례(M4)가 만나는 곳. M7이 의도적으로 빈칸을 남김.

## 3. 정보 비대칭과 사상의 자유 시장

- **출발 교과 노드**: 경제 — 시장 실패·정보 비대칭·역선택·정부 개입. 건너간 노드: 정치와 법 — 표현의 자유(기본권), 헌법 재판소.
- **이동 경로**
  1. 교과 개념 정의: 완전경쟁 가정 vs 정보 비대칭 → 정부 개입 (1문단)
  2. 시사 사례: 생성형 AI 생성물 표시 의무, 의무 대상 확대 주장 (2문단)
  3. M4(은유 이식): 완전경쟁시장 모델을 표현 영역으로 옮긴 사상의 자유 시장 이론 (3문단)
  4. M5: 비판론 — 진실 정보 과소 공급, 공동 규제(사전 자율 → 사후 정부) (4문단)
  5. 판례 매핑: 실명 확인 사건 다수 의견 vs 소수 의견 (5문단)
- **고리 지점**
  - 1문단 경제 논리(정보 비대칭이면 개입)와 4문단 비판론이 사실상 같은 구조. 3문단 이론은 1문단의 "완전경쟁 가정"에 서 있음. 문단을 건너야 대칭이 보임.
  - 다수/소수 의견을 두 관점에 대응시키기 (소수 의견만 명시, 다수 의견 쪽 관점은 추론).
  - 공동 규제의 순서(사전 플랫폼 → 사후 정부).
- **고리가 생긴 곳**: 한 교과 모델을 다른 영역에 옮긴(M4) 뒤 관점 대립(M5)을 세워, 1문단 원리가 한쪽 관점의 근거가 되는 곳.

## 4. 의미 내재주의와 외재주의

- **출발 교과 노드**: 국어(언어와 매체) — 단어의 의미와 지시 대상. 예시로 빌린 노드: 화학 — 물의 화학식, 원소(금).
- **이동 경로**
  1. 전통 관점 + 용어 두 개(지시체, 기술구) (1문단)
  2. M5: 반대 관점(퍼트넘) (2문단)
  3. 통제 사고 실험: 인식은 같게, 대상만 다르게 (3문단)
  4. M3: 실제적 본성·자연종 명사 (4문단)
  5. 확장 함의: 언어적 노동 분업 (4문단)
- **고리 지점**
  - 사고 실험 구조(인식 동일 + 대상 상이 → 의미 상이)를 새 사례에 대입.
  - 같은 사례를 두 관점에서 판정 (내재주의라면 두 '물'의 의미가 같다고 봄).
  - 노동 분업과 외재주의 연결: 일반인이 금의 실제적 본성을 몰라도 '금'을 쓸 수 있음 → 기술구가 의미를 결정하지 않는다는 쪽 근거.
- **고리가 생긴 곳**: 관점 대립(M5)을 변수 하나만 바꾼 사고 실험으로 구체화한 곳. 통제 구조가 그대로 문항 틀이 됨.

## 4지문 공통 관찰

1. **출발 노드는 1문단에 정의로 나오고, 고리는 교과 밖으로 1~2단계 내려간 곳에서 생긴다.** 교과 범위 안에만 머물면 학생이 배경지식·상식으로 풀어 버리고, 너무 멀리 가면 지문이 설명을 감당하지 못한다.
2. **이동 하나로는 고리가 안 생긴다. 두 이동이 같은 개념을 공유하며 만나는 곳에서 생긴다.** 법인 = 항목 정의 × 판정 규칙(잉여금 공유), 표면 장력 = 두 식 × 사례(표면 장력 공유), 정보 = 경제 모델 × 관점 대립(완전경쟁 가정 공유), 의미 = 관점 × 사고 실험(지시체 공유).
3. **4지문 모두 교과 노드 2개 이상을 엮었다.** 대부분 한 과목이 뼈대, 다른 과목이 적용처나 예시.
4. **의도적 빈칸(M7)이나 결과만 주는 서술이 고리를 만든다.** 지문이 다 설명하면 문항이 얕아진다.
5. 영역별 경향: 과학·기술은 M3(식)+M6(범위)+M7, 사회는 M1+M2+M6, 인문·사회 논쟁형은 M4+M5. 문항 양식 분류(A 개념연결 / B 계산 / C 관점비교)와 대응한다.

## 생성 흐름 초안 (위 관찰을 그대로 옮긴 것)

1. 교과 지도에서 출발 노드 하나 선택 (+ 엮을 두 번째 노드 후보).
2. 이동 후보를 M1~M7 조합으로 여러 개 생성 (2~3개 이동).
3. **만남 검사**: 두 이동이 공유하는 개념이 있는가 → 있으면 거기서 추론 고리 조건(닮은 이웃 쌍, 원칙-예외, 값에 따라 바뀌는 규칙, 직관 어긋남) 검사.
4. 기출 지도와 대조: 같은 출발 노드의 기출이 이미 같은 경로를 갔으면 버리거나 방향 바꿈.
5. 교과 밖으로 내려간 세부(M3)는 검증 출처 확보. 출처 없으면 그 경로 버림.
6. 서술: 고리 지점은 문단을 나눠 배치하고, 한 곳은 M7로 비워 둠.

## Ghootae에게 확인할 것

- 직접 쓰실 때 이동 방향이 위 M1~M7과 맞는지, 빠진 이동이 있는지.
- "두 이동이 만나는 곳에서 고리가 생긴다"가 직관과 맞는지.
- 교과 밖으로 얼마나 내려가도 되는지에 대한 감각 (위 관찰 1).
