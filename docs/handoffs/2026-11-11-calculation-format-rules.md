## 0. 한 줄 요약

계산 양식은 실제 산수가 아니라 **식 속 변수의 방향·상쇄·범위를 따지는 관계 추론**이다. 같은 식을 쉬운 고리에서 어려운 고리로 단계적으로 공격하고, 정답 자리에는 학생이 가장 많이 틀릴 판단을 둔다.

## 1. 지문 단계

1. 뼈대 = 원리(식) 1개 + 현실 적용 사례 여러 개를 병렬로 둔다. 사례가 나중에 문항 자리가 된다. (C1)
2. 사례마다 식의 변수가 다른 방향, 다른 조건으로 움직이게 고른다. (C2)
3. 마지막에 새 개념(무차원 수 등)을 하나 얹어 원리를 넓힌다. (C3)
4. 계산 문항용 수치는 지문에서 미리 깐다. 값보다 **범위·구간**으로 주고, 범위를 벗어났을 때 생기는 결과(위·아래 각각)도 함께 쓴다. (C4, C17)

## 2. 〈보기〉 단계

5. 시간 축(처음 → 나중)을 두고, 대상 둘 중 하나만 변하게 한다. (C5)
6. 눈에 띄는 나중 사건이 처음 상태를 가리게 해 "처음 상태 망각"을 노린다. (C6)
7. 조작 하나(첨가제)로 식의 변수 하나를 움직인다. (C8)
8. 변수 이름 대신 **관찰 가능한 특징**으로 쓴다(끈적해짐 → 점도, 잘 안 나옴 → 범위 밖). 법인 규칙 6(용어 대신 정의로 풀어 씀)의 과학 버전. 
9. 〈보기〉는 짧게 두고, 새 시점·새 조건은 선지에서 만든다. (C19, rules-A 규칙 10·11과 일치)

## 3. 선지 단계

### 고리 고르기
10. 같은 식을 여러 번, 단계적으로 공격한다: 범위 → 한 변수 방향 → 여러 변수 상쇄. (C13)
11. 같은 고리를 대상·시점만 바꿔 다시 쓸 수 있다. (C16)
12. 식·범위를 충분히 썼으면 지문에서 아직 안 쓴 문장으로 넓힌다. 한 문항이 지문 여러 부분을 덮는다. (C17, 법인 규칙 11과 같은 계열)

### 함정 장치
13. 대비 표현("~와 달리") 하나로 함정을 만든다. (C6)
14. 가치 직관("좋아졌다 = 커졌다")을 식의 실제 방향과 맞부딪히게 한다. (C9)
15. 주의가 덜 가는 대상(배경 대상)의 상태를 묻는다. (C15)
16. 결론에 영향 없는 조건("~은 변하지 않았으나")을 넣어 변수 추적을 요구한다. (C18)
17. 변수 상쇄: 두 변수를 반대로 같은 배수만큼 바꾸고 나머지는 "유지한 채"로 고정해 "변함 없음"을 묻는다. 계산은 2배·1/2 수준. (C11)

### 참/거짓과 정답 정하기
18. 선지마다 참·거짓 두 버전 중 더 어려운 쪽을 고른다. (C10, 법인 규칙 14·15의 거울)
19. 상식만으로 맞혀지는 버전은 쓰지 않는다. 참 버전이 상식과 같으면 거짓으로 남긴다. (C20, 법인 규칙 14)
20. 정답 자리 = 가장 많이 틀릴 판단. 긍정 발문이면 식을 직접 공격하는 참 선지, 부정 발문이면 참으로 만들 수 없는 거짓 선지. (C12, C21, 법인 규칙 16)
21. 난도 배분: 어려운 선지 뒤에 쉬운 선지를 넣어 균형을 맞춘다. 가장 직접 쓸 수 있는 고리(범위)는 쉬운 선지에 쓴다. (C7, C14)

## 4. 16번 실제 구조 (예시)

| 선지 | 참/거짓 | 난도 | 고리 | 장치 |
|---|---|---|---|---|
| ① | 거짓 | 쉬움 | 범위(구입 당시) | "~와 달리", 처음 상태 망각 |
| ② | 거짓 | 중간 | 한 변수 방향(첨가제 → 점도↓) | 가치 직관 vs 식 방향 |
| ③ | 참 · 정답 | 어려움 | 여러 변수 상쇄 | "유지한 채", 2배·1/2 |
| ④ | 거짓 | 쉬움 | 범위(두 달 뒤 파랑) | 배경 대상 공격 |
| ⑤ | 거짓 | 어려움 | 범위 밖 결과(새 문장) | 새 시점, 방해 정보, 상식 역이용 |

## 5. 법인(개념 연결) 양식과 비교

| | 개념 연결+적용 (법인) | 계산 (표면 장력) |
|---|---|---|
| 지문 재료 | 두 기준 분류, 헷갈리는 용어 묶음 | 식 1개, 변수가 다르게 움직이는 사례, 수치 범위 |
| 〈보기〉 | 용어 → 정의로 풀어 씀, 오해 부르는 디테일 | 변수 → 관찰 특징으로, 시간 축·조작 하나 |
| 어려운 선지 | 2~3개 개념 겹치고 조사·주체로 비틂 | 여러 변수 동시 변화(상쇄), 방해 조건 |
| 좋은 거짓 | 한 문장만 보면 참, 두 문장 통합 시 거짓 | 직관·상식과 맞지만 식 방향과 어긋남 |
| 공통 | 상식형 거짓 버림 · 더 어려운 버전 선택 · 정답 = 가장 어려운 판단 · 선지가 지문을 고루 덮음 |
