# 출제자 시뮬레이션 2: 표면 장력(라플라스 식) 지문 — 진행 기록

- 날짜: 2026-11-11 · 시뮬레이션: Ghootae · 정리: 웹 스레드 · 양식: 계산(과학·기술)

## 1. 지문 작성 과정 (Ghootae 원문 요약)

1. 목표: 라플라스 식을 쓸 수 있는 지문 → 라플라스 식이 적용되는 현실 사례를 설명하는 글.
2. 서론: 액체가 구형을 이루는 현상에서 시작 → 라플라스 식으로 설명 가능함을 소개.
3. 본론 1: 폐포에 적용.
4. 본론 2: 기포가 합쳐지는 사례.
5. 본론 3: 잉크 방울에 적용.
6. 본론 4: 새 개념 '오네소르게 수' 소개.
7. 계산 문제를 만들려면 수치가 필요 → 마지막 문단에 오네소르게 수의 범위.

## 2. 규칙 후보 (웹 정리, 확인 전)

- C1. 지문 뼈대 = 원리(식) 1개 + 현실 적용 사례 여러 개를 병렬로. 사례 하나하나가 나중에 문항 자리가 된다.
- C2. 사례마다 식의 변수가 다른 방향·다른 조건으로 움직이게 고른다(작은 폐포/큰 폐포, 작은 기포→큰 기포, 잉크 방울).
- C3. 마지막에 새 개념(무차원 수 등)을 하나 더 얹어 원리를 확장한다.
- C4. 계산 문항을 위한 수치는 지문 단계에서 미리 깐다. 수치는 값 자체보다 '범위·구간'으로 준다(→ 대소·구간 판정 문항).
- 법인 지문 규칙과 비교: 법인은 "분류 조건 + 헷갈리는 용어 묶음"이 재료, 표면 장력은 "식 + 변수가 다르게 움직이는 사례들 + 수치 범위"가 재료.

## 3. 문항 16 출제 과정 (Ghootae, 진행 중)

1. 계산 문항 하나가 필요 → 그래서 마지막 문단을 넣어 둠. 쓸 식: 0.1 < 오네소르게 수 = 점도 / (표면 장력 × 밀도 × 지름) < 1.
2. 적용 사례는 잉크젯 프린터의 잉크일 수밖에 없음.
3. 오네소르게 수를 정하는 변수들이 서로 다르게(차별적으로) 변하는 경우를 생각 → 〈보기〉 작성.
4. 가장 쉽게 쓸 수 있는 고리 = 0.1~1 범위 정보.
5. 〈보기〉에서 "두 달 뒤 빨간 잉크가 잘 나오지 않았다"에 학생이 집중하면, 처음에는 빨강·파랑 모두 잘 나왔다는 사실을 잊을 수 있음 → "구입 당시의 빨간색 잉크의 오네소르게 수와 달리,"를 덧붙여 ① 완성: "구입 당시의 빨간색 잉크의 오네소르게 수와 달리, 구입 당시 파란색 잉크의 오네소르게 수는 대략 0.1에서 1.0 사이에 있었겠군."
6. 부정 선지로 하기엔 너무 단순 → 아주 쉬운 함정으로.

### 규칙 후보 (웹 정리)

- C5. 〈보기〉에 시간 축(처음 상태 → 나중 상태)을 두고, 대상 둘(빨강·파랑) 중 하나만 변하게 한다. 변수는 서로 다르게 움직이게 고른다.
- C6. 눈에 띄는 나중 사건(두 달 뒤 고장)이 처음 상태(둘 다 정상)를 가리게 해, "처음 상태 망각"을 함정으로 쓴다. 대비 표현("~와 달리") 하나로 함정을 만든다.
- C7. 범위 정보(0.1~1)처럼 지문에서 가장 직접 쓸 수 있는 고리는 쉬운 선지(①)에 쓴다. 문항 안에서도 쉬운 선지 → 어려운 선지로 난도를 배치한다.
- 확인 (Ghootae): 16번 발문은 "적절한 것"(긍정 발문). ①은 틀린 선지(오답 매력 선지)로, 빨강도 구입 당시엔 범위 안이었으므로 "~와 달리"가 틀린 쉬운 함정.
- 참고: 긍정 발문에서는 거짓 선지 4개가 오답 함정이고 참 선지 1개가 정답이다. 법인 13번(부정 발문)의 "참으로 못 만드는 선지가 정답" 규칙은 여기서 "거짓으로 못 만드는(또는 가장 깊은 연결이 필요한) 참 선지가 정답"으로 뒤집혀 적용될지 확인 필요.

### 선지 (두 번째, 중간 난도 함정)

- 〈보기〉의 '첨가제'로 변수 하나(점도)를 움직여 오네소르게 수 식의 방향 이해를 공격.
- 빨간 잉크에 첨가제를 넣어 점도를 낮춤 → 식상 오네소르게 수는 작아져야 함. 식을 모르는 학생은 "안 나오던 게 나오니 좋아짐 = 수가 커짐"으로 착각할 수 있음.
- 선지: "빨간색 잉크에 첨가제를 넣어 인쇄가 문제없이 잘 이루어졌다면, 첨가제를 넣어 잉크의 오네소르게 수가 더 커진 것이겠군." (오답)
- 참 버전(작아졌다)으로 만들면 너무 쉬워짐 → 중간 난도 함정(오답)으로 유지.

### 규칙 후보 (웹 정리)

- C8. 〈보기〉에 조작 하나(첨가제)를 넣어 식의 변수 하나를 움직이고, 결과(수의 증감)를 묻는다.
- C9. 함정은 "좋아졌다 = 커졌다" 같은 가치 직관을 식의 실제 방향(분자 감소 → 수 감소)과 맞부딪히게 만든다. 법인의 "상식에 맞아 헷갈림"과 같은 계열(직관 점화).
- C10. 선지마다 참/거짓 두 버전 중 더 어려운 쪽을 고른다. 긍정 발문에서 참 버전이 쉬우면 거짓(오답)으로 남긴다(법인 13번의 "부정형이 쉬우면 버림"의 거울).

### 선지 (세 번째, 정답)

- 식 이해 검증이 핵심이므로 두 번째 선지에 이어 다시 식을 쓴다. 이번엔 식을 직접 건드린다.
- 여러 변수를 함께 바꾸면 헷갈린다 → "파란색 잉크의 점도와 표면 장력은 유지한 채, 밀도를 두 배로 높이고 노즐의 지름을 반으로 줄인다면 파란색 잉크의 오네소르게 수는 변함이 없겠군." (참)
- 수식을 보면 얼어붙는 학생이 가장 많이 틀릴 선지 → 정답으로 확정.
- 검산(웹): 분모의 밀도×지름 = 2 × 1/2 = 1, 점도·표면 장력 고정 → 수 불변. 지문 식에 제곱근이 있어도 곱이 같으므로 결론은 같다.

### 규칙 후보 (웹 정리)

- C11. 변수 상쇄: 두 변수를 반대 방향으로 같은 배수만큼 바꾸고 나머지는 고정("유지한 채")해 "변함 없음"을 묻는다. 계산은 배수(2배, 1/2) 수준이고, 판단은 관계 이해로 한다. (기출 양식 분류에서 본 B형 특징 "변수 고정 단서로 상쇄 선지"와 일치)
- C12. 긍정 발문의 정답 = 가장 많이 틀릴 참 선지. 법인 13번(부정 발문)의 "참으로 못 만드는 선지가 정답"과 짝: 어느 발문이든 정답 자리에 가장 어려운 판단을 둔다.
- C13. 한 문항 안에서 같은 식을 여러 번(① 범위, ② 한 변수 방향, ③ 여러 변수 상쇄) 단계적으로 공격해 난도를 쌓는다.

### 선지 (네 번째, 쉬운 함정)

- 어려운 선지를 넣었으니 하나는 쉽게. 범위 정보를 한 번 더 쓴다.
- 〈보기〉에서 빨간 잉크 문제에 집중하느라 파란 잉크 내용을 덜 본 학생을 노린다 → 파란 잉크 이야기로.
- 선지: "구입 당시와 달리, 두 달이 지난 후 파란색 잉크의 오네소르게 수는 인쇄의 적정 범위를 벗어났겠군." (오답: 파란 잉크는 계속 잘 나왔으므로 범위 안)

### 규칙 후보 (웹 정리)

- C14. 난도 배분: 어려운 선지를 넣은 뒤 쉬운 선지 하나로 균형을 맞춘다(문항 전체 난도 조절).
- C15. 주의가 덜 가는 쪽 공격: 〈보기〉의 눈에 띄는 대상(빨강) 대신 배경 대상(파랑)의 상태를 묻는다. ①의 "처음 상태 망각"과 같은 계열(주의 배분 함정).
- C16. 같은 고리(범위)를 대상·시점을 바꿔 다시 쓴다(① 구입 당시 빨강 대비, ④ 두 달 뒤 파랑).
