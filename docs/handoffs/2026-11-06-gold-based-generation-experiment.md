## 0. 배경과 질문

사용자 질문(2026-11-06):

1. 자산화한 지문·풀이 골드로 시중 AI 문항 생성보다 정확하고 타당한 문항을 만들 수 있는가?
2. 지문 자체를 대체 생성할 수 있는가? 원문 A의 명제 구조를 추출하고, 개념 지도(교과 개념 + 기출 개념)에서 비슷한 구조를 만들 수 있는 주제를 골라, 구조를 먼저 만들고 글을 써서 주제가 다른 기출 유사 지문을 만든다.

동기:

- 저작권: 비문학 기출은 사실상 묵인, 문학은 위험(2026-11-06 조사). 저작권은 표현을 보호하고 구조(아이디어)는 보호하지 않으므로, 뼈대만 옮기고 주제·문장이 다른 지문은 기출 의존을 크게 줄인다.
- SNS 독해력 테스트: 기출 문항은 정답이 인터넷에 있다. 생성 문항이 오히려 유리하다.
- 진단: 생성 시점부터 모든 오답이 "어느 지도 노드에 어떤 비틂"으로 태깅된다. 같은 비틂을 새 문항으로 다시 풀게 하는 재도전 훈련이 가능하다.

가설(예상, 이 저장소의 측정 근거 없음): 시중 방식(지문만 주고 선지를 바로 쓰게 함)의 대표 실패는 복수 정답, 지문 없이 풀리는 선지, 근거를 짚을 수 없는 오답이다. 우리 자산은 **설계(무엇을 어떻게 비틀지)와 검증(역연결·코드 검사)** 단계를 끼워 넣을 수 있어 이 실패를 줄인다. E1의 A안이 이 실패를 실제로 보이는지가 첫 관찰 대상이다.

정정: 초안은 "볼록 렌즈 11번 복수 정답 실패"를 이 가설의 사례로 들었으나, 그것은 문항 생성이 아니라 실제 기출 문항의 풀이 골드 후보 생성에서 시각 자료(공간 관계)를 놓쳐 C2·C3가 모두 거짓이 된 실패다(`docs/PROBLEM-GOLD-ASSET-REGISTER-2026-09-09.md` 217~221행, 256~260행). 가설의 근거에서 뺀다.

## 2. 실험 E1: 골드 기반 문항 생성 (기출 지문 위)

### 대상

동결 지도·선지 연결 동결본이 모두 있는 지문 2~3개. 1순위: 법인(`corporate-law`), 표면 장력(`surface-tension-laplace`). 선택: 정보 비대칭, 세트 E 지문(결정 기록 때 표본 크기와 함께 정함). 해당 지문의 실제 기출 문항은 생성 입력에서 **빼 두고** 블라인드 비교용으로만 쓴다(선지 연결 동결본도 그 지문 것은 입력에 넣지 않는다. 비틂 분포는 다른 지문 동결본에서 가져온다).

### 조건

- **A안(기준선, 시중 방식)**: 지문 원문 + 발문 유형만 주고 5지선다를 바로 생성. 허수아비 비교가 되지 않도록 지시문에 "정답은 하나, 오답마다 원문에서 틀린 곳을 짚을 수 있어야 함, 지문 없이 풀리면 안 됨" 같은 품질 요구는 넣는다.
- **A′안(2단계, 골드 없음)**: 지문 원문만 주고, 모델이 스스로 B안과 같은 형식의 설계표를 만든 뒤 집필한다. 2단계 방식의 효과와 골드의 효과를 가르기 위한 조건이다. 질문 1("우리 자산이 시중보다 나은가")의 주 비교는 **A′ 대 B**, A 대 A′는 2단계 방식 자체의 효과다.
- **B안(골드 기반)**: 두 단계.
  1. 설계: 동결 지도·입장·관계 유형을 주고, 문항마다 `{ 발문 유형, 극성, 정답 선지 근거 노드, 오답마다 (대상 노드 id, 비틂 종류 14종 중 하나, 바꾼 내용) }` 설계표를 만든다. 비틂 종류 분포는 다른 지문 동결본의 기출 분포에 맞춘다.
  2. 집필: 설계표대로 선지 문장을 쓴다. 매력 요인은 D-0170 규칙(원문 구절 또는 한 문장으로 명시 가능한 상식)만.
- A′안 설계표의 비틂 종류는 14종 목록을 주지 않는다(목록 자체가 골드 자산이므로). 노드 id 대신 원문 구절로 대상을 적는다.
- 문항 수: 지문당 조건별 3문항(일치·불일치형 중심). 〈보기〉 적용형은 E1 범위 밖(3절 한계 참조).

### 자동 관문 (코드 + 모델)

1. **형식**: 선지 5개, 정답 1개, 설계표 노드 id 실재, 설계표 비틂 종류가 목록 안.
2. **단일 정답**: 서로 다른 모델 2~3개(예: luna·sol·다른 공급자)가 지문을 보고 풀어 모두 같은 정답에 모이는가. 갈리면 결함 후보.
3. **지문 없이 풀림**: 같은 모델들이 지문 없이 풀어 정답률이 우연 수준(20%) 근처인가. 높으면 상식으로 풀리는 문항.
4. **역연결**: `run-choice-link.mjs`(v5 지시문)로 생성 문항을 연결한다. 정오는 기존 규칙대로 정답에서 고정(D-0162 보완 3). B안은 설계표의 대상 노드·비틂 종류가 복원되는지(대상 겹침, 종류 일치)를 잰다. A·A′안도 같은 방식으로 연결해 비틂 분포·`readingGap` 비율·`OUTSIDE` 조각 비율을 비교한다.
5. **원문 인용 검사**: 역연결의 `evidenceQuote`가 원문 부분 문자열인가(기존 코드 검사).

### 사람 판정 (블라인드)

A·A′·B안·실제 기출을 문항 단위로 섞어 출처를 가린 HTML 검토지(기존 `USER-REVIEW.html` 형식)를 만든다. 사용자는 문항마다:

- 정답 유일성(유일 / 복수 / 없음)
- 오답 근거 명확성(선지마다 원문에서 틀린 곳을 짚을 수 있는가)
- 수능다움(1~4)

**출처 추측(기출 / 생성)은 사용자가 하지 않는다.** 사용자는 법인(K4, 회사법 13번 ②)·표면 장력 등 대상 지문의 기출 문항을 선지 연결·출제자 전략 글 검토에서 이미 봤으므로, 기억으로 기출을 알아볼 수 있다. 출처 추측은 해당 기출을 보지 않은 판정자(예: 교사 시연 참여 교사)가 하거나, 판정자를 구하지 못하면 이 항목과 해당 성립 기준을 뺀다. 수능다움도 같은 영향을 받을 수 있으므로, 사용자 판정 결과에서는 기출 문항의 점수를 따로 보고 생성 조건끼리(A·A′·B) 비교를 주로 본다.

### 성립 기준 (실행 전에 확정할 것, 초안)

- B안 결함률(관문 2·3 실패 + 사용자 "복수/없음") < A′안 결함률, 그리고 B안 결함률 ≤ 1/6 문항.
- B안 역연결 비틂 종류 복원 ≥ 80% 선지.
- B안 수능다움 평균이 A′안보다 높다.
- (기출을 보지 않은 판정자가 있을 때만) 그 판정자의 출처 추측에서 B안을 기출로 본 비율 ≥ 30%.

## 3. 실험 E2: 지문 대체 생성 (구조 이식)

### 흐름

```
원문 A 동결 지도 + 입장 + 관계 유형 + 선지 연결(twistTargetIds)
→ 뼈대 추출: 문단 역할, 노드·관계 그래프, 입장 대립, "선지 고리"(대비 쌍·조건 분기·기제-결과·입장 대립 등 기출 선지가 걸린 곳)
→ 주제 후보 탐색: 같은 고리가 성립하는 주제
→ 뼈대 사상: 원 노드 → 새 개념 대응표 (+ 각 사실 명제의 출처 문장)
→ 집필
→ 역분석 + 사실 검사 + 문체 지표
→ (통과 시) E1 B안 방식으로 문항 생성
```

### 핵심 설계 원칙

1. **옮길 구조는 문항이 걸리는 구조다.** 관계 그래프 전체보다, 기출 선지가 실제로 비튼 노드(`twistTargetIds`)와 그 주변 관계가 새 주제에서도 같은 종류로 성립하는지를 주제 선택 기준으로 삼는다.
2. **사실을 구조에 맞춰 바꾸지 않는다.** 구조가 안 맞으면 주제를 버린다. 새 지문의 사실 명제는 모두 출처 문장(교과서·백과·공공 자료 등)으로 뒷받침돼야 한다.
3. **개념 지도는 처음부터 크게 만들지 않는다.** E2 파일럿은 주제 후보를 모델 제안 + Claude 검토로 고른다. 개념 지도 자산화는 파일럿 성립 뒤 별도 결정(배경지식 확장 기능의 교과 개념 지도와 같은 자산이 될 수 있음).

### 주제 거리 3단계

| 단계 | 예(법인 원문 기준) | 의미 |
|---|---|---|
| T1 같은 분야 형제 주제 | 법인 → 조합(재단은 원문 2문단에 있어 제외) | 개념 사상이 가장 쉬움. 먼저 성공해야 함 |
| T2 같은 분야 다른 주제 | 법인 → 다른 사법 제도 | 구조만 공유 |
| T3 다른 분야 | 법인 → 과학·인문 주제 | 구조 일반성 시험 |

파일럿: 원문 2개(법인, 표면 장력) × T1·T2 각 1편 = 4편. T3는 T1·T2 결과를 본 뒤.

### 관문

1. **역분석 구조 일치**: 생성 지문에 분석 골드 절차(지도 3회 → 동결 선택 점검표 → 입장 → 관계 유형)를 **뼈대를 보여 주지 않고** 돌린다. 원 뼈대와 비교:
   - 노드 대응률(사상표 기준으로 원 노드가 새 지도에서 대응 노드를 갖는 비율)
   - 관계 유형 일치율(대응 노드 쌍의 18유형 일치)
   - 입장 귀속 일치(인물·학파 귀속이 사상표대로인가)
   - 선지 고리 보존(원 `twistTargetIds` 노드의 대응 노드가 모두 존재)
2. **사실 검사**: 집필 전에 코드 에이전트가 출처 묶음(공공 백과·정부·학회 자료, URL 포함)을 파일로 모으고 집필은 그 문장 안에서만 한다(D-0206). 사실 명제마다 출처 문장 대조. 출처 없는 사실 명제 0건이어야 함. Claude 검토 + 표본 사용자 확인.
3. **문체 지표**: 문단 수, 문단당 문장 수, 문장 길이 분포, 정보 밀도(문단당 명제 수)를 원문과 비교(한자어 비율은 D-0206로 제외). 허용 폭은 기출 표본 분포에서 정한다.
4. **표현 거리**: 원문과의 문장 단위 유사도(n-gram 겹침)가 낮아야 함. 원문 문장 재진술이 남으면 실패(저작권 목적).

### 사람 판정

E1과 합쳐, 실제 기출 지문·문항과 생성 지문·문항을 섞은 블라인드 검토. 지문 단위로 수능다움(1~4), 출처 추측, 사실 오류 발견 여부.

### 관문 기준의 천장 (측정, 2026-11-06)

같은 원문·같은 지시문으로 지도를 세 번 만든 회차끼리의 일치를 측정했다(`scripts/measure-map-run-agreement.mjs`, 결과 `docs/experiments/map-run-agreement-2026-11-06/results.json`, 외부 전송 없음). 대응은 명제의 `sourceQuote` 원문 구간(상위 노드는 하위 명제 구간의 합)의 겹침 비율(IoU) ≥ 0.5로 정했다.

| 지표 | 지시문 v2 10지문 평균 (최저) | 전체 36지문 평균 (최저) |
|---|---|---|
| 노드 대응(종류 무관) | 97.4% (95%) | 97.3% (94%) |
| 노드 대응(같은 종류) | 95.1% | 95.3% |
| 관계 재현(양 끝 대응, 방향 같음) | 68.1% (62%) | 67.8% (50%) |
| 관계 재현(방향 반대·끝 범위 차이 허용) | 86.3% (지문별 81~91%) | — |
| 관계 유형 일치(재현된 관계 쌍) | 측정 자료 없음 | 93.8% (v1 지도 6지문, 분류 v2, 831쌍) |
| 선지 고리 보존(동결 회차 → 다른 회차) | 92%(선지 연결이 있는 7지문, `twistTargetIds` 53개 × 다른 회차 2개) | — |

해석:

- 노드 대응은 같은 원문 위 비교라 거의 자명하게 높다. 생성 지문은 원문이 달라 사상표로 대응을 정해야 하므로 이 값은 상한일 뿐 기대치가 아니다.
- 엄격한 관계 재현(68%)은 측정 방식의 하한이다. 불일치 표본 51건을 내용으로 판정하니(`docs/experiments/map-run-agreement-2026-11-06/REPORT-desktop.md` 7절):
  - 같은 연결인데 방향·범위·이름만 다름: 35건
  - 묶음 구성이나 명제 병합으로 같은 연결을 표현함: 12건
  - 진짜 해석 차이: 2건

  모집단 추정으로 실질 일치는 약 96%다. 그래서 관계 재현은 방향 반대·끝 범위 차이를 허용하는 지표(원문 천장 86%, 지문별 81~91%)로 잰다. 관계 유형 일치는 재현된 관계 쌍 안에서 잰다.
- 선지 고리 보존 실패 9건(106회 확인 중: 법인 P5-6, 정보 비대칭 P4-3 ×2, mRNA P2-7 ×2, 플라스틱 P5-6·P5-12, 경마식 보도 P2-4 ×2)은 모두 IoU 0.39~0.48이다. 노드가 사라진 것이 아니라 회차마다 명제를 나누는 크기가 달라서 생긴 실패다. 100%는 노드의 분할·병합을 대응으로 인정할 때만 달성할 수 있다.

### 성립 기준 (초안, 천장 반영)

- T1 2편 모두:
  - 노드 대응 ≥ 90%(사상표 기준, 천장 97%)
  - 관계 재현(방향 반대·끝 범위 차이 허용) ≥ 같은 지문 원문 회차 간 값(81~91%)에서 10%p 뺀 값. 미달 관계는 표본을 내용으로 판정한다(묶음·병합 표현 인정)
  - 재현된 관계 쌍의 유형 일치 ≥ 85%(천장 94%, 지금 분류 지시문 v3로 원문 회차 간 값을 다시 재면 갱신)
  - 선지 고리 보존 100%(노드의 분할·병합을 대응으로 인정)
  - 출처 없는 사실 0건, 표현 거리 기준 통과
- 더 나은 비교(권고): 생성 지문도 지도를 3회 만들어 "원 뼈대 ↔ 새 지도" 일치가 "원문 회차 간" 일치의 범위 안에 드는지 본다. 고정 숫자보다 이 비교를 주 기준으로 삼는다.
- 사용자 판정 수능다움 ≥ 3 평균.

## 4. 한계 (알고 시작할 것)

- **〈보기〉 적용형(고난도 3점)**: 새 〈보기〉 사례를 만들어야 해서 지도만으로 부족하다. E1·E2 모두 범위 밖. 다음 단계 별도 설계.
- **계산형 과학 지문**: 수치 정합까지 맞춰야 한다. E2 파일럿에서 표면 장력은 정성 구조만 옮기고, 수치가 필요한 고리는 관찰 항목으로 남긴다.
- **규모**: 동결 분석 골드는 십여 지문(UI 4, calibration 6, 세트 E 4 등), 비틂 목록은 오답 약 100개를 기준으로 만들었다. 선지 연결 동결본은 UI 6지문과 세트 E 4지문 80선지다. 분포 추정이 거칠다.
- **난이도**: 학생 데이터 없이는 보정 불가. 이번 실험은 정확성·타당성만 본다.
- **문학**: 이 방식(명제 지도 기반)은 통하지 않는다.
- **저작권**: "구조는 보호되지 않는다"는 단순화다. 세부 구성·순서를 그대로 옮기면 비문언적 유사성 다툼이 있을 수 있어, 상업적 사용 전 법률 확인이 필요하다.
- **E1 단독의 저작권 효과**: 기출 지문 위 새 문항은 문항만 바뀌고 지문은 남는다. 완전한 대안은 E2.
- **기출 자체의 결함**: 회사법 13번 ②처럼 결함 선지가 있으므로(D-0196), 실제 기출을 "정답"으로 두지 않고 블라인드 비교 대상 중 하나로만 쓴다.

## 8. 열린 질문 (결정 기록 때 정할 것)

1. 성립 기준 숫자(2·3절 초안)를 그대로 쓸지. E2는 고정 숫자 대신 "원문 회차 간 범위 안" 비교를 주 기준으로 할지.
2. 다중 모델 풀이에 다른 공급자 모델을 넣을지(비용·외부 전송 범위).
3. E2 사실 출처로 무엇을 허용할지(교과서만 / 공공 백과 포함).
4. 생성 문항을 SNS 테스트에 쓸 때의 기준(E1·E2 결과 뒤 별도 결정).
5. 출처 추측 판정자를 누구로 할지(사용자 제외). 구하지 못하면 그 항목을 뺀다.
