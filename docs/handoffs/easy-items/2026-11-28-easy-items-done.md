## 2. 세트로 묶을 때 지켜야 할 것

1. **같은 지문 문항끼리 겹치지 않게.**
   - 앞 문항 선지를 "이미 쓴 선지"로 넘긴다(내용 일치·밑줄).
   - 어휘는 "이미 고른 낱말"을 넘긴다. vocab-b 에서 같은 지문 두 어휘 문항이 '잃었다'를 둘 다 고른 일이 있었다.
2. **지문 표시가 겹치지 않게.**
   - 밑줄 문항은 ㉠·㉡, 어휘는 ⓐ~ⓔ, 어려운 문항은 〈보기〉 또는 [A]를 쓴다.
   - 한 지문판에 모든 표시를 합치고, 표시 구절끼리 겹치지 않는지 확인한다.
   - 표시 구절은 지문에 딱 한 번 나오는 것이어야 한다(밑줄 ul-c 실패 원인).
3. **수능 순서.** 내용 일치 → 밑줄 이해 → (어려운 3점 〈보기〉) → 어휘. 4문항 세트 기준. 정확한 자리 배치는 `set-pattern.md`(기출 세트 틀) 참고.
4. **어휘 꼴 B(바꿔 쓰기)는 사람이 함께 본다**(D-0240 3절). 세트 시험 보고서에 꼴 B 문항을 따로 표시한다.

## 3. 알게 된 것 (다음 일에 도움)

- **평가자 한계:** 평가자가 평가원 기출을 알아본다(출처 맞히기 8개 중 6개). 기출 지문 위 시험은 점수가 후할 수 있으니 "우리 지문 시험"을 꼭 거친다. 같은 문항 점수도 실행마다 0.25~0.5 흔들린다(기출 수소 1.5 → 1.0 → 0.75).
- **"적절한 것" 발문이 늘 약한 곳이었다.** 오답이 지문 문장 끝을 뒤집으면 "너무 쉬움"이 나온다. 기출은 관계(범위·조건·역할)나 문장 안쪽(짝 순서·주체·목적)을 비튼다.
- **표시 자리(밑줄·ⓐ)는 생성기가 골라도 된다.** 단 "지문에 딱 한 번"과 "정의·설명 자리" 조건이 필요하다.
- **make_blind 는 선지를 출처와 글자 단위로 대조한다**(match-b 경로 실수 뒤 모든 CLI에 넣음).

## 4. 남은 것

- (가)(나) 비교 첫 문항: 두 편짜리 지문이 생기면.
- 어휘 두 낱말 짝 꼴(평가원 20 중 3): 다루지 않음.
- 출처를 가린 기출로 "기출 알아보기" 효과 재기: 꼴 B 판단과 세트 시험 해석에 도움(제안만, 비용 거의 0).
- "이유" 발문 밑줄 문항은 블라인드로 따로 재지 않았다.
