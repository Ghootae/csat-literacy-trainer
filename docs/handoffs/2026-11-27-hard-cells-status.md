## 3. 칸마다 남은 약점·주의

| 칸 | 남은 약점·주의 |
|---|---|
| 과학 표 | v6 이전 기준으로만 확정. A형 깊이 보류. |
| 과학 사례 | 생성 6개 모두 ㉯(〈보기〉 없이 지워지는 선지 2개). 시험 지문이 고체 촉매 하나뿐(지문 닫음). 깊은 과학 지문(예: 플라스틱)에서 다시 볼 후보. |
| 과학 실험 | 1지문(표면 장력)·B형만. A형 기출 없음. |
| 과학 그래프 | 생성 그래프가 곡선·교점형이 아님(곧은 선·꺾은선). |
| 인문·사회 사례 A형 | 보통 기출 수준(1점대). 상위(2점)는 공손룡 옛 A 하나. 미끼·단계 수·상위 특성 4개 모두 점수를 설명 못 함 → 상위 노리기는 보류(후보: 짝 카드 단독 재측정 0원, 후보 여럿 고르기 ~$2). |
| 인문 관점 | 경계 통과. 새 A형은 '기본 구분 확인 수준'(1.0), B형이 받침. |
| 사회 관점 | L3(생성 지문) 미검증. 기출 앵커 일부 (가)(나)·[A] 표시 빠짐. |
| 사회 표 | 대조 기출 조세 12가 회차마다 흔들림. |
| 사회 그래프 | L2 앵커 3개뿐. |

공통: 거의 모든 칸이 지문 1편 표본. 낮은 문항의 반복 이유는 ㉲(지문 한 문장 대입)과 ㉯(〈보기〉 없이 풀림)이고, 이 둘은 기출 1점대 문항에도 흔하다.
판정 기준이 칸마다 4-2·4-3·4-4로 섞여 있다. 4-3(절대 1.5)으로 통과한 칸은 4-4로 다시 재도 통과일 가능성이 크다(4-3이 더 엄격).
