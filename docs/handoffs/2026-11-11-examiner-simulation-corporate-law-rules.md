# 출제자 시뮬레이션 1: 법인 지문 → 출제 규칙 후보

- 날짜: 2026-11-11 · 시뮬레이션: Ghootae(평가원 출제자 빙의) · 정리: 웹 스레드
- 대상: 법인 지문 작성 과정 + 기출 13번(〈보기〉, 적절하지 않은 것, 정답 ②) 출제 과정
- 상태: 지문 1개에서 나온 후보. 과학형·인문형 지문으로 확인 전.

## 1. 13번이 만들어진 순서 (요약)

1. 목표: 가장 어려운 문항. 자리 = 앞 문단의 "법인 자산 운용 주체" 개념과 뒤 문단의 "주식회사 자산" 개념이 만나는 곳.
2. 〈보기〉 1차: 이익 분배 재원이 줄어 배당을 보류한 상황(용어 대신 정의로 서술) → 선지 ① (참).
3. 개념 하나 더 필요 → 운용 권한. 자연스럽게 안 붙어서 병렬로 추가: 설립자 갑이 자신이 출연했던 부동산을 기부(“개인 것”이라는 착각 유도).
4. ②: 법인격 부여 대상 + 운용 권한의 근거 + 개인 출연을 한 문장에 겹치고, "주주들에 **의해**"로 주체 관계를 비틂 → 참으로 만들 수 없어서 정답.
5. ③: 〈보기〉의 막힌 길(이익 잉여금) → 다른 길(자본 거래). 부정형은 너무 쉬워서 참으로 둠.
6. ④: 남은 개념(자본금). 부정형("그래도 자본금은 못 쓴다")은 "원칙적으로 감액 금지"가 받쳐 줘서 좋은 후보였지만, 정답이 이미 ②라 참으로 둠.
7. ⑤: 남은 문단(실행 요건, 외부 유출 → 주주 총회). 같은 착각(갑의 것)을 다른 각도로 공격. 부정형은 상식으로 틀려서 버리고 참으로 둠.

## 2. 규칙 후보

### 지문 단계
1. 난도는 소재에서 먼저 정한다(용어가 어렵고 구조가 복잡한 영역).
2. 두 기준으로 나뉘는 분류(사단/재단 × 영리/비영리)를 깔아 둔다. 조합이 문제 재료가 된다.
3. 한 대상이 두 분류에 동시에 속하게 쓴다(주식회사 = 영리 + 사단). 한쪽만 비틀 수 있다.
4. 서로 헷갈리는 용어를 한 문단에 묶는다(자본금·이익 잉여금·자본 잉여금).
5. 고난도 자리 = 멀리 떨어진 문단의 일반 원리와 세부가 만나는 곳.

### 〈보기〉 단계
6. 〈보기〉에는 지문 용어를 쓰지 않고 정의를 풀어 쓴다. 학생이 지문 개념으로 되돌려 옮겨야 한다. (P1에서 빠졌던 단계)
7. 〈보기〉 문장 하나하나가 선지의 고리다.
8. 〈보기〉는 매끄러운 이야기가 아니라 필요한 개념 고리의 모음이다. 안 붙으면 병렬로 붙인다.
9. 〈보기〉 디테일은 특정 오해를 일부러 부르도록 고른다(개인 출연 → "갑의 것").
10. 같은 오해를 두 선지에서 다른 각도로 공격한다(② 권한·법인격, ⑤ 처분 절차).

### 선지 단계
11. 지문 핵심 개념·문단의 체크리스트를 두고, 선지들이 고루 덮게 한다.
12. 참 선지도 단순 확인으로 두지 않는다. 〈보기〉 표현을 지문 개념으로 옮기는 한두 단계를 요구한다(③ "설립 목적 달성" → 영리 = 경제적 이익).
13. 어려운 선지는 학생이 섞기 쉬운 지문 내용 2~3개를 한 문장에 겹치고, 조사·주체 관계 같은 작은 표현으로 비튼다.
14. 거짓 선지 채택 기준:
    - 부정어만 붙여 바로 틀린 게 보이면 버린다(③).
    - 상식만으로 틀린 게 보이면 버린다. 지문 이해를 검증하지 못한다(⑤).
    - **좋은 거짓 선지 = 지문 한 문장만 읽으면 참처럼 보이고, 두 문장을 통합해야 거짓이 되는 선지**(④ 부정형: "원칙적 감액 금지"만 보면 참, "손실 보전에 자본금 사용"까지 보면 거짓).
15. 선지의 정오는 미리 정하지 않는다. 참으로 먼저 쓰고, 위 기준을 통과하는 거짓 버전이 있을 때만 거짓 후보로 둔다.
16. 정답은 마지막에 고른다. 참으로 만들 수 없는 선지, 또는 가장 좋은 거짓 후보가 정답이 된다.
17. (주의) 오류를 여러 개 겹친 정답 선지는 각 오류가 지문 문장으로 분명히 반박되어야 한다. 하나라도 해석에 따라 맞을 수 있으면 출제 오류성 모호함이 생긴다(13번 ② 사례).

## 3. P1 생성기와의 차이

| | P1 생성기 | 출제자 |
|---|---|---|
| 출발점 | 규칙 하나 + 값 | 지문에서 섞기 쉬운 개념 쌍, 먼 문단 연결 지점 |
| 상황 | 변수 이름과 값을 그대로 줌 | 용어를 정의로 풀어 쓰고, 오해를 부르는 디테일을 넣음 |
| 선지 범위 | 같은 규칙·계산 반복 | 개념·문단 체크리스트를 고루 덮음 |
| 거짓 선지 | 계산 단계마다 비틀기 유형 배정(방향 뒤집기 등) | 부정·상식형은 버리고, "한 문장 참 / 두 문장 통합 거짓"만 채택 |
| 정답 | 처음부터 정함 | 마지막에 고름 |
