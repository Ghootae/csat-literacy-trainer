- **기출 대조 결과는 생성물과 나란히 써야 한다.** "기출 16편이 원칙을 지킨다"라고만 쓰자 Ghootae가 "그럼 v3.1도 문제없는 것 아니냐"로 읽었다(13:54). 기출 쪽과 생성물 쪽 수치를 한 표에 둔다.
- **수리 단계가 좋은 문항을 단순하게 만들 수 있다.** e3가 '거꾸로 짐작하기' 선지를 지름길로 오탐했다. 수리 전 판을 블라인드에 넣는 규칙 덕분에 드러났다.
- **웹은 CLI 보고를 기다리지 않고 Mac 파일을 직접 읽어 확인할 수 있다**(device_stage_files). 평가 원문도 웹이 다시 센다.
- **웹이 지문을 고르는 단계는 실험 관문이다.** 자동 파이프라인으로 가려면 이를 대신할 검사가 필요하다(3절 4번).
- **Ghootae는 생성 지문을 직접 읽고 기출 유사성을 의심했다.** 생성 지문을 보여 줄 때는 기출 겹침 검사 범위(158세트)와 그 밖의 한계를 함께 밝힌다.
