# 웹 검토: P1 생성 문항 7개 퀄리티

- 날짜: 2026-11-11 · 작성: 웹 스레드 "원리 적용 구조 이슈 검토"
- 대상: `REVIEW-p1-items.md`(법인 a·b, 표면 장력 a·b, 오디오 b, 플라스틱 a·b. 오디오 a는 열린 자리 없음으로 미생성)
- 성격: 웹의 의견. 최종 "깊다" 판정(D-0215 (라))은 Ghootae가 한다.

## 0. 결론

- **정확성은 좋다.** 7문항 모두 정답 키를 직접 계산해 확인했고, 맞다. 지문 밖 지식도 쓰지 않았다. 지시문 제약(〈보기〉 정합, 부정 발문 1회, 계산 단계 기록)도 지켰다. 파이프라인 자체는 작동한다.
- **깊이는 기출에 못 미친다.** 웹 기준으로 "기출 15번만큼 생각하게 만든다"고 볼 문항은 없다. 그나마 가까운 것은 표면 장력 b와 표면 장력 a다.
- 원인은 하나로 모인다. **상황이 규칙의 변수 값을 그대로 건네준다.** 기출의 깊이는 대부분 "상황의 특징을 규칙의 변수로 옮기는 단계"에서 나오는데, P1은 그 단계를 생성기가 대신 해 버렸다.

## 1. 핵심 문제: "번역 단계"가 빠졌다

같은 지문의 기출과 나란히 보면 차이가 분명하다.

| 기출 | 상황이 주는 것 | 학생이 해야 하는 번역 |
|---|---|---|
| 표면 장력 15 | 두 기포가 합쳐져 더 큰 기포가 됨 | "더 큰 기포" → 반지름↑, "구성 물질 같음" → 표면 장력 같음 |
| 표면 장력 16 | 잉크가 더 끈적해짐, 밀도 2배·지름 ½ | "끈적" → 점도↑, 밀도×지름 곱 → 상쇄되어 그대로 |
| 플라스틱 10 | 가지 친 구조 / 직선형 구조 | 가지 → 조밀 배열 어려움 → 결정 영역↓ → 물성 |
| 법인 13 | 적자 누적, 이익 분배 재원 감소 | 재원 → 이익 잉여금, 분배 → 배당 요건 |

| P1 | 상황이 주는 것 | 번역 |
|---|---|---|
| 플라스틱 a·b | 결정 영역 20%→40%, 25% 대 55% | 없음. 규칙의 변수 이름을 그대로 줌 |
| 표면 장력 a | 표면 장력이 절반, 반지름 같음 | 없음 |
| 표면 장력 b | 표면 장력 2배, 점도 2배, 오네소르게 수 0.05·2.0 | 없음 |
| 오디오 b | 소리 크기·차폐 문턱값 수치 | 없음(뺄셈) |
| 법인 a·b | 주식 수·액면가·잉여금 금액 | 없음(곱셈·나눗셈) |

그래서 P1 문항은 "규칙 문장을 찾아 방향대로 읽거나 산수를 하면" 풀린다. 플라스틱 a·b는 사실상 규칙 한 문장을 다섯 조각으로 나눈 내용 확인 문항이다. 판정자 기준으로도 STATED에 가깝게 나올 가능성이 크다.

## 2. 그 밖의 문제

1. **산수 의존.** 법인 a·b, 표면 장력 a, 오디오 b는 정오가 계산 결과에 달려 있다(1,300만 원, 102, 20% 대 25%). 수능 독서는 수치를 쓰더라도 방향·대소 판단이 중심이다(기출 17의 표도 크기 비교 수준). 지금 형태는 국어 문항이라기보다 산수 문항에 가깝다. 법인 b ④(증가분이 "증자 후 자본금의 25%"인가)는 국어 능력이 아니라 분모를 헷갈리게 하는 함정이다.
2. **규칙을 하나만 쓴다.** 기출 15는 라플라스 식과 "공기는 압력 높은 곳 → 낮은 곳"을, 16③은 세 변수의 곱을 엮는다. P1은 대부분 규칙 하나로 끝난다. 표면 장력 b(오네소르게 수 방향 → 안정 범위 → 결과)만 두 규칙을 잇는다.
3. **a와 b가 겹친다.** 법인 a·b는 둘 다 "무상 증자 → 자본금 계산", 플라스틱 a·b는 둘 다 "결정 영역 비율 비교"다. 또 a는 "지문 속 상황"이어야 하는데, 법인 a·표면 장력 a·플라스틱 a 모두 발문 안에 새 수치 사례를 넣었다. 사실상 〈보기〉를 발문에 옮긴 형태라 a형의 정의(지문이 깔아 둔 상황)가 지켜지지 않았다.
4. **선지 구성 결함.**
   - 표면 장력 b ③("안정적 인쇄 가능")과 ④("위성 방울 발생")는 서로 모순이다. 거짓이 하나뿐인 발문에서 정답이 둘 중 하나로 좁혀진다.
   - 플라스틱 a 정답 ③("밀도도 두 배가 되었다고 볼 수는 없다")은 "지문이 비례를 말하지 않았다"는 부재 추론이다. 계산이 아니라 6.3에서 논의한 "지문에 없는 주장" 유형이다.
   - 법인 a ①②(자본금이 300만 원, 분배 주식이 1만 주)는 계산 없이도 터무니없어 매력도가 0에 가깝다.
5. **기출과 닮음.** 오디오 b는 기출 17(소리 A~D, 크기와 차폐 문턱값)의 축소판이고, 표면 장력 b는 기출 16(오네소르게 수, 점도 변화 → 노즐 밖으로 못 나옴)과 같은 축이다. 기출 겹침 검사 결과와 대조해 볼 것.

## 3. 그래도 좋은 점

- 표면 장력 a ②("내부 압력이 절반")는 "압력 차이"와 "내부 압력"을 혼동하게 하는 개념 함정이다. 기출 15의 오답과 같은 종류다. 이런 오답이 더 많아야 한다.
- 법인 a는 "무상 증자는 자산 총 규모 불변"과 "자본금은 늘어난다"의 긴장을 건드린다. 기출 12①과 같은 포인트다. 산수로 감싸지 않았다면 좋은 문항이 됐을 것이다.
- 표면 장력 b는 "방향 → 범위 → 결과"의 2단 추론이 있다. 7문항 중 구조가 가장 기출에 가깝다.

## 4. 문항별 웹 판정 (참고용)

| 문항 | 웹 의견 | 이유 한 줄 |
|---|---|---|
| 법인 a | 아니다 | 산수 문항. 무상 증자 → 자본금 증가 포인트는 좋음 |
| 법인 b | 아니다 | a와 같은 계산, 분모 함정 |
| 표면 장력 a | 경계 | 변수 직접 제시 + 산수. 다만 ② 개념 함정은 좋음 |
| 표면 장력 b | 경계(가장 나음) | 2단 추론. ③·④ 모순 결함, 기출 16과 같은 축 |
| 오디오 b | 아니다~경계 | 기출 17 축소판, 개념 함정 없이 뺄셈·정렬 |
| 플라스틱 a | 아니다 | 규칙 한 문장 쪼개 읽기. 정답이 부재 추론 |
| 플라스틱 b | 아니다 | a와 같은 내용 |

## 5. 다음 수 (실패 단계 = 단계 2 상황 설계)

제안서 5절 대응표에 없던 새 실패 유형이다. "상황이 변수 값을 직접 제시함."

1. **SITUATION 지시문 수정(v2):**
   - 상황에는 규칙의 변수 이름(결정 영역 비율, 표면 장력, 점도 등)을 직접 쓰지 않는다. 대신 **관찰 가능한 특징·사건**으로 준다(예: "가지 친 구조", "더 끈적해짐", "두 기포가 합쳐짐").
   - 계산표 첫 단계는 반드시 "특징 → 변수" 번역 단계다. 그 근거도 지문 구절이어야 한다(예: "끈적끈적할수록 점도가 크다").
   - 산수 계산을 정오의 근거로 삼지 않는다. 수치는 크기 비교·방향 판단에만 쓴다.
   - 규칙 두 개 이상을 잇거나, 변수 두 개 이상이 함께 바뀌어 상쇄·강화되는 상황을 우선한다(기출 16③ 유형).
2. **WRITE 지시문 보강:** 정답과 오답이 서로 직접 모순되는 짝을 만들지 않는다. 오답의 절반 이상은 "개념 혼동형"(압력 차와 내부 압력, 원인과 결과, 두 대상 바꾸기)으로 만든다.
3. **a형 재정의:** 발문에 새 수치 사례를 넣으면 a가 아니다. 열린 자리가 없으면 만들지 않는 것이 맞다(오디오 a처럼).
4. 판정자 구조 판정 결과가 나오면, 위 "번역 단계 없음"이 APPLIED 판정에서 어떻게 나왔는지 함께 본다. 만약 이런 문항이 APPLIED로 판정된다면, 기준표가 "깊이"를 충분히 가르지 못한다는 뜻이다. 그럴 경우 "번역 단계 유무"를 따로 기록하는 필드를 검토한다.
