# 출제자 시뮬레이션 기록 템플릿

- 지문:
- 날짜:
- 이 지문의 기출 문항을 이미 본 적이 있는가: 예 / 아니오

## A. 지문을 읽고 (문항 만들기 전)

1. 이 지문에서 꼭 물어야 할 핵심 개념·원리 (2~4개)와 고른 이유
2. 학생이 헷갈릴 만한 곳 (오해 예상)
   - 예: 비슷한 두 개념, 방향이 반대인 규칙, 예외 조건, 원인과 결과의 순서
3. 서로 부딪히거나 엮이는 규칙 쌍 (함께 물으면 깊어지는 곳)

## B. 문항마다 (문항 수만큼 반복)

- 문항 번호·유형: 내용 일치 / ㉠ 이해 / 비교 / 〈보기〉 적용 / 기타
1. 출제 포인트: 이 문항으로 무엇을 확인하려는가
2. 상황 (있으면): 학생에게 무엇을 주고, 학생이 그것을 지문의 어떤 개념으로 옮겨야 하는가
3. 정답 설계: 정답을 맞히려면 어떤 생각을 몇 단계 거쳐야 하는가
4. 오답 설계: 선지마다 노린 오해 한 줄
   - ①
   - ②
   - ③
   - ④
   - ⑤
5. **버린 안과 버린 이유** (가장 중요)
   - 예: "이 선지는 지문 한 줄로 바로 풀려서 뺌", "이 상황은 지문 밖 지식이 필요해서 뺌"

## C. 다 만든 뒤 (기출과 비교)

1. 실제 기출과 같은 포인트를 골랐나, 다른 포인트를 골랐나
2. 기출이 더 잘한 점 / 내가 더 나은 점
3. 이번 지문에서 얻은 출제 규칙 후보 (한 줄씩)
