# 문항 재생성 방향 검토 — 인간 보고서

## 1. 개요

### 1) 목적
현재 원리 적용형 생성 파일럿 P1이 문항 재생성의 목표에 맞게 진행되는지, 설계·저장된 산출물·검증 결과를 검토했다. 새 생성이나 외부 API 호출은 하지 않았다. 이 검토는 기존 판정의 재실행이 아니며, 아래 권고는 사용자 미승인 제안이다.

### 2) 결과
**전반적인 방향은 맞다. 다만 지금 확인된 것은 원리 적용형 문항의 생성 가능성이고, 기출 수준의 깊이나 새로운 추론 구조를 안정적으로 만든다는 증거는 아직 부족하다.**

좋은 선택은 세 가지다. 첫째, E1(골드 기반 생성 비교)에서 골드의 이점이 관찰되지 않자 그 실험을 닫았다. 둘째, 원리 적용형을 고난도 전체가 아닌 유형 하나로 제한했다. 셋째, 규칙 추출 → 상황·계산표 → 선지 집필로 나누고, 정답을 숨긴 별도 풀이 검증을 두었다. 어떤 단계에서 문제가 생겼는지 찾기 좋은 구조다.

저장 결과에서 P1은 계획 8문항 중 7문항이 생성됐다. 오디오의 보기 없는 문항은 재료 부족으로 건너뛰었다. 7개 모두 저장된 풀이·구조 판정상 조건 (가)~(다)를 충족한다. 이는 사용자 ‘깊다’ 판단까지 포함한 최종 성공 판정은 아니다. 또한 풀이 검토의 주석에는 해석 전제가 남아 있다.

### 3) 다음 스텝
새로 많이 만들기보다 현재 7개를 **정확성, 필요한 추론, 기출과의 의미 중복**으로 나눠 검토하는 것이 우선이다. 현행 통과 기준은 소급 변경하지 않고, 보조 검토 결과를 옆에 붙일 것을 권한다.

## 2. 본문

### 2.1 원리 적용의 개수와 깊이가 혼동될 수 있음 (미해결)
플라스틱 b의 선지에는 “결정 영역이 차지하는 비율이 더 높은 B가 A보다 밀도가 높고 단단하겠군”이 있다. 보기의 A 25%, B 55%는 크기 비교만 필요하다. 다른 선지도 같은 비율 차이에 물성의 증감 방향을 적용한다. 두 판정자는 다섯 선지를 모두 APPLIED(구체 상황에 원리를 적용해야 판단되는 선지)로 분류했다.

이는 원리 적용형이라는 판정과 양립하지만, 다섯 번의 적용이 깊은 추론 하나를 뜻하지는 않는다. **가장 쉬운 정답 도달 경로에서 반드시 연결해야 하는 관계가 무엇인지**를 함께 확인해야 한다. 생성기가 계산표를 여러 단계로 썼다는 사실만으로 깊이를 인정해서도 안 된다.

### 2.2 기출 겹침 0건의 의미가 제한적임 (미해결)
법인 a 정답은 “무상 증자를 마친 뒤 자본금은 증자 전보다 30% 증가한 1,300만 원이 된다.”이다. 기출 12번 ①도 무상 증자 후 자본금 총량이 유지된다는 주장을 판단하게 한다. 법인 b 역시 무상 증자와 자본금 변화를 수치화한다.

자동 검사는 문자열 유사도 임계값을 넘는 항목을 표시한다. 표시 0건은 의미 중복 없음의 증거가 아니다. 기호로 적힌 기출과 풀어 쓴 생성문은 특히 표현이 다르다. 법인 a·b는 새로운 문장과 계산 조건을 갖지만, 핵심 상황·결론의 재사용 후보로 따로 표시해야 한다. 기존 결정 D-0215(파일럿 범위와 통과 조건)의 원문 대조 요구를 실제로 마무리할 필요가 있다.

### 2.3 보기 없는 문항도 새 조건을 발문에 넣음 (판단 필요)
표면 장력 a는 발문에 내부 압력 104·외부 압력 100·표면 장력 절반·반지름 고정 조건을 추가했다. 법인 a도 주식 수·액면가·증자 금액을 추가한다.

따라서 a(보기 없음)와 b(보기 있음)의 결과를 비교할 때 ‘기존 상황 대 새 상황’으로만 해석하기 어렵다. 기존 소재에 새 수치를 붙인 경우와 완전히 새 사례를 나눠 기록하면 된다. 이 관측만으로 현재 문항을 탈락시키거나 지시문을 바꾸자는 뜻은 아니다.

### 2.4 자동 통과 이후에도 사람 검토가 필요함 (미해결)
표면 장력 b는 저장된 풀이 판정이 OK이지만, 검토 주석에는 보기의 C가 범위 밖인 원인을 특정하지 않고 범위 초과 일반에 결과를 적용하는 읽기가 필요하다는 내용이 남아 있다. 결함 확정은 아니며 원문으로 해소할 경계다.

형식 검사 4건도 성격을 나눠 봐야 한다. 법인 a·표면 장력 a의 발문 끝 경고는 물음 뒤 단서가 붙은 탓이고, 오디오 b·표면 장력 b는 정답만 가장 길다는 경고다. 단순 문구 형식과 답 노출 가능성은 같은 문제로 취급하지 않는 편이 좋다.

### 2.5 다음 투자의 우선순위 (판단 필요)

| 방안 | 얻는 것 | 한계 | 의견 |
|---|---|---|---|
| 현재 7개 검토를 마무리 | 통과 이유·실패 원인·의미 중복을 구분 | 사람이 원문을 봐야 함 | 우선 추천 |
| 같은 4지문에서 생성 반복 | 출력 변동 확인 | 이미 보며 고친 표본이라 일반화 증거가 약함 | 이후 필요할 때 |
| 기준을 고정하고 새 지문에서 소규모 검증 | 다른 재료에서도 작동하는지 확인 | 새 실행 계획 필요 | 현재 검토 다음 |
| 곧바로 여러 유형·대량 생성 | 양적 확대 | 품질 기준의 빈틈까지 확대 | 아직 이르다 |

성공 기준 ‘8개 중 5개’는 유지한다. 생성되지 않은 1개를 빼고 분모를 7로 바꾸지 않는다. 생성된 7개 중의 품질과 계획 8개를 얼마나 다뤘는지를 따로 보고하면 된다. 원리 적용형의 성립과 실제 학생 난이도도 구분한다.
