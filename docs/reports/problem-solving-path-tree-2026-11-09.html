문제 풀이 행위 경로

진단 문제 풀이, 문항 하나 기준. 2026-11-09 결정안((나) + 버튼 둘 + 힌트) 반영. 문단 요약은 제외. 상태기계는 작업 브랜치 feedback.ts 기준으로 확인.

코드 모델 호출 없음, 서버 규칙 sol luna 호출 없음 학생 행동·표시 luna→sol 이번에 바뀜 새 새로 만듦 [범주 n] 결과 화면 범주(첫 응답 기준)

1. 첫 응답

지문의 모든 문항을 입력하고 "답 입력 마침"을 누르면, 아래의 판정, 사고 진단, 힌트 호출이 동시에 뒤에서 시작된다. 지문 판정이 모두 끝나면 1번 문항부터 피드백이 열린다.

  • 선지 선택 + 근거 방식 선택 학생
    • A. 근거 작성 → 코드 정답/오답 가르기
      • A1. 정답 → solluna→sol 선택 판정 (충분 / 부족 / 오류 / 판정 불가) + 교정 질문 생성
        • 충분 → "근거도 정확해" 끝 호출 없음 [범주 1 근거 있는 정답]
        • 부족 → 안내 한 줄 → 설명 보기 여부 학생 [범주 2 근거 약한 정답]
          • 본다 → 마지막 설명 solluna→sol 정답 설명 작성 (미리 생성) → "이해됐어?" 자기 보고
          • 안 본다 → 끝
          사고 진단 sol 뒤에서 (충분이 아닌 정답 대상)
        • 오류 → 리뷰 R (아래 3절) [범주 3 근거가 틀린 정답]
        • 판정 불가 → 안내 + 마지막 설명 sol [범주 1로 표시, 기록에 보류 표시 (제안)]
        • 원자료·정답 기준 문제 → "우리가 확인할게" 다음 문항 코드
      • A2. 오답 → sol 선택 판정 + 교정 질문 생성 + 사고 진단 sol 뒤에서 [범주 6 오답]
        • 오류 있음 → 리뷰 R (아래 3절)
        • 판정 불가 → 마지막 설명 sol
        • 근거는 타당한데 오답 → 문항 확인 표시 코드
    • B. "확실해요" 새 → 코드 정답/오답 가르기
      • B1. 정답 → 끝, 판정 없음 호출 없음 [범주 4 확신 정답]
      • B2. 오답 → "정답이 아니야, 근거 적어 줄래?" 학생 [범주 6 오답]
        • 근거 작성 → A2와 같음 sol
        • 근거 미제출 → 마지막 설명 sol
    • C. "잘은 모르겠지만 정답 같음" 새 → 코드 정답/오답 가르기
      • C1. 정답 → sol새 힌트 하나 생성 (짧은 전용 호출, 뒤에서) [범주 5 확신 없이 맞힘]
        • 힌트 보기 → 근거 작성 학생 → sol 선택 판정
          • 충분 → 끝
          • 부족·오류 → 마지막 설명 sol 이때만 생성
        • 건너뛰기 → 마지막 설명 sol
      • C2. 오답 → B2와 같음 [범주 6 오답]

2. 리뷰 R (교정 대화)

첫 판정의 오류마다 sol이 미리 만든 질문을 차례로 낸다. 오류 순서는 코드가 정한다(대상 → 선지 읽기 → 내용).

  • 교정 질문 표시 호출 없음 (sol이 판정 때 만든 질문)
    • 학생 답 → luna 질문에 대한 답 판정 (오류마다 고침/남음, 새 오류)
      • 남은 오류 있음 → 다음 교정 질문 (반복)
      • 모두 고침
        • 정답 문항 (A1 오류에서 온 경우) → "설명 볼래?"
          • 본다 → 마지막 설명 solluna→sol
          • 그만 → 끝
        • 오답 문항 → "다시 골라 볼래?"
          • 재선택 (마지막 선택) → 코드 정답/오답
            • 정답 + 근거 → solluna→sol 선택 판정 (질문은 더 없음)
              • 충분 → 끝
              • 부족·오류 → 마지막 설명 solluna→sol
            • 정답 + 근거 없음 → 끝
            • 오답 + 근거 → sol 선택 판정 → 마지막 설명 sol
            • 오답 + 근거 없음 → 마지막 설명 sol
          • 설명 요청 → 마지막 설명 sol
      • 못 고침 → 마지막 설명 sol 정답 공개·코칭
    • 건너뛰기 → 마지막 설명 sol

마지막 설명 뒤에는 늘 "이해됐어?" 자기 보고로 끝난다.

4. 메모

  • luna가 남는 곳은 리뷰 중 교정 답 판정 하나뿐이다.
  • 근거가 충분한 정답(범주 1)과 확신 정답(범주 4)은 마지막 설명과 사고 진단을 만들지 않는다. 그래서 앞서 드린 세트당 비용 추정(정답마다 설명을 sol로 만든다고 본 값)은 조금 높게 잡혔다. 실제로는 세트당 약 $0.02~0.05 낮을 수 있다.
  • 범주는 첫 응답으로 정한다. 리뷰나 재선택 결과는 범주를 바꾸지 않고, 서비스 반응 자료로 따로 기록한다.
  • 미정: 판정 불가 정답 표시(제안: 범주 1 + 보류 표시), C1 힌트 규칙과 힌트 뒤 근거의 판정 기준.
