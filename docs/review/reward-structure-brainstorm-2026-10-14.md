# 보상 구조 브레인스토밍 (2026-10-14, 보류)

상태: 사용자와 자유 논의한 아이디어 목록이다. 채택·검증된 설계가 아니며, 사용자 요청으로
나중에 다시 논의한다. 첫 타겟 결정만 [D-0125](../../memory/decisions/D-0125-first-target-top-tier-middle-school.md)로 확정했다.

## 출발점

- 사용자 문제 제기: 꾸준한 이용에는 정확성·일관성보다 보상 설계가 중요할 수 있다.
- Claude 의견: 정확성은 바닥, 보상은 곱셈이다. 보상을 강하게 걸수록 판정 오류(예: 공손룡12 과잉
  교정)의 비용이 커지므로 "보상을 무엇에 거느냐"가 먼저다. 정답 수·문단 PASS 수에 걸면 판정기
  공략(D-0012의 원문 상세 재현 우려)을 부른다.
- 보상보다 먼저 볼 후보: 제출 대기 중앙값 약 14초·최대 48.5초(`memory/CURRENT_STATE.md`, v5
  48세션 기록). 외부 학생 검증에서 이탈 지점을 먼저 기록하자는 제안.

## 타겟 (사용자 제시)

- 문해력을 걱정하는 중등 학부모, 일찍 수능을 완성하려는 상위권 중등, 고1 일반. 고3은 이런 훈련을
  하기엔 바쁘다고 봄.
- 마케팅 구상: "6개월 훈련 뒤 중3이 수능 1등급" 같은 스토리.
- 첫 집중: 상위권 중등(D-0125). 지문 레벨을 고1 학평까지 넓힐 필요(사용자 의견, 작업은 나중).

## 구조 아이디어

- 결제자(학부모)와 사용자(아이)가 다르므로 보상을 두 갈래로 설계.
- 학년 사다리 = 레벨업: 고1 학평 → 고2 학평 → 고3 학평·모평 → 수능. 진도 자체가 보상이자
  마케팅 문장.
- 월간 실전 측정: 시간 제한·도움 없는 기출 세트, 회차 등급컷으로 추정 등급. 훈련 대화(LLM 판정,
  변동 있음)와 분리해 숫자는 실전 측정에서만 나오게 한다.
- 시작 시점 진단 측정이 없으면 "원래 잘하던 아이" 반론을 막을 수 없다.

## 아이 쪽 아이디어

1. 함정 도감: 생각을 고칠 때마다 함정 유형 카드 수집.
2. 함정 면역: 같은 유형 함정을 나중에 안 빠지고 통과하면 면역 도장. 처음 틀림이 아니라 전이를
   보상해 일부러 틀리는 공략을 막는다. (Claude 대표 추천: 1+2)
   - 연결 자산: 함정 지도·사고 진단·정답 경로 요소 작업(Q-0034, D-0109, D-0119~D-0124).
3. 고3 선배 비교: 공개 문항 정답률 활용("고3 정답률 41%, 너는 한 번에").
4. AI에게 이의 제기: 판정이 틀렸다고 근거로 반박해 맞으면 최대 보상. 판정 오류를 몰입·개선
   데이터로 전환.
5. 출제자 모드: 매력적 오답 선지 만들기, AI나 다른 학생을 속이면 점수.
6. 배경지식 지도: 경제·법·과학기술·철학·예술 영역 채우기.
7. 독해 속도 개인 기록.
8. 숨은 킬러 지문: 변동 보상, 역대 오답률 최상위 지문.

## 학부모 쪽 아이디어

9. 생각이 바뀐 장면 리포트: 실제 대화 인용으로 "이번 주 고친 생각".
10. 저녁 식탁 질문: 이번 주 지문을 소재로 부모가 물어볼 질문 제공.
11. 학년 진도선: "중3 ○월, 고2 학평 지문 단계".
- 아이에게 무엇이 공유되는지 보이게 해 감시감을 줄인다.

## 피할 것

- 끊기면 0이 되는 손실형 스트릭(쉬어도 유지되는 장치 정도만).
- 정답 수 포인트.
- 전체 공개 랭킹(친구끼리 작은 리그 정도).

## 미리 확인할 것 (미검증)

- "1등급"은 국어 전체 등급이다. 비문학만 훈련하므로 주장 범위를 좁히거나 다른 영역이 필요하다.
  - 사용자 입장(2026-10-14): 문학 등 다른 분야 확장은 당분간 고려하지 않는다(LLM 분석이 상당히
    도전적일 것으로 봄). 따라서 마케팅 주장은 독서(비문학) 범위로 좁히는 쪽이 된다.
- 평가원·교육청 기출의 상업적 이용 승인 조건(Claude가 확인하지 않음).
- 성과 광고 문구의 근거 자료 보존.

## 재개 시 첫 질문

- 대표 보상 축을 수집형(도감·면역), 경쟁형(리그·고3 비교), 성장형(사다리·실전 측정) 중 무엇으로
  둘 것인가, 혼자 하는 게임인가 친구와 하는 게임인가.

## 추가 논의: 문단 요약과 문제 풀이 분리 (2026-10-14, 논의만·미결정)

결정 기록으로 남기지 않고 논의로만 둔다(사용자 요청). 현재 학생용 흐름(문단 PASS 또는 진행 선택
뒤 문항)은 바뀌지 않았다.

### 사용자 구상

- 문단 요약은 원하는 학생·약한 학생용 별도 코스, 또는 레벨 테스트의 일환 + 훈련 코스.
- 레벨 테스트: 문단 요약만 받고 피드백 없음. 에이전트+사람 검토로 정확하게 평가.
- 문단 요약 훈련: 실시간 판정·피드백의 흔들림은 어느 정도 감수. 대신 자료를 수집해 주기적으로
  에이전트+사람 검토로 변화를 정확하게 추적.
- 훈련을 마쳤거나 레벨이 높은 학생: 문단 요약을 완전히 빼고, 틀리면 관련 부분을 다시 읽게 하는
  것으로 충분.
- 효과: 문단 요약과 문제 풀이를 분리하고, 가장 약한 문단 판정을 방어.

### Claude 의견

- 원리: 판정이 결과를 오래 좌우하는 곳은 느리더라도 정확하게(오프라인·사람), 흔들려도 되는 곳은
  빠르게(실시간 모델). 훈련 대화와 월간 실전 측정 분리와 같은 원리.
- 피드백 없는 레벨 테스트는 대기 시간·실시간 정확도 부담이 없고, Q-0001이 레벨 테스트의 전제에서
  빠진다.
- 상위권 경로는 v5의 직접 교정 질문·지문 표시(D-0118)가 이미 있어 문단 관문 제거가 주 변경이다.
- 문단 골드는 모든 지문이 아니라 레벨 테스트·훈련용 선별 지문에만 필요해져 학평 확장이 쉬워진다.
- 이전 제안(레벨은 학평 객관식, 요약은 원인 진단)은 사용자 구상(요약 + 사람 검토)으로 대체 논의됨.
  쓰기 능력이 독해 측정에 섞이는 문제는 남는다.

### 보완 후보

1. 사람 검토로 결과가 늦는 공백: 기본 레벨로 바로 시작하고 다음 날 학부모에게 레벨 리포트(첫 보상
   장면).
2. 변화 추적은 같은 자로: 학평 정답률로 난도를 맞춘 평행 지문 세트를 미리 짝짓는다.
3. 사람 검토 비용: 초기 전수 검토 → 이후 에이전트·사람 불일치나 경계 사례만 사람 검토. 초기 기록이
   전환 기준 데이터가 된다.

```
신규 학생 → 레벨 테스트(문단 요약, 피드백 없음, 에이전트+사람 검토)
   ├ 약함 → 문단 요약 훈련(실시간, 흔들림 감수)
   │          └ 주기적 재측정(평행 지문, 에이전트+사람) → 졸업
   └ 강함/졸업 → 문제 풀이 전용(문단 관문 없음, 틀리면 관련 부분 다시 읽기)
```

## 추가 논의: 다른 영역 범위와 문법 DB (2026-10-14, 논의만·미결정)

결정 기록 없음. 현재 범위는 독서(비문학)이며 아래는 나중에 다시 꺼낼 때의 출발점이다.

### 확인한 사실: 2028학년도 수능 개편

- 2028학년도부터 국어 선택과목 폐지. 모든 학생이 '화법과 언어', '독서와 작문', '문학' 범위의 공통
  문항을 푼다. 2029학년도도 같은 체제, 45문항 80분(2026-08 보도).
- 2026년 중3은 2030학년도 수능 응시 → 타겟 전원이 새 체제. 언어는 선택이 아니라 공통 범위다.
- 출처: [서울신문 2023-10-11](https://www.seoul.co.kr/news/society/education-news/2023/10/11/20231011003006),
  [교육부 2028 대입 개편 확정안 PDF](https://files-scs.pstatic.net/2024/07/02/Ic4S8r8egU/[교육부+12-27(수)+브리핑시(11시)+보도자료]+(별첨)+미래+사회를+대비하는+2028+대학입시제도+개편+확정안.pdf),
  [한국경제 2026-08](https://www.hankyung.com/article/2026081878891).
- 함의: "국어 전체 1등급" 주장에는 언어·문학이 모두 필요하다. 문법 DB는 2022 개정 '화법과 언어'
  기준으로 만든다.

### 영역별 Claude 의견

| 영역 | 지금 엔진 적합도 | 상위권 학습 가치 | 의견 |
|---|---|---|---|
| 화법·작문, 매체 | 높음(근거가 주어진 대본·자료 안) | 낮음(속도 과목) | 저비용 확장 후보 |
| 문학 | 현대 갈래·〈보기〉 문항은 비교적 가까움 | 높음 | 사용자 입장: 당분간 고려 안 함 |
| 언어(문법) | 지문형·〈보기〉형은 높음, 배경지식형 단독 문항은 낮음 | 높음 | 아래 DB 설계가 필요 |

- 문학 정정: 수능 문학 문항은 이의 신청을 견디도록 작품·〈보기〉 근거로 정형화돼 있다(사용자 지적).
  위험은 인상 근거의 충분성 경계, 외부 배경 투사, 고전 갈래 고어 해석에 몰린다.
- 비문학이 공식 해설 고정으로 잘 된 이유는 판단에 필요한 정보가 입력 안에 모두 있기 때문이다.
  배경지식형 문법은 해설 밖 학생 주장 검증과 교정 설명 생성이 모델 지식에 의존한다.

### 문법 DB 구상 (사용자 제안: 고등 문법 규칙 DB + RAG)

- 효과 기대: 문제 풀이 판정 오류 감소, DB로 학생 지식망의 구멍을 효율적으로 메움.
- Claude 의견:
  - DB 주입은 규칙 혼동은 줄이지만 특정 단어에 규칙을 적용하는 계산 오류는 못 줄인다. 그래서 두 층:
    결정적 규칙(음운 변동·표준 발음 등)은 실행 가능한 코드, 경계 판단 규칙(품사·문장 성분·보조용언·
    형태소 경계)은 정의·조건·예·반례·흔한 오개념 DB.
  - 실시간 유사도 검색 대신 문항별 필요 개념을 사람이 미리 연결(source-direct 원칙 확장).
  - 선수 개념 연결로 오답의 빠진 선수 개념을 거슬러 찾고 그 구멍만 메운다. 이러면 "문법 처방은 개념
    강의라 제품 밖"이라는 반론이 뒤집힌다.
  - 문법은 개념이 이산적이라 학생 사고 추적(Q-0034)을 비문학보다 깨끗하게 해볼 수 있는 영역일 수 있다.
  - 위험: DB 정확성(학교문법·학자 이견·교육과정 차이 → 전문가 검수), 교과서 문장 사용 금지, 개념 수백 개 규모.

### 교재 스캔 + 재구성 안 (사용자 제안)

- Claude 의견: 속도는 빠르나 법적 위험이 가장 큰 길. 규칙 자체는 사실이라 자유롭지만 설명 문장·
  정리 표·예문 선택·배열(편집저작물)과 DB제작자 권리가 걸릴 수 있고, LLM 재구성도 원본에 가까우면
  2차적 저작물 여지가 있다(법률 전문가 확인 필요). 스캔이 아끼는 건 개념 목록 작성 시간 정도이고
  검수·경계 사례 선정·선수 관계는 그대로 남는다.
- 권고: 교재는 범위·경계 사례 유형을 대조하는 체크리스트로만 쓰고, 설명은 공공 자료 근거로 새로
  쓰며, 예문은 직접 만들어 코드·사전으로 검증하고, 항목별 출처를 기록한다.
- 먼저 할 작은 확인: 음운 변동 한 단원(수십 개념)만 직접 작성 → 학평 음운 문항에 해설 밖 틀린
  주장을 담은 가상 답변 → DB 유무에 따른 판정기의 지어낸 문법 설명 횟수 비교.

## 추가 논의: 독서만으로 IRT 등급 추정 (2026-10-14, 논의만·미결정)

사용자 제기: 독서 영역만으로도 IRT로 등급을 '추정'할 수 있지 않은가.

### Claude 의견

- 1단계, 독서 실력의 전국 위치(가능): 수능·모평·학평의 공개 문항별 정답률로 문항 난도를 전국
  모집단 기준으로 매기고, 라쉬 계열 모형으로 "수능 독서 문항 기준 전국 상위 X%"를 추정한다.
  외부 비율 베이지안 아이디어(`memory/checkpoints/2026-10-14-bayesian-external-rates-idea.md`)와 같은 계열.
  - 한계: 공개 정답률만으로는 난도만 얻고 변별도는 없다(응답 원자료 없음 → 능력 분포 가정 아래 근사).
    자사 응답으로 보정하면 상위권 쏠림 편향이 생긴다.
  - 한 회차 독서는 약 17문항이라 한 번 측정 오차가 크다. 월별 누적이나 적응형 출제로 줄인다.
- 2단계, 국어 등급으로 옮기기(약함): 등급은 국어 전체 점수 기준이다. 상위권 중3은 고등 문법·고전
  갈래를 아직 배우지 않았을 가능성이 커서 독서 기반 국어 등급 추정은 체계적으로 높게 나올 수 있다.
- 측정 시험 구분: 고1 학평 상위 4%와 수능 상위 4%는 모집단이 다르다(수능은 재수생 포함). "수능
  1등급 수준" 주장은 수능·모평 문항으로 측정하고, 학평은 훈련·중간 측정용으로 쓴다.
- 정정: 앞 절의 "학평 회차 등급컷으로 추정 등급"은 등급컷이 국어 전체 점수 기준이라 독서만 푼
  결과에 그대로 적용할 수 없다.

### 주장별 근거 강도

| 주장 | 근거 강도 |
|---|---|
| "수능 독서 문항 기준 전국 상위 X% 수준" | 강함(IRT 추정, 오차 범위 표기) |
| "독서는 1등급권" | 중간(위 추정을 상위 4%에 대응) |
| "국어 1등급" | 약함(실제 모의고사 전 영역 점수 필요) |

- 권고: 제품·학부모 리포트에는 첫째·둘째 문장을 쓰고, "국어 1등급"은 실제 학평·모평 성적표로만
  말한다.
