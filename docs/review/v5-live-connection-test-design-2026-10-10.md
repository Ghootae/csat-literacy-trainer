# v5 개발자 경로 실모델 확인 시험 설계안

- 날짜: 2026-10-10
- 작성: Claude
- 대상 구현: `docs/handoffs/2026-10-10-v5-developer-path-connection.md`(D-0112), 테스트 342/342 통과 상태
- 상태: 설계안(사용자 승인 전). 승인 뒤 실행기 구현은 코덱스 인계, 실행 전 별도 실행 승인.

## 1. 목적

모의 응답 테스트가 확인하지 못한 세 가지를 실제 `gpt-6-luna`·`gpt-6.1-sol`로 확인한다.

1. 새 코드 경로가 실제 응답으로 끝까지 이어지는가: 주장 분리(`studentClaims`) 계약, 재시도, 판정+종료 설명 2호출, 호출별 모델 배정.
2. 처음 쓰는 종료 설명의 품질: 재선택 오답(`RESELECTION_WRONG`), 근거 확인 불가(`RATIONALE_UNVERIFIABLE`), 재선택 정답·근거 오류(`NO_CORRECTION`).
3. 학생이 기다리는 시간: 한 제출에서 판정+종료 설명이 이어질 때의 소요 시간.

## 2. 방법

- 실행은 운영 코드 그대로: `ProblemFeedbackV4Controller` + `OpenAIFeedbackEvaluator`(라우팅·지시문 기본값). 실험용 지시문 바꿔 끼우기 없음.
- 시작 상태 두 가지:
  - **이어 하기**: REPAIR 시험의 첫 판정 세션(`docs/experiments/v5-repair-test-2026-10-10/variants.json`의 `sessions`, 교정 질문 대기 상태)을 불러와 교정 답부터 실제로 진행한다. 교정 질문 문구가 고정되므로 미리 쓴 답이 질문과 맞는다. 불러온 세션에는 새 필드 `pendingEnd: null`만 더한다.
  - **처음부터**: 선지·근거 제출부터 전부 실제로 진행한다(첫 선택 판정의 주장 분리 계약을 운영 코드로 확인). 교정 질문이 실행마다 달라질 수 있어 경로가 예정과 다르면 '경로 이탈'로 기록한다(실패로 세지 않고 보고).
- 학생 입력은 아래 표에 고정한다. 각 경로 2회 반복.

## 3. 경로와 학생 입력

문항: 표면 장력 q16(정답 ③), 도파민 q13(정답 ②), 정보 비대칭 q13(정답 ⑤), mRNA q19(정답 ⑤).

- L11은 판정기가 근거에서 오류를 찾아 교정 질문으로 가면 경로 이탈로 기록한다(어느 쪽이 맞는지는 검토에서 본다).
- L16·L17은 교정 질문이 둘 이상 나오거나 예정에 없는 단계가 오면 경로 이탈로 기록하고 거기서 멈춘다. 질문 문구는 자동으로 판단하지 않는다: 실제 문구를 기록하고 고정 답으로 계속 진행하며, 질문과 답이 맞는지는 실행 뒤 검토에서 본다(2026-10-10 Claude 보완, 코덱스 지적).
- 모든 학생 입력은 실행 전 고정(FROZEN 해시)한다.

## 4. 자동 검사 (칸마다)

- 경로·단계 전이·종료 사유·결과(outcome)가 예정과 같은가(이탈은 따로 표시).
- 호출마다 실제 모델이 배정표와 같은가(`attempts[].model`).
- 공개 메시지에 공식 해설 문장이 없는가. 오답 종료에만 "정답은 N번입니다."가 있고 정답 종료에는 없는가. `answerRevealed`가 맞는가.
- 공개 뷰(`feedbackPublicView`)에 `officialExplanation`·`answer.explanation`이 없는가.
- 종료 설명 정적 검사: 내부 식별자 없음, 손상 문자열 없음, 학생 3인칭("학생은/학생이") 여부, 해요체 아닌 종결.
- 재시도 횟수·사유(주장 계약 실패 포함), 호출별 소요 시간, 한 제출의 총 소요 시간.

## 5. 의미 검토

- 대상: 종료 설명이 생성된 칸 전부(L1·L2·L4~L13·L15·L17 × 2회 = 28칸 안팎).
- 기준: 지금까지와 같다(원문 정확성·과장 없음, 학생 발화 인용·귀속, 필수 요소, 종료 사유와의 정합, 형식).
  - 오답: 처음 생각 중 틀린 곳(근거 없음·확인 불가면 단정하지 않음) + 맞는 내용 + 정답 이유.
  - 정답: 선택 인정 + 근거의 틀린 곳 + 맞는 근거로 답 잇기.
  - 새 종료 사유는 특히 본다: 재선택 오답에서 두 번째 선택의 생각을 짚는가, 근거 확인 불가에서 학생 생각을 지어내지 않는가, NO_CORRECTION에서 교정 질문이 있었던 것처럼 쓰지 않는가.
- 절차: Claude 판정 고정 → GPT 블라인드 검토(코덱스, 읽기 전용) → 불일치는 문항 원문으로 판정.

## 6. 규모·비용·한도

- 17경로 × 2회 = 34세션. 예상 호출: sol 약 24회, luna 약 46회(재시도 제외).
- 예상 비용: sol 약 0.35달러(선택 판정 약 0.03, 종료 설명 약 0.01달러/회), luna 약 0.15달러. 합계 약 0.5달러.
- 한도: sol 40요청·1.2달러, luna 80요청·0.3달러. 한도에 닿으면 멈추고 보고.
- 기록: 요청 원장(START/END), 세션 기록(JSONL), 칸별 결과 파일. 출력 위치 `docs/experiments/v5-live-connection-2026-10-10/`.
- 보안: `node --env-file=.env`로만 실행, 키 출력 금지.

## 7. 판정 기준(통과 조건)

- 경로 이탈을 뺀 칸에서 자동 검사 위반 0(모델 배정·공식 해설 비공개·정답 번호 규칙·공개 뷰).
- 종료 설명 의미 검토에서 원문과 어긋나는 내용(FAIL) 0. 경미(MINOR)는 목록으로 보고.
- 경로 이탈·재시도·소요 시간은 수치로 보고(통과 조건 아님).
