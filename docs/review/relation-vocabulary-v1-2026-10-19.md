# 관계 유형 1차 목록 (Claude, 16지문 표본)

- 날짜: 2026-10-19
- 상태: **검증 후 목록(2026-10-20, 4갈래 18유형 + 기타).** [D-0147](../../memory/decisions/D-0147-relation-vocabulary-sampling.md) 산출물. 17유형으로 시작해 검증 6지문(Claude 블라인드 일치 85%, 차순위 포함 98%, 기타 1.3%, §6) 뒤 병렬·공통을 더했다. 분류 지시문: `docs/experiments/relation-classify-2026-10-19/CLASSIFY-PROMPT-v3.md`.
- 재료: 16지문 지도 48개의 관계 1,607개([표본 정리](../experiments/analysis-map-sample-2026-10-19/SAMPLE-SUMMARY.md)). 지문마다 r1 지도의 관계를 앞뒤 명제·노드 문장과 함께 읽었고(공손룡·법인·정보 비대칭·표면장력·공포 소구·노자·쇤베르크·노비제 전체, 나머지는 드문 이름 위주), r2·r3은 이름으로 확인했다. 2지문 초안 메모는 참고하지 않았다.
- 쓰임: 학생 이해 지문 축 (나) "관계 유형 + 층". 관계 판정 결과를 유형별·갈래별로 모은다.

## 1. 읽으며 확인한 것 (목록 설계의 전제)

1. **모델이 붙인 이름은 유형의 근거가 못 된다.** 같은 이름이 서로 다른 관계에 붙는다.
   - "인과": 실제 작용(표면 장력 감소 → 폐포 확장 쉬움)에도, 정의에서 따라 나오는 판단(법인 R7 "비영리 법인이므로 이익을 추구하지 않는다")에도 붙는다. 뒤의 것은 근거·도출이다.
   - "대조": 같은 기준에서 대상이 다른 것(D1 흥분성 vs D2 억제성), 두 학자의 견해 차이(노자 R38 한비자 가변 vs 오징 불변), 한 대상 안의 어긋남(노비제 R21 "권리 보장을 주장하면서도 민을 무지하다고 봄")에 모두 붙는다. 셋은 학생에게 요구하는 이해가 다르다.
   - 따라서 유형은 **생성 뒤 별도 단계에서 관계의 앞뒤 문장을 보고** 고른다(지도 지시문 무수정, 입장 표시와 같은 방식).
2. **인문·예술·역사 지문은 관점 사이 관계가 중심이다.** 공통점·동의·계승·해석·비판이 많고, 과학·기술 지문에는 거의 없다. 과학·기술은 작용·과정·조건, 법·경제는 근거·원칙과 예외·계산이 많다.
3. **(가)(나) 사이 관계는 거의 모두 관점 갈래**(관점 차이, 공통, 해석)다. 다만 지도가 이 관계를 지도당 0~3개만 잡는다(별도 문제, §5).

## 2. 목록 (4갈래 18유형 + 기타)

### 가. 내용 — 지문 속 대상·현상이 어떻게 이어지는가

| 유형 | 정의 | 예 |
|---|---|---|
| **인과·작용** | A가 실제로 B를 일으키거나 B로 이어진다. 한쪽을 얻으면 다른 쪽을 잃는 상충도 여기 | 계면 활성제 → 표면 장력 감소(표면장력 R7), 반음 간격 배열 → 조성 경계 모호(쇤베르크 R9), 승인 시간 단축 → 보안성 저하(블록체인 R19 상충) |

## 3. 판별 순서 (헷갈릴 때)

위에서부터 처음 "예"가 나오는 유형을 고른다.

1. 양쪽이 **서로 다른 인물·이론·입장**인가?
   - 한쪽이 다른 쪽을 부정·문제 삼으면 → 비판·반박
   - 한쪽이 다른 쪽을 특정 틀로 읽거나 가치를 매기면 → 해석·평가
   - 같은 견해거나 받아들이면 → 공통·수용
   - 다른 견해를 나란히 놓으면 → 관점 차이
2. 한쪽이 다른 쪽의 **배경·계기**인가? → 배경·계기
3. **화제·논의·시대가 넘어가는가?** → 전개·전환
4. **문제 → 대응**인가? → 문제·대응
5. **A인데도 B / 원칙과 예외 / 한계**인가? → 양보·한계
6. **앞의 원리를 다른 사례·영역에 쓰는가?** → 원리 적용
7. **B가 A의 사례·세부**인가(또는 사례 → 일반 성질)? → 구체화·예시
8. **이름 붙이기·뜻 풀이·식·재진술**인가? → 정의·명명
9. A 때문에 B가 **참이라고 판단·설명**하는가(따라서, ~이므로, 계산하면)? → 근거·도출
10. A가 B를 **실제로 일으키는가**? → 인과·작용
11. 경우·조건에 따라 **갈리는가**? → 조건·분기
12. **목적을 위한 수단**인가? → 수단·목적
13. **차례**만 있는가? → 과정·순서
14. 같은 기준에서 **값이 다른가**? → 대조
15. 같은 층위의 두 항목을 **나란히 놓거나 공통점**으로 묶는가? → 병렬·공통
16. **종류·구성 요소**인가? → 분류·구성

핵심 경계:
- **대조 / 관점 차이 / 양보·한계.** 다른 것이 대상이면 대조, 사람의 견해면 관점 차이, 한 대상·한 사람 안에서 어긋나면 양보·한계.
- **병렬·공통 / 공통·수용 / 분류·구성.** 대상들이 같은 층위에서 나란하거나 공통점을 가지면 병렬·공통, 인물·이론의 견해가 같으면 공통·수용, 한쪽이 다른 쪽의 하위 항목이면 분류·구성이나 구체화·예시.
- **근거·도출 / 인과·작용.** 판단·설명의 근거면 근거·도출(정의에서 따라 나오는 것, 계산 포함), 세계 속 실제 작용이면 인과·작용.
- **원리 적용 / 구체화·예시.** 같은 대상을 더 자세히 풀면 구체화, 앞의 원리를 다른 대상에 가져가면 원리 적용.
- **비판·반박 / 관점 차이.** 글이 한쪽을 다른 쪽에 대한 공격으로 제시하면 비판·반박, 나란히 비교만 하면 관점 차이.

## 4. 표본에서의 대략 분포 (이름 기준 자동 배정, 참고용)

자유 이름에 낱말 규칙을 대 본 결과다. 이름이 유형을 잘못 말하는 경우(§1)가 많아 **정확한 분포가 아니며**, 관점 차이는 모델이 대부분 "대조"라 불러 크게 과소 집계된다. 규칙에 걸리지 않은 이름은 1,607개 중 46개(2.9%, 연구 공백과 초점·법제화·귀착 결정 등)이고, 문맥으로 보면 대부분 위 유형에 들어간다(예: 연구 공백과 초점 → 배경·계기, 법제화 → 전개·전환).

| 갈래 | 비율(대략) |
|---|---|
| 내용 | 약 33% (인과·작용 13, 대조 10, 과정 4, 조건 2, 수단·목적 2, 분류 일부) |
| 논증 | 약 48% (구체화·예시 19, 근거·도출 15, 원리 적용 5, 양보·한계 3, 문제·대응 3, 정의·명명 3) |
| 관점 | 약 11% (비판·반박 4, 공통·수용 3, 해석·평가 3, 관점 차이 1 이상) |
| 흐름 | 약 8% (전개·전환 6, 배경·계기 2) |

## 5. 열린 점

1. **학생 지문 단위로는 갈래(4)가 먼저, 유형(17)은 표본이 쌓인 뒤.** 학생 한 명이 한 지문에서 만나는 관계는 30~40개라 유형별 성공률은 지문 몇 개를 모아야 안정된다. "논의 전환에 약하다" 같은 이미지는 관점·흐름 갈래로 먼저 볼 수 있다.
2. **(가)(나) 사이 관계는 따로 다루지 않는다(닫힘).** 지도가 구역 사이 관계를 지도당 0~3개만 잡지만 보강 단계를 두지 않는다. 사용자(2026-10-19): "(가), (나)와 같은 복합 지문의 관계 분석은 안해도 될 거 같아." → 확인: 복합 지문은 그대로 쓰고 각 글 안의 관계는 지금처럼 분석하되, 구역 사이 관계 보강만 하지 않는다.
3. **상충**을 인과·작용에 넣었다. 수능에서 자주 묻는 형태라 검증 지문에서 많이 나오면 따로 뺄지 다시 본다.
4. **방향.** 구체화·예시와 일반화, 근거와 결론처럼 같은 유형이 방향만 다른 경우가 있다. 유형은 방향과 무관하게 붙이고, 판정에 방향이 필요하면 from/to를 그대로 쓴다.
5. **검증 방법(3단계) 제안.** 분류는 생성 뒤 별도 단계(모델에 목록·판별 순서·관계 앞뒤 문장을 주고 유형 1개 선택, 확신 낮으면 기타)로 한다. 검증 6지문 지도(각 3회)를 만들고, 분류 결과에서 ① 기타 비율(목표 5% 이하), ② Claude 무작위 표본 검토 일치율, ③ 같은 지문 다른 지도 사이 유형 분포 안정성을 본다. 분류 지시문을 이 16지문으로 다듬을 경우 검증 지문으로는 다듬지 않는다.

## 6. 검증 결과 (2026-10-20)

- 분류는 생성 뒤 별도 단계(`scripts/run-relation-classify.mjs`, 관계 이름 제외)로 한다. 지시문을 16지문으로 두 번 다듬었다(`docs/experiments/relation-classify-2026-10-19/tune-v1/REVIEW.md`, `tune-v2/REVIEW.md`): v1의 계통적 오류(판별 1의 견해 관계 과흡수, 판별 4의 근거 흡수, "바탕으로"의 수단·목적)를 v2가 고쳤고, 같은 지도 재분류에서 약 7%는 실행마다 흔들린다.
- 검증 6지문(지도 18개, 관계 623개)에 v2를 그대로 적용: Claude 블라인드 표본 60개와 1순위 일치 85%, 차순위 포함 98%, 기타 1.3%, 지도 3개 사이 갈래 분포 차이(TVD) 0.02~0.17(`docs/experiments/relation-classify-2026-10-19/heldout/VALIDATION.md`).
- 기타 8건 중 6건이 병렬·공통 계열이라 이 유형을 더했다(다듬기에서 정한 추가 조건). 검증 지문을 보고 더했으므로 이 유형을 포함한 v3의 성능은 새 지문에서 따로 확인한다.
- 실제 분포(검증 6지문, v2): 내용 30.8%, 논증 58.7%, 관점 4.8%, 흐름 4.3%, 기타 1.3%. §4의 이름 기준 추정보다 논증이 많고 관점·흐름이 적다(관점은 인물·이론이 나오는 지문에만 있다).
