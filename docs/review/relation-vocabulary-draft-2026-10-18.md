## 1. 목록 (10 + 기타)

두 갈래로 나눈다. **내용 관계**는 지문 속 대상·현상이 어떻게 이어지는지, **논의 흐름**은 글이 어떻게 전개되는지다.

| 갈래 | 유형 | 정의 | 공손룡 예 | 도파민 예 |
|---|---|---|---|---|
| 내용 | **인과·작용** | A가 실제로 B를 일으키거나 B로 이어진다(~하면 ~된다) | 같은 명으로 다른 실 지시 → 구별 사라짐(R6) | 창백핵 억제 → 시상으로 가바 분비 없음(R22), 분비된 도파민 → 자가 수용체 결합(R13 되먹임) |
| 내용 | **과정·순서** | A 다음에 B가 온다. 일으킨다는 주장 없이 단계의 차례만 | – | 티로신 → 레보도파 → 도파민(R5), 저장 → 분비(R7) |
| 내용 | **조건·분기** | 조건·경우에 따라 결과가 갈린다 | '새'가 대상 수에 따라 유명·사명(C5-5 내부) | DAT 있음/없음에 따라 분해 위치가 다름(R18), 재사용 또는 분해(R17) |

## 2. 판별 순서 (헷갈릴 때)

위에서부터 처음 "예"가 나오는 유형을 고른다.

1. 서로 다른 **입장·주장**이 맞서는가? → 반박·대립
2. B가 A의 **사례나 세부**인가? → 구체화·예시
3. 화제·관점이 **다른 논의로 옮겨 가는가**? → 전환
4. A 때문에 B가 **참이라고 판단·설명**하는가(따라서, ~이므로, 그래서 ~할 수 있다)? → 근거·도출
5. A가 B를 **실제로 일으키는가**(~하면 ~된다)? → 인과·작용
6. 경우·조건에 따라 **갈리는가**? → 조건·분기
7. **목적을 위한 수단**인가? → 수단·목적
8. **시간 차례**만 있는가? → 과정·순서
9. 같은 기준에서 **값이 다른가**? → 대조
10. **종류·이름·구성**인가? → 분류·정의

핵심 경계 두 개:
- **근거·도출 vs 인과·작용.** "D1이 직접 경로에 밀집해 있으므로 도파민은 직접 경로를 활성화한다"는 설명(근거·도출). "선조체가 가바를 분비하면 창백핵이 억제된다"는 실제 작용(인과·작용). 과학 지문에서 모델이 "기작 근거", "분포 근거"라 부른 것은 근거·도출로 간다.
- **대조 vs 반박·대립.** 두 대상이 다른 것은 대조, 두 입장이 다투는 것은 반박·대립.

## 4. 열린 점

- 공손룡의 R22(5문단 분류 논의 → 4문단 일대일 부정, 모델 이름 "이론적 배경")는 근거·도출로도, 전환으로도 읽힌다. 판별 순서로는 3번(전환)에서 걸린다.
- "논의 전환"이라는 사용자 예를 이 목록으로 옮기면 반박·대립 + 전환 두 유형이다. 학생 지문에서 둘을 묶어 볼지 따로 볼지는 쓰임을 보며 정한다.
- 관계 유형을 지도 생성 때 바로 고르게 할지(지도 지시문 변경), 생성 뒤 별도 단계로 분류할지(입장 표시처럼)는 시험 설계에서 정한다. Claude 권고: 별도 단계(기준선 지도 지시문을 바꾸지 않음).
