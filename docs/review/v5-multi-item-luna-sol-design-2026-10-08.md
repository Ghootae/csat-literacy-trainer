## 3. 문항과 응답

| 문항 | 응답 | 기대값 구성 |
|---|---|---|
| 정보 비대칭 13 | I1~I6 | ERROR 2, SUPPORTED 2, UNKNOWN·INSUFFICIENT 1, UNKNOWN·INSUFFICIENT·ERROR 중 하나 1 |

| 도파민 13 | D1~D6 | ERROR 3, SUPPORTED 2(D6은 관계만 말한 짧은 근거, D-0085), UNKNOWN·INSUFFICIENT 1 |

### 3.2 mRNA 19번(그림 문항) 새 응답 6개 — **기대값 사용자 확인 필요**

발문은 적절하지 않은 것 고르기, 정답 ⑤(C5). 공식 해설: 투석은 pH를 높이고 높은 pH에서 이온화 지질은 중성이 되지만,
⑤의 소수성 약화와 더 작은 복합체 형성은 지문·보기에 근거가 없다. 그림은 두 용액이 Y자 미세관의 **서로 다른 입구**로 들어가 합류하는 과정도다.

| ID | 선택 | 응답 | 기대 | 확인하려는 것 |
|---|---|---|---|---|
| M1 | ⑤ | 투석으로 pH가 높아지면 이온화 지질이 중성이 된다는 건 지문에 있지만, 소수성이 약해져 인력이 줄고 더 작은 복합체가 생긴다는 내용은 지문에도 보기에도 없어요. 그래서 5번이 적절하지 않아요. | SUPPORTED | 정상 |
| M2 | ⑤ | pH가 높아지면 수소 이온 농도가 높아져서 이온화 지질이 양전하를 띠게 돼요. 그러니까 소수성이 약해진다는 5번은 틀렸어요. | ERROR(pH·수소 이온 방향) | 인과 방향 역전 |
| M3 | ⑤ | 그림을 보면 mRNA 용액과 에탄올 용액이 한 입구로 같이 들어가서 처음부터 섞여 있어요. 5번의 소수성이 약해져 더 작은 복합체가 생긴다는 건 지문에 근거가 없으니 틀렸어요. | ERROR(그림의 입구) | **그림을 읽어야만 잡히는 오류** |
| M4 | ③ | 이온화 지질은 pH가 높을 때 양전하를 띠니까, 산성 용액과 섞이면 양전하를 띤다는 3번이 적절하지 않아요. | ERROR(pH와 양이온화 방향) | 오답 선택 + 내용 오류 |
| M5 | ⑤ | 이온화 지질은 용액의 pH에 따라 양이온성이 달라져요. | UNKNOWN 또는 INSUFFICIENT | 참이지만 선지와 연결 없음 |
| M6 | ④ | 투석하면 pH가 높아져 수소 이온 농도가 낮아지고, 그러면 이온화 지질이 전기적으로 중성이 되니까 4번은 맞는 설명이에요. | SUPPORTED + 선택 불일치 질문 | 맞는 근거와 선택의 충돌(부정 발문) |

- M3: 운영 앱은 판정기 원자료에서 그림의 alt를 빼고 그림만 보낸다(`packages/app/src/server/content.ts` 132~139행). 실험도 같게 하므로
  M3은 그림을 실제로 읽어야만 잡히는 오류다(2026-10-08 Codex 구현 중 확인, 처음 설계의 "alt로도 잡힌다"는 걱정은 틀렸다).

## 5. 규모·비용·상한

- 30응답 × 3반복 × 2모델 = 180칸. 결론 독립 확인·형식 재시도를 포함해 약 200~230요청을 예상한다.
- 공손룡 실측(66칸 기준)으로 어림한 비용: luna 약 0.3~0.5달러, sol 약 2.5~4달러. 이미지·긴 해설이 있어 오차가 크다.
- 상한: luna 130요청·1.5달러, sol 130요청·6달러. 상한에 닿으면 멈추고 보고한다.
- 가격은 사용자가 준 2026-10-07 공식 가격을 쓴다(luna 입력 0.10·출력 0.50, sol 입력 2·출력 10달러/100만 토큰).

## 6. 지표

1. 자동: 라벨·단계 기대 일치(응답별·문항별·모델별), 형식 오류·재시도, 응답 시간(칸 중앙값·p90), 실제 비용.
2. 의미 검토(공손룡과 같은 P1~P4, Claude 먼저 고정 → GPT-6 Astra 블라인드):
   - P1 판정, P2 근거, P3 귀속, P4 오류 위치.
   - **새로 나눔:** P2 실패를 학생에게 보이는 칸(errors.description·question·selectionMismatchQuestion·coaching)과 내부 칸(reason·reconstructedPath·studentClaims.sourceBasis)으로 나눠 센다.
     luna의 약점이 학생에게 실제로 보이는지가 운영 판단의 핵심이다.
   - 교정 질문 품질(양자택일·예/아니오·정답 노출)은 따로 나열한다.
3. 공손룡 결과는 같은 기준으로 표에 함께 싣는다.
