# 학생 역할 시뮬레이션·기록 검토 기준 (2026-10-29)

- 사용자 승인(2026-10-28~29): Claude가 학생 입장에서 6개 지문 문단·문제에 다양한 응답을 넣어 검토. 0단계 저장 기록 검토 → 1단계 mRNA 시험 운영(상한 $10) → 2단계 나머지 5개 지문(재승인).
- 기준 버전: 문단 `paragraph-simple-holistic-v4.8`(10-28 채택, 그 전 기록은 v4.7), 문제 판정 `problem-feedback-v5.6` + 마지막 설명 레이아웃 v1(D-0184).

## Claude가 판정하는 것 (사례마다 해당 번호 표시)

판단 기준은 판정기가 정한 핵심 내용이 아니라 **원문**이다.

| 코드 | 무엇 | 예(실제) |
|---|---|---|
| A1 | 판정이 원문과 어긋남: 담은 것을 빠짐/오류로, 또는 빠진 것·틀린 것을 담음/정답 근거로 | — |
| A2 | 핵심 내용이 원문 세부까지 요구해, 결론으로 이어지는 관계는 담았는데 빠짐 판정 | mRNA 3문단 "서로 몰려" |
| A3 | 상위어·압축 표현을 부족으로 봄 | mRNA 5문단 "면역 반응" |
| B1 | 단계 사이 판정 뒤집힘(담음→빠짐) | mRNA 5문단(v4.7) |
| B2 | 학생이 이미 쓴 요소를 다시 묻는 질문 | mRNA 3문단 배열 전체 재질문 |
| C1 | 질문이 답을 흘림(학생이 쓰지 않은 답 개념어를 질문에 넣음) | v4.8 V2 5·8번 |
| C2 | 개념 이름 하나만 대도 답처럼 보이는 질문 | "인지질의 성질은 …에 어떻게 나타나?" |
| C3 | 질문이 실제 오류를 겨누지 않음 | mRNA 5문단 산도·pH 방향 |
| C4 | 한 질문에 두 가지를 물음 | — |
| D1 | 마무리가 맞는 방향의 덜 말한 답을 "다르다"고 부정 | mRNA 3문단 CLOSE_GAP |
| D2 | 마무리·설명이 원문과 다른 내용을 단정 | — |
| E1 | 내부 용어, 형식 위반, 화면 깨짐, 오류 화면, 재요청 실패 | — |
| E2 | 흐름 이상: 버튼·단계 전환·대기 문구·끝맺음 | — |

## 사용자에게 넘기는 것 (Claude 판정 안 함)

- 설명·질문이 학생에게 이해하기 쉬운지, 말투가 자연스러운지. 대표 사례를 모아 보여 준다.

## 기록 형식

사례 한 줄: `지문/문단(또는 문항·선지) · 세션 · 단계 · 코드 · 학생 말 · 피드백 발췌 · 원문 근거 · 한 줄 이유`. 보고는 코드별 건수 + 대표 사례 1~2개, 일반 규칙 수정 후보.
