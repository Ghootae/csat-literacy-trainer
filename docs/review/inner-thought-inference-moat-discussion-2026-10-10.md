# 학생 내적 사고 추론과 지문·문항 정량화: moat 논의 (2026-10-10)

상태: **논의 보류(parked)**. 사용자 결정에 따라 문단 요약·문제 풀이 파트 안정화 뒤 이어서
논의한다. 아래는 사용자 문제 제기와 Claude의 1차 의견이며, 채택된 정책이나 검증된 사실이
아니다. 관련 열린 질문: `memory/OPEN_QUESTIONS.md`의 Q-0034.

## 사용자 문제 제기

제품이 실제 moat를 가지려면 (1) 학생 내적 사고의 평가와 변화 추적, (2) 그를 위한 지문·문항의
정량적 평가 능력이 필요하다.

- 문단 요약: `지문 → (내적 사고) → 요약 → 평가`. 보유 자료는 지문·요약·평가이며, 여기서
  내적 사고를 유추할 수 있는가?
- 문제 풀이: `지문+문항 → (내적 사고) → 풀이 과정 → 평가 → 피드백`. 논리는 같고 더 복잡하다.

## Claude 1차 의견 (가설·제안, 미검증)

1. **수동 역추론은 식별 불가능에 가깝다.** 한 출력에 여러 사고가 대응한다. 예: 요약의 관계
   누락 = 미독해 / 비중요 판단 / 압축 선택. 문제 풀이에서는 단계 오귀속이 이미 관측됐다.
   - 정보 비대칭 13번: 최종 정답이지만 ④ 내용 오해가 수정되지 않았고, 판정기는
     `SELECTION_EXECUTION`으로 분류했다 (`memory/checkpoints/2026-10-01-information-asymmetry-q13-user-review.md`).
   - 공손룡 12번: 지시 대상/기호 위치 혼동이 내용 오류로 과잉 교정된 의심
     (`memory/checkpoints/2026-10-02-gongsun-q12-v4-user-review.md`).
2. **가능하게 하는 조건 세 가지** (교육측정의 증거 중심 설계·인지진단모형·지식 추적 계열).
   - ① 내적 사고를 유한한 가설 공간으로 정의: 문단은 명제 포착·관계 유형(인과·대조·조건·
     상하위)·왜곡 유형(주체 역전·극성 반전·범위 과잉 일반화·세부 수준 불일치), 문제는
     발문 극성 → 선지 명제 해석 → 근거 위치 → 대조 → 판정 중 끊긴 단계.
   - ② 지문·문항을 같은 좌표계로 정량화(Q-matrix: 각 문항이 요구하는 관계·단계). 이것이
     없으면 학생 약점과 문항 난도를 분리할 수 없으므로, 문항 정량화는 학생 상태 추정의
     전제 조건이다.
   - ③ 관찰이 아니라 실험: 남은 가설을 가르는 질문을 설계한다. 현행 진단 질문이 원형이나
     가설 공간과 명시적으로 연결돼 있지 않다.
3. **타당성 기준은 예측**: 추정한 상태가 같은 특성을 가진 미시행 문항의 반응을 예측해야
   실재하는 상태로 본다. 소수 학생의 think-aloud는 보조 기준점.
4. **moat 원천 가설**: LLM 판정 자체가 아니라 실제 학생 반응으로 보정된 문항 특성 지도,
   추적 질문 결과를 포함한 장기 학생 기록, 예측으로 검증된 오개념 분류 체계.
5. **현 프로젝트의 선행 병목**
   - 판정기 자체 신뢰도: 같은 경계 응답이 실행마다 `SUPPORTED`/`UNCERTAIN`으로 갈리는 변동이
     기록돼 있다 (`memory/CURRENT_STATE.md` 문제 풀이 대화 절). 도구 잡음 정량화가 먼저다.
   - 보정 데이터: 현재 사용 기록은 프로젝트 사용자 1인이며 외부 학생 검증 대기 상태다.

## 기존 설계와의 관계

`docs/STUDENT-STATE-MODEL-V1.md`는 학생의 실제 내적 상태를 추정하지 않는다고 명시한다. 이번
논의는 V1을 넘어서는 방향이므로, 재개 시 V1의 불변식(INDETERMINATE 처리, 도움 수준 분리 등)을
어떻게 계승·대체할지 먼저 정해야 한다.

## 재개 시 첫 제안 (미승인)

문제 풀이부터 단계별 오류 코드로 가설 공간 v0를 정의하고, 기존 6지문·6문항에 Q-matrix를
수작업으로 부여한 뒤 기존 판정 결과를 재태깅한다. 판정기의 단계 오귀속 빈도와 현 데이터로
구분 불가능한 단계를 확인해 외부 학생 실험 설계의 입력으로 쓴다.

## 추가 논의 (2026-10-14): 외부 정답률·선지 선택률의 베이지안 활용

상태: **아이디어 기록, 미착수**. 사용자 제기, Claude 의견. 채택된 정책이 아니다.

사용자 제기: 문항별 오답률·선지별 선택률이 있으면 베이지안 방식으로 학생의 전체 분포상 위치를 추정할 수 있지 않은가. 모집단 특성도 추론할 수 있지 않은가(막연한 아이디어).

| 아이디어 | Claude 판단 | 필요한 것·한계 |
|---|---|---|
| 학생의 전국 분포상 위치 | 가능(대략). 문항반응이론(라쉬) 계열. 오답 선지의 희소성까지 쓰면 더 정밀(명목 반응 모형) | 정답률만으로는 변별도를 몰라 같은 변별도 가정 필요. 외부 집계(메가스터디)는 이용자 표본이라 상향 편향 가능. 20~30문항 이상 누적 필요 |
| 함정·요소 판정의 베이지안화 | 가능, 가장 실용적. "3번 중 2번이면 확정" 같은 임의 기준을, 전국 함정 비율을 사전 분포로 둔 "평균보다 약할 확률"로 대체 | 흔한 함정(예: 13번 ② 28%) 1회는 약하게, 드문 함정 반복은 강하게 반영. 우리 진단 결과 + 외부 비율 |
| 모집단에게 어려운 특성 | 가능. 선지 선택률을 문항 지도 특성(노드 수·요소·함정 태그)에 회귀 | 문항 수십 개 이상의 지도 필요. 부수 효과: 노드 수 깊이 지표의 타당성 검증, LLM이 실패한 함정 강도 예측(D-0109)을 통계 모형으로 대체 |
| 모집단의 학생 유형(잠재 집단) | 외부 자료로는 불가. 비율은 주변 분포라 같은 학생이 여러 함정에 걸리는지 모름 | 우리 사용자의 학생별 응답 패턴 필요(잠재 집단 분석). 외부에 없는 자료라 moat 원천 |

Claude 권고 착수 순서(미승인): 문항 지도를 수십 개로 늘린 뒤 "모집단에게 어려운 특성" 회귀부터. 지도 확장이 다른 실험에도 필요하고 깊이 지표 검증을 함께 얻는다.
