## 1. 비틂 14종

★는 기존 한국어 이름을 학생용으로 바꾼 것이다.

| 코드 | 학생용 이름 | 한 줄 설명 | 예 (세트 E에 있으면 세트 E, 없으면 일반 예) |
|---|---|---|---|
| `NEGATION` | 긍정·부정 뒤집기 | 지문에서 '있다·된다·허용된다'고 한 것을 '없다·안 된다·금지된다'로, 또는 그 반대로 바꿨어. | 세트 E(오디오): 문턱값보다 작은 A는 들리지 않는데, 선지는 "A를 들을 수 있겠군" |
| `DIRECTION` | 방향 뒤집기 | 늘어남↔줄어듦, 이쪽→저쪽, 앞↔뒤처럼 변화나 관계의 방향을 반대로 바꿨어. | 일반: 작은 기포에서 큰 기포로 가는데, 선지는 "큰 기포에서 작은 기포로" |
| `SUBSTITUTION` | 요소 바꿔치기 | 지문에 나온 대상·물질·수단 하나를 다른 것으로 바꿔 넣었어. | 세트 E(오디오): 초기 녹음기는 아날로그로 저장했는데, 선지는 "디지털 신호로 저장한다" |
| `CONFLATION` | ★다른 두 가지를 같은 것으로 | 지문이 분명히 구별한 두 가지를 같은 것처럼 섞었어. | 일반: 자산 총액이 그대로라는 말을 자본금이 그대로라는 말로 |
| `CAUSE_SWAP` | 원인·근거 바꿔치기 | 결과는 맞게 썼는데, 그 결과의 원인이나 근거 자리에 다른 것을 넣었어. | 세트 E(오디오): 임계대역 폭은 차폐음의 주파수로 정해지는데, 선지는 차폐 문턱값으로 정해지는 것처럼 |
| `WRONG_REASON` | ★상관없는 두 사실 잇기 | 둘 다 지문에 있는 맞는 말인데, 원인과 결과가 아닌 두 사실을 원인과 결과처럼 이어 붙였어. | 일반: 효소가 있는 위치와 조절 방식의 차이는 둘 다 지문에 있지만, 선지는 위치 때문에 조절 방식이 다르다고 이음 |
| `CONDITION_SHIFT` | 조건 옮기기 | 어떤 조건·상황·시점에서만 맞는 내용을 다른 조건·상황·시점에 옮겨 놓았어. | 세트 E(오디오): 압축 전에는 비트를 고르게 나누는데, 선지는 "압축할 때 같은 개수의 비트가 할당되겠군" |
| `HOLDER_SWAP` | ★주장의 주인 바꾸기 | 한 사람·학파·이론의 주장을 다른 쪽의 주장인 것처럼 바꿨어. | 세트 E(의식과 인지): 객관주의의 '의식은 물질에 불과하다'는 생각을 ㉠의 주장으로 |
| `PAIR_SWAP` | ★두 대상의 특징 맞바꾸기 | 지문이 서로 맞세운 두 대상(㉠과 ㉡ 등)에서 한쪽의 특징을 다른 쪽에 붙였어. | 세트 E(플라스틱): 유연하고 충격에 강한 소재에 맞는 것은 ㉮인데, 선지는 ㉯ |
| `ABSOLUTIZE` | ★'모두·반드시'로 단정하기 | 대상은 그대로 두고 말을 바꿨어. '일부', '~할 수 있다', '~일 때'처럼 제한하는 말을 '모두', '반드시', '어떤 경우에도', '~만'으로. | 일반: 조건이 맞으면 허용된다는 말을 "어떠한 경우에도 금지된다"로 |
| `SCOPE_EXTEND` | 적용 범위 넓히기 | 대상을 넓혔어. 한쪽이나 한 영역에만 맞는 특징을 양쪽이나 다른 영역까지. | 세트 E(플라스틱): 성장하는 한쪽 끝에만 있는 불안정한 탄소를, 선지는 "양쪽 끝부분에서" |
| `DEGREE` | 정도 바꾸기 | 방향은 그대로 두고 정도만 바꿨어. | 일반: "조금 늘어난다"를 "크게 늘어난다"로 |
| `ADDED_CONTENT` | 없는 내용 덧붙이기 | 지문(〈보기〉 포함)에 없는 기능·원인·사실·단계를 덧붙였어. | 세트 E(의식과 인지): 지문에 없는 '의식이 세계를 구성한다'는 기능을 덧붙임 |
| `ADDED_METHOD` | ★글이 하지 않은 서술 방식 | 글이 쓰지 않은 서술 방식(비교, 장단점 분석, 시대순 서술 등)을 썼다고 했어. | 일반: 글은 장단점을 비교하지 않았는데, 선지는 "장단점을 비교하며" |

`OTHER`(기타): 유형 이름을 보이지 않는다. 꼬리표는 "그 밖의 함정", 카드에는 바뀐 내용 문장만. "자주 걸린 함정" 집계에서 뺀다.

세트 E에 나오지 않는 유형: `CONFLATION`·`WRONG_REASON`·`ABSOLUTIZE`·`DEGREE`. 다른 세트를 위해 함께 정한다.

## 2. 관계 4갈래

| 갈래(내부) | 학생용 이름 | 한 줄 설명 | 들어가는 관계(정의 확인용) |
|---|---|---|---|
| 내용 | 대상 사이의 관계 | 원인과 결과, 순서, 조건, 목적, 대조, 종류처럼 지문 속 대상들이 서로 어떻게 이어지는지 | 인과·작용, 과정·순서, 조건·분기, 수단·목적, 대조, 병렬·공통, 분류·구성 |
| 논증 | 주장과 근거 | 글이 무엇을 근거로 말하는지, 예를 들어 풀고 원리를 적용하고 예외를 두는지 | 근거·도출, 구체화·예시, 원리 적용, 정의·명명, 양보·한계, 문제·대응 |
| 관점 | 사람·이론 사이의 입장 | 누가 누구와 생각이 같거나 다른지, 누가 누구를 비판하거나 평가하는지 | 관점 차이, 공통·수용, 비판·반박, 해석·평가 |
| 흐름 | 글의 흐름 | 왜 그 논의가 나왔는지, 화제가 어디서 어디로 넘어가는지 | 배경·계기, 전개·전환 |

화면 문장 예(숫자는 형식 확인용): "이번 요약에서 **주장과 근거**는 8곳 중 6곳을, **글의 흐름**은 6곳 중 2곳을 잡았어."
분모는 문단 안 관계만 센다(D-0160).

## 4. 코드 에이전트 점검(정확성·단정·형식)

- 정확성: 한 줄 설명이 원 정의의 범위를 벗어나지 않는지 대조했다. 관계 갈래 설명은 오른쪽 칸 유형을 모두 덮는다
  (병렬·공통은 열거에 없지만 "서로 어떻게 이어지는지"에 포함).
- `WRONG_REASON` 이름의 "상관없는": 원 정의는 "묻는 현상의 이유가 아닌데 이유로 이음"이다. 두 사실이 다른 방식으로는 관련될 수
  있으므로(예: 같은 단락의 같은 대상) "상관없는"은 "원인·결과로는 상관없는"의 뜻이다. 한 줄 설명이 이 범위를 밝혀 주므로 그대로 둔다.
- 단정: 학생 능력 평가 없음. 독해 패턴은 개수로만 말한다.
- 형식: 반말, 설명 한두 문장.

## 5. "바뀐 내용" 문장 (화면 인계 B 범위)

- 지금 동결본 `twistDetail`은 개발용 명사구다(예: "초기 녹음기의 아날로그 저장을 디지털 저장으로").
- 방향(사용자 추천, 2026-11-06): 세트가 고정돼 있으므로 학생용 문장을 한 번 생성하고 사람이 손본 뒤 세트 자료로 고정한다. 런타임 생성 단계는 두지 않는다.
- 규모: 세트 E 동결본의 비틀린 선지 43개(비틀린 조각 51개). 사용자 판정 때의 "약 60개"는 오답 선지 전체(16문항 × 4)를
  센 것으로 보이며, "옳지 않은 것" 문항의 오답 선지는 맞는 말이라 바뀐 내용이 없다.
- 생성은 외부 전송이므로 범위(요청 수·상한)를 따로 승인받는다. 손질은 사용자 판정 대상이다.

## 6. 화면 문구 (인계 B 실행 중 추가, 사용자 확인 2026-11-07)

인계 B에 없던 문구를 하위 에이전트가 화면에 쓰고 보고했다(`docs/handoffs/2026-11-06-sns-diagnostic-screen.md` 결과 보고). 사용자가 코드 에이전트 권고대로 확정했다.

- 새로 지은 문구(그대로 확정): 머리 "지문 n/N", 버튼 "이전 문항"·"다음 문항"·"다음 지문"·"결과 보기"·"접기", 답 칸 제목 "내 답",
  문항 번호 묶음 이름 "문항 이동"(화면 읽기 프로그램용), 중간 화면 칸 이름 "이 지문까지의 위치"·"이 지문 결과",
  결과 화면 범례 "채운 칸은 정답, 테두리 칸은 오답, 점선 칸은 확인 중이야. 칸을 누르면 아래 카드가 펼쳐져."
- 고친 문구: 좁은 화면 탭 "답" → **"내 답"**(근거도 쓰는 칸이라 "답"만으로는 정답 보기처럼 읽힐 수 있고, 칸 제목과 맞춤).
- 확인만 한 문구: "이번에 걸린 함정: {이름}"은 인계 B J5에 이미 있다. 요약 화면의 "이 문단의 중심 내용과 관계를 자기 말로 써 봐."·
  "내 생각을 적어 봐…"·"이 문단은 끝났어."·"다음 문단"은 기존 문단 요약 화면(`SimpleDialogueApp.tsx`) 문구를 그대로 썼다.
