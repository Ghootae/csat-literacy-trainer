# 문제 풀이 진단 시스템 구현 계획

최초 작성일: 2026-08-26

대상 브랜치: `experiment/problem-solving-mvp`

## 1. 문서 목적

이 문서는 문제 풀이 진단 시스템의 구현 순서, 섹션별 산출물, 완료 조건과 현재 상태를 기록하는 실행 계획이다.

첫 제품 수직 슬라이스는 로컬 데이터 정본과 그림이 확보된 mRNA 백신·지질 나노 입자 19번 문항으로 만든다. PCR Ct 사례는 하나의 상위 표상 오류를 최소 개입으로 교정하는 기대 행동 기준으로 보존한다. 시스템은 학생의 오답을 즉시 설명하지 않고, 선택과 근거를 함께 설명하는 사고 경로를 필요한 만큼만 복원한 뒤 최초 오류를 가장 작은 개입으로 수정하게 해야 한다.

문단 이해 시스템의 `axis-dialogue-v2` 판정 규칙은 변경하지 않는다. 문단 이해 결과는 문제 풀이의 정답 기준이 아니라 학생 표상의 사전 정보로만 사용한다.

## 2. 상태와 갱신 규칙

상태는 다음 네 값만 사용한다.

| 상태 | 의미 |
|---|---|
| `PENDING` | 아직 시작하지 않음 |
| `IN_PROGRESS` | 현재 작업 중인 섹션 |
| `BLOCKED` | 외부 결정이나 자료가 없어 진행할 수 없음 |
| `COMPLETED` | 산출물, 완료 조건, 검증을 모두 충족함 |

한 번에 한 섹션만 `IN_PROGRESS`로 둔다. 섹션을 완료할 때마다 같은 변경에서 다음을 함께 수행한다.

1. 상단 진행 현황표의 상태를 `COMPLETED`로 변경한다.
2. 해당 섹션의 체크리스트와 검증 결과를 실제 결과에 맞게 갱신한다.
3. `진행 기록`에 날짜, 완료 내용, 검증 결과, 남은 제한을 추가한다.
4. 다음 섹션을 시작한다면 그 상태를 `IN_PROGRESS`로 변경한다.
5. 계획이 바뀌면 기존 결정을 지우지 않고 변경 이유를 진행 기록에 남긴다.

테스트가 일부 실패한 상태에서는 실패가 이번 변경과 무관하다는 근거가 있더라도 이를 기록하고, 해당 섹션의 완료 조건이 충족됐는지 별도로 판단한다.

## 4. 구현 불변 조건

모든 섹션에서 다음 조건을 지킨다.

- 오답일 때 학생의 선택 근거를 진단 출발점으로 사용한다.
- 대표 오답 경로는 참고 후보로만 사용하며 새로운 학생 경로를 허용한다.
- 학생이 실제로 말하거나 선택한 관찰과 모델의 추론을 분리한다.
- 네 가지 충분성 조건을 모두 만족할 때만 경로를 충분하다고 판정한다.
- 충분한데 추가 진단을 하지 않고, 불충분한데 성급하게 교정하지 않는다.
- 한 턴에는 다음 행동과 학생용 질문을 각각 하나만 선택한다.
- 진단 질문은 대안 가설을 구별하고, 교정 질문은 특정된 최초 오류를 수정한다.
- 이미 확인된 내용이나 현재 오답과 무관한 지문 내용을 다시 검사하지 않는다.
- 질문 문장을 학생 지식의 증거로 저장하지 않는다.
- 정답 선지와 전체 정답 경로를 교정 전에 불필요하게 노출하지 않는다.
- 과거 문단 표상과 개인 경향은 현재 오류의 사전 정보이며 확정 판정이 아니다.
- 최대 진단 횟수 이후에는 무제한 질문 대신 직접 코칭으로 전환한다.
- 최종 정오뿐 아니라 개입 깊이, 자기 교정, 재발과 전이를 기록한다.
- 기본 골드는 지문·발문·보기·그림·선지·정답 키에서 생성하며 공식 해설을 생성 근거로 사용하지 않는다.
- 문항 골드는 확정된 지문 명제를 수정하거나 해설의 추가 관계를 지문 명제로 역수입할 수 없다.
- 공식 해설의 추가 관계는 `supplementalExplanationInferences`에만 저장하고, 기본 골드로 판정할 수 없는 경우에만 검토된 보조 정보로 사용한다.
- 정답 기준 경로는 선지를 판정하는 데 필요한 최초 결정적 분기까지만 요구하며, 불필요한 후속 결론을 학생의 필수 이해로 취급하지 않는다.
- `NOT_JUSTIFIED`는 내용 평가일 뿐 그 자체로 거짓 판정이 아니며, 기각할 때는 별도의 판정 근거를 명시한다.
- 보충 해설은 학생의 설명 요청, 기본 교정 실패 또는 직접 코칭 단계처럼 허용된 조건에서만 사용한다.
- 사전 오답 경로의 분기 층위는 확정 진단이 아니라 복수의 후보로 저장하고 현재 학생 응답으로 검증한다.
- 정답 선택과 올바른 근거를 동일시하지 않는다. 정답 근거 입력은 선택 사항이며, 제출된 근거에 명백한 오류가 확인된 경우에만 근거 진단으로 진입한다.
- 정답 근거가 모호하거나 평가가 불확실하다는 이유만으로 진단을 시작하지 않는다. 정답 선택 후 개입은 학생 근거와 골드가 명백히 충돌할 때로 제한한다.

### 섹션 1. mRNA 19번 문항·시각 골드

상태: `COMPLETED`

목표는 로컬 데이터베이스의 고2 2023년 3월 교육청 모의평가 「mRNA 백신과 지질 나노 입자」 19번을 첫 제품 수직 슬라이스의 골드로 고정하고, 그림·표가 있는 문항의 공통 처리 기준을 마련하는 것이다.

작업:

- 로컬 정본 JSON에서 출처 ID, 발문, 보기, 선지와 이미지 배치를 정확히 구조화한다.
- 이미지 URL, 해시, 크기, 역할, 필수 여부와 대체 설명을 기록한다.
- 그림의 라벨·흐름·결합 관계를 `visualAssertions`로 분리한다.
- 지문 명제는 원문 명시·함의 관계만 포함하고 문항 적용 추론과 분리한다.
- 각 선지를 원자적 주장으로 분해하고, 주장별 상태·의존 관계·결정적 여부를 기록한다.
- 주장에 대한 내용 평가, 근거 강도, 운영상 판정과 판정 근거를 서로 분리한다.
- 주장별 보충 해설 fallback과 사용할 수 있는 런타임 조건을 구조화한다.
- 정답 ⑤의 결정적 경로는 pH 상승과 중성화 적용 뒤 ‘소수성 약화’ 연결을 판정하는 지점까지만 둔다.
- 공식 해설의 소수성 강화·인력 증가·결합 증가·복합체 크기 증가는 별도의 보충 해설 층에 저장한다.
- 선택한 오답의 오류 후보와 정답 ⑤를 놓친 오류 후보를 분리한다.
- 필수 시각 자산을 읽을 수 없을 때 문항을 사용 불가로 처리할 수 있도록 필수 여부를 기록한다.
- 사람 검토 후에만 골드 상태를 `human_reviewed`로 승격한다.

완료 조건:

- [x] 로컬 정본의 출처 ID와 경로가 보존된다.
- [x] 이미지 자산의 URL, SHA-256, 크기와 배치가 보존된다.
- [x] 그림의 두 입력, Y자 관 합류와 복합체 형성이 시각 의미 ID로 구조화된다.
- [x] 지문 명제가 MP1~MP5로 제한되고 문항 추론과 분리된다.
- [x] 모든 선지가 원자적 주장과 제시문·보기·시각 정보에 연결된다.
- [x] ⑤가 네 주장으로 분해되고 `OC5-2`가 최초 결정적 분기로 표시된다.
- [x] 실제 복합체 크기 증가가 결정적 경로에서 제거되고 공식 해설 보충 층에만 남는다.
- [x] `NOT_JUSTIFIED` 평가와 `ANSWER_KEY_CONSTRAINED` 기각 판정이 분리된다.
- [x] SI1 fallback이 설명 요청·교정 실패·직접 코칭 조건에만 연결된다.
- [x] 필수 경로, 결정적 분기 RP4와 결론 RP5가 분리된다.
- [x] 선택 오답 경로 WP1~WP4A·WP4B와 정답을 놓친 경로 WP5A~WP5D가 분리된다.
- [x] 사전 오답 경로가 복수의 `candidateDivergenceLayers`를 허용한다.
- [x] ②의 ‘속도 조절’ 해석 경계를 검수 메모로 보존한다.
- [x] 후보 골드가 스키마 검증과 타입 검사를 통과한다.
- [x] 수정된 정보 계층과 ⑤의 결정적 경로를 사람이 다시 검토한다.
- [x] 재승인 후 `human_reviewed`로 승격한다.

### 섹션 2. 진단 에피소드 계약과 기대 에피소드

상태: `COMPLETED`

목표는 관찰·추론·검증·결과를 분리하고 모델이 매 턴 반환할 구조를 코드 계약으로 고정하는 것이다.

작업:

- `ProblemDiagnosticEpisode` 스키마를 만든다.
- 관찰 층에 최초 선택, 확신도, 근거, 선택적 전략, 차선 후보, 후속 답변, 재선택을 저장한다.
- 추론 층에 선택 오답과 놓친 정답의 독립 타깃, 재구성 경로, 최초 오류 후보, 대안 가설과 참조 근거를 저장한다.
- 충분성 네 조건을 타깃별 boolean과 근거로 출력하게 한다.
- 서로 다른 개입을 요구하는 활성 가설이 남을 때만 추가 진단을 요구한다.
- 매 턴 활성 진단 타깃을 하나만 선택하되 다른 타깃의 미평가·불충분·충분 상태를 보존한다.
- 합리적인 문항 해석 이의를 학생 오류와 분리하고 문항 경계 설명으로 처리한다.
- 검증 층에 후속 답변과 재선택이 가설을 지지·기각한 결과를 저장한다.
- 결과 층에 최종 정오, 개입 수준, 수정된 표상과 전이 확인 대상을 저장한다.
- 다음 행동 유니온을 구현한다.

```ts
type ProblemSolvingNextAction =
  | 'ASK_DIAGNOSTIC'
  | 'ASK_CORRECTIVE'
  | 'REQUEST_RESELECTION'
  | 'DIRECT_COACHING'
  | 'COMPLETE';
```

- 충분성 판정과 다음 행동의 모순을 코드에서 거부한다.
- 질문이 필요한 행동에는 질문 하나만, 그 외 행동에는 질문이 없도록 검증한다.

## 6. MVP 이후로 미루는 범위

다음은 mRNA 19번 수직 슬라이스와 PCR 행동 기준 또는 두 번째 로컬 문항의 교차 검증이 끝날 때까지 구현하지 않는다.

- 완결된 오류 유형 분류 체계
- 고정 진단 질문 은행
- 자동 골드 승인
- 학생의 고정 성향을 단일 에피소드로 확정하는 기능
- 고도화된 개인화 추천
- 장기 전이 점수의 자동 산출

개인화 모델은 에피소드 저장 구조만 고려하되, 반복되고 후속 문항에서 검증된 경향을 승격하는 정책은 실제 데이터가 쌓인 뒤 별도 계획으로 다룬다.
