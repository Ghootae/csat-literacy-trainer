# 전체 골드 모델 품질 비교 프롬프트 v1

입력은 코드가 확정한 4방향 프로필, 학생이 버튼으로 고른 선지, 학생 근거, 전체 기본 골드다. 모델 비교의 최우선 기준은 비용이 아니라 인간이 고정한 근거 판정 품질이다.

## 결정권

- `evaluationContext.profile`, `selectionCorrect`, `choiceDecision`, `selectionIntent`는 코드가 확정했다. 바꾸거나 재계산하지 않는다.
- `choiceDecision`은 대상 선지가 실제로 채택되어야 하는지(`ACCEPTED`) 또는 기각되어야 하는지(`REJECTED`)를 뜻한다.
- 모델은 학생 근거가 이 실제 판단을 승인된 원문·보기·시각 근거로 타당하게 뒷받침하는지만 판정한다.
- 선지 문장을 다시 말한 부분은 근거가 아니다. 학생이 제시한 이유·관계·조건을 평가한다.

## 충분성 정책

- 입력의 `sufficiencyPolicy`를 따른다.
- 전체 골드의 기존 `itemInference`와 파생 sufficient set은 대표 승인 경로이지 가능한 모든 유효 경로의 완전한 목록이 아니다.
- 학생이 기존 대표 경로와 다른 설명을 제시해도 전체 골드의 승인 원문·보기 사실만으로 그 경로가 성립하면 유효한 대안 충분 경로로 인정한다.
- 다른 대표 경로에 포함된 전제를 학생의 독립적인 대안 경로에 추가로 요구하지 않는다.
- 학생이 핵심 인과 관계와 선택 결론을 명시했다면, 승인 근거에 있는 중간 용어를 그대로 재현하지 않았다는 이유만으로 거부하지 않는다.
- 단, `ALL_OF`에서 서로 독립적인 핵심 대상이나 조건을 실제로 누락했다면 `INSUFFICIENT`다. 예를 들어 선지가 a와 b 모두를 요구하는데 a만 설명하면 충분하지 않다.

## 모든 실질 주장 분해

- 학생 근거의 선택 결론만 보지 말고 이유로 제시한 실질 주장을 빠짐없이 별도 finding으로 평가한다.
- 핵심 근거가 맞아도 틀린 부가 설명을 생략하지 않는다.
- 학생이 제시한 경로에서 선택 결론에 필요한 전제이면 `DECISIVE`, 없어도 올바른 선택 근거가 유지되면 `NON_DECISIVE`다.
- 결정적 핵심이 충분하고 틀린 내용이 비결정적 부가 설명에 한정되면 전체 `SUPPORTED`를 유지하고, 부가 오류는 `NON_DECISIVE CONFLICTS` finding으로 보존한다.
- 입력에 없는 사실을 상식이나 정답 키로 보충하지 않는다.

## 판정

- `SUPPORTED`: 학생 근거가 실제 `choiceDecision`의 승인된 충분 경로 하나를 충족하고 결정적 충돌이 없다.
- `CONTRADICTED`: 승인 근거로 학생이 제시한 결정적 주장의 부정을 도출할 수 있다.
- `INSUFFICIENT`: 학생이 충분 경로를 완성하지 못했거나 제시한 결정적 주장도 그 부정도 승인 근거에서 도출되지 않는다.
- `DECISIVE MATCHES` 일부가 있어도 독립 핵심 전제가 빠지면 전체는 `INSUFFICIENT`일 수 있다.

## DOES_NOT_JUSTIFY

- `DOES_NOT_JUSTIFY`는 약한 모순이 아니다. 주장과 그 부정 모두 승인 근거에서 도출되지 않는 독립 관계다.
- 학생이 `DOES_NOT_JUSTIFY` 대상 주장을 사실이라고 단정하면 `NOT_ESTABLISHED`다. 반대 사실이 도출될 때만 `CONFLICTS`다.
- 프로필이 `WRONG_*`이거나 실제 선지가 `REJECTED`라는 이유만으로 `CONTRADICTED`를 출력하지 않는다.

## 출력 근거

- `studentQuote`는 학생 근거에 실제로 존재하는 연속 문자열만 사용한다.
- `sourceRefs`는 입력 `evidenceGold`에 실제 존재하며 해당 finding을 직접 뒷받침하는 ID만 사용한다.
- `MATCHES`: 승인 근거로 학생 주장을 도출할 수 있다.
- `CONFLICTS`: 승인 근거로 학생 주장의 부정을 도출할 수 있다.
- `NOT_ESTABLISHED`: 학생 주장도 그 부정도 도출되지 않는다.
- 자연어 후처리로 구조화 판정을 뒤집지 않으므로 출력 계약을 엄밀히 지킨다.
