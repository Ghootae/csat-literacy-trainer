## 학생 응답에 비추어 누락의 중요도를 판정하는 순서

아래 순서를 현재 호출 안에서 적용한 뒤 axisStates와 axisFeedback을 함께 확정한다.
별도 판정기, 새 중심축, 명제 점수 또는 고정 필수/선택 목록을 만들지 않는다.

1. 먼저 학생의 누적 발화에서 이미 확인한 해당 축의 의미를 파악한다. 특정 단어의 부재는 의미 누락과 다르다. 바꿔 말하기·질문 문맥·분명한 생략으로 표현된 의미를 누락으로 세지 않는다.
2. 여전히 미확인인 의미가 있다면 축 description 안에서 무엇인지 특정한다. 원문으로 새 요구를 만들거나, 학생이 말하지 않은 정답을 보충하지 않는다.
3. 이미 표현한 내용을 함께 고려하여, 그 미확인 때문에 이 축의 중심 설명을 이해했다고 보기 어려운 구체적인 공백이 남는지 판단한다. 단순히 축 문장에 포함되어 있다거나 더 정확히 말할 수 있다는 이유만으로 중요한 누락으로 보지 않는다.
4. 중심 주체·대상·역할·관계 자체, 변화 전후의 연결, 인과·대조의 방향, 주장 범위를 정하는 조건·부정 등이 확인되지 않아 설명이 실질적으로 달라지는 경우와, 중심 설명이 이미 보존된 뒤의 위상·강조·부연 누락을 구별한다. 어떤 종류의 단어라는 이유만으로 자동 분류하지 않는다. 조건의 생략을 반대 주장이나 조건 없는 단정으로 바꾸지 않는다.
5. 위 판단을 반영하여 다음 중 하나로 확정한다.
   - PASS / captured: 학생이 축의 중심 설명을 충분히 보존했다. 남은 차이가 부수적 표현·위상·중복 구체화뿐이면 이를 독립 미충족 요건으로 남기지 않는다. 단, 학생이 확인하지 않은 별개 중심 내용을 이해한 것으로 보충하지 않는다.
   - UNCLEAR_OK / partial 또는 unknown: 일부 의미는 아직 미확인이나, 학생이 이미 표현한 중심 관계를 고려할 때 중요한 공백이라고 판단할 근거가 약하다. 충분하다고 확정할 근거도 부족하므로 PASS와 구별한다. 경계가 애매하면 OK 쪽으로 판단하되 학생 근거가 전혀 없는데 확인된 의미를 만들어내지 않는다.
   - UNCLEAR_SERIOUS / partial 또는 unknown: 중요한 중심 설명을 이해했다고 볼 근거가 매우 부족하다. 이미 표현한 내용으로도 메워지지 않는 공백이 무엇인지 구체적으로 설명한다. 단어 나열만으로 관계를 복원하지 않는다.
   - ERROR / distorted: 학생이 현재 유지하는 명시적 오류가 있다. 누락의 중요도 판단을 이유로 오류를 완화하거나 맞는 주장으로 상쇄하지 않는다. 누락과 오류는 별개다.

axisFeedback.reason에 '이미 확인한 의미 / 남은 공백 또는 표현 차이 / 그것이 중심 설명에 미치는 영향'을 짧게 남긴다. 긴 내부 추론이나 새 출력 필드는 쓰지 않는다.
누락 개수·글 길이·압축 점수를 사용하지 않는다. 사소한 누락을 모두 PASS로 바꾸라는 지시가 아니다.
PASS는 확인된 축 의미를, OK는 확인된 올바른 부분만 revealedText에 재서술한다. SERIOUS/ERROR는 null이다.
각 축은 한 번씩 포함하고, PASS/OK의 revealedText에는 실제 학생 근거가 있어야 한다.
